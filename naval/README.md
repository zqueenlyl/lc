# 《纳瓦尔宝典》学习笔记

> 硅谷投资人纳瓦尔·拉维坎特（Naval Ravikant）把「致富」和「幸福」都当成**可练习的技能**。核心问题：怎样不靠运气创造财富，同时不把人生交出去换地位？

一句人话：**财富 = 专长 × 责任 × 杠杆；幸福 = 减少欲望、回到当下。两件事都是技能，不是抽奖。**

本书是埃里克·乔根森（Eric Jorgenson）把纳瓦尔十年推特、播客、采访编成的原则集，中文版《纳瓦尔宝典》（中信，2022）。本目录是**学习笔记**，按原书两大部分（财富 / 幸福）重组，不摘录正文。读完不等于会用，过线见 [08](./08-自测与实践清单.md)。

- 微信读书：[纳瓦尔宝典](https://weread.qq.com/web/reader/e1e32b00729fc94fe1e824d)
- 英文公开版：[navalmanack.com](https://www.navalmanack.com/)
- 一手长文：[How to Get Rich](https://nav.al/rich)、[Happiness](https://nav.al/happiness)

1. **三组分词不混**：财富 / 金钱 / 地位；专长 / 可培训技能；欲望合同 / 目标。
2. **写得出杠杆账**：现在出租的是时间、资本、代码还是媒体；睡觉时有没有收入。
3. **走得完一次真实选择**：换工作、上产品或签欲望，用诊断四问写出四行。
4. **拆得掉点名误解**：努力上班就会致富、杠杆 = 管人、幸福是性格、地位就是成功、冥想是清空大脑。

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| **财富（Wealth）** | 睡觉时仍在为你工作的资产（工厂、代码、内容、股权），买的是自由 |
| **金钱（Money）** | 社会开给你的 IOU，用来转移财富，会被稀释 |
| **地位（Status）** | 社会等级里的排名；零和，赢必须有人输 |
| **专长（Specific Knowledge）** | 教不会、学得会；来自好奇心和天赋，看起来像玩 |
| **责任（Accountability）** | 用真名签字，成功归你、失败也归你，才能拿到股权 |
| **杠杆（Leverage）** | 劳动力、资本、代码、媒体；后两种无需许可、复制成本趋零 |
| **判断力（Judgment）** | 预见行动的长期后果；杠杆无限时，这是最贵的技能 |
| **产品化自己（Productize Yourself）** | 把「你」×「专长」×「杠杆」做成可规模化的产品 |
| **欲望合同** | 欲望 = 在得到之前自愿当不开心的人 |
| **退休（纳瓦尔用法）** | 停止为想象中的明天牺牲今天；不是「存够钱就不干活」 |
| **理性佛教** | 要冥想与无常，不要宇宙论和仪式 |

## 常见误解速查（本目录反复纠正的几条）

| 误解 | 正确 |
|---|---|
| 努力上班、加班、升职就会致富 | 出租时间换的是金钱，有上限；财富来自睡觉时仍在工作的资产 |
| 财富、金钱、地位是一回事，「成功」就够了 | 三个词规则不同：正和资产 / IOU / 零和椅子 |
| 杠杆 = 管很多人，或把自己逼到极限 | 劳动力是最差杠杆；新杠杆是代码和媒体；努力的对象是建立杠杆，不是填满日历 |
| 热门岗位、能开班教会的技能就是专长 | 能批量教的会被替代；专长对你像玩、对别人像工 |
| 在大公司努力本身就是终点 | 那是攒专长和信誉的手段，终点是所有权（创立或买入股权） |
| 判断力 = 智商，或读过很多商业书 | 判断力是看见长期后果；商业书教的是已被竞争掉的优势 |
| 幸福是性格抽签，或成功附赠 | 幸福是可练的技能；成功是外部记分牌 |
| 欲望驱动进步，所以越多越好 | 每份欲望都是「得到之前不开心」的合同；少签、签大的 |
| 冥想是把脑子清空，或一种高级体验 | 冥想是看见念头来去，拉开观察者和内容的距离 |
| 伦理是吃亏，长期博弈太慢 | 伦理是长期的贪婪；占眼前小便宜是在砍自己的贴现率 |

## 主线怎么串

```
日历被谁填？
  别人 → 还在出租时间（02）
  自己 → 问：睡觉时有没有收入？
    没有 → 缺专长 / 责任 / 股权 / 杠杆（02–03）
    有   → 问：放大的方向对不对？（04）

内心吵不吵？
  匮乏、不安全 → 先财富（01–03），不要在 hard mode 上修心
  比较、嫉妒   → 地位游戏还是欲望合同（01、05）
  念头停不下来 → 习惯、冥想、薄身份（05–07）

任何选择先写四行（08）：
  哪场游戏？钱怎么来？合同要不要签？放大的是什么？
```

## 怎么读这本书（以及这份笔记）

1. **当原则集，不当传记。** 原书自己也说：这是一本可跳读的手册，不是必须从第 1 页读到最后。
2. **先建立坐标系再收集金句。** 没有「财富 ≠ 地位」这一步，后面所有杠杆口诀都会被听成鸡汤。
3. **对照自己的杠杆账。** 读完 02–03，用一句话回答：我现在出租的是时间、资本、代码，还是媒体？答不出就去 [08](./08-自测与实践清单.md)。
4. **幸福章不要当效率技巧。** 05–07 的目标是内心噪音下降，不是「更幸福所以更赚钱」——后者只是副作用。

一手尽量读 [nav.al](https://nav.al/rich)；中文版用来对齐章节标题和阅读节奏。本笔记负责把主张收成可检索的骨架，并给一套能填空的自检。
