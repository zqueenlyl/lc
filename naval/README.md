# 《纳瓦尔宝典》学习笔记

> 硅谷投资人纳瓦尔·拉维坎特（Naval Ravikant）把「致富」和「幸福」都当成**可练习的技能**。核心问题：怎样不靠运气创造财富，同时不把人生交出去换地位？

一句人话：**财富 = 专长 × 责任 × 杠杆；幸福 = 减少欲望、回到当下。两件事都是技能，不是抽奖。**

本书是埃里克·乔根森（Eric Jorgenson）把纳瓦尔十年推特、播客、采访编成的原则集，中文版《纳瓦尔宝典》（中信，2022）。本目录是**学习笔记**，按原书两大部分（财富 / 幸福）重组，不摘录正文。

## 学习路线

```
坐标系
  01 人物与坐标系

财富（先解决「钱的问题」）
  02 积累财富 ──► 03 杠杆 ──► 04 判断力

幸福（钱解决不了的部分）
  05 学习幸福 ──► 06 自我救赎 ──► 07 哲学
```

- **只想搞清「怎么不出租时间」**：读 01 → 02 → 03。
- **已经有杠杆、卡住的是决策质量**：加读 04。
- **钱不是瓶颈、内心仍吵**：从 05 读到 07。纳瓦尔自己的顺序是先财富后幸福——物质匮乏时硬修心，是在 hard mode 上打游戏。

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| **财富（Wealth）** | 睡觉时仍在为你工作的资产（工厂、代码、内容、股权），买的是自由 |
| **金钱（Money）** | 社会开给你的 IOU，用来转移财富，会被稀释 |
| **地位（Status）** | 社会等级里的排名；零和，赢必须有人输 |
| **专长（Specific Knowledge）** | 教不会、学得会；来自好奇心和天赋，看起来像玩 |
| **责任（Accountability）** | 用真名签字，成功归你、失败也归你，才能拿到股权 |
| **杠杆（Leverage）** | 劳动力、资本、代码、媒体；后两种无需许可、复制成本趋零 |
| **判断力（Judgment）** | 预见行动的长期后果；杠杆无限时，这是最贵的技能 |
| **产品化自己（Productize Yourself）** | 把「你」×「专长」×「杠杆」做成可规模化的产品 |
| **欲望合同** | 欲望 = 在得到之前自愿当不开心的人 |
| **理性佛教** | 要冥想与无常，不要宇宙论和仪式 |

## 怎么读这本书（以及这份笔记）

1. **当原则集，不当传记。** 原书自己也说：这是一本可跳读的手册，不是必须从第 1 页读到最后。
2. **先建立坐标系再收集金句。** 没有「财富 ≠ 地位」这一步，后面所有杠杆口诀都会被听成鸡汤。
3. **对照自己的杠杆账。** 读完 02–03，用一句话回答：我现在出租的是时间、资本、代码，还是媒体？
4. **幸福章不要当效率技巧。** 05–07 的目标是内心噪音下降，不是「更幸福所以更赚钱」——后者只是副作用。

一手尽量读 [nav.al](https://nav.al/rich)；中文版用来对齐章节标题和阅读节奏。本笔记负责把主张收成可检索的骨架。
