# 01. 人物与坐标系：财富、金钱、地位

> 先分清三个经常被混用的词。后面所有「致富」口诀，都长在这三个词的差别上。

一句人话：**财富是睡觉也在干活的资产，金钱是 IOU，地位是零和椅子。先分清这三个词，再收集金句。**

---

## 一、这本书是谁在说话

**纳瓦尔·拉维坎特**（Naval Ravikant）：AngelList 联合创始人，早期投过 Twitter、Uber 等。公开身份是投资人，真正被传播的是一套**关于财富与幸福的实践哲学**——十年间写在推特、播客和采访里，不是写在一本系统教材里。

**埃里克·乔根森**把这些碎片编成《纳瓦尔宝典》（*The Almanack of Naval Ravikant*）。原书结构很直：

| 部分 | 回答的问题 |
|---|---|
| **财富** | 怎样不靠运气、不出租时间地创造资产 |
| **幸福** | 钱解决不了之后，内心怎么安静下来 |

纳瓦尔自己的顺序也是这个：先解决物质匮乏（否则欲望会以「生存」的名义绑架你），再练幸福。颠倒过来不是不行，只是难很多。

一句人话：**这不是成功学，是一张「创造资产 + 降低内心噪音」的原则表。**

---

## 二、三个词，不要混

| 词 | 是什么 | 不是什么 |
|---|---|---|
| **财富** | 睡觉时仍在工作的资产：代码、内容、股权、能出租的工厂 | 工资、奖金、炫耀性消费 |
| **金钱** | 社会开给你的 IOU，用来**转移**财富 | 财富本身；印多了会被稀释 |
| **地位** | 等级里的排名：谁先说话、谁被羡慕 | 自由；地位涨，往往有人必须掉 |

纳瓦尔的公开定义（推特原文大意）：**追求财富，而不是金钱或地位。财富是睡觉时仍在为你赚钱的资产。**

财富买的是**自由**：不用 7 点赶地铁、不用把领带当项圈、不用把最好的小时数卖给一份不认同的工作。游艇和皮草很快会无聊；日历不被别人填满，才是目标。

---

## 三、两场游戏

人生里同时进行两场大赛，规则完全不同。

| | 财富游戏 | 地位游戏 |
|---|---|---|
| **和谁玩** | 把新东西做出来 | 在既有梯子上爬 |
| **和零** | **正和**：你有房不妨碍我有房 | **零和**：第三名要变第二，第二必须让位 |
| **进化来源** | 农耕以后才能储存剩余 | 更古老：部落里谁是 1 号 |
| **攻击方式** | 创造被攻击时，对手常改打地位牌 | 把别人踩下去，自己才显得高 |
| **情绪产物** | 建设、复利 | 愤怒、比较、道德姿态 |

记者骂科技新贵、网上骂「有钱就是原罪」，很多时候不是在讨论分配公式，而是在**用道德换地位**。地位游戏要赢，必须有人输——所以它会把人练成好斗的。

不是说地位不存在：谁来拍板、谁被信任，社会需要等级。只是**别把地位游戏误认成财富游戏**。前者零和，后者可以把蛋糕做大。

记忆口诀：**财富做大蛋糕，地位抢椅子。**

对照自己：上周日历里，建造（产品、代码、作品、交易）和表演（比较、站队、被看见）哪个更长？前者偏财富游戏，后者偏地位游戏。填空见 [08](./08-自测与实践清单.md)。

## 四、伦理边界：做大，不是拿走

纳瓦尔反复划一条线：**真正的财富创造是给世界增加丰盛**，不是从别人口袋里掏。

- 掠食 / 寻租 / 垄断 / 把污染成本甩给别人 → 这是「拿」，不是「做」。
- 科技把过去只有国王才有的东西（电、抗生素、手机）变成穷人也能用的 → 这是「做」。

思想实验：如果每个人都有优秀软硬件工程师的知识，社会 20 年后会怎样？他的答案是机器人、自动化农场、自动驾驶把「为生存而做的劳动」压下去，剩下的工作更接近创造。这不是预测报告，是为了说明：**财富不是存量争夺，是知识变成丰盛。**

配套判断：一个社会如果「拿的人」太多、「做的人」太少，会塌。他拿委内瑞拉当反例——重点不是党派，是**寄生比例过高，宿主会死**。

本笔记不讨论具体政见。带走的工程含义只有一句：**你要站在创造丰盛那一侧，并且能讲清你创造了什么。**

## 五、致富是技能，不是中奖

很多人把有钱归因于运气。纳瓦尔要的是另一件事：

> 在 1000 个平行宇宙里，你要在 999 个里都富裕，而不是只在 50 个幸运宇宙里富裕。

技能可以迁移：他说过类似的话——如果把钱清零、扔到任何一个英语国家的街上，若干年内还能再站起来，因为那是一套练过的能力，不是一次抽签。

运气不是零。他借用过一种四分法（经 Marc Andreessen 转述）：

| 类型 | 含义 | 你能做什么 |
|---|---|---|
| 盲目运气 | 纯随机 | 无法设计 |
| 主动运气 | 多动就多撞 | 提高尝试次数 |
| 识别运气 | 准备好了才能看见 | 练判断力 |
| 吸引运气 | 别人因为你是谁而把机会送上门 | 把专长和信誉做出来 |

目标不是消灭运气，是**把自己变成运气愿意停留的人**。展开见 [02-积累财富](./02-积累财富.md)。

## 六、原书怎么用、这份笔记怎么用

| 读法 | 适合 |
|---|---|
| 跳读金句 | 已经有坐标系，只要提醒 |
| 按财富 → 幸福读完 | 第一次建立整张图 |
| 只读 02–04 | 正在选工作 / 创业 / 是否拿股权 |
| 只读 05–07 | 物质不是瓶颈，内心很吵 |
| 过线填空 | [08-自测与实践清单](./08-自测与实践清单.md) |

原书还有推荐序、经历表、生命公式、个人原则。那些是**人的上下文**，不是另一套定理。人物背景够用这一页；公式和原则收到 [07-哲学](./07-哲学.md)。

## 七、本章纠正

| 误解 | 纠正 |
|---|---|
| 工资高 = 已经在积累财富 | 工资是金钱（IOU）；财富是睡觉时仍在工作的资产 |
| 被羡慕、职级高 = 成功 | 那是地位游戏；零和，赢必须有人输 |
| 有钱都是运气 | 目标是 1000 个平行宇宙里 999 个都站得住；运气要变成愿意停留的那种 |

**自检**：用一句话分开你的薪水、存款、作品 / 股权、粉丝数——哪个是财富，哪个是金钱，哪个是地位？答不出，先不要往下收集杠杆口诀。

**记忆线索**：三个词是坐标系，两场游戏是地图图例。下一章把「不出租时间」拆成可执行的四块——专长、长期关系、责任、股权。 → [02-积累财富.md](./02-积累财富.md)
