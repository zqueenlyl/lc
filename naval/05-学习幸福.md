# 05. 学习幸福：技能、选择、欲望、习惯

> 致富解决的是「钱的问题」。钱能买掉一部分不幸福（匮乏、不安全），买不来内心安静。**幸福是一种可以练的技能**，不是性格抽签，也不是成功附赠。

一句人话：**欲望是一份「得到之前同意不开心」的合同；少签、签大的，到期结束。**

---

## 一、先把词用松一点

「幸福」在不同人嘴里指快感、满足、平静、喜乐甚至开悟。纳瓦尔故意混着用：这不是数学，硬定义会对齐失败。当诗读——看整体指向，不要拿第 3 句去反驳第 1 句。

他的工作定义更接近：

> 幸福是回到「这一刻什么都不缺」的状态。

不是持续高潮。高潮会过去，还会制造回落。追求快感本身，在丰盛时代很容易变成成瘾——食物、短视频、色情、酒精都是被武器化过的多巴胺。旧时代剑圣说「不要为快感本身去追」；今天的供给比那句话诞生时狠几个数量级。

---

## 二、幸福是技能，也是选择

两句并列，不打架：

| 命题 | 含义 |
|---|---|
| **技能** | 基线有遗传，但可塑性比运动能力大得多。脾气、展望、多快被激怒，都练得动 |
| **选择** | 你不是被钉在当前的幸福档位上。很多人因为「反正改不了」而把幸福贬值，于是真的不练 |

纳瓦尔说自己是从相对不幸福**故意练成**比较幸福的。因为走过这条路，他才敢讲方法；身体健康他讲得少，因为那块他没自认为练成。

「我很聪明所以我应该不幸福」是常见抗拒。半真：看得穿幕布的人更难装轻松。但若聪明到能换健康和财富，也聪明到能在生物约束内换平静——而且这个约束比你以为的宽（醉酒、冥想、深度呼吸都能短暂打开更大的动态范围，说明档位不是焊死的）。

另一抗拒：「幸福了就没驱动力了。」也半真。成佛和发射火箭很难是同一个人。但**不幸福极其不经济**：睡眠差、易怒、挖坑再填、判断力被多余念头占满。平静之后，他的观察是：工作更少，决策更好，有效产出反而上升。只要判断质量的提升大于驱动力的下降，你就赚了。

这和 [04-判断力](./04-判断力.md) 直接咬合：杠杆时代拼的是决定，不是工时。

---

## 三、欲望是一份合同

最硬的一句（公开推特）：

> 欲望是你签下的合同：在得到那东西之前，你同意做不开心的人。

机制：

1. 你想要 X，内心出现缺口；
2. 你为填缺口而焦虑、劳动、比较；
3. 得到 X 之后，你回到想要之前的基线，并长出下一个 X。

没有单件货物能把基线永久抬上去。若「得到」能永久幸福，洞穴人该很惨、我们该狂喜——人均幸福并没有随物质这么涨。

所以策略不是消灭所有欲望（那是出家 hard mode），而是：

- **欲望改成主动选择**：我愿意为这个 X 付一段不开心，到期就结束合同，不自动续约；
- **少签、签大的**：同时履行二十份欲望合同，等于长期处在违约边缘；
- **物质欲望优先用创造去满足**，而不是用三十年禁欲去压。纳瓦尔的判断：现代人满足物质欲望，往往比成功禁欲更快。先把 [01–03](./01-人物与坐标系.md) 的财富技能用上，再在 hard mode 上修心。

签之前四问（写不出来就还没签，只是在焦虑）：

1. 这份不开心我真的要买吗？买几个月？
2. 到期后自动续约吗？
3. 同时履行的合同是否已经超过两份？
4. 这是我的欲望，还是捡来的地位剧本？

## 四、成功、嫉妒、当下、习惯

| 主题 | 原则 | 反例 |
|---|---|---|
| **成功 ≠ 幸福** | 成功是外部记分牌；幸福是内部噪音水平 | 用下一个成就续命，是把欲望合同做成永续债 |
| **嫉妒** | 幸福的敌人。地位游戏靠比较，比较靠嫉妒供能 | 「我可以学他的方法，但不必要他的人生」 |
| **当下** | 过去和未来都只在这一刻被想起；能住的只有现在 | 把人生活成对未来缺口的预支 |
| **心境平和** | 幸福更接近「运动中的平静」，不是兴奋 | 用刺激当幸福，账单是成瘾 |
| **接受** | 先接受这一刻的实然，再决定改不改 | 拒绝现实不会让它消失，只会让判断迟到 |
| **退休** | 停止为想象中的明天牺牲今天 | 不是「存够钱就不干活」；有杠杆且合同很少时，今天已经不必预支 |

嫉妒可以当雷达：它标出你还在乎的地位游戏。看见之后，要么把那项改成自己的欲望合同（真的要，就去干），要么放下。最差是又妒又不动——合同在履行，产品永远不交货。

习惯是幸福的工程实现：睡眠、日照、走动、少摄入被设计过的超刺激、减少无意义争论。原则要落到日历上，否则仍是金句。

## 五、现代战场：武器化成瘾

丰盛之后，痛苦的主因从「得不到」变成「停不下来」。

- 公司的产品目标常常是占用你的注意力，不是完成你的目的；
- 戒掉某样东西在社交上可能「不礼貌」（不喝酒、少刷、不回立刻）；
- 快感会制造对称的痛苦和失去的恐惧。

对抗不是禁欲表演，是**提高默认平静**，让超刺激显得没那么必要。下一章的冥想、锻炼、自我塑造，都是这条线上的工具。

## 六、和财富章怎么接

```
财富技能 ──► 买掉匮乏造成的不幸福
幸福技能 ──► 买不掉的那部分：比较、欲望、失控的念头
判断力   ──► 两边共用的输出：更少、更好的决定
```

不要把 05–07 读成「幸福优化工作流」。若你的真实动机仍是更赚钱，先诚实回去读 02–04；把幸福当杠杆用，会把欲望合同写得更隐蔽。

## 七、本章纠正

| 误解 | 纠正 |
|---|---|
| 幸福是性格抽签，或成功附赠 | 基线有遗传，但可练；成功是外部记分牌 |
| 欲望越多越有驱动力 | 每份欲望都是自愿的不开心；同时签二十份等于长期违约 |
| 幸福了就没驱动力，所以该保持焦虑 | 不幸福极其不经济；平静之后决策更好，有效产出往往上升 |
| 退休 = 存够钱就不干活 | 退休是停止为想象中的明天牺牲今天 |
