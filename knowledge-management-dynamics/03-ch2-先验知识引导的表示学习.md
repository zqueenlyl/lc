## 一、问题设定

深度表示学习的成功依赖大量标注数据，而满足独立同分布假设的标注成本不可承受。作者把根因写成：传统范式让模型在**特定数据域**上做监督训练，因此只能拿到**域偏置的判别信息**（domain-biased discriminative information）；监督数据不足时，判别信息更不够。

解法方向：引入**无偏先验知识**（unbiased prior knowledge）引导训练。所谓「无偏」指这类知识来自人类知识、跨多个甚至所有数据域通用；所谓「先验」指它在对某个具体数据域做经验归纳之前就已存在。

按知识引入的时机，分三层，每层各有一个公认难题：

| 层 | 知识以什么形式进来 | 对应技术 | 章内点出的挑战 |
|---|---|---|---|
| **任务级** | 当作任务假设，构造辅助自监督任务 | 自监督 / 对比学习 | **样本效率低** |
| **特征级** | 从人类知识库取特征来引导 | 知识图谱表示学习 | **缺少知识引入路线图** |
| **可解释级** | 用人类理论框架引导训练 | 因果推断指导的表示学习 | **表示学习理论指导不足** |

## 二、任务级：FeAug（§3）

### 问题

对比学习的核心是拉近同一样本的不同视图、推远不同样本。但它需要**大量样本对**——大 batch 或大 memory bank——因为多数对不含信息量：正对在隐空间已经很近、负对已经很远，对优化贡献极小。于是实践上堆激进数据增广（抖动、随机裁剪、色彩通道分离）和大 memory bank。近期工作又进一步依赖精选**难负样本**。而当对数变少时，对比损失会导致**特征坍缩**（所有图输出相同特征）。

### 方法：先把标准对比学习钉住，再加 MAG

标准对比学习（章内当预备知识）：

1. 每个样本有多个视图（抖动、裁剪等）。**同一样本的不同视图 = 正对**；**不同样本的视图 = 负对**。
2. 视图过编码器 `f` → 表示；再过投影头 `g` → 特征 `z`。相似度用判别函数 `d`（通常是余弦）。
3. 对比损失一次只处理 **1 个正对 + 若干负对**：拉近正对、推开负对。
4. **测试时丢掉投影头**，只用编码器表示做下游任务。

问题是：多数对在隐空间已经分得够开/够近，梯度几乎为零；batch 小了就容易**特征坍缩**（所有图输出同一向量）。前人解法是堆图像增广 + 大 memory bank + 精选难负样本。作者换了一条路：**增广作用在特征上，不作用在像素上**。

**FeAug 的零件**：每个视图配一个 **Meta Augmentation Generator（MAG）** `a_ω`。训练时编码器、投影头、MAG 一起学，但是**分两拍、交替**（章内 Figure 1）：

```
每一步：
  拍 1  冻结 MAG
        用标准对比损失更新编码器 f 和投影头 g
  拍 2  冻结 f 和 g
        用「元更新」调 MAG：看编码器在「原特征 + 增广特征」上的表现
        （用二阶导 / Hessian：保留 f、g 的计算图，再对 ω 求导）
直到收敛
```

元更新的意图：让 MAG 造出**对对比任务更有信息量**的特征，这样同一批训练数据上编码器能同时用原特征和增广特征。

**边距注入（margin injection）为什么必须有**：如果原特征本身没信息量，对比损失回传的梯度很小，MAG 几乎不更新 → 增广特征塌成原特征的复制。作者在元目标上加一项正则：增广特征相对原特征必须拉开一个边距。实现上：

- 只拿**原特征**算正对相似度集合、负对相似度集合，生成一个 margin；
- 再在「一个原特征 + 一个增广特征」组成的正/负对上加截断到零的惩罚（低于边距才罚）；
- 超参控制这项正则相对元损失的权重。

章内还提了不止一种 margin 生成法（一种主方法 + 两种变体），正文只把主方法写进更新式。效果描述：同一图像的特征更集中，不同图像的间隔变大——增广既没塌，又帮编码器学到更可分的表示。

跟读检查：你能画出「像素增广 vs 特征增广」的差，以及「两拍交替 + 边距防塌」，这一节就算跟上了。完整损失式回原章 §3.2.3。

### 结果（章内 Table 1）

统一 batch size 64；backbone 为 AlexNet 的 5 层卷积（conv）+ 2 层全连接（fc），**均不预训练**；增广策略与 memory bank 沿用 CMC；20 次独立试验、取最后 20 epoch 均值、报 95% 置信区间。对比对象包含 BiGAN、NAT、DIM、SwAV、SimCLR、CMC、MoCo、BYOL、Barlow Twins、DACL、LooC、DCL、HardCL 与全监督基线。

| 方法 | STL-10 (conv/fc) | CIFAR10 | CIFAR100 | Tiny ImageNet |
|---|---|---|---|---|
| 全监督基线 | 68.70 | 75.39 | 42.27 | 36.60 |
| SimCLR | 75.57 / 77.15 | 80.58 / 80.07 | 50.03 / 49.82 | 36.24 / 39.83 |
| CMC | 83.03 / 85.06 | 81.31 / 83.28 | 58.13 / 56.72 | 41.58 / 40.11 |
| HardCL | 83.16 / 85.15 | 83.04 / 86.22 | 58.97 / 59.13 | 42.89 / 42.01 |
| **FeAug** | **85.41 / 85.62** | **87.87 / 88.12** | **59.97 / 61.06** | **44.51 / 45.36** |

读这张表要注意：**小 batch（64）+ 无预训练的 AlexNet 骨架**是作者刻意设定的「受限」场景，数字不能与用 ResNet + 大 batch 的公开结果对比。

## 三、特征级：CapKP（§4）

### 为什么是知识图谱

知识图谱被当作「人类知识的数据库」：按语义网的三元组定义，实体为节点、关系为边，构成有向多关系图。章内点名的通用图谱有 WordNet、YAGO、DBpedia、Freebase、WikiData、NELL、CN-DBpedia、ConceptNet；领域图谱有 Open PHACTS、Watson、AMiner；商业产品如 Google KG。代表性的图谱表示学习方法列了 ConvE、ConvKB、CapsE、KG-BERT。

### 问题与假设

作者做了组零样本对照实验（Figure 2）：把 CLIP 的提示分三类——无语义信息（CLIP 原版）、含粗粒度语义、用更多词描述相近语义。结论是含语义的提示都更好，但**加长描述相对简单语义提示的增益很小**。于是提出

> **假设 4.1**：在提示中加入（标签相关的）语义信息，能提升预训练视觉-语言模型的零样本推理表现——收益来自语义本身，不是词数。

### 方法：CapKP = Causality-pruning Knowledge Prompt

先补 CLIP 在这一章里怎么用（§4.2.1），否则后面的「换提示」没有落点：

- 双编码器：图像（ResNet 或 ViT）+ 文本（Transformer）；预训练 4 亿图文对，对比损失对齐两个空间；文本最长 77 token，BPE 后 512 维。
- 零样本分类：图像特征 vs 各类别提示（默认 `"a photo of a [Y]"`）过文本编码器得到的标签特征，温度缩放后的余弦相似度当预测。
- 固定模板不跨任务最优：章内转述 CoOp 的数字——Flowers102 上 `"a photo of a [Y]"` 60.86%，改成 `"a flower photo of a [Y]"` 升到 65.81%；Caltech101 上反而更短的 `"a [Y]"`（82.68%）好过 `"a photo of [Y]"`（80.81%）。所以要**可学习、且带语义**的提示，而不是更长的句子。

作者再补一条观察（假设 4.2）：预训练语料里的句子常常只有跨标签共享的泛化语义（「尾巴」），细粒度标签特有的信息反而稀缺。于是提示有两种拼法：

| 形态 | 怎么拼 |
|---|---|
| **标签专属（SPE）** | 可学习向量（高斯初始化） ⊕ CapKP(标签) ⊕ 标签的小写 BPE；CapKP 输出维数与 CLIP 文本维一致（如 512）；系数平衡可学习向量与知识向量 |
| **标签共享（SHR）** | 级联拼接 + 一层线性映射，让不同标签共用一段泛化语义 |

分类时仍走 CLIP 那条「文本编码器出分类权重 → 与图像特征比相似度」。

**CapKP 本体增强嵌入（知识从哪来）**：

```
对每个类别标签 Y：
  1. 在本体化知识图谱里找与 Y 语义最像的实体
  2. 取它的 1-hop 邻居 → 标签相关子图 G_i
  3. 因果剪枝 κ(G_i)（下一步）
  4. GNN 读出剪完的图 → 知识向量 φ(Y)
     节点/边都有嵌入；聚合是非线性网络 + 内积，只在剪完的邻居上做
```

**因果剪枝（什么边该留下）**：把 Granger 因果搬到知识图谱——某条**关系类型** `r` 如果加进去能让「图规则打分 / 下游文本表示」更好，就说 `r` Granger-cause 这个图。操作（章内 Figure 4；**剪枝过程中 GNN 编码器冻结**）：

```
对子图里每一种关系类型 r：
  暂时删掉所有类型为 r 的边
  看联合模型误差怎么变（剪前 ε vs 剪后 ε_{-r}）
  损失变化大 → 这条关系对预测图 / 文本表示有因果贡献，留下
  变化小 → 与下游任务因果解耦，剪掉
```

消融命名（§4.3.4）：全量叫 **CapKP**；去掉因果剪枝叫 **KP**；两种提示形态分别记 SPE / SHR。

一句话：**先检索 1-hop 子图把语义喂给提示，再按「删了这条关系损失变不变」清噪声边。** 跟读检查：能说出「CLIP 分类权重从哪来」「子图怎么取」「剪枝判据是损失振荡不是人工规则」，这一节就算跟上了。完整符号回原章 Eq. (11)–(16)。

### 结果（§4.4）

11 个公开图像分类集：ImageNet、Caltech101、StanfordCars、FGVC Aircraft、Flowers102、OxfordPets、Food101、SUN397、UCF101、DTD、EuroSAT，覆盖通用物体、场景、动作、细粒度、纹理、卫星图。按 CLIP / CoOp 协议训 1/2/4/8/16 shots，每设定 3 次独立运行取均值。基线为 CLIP（7 个手写模板做 prompt ensembling）与 CoOp（自动生成提示）。结论：**各 shot 设定下 CapKP 一致优于两个基线**；随 shot 增加所有方法都提升。章内以 Figure 5 呈现，未给数值表。

## 四、可解释级：MSR（§5）

### 用结构因果模型重看对比学习

作者把对比学习放进**结构因果模型**（SCM）里分析，识别出的关键问题是：**背景信息是混淆因子**（confounder）——模型可能靠背景而非语义把正负对分开。对应手段是因果干预中的**后门调整**（backdoor adjustment）。展开如下。

**对比学习在这一节的设定**（和 FeAug 那节略有不同，这里按 SimCLR 式）：batch 里 N 张图，每张随机增广成 2 个视图，共 2N 个样本进特征提取器。锚点配 **1 个正对、2N−2 个负对**；损失是带温度的余弦对比损失。

**结构因果模型（章内 Figure 6）**作者怎么画：

- 把锚点看成「标签」：最小化对比损失 ≈ 用正样本去预测这个标签。
- 语义信息 `X_s` 既流向特征（当卷积核/通道语义），也和正样本、锚点缠在一起。
- 有效的 CL 应该靠**前景**预测标签；但 SCM 里还有一条**伪路径**：背景相似也能把正对拉近。
- 正对来自同一张原图 → 前景和背景都像；假负样本（前景其实同类）被推开时，前景相似度下降、背景相似度的相对作用被放大。于是模型学会了**背景依赖的语义**。

干预目标：用 `do(·)` 替代观察分布，切断伪路径。手段是**后门调整**：把混淆因子（语义/背景通道）分层，对每一层的条件预测再按层的先验加权平均。

**MSR 怎么把后门调整做成可训练模块**：

- 特征图形状 `宽 × 高 × 通道`。预训练 CNN 里通道大致对应视觉概念，但**一个通道不够一个概念**，所以每个语义概念配一个权重向量：概念内部通道权重大、外部小。
- **Meta Semantic Regularizer** 是一个小 CNN：一张图做两次增广后，正则器出一张**语义相关权重矩阵 A**，两个视图**共用**这张矩阵（通道级加权 = 分层）。
- 三个零件：特征提取器 `f`、正则器 `msr`、投影头。每个 epoch 仍是**两拍**：

```
拍 1  用「增广样本 × 权重矩阵 A」更新 f 和投影头
      目标 = 原对比损失 + λ × 语义正则项
拍 2  元学习更新 msr：
      先把 f / 投影头按当前 A 走一小步
      再让 msr 去最小化「这一小步之后」的对比损失
      → A 被逼成「能让对比学习在同一批数据上更有效」的分层
直到收敛
```

可插拔：挂到 SimCLR / BYOL / LMCL / ReSSL 上，超参 λ / γ 各变体不同（SimCLR+MSR 均为 1；BYOL+MSR 与 LMCL+MSR 为 λ=0.1、γ=1；ReSSL+MSR 为 λ=0.01、γ=1）。

跟读检查：能说出「背景为什么是混淆因子」「后门调整在特征上长成通道权重」「两拍里谁在学分层」，这一节就算跟上了。完整干预式回原章 Eq. (17)–(23)。

### 结果（章内 Table 2）

数据集 CIFAR10 / CIFAR100 / STL-10 / Tiny ImageNet，ResNet-18 提特征，按 SimCLR 设置，评测用线性探针与 5-NN 两种分类器。

| 方法 | CIFAR10 linear | CIFAR100 linear | STL-10 linear | Tiny ImageNet linear |
|---|---|---|---|---|
| SimCLR | 91.80 | 66.83 | 90.51 | 48.84 |
| BYOL | 91.73 | 66.60 | 91.99 | 51.00 |
| RELIC（因果相关基线） | 91.96 | 67.24 | 91.15 | 49.17 |
| SimCLR + MSR | 92.34 | 67.59 | 92.03 | 50.12 |
| **BYOL + MSR** | 92.26 | 66.97 | **93.22** | **52.54** |
| **LMCL + MSR** | **92.45** | **67.99** | 91.56 | 52.61 |
| ReSSL + MSR | 91.77 | 65.12 | 89.91 | 47.17 |

作者的读法：所有 MSR 变体都优于各自基线；最好的是 BYOL+MSR 与 LMCL+MSR；四个变体中有三个优于同为因果路线的 RELIC，支持「背景是混淆因子」这一判断。注意增幅多在 **0.3–1.6 个点**量级，ReSSL+MSR 在 CIFAR100 上其实**低于**表中 SimCLR 等方法——提升不是无条件的。

## 五、贡献与遗留（§6–§7）

三条贡献对应三层：FeAug 解样本效率、CapKP 解知识引入路线、MSR 解理论指导。作者自陈的遗留问题也很清楚：

- 无偏知识整合**仍缺统一理论框架**；
- 数据极度受限时，任务级方法提样本效率仍难；
- 特征级需要更高效地从大规模知识图谱抽取与利用知识；
- 可解释级需更深入的因果关系探索。

## 六、和本库的关系

这一章与「知识管理」的唯一连接是 metaphor：把知识图谱和理论框架当「人类知识库」。对本库有用的是三个技术点：

| 章内点 | 本库落点 | 可借什么 |
|---|---|---|
| 特征空间增广优于图像空间增广 | 本库对比学习覆盖薄，[transformer](../ai/foundation/transformer/) 不含 SSL 线 | 一个具体论证：对比损失作用在特征上，图像增广要多走一次编码 |
| 知识图谱子图 → 提示（CapKP） | [多模态](../ai/foundation/generative/multimodal/)（CLIP 线）· [上下文图](../ai/agent/loop-graph/context-graph.md) | 「用结构化知识构造提示」的一种实现；和 GraphRAG 的构图动机同源但目标不同（这里是分类，不是问答） |
| 背景是混淆因子 → 后门调整 | 本库无因果专题 | 若将来写「评测里的伪相关」，这是一个可引的机制表述 |

边界要划清：

- 这里的 **knowledge graph 是训练/提示的特征源**，不是 [知识库](../ai/knowledge/knowledge-base/) 意义上的检索底座；
- 这里的 **ontology-enhanced 指用本体化图谱抽子图**，与 Palantir 运营本体、与 OWL 推理都不是一回事；
- 这里的 **cross-level 是「三层引入时机」**，与第 5 章标题里的 cross-domain（跨部门知识流动）毫无关系。两章放在同一本书里，恰好说明「knowledge」这个词在本书内部就有多重含义。

**红线**：引用本章数字时必须带上受限设定（batch 64、AlexNet 无预训练 / ResNet-18 小数据集），否则会被误当成 SOTA 比较；「Perspective Chapter」不等于经同行评审的完整实验论文。
