## 1. 一个 Block = 四件套；N 层堆叠 = 完整模型

一个 Block = `[Attention 子层（[环节04](./环节04-Attention注意力详解.md)）→ 残差/归一化（[环节06](./环节06-残差连接与归一化详解.md)）→ FFN 子层（[环节05](./环节05-FFN激活与MoE详解.md)）→ 残差/归一化]`。把 N 个 Block 串起来，出入口接上 Embedding（[环节02](./环节02-Embedding查表详解.md)）与输出头（[环节08](./环节08-输出头与训练目标详解.md)），就是完整模型。

**分层语义**：浅层学词法/局部搭配，中层学句法/指代，深层学长程语义与"要接什么词"。

### 1.1 一张图看懂 Decoder-only（整体前向）

> 读图先记一条：**"重复 N 层，每层相同"指结构相同（四件套、维度、形状），不是参数相同**。每一层都带着自己**独立随机初始化、独立训练**的一套 `W_Q/W_K/W_V`（连同 `W_O`、FFN、LayerNorm 参数），层间互不共享，参数量随层数线性增长（§5 上表）。层与层能各司其职（浅层词法 → 深层语义），前提正是这些权重在训练中分化出不同分工，而不是共用同一份——所以"每层相同"绝不等价于"一层学会、各层拷贝"。

```
 输入 Token 序列            idx = [ i0, i1, …, i_{n-1} ]
        │
        ▼
 ┌────────────────────────────────┐
 │ Token Embedding  查表 (|V|×d)   │ → (n, d)
 │ + 位置编码（RoPE / 可学习绝对） │
 └────────────────────────────────┘
        │  X : (n, d)   ← 一次前向吃进整条序列（并行）
        ▼
 ┌───────────────────────────────────────────────────────────┐
 │            Transformer Block，重复 N 层，每层相同          │
 │                                                           │
 │  ① Masked Self-Attention（只看过去，因果）                │
 │     Q = X·W_Q    K = X·W_K    V = X·W_V     各 (n, d)     │
 │     S = Q·Kᵀ / √d_k            (n, n)  ← O(n²) 的来源     │
 │     S[i][j] = -∞ 当 j > i      （Mask：挡住"未来"）       │
 │     P = softmax(S)              (n, n)  每行和为 1        │
 │     O = P·V                      (n, d)                   │
 │  ② 残差：X ← X + O                                        │
 │  ③ LayerNorm → FFN（ReLU/GELU/SwiGLU）→ LayerNorm         │
 └───────────────────────────────────────────────────────────┘
        │  Z : (n, d)
        ▼
  LM Head（线性层，无 softmax）：logits = Z·W_head + b_head   (n, |V|)
        │
        ├──────────────────────────────┬──────────────────────────────┐
        ▼                              ▼                              ▼
 训练（一次算整条序列）           推理 Decode（逐 token）        推理 Decode（KV Cache）
 对每个位置 i 预测 token i+1     只看最后一行的 logits          只看最后一行，但 K/V 增量缓存
 CE loss：-Σ log P(tok_{i+1})    softmax → 采样新 token         新 token 再进来时 Q 只需与
 回传梯度更新全部 W              新 token 拼接回序列             缓存 K/V 做注意力，不再重算
```

**训练与推理最关键的结构性差异**：训练时"整条序列并行前向、所有位置一起算"（靠 Mask 保证因果）；推理时只能"一个 token 一个 token 地长出来"，所以每一步都希望复用上一步算过的 K/V——这就是 KV Cache（详解见 [环节 10](./环节10-推理解码与KV缓存详解.md)）。

### 1.2 全局符号与维度约定（全链路通用）

| 符号 | 含义 | 教学取值 |
|---|---|---|
| n / T | 序列长度 | 3 |
| d | 隐藏维度 d_model | 4 |
| d_k = d_v | 注意力投影维度 | 4（单头） |
| H | 注意力头数 | 1（演示）；实际 12~96 |
| N | Block 层数 | 1（演示）；实际 12~120 |
| \|V\| | 词表大小 | 4：{a, b, c, d} |
| X | 输入表示矩阵 | (n, d) |
| P | 注意力权重（行归一化） | (n, n) |
| Z | Block 输出 | (n, d) |
| logits | 未归一化得分 | (n, \|V\|) |

**层间数据流一条线说清**：`X` 和 `Z` 只是"同一份数据在不同加工站的叫法"——第 ℓ 层的**输出就是第 ℓ+1 层的输入**，形状永远是 `(n, d)`：n 行 = n 个 token，每行是"该 token 目前理解的上下文表示"。形状不变是残差主干的必然（`X ← X + 子层(X)`，见 [环节 06](./环节06-残差连接与归一化详解.md)）；变的只有行向量里装的语义——第 0 层输入（Embedding+位置信息）只知道"我是哪个词、在哪"，之后每过一层就多一层对前缀的融合（词法 → 句法/指代 → 长程语义），每层视野不增（Mask 只看前缀），增的是对同一段前缀的加工深度；最后一层输出末行 = 全前缀浓缩，喂 LM Head 出 next-token 分布。口诀：**形状是流水线上不变的容器 (n,d)，层是加工站，每站往里加一层"对上下文的领悟"**。

## 2. 为什么是 Transformer：从 RNN / LSTM 的演进史看过来

> 本节是**演进骨架**（为什么被替换）；RNN/LSTM 本体级纵深（BPTT 数值手推 / GRU / 双向·Seq2Seq / 现代类 RNN 谱系）见 [RNN知识整理.md](../rnn/RNN知识整理.md)，骨架不与它重复展开。

| 模型 | 一句话 | 核心思想 |
|---|---|---|
| RNN | 用一个固定向量压缩全部历史 | 状态即记忆 |
| LSTM | RNN + 记忆单元 + 三个门 | 让信息选择性地"遗忘/写入/读出" |
| Transformer | 不压缩历史，所有 token 互相直接可见 | 注意力即上下文 |

**本质区别**：

- RNN 家族：历史 → 压进一个固定向量 h_t（**有损压缩（lossy compression）**，信息瓶颈，越长越稀释）
- Transformer：历史 → 保留每个 token 的独立表示，用注意力权重动态加权（**无损可见**，代价 O(n²)）

### 2.1 RNN：状态即记忆（串行 + 有损）

**公式**：`h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)`，`y_t = softmax(W_o · h_t)`。

**结构图（时间展开）**：

```
x_1 ──┐        x_2 ──┐        x_3 ──┐
      ▼               ▼               ▼
   [RNN] ── h_1 ── [RNN] ── h_2 ── [RNN] ── h_3
       │                │                │
       ▼                ▼                ▼
      y_1              y_2              y_3
```

**特点**：

- **参数共享（parameter sharing）**：每个时间步（time step）用同一套 W_h / W_x，参数量与序列长度无关；
- **串行依赖（sequential dependency）**：h_t 依赖 h_{t-1}，一步都不能并行；
- **有损压缩（lossy compression）**：全部历史压进 h_t，早期 token 会被后面不断"覆盖稀释"。

**缺陷（数学视角）**：反向传播时 ∂L/∂h_1 要经过 t 次链式连乘，含 ∏(W_hᵀ) 项。W_h 的特征值（eigenvalue）<1 → 梯度指数衰减（**消失**）；>1 → **爆炸**。实际很难记住超过 ~10 步的依赖。

### 2.2 LSTM：RNN + 记忆单元 + 三个门

- **遗忘门（forget gate）f_t**：决定丢弃多少旧记忆；**输入门（input gate）i_t**：决定写入多少新信息；
- **候选 c̃_t**：新信息的内容本身；**输出门（output gate）o_t**：决定从记忆中读出多少；
- **c_t（核心）**：记忆单元，一条"直达高速公路"。

**公式**（输入为拼接向量 [h_{t-1}, x_t]）：

```
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)          # 遗忘门
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)          # 输入门
c̃_t = tanh(W_c · [h_{t-1}, x_t] + b_c)       # 候选记忆
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t              # 记忆更新：遗忘旧 + 写入新
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)          # 输出门
h_t = o_t ⊙ tanh(c_t)                        # 对外输出
```

**结构图**：

```
      ┌──────────────────────────────────────────────┐
      │          记忆传送带 c_t（主线）               │
      │   c_{t-1} ──(× f_t)──(+)──────────▶ c_t      │
      │                          ↑                   │
      │      (× i_t) ── 候选 c̃_t                     │
      │   x_t ──▶ 遗忘门f / 输入门i / 候选c̃ / 输出门o │
      │                                   │          │
      │              h_t ◀──(o_t × tanh(c_t))        │
      └──────────────────────────────────────────────┘
```

**为什么解决梯度消失**：`∂c_t / ∂c_{t-1} = f_t`，梯度沿 c 有一条**直达路径**，不经过连乘的 W 矩阵；当 f_t ≈ 1（保留记忆）时梯度可近似无损穿越几十上百步。本质与 ResNet 恒等映射同理——给梯度修高速公路（呼应 [环节 06](./环节06-残差连接与归一化详解.md) 的残差思想）。

**与 Transformer 的分水岭**：RNN/LSTM 即便改进记忆，仍是**串行 + 固定容量压缩**；Transformer 用"整序列互相可见 + 加权引用"，换来 GPU 友好的并行与无损长程访问。

## 3. 三种整体架构怎么选

| 架构 | 结构 | 擅长 | 缺点 | 代表 |
|---|---|---|---|---|
| **Encoder-only** | 只留"双向编码"部分 | 理解/分类/检索（无生成） | 不自回归，难做开放生成 | BERT 系 |
| **Encoder-Decoder** | 编码器（encoder）读完整输入 + 解码器（decoder）带交叉注意力（cross-attention）生成 | 输入输出差异大的任务（翻译/摘要） | 结构重、规模上不去 | T5、BART |
| **Decoder-only（GPT 系，主流）** | 只剩"因果自回归解码器"，输入输出一套注意力 | 结构最简、规模堆得最大、生成/理解通吃 | 严格单向（相对而言） | GPT、LLaMA、Qwen、DeepSeek |

**为什么当前是 Decoder-only 赢**：同一套掩码自回归（masked autoregression）可同时完成训练（next-token）与推理（自回归，autoregression），无需交叉注意力 → 架构简单 → 同等算力能堆更大规模 → Scaling Law 下赢者通吃。

**为什么 Decoder-only 只用 Masked Self-Attention、不加 Cross-Attention**：Encoder-Decoder 的 Cross-Attention 是"看完整输入"；Decoder-only 把输入也当序列，首尾都是自回归，同一套注意力覆盖全部——结构更简，规模堆得更大。训练并行不偷看的根本是 Mask（"并行算全部位置" ≡ "逐词预测"），机制见 [环节 04](./环节04-Attention注意力详解.md) §2.3。

## 4. 三种架构怎么"推算下一个 token"（机制对照）

统一视角：模型学的是**条件概率（conditional probability）p(x_{t+1} | x_1 ... x_t)**——给定已见 token，输出词表上的概率分布（probability distribution），取最可能的词。

### 4.1 RNN：逐 token 顺序推进

1. x_1..x_t 逐个过 Embedding 查表 → 向量；
2. 顺序更新状态：h_1 = f(h_0, x_1) → h_2 = f(h_1, x_2) → … → h_t；
3. 最后一步：logits = W_o · h_t；4. Softmax → 概率 → argmax/采样 → 下一个 token。

**数值例子**（h 维=2，词表 {a,b,c}，简化权重）：

```
x_a = [1,0]   x_b = [0,1]   x_c = [1,1]          # 输入向量
W_x = [[1,1],[0,1]]   W_h = I（恒等简化）

h_1 = tanh(W_x·x_a)                = tanh([1,0])    = [0.76, 0.00]
h_2 = tanh(h_1 + W_x·x_b)          = tanh([0.76,1]) = [0.64, 0.76]
h_3 = tanh(h_2 + W_x·x_c)          = tanh([1.64,1.76]) = [0.93, 0.94]

logits = W_o·h_3   (W_o = [[1,0],[0,1],[1,1]])  = [0.93, 0.94, 1.87]
softmax → [0.25, 0.25, 0.50]  →  argmax = 第 3 个词
```

**关键认知**：预测质量取决于 h_t 这份"压缩档案"够不够好——输入越长，早期信息越容易被冲淡，这是 RNN 的天花板。

### 4.2 LSTM：同骨架 + 记忆单元

骨架与 RNN 完全一致（逐时间步滚），区别是每步多维护 c_t：

1. 用 h_{t-1}、c_{t-1} 与当前 x_t 一起算三个门 + 候选；
2. 更新记忆：c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t；
3. 输出：h_t = o_t ⊙ tanh(c_t)；4. 最后一个 h_t → LM Head → Softmax → 下一个 token。

**直觉**：c_t 像"笔记本"，三个门分别是"撕掉旧页 / 抄入新页 / 打开朗读"。答案质量 = 笔记本信息够不够全、门控够不够聪明。

### 4.3 Transformer：一次并行算完（Decode 视角）

1. 序列 [a, b, c] 一次过 Embedding + 位置编码（全部并行）；
2. 全序列并行算 Q/K/V → Score → (训练时 Mask) → Softmax → 加权求和（[环节04](./环节04-Attention注意力详解.md) 有完整数值手算）；
3. 取**最后一个位置的向量 z_last**（预测只需要它）；
4. z_last → LM Head → logits → Softmax → 采样/argmax；
5. 新 token 追加进序列，重复第 2 步（此时可用 KV Cache 增量计算）。

**数值例子**（d_model=4，词表 {a,b,c,d,e}，W_Q=W_K=W_V=I 简化，单头）：

```
Embedding + 位置编码：
  x1 (a, pos0) = [1, 1, 1, 0]
  x2 (b, pos1) = [0, 1, 1, 1]
  x3 (c, pos2) = [1, 1, 0, 1]

Score = Q·Kᵀ / √4：
  行1: [1.5, 1.0, 1.0]   行2: [1.0, 1.5, 1.0]   行3: [1.0, 1.0, 1.5]

Softmax（行3 = "c" 看前面所有 token 的注意力权重）：
  行3: [e¹, e¹, e^1.5] / 9.92 = [0.274, 0.274, 0.452]

加权求和（取最后一个位置的输出）：
  z3 = 0.274·x1 + 0.274·x2 + 0.452·x3 = [0.726, 1.000, 0.548, 0.726]

LM Head（简化：与每个词的 embedding 点积得 logits）：
  a: 1.274   b: 1.726   c: 1.726   d: 1.274   e: 1.452
Softmax → [0.158, 0.248, 0.248, 0.158, 0.188]
```

**三个核心洞察**：

1. **位置 3 的输出向量 = 所有前面位置向量的加权和**，权重由注意力得分决定——这就是"注意力即上下文"；
2. **全序列并行**：一次矩阵乘法同时算出所有位置间的关系，不需要像 RNN 一步步滚；
3. 推理只关心最后一个位置的向量，但**训练时每个位置都要预测**，所以全序列一起算。

## 5. 对比总表（RNN vs LSTM vs Transformer）

| 维度 | RNN | LSTM | Transformer |
|---|---|---|---|
| 历史表示 | 固定向量 h_t（压缩） | c_t + h_t（门控（gated）压缩） | 所有位置向量（不压缩） |
| 计算方式 | 串行 | 串行 | 并行 |
| 长程依赖 | 差（梯度消失） | 好（门控直通） | 好（直接可见） |
| 步进复杂度 | O(n) 步 × O(d²) | O(n) 步 × O(d²) | O(n²) 注意力 + O(n·d²) |
| 训练并行度 | 低 | 低 | 高（GPU 友好） |
| 可支持上下文 | 几十 | 几百 | 几千 ~ 百万 |
| 参数效率 | 高（共享） | 高（共享） | 低（每层独立） |
| 现状 | 概念/教材 | 学术 / 小规模序列 | LLM 事实标准 |

**RNN 被彻底淘汰了吗？** 主流 LLM 不用，但线性注意力 / RWKV / Mamba 在做"类 RNN 高效序列建模"，核心动机都是把 O(n²) 降下来（见 [环节 04](./环节04-Attention注意力详解.md) §4 的稀疏/线性方案表；各家族逐个拆解见 [RNN知识整理.md](../rnn/RNN知识整理.md) §8）。工程选型：通用序列建模 = Transformer；成本敏感/超长序列边缘场景才考虑替代品。

## 6. 面试高频追问

1. **为什么 Transformer 能并行而 RNN 不能？** RNN 每步 h_t 依赖 h_{t-1}（串行数据依赖）；attention 各位置无串行依赖，Q/K/V 全是矩阵乘法，天然可并行。
2. **RNN 为什么梯度消失？LSTM 怎么解决？** 反向连乘 W_hᵀ 特征值 <1 指数衰减；LSTM 靠门控直通 c 路径缓解（与 ResNet 同理）。
3. **为什么主流不是 Encoder-Decoder？** 交叉注意力 + 双向编码让结构变重；Decoder-only 一套掩码自回归同时搞定训练与推理，规模堆得最大。
4. **Decoder-only 为什么不加 Cross-Attention？** 输入也当序列处理，同一套自回归注意力覆盖全部，无需"编码器→解码器"两套。
5. **训练与推理的结构性差异？** 训练整条并行（Mask 保因果）、每个位置都预测；推理一次只长一个 token、只看最后一行。（机制对照表见 [环节 08](./环节08-输出头与训练目标详解.md) §6 / [环节 10](./环节10-推理解码与KV缓存详解.md)。）
