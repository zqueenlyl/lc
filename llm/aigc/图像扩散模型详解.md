# 图像扩散模型详解（DDPM → 潜空间 → UNet/DiT → 可控生成）

> **定位**：图像生成的事实标准（Stable Diffusion / FLUX / Midjourney 全在扩散系）。本篇把扩散数学吃透——DDPM 加噪/去噪/损失为什么是"预测噪声"、怎么加速采样、为什么躲进潜空间、文本条件与 CFG、可控生成三件套、成本工程。**视频生成（[视频生成详解.md](./视频生成详解.md)）与扩散系 TTS 都是本篇的"加时间/换信号"变体。**
> 前置：自回归文本侧机制见 `transformer/`（可先不读也能懂本篇，两者是并行的两条生成路线）。

---

## 1. 直觉先行：两步走

- **训练**：拿真实图像，人为逐步加噪到几乎纯噪声；同时学一个网络 **ε_θ 从带噪图反推"这一步加的是多少噪声"**（等价于学去噪方向）。
- **生成**：从纯随机噪声出发，让网络一步一步"猜噪声 → 减掉 → 更干净"，迭代 N 步得到图。

一句话：**扩散 = 学会"反向走一遍加噪过程"**。它不是 GAN 那样"造假像真"，而是学一条从噪声分布到数据分布的**确定性-ish 的路径**，所以训练稳定、覆盖全分布、可条件化。

## 2. DDPM 前向（加噪）——公式与数值

给真实样本 x₀，按一个调度（noise schedule）逐步加高斯噪声，T 步后几乎纯噪声。一步写成"闭式解"（不用真的走 T 步，可一步采样任意 t 时刻的带噪图）：

```
x_t = √(ᾱ_t) · x₀ + √(1 − ᾱ_t) · ε ,   ε ~ N(0, I)
ᾱ_t = ∏_{s=1}^{t} (1 − β_s)          # 累积保留系数（β_s 为每步加噪强度，前小后大）
```

**数值走查**（灰度单像素直觉，简化 β 恒定 = 0.1/步，T=10）：ᾱ_t = 0.9^t

| t | ᾱ_t | √ᾱ_t | √(1−ᾱ_t) | 若 x₀=0.5、ε=0.8：x_t |
|---|---|---|---|---|
| 0 | 1 | 1 | 0 | 0.5（原图） |
| 1 | 0.90 | 0.949 | 0.316 | 0.475 + 0.253 = 0.73 |
| 3 | 0.729 | 0.854 | 0.520 | 0.427 + 0.416 = 0.84 |
| 5 | 0.590 | 0.768 | 0.640 | 0.384 + 0.512 = **0.90** |
| 10 | 0.349 | 0.591 | 0.807 | 0.296 + 0.646 = **0.94** |

看最后一列：t 越大，带噪像素越来越被噪声项 `√(1−ᾱ_t)·ε` 主导（真实信号系数 √ᾱ_t → 0），到 t≈T 已基本是纯噪声。**这就是"前向确定性过程"——不学习，只是按公式污染。**

## 3. DDPM 反向（去噪）与训练损失——为什么"预测噪声"

- 反向：已知 x_t，想得到更干净的 x_{t-1}。数学上可以推导出反向条件分布 p(x_{t-1}|x_t) 近似高斯，其均值只依赖"当前图 + 本步噪声"。
- 所以训练目标变成：**给定 (x_t, t)，预测 ε**。损失就是均方误差：

```
L = E_{t, x₀, ε} [ ‖ ε − ε_θ( √ᾱ_t · x₀ + √(1−ᾱ_t)·ε , t ) ‖² ]
```

直觉三步：① 随机挑时刻 t；② 按公式一步造出带噪图；③ 让网络输入(带噪图, t) 猜"我刚才加的噪声 ε"，猜得准 → 损失小。训练时 t 全范围采样，让网络学会**任意噪声程度下的去噪**——生成时就能从纯噪声一步步"去"到干净图。

采样单步公式（预测噪声版本，z~N(0,I)，最后一步 z=0）：

```
x_{t-1} = 1/√(1−β_t) · ( x_t − β_t/√(1−ᾱ_t) · ε_θ(x_t, t) ) + σ_t · z
```

**关键认知**：扩散模型 = "一个输入带噪图和时间步 t、输出噪声估计的网络 ε_θ"。骨干网络替换（UNet → DiT）、条件注入（文本/图/结构）、采样加速，全部是在为这个核心方程服务。

## 4. 采样加速：从 1000 步到 1 步

| 方法 | 思路 | 典型步数 | 质量/成本 |
|---|---|---|---|
| DDPM 原始 | 逐 t 随机采样 | 1000 | 最稳最慢 |
| **DDIM** | 去掉采样随机项 → **确定性**轨迹（还支持"语义插值 / 反转去编辑"） | 20~50 | 少步仍好 |
| DPM++ / DPM-Solver | 更快的高阶 ODE solver | 10~25 | 主流默认 |
| 蒸馏（LCM / SDXL-Turbo / Lightning） | 训练把多步"蒸馏"成少步甚至 1 步 | 1~4 | 快一个数量级，细节略损 |

工程含义：**文生图成本由步数主导**——同模型 50 步 vs 4 步，推理差 ~10×。按质量需求路由（高质慢模型 vs 快模型）是最划算的成本杠杆。

## 5. 潜空间扩散（LDM / Stable Diffusion）：为什么躲进 VAE

在像素空间直接扩散，每步算 1024×1024×3 太大。**先让 VAE 把图像压进潜空间（下采样 8×：1024px → 128×128×4 latent），在潜空间加噪/去噪，最后 VAE 解码回像素。**

```
文本 prompt ──► CLIP/text 编码器 ──► 条件 ──► 去噪骨干(潜空间) ──► VAE Decoder ──► 像素图
随机噪声 z_T ────────────────────────────► 逐步去噪 z_t … z_0
```

- 为什么可行：潜空间保留了语义主要信息（丢的是高频视觉细节），扩散在"语义空间"做，既快又稳
- VAE 用 KL 正则约束潜空间分布接近正态 → 与"从纯噪声扩散"衔接自然
- **Stable Diffusion 全称 Latent Diffusion**；SDXL/FLUX 同框架（下采样 8×）

## 6. 骨干网络演化：UNet → DiT（扩散的 Transformer 化）

| | UNet（SD 1.5/SDXL） | DiT（FLUX、Sora 系） |
|---|---|---|
| 结构 | 卷积编解码 + 多尺度 skip | **图像切 patch 当 token，纯 attention**（= transformer 那套） |
| 归纳偏置 | 卷积自带局部性，小数据友好 | 无偏置靠数据堆，规模上去后更强 |
| 生态 | 最成熟（LoRA/ControlNet 全有） | 新一代主力（FLUX、视频系） |
| 与 LLM 复用 | 无 | 可直接复用 attention/MoE/量化/服务设施（回链 [环节11](../transformer/环节11-服务化与推理引擎详解.md)） |

**收敛趋势**：DiT = 扩散 + Transformer → 扩散网络和语言模型的训练/推理设施开始统一（换 LLM 后端即可跑扩散）。FLUX 的 MMDiT 更进一步让**文本流和图像流在同一个网络内双向交互**。

## 7. 文本条件与 CFG（Classifier-Free Guidance）

- 条件注入：把文本（CLIP text / T5 编码）通过 cross-attention 或 adaLN 送入去噪网络，让网络"按提示去噪"
- **CFG 公式**（生成时把"有条件"和"无条件"两个预测拉开）：

```
ε_guided = ε_uncond + w · (ε_cond − ε_uncond)
```

  - w=1：等于纯条件；w≈7（常用）：服从 prompt，但过头会过饱和/失真；w 更大 → "过度迎合 prompt"
  - **negative prompt 本质**：把 ε_uncond 的"无条件"换成"反向描述"（如"模糊、低质"），等于引导逃离这些特征
  - 数值直觉：同 prompt 下 w 从 1→7，生成结果从"松散的符合"变"强烈贴合提示词"，代价是多样性与画质过锐

## 8. 可控生成三件套（工程最常用）

| 手段 | 原理 | 典型用途 |
|---|---|---|
| **LoRA** | 只调增量矩阵（复用 [环节09](../transformer/环节09-训练管线详解.md) §4 同思想） | 风格/角色热加载，不动基座 |
| **ControlNet** | 拷贝一份骨干作"控制分支"，用 **zero conv** 接入（初始输出为零 → 不破坏预训练，训练只学控制增量） | 姿态/线稿/深度图/边缘控制 |
| **IP-Adapter / Image Prompt** | 把参考图编码成 image embedding 当附加条件 | 图作提示（换脸不换姿势、风格迁移） |

## 9. 工程要点（后端直用）

1. 请求模型：`steps`(20~50)/`CFG`(~7)/`seed`/negative prompt/尺寸；同 prompt+seed 结果确定 → **可幂等缓存**
2. **异步队列 + 进度查询**：秒级任务别同步阻塞；配额/并发看板；失败重试（seed 变化提醒用户）
3. 成本模型：≈ 步数 × 骨干 FLOPs × 潜空间尺寸（与分辨率强相关）；分级路由（低质快 / 高质慢）
4. 服务端双线审核（规则 + 模型），落库留痕；风格/版本漂移 → 锁版本 + 灰度回归
5. 后处理链：安全审查 → 超分/修复 → 水印 → CDN 回源

## 10. 面试高频追问

1. **扩散 vs GAN vs 自回归的本质区别？** GAN 学"判别+生成"对抗不稳定、模式坍缩；扩散学"加噪→去噪"的分布路径，训练稳定、覆盖全；自回归逐单元生成适合离散序列，扩散并行迭代适合连续信号。
2. **为什么训练目标能简化为"预测噪声"而不是预测原图？** 重参数化：带噪图可写成 x₀ 与 ε 的闭式线性组合，反过来最大化似然时噪声是唯一随机源，预测 ε 等价且数值稳定。
3. **DDIM 快在哪？为什么支持确定性采样？** 去掉每步随机项 σ_t·z → 轨迹确定；步数可降（同 ODE 解）；确定轨迹还能做"图像反转→编辑"。
4. **为什么要在潜空间扩散？** 像素空间维度爆炸、训练/推理贵；潜空间下采样 ~8× 且保留语义，扩散在语义空间做。代价是 VAE 引入重建失真（细节/文字损失）。
5. **CFG 数学上在干什么？** 推大 (ε_cond − ε_uncond) 方向，即"更服从条件的更新步"。w 太大 → 过饱和、多样性崩。
6. **UNet vs DiT 怎么选？** 数据/生态小用 UNet；追求规模上限与 LLM 设施复用走 DiT。趋势是 DiT。
7. **可控生成为什么不重新训一个模型？** LoRA/ControlNet 都复用冻结基座 + 极小可训参数量，成本低、可热切换、不破坏原能力。
8. **文生图服务为什么必须异步 + 可缓存？** 秒级到十秒级延迟不能扛同步链路；同 seed 幂等 → 缓存命中可免算，这是成本大头。
