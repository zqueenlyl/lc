## 1. RNN 基础：状态即记忆

**一句话**：用一个固定维度的向量 `h_t` 把所有已见历史"压扁"存下来，每来一个新 token 就滚动更新一次。

**标准公式**（Elman RNN）：

```
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
y_t = softmax(W_o · h_t)        # 逐位置输出（语言建模/序列标注）
```

- `x_t ∈ R^d`：当前输入（词的 embedding）；`h_t ∈ R^m`：隐藏状态（压扁后的"记忆"）
- `W_x ∈ R^{m×d}`、`W_h ∈ R^{m×m}`（**核心**：对历史做线性变换）、`W_o ∈ R^{V×m}`

**结构（时间展开）**：循环网络在时间上展开，等价于一个**深度 = 序列长度、且各层权重完全相同**的前馈网络：

```
x_1 ──┐        x_2 ──┐        x_3 ──┐
      ▼               ▼               ▼
   [RNN] ── h_1 ── [RNN] ── h_2 ── [RNN] ── h_3
       │                │                │
       ▼                ▼                ▼
      y_1              y_2              y_3
```

**三大特性（由此引出全部后续问题）**：

| 特性 | 含义 | 后果 |
|---|---|---|
| 参数共享 | 所有时间步共用同一套 W_h / W_x | 参数量与序列长度无关，可处理任意长度 |
| 串行依赖 | h_t 依赖 h_{t-1}，前一步没算完下一步不能算 | 无法并行 → 训练慢，GPU 利用率低 |
| 有损压缩 | 全部历史压进固定向量 h_t，每步被新信息覆盖稀释 | 长依赖记不住 → 梯度消失 + 信息瓶颈 |

**关键认知**：RNN 是"状态即记忆"——历史只存在于 h_t 这一个向量里。Transformer 则是"记忆外置"（每个位置都有独立表示，需要谁就注意力加权访问谁）。一个压进固定向量，一个展开成可见矩阵，这是两类架构最本质的分野，也是 §8 现代谱系所有工作的出发点。

## 2. BPTT：误差怎么穿过时间（Backpropagation Through Time）

**问题**：RNN 所有步共享一套权重，误差不止来自最后一步——语言建模每一步都算交叉熵，所以要把**每一步的损失加起来**，再沿着时间倒着把梯度传回每一步。

**推导骨架**：总损失 `L = Σ_t L_t(y_t, y_t*)`。对某个权重（以 W_h 为例）求导时，h_t 同时影响 L_t、L_{t+1}…L_T，所以：

```
∂L/∂W_h = Σ_t  Σ_{k≤t}   (∂L_t/∂h_t) · (∂h_t/∂h_k) · (∂h_k/∂W_h)
                      └────────┬────────┘
                 ∂h_t/∂h_k =  ∏_{j=k+1}^{t} (∂h_j/∂h_{j-1})
                 ∂h_j/∂h_{j-1} = W_hᵀ · diag(1 - h_j²)   # tanh 的导数矩阵
```

**问题就出在中间那串连乘**：误差从 t 传回 k，要跨 `(t-k)` 步，每步乘一次 `W_hᵀ · diag(1-h_j²)`。连续矩阵相乘，梯度按"矩阵谱半径（≈ 最大特征值）的 (t-k) 次幂"放大或缩小。

**数值手推（标量直觉示例）**：假设每一步缩放系数近似常数 `a`，跨 `n` 步后梯度比例 ≈ `aⁿ`：

| a | n=10 | n=30 | n=50 | n=100 | 结果 |
|---|---|---|---|---|---|
| 0.9 | 0.35 | 0.042 | 6.6×10⁻³ | 2.7×10⁻⁵ | **梯度消失**：早期信息几乎学不到 |
| 0.99 | 0.90 | 0.74 | 0.60 | 0.37 | 临界区 |
| 1.05 | 1.63 | 4.3 | 11.5 | 131.5 | 缓慢增长，训练震荡 |
| 1.5 | 57.7 | 1.9×10⁵ | 6.4×10⁸ | — | **梯度爆炸**：参数一步被冲飞 → NaN |

真实情况是矩阵（谱半径 + tanh 饱和导数叠加），但数量级规律完全一致：**只要缩放系数偏离 1 一点，跨几十步就指数爆炸或湮灭**。这决定了朴素 RNN 实际记不住超过 ~10 步的依赖。

**训练复杂度**：BPTT 一次前向 + 反向都要遍历整个序列，串行执行 → 训练 O(序列长)。长序列必须用 **TBPTT（Truncated BPTT）**：把序列切成窗口，每段只回传固定步数（损失小幅近似，换取可训练性）。

> 面试价值：BPTT 名字唬人，本质就是把"共享权重的深度网络"按时间展开做反向传播，**层的数量 = 序列长度**——所以 RNN 的梯度消失和超深网络的梯度消失是同一个病。LSTM/残差连接治的也是同一个病。

## 3. 梯度消失 vs 梯度爆炸：两个不同性质的问题

| | 梯度消失 | 梯度爆炸 |
|---|---|---|
| 数学原因 | ∏(W_hᵀ · diag(f′)) 特征值 < 1 | ∏(W_hᵀ · diag(f′)) 特征值 > 1 |
| 现象 | 早期时间步的参数**几乎不动**，学不到长依赖 | 梯度巨大，参数一步跳飞 → loss NaN |
| 本质 | **学习能力**问题（结构性，改结构才能治本） | **稳定性/工程**问题（有通用兜底手段） |
| 定位 | RNN 被淘汰的头号元凶 | 深网络通病，Transformer 也会遇到 |

**缓解工具箱**：

| 手段 | 针对 | 原理 / 备注 |
|---|---|---|
| 梯度裁剪（gradient clipping） | 爆炸 | 全局范数裁剪：若 ‖g‖>阈值(常取 1.0~5.0)，g ← g·阈值/‖g‖。只改方向不变、长度收敛，近似等价于"只减小学习率但保留方向" |
| 换激活 | 消失 | ReLU 导数恒 1 不衰减；但 RNN 里 ReLU 更易爆炸（无饱和上限）且正值域线性叠加以至于状态发散，需配正交初始化 |
| 正交初始化 | 爆炸/消失 | 让 W_h 的奇异值 ≈ 1，使连乘既不放大也不衰减（Glorot 对 RNN 不够，常用 `init=orthogonal`） |
| 门控 / 直通路径 | 消失（治本） | LSTM 的 c 传送带、GRU 的更新门、残差连接——给梯度一条"不走连乘"的高速路（详见 §4、环节06） |
| TBPTT | 消失（缓解） | 限制回传步数，损失更近的梯度也能让远层动起来（治标） |

**工程铁律**：梯度爆炸用裁剪就能兜底（训练初期必加）；梯度消失裁剪救不了，只能换结构——这正是 LSTM 出场的原因。

## 4. LSTM：记忆传送带（Long Short-Term Memory）

**直觉**：RNN 只靠一个 h_t 既当"记忆"又当"输出"，一更新全被冲淡。LSTM 拆成两条线：**c_t（记忆单元，你记得什么）** + **h_t（输出，你向外说什么）**，谁想改记忆必须过三个"门"。

```
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)          # 遗忘门：旧记忆保留多少（0 全忘 / 1 全留）
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)          # 输入门：新信息写多少
c̃_t = tanh(W_c · [h_{t-1}, x_t] + b_c)       # 候选记忆：新信息的"内容"
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t              # 记忆更新：遗忘旧 × 写入新
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)          # 输出门：从记忆里读出多少给外界
h_t = o_t ⊙ tanh(c_t)                        # 对外输出
```

**为什么 LSTM 能记住长距离（数学视角）**：看记忆更新式对 c_{t-1} 的偏导：

```
∂c_t / ∂c_{t-1} = f_t        （f_t 是一个对角阵/标量门，不是 W 矩阵）
```

误差沿 c 这条线回传时，每一级只乘一个遗忘门系数，**不经过连乘的 W_hᵀ**。当模型选择"这段信息该留着"（f_t → 1），梯度就能近乎无损地穿过几十上百步。这和 ResNet 的恒等旁路、Transformer 的残差是**同一个思想：给梯度修高速公路**（互链 [环节06-残差连接与归一化详解.md](../transformer/环节06-残差连接与归一化详解.md)）。

**代价**：门的开关是学出来的——"记住什么"本身变成可训练策略，代价是每个时间步计算量 4×RNN（4 组权重），且**串行依赖没有消除**：c_t 依赖 c_{t-1}，还是只能一步步滚。

## 5. GRU：两门版简化（Gated Recurrent Unit）

**直觉**：LSTM 三四个门有点冗余。GRU 把"记忆单元"取消，只留两个门，直接更新 h_t：

```
z_t = σ(W_z · [h_{t-1}, x_t] + b_z)          # 更新门：旧状态 vs 新候选，各占多少（= f+i 合一）
r_t = σ(W_r · [h_{t-1}, x_t] + b_r)          # 重置门：算新候选时，旧历史"重置"掉多少
h̃_t = tanh(W_h · [r_t ⊙ h_{t-1}, x_t] + b_h) # 候选状态
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t        # 直接加权融合（无独立 c_t）
```

**LSTM vs GRU**：

| 维度 | LSTM | GRU |
|---|---|---|
| 门数 | 3 门 + 1 候选（f/i/o + c̃） | 2 门 + 1 候选（z/r + h̃） |
| 参数量 | 4 组 W（约 GRU 的 4/3） | 3 组 W，更省 |
| 状态 | c_t（记忆）+ h_t（输出）双状态 | 只有 h_t 单状态 |
| 暴露控制 | 输出门可"只字不提"（h=0 但 c 记住） | 无输出门，h 全量暴露 |
| 梯度通道 | f_t 直通 | (1-z_t) 直通，同理 |
| 经验表现 | 数据多、任务难时略强、更稳 | 数据少/算力紧时性价比高，速度更快 |

**选型**：两者在多数任务上差距很小；GRU 参数少 25%、更快，适合小模型/低资源；LSTM 表达与可控性更精细，学术与经典任务存量更大。**大模型时代两者一起退役**——因为通病一样：串行 + 固定容量压缩。

## 6. RNN 变体与工程展开

**6.1 双向 RNN（BiRNN）**：正向读一遍 + 反向读一遍，每位置拼接两个方向的 h。动机：**后文也能给当前词提供信息**（如消歧）。历史意义：BERT 的"双向编码"精神雏形——这也是为什么"预训练语言模型"真正腾飞要等 Transformer：双向 = 非因果，天然不适配逐 token 生成任务，而 Decoder-only 直接用单向右向因果建模统吃训练与推理（互链 [环节07](../transformer/环节07-Block堆叠与整体架构详解.md) §3）。

**6.2 多层堆叠**：层间把上一层的 h_t 序列当下一层的输入序列（而非拼接）。与 Transformer 堆 Block 同理：底层学词法/局部，高层学语法/语义抽象。但 RNN 每加一层，BPTT 深度 = 时间 × 层数，训练更不稳——工程上往往"浅层 RNN + 深度在别处"。

**6.3 Seq2Seq（Encoder-Decoder）与注意力诞生**：编码器把整句压成**最后一个 h**，解码器从这一个向量开始生成——固定向量瓶颈被推到极致（长句信息全丢）。救法是 **Bahdanau 注意力（2014）**：解码每步不再只看最后一个 h，而是对编码器**所有位置的 h 做加权求和（对齐）**。

- 这一步是历史分水岭：从"压缩历史"转向"显式访问历史"
- 权重 = 对齐分数，是**可学习的"软索引"**——注意力机制的原型
- 再往后：去掉 RNN 骨架，只剩注意力 → Transformer（互链 [环节04-Attention注意力详解.md](../transformer/环节04-Attention注意力详解.md)）

**6.4 训练工程要点**：

| 技巧 | 解决什么 |
|---|---|
| 梯度裁剪 | 爆炸（§3，训练必须加） |
| 变长批处理 | 序列长短不一：batch 内 pad 到同长 + 掩码损失（padding 不贡献 loss） |
| Teacher Forcing | 训练时把"上一步真实词"喂下一步（而不是模型自己的预测），收敛快；但推理时用的是自己的预测 → 分布漂移，可用 scheduled sampling（按概率逐步切到自回归输入）缓解 |
| 正交初始化 + 小学习率 | 稳定连乘 |

## 7. 全维度对比 + 现在谁还在用 RNN

**RNN vs LSTM vs Transformer**（演进骨架与推 token 数值对照见 [环节07](../transformer/环节07-Block堆叠与整体架构详解.md) §2/§4/§5，本篇聚焦维度补齐）：

| 维度 | RNN | LSTM | Transformer |
|---|---|---|---|
| 历史表示 | h_t（固定向量，有损压缩） | c_t+h_t（门控压缩） | 全部位置向量显式可见 |
| 计算方式 | 串行（状态依赖） | 串行 | 并行（矩阵化） |
| 长程依赖 | 差（连乘衰减） | 好（门控直通） | 好（任意位置直接连） |
| 步进成本 | 训练 O(n·d²) / 推理每步 O(d²) | 同左（×4 门） | 训练 O(n²)·d / 推理每步 O(n·d) |
| 推理状态 | 固定（一个 h） | 固定（c,h） | 随上下文线性增长（KV Cache） |
| 训练并行度 | 低（BPTT 串行） | 低 | 高，GPU 友好 |
| 参数效率 | 最高（全共享） | 高 | 低（每层独立） |
| 可支持上下文 | 几十 | 几百 | 数千 ~ 百万 |
| 现役状态 | 概念 / 教材 / 时序小任务 | 学术 / 中小序列 | LLM 事实标准 |

**本质分水岭（一句话）**：RNN 系把"记忆"做成**固定容量的串行压缩**，Transformer 把"记忆"做成**容量随上下文增长的显式访问**——前者换来 O(1) 状态与参数效率，后者换来并行训练与无损长程。Transformer 赢在"并行 + 能堆大"这两点上与算力、数据红利同频。

**现在 RNN 系还活着吗（工程盘点）**：

1. **增量/流式场景**：状态天然 O(1)、只依赖过去 → 实时语音流式识别/合成、在线逐 token 处理、无法预取全序列的边缘端
2. **低成本推理**：无 KV Cache、内存恒定，适合嵌入式/低功耗（被 §8 现代谱系继承）
3. **参照系价值**：理解 Transformer 的"为什么"（面试必考）；理解现代高效架构的"递归本质"（§8 的一切都在证明 RNN 没死）
4. **科研与教学**：强基准、可解释性研究

## 8. 现代类 RNN：RNN 思想回来了（线性注意力 / RWKV / Mamba）

**8.1 为什么回潮**：Transformer 的问题不是效果，是**成本**——训练 O(n²) 注意力、推理时 KV Cache 随序列线性膨胀。而 RNN 恰好相反：**推理状态恒定、训练却串行**。全世界的目标很一致：**训练要像 Transformer 一样并行，推理要像 RNN 一样恒定状态**。于是"把 RNN 用可并行的方式重写一遍"成了最热赛道。

**8.2 统一视角（先看懂这张表，后面全是变体）**：

| | 记忆形式 | 训练 | 推理每步 | 读取历史 |
|---|---|---|---|---|
| Transformer | 显式存全部 KV（n×d） | 并行 O(n²·d) | O(n·d) | 任意位置按需精确访问 |
| RNN / LSTM | 压缩成固定状态（≈d） | 串行 BPTT | O(d²) 恒定 | 只能读"压缩后的摘要" |
| 现代类 RNN | 压缩成固定状态（≈d²内） | **可并行**（前缀计算/扫描） | O(d²) 恒定 | 状态按内容选择性更新 |

**8.3 线性注意力（Linear Attention / RetNet）**：数学上最优雅的一步——attention 的 softmax 换成核函数 φ(·)，因果注意力就能改写成**逐 token 累积的 RNN 形式**：

```
标准形式:  o_t = softmax(Q_t Kᵀ/√d) V          # 需要全序列 QK
线性改写:  S_t = S_{t-1} + φ(k_t) · v_tᵀ        # 状态：外积累积（== RNN 更新）
           o_t = φ(q_t)ᵀ · S_t                   # 读取：内积查询
```

- 即：**线性注意力 = 一个以"外积状态 S"为记忆的 RNN**，attention 与 RNN 由此在数学上统一
- 状态 S 固定尺寸 → 推理 O(1) 状态；训练时 S_t 可并行前缀计算
- 代价（为什么打不过 softmax attention）：核近似丢失 softmax 的归一化"锐利选择"；历史被压进固定状态后仍是**有损压缩**——精度型任务（精确检索、指针复制）明显退化
- RetNet / TransNormer / RWKV 家族的基础都是这一思想

**8.4 RWKV：把 Transformer 结构 RNN 化**（RNN 思想最彻底的实践者）：

- 每个 Block 仍保留类似 Transformer 的 RMSNorm、残差、FFN、多头，但把 **Self-Attention 换成"时间混合"（Time Mixing）**
- 核心替代：位置间权重不再用注意力计算，而是用**可学习的逐通道位置衰减 + 相对位置偏置**；Token Shift 把上两层输出按比例混入本层输入，弥补"不能主动查询历史"的缺陷
- 训练 = 整序列并行（可写成矩阵运算，一次算完所有位置），推理 = 逐 token 更新一组常数大小的状态 → **纯 RNN 式 O(1) 状态**
- 结论：用"预训练可并行 + 推理类 RNN"拿到了接近 Transformer 的效果，换来极低推理成本，代价是长上下文检索/精确引用弱于 attention

**8.5 Mamba / S4（状态空间模型 SSM）**：

- 连续系统 `h'(t) = A·h(t) + B·x(t)`，离散化后正是 RNN 骨架：`h_t = Ā·h_{t-1} + B̄·x_t`
- S4：用 HiPPO 结构化初始化 A，让固定状态也能"记住"长程（不用学，天生带记忆结构）
- **Mamba 的关键 = 选择性（Selective）**：让 B、C 和步长 Δ 都**依赖输入 x**——即模型按内容决定"这条信息要不要写进状态、要不要被读到"。这解决了"固定 A/B/C 的 SSM 无法按内容选择记忆"的致命短板（固定参数的线性递归只能记住统计规律，记不住"我的名字叫张三"这类具体事实）
- 工程实现：不用逐时间步循环训练，而用**硬件感知的分段并行扫描（parallel scan）**把 O(n) 步并行化 → 训练可并行 + 推理状态恒定，复杂度 O(n)
- 局限：固定状态的内存写入仍是"竞争式"的——新信息会覆盖旧信息，超长文档的精确回溯仍弱于 attention

**8.6 现状结论（2026 视角）**：

| 家族 | 状态成本 | 训练 | 精确长程检索 | 代表 | 现状 |
|---|---|---|---|---|---|
| softmax Attention | KV 随 n 增长 | 并行 O(n²) | 最强 | GPT/LLaMA/Qwen/DeepSeek | LLM 主流 |
| 线性注意力 | 固定 | 并行 O(n) | 弱 | RetNet、Performer 等 | 研究者喜爱，落地少 |
| RWKV | 固定 | 并行（类 Transformer 写法） | 弱 | RWKV-4/5/6 | 边缘端/成本敏感落地 |
| Mamba | 固定 | 并行扫描 O(n) | 中（有选择性仍被覆盖） | Mamba-1/2、Jamba 等 | 走向与 attention 混合 |

**一句话总结本谱系**：线性注意力/线性 RNN（RWKV、Mamba、RetNet）在做同一件事——**把 Transformer 训练的可并行性 + RNN 推理的恒定状态合体**，代价是把"任意精确访问历史"降级成"固定状态的选择性压缩"。工业界目前的主流答案是**混合**：Mamba/线性注意力块 + 标准 attention 块交错（如 Jamba 系、Zamba），用少量 attention 块兜住精确检索，用 RNN 块压成本。这与环节 04 §4 的稀疏/线性方案表是同一张考卷的不同答题（互链 [环节04](../transformer/环节04-Attention注意力详解.md)）。

## 9. 面试高频问答

1. **为什么 RNN 不能并行训练？** h_t 依赖 h_{t-1}，形成**串行数据依赖**；attention 各位置互不依赖、Q/K/V 全是整序列矩阵乘法，天然并行。

2. **RNN 为什么梯度消失？** BPTT 反向要连乘 `(t-k)` 个雅可比 `W_hᵀ·diag(f′)`，梯度按谱半径的幂指数缩水，隔十几步就学不到早期信息——本质是"共享权重 + 深度=序列长度"的深网络病。

3. **LSTM/GRU 怎么解决梯度消失？和 ResNet 什么关系？** 提供一条**绕过权重连乘的直通路径**：LSTM 的 `∂c_t/∂c_{t-1}=f_t`（遗忘门近似 1 时无损穿越）；GRU 的 `(1-z_t)` 同理。与残差恒等映射同源——都是"给梯度修高速公路"（互链 [环节06](../transformer/环节06-残差连接与归一化详解.md)）。

4. **梯度爆炸怎么办？为什么 Transformer 也会遇到？** 裁剪全局范数（阈值 1~5）：梯度超限就按比例缩回，只改长度不动方向。爆炸是深网络的通病，与序列/层深都有关，Transformer 训练初期同样要加。

5. **LSTM vs GRU 怎么选？** 结构差在门数与状态（3 门+双状态 vs 2 门+单状态），参数约 4:3；GRU 更省更快，数据少时更稳；LSTM 表达更细、存量研究更大。效果差距通常很小。

6. **现在大模型为什么不用 LSTM？** 三层理由：① 训练串行、无法吃满 GPU 并行红利；② 记忆是固定容量压缩，上下文稍长就稀释，不如注意力"显式访问"；③ 深度堆叠后 BPTT 梯度更难稳。本质是 LSTM 输在"并行 + 可扩展"上，而非单点效果。

7. **"线性注意力就是 RNN"怎么理解？** 把 softmax 换成核后，因果 attention 可改写为 `S_t = S_{t-1} + φ(k_t)v_tᵀ; o_t = φ(q_t)ᵀS_t`——这就是一个以外积为状态、逐 token 更新的 RNN。两者是**同一数学骨架的两种记忆读法**（显式 vs 压缩）。

8. **Mamba 的"选择性"解决了什么？** 固定参数的 SSM 对所有输入一视同仁地更新状态，只能学统计规律；Mamba 让 B/C/Δ 随输入变化，模型能**按内容决定忘什么、记什么**（类似 LSTM 门控但更一般），代价是仍存在固定状态的覆盖竞争。

9. **RNN/SSM 系为什么长程精确检索不如 attention？** 记忆被压缩成固定状态，读到的是"摘要"，没有逐 token 的精确索引；attention 保留了每个位置，可被任意 query 精确命中。所以混合架构用少量 attention 块补检索、RNN 块压成本。

10. **BPTT 和 Transformer 反向的复杂度差异？** BPTT 沿时间步串行展开，时间维度不可省（截断是近似）；Transformer 反向的注意力部分与序列长度相关的也是矩阵运算，但训练可整序列并行 + 无状态依赖。工程上更关心的是**推理**：RNN 每步 O(1) 状态、Transformer 每步 KV 随长度增长——这正是 §8 所有架构的动机。
