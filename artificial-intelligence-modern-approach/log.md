## 1. 读法说明

### 1.1 编号体系

| 前缀 | 含义 | 是否已改笔记 |
| ---- | ---- | ------------ |
| **E-xxx** | **笔记勘误**：我们自己的理解错误 / 推导错误 / 译法错误 | ✅ 已回改到对应章节笔记 |
| **O-xx** | **原书自身疑误**：印刷版 vs 官方勘误不一致、原书前后矛盾、疑似笔误 | 按原文照录 + `⚠️ 待核` 标注，**不擅自"修正"原书** |
| **P-xx** | **待核未闭环**：缺少一手信源或需对照纸书/中译本才能定论 | ⏳ 挂起 |

### 1.2 类型列（T1–T8，对应 `references/pitfalls.md`）

| 码 | 类型 | 码 | 类型 |
| -- | ---- | -- | ---- |
| T1 | 方向颠倒 | T5 | 近似概念混用 |
| T2 | 缺步骤 | T6 | 版本 / 来源错（3e 当 4e、章序错） |
| T3 | 性质误判 | T7 | 量化描述错（复杂度、数值、公式） |
| T4 | 类别混淆 | T8 | 归属错误（文献内容当原书、作者发挥当原著） |

### 1.3 状态列

`✅ 已修` · `⚠️ 照录标注` · `⏳ 待核` · `🔴 重大`

### 1.4 新增条目的规则

1. **发现即记**：新错误先追加到本文件对应章节分组（编号顺延），不要只改笔记了事。
2. **一条一坑**：一个位置一个错误占一行；同一位置多个错误拆多行。
3. **必填出处**：书页码（非 PDF 索引页，偏移 −12）或 Figure 编号；无页码的写"原书全文检索 0 次"。
4. **回写上层**：属于方法论级别的（会重复踩的）→ 同步进 `AIMA-翻译项目配置.md` §5；属于术语的 → 同步进 `AIMA-术语对照表.md`。
5. **闭环即改状态**：待核项一旦拿到一手证据，把 `P-xx` 的结论写入备注并把状态改成 ✅，不要删除原行。
