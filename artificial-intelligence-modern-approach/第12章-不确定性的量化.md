# 第 12 章 不确定性的量化（Quantifying Uncertainty）

> 来源：《人工智能：现代方法（第 4 版）》第四部分「不确定知识和不确定推理」
> 作者：Stuart Russell、Peter Norvig ｜ 中文版：人民邮电出版社
> 说明：本文为按原书章节结构整理的**学习笔记**（非逐字原文）。

## 0. 为什么需要概率

前 11 章的逻辑智能体要求知识**确定成立**，但真实世界做不到。章首：不确定性来自**部分可观测、非确定性或对手**。

用逻辑写诊断规则会失败，三个原因（§12.1.1）：

| 原因 | 说明 |
|---|---|
| **懒惰（laziness）** | 列出无例外规则所需的全部前件或后件太费事，这样的规则也难用 |
| **理论无知** | 该领域没有完备理论 |
| **实践无知** | 即使知道全部规则，某个具体病例的必要检验也可能没做或做不了 |

**资格问题**（qualification problem，p.241）：要让规则在逻辑上为真，得补上几乎无限的限定。概率用信念度概括懒惰与无知带来的不确定性，从而处理资格问题。

**核心转变**：从"真/假"转向"**信念度（degree of belief）**"。
**决策论 = 概率论 + 效用论**；理性智能体在不确定性下选择**期望效用最大**的动作。

---

## 12.1 不确定性下的动作

### 12.1.1 不确定性概述

以牙科诊断为例。定义布尔变量：

- `Toothache`（牙痛）、`Cavity`（龋齿）、`Catch`（探针卡住）

即使有牙痛，也不能确定有龋齿——还需要概率化的**因果知识**：

```
P(Cavity | Toothache) = 0.8
```

即："在有牙痛的前提下，有 80% 的可能存在龋齿。"

### 12.1.2 不确定性与理性决策

理性决策需要两个要素：

1. **信念度**：P(结果 | 动作、证据) —— 世界是怎样的
2. **效用（utility）**：结果对我的价值 —— 我想要什么

**期望效用（expected utility）**：

```
EU(a | e) = Σ_{s'} P(RESULT(a) = s' | a, e) · U(s')
```

选择动作 `a* = argmax_a EU(a | e)`。

> **例子：赶飞机**
> 计划 A90：起飞前 90 分钟出门，赶上航班的概率是 **97%**。A180 更可能赶上，但空等更久。A1440 提前 24 小时出发，几乎保证准时，等待却不可接受。
> 理性选择同时取决于各目标的相对重要性（效用）和实现的可能性。

## 12.2 基本概率记号

### 12.2.1 概率是关于什么的

- **样本空间（sample space）**：所有可能世界（possible world）的集合。
- 概率模型为每个可能世界 ω 赋予 P(ω)，且 `0 ≤ P(ω) ≤ 1`，`Σ_ω P(ω) = 1`。
- 文献注记区分三种看法：**频率主义**（只能来自实验的长期相对频率）、**客观主义**（概率是对象的真实倾向）、**主观主义**（刻画智能体的信念度）。正文把概率陈述相对于知识状态。

### 12.2.2 概率断言中的命题语言

- **随机变量（random variable）**：布尔型（`Cavity`）、离散型（`Weather` ∈ {sun, rain, cloud, snow}）、连续型（如 `NoonTemp`）
- **初等命题**：某个变量取某个值，如 `Weather = sun`（无歧义时可单写 `sun`）。**可能世界**是给所考虑的全部随机变量各赋一个值
- **复合命题**：用 ¬、∧、∨ 连接初等命题；逗号也常表示合取

- **概率分布**（单个变量）：`P(Weather) = ⟨0.6, 0.1, 0.29, 0.01⟩`，顺序 ⟨sun, rain, cloud, snow⟩
- **联合 / 全联合分布**：如 `P(Toothache, Cavity, Catch)`（2³ = 8 个条目）；变量取遍所考虑的全部随机变量时即全联合
- 命题概率是它在其中为真的那些世界的概率之和：`P(Weather = sun ∨ Weather = rain) = 0.6 + 0.1 = 0.7`

### 12.2.3 概率公理及其合理性

**基本公理**（式 12.1，可能世界）：`0 ≤ P(ω) ≤ 1`，且 `Σ_{ω ∈ Ω} P(ω) = 1`。命题的概率等于它在其中为真的世界概率之和（式 12.2）。

**由此导出**：

- 否命题：`P(¬a) = 1 − P(a)`
- 容斥：`P(a ∨ b) = P(a) + P(b) − P(a ∧ b)`（式 12.5）

式 (12.1) 与式 (12.5) 常合称 **Kolmogorov 公理**。

其余基本工具：

- **条件概率**：`P(a | b) = P(a ∧ b) / P(b)`（b 的信念为前提）
- **乘积法则**：`P(a ∧ b) = P(a | b) · P(b)`
- **链式法则**：`P(X₁, …, Xₙ) = Π_{i=1}^{n} P(Xᵢ | X₁, …, Xᵢ₋₁)`

> 贝叶斯立场：概率公理可视为"理性信念系统必须满足的约束"，由荷兰赌（Dutch book）论证其合理性。

## 12.3 使用完全联合分布进行推断

**思想**：只要拥有全联合分布 `P(X₁, …, Xₙ)`，就能回答任何概率查询。

**方法：边缘化（marginalization）+ 求和消元**

```
P(Y) = Σ_z P(Y, z)                    （对所有未观测变量 z 求和）

P(Y | e) = α · Σ_z P(Y, z, e)          （α 为归一化常数）
```

**牙科例子**（只保留 `Toothache`、`Cavity`、`Catch`）：

```
P(Toothache) = 0.108 + 0.012 + 0.016 + 0.064 = 0.2
```

求 `P(Cavity | Toothache)`：表中 `Cavity ∧ Toothache` 有两行（Catch 与 ¬Catch），必须先对 `Catch` **边缘化（求和）**，再归一化：

```
P(Cavity | Toothache) = α ⟨0.108 + 0.012, 0.016 + 0.064⟩
                      = α ⟨0.12, 0.08⟩
                      = ⟨0.6, 0.4⟩
```

> ⚠️ 常见错误：直接把 `⟨0.108, 0.012⟩` 归一化——那会得到 `⟨0.9, 0.1⟩`，而它其实是另一个查询 `P(Catch | Cavity ∧ Toothache)` 的答案。**规则：查询里有几个未观测变量，就要先对它们求和消元，最后才归一化。**（此例中 `¬Cavity` 那两项 0.016 + 0.064 绝不能丢。）

**致命缺点**：n 个布尔变量需要 `2ⁿ − 1` 个数值。n = 30 时已是 10 亿。**必须利用独立性**。

## 12.4 独立性

**定义**：a 与 b 独立，当且仅当

```
P(a | b) = P(a)   或等价地   P(a ∧ b) = P(a) · P(b)
```

- **无条件独立**（书中称 independence，亦称 marginal independence 与 absolute independence）
- 例子：`P(Toothache, Catch, Cavity, Weather) = P(Toothache, Catch, Cavity) · P(Weather)`
  → 四个变量的全联合有 2×2×2×4 = **32** 项，可由一张 **8** 项的牙科表加一张 **4** 项的天气表构造。
- 若 n 个变量**相互独立（mutually independent）**，则 `P(X₁,…,Xₙ) = Πᵢ P(Xᵢ)`，只需 n 个数值而非 2ⁿ − 1 个。

> ⚠️ **两两独立 ≠ 相互独立**：两两独立只要求任意一对独立，并不蕴含联合分布可分解。这是概率论里最常踩的坑，本书说的是"相互独立"。

**问题**：无条件独立很罕见（几乎任何变量都与其他变量有某种关联）。
**出路**：**条件独立性**——给定第三个变量后独立，这正是贝叶斯网络（第 13 章）的基础。

## 12.5 贝叶斯法则及其应用

```
P(b | a) = P(a | b) · P(b) / P(a)
```

多值变量写成向量形式：

```
P(Y | X) = P(X | Y) · P(Y) / P(X)
```

**为什么重要**：因果知识（`P(症状 | 疾病)`）通常容易获取，而诊断知识（`P(疾病 | 症状)`）才是我们想要的——贝叶斯法则把两者连接起来。

### 12.5.1 应用贝叶斯法则：简单实例

已知：
- 脑膜炎导致脖子僵硬：`P(s | m) = 0.7`（70% 的时间）
- 脑膜炎先验：`P(m) = 1/50000`
- 脖子僵硬先验：`P(s) = 0.01`（1%）

求 `P(m | s)`：

```
P(m | s) = 0.7 × (1/50000) / 0.01 = 0.0014
```

→ 脖子僵硬的患者里只有 **0.14%** 患脑膜炎。脑膜炎很强地指示脖子僵硬（0.7），但脖子僵硬的先验远高于脑膜炎的先验，所以后验仍然很小。

### 12.5.2 应用贝叶斯法则：合并证据

最朴素的做法：

```
P(Cavity | Toothache ∧ Catch) = α · P(Toothache ∧ Catch | Cavity) · P(Cavity)
```

若假设各证据在给定病因下**条件独立**（朴素贝叶斯）：

```
P(Toothache ∧ Catch | Cavity) = P(Toothache | Cavity) · P(Catch | Cavity)
```

→ 原 8 项表有 7 个独立数字；分解后是 `P(Toothache|Cavity)`、`P(Catch|Cavity)` 与 `P(Cavity)`，共 2+2+1 = 5 个。n 个症状时表示规模从 O(2ⁿ) 降为 O(n)。

## 12.6 朴素贝叶斯模型

**结构**：一个**共同原因（cause）**节点指向若干**证据（effects）**节点，且证据在给定原因下条件独立。

```
P(Cause, E₁, …, Eₙ) = P(Cause) · Π_i P(Eᵢ | Cause)
```

**后验计算**（贝叶斯法则的直接应用）：

```
P(Cause | e₁, …, eₙ) = α · P(Cause) · Π_i P(eᵢ | Cause)
```

### 12.6.1 用朴素贝叶斯做文本分类

- 任务：把文本分到预先定义的类别。书中例子是报纸栏目 news、sports、business、weather、entertainment（同一模型也用于垃圾邮件过滤等）
- 原因变量是 `Category`，效果变量是关键词**是否出现** `HasWord_i`（真/假）
- 独立假设常常不成立（如 “first quarter”）。后验会过度接近 0 或 1，但类别**排序**常常仍然准确

## 12.7 重游 wumpus 世界

用概率推理增强第 7 章的 wumpus 智能体：

- 智能体在方格 (i, j) 感知：`Breeze`（相邻有坑）、`Stench`（相邻有 wumpus）、`Glitter`（有金子）
- 目标：计算 `P(Pit at (i,j) | 已知的方格的坑相关信息)`

**关键洞见**：**"无感知"也是信息**。例如在某格感知到"无微风"，就排除了相邻格有坑的可能。

**场景**（原书 Figure 12.5）：智能体已访问 (1,1)、(1,2)、(2,1)；在 (1,1) **无**微风，在 (1,2) 与 (2,1) **都**感知到微风。原书设定：**除 (1,1) 外每个方格独立地以 0.2 的概率有坑**。方格被划分为三类：

| 类别 | 方格 | 处理方式 |
|---|---|---|
| **Known（已知）** | (1,1)、(1,2)、(2,1) | 已知无坑（证据的一部分） |
| **Frontier（前沿）** | (1,3)、(2,2)、(3,1) | 与已知格相邻，需枚举 |
| **Other（其余）** | 剩下 10 格 | 由条件独立性**整体消掉** |

> 关键：Other 格**不是"已知安全"**，而是可以被严格求和消掉——这正是本节的技术要点。

**对 `P₁,₃` 的推断**：把 `P₁,₃` 当作查询变量，则前沿只剩 `P₂,₂`、`P₃,₁`（4 种组合）。原书推导（式 12.23 后）：

```
P(P₁,₃ | known, b) = α′ P(P₁,₃) Σ_{frontier} P(b | known, P₁,₃, frontier) · P(frontier)
```

其中 `P(b | ·)` 只取 **1（与微风一致）或 0（不一致）**——不是软概率。于是求和就退化成"把所有**相容的**前沿组合的概率加起来"（原书 Figure 12.6 列出了这些模型）：

```
P₁,₃ = true  ：(1,2) 的微风已由 (1,3) 解释；(2,1) 的微风还需 (2,2) 或 (3,1) 有坑
               → 相容模型 (t,f)(f,t)(t,t) = 0.16 + 0.16 + 0.04 = 0.36
P₁,₃ = false ：(1,2) 的微风只能由 (2,2) 解释（(3,1) 与 (1,2) 不相邻）
               → 相容模型 (t,f)(t,t)      = 0.16 + 0.04       = 0.20

P(P₁,₃ | known, b) = α′ ⟨0.2, 0.8⟩ · ⟨0.36, 0.20⟩
                   = α′ ⟨0.072, 0.160⟩
                   ≈ ⟨0.31, 0.69⟩
```

**同一场景下的另外两格**：

```
P(P₂,₂ | known, b) = 0.2·1 / (0.2·1 + 0.8·0.2·0.2) = 0.2 / 0.232 ≈ 0.86
P(P₃,₁ | known, b) ≈ 0.31   （与 (1,3) 对称）
```

要点：

1. **结论（原书的落点）**：[1,3] 与 [3,1] 约 **0.31**，[2,2] 约 **0.86**。概率智能体应**避开 [2,2]**。纯逻辑只能说这三格都可能有坑，并不知道 [2,2] 比另外两格更糟。图 12.5(a) 里“没有可证明安全的格子”是逻辑局面；概率给出的差别是 [2,2] 糟得多。
2. 但**计算成本**随未知方格数指数增长（要枚举 2^f 种前沿组合）→ 需要更紧凑的表示（贝叶斯网络，第 13 章）与近似推断。

## 小结

1. 不确定性来自部分可观测、非确定性与对手；逻辑规则还因懒惰、理论无知与实践无知而失败。智能体用**信念度**处理它，从而应对资格问题。
2. 理性决策 = 最大化**期望效用**；决策论 = 概率论 + 效用论。
3. 概率公理（Kolmogorov）给出概率推论的形式基础；条件概率与乘积/链式法则是基本工具。
4. **全联合分布**可回答所有查询（通过边缘化与归一化），但规模为 2ⁿ，不实用；查询时要先对**所有**未观测变量求和消元。
5. **相互独立**（不是两两独立）能让联合分布分解为 `Π P(Xᵢ)`，从而指数级压缩表示；**条件独立性**更常见且强大。
6. **贝叶斯法则**把因果知识与诊断推断连接起来；**朴素贝叶斯**用条件独立假设简化推断，在文本分类上很成功。
7. wumpus 世界里三格约为 0.31 / 0.86 / 0.31，概率智能体应避开 [2,2]；逻辑智能体不知道这一格更糟。代价是随未知方格数指数爆炸，需要更结构化的表示。
