# 第 12 章 不确定性的量化（Quantifying Uncertainty）

> 来源：《人工智能：现代方法（第 4 版）》第四部分「不确定知识和不确定推理」
> 作者：Stuart Russell、Peter Norvig ｜ 中文版：人民邮电出版社
> 说明：本文为按原书章节结构整理的**学习笔记**（非逐字原文）。

## 0. 为什么需要概率

前 11 章的逻辑智能体要求知识**确定成立**，但真实世界做不到。不确定性的来源：

| 来源 | 说明 |
|---|---|
| **部分可观测** | 传感器无法看到全部状态（如牙医看不到神经） |
| **非确定性** | 动作效果不确定（如吃药未必痊愈） |
| **资格问题**（qualification problem） | 列举"动作可行"的全部前提实际上不可能 |
| **理论无知 / 实践无知** | 不知道全部规则，或懒得列全部例外 |

**核心转变**：从"真/假"转向"**信念度（degree of belief）**"。
**决策论 = 概率论 + 效用论**；理性智能体在不确定性下选择**期望效用最大**的动作。

---

## 12.1 不确定性下的动作

### 12.1.1 不确定性概述

以牙科诊断为例。定义布尔变量：

- `Toothache`（牙痛）、`Cavity`（龋齿）、`Catch`（探针卡住）

即使有牙痛，也不能确定有龋齿——还需要概率化的**因果知识**：

```
P(Cavity | Toothache) = 0.8
```

即："在有牙痛的前提下，有 80% 的可能存在龋齿。"

### 12.1.2 不确定性与理性决策

理性决策需要两个要素：

1. **信念度**：P(结果 | 动作、证据) —— 世界是怎样的
2. **效用（utility）**：结果对我的价值 —— 我想要什么

**期望效用（expected utility）**：

```
EU(a | e) = Σ_{s'} P(RESULT(a) = s' | a, e) · U(s')
```

选择动作 `a* = argmax_a EU(a | e)`。

> **例子：赶飞机**
> 提前 90 分钟出发：赶不上概率 0.05，代价是等待 90 分钟；提前 30 分钟出发：赶不上概率 0.30，但只等 30 分钟。
> 理性选择由两条曲线的**交叉点**决定——这正是决策论要解决的"权衡"。

## 12.2 基本概率记号

### 12.2.1 概率是关于什么的

- **样本空间（sample space）**：所有可能世界（possible world）的集合。
- 概率模型为每个可能世界 ω 赋予 P(ω)，且 `0 ≤ P(ω) ≤ 1`，`Σ_ω P(ω) = 1`。
- **两种解释**：
  - **频率主义**：概率 = 长期相对频率
  - **主观主义（贝叶斯）**：概率 = 智能体的信念度（本书采用）

### 12.2.2 概率断言中的命题语言

- **随机变量（random variable）**：布尔型（`Cavity`）、离散型（`Weather` ∈ {sunny, rain, …}）、连续型（`Temp`）
- **原子事件**：变量取特定值，如 `Weather = rain`
- **复合命题**：由原子事件用 ¬、∧、∨ 构成

- **全联合分布 / 概率分布**：
  - `P(Weather) = ⟨0.72, 0.1, 0.08, 0.1⟩`（离散）
  - `P(Toothache, Cavity, Catch)`（联合分布，含 2³ = 8 个条目）
- 用于复合命题的**求和**：`P(Weather = sunny ∨ Weather = rain) = 0.72 + 0.1 = 0.82`

### 12.2.3 概率公理及其合理性

**Kolmogorov 公理**（以可能世界为单位）：

1. `0 ≤ P(ω) ≤ 1`（非负性）
2. `Σ_{ω ∈ Ω} P(ω) = 1`（归一性）

**导出结论**：

- 否命题：`P(¬a) = 1 − P(a)`
- 包含-排斥：`P(a ∨ b) = P(a) + P(b) − P(a ∧ b)`
- **条件概率**：`P(a | b) = P(a ∧ b) / P(b)`（b 的信念为前提）
- **乘积法则**：`P(a ∧ b) = P(a | b) · P(b)`
- **链式法则**：`P(X₁, …, Xₙ) = Π_{i=1}^{n} P(Xᵢ | X₁, …, Xᵢ₋₁)`

> 贝叶斯立场：概率公理可视为"理性信念系统必须满足的约束"，由荷兰赌（Dutch book）论证其合理性。

## 12.3 使用完全联合分布进行推断

**思想**：只要拥有全联合分布 `P(X₁, …, Xₙ)`，就能回答任何概率查询。

**方法：边缘化（marginalization）+ 求和消元**

```
P(Y) = Σ_z P(Y, z)                    （对所有未观测变量 z 求和）

P(Y | e) = α · Σ_z P(Y, z, e)          （α 为归一化常数）
```

**牙科例子**（只保留 `Toothache`、`Cavity`、`Catch`）：

```
P(Toothache) = 0.108 + 0.012 + 0.016 + 0.064 = 0.2
P(Cavity | Toothache) = α ⟨0.108, 0.012⟩ ≈ ⟨0.6, 0.4⟩
```

**致命缺点**：n 个布尔变量需要 `2ⁿ − 1` 个数值。n = 30 时已是 10 亿。**必须利用独立性**。

---

## 12.4 独立性

**定义**：a 与 b 独立，当且仅当

```
P(a | b) = P(a)   或等价地   P(a ∧ b) = P(a) · P(b)
```

- **绝对值独立性**（unconditional independence）
- 例子：`P(Toothache, Catch, Cavity, Weather) = P(Toothache, Catch, Cavity) · P(Weather)`
  → 4 个变量的表从 2⁴ − 1 = 15 个值降到 2³ − 1 + 1 = 8 个值。
- 若 n 个变量两两独立，只需 n 个数值，而非 2ⁿ。

**问题**：绝对独立性很罕见（几乎任何变量都与其他变量有某种关联）。
**出路**：**条件独立性**——给定第三个变量后独立，这正是贝叶斯网络（第 13 章）的基础。

---

## 12.5 贝叶斯法则及其应用

```
P(b | a) = P(a | b) · P(b) / P(a)
```

或者写成**多证据形式**：

```
P(Y | X) = P(X | Y) · P(Y) / P(X)
```

**为什么重要**：因果知识（`P(症状 | 疾病)`）通常容易获取，而诊断知识（`P(疾病 | 症状)`）才是我们想要的——贝叶斯法则把两者连接起来。

### 12.5.1 应用贝叶斯法则：简单实例

已知：
- 脑膜炎导致脖子僵硬：`P(s | m) = 0.5`
- 脑膜炎先验：`P(m) = 1/50000`
- 脖子僵硬先验：`P(s) = 1/20`

求 `P(m | s)`：

```
P(m | s) = 0.5 × (1/50000) / (1/20) = 0.0002
```

→ 结论：脖子僵硬**不意味着**脑膜炎（这正是医生用贝叶斯推理的理由）。

### 12.5.2 应用贝叶斯法则：合并证据

最朴素的做法：

```
P(Cavity | Toothache ∧ Catch) = α · P(Toothache ∧ Catch | Cavity) · P(Cavity)
```

若假设各证据在给定病因下**条件独立**（朴素贝叶斯）：

```
P(Toothache ∧ Catch | Cavity) = P(Toothache | Cavity) · P(Catch | Cavity)
```

→ 只需存 2 个条件概率而非 4 个，规模从 2ⁿ 降为 n。

---

## 12.6 朴素贝叶斯模型

**结构**：一个**共同原因（cause）**节点指向若干**证据（effects）**节点，且证据在给定原因下条件独立。

```
P(Cause, E₁, …, Eₙ) = P(Cause) · Π_i P(Eᵢ | Cause)
```

**后验计算**（贝叶斯法则的直接应用）：

```
P(Cause | e₁, …, eₙ) = α · P(Cause) · Π_i P(eᵢ | Cause)
```

**典型应用：文本分类**

- 任务：把邮件分为`垃圾/非垃圾`，或新闻归入不同主题
- 特征：词（或词组）的出现。文本由 n 个词组成，每个词的条件概率相乘
- 优点：只需 O(n) 数量级的参数，训练快、推断快，实践中效果好
- 缺点：**条件独立假设常常过强**（词与词明显相关），但"分类决策"往往仍正确
- 变体：若用二元特征（出现/不出现）而非计数，就是 Bernoulli 朴素贝叶斯

## 12.7 重游 wumpus 世界

用概率推理增强第 7 章的 wumpus 智能体：

- 智能体在方格 (i, j) 感知：`Breeze`（相邻有坑）、`Stench`（相邻有 wumpus）、`Glitter`（有金子）
- 目标：计算 `P(Pit at (i,j) | 已知的方格的坑相关信息)`

**关键洞见**：**"无感知"也是信息**。例如在某格感知到"无微风"，就排除了相邻格有坑的可能。

**计算示例**（前沿两方格问题）：

```
P(P₁,₃) = 0.2    P(P₂,₂) = 0.2    P(P₁,₃ ∨ P₂,₂) = 0.2 → 二者互斥地不确定
∴ P(P₁,₃) = 0.2 / (0.2 + 0.2 − 0.04) ≈ 0.31   （用归一化后）
```

要点：
1. 概率推理让小世界（小型网格）里的智能体能**做出有信息的冒险决策**
2. 但**计算成本**随网格规模指数增长 → 需要更紧凑的表示（贝叶斯网络，第 13 章）与近似推断

## 小结

1. 不确定性来自部分可观测、非确定性、资格问题与无知；智能体用**信念度**处理它。
2. 理性决策 = 最大化**期望效用**；决策论 = 概率论 + 效用论。
3. 概率公理（Kolmogorov）给出概率推论的形式基础；条件概率与乘积/链式法则是基本工具。
4. **全联合分布**可回答所有查询（通过边缘化与归一化），但规模为 2ⁿ，不实用。
5. **独立性**能指数级压缩表示；**条件独立性**更常见且强大。
6. **贝叶斯法则**把因果知识与诊断推断连接起来；**朴素贝叶斯**用条件独立假设简化推断，在文本分类上很成功。
7. wumpus 世界说明概率推理能产生有效行为，但需要更结构化的表示。
