## 0. 本章要解决的问题

第 17 章求解 MDP 时，转移模型 `P(s′|s,a)` 和奖励 `R(s,a,s′)` 是**给定的**。本章的智能体**身在** MDP 里：模型或奖励函数可以未知，必须自己行动，才能从经验里学会把期望奖励之和最大化。

监督学习靠教师给出的输入/输出对。把它套到国际象棋上：局面进、着法出，训练数据可以是数百万盘大师对局。赢家的着法大体是好的，但例子大约只有 **10⁸**，局面空间大约 **10⁴⁰**。新对局很快走出数据库，学到的函数也不知道着法要达成将死、甚至不知道着法怎样改子力位置。更现实的问题没有这样的“大师数据库”。

**强化学习（reinforcement learning，RL）**让智能体与世界交互，并周期性地收到**奖励**（心理学里也叫 reinforcement）。象棋里赢为 **1**、负为 **0**、和为 **1/2**。目标与第 17 章相同：最大化期望奖励之和。差别是智能体没有拿到一份写好的 MDP。像下一盘不懂规则的新游戏，走了大约一百步，裁判才说“你输了”。

给奖励信号通常比给“每个局面的正确动作”容易：几行代码就能告诉象棋程序输赢，或告诉赛车程序冲线、失败或撞车。设计者也不必是能在任何局面指出正确动作的专家。

只在极少状态给出信息的奖励叫**稀疏奖励（sparse reward）**。网球、板球可以按每一分、每一次跑动加奖；赛车可以奖“沿正确方向前进”；学爬时任何向前的位移都算成就。这些中间奖励让学习容易得多。奖励信号本身正确时，RL 是一条很一般的造智能体的路，模拟环境里经验几乎不缺。加上深度学习之后，新应用包括：从原始画面学打 Atari（Mnih 等，2013）、控制机器人（Levine 等，2016）、打扑克（Brown 与 Sandholm，2017）。

本章把做法分成三类：

| 做法 | 学什么 | 用不用转移模型 |
|---|---|---|
| **基于模型的强化学习** | 效用 `U(s)`（从 s 起的奖励之和）。模型可以事先已知（如下棋规则），也可以从动作效果里学 | 用 |
| **无模型 · 动作效用学习** | 最常见的是 **Q-learning**：学 `Q(s,a)`，即在 s 执行 a 之后的奖励之和。选 `Q` 最大的动作 | 不用 |
| **无模型 · 策略搜索** | 直接学 `π(s)`。按第 2 章的说法，这是反射智能体 | 不用 |

部分可观测时，转移模型还用于状态估计（第 14 章）。

脚注：RL 文献更靠近运筹学而不是经济学，常把效用函数叫作**价值函数**，记为 `V(s)`。本章仍用第 17 章的效用 `U`。

路线：22.2 策略固定，只学效用（被动）；22.3 还要自己决定做什么（主动），核心是探索；22.4 用归纳学习（含深度学习）加快泛化，并讨论伪奖励与分层动作；22.5 策略搜索；22.6 用演示而不是奖励信号的学徒学习；22.7 应用。读 22.2 之前需要第 17 章的 MDP。

## 22.1 从奖励中学习（Learning from Rewards）

本节的动机已写在 §0。这里只把后文会反复用到的划分固定下来。

- **被动强化学习**：策略 `π(s)` 固定，任务是学状态效用，或状态–动作对的值；也可以顺便学环境模型。
- **主动强化学习**：智能体还得弄清该做什么。主要问题是**探索**——必须尽量经历环境，才能学会在其中如何行动。

奖励写在**转移**上，与第 17 章一致。后文所有贝尔曼方程都是对 `s′` 求和，方括号里是 `R(s,a,s′)+γU(s′)`，`max` 在求和之外。4×3 网格上非终止状态之间的转移奖励为 **−0.04**（图 22.1）。

## 22.2 被动强化学习（Passive Reinforcement Learning）

环境完全可观测，动作和状态都不多，策略 `π(s)` **已经固定**。智能体要学的是 `U^π(s)`：从 s 开始执行 `π` 的期望折扣总奖励。这样的智能体叫**被动学习智能体**。

任务接近策略迭代里的**策略评估**（17.2.2），差别是被动智能体**既不知道** `P(s′|s,a)`，**也不知道** `R(s,a,s′)`。

例子是第 17 章的 **4×3** 世界。意图方向成功概率 0.8，两个垂直方向各 0.1；撞墙留在原地。进入两个终止格的转移奖励为 **+1** 与 **−1**，其余转移 **−0.04**。本章公式都保留折扣因子 `γ`，但 4×3 上取 **`γ = 1`**（不折扣）。

图 22.1(a)：该随机环境下的最优策略有**两套**，因为在 **(3,1)**，Left 与 Up 都最优（与图 17.2 相同）。图 22.1(b) 是给定策略 `π` 时各状态的效用。文本层自上而下、从左到右读出的小数如下（终止格的 +1/−1 来自试验箭头与第 17 章的终止格，不是四位小数）：

|  | 1 | 2 | 3 | 4 |
|---|---:|---:|---:|---:|
| **y=3** | 0.8516 | 0.9078 | 0.9578 | +1 |
| **y=2** | 0.8016 | 墙 | 0.7003 | −1 |
| **y=1** | **0.7453** | 0.6953 | 0.6514 | 0.4279 |

(1,1) 的 **0.7453** 与第 17 章最优期望总奖励一致。九个非终止格是后文 RMS 的平均范围。

智能体用 `π` 做一系列**试验（trial）**。每次从 **(1,1)** 出发，直到终止格 **(4,2)** 或 **(4,3)**。感知同时给出当前状态，以及**刚刚这次转移**带来的奖励。书中三条典型试验（动作在箭头上，奖励是该转移的 `R`）：

1. `(1,1) −0.04↑ (1,2) −0.04↑ (1,3) −0.04→ (1,2) −0.04↑ (1,3) −0.04→ (2,3) −0.04→ (3,3) +1→ (4,3)`
2. `(1,1) −0.04↑ (1,2) −0.04↑ (1,3) −0.04→ (2,3) −0.04→ (3,3) −0.04→ (3,2) −0.04↑ (3,3) +1→ (4,3)`
3. `(1,1) −0.04↑ (1,2) −0.04↑ (1,3) −0.04→ (2,3) −0.04→ (3,3) −0.04→ (3,2) −1↑ (4,2)`

目标是用这些奖励估计每个非终止状态的 `U^π(s)`。定义与式 (17.2)（p.567）相同：

```
U^π(s) = E[ Σ_{t=0}^{∞} γ^t R(S_t, π(S_t), S_{t+1}) ]          (22.1)
```

`S_t` 是从 `S₀ = s` 执行 `π` 时、时刻 t 所到状态的随机变量。

### 22.2.1 直接效用估计

**直接效用估计（direct utility estimation）**把状态效用定义成从该状态起的期望总奖励，即期望**此后奖励（reward-to-go）**。一次试验给每个被访问状态提供这个量的样本。

`γ = 1` 时，此后奖励就是从该次访问起、直到终止的奖励之和。第一条试验从终点倒推：

| 访问 | 此后奖励 |
|---|---|
| (3,3)→(4,3) 得 +1 | **1** |
| (2,3) | −0.04 + 1 = **0.96** |
| (1,3) 第二次 | −0.04 + 0.96 = **0.92** |
| (1,2) 第二次 | −0.04 + 0.92 = **0.88** |
| (1,3) 第一次 | −0.04 + 0.88 = **0.84** |
| (1,2) 第一次 | −0.04 + 0.84 = **0.80** |
| (1,1) | −0.04 + 0.80 = **0.76** |

与原文一致：(1,1) 一个样本 **0.76**；(1,2) 两个样本 **0.80** 与 **0.88**；(1,3) 两个样本 **0.84** 与 **0.92**。每次试验结束时，算法记下各状态的观察此后奖励，用表中的**运行平均**更新估计。试验无穷多时，样本平均收敛到式 (22.1) 的期望。

于是 RL 被化成监督学习：每个例子是一对（状态，此后奖励）。强有力的监督学习算法很多，但这条路丢掉一条约束：

**一个状态的效用，由该状态的奖励和后继状态的期望效用决定。**

固定策略时，效用满足贝尔曼方程（亦见式 (17.14)）：

```
U_i(s) = Σ_{s′} P(s′|s, π_i(s)) [ R(s, π_i(s), s′) + γ U_i(s′) ]     (22.2)
```

忽略状态之间的联系，就丢掉学习机会。第二条试验到达此前没去过的 **(3,2)**，下一步到 **(3,3)**；第一条试验已经表明 (3,3) 效用很高。贝尔曼方程立刻提示 (3,2) 的效用也可能高，因为它通向 (3,3)。直接效用估计要等到**这次试验结束**才知道这件事。

更广地说，直接效用估计是在一个过大的假设空间里找 `U`：其中许多函数违反贝尔曼方程。因此它往往收敛很慢。

### 22.2.2 自适应动态规划

**自适应动态规划（adaptive dynamic programming，ADP）**先学会把各状态效用连在一起的转移模型，再用动态规划解对应的 MDP，从而用上这些约束。

对被动智能体：把学到的 `P(s′|s, π(s))` 和观察到的 `R(s, π(s), s′)` 代入式 (22.2)。策略固定时这些方程是**线性的**，任意线性代数程序都能解。也可以改用**修正策略迭代**（p.578）：模型每变一次，就用简化的价值迭代更新效用；模型通常只变一点，用上一轮效用当初值，收敛很快。

环境完全可观测时，学转移模型是监督学习：输入是状态–动作对 `(s,a)`，输出是结果状态 `s′`。`P(s′|s,a)` 用计数表 `N_{s′|sa}` 直接估计：在 s 执行 a 后到达 s′ 的次数。三条试验里，**(3,3)** 上 Right 执行了 **4** 次，结果两次到 (3,2)、两次到 (4,3)，于是

```
P((3,2)|(3,3), Right) = P((4,3)|(3,3), Right) = 1/2
```

被动 ADP 智能体（图 22.2）大致是：

```
function PASSIVE-ADP-LEARNER(percept) returns 动作
  percept 给出当前状态 s′ 与奖励 r
  持久：固定策略 π；带 P、R、A、γ 的 MDP；效用表 U（初空）；
        计数 N_{s′|s,a}（初 0）；上一状态与动作 s,a（初空）
  若 s′ 是新状态：U[s′] ← 0
  若 s 非空：
      N_{s′|s,a}[s,a][s′] 加 1
      R[s,a,s′] ← r
      把 a 加入 A[s]
      P(·|s,a) ← NORMALIZE(N_{s′|s,a}[s,a])
      U ← POLICY-EVALUATION(π, U, mdp)     # 解固定策略的贝尔曼方程，p.577
  s,a ← s′, π[s′]
  return a
```

智能体自选一个 `γ`，并增量地计算 MDP 的 `P` 与 `R`。

图 22.3 是它在 4×3、图 22.1 最优策略下的学习曲线。效用估计变好的速度，只受“学转移模型有多快”限制；就这一点说，ADP 是衡量其他 RL 算法的基准。状态空间一大就不可行：西洋双陆棋大约要解 **10²⁰** 个方程、**10²⁰** 个未知数。

图 22.3 上的数字：很少被访问的 **(2,1)** 与 **(3,2)** 分别要 **14** 次和 **23** 次试验，才“发现”自己连到 (4,3) 的 +1 出口。(b) 是 `U(1,1)` 估计的**均方根误差（RMS）**，对 **50** 次运行、每次 **100** 个试验取平均。

### 22.2.3 时序差分学习

解底层 MDP 不是使用贝尔曼方程的唯一办法。也可以用观察到的转移去调整观察到的状态效用，使它们满足约束。

第二条试验里有一次从 **(1,3)** 到 **(2,3)**。第一次试验之后的估计是 `U^π(1,3) = 0.88`、`U^π(2,3) = 0.96`（0.88 是样本 0.84 与 0.92 的平均；0.96 是 (2,3) 的唯一样本）。若这次转移**每次**都发生，应有

```
U^π(1,3) = −0.04 + U^π(2,3) = 0.92
```

⚠️ **待核**：紧接着的原文写“它当前的估计 **0.84** 可能偏低，应当上调”。同一段前面把估计写成 **0.88**。0.84 是第一次试验里 (1,3) 的一个样本，0.88 才是运行平均。此处照录两处数字，不把其中一处改写成另一处。

一般地，经动作 `π(s)` 从 s 转到 s′ 时，更新

```
U^π(s) ← U^π(s) + α [ R(s, π(s), s′) + γ U^π(s′) − U^π(s) ]     (22.3)
```

`α` 是**学习率**。更新用的是相继状态（因而相继时刻）的效用差，所以叫**时序差分（temporal-difference，TD）**方程。与第 19 章权值更新（如式 (19.6)，p.680）一样，TD 项 `R(s,π(s),s′)+γU^π(s′)−U^π(s)` 是误差信号，更新用来减小它。

TD 方法把效用估计朝“估计正确时局部成立的均衡”推。被动学习的均衡就是式 (22.2)。式 (22.3) 确实会到达这个均衡，但有两处细处：

1. 更新只含**观察到的**后继 `s′`，均衡条件却含所有可能的下一状态。罕见转移会让 `U^π(s)` 一次改很多；这种转移本身罕见，所以极限下 `U^π(s)` 的**平均值**仍收敛到正确量，数值本身可以继续波动。
2. 若把 `α` 改成随该状态被访问次数增加而下降的函数（图 22.4），则 `U^π(s)` **本身**收敛到正确值。技术条件在 p.684。图 22.5 用的是 `α(n) = 60/(59+n)`，满足这些条件。

图 22.4 的被动 TD 智能体：

```
function PASSIVE-TD-LEARNER(percept) returns 动作
  percept 给出 s′ 与 r
  持久：固定策略 π；上一状态 s（初空）；效用表 U（初空）；状态频率 N_s（初 0）
  若 s′ 是新状态：U[s′] ← 0
  若 s 非空：
      N_s[s] 加 1
      U[s] ← U[s] + α(N_s[s]) × (r + γ U[s′] − U[s])
  s ← s′
  return π[s′]
```

图 22.5：4×3 上的 TD 曲线。(a) 单次运行 **500** 个试验中若干状态的效用估计，可与图 22.3(a) 的 100 次试验对照。(b) `U(1,1)` 的 RMS，同样是 **50** 次运行、每次 **100** 个试验的平均。TD 学得不如 ADP 快，波动大得多，但简单得多，每次观察的计算也少得多。

**TD 做更新不需要转移模型。** 环境用观察到的转移，自己把相邻状态连起来。

ADP 与 TD 都做局部调整，让每个状态与其后继“一致”。差别在于：TD 让状态对齐**观察到的**那一个后继（式 22.3）；ADP 让状态对齐**所有可能**后继，并按概率加权（式 22.2）。把 TD 调整对大量转移取平均后，这个差别消失，因为各后继出现的频率近似于它的概率。更要紧的差别是：TD 对每次观察到的转移只调整**一次**；ADP 调整到 `U` 与 `P` 重新一致为止，需要多少次就做多少次。观察到的转移只局部改变 `P`，影响却可能要传遍整个 `U`。因此 TD 可以看成 ADP 的一种粗糙但高效的一阶近似。

从 TD 的角度看，ADP 的每一次调整都像是用当前转移模型模拟出来的一次**伪经验（pseudoexperience）**。TD 也可以用模型生成许多想象中的转移：每观察到一次真实转移，就生成大量假想转移。效用估计会越来越接近 ADP，代价是计算时间。

同样，可以直接近似价值迭代或策略迭代，从而做出更高效的 ADP。价值迭代本身高效，但状态数若到 **10¹⁰⁰** 就不可行；而每轮里大量调整极其微小。一个办法是限制每次观察之后的调整次数，或用启发式只做最显著的那些。**优先扫描（prioritized sweeping）**优先调整这样的状态：它的可能后继刚刚发生了大幅度的效用调整。

用这类启发式，近似 ADP 在训练序列条数上可以和完整 ADP 差不多快，总计算量则可以少若干个数量级（习题 22.PRSW），从而处理完整 ADP 放不下的状态空间。还有一个好处：新环境学习早期，`P` 往往离正确很远，为它算一个精确效用函数意义不大。近似算法可以用一个随模型变准而减小的最小调整幅度，从而去掉学习早期因模型大变而出现的很长的价值迭代。

## 22.3 主动强化学习（Active Reinforcement Learning）

被动智能体的策略是固定的。**主动学习智能体**自己决定采取什么动作。先改 ADP。

第一，要学的是**全部动作**的转移模型，而不只是固定策略下的模型。`PASSIVE-ADP-AGENT` 的学习机制够用。第二，效用是**最优策略**下的效用，服从贝尔曼方程：

```
U(s) = max_{a ∈ A(s)} Σ_{s′} P(s′|s,a) [ R(s,a,s′) + γ U(s′) ]     (22.4)
```

用第 17 章的价值迭代或策略迭代求解。奖励仍在转移上：`R(s,a,s′)` 在对 `s′` 的求和里面，`max` 在求和之外。

第三，每一步做什么。若 `U` 对学到的模型已是最优，可以用一步前瞻取出最优动作；若用的是策略迭代，最优策略已经在手，执行它推荐的动作即可。问题是：该不该这么做？

### 22.3.1 探索

图 22.6 是一个 ADP 智能体的试验序列：每步都执行**当前学到的模型**下最优策略所推荐的动作。它**没有**学到真实效用，也**没有**学到真实最优策略。第三次试验找到一条沿下路到达 +1 的策略，经过 **(2,1)、(3,1)、(3,2)、(3,3)**（图 22.6(b)）。小幅试探之后，从**第八次**试验起它钉在这条策略上，既不学其他状态的效用，也找不到经由 **(1,2)、(1,3)、(2,3)** 的最优路线。这叫**贪心智能体**：每步都贪心地采取它当前认为最优的动作。贪心有时能收敛到最优策略，常常不能。

选“最优动作”为什么得到次优结果？因为学到的模型不等于真实环境；在模型里最优的动作，在真实环境里可以是次优的。智能体又不知道真实环境，算不出真实环境下的最优动作。

动作除了带来奖励，还用结果状态里的感知带来**信息**。与 17.3 的老虎机问题相同，必须在两件事之间权衡：利用当前最好的动作以最大化短期奖励，以及探索先前未知的状态以获得可能改变策略的信息（并在将来得到更大奖励）。本节不把老虎机当作主例，只借用这个权衡。

精确解出最优探索方案很难，但仍可以设计最终能发现最优策略的方案，只是花费的时间可以长于最优。这类方案不能对“下一步”贪心，而应是 **GLIE**（greedy in the limit of infinite exploration，无限探索极限下的贪心）。GLIE 必须在每个状态把每个动作试**无限次**，这样“漏掉最优动作”的概率才不会停在一个正的有限数上。使用 GLIE 的 ADP 最终会学到真实转移模型，然后可以转为利用。

最简单的 GLIE 之一：在时刻 t 以概率 **1/t** 选随机动作，其余时间走贪心策略。它最终收敛到最优策略，但可以很慢。更好的做法给“试得很少的动作”一些权重，同时倾向于避开被认为低效用的动作（与 5.4 的蒙特卡洛树搜索同类）。做法是改写约束方程 (22.4)，给相对未探索的状态–动作对更高的效用估计。

这等于对环境放一个**乐观先验**，使智能体一开始表现得好像到处都有很好的奖励。令 `U⁺(s)` 为 s 的乐观效用估计（期望此后奖励），`N(s,a)` 为在 s 试过动作 a 的次数。ADP 里若用价值迭代，就把式 (17.10)（p.573）改成：

```
U⁺(s) ← max_a  f( Σ_{s′} P(s′|s,a) [ R(s,a,s′) + γ U⁺(s′) ] , N(s,a) )     (22.5)
```

`f` 是**探索函数**。`f(u,n)` 在贪心（偏好高效用 `u`）与好奇（偏好试得少、计数 `n` 低的动作）之间取舍。它应随 `u` 增加、随 `n` 下降。一个特别简单的定义：

```
f(u, n) = R⁺    若 n < N_e
        = u     否则
```

`R⁺` 是“任何状态上可能得到的最佳奖励”的乐观估计，`N_e` 是固定参数。效果是每个状态–动作对至少被试 **`N_e` 次**。

式 (22.5) 右边用的是 `U⁺` 而不是 `U`，这一点很重要。探索进行下去后，起点附近的状态和动作会被试很多次。若右边用较悲观的 `U`，智能体很快就不愿再向远处探索。用 `U⁺` 时，探索的好处从未探索区域的边缘往回传，因此**通向**未探索区域的动作被加权提高，而不只是那些本身陌生的动作。

图 22.7 用 **`R⁺ = 2`、`N_e = 5`**。策略损失很快走向 0，与贪心不同；仅仅 **18** 次试验就找到非常接近最优的策略。效用估计的 RMS **没有**同样快地收敛：智能体很快不再探索无奖励的部分，之后只是“偶然”经过。它不去关心那些已知不好、而且可以避开的状态的精确效用——坠落悬崖时，学哪家电台最好没有多大意义。

### 22.3.2 安全探索

到这里为止，假定智能体可以随意探索：负奖励只用来改进世界模型。下棋输掉，除了面子，没有损伤，学到的东西让下一盘更好。自动驾驶的模拟器里可以去探性能边界，撞了按重置。

真实世界没有这么宽容。太阳鱼幼体活到成年的概率大约是 **0.00000001**。许多动作在 4.5 节在线搜索的意义上**不可逆**：之后没有任何动作序列能把状态恢复到该动作之前。最坏情况是进入**吸收状态**：任何动作都没有效果，也没有奖励。

许多实际场合承担不起不可逆动作或吸收状态。在真车上学驾驶，应当避开：

- 大负奖励的状态，如严重车祸；
- 无法逃出的状态，如开进深沟；
- 永久限制未来奖励的状态，如损坏发动机、最高速度被降低。

进入坏状态有两种原因：模型未知，主动朝一个结果很坏的方向探索；或者模型是错的，不知道某个动作会灾难性。图 22.2 用**最大似然估计**（第 20 章）学转移模型，而且只按估计模型选策略，等于把模型当成正确的。这不一定好：不懂红绿灯的出租车智能体闯一两次红灯没事，然后形成“以后所有红灯都闯”的策略。

更好的想法：选一个对“有合理机会成为真模型”的**整个范围**都还不错的策略，哪怕它对最大似然模型并不是最优。原文说有三种带这个味道的数学途径；正文明确展开的是下面两条。

**贝叶斯强化学习**：对“真模型是什么”的假设 `h` 给先验 `P(h)`，用迄今的观察按贝叶斯规则得到后验 `P(h|e)`。若智能体决定停止学习，最优策略是期望效用最高的那一个。令 `U^π_h` 为在模型 `h` 中执行 `π`、对所有可能起点取平均的期望效用，则

```
π* = argmax_π  Σ_h  P(h|e) U^π_h
```

某些特殊情形下这个策略甚至可以算出来。若以后还要继续学习，最优策略就难得多：必须考虑未来观察对转移模型信念的影响。问题变成一个**探索 POMDP**，其信念状态是模型上的分布。原则上，智能体还没进入世界就可以把这个探索 POMDP 写出来并解掉（习题 22.EPOM 要求对扫雷游戏找出最好的第一步）。结果是一套完整策略：给定任何感知序列，告诉智能体下一步做什么。解探索 POMDP 通常完全不可行，但这个概念给 22.3 的探索问题提供了分析基础。

完全贝叶斯也不能防止不合时宜的死亡。除非先验指出哪些感知意味着危险，否则没有东西阻止智能体采取通向吸收状态的探索动作。曾经有人认为人类婴儿天生怕高、不会爬下悬崖，事实并非如此（Adolph 等，2014）。

**鲁棒控制**：允许一组可能模型 `H`，但不给它们概率。最优**鲁棒策略**是在 `H` 上最坏情形里结果最好的策略：

```
π* = argmax_π  min_h  U^π_h
```

`H` 常常取后验 `P(h|e)` 超过某个似然阈值的模型，因此鲁棒做法与贝叶斯做法有关。

鲁棒控制可以看成智能体与对手的博弈：对手对任何动作挑选最坏结果，得到的策略是该博弈的极小化极大解。逻辑 wumpus 智能体（7.7 节）就是这种鲁棒控制智能体：它考虑所有逻辑上可能的模型，不去探索任何可能有坑或 wumpus 的位置，从而在全部可能假设的最坏情形上找效用最大的动作。

最坏情形假设的问题是行为过度保守。一辆假定其他每辆车都会来撞它的自动驾驶汽车，只能停在车库里。现实生活充满这种风险–收益权衡。

进入 RL 的一个理由是摆脱监督学习那种人类教师，但人类知识可以帮助系统保持安全。一种做法是录下有经验的教师的一串动作，使系统一开始就行为合理，再从那里改进。另一种做法是由人写下系统能做什么的约束，由强化学习系统**之外**的程序强制执行。训练自主直升机时，可以提供一份**部分策略**：直升机进入某个状态、再有不安全动作就会进入无法恢复的状态（安全控制器不能保证避开吸收状态）时，由这份策略接管。其余状态里，学习智能体可以随意行动。

⚠️ **待核**：原文写“三种数学途径”，随后只以“第一种”“第二种”展开贝叶斯强化学习与鲁棒控制，接着转入人类知识（示教记录与外部约束）。正文没有第三条带标题的数学途径。笔记不补写。

### 22.3.3 时序差分 Q 学习

主动 ADP 已经有了。主动 TD 智能体最明显的改动，是它得学一个转移模型，才能用一步前瞻按 `U(s)` 选动作。TD 智能体获取模型的问题与 ADP 相同，TD 更新规则不变。训练序列数目趋于无穷时，TD 收敛到与 ADP 相同的值。

**Q-learning** 改为学习动作效用函数 `Q(s,a)`，从而不需要模型。`Q(s,a)` 是：在 s 采取 a，**此后按最优方式行动**的期望折扣总奖励。知道 Q 函数之后，最优行动就是 `argmax_a Q(s,a)`，不必基于转移模型做前瞻。

`Q(s,a)` 的贝尔曼方程来自式 (17.8)：

```
Q(s,a) = Σ_{s′} P(s′|s,a) [ R(s,a,s′) + γ max_{a′} Q(s′,a′) ]     (22.6)
```

仿照效用的 TD 更新 (22.3)，Q-learning 的 TD 更新是：

```
Q(s,a) ← Q(s,a) + α [ R(s,a,s′) + γ max_{a′} Q(s′,a′) − Q(s,a) ]     (22.7)
```

每当在 s 执行 a 并到达 s′ 时计算。误差项是 `R(s,a,s′)+γ max_{a′} Q(s′,a′)−Q(s,a)`。

这条更新式里没有转移模型 `P(s′|s,a)`。学习阶段和选动作阶段都用不到它。无模型方法因此可以用于非常复杂的领域：不必提供模型，也不必学习模型。另一方面，Q-learning 智能体无法向未来看，奖励稀疏、又必须构造很长动作序列才能到达奖励时，会有困难。

探索性 TD Q-learning 智能体（图 22.8）：

```
function Q-LEARNING-AGENT(percept) returns 动作
  percept 给出 s′ 与 r
  持久：动作价值表 Q（初 0）；状态–动作频率 N_sa（初 0）；上一状态与动作 s,a（初空）
  若 s 非空：
      N_sa[s,a] 加 1
      Q[s,a] ← Q[s,a] + α(N_sa[s,a]) ( r + γ max_{a′} Q[s′,a′] − Q[s,a] )
  s,a ← s′, argmax_{a′} f( Q[s′,a′], N_sa[s′,a′] )
  return a
```

它使用与探索性 ADP **相同**的探索函数 `f`，因此要保留动作计数 `N`。它避免学习转移模型。若探索策略更简单——例如在随时间下降的一定比例步骤上随机行动——就可以不要这些统计量。

更新式里用 `max Q`；选动作时用 `argmax f(Q, N)`。

**SARSA**（state, action, reward, state, action）与 Q-learning 很近。更新与式 (22.7) 类似，但用的是**实际采取**的动作 `a′` 的 Q 值：

```
Q(s,a) ← Q(s,a) + α [ R(s,a,s′) + γ Q(s′,a′) − Q(s,a) ]     (22.8)
```

规则用在每个五元组 `s, a, r, s′, a′` 结束时，名字即由此而来。差别很细：Q-learning 从 s′ 的**最佳**动作回传 Q 值；SARSA 等到动作真的做出，再回传**那个**动作的 Q 值。智能体若总是贪心选取 Q 值最好的动作，两者相同。有探索时它们不同：探索带来负奖励时，SARSA 惩罚该动作，Q-learning 不惩罚。

Q-learning 是**离策略（off-policy）**算法：它学的 Q 值回答的是“假如我停止当前策略，改按（依我的估计）选最佳动作的策略来行动，这个动作在这个状态值多少？” SARSA 是**在策略（on-policy）**算法：它回答的是“假如我坚持当前策略，这个动作在这个状态值多少？” Q-learning 更灵活，能在各种各样的探索策略控制下学会好好行动。若整体策略哪怕部分地由其他智能体或程序控制，SARSA 更合适：学“实际上会发生什么”的 Q 函数，比学“假如由我来挑估计中的最佳动作会怎样”更好。

Q-learning 和 SARSA 都能学到 4×3 的最优策略，但比 ADP 慢得多。原因是局部更新不能借助模型，在全部 Q 值之间强制一致性。

## 22.4 强化学习中的泛化（Generalization in Reinforcement Learning）

到这里，效用函数和 Q 函数都是表：每个状态一个输出。状态数大约到 **10⁶** 还能用，玩具二维网格足够。真实环境状态多得多，收敛会太慢。西洋双陆棋比多数真实应用简单，仍有大约 **10²⁰** 个状态，无法靠走遍来学习。

第 5 章的评价函数，是对可能极大的状态空间的一种紧凑的合意程度度量。用本章的术语，评价函数就是近似效用函数。构造真实效用函数或 Q 函数的紧凑近似，叫**函数近似（function approximation）**。例如用特征 `f₁,…,fₙ` 的加权线性组合：

```
Û_θ(s) = θ₁ f₁(s) + θ₂ f₂(s) + ⋯ + θₙ fₙ(s)
```

算法不必学表里的 10²⁰ 个状态值，而可以学比如说 **20** 个参数 `θ = θ₁,…,θ₂₀`，使 `Û_θ` 成为真实效用的好近似。这个近似效用有时再配上前瞻搜索，以做出更准确的决策。加上前瞻之后，有效行为可以从一个简单得多、用少得多的经验就能学会的效用近似器里产生出来。

函数近似使很大的状态空间上的效用（或 Q）变得可表示；更重要的是，它允许**归纳泛化**：智能体能从访问过的状态推广到还没访问的状态。Tesauro（1992）用此技术做出了人类冠军水平的双陆棋程序，尽管它只探索了完整状态空间的**万亿分之一**。

### 22.4.1 近似直接效用估计

直接效用估计（22.2）在状态空间里生成轨迹，对每个状态抽出从该状态起到终止的奖励之和。状态与这个和构成监督学习的一个训练例子。

用简单线性函数表示 4×3 的效用，方格特征就是它的 x、y 坐标：

```
Û_θ(x, y) = θ₀ + θ₁ x + θ₂ y          (22.9)
```

若 `(θ₀, θ₁, θ₂) = (0.5, 0.2, 0.1)`，则

```
Û_θ(1, 1) = 0.5 + 0.2·1 + 0.1·1 = 0.8
```

有了一批试验，就有一批 `Û_θ(x,y)` 的样本值，可以用标准线性回归（第 19 章）求最小平方误差意义下的最佳拟合。

对 RL，更合理的是**在线**学习：每次试验之后更新参数。设某次试验从 (1,1) 起的总奖励是 **0.4**。这表示当前的 `Û_θ(1,1) = 0.8` 太大，必须减小。与神经网络学习一样，写误差函数再对参数求梯度。若 `uⱼ(s)` 是第 j 次试验中从 s 起观察到的总奖励，误差取预测与实际之差的平方的一半：

```
Eⱼ(s) = ( Û_θ(s) − uⱼ(s) )² / 2
```

沿减小误差的方向移动参数：

```
θᵢ ← θᵢ − α ∂Eⱼ(s)/∂θᵢ
    = θᵢ + α [ uⱼ(s) − Û_θ(s) ]  ∂Û_θ(s)/∂θᵢ          (22.10)
```

这是在线最小二乘的 **Widrow–Hoff 规则**，也称 **delta 规则**。对式 (22.9) 的线性近似器，三条更新是：

```
θ₀ ← θ₀ + α [ uⱼ(s) − Û_θ(s) ]
θ₁ ← θ₁ + α [ uⱼ(s) − Û_θ(s) ] x
θ₂ ← θ₂ + α [ uⱼ(s) − Û_θ(s) ] y
```

代入 `Û_θ(1,1) = 0.8`、`uⱼ(1,1) = 0.4`：差值是 −0.4，且该点 `x = y = 1`，所以 `θ₀、θ₁、θ₂` 都减小 **0.4α**，(1,1) 上的误差下降。

**为一次观察到的转移去改 `θᵢ`，会同时改变所有其他状态上的 `Û_θ`。** 这就是“函数近似使强化学习器能从经验中泛化”的意思。

假设空间不太大、且包含一些与真实效用还算拟合的函数时，用函数近似会学得更快。习题 22.APLM 要求比较有无函数近似的直接效用估计。4×3 上的改进看得出来，但不剧烈，因为状态空间本来就很小。**10×10**、在 **(10,10)** 处奖励 +1 的世界上，改进大得多。

10×10 适合线性效用函数：真实效用光滑、近乎线性，基本上是一条从 (1,1) 到 (10,10) 的对角斜坡（习题 22.TENX）。若把 +1 放在 **(5,5)**，真实效用更像一座金字塔，式 (22.9) 的近似器会严重失败。

线性函数近似要求的是**对特征线性**，特征本身可以是状态变量的任意非线性函数。加上测量到目标距离的特征

```
f₃(x, y) = √( (x − x_g)² + (y − y_g)² )
```

之后，线性近似器就表现良好。

### 22.4.2 近似时序差分学习

同样的想法用于 TD：调整参数，以减小相继状态之间的时序差分。式 (22.3) 与 (22.7) 的新形式是

```
θᵢ ← θᵢ + α [ R(s,a,s′) + γ Û_θ(s′) − Û_θ(s) ]  ∂Û_θ(s)/∂θᵢ          (22.11)
```

以及

```
θᵢ ← θᵢ + α [ R(s,a,s′) + γ max_{a′} Q̂_θ(s′,a′) − Q̂_θ(s,a) ]  ∂Q̂_θ(s,a)/∂θᵢ     (22.12)
```

函数近似器对特征线性时，可以证明被动 TD 的更新收敛到真实函数的**最近可能近似**。效用函数之间的距离定义相当技术性，见 Tsitsiklis 与 Van Roy（1997）。主动学习再加上神经网络这类非线性函数时，几乎没有保证：有一些非常简单的情形，这些更新规则会让参数跑到无穷，尽管假设空间里存在好解。有更精致的算法能避开这些问题，但使用一般函数近似器的强化学习目前仍是一门精细的手艺。

除了参数发散，还有更出人意料的**灾难性遗忘（catastrophic forgetting）**。假设在训练一辆自动驾驶汽车沿（模拟）道路安全行驶、不要冲出路面。冲出路面边缘给高的负奖励，并用道路位置的二次特征，使车学到“路中央的效用高于靠近边缘”。一切顺利，车学会完美地走在路中央。几分钟后你准备停掉模拟、写下优秀结果，车突然拐出路面并坠毁。

原因是它学得太好：既然它学会了驶离边缘，它就学到整个中央区域都是安全的，并**忘掉**靠近边缘的区域是危险的。中央区域的值函数因此是平的，二次特征的权重变成 0；此后线性特征上任何非零权重都会让车滑向某一侧。

一种解决办法叫**经验回放（experience replay）**：让车定期重温年轻时的撞车行为。学习算法保留整个学习过程的轨迹并重放，使值函数对它不再访问的那部分状态空间仍然准确。

对基于模型的 RL，函数近似对学习环境模型也很有帮助。可观测环境下学模型是监督学习：下一个感知给出结果状态。第 19–21 章的监督学习方法都能用，但要调整到预测的是**完整状态描述**，而不只是布尔分类或单个实数。有了学到的模型，智能体可以做前瞻搜索来改进决策，也可以做内部模拟来改进 `U` 或 `Q` 的近似表示，而不必依赖缓慢、可能昂贵的真实世界经验。

部分可观测时，学习困难得多：下一个感知不再是状态预测问题的标签。若已知隐变量是什么、以及它们彼此之间和与可观测变量之间的因果联系，就可以固定动态贝叶斯网络的结构，用 EM 算法学习参数（第 20 章）。学习动态贝叶斯网络的内部结构、并创造出新的状态变量，仍被认为是难题。深度循环神经网络（21.6 节）在某些情形下成功发明了隐藏结构。

### 22.4.3 深度强化学习

需要超出线性近似器，有两个原因，其实是同一个：可能没有任何线性函数能接近效用或 Q 函数；也可能发明不出所需特征，尤其在新领域里。把 `U` 或 `Q` 写成特征的线性组合总是可能的，特别是若有 `f₁(s) = U(s)` 或 `f₂(s,a) = Q(s,a)` 这样的特征；但除非这些特征能以可高效计算的形式写出来，线性近似器就可能不够。

因此，从强化学习的早期起，研究者就探索过更复杂的非线性函数近似器。目前深度神经网络（第 21 章）在这个角色上很流行，即使输入是完全没有人工特征提取的原始图像也有效。顺利的话，深度网络自己发现有用的特征。若网络最后一层是线性的，就可以看出它用哪些特征来搭建自己的线性函数近似器。用深度网络做函数近似器的强化学习系统，叫**深度强化学习**系统。

与式 (22.9) 一样，深度网络是由 `θ` 参数化的函数，只是函数复杂得多。参数是各层的全部权值。式 (22.11)、(22.12) 所需的梯度，与监督学习所需的梯度相同，可以用 21.4 节的反向传播来算。

22.7 节会讲深度 RL 的显著结果：学会以专家水平玩多种电子游戏、在围棋上击败人类世界冠军、训练机器人完成复杂任务。

尽管成功引人注目，深度 RL 仍有明显障碍：往往难以得到好性能；环境只要与训练数据有一点差别，训练好的系统行为就可以非常难以预测。与深度学习的其他应用相比，深度 RL 很少用于商业场景。它仍然是非常活跃的研究领域。

### 22.4.4 奖励整形

如章首所说，真实环境的奖励可以非常稀疏：要做很多原语动作才得到任何非零奖励。踢足球的机器人可能在失球之前，向各关节发出**十万**条电机控制指令。然后它得弄清自己错在哪里。这叫**信用分配问题（credit assignment problem）**。除了踢上万亿场球、让负奖励最终传回该负责的动作，还有没有好办法？

动物训练里常用的一种方法叫**奖励整形（reward shaping）**：给智能体额外的奖励，即**伪奖励（pseudoreward）**，用来表示“有进展”。例如机器人碰到球、或把球向球门推进，都给伪奖励。这种奖励可以极大加快学习，也容易提供，但有风险：智能体可能去最大化伪奖励而不是真奖励。站在球旁边“振动”，就会产生许多次碰球。

第 17 章（p.569）有一种修改奖励函数、同时不改变最优策略的办法。对任意势函数 `Φ(s)` 和任意奖励 `R`，新奖励是

```
R′(s, a, s′) = R(s, a, s′) + γ Φ(s′) − Φ(s)
```

`Φ` 可以反映状态里任何想要的方面，例如子目标是否达成、或到期望终止状态的距离。对踢球机器人，`Φ` 可以在本方控球的状态上加一个常数奖，再为“球离对方球门更近”加另一个奖。整体学习会更快，但不会阻止机器人在危险时把球回传给守门员。

### 22.4.5 分层强化学习

对付很长的动作序列，另一种办法是把它拆成几段，再拆，直到序列短到容易学。这叫**分层强化学习（hierarchical reinforcement learning，HRL）**，与第 11 章的 HTN 规划有很多共同之处。例如足球进球可以拆成：获得控球、传给队友、接球、向球门盘带、射门；每一项还可以再拆成更低层的运动行为。获得控球和射门都有多种方式，可以传给多名队友，因此每个高层动作可以有许多不同的低层实现。

用来说明的简化足球叫 **keepaway**：三名队员的一队尽量长时间控球，靠盘带和互传；另一队两名队员靠拦截传球或铲抢持球者来夺球。脚注说，keepaway 的灵感来自巴塞罗那队真实战术的传闻，多半没有根据。游戏在 RoboCup 2D 模拟器里实现，提供详细的连续状态运动模型，时间步 **100 ms**，已被证明是 RL 的好试验台。

分层强化学习智能体从一个**部分程序（partial program）**开始，它勾勒行为的层次结构。智能体程序的部分编程语言，在普通编程语言上增加表示“未指定选择”的原语，这些选择必须由学习填上。（这里用伪代码。）部分程序可以任意复杂，只要它终止。

普通 RL 是 HRL 的特例。只要给出允许智能体不断从当前状态可执行动作集 `A(s)` 里任选的平凡部分程序：

```
while true do
    choose(A(s))
```

`choose` 允许智能体在指定集合里任选一个元素。学习过程把部分智能体程序变成完整程序：学会每个选择该怎么做。例如可以为每个选择配一个 Q 函数；Q 函数学会之后，程序每次遇到选择就取 Q 值最高的选项。

keepaway 里“持球方”单名队员的部分程序更有意思。顶层做什么，主要取决于自己是否持球：

```
while not IS-TERMINAL(s) do
    if BALL-IN-MY-POSSESSION(s) then choose({PASS, HOLD, DRIBBLE})
    else choose({STAY, MOVE, INTERCEPT-BALL})
```

每个选择调用的子程序还可以再做选择，一直到能直接执行的原语动作。例如高层动作 `PASS` 选择传给哪名队友，也可以选择什么都不做、把控制权交回上层（例如没有人可传）：

```
choose({ PASS-TO(choose(TEAMMATES(s))), return })
```

`PASS-TO` 还要选择传球的速度和方向。对人来说——哪怕足球经验很少——提供这种高层建议很容易；要写出规则、决定踢球的速度和方向以最大化保持控球的概率，则很难，甚至不可能。选哪名队友接球、自己移动到哪里才方便接球，也远非显然。部分程序提供的是一般的 know-how：复杂行为的总体脚手架和结构组织；细节由学习过程填上。

HRL 的理论基础是**联合状态空间（joint state space）**。每个状态 `(s, m)` 由物理状态 `s` 和**机器状态** `m` 组成。机器状态由智能体程序的当前内部状态定义：当前调用栈上每个子程序的程序计数器、参数值、以及全部局部和全局变量的值。例如程序已选择传给队友 Ali，正在计算传球速度，那么“Ali 是 `PASS-TO` 的参数”就是当前机器状态的一部分。**选择状态** `σ = (s, m)` 是指 `m` 的程序计数器正处在智能体程序的一个选择点上。两个选择状态之间可以发生任意多次计算转移和物理动作，但它们可以说都是预先注定的：按定义，中间智能体不做任何选择。

分层 RL 智能体解的是一个马尔可夫决策问题，要素为：

- 状态是联合状态空间的选择状态 `σ`。
- `σ` 上的动作是部分程序在 `σ` 提供的选择 `c`。
- 奖励函数 `ρ(σ, c, σ′)` 是选择状态 `σ` 与 `σ′` 之间全部物理转移的奖励之和的期望。
- 转移模型 `τ(σ, c, σ′)`：若 `c` 调用物理动作 `a`，则 `τ` 借用物理模型 `P(s′|s,a)`；若 `c` 调用计算转移（如调用子程序），则按编程语言规则确定性地修改计算状态 `m`。

解这个决策问题，得到的是与原来的部分程序相一致的最优策略。

脚注：到达下一个选择状态之前可能执行不止一个物理动作，因此技术上这是**半马尔可夫决策过程**，允许动作有不同时长，包括随机时长。若 `γ < 1`，动作时长会影响该动作期间所得奖励的折扣，于是要额外做折扣记账，转移模型还包含时长分布。

分层 RL 对学习复杂行为可以非常有效。在 keepaway 中，基于上面勾勒的部分程序的 HRL 智能体，面对标准抢球策略可以**永远**保持控球；此前的纪录大约是 **10 秒**。一个重要特点是：低层技能不是通常意义上的固定子程序；它们的选择对智能体程序的**整个内部状态**敏感，因此被从程序的不同位置调用、以及当时正在发生什么，都会使它们表现不同。必要时，低层选择的 Q 函数可以用单独的训练过程和自己的奖励函数来初始化，再集成进整体系统，使它们在整个智能体的语境里工作良好。

上一小节看到，整形奖励有助于学习复杂行为。在 HRL 里，学习发生在联合状态空间，给整形提供了额外机会。例如为了帮助学习 `PASS-TO` 内部“准确传球”的 Q 函数，可以提供依赖**预定接球者位置**以及对手与该队员接近程度的整形奖励：球应靠近接球者、远离对手。这看起来完全显然；但预定接球者的身份**不属于世界的物理状态**。物理状态只有球员和球的位置、朝向与速度。物理世界里没有“传球”、也没有“接球者”；它们完全是内部构造。因此没有办法把这种合理建议提供给一个标准 RL 系统。

行为的层次结构还给总体效用函数提供了一种自然的**加性分解（additive decomposition）**。效用是奖励沿时间的和。考虑比如说十个时间步，奖励 `[r₁, r₂, …, r₁₀]`。设前五个时间步智能体在做 `PASS-TO(Ali)`，后五个在做 `MOVE-INTO-SPACE`。则初始状态的效用，等于 `PASS-TO` 期间的总奖励加上 `MOVE-INTO-SPACE` 期间的总奖励。前者只取决于球是否及时、并有足够空间到达 Ali、使 Ali 能保住控球；后者只取决于智能体是否到达一个适合接球的好位置。总体效用分解成若干项，每一项只依赖少数变量。于是学习比“学一个依赖全部变量的单一效用函数”快得多。这与第 13 章里使贝叶斯网络能够简洁的表示定理有些类似。

## 22.5 策略搜索（Policy Search）

本章考虑的最后一种做法叫**策略搜索**：只要策略的性能还在变好，就继续拧它，然后停止。就某种意义说，它是本章最简单的方法。

策略 `π` 把状态映射到动作。我们主要关心**参数化**表示：参数个数远少于状态个数（与上一节相同）。例如用一组参数化的 Q 函数表示 `π`，每个动作一个，并采取预测值最高的动作：

```
π(s) = argmax_a  Q̂_θ(s, a)          (22.13)
```

每个 Q 函数可以是式 (22.9) 那样的线性函数，也可以是深度神经网络之类的非线性函数。策略搜索然后调整 `θ` 来改进策略。

策略若由 Q 函数表示，策略搜索会产生一个学习 Q 函数的过程。带函数近似的 Q-learning 寻找的 `θ`，使 `Q̂_θ` “接近”最优 Q 函数 `Q*`。策略搜索寻找的 `θ`，使性能好。两套结果可以差得很远。例如近似 Q 函数 `Q̂_θ(s,a) = Q*(s,a)/100` 给出最优性能，尽管它一点也不接近 `Q*`。另一个清楚的例子：`π(s)` 用近似效用 `Û_θ` 做比如说深度为 **10** 的前瞻来计算。一个结果很好的 `θ`，可以离“让 `Û_θ` 像真实效用”很远。

式 (22.13) 这类表示还有一个问题：动作离散时，策略是参数的**不连续**函数。存在这样的 `θ`：`θ` 的无穷小变化会让策略从一动作切换到另一动作。策略的价值因此也可能不连续变化，基于梯度的搜索就困难。所以策略搜索常用**随机策略**表示 `π_θ(s,a)`，它指定在 s 选择动作 a 的概率。一种流行表示是 softmax：

```
π_θ(s, a) = exp(β Q̂_θ(s, a)) / Σ_{a′} exp(β Q̂_θ(s, a′))          (22.14)
```

参数 `β > 0` 调节 softmax 的软硬。`β` 相对于 Q 值之间的间隔很大时，softmax 接近硬 max；`β` 接近 0 时，softmax 接近在动作上的均匀随机选择。`β` 的一切有限值上，softmax 对 `θ` 可微；策略价值连续依赖于选动作的概率，因此也是 `θ` 的可微函数。

改进策略的方法，先看最简单的情形：确定性策略、确定性环境。令 `ρ(θ)` 为**策略价值**，即执行 `π_θ` 时的期望此后奖励。若能写出 `ρ(θ)` 的闭式，这就是第 4 章的标准优化问题。`ρ(θ)` 可微时，可以沿**策略梯度** `∇_θ ρ(θ)` 走。若没有闭式，也可以直接执行 `π_θ`、观察累积奖励来评估它，并用爬山沿**经验梯度**走：对每个参数的小增量，评估策略价值的变化。在通常的保留条件下，这个过程收敛到策略空间的局部最优。

环境（或策略）非确定性时，事情更难。爬山要比较 `ρ(θ)` 与 `ρ(θ+Δθ)`。每次试验的总奖励可能波动很大，少量试验得到的策略价值估计很不可靠，比较两个这样的估计更不可靠。一个办法是多跑试验，测量样本方差，用它判断试验是否已经多到能可靠指出 `ρ(θ)` 的改进方向。对许多真实问题这不实际：试验可能昂贵、耗时、甚至危险。

对非确定性策略 `π_θ(s,a)`，可以直接从在 `θ` 处执行的试验结果，得到梯度 `∇_θ ρ(θ)` 的无偏估计。为简单起见，先对**片段式**环境推导：每个动作 `a` 获得奖励 `R(s₀, a, s₀)`，环境在 `s₀` 重新开始。此时策略价值就是奖励的期望值：

```
∇_θ ρ(θ) = ∇_θ Σ_a R(s₀, a, s₀) π_θ(s₀, a)
          = Σ_a R(s₀, a, s₀) ∇_θ π_θ(s₀, a)
```

再做一个技巧，使这个求和能用 `π_θ(s₀, a)` 所定义的分布抽出的样本来近似。设共有 `N` 次试验，第 j 次采取的动作是 `aⱼ`。则

```
∇_θ ρ(θ) = Σ_a π_θ(s₀, a) · R(s₀, a, s₀) · ∇_θ π_θ(s₀, a) / π_θ(s₀, a)
          ≈ (1/N) Σ_{j=1}^{N} R(s₀, aⱼ, s₀) · ∇_θ π_θ(s₀, aⱼ) / π_θ(s₀, aⱼ)
```

策略价值的真实梯度，被近似为若干项之和，每一项涉及该次试验中选动作概率的梯度。序贯情形推广为：对每个被访问的状态 `s`，

```
∇_θ ρ(θ) ≈ (1/N) Σ_{j=1}^{N} uⱼ(s) · ∇_θ π_θ(s, aⱼ) / π_θ(s, aⱼ)
```

其中 `aⱼ` 是第 j 次试验在 s 执行的动作，`uⱼ(s)` 是第 j 次试验中从 s 起收到的总奖励。得到的算法叫 **REINFORCE**，出自 Ron Williams（1992）。它通常比“在每个 `θ` 上用大量试验做爬山”有效得多，但仍然比所需要的慢很多。

考虑如下任务：给定两份二十一点策略，判断哪一份更好。它们每手的真实净收益比如说是 **−0.21%** 与 **+0.06%**，分出高下非常重要。一种做法是让每份策略对标准“庄家”打一定手数，再测量各自的赢额。问题与前面相同：每份策略的赢额随牌好坏剧烈波动。要可靠地看出哪份更好，需要几百万手。用随机抽样比较爬山算法里两份相邻策略时，会出现同一个问题。

二十一点上更好的做法是**事先生成一定数量的手牌，让每个程序打同一组牌**。这样，因拿到的牌不同而产生的测量误差被消掉。只需几千手就能判断两份策略哪份更好。

这个想法叫**相关抽样（correlated sampling）**，可以用于一般的策略搜索，只要环境模拟器里的随机数序列可以重复。它被实现在名为 **PEGASUS** 的策略搜索算法里（Ng 与 Jordan，2000），这是最早实现完全稳定的自主直升机飞行的算法之一（图 22.9(b)）。可以证明：为保证每个策略的价值都被估计好，所需的随机序列条数**只依赖策略空间的复杂度**，完全不依赖底层领域的复杂度。

## 22.6 学徒学习与逆向强化学习（Apprenticeship and Inverse Reinforcement Learning）

有些领域复杂到很难为 RL 定义奖励函数。我们到底要自动驾驶汽车做什么？它不应当太久才到达目的地，但也不应当开得快到承担不当风险或吃超速罚单。它应当省燃料/能源。它不应当把乘客颠得太厉害或加速太猛，但紧急情况下可以急刹车。如此等等。给每个因素多大权重是一件难事。更糟的是，几乎一定有重要因素被忘掉，例如对其他驾驶员的体谅义务。漏掉一个因素，通常导致行为把**极端值**赋给被漏掉的因素——这里就是极度不顾及他人的驾驶——以便最大化其余因素。

一种办法是在模拟里大量测试，注意到有问题的行为，再修改奖励函数来消除它们。另一种办法是寻找关于合适奖励函数的额外信息来源。一个来源就是**已经在优化**（或近乎优化）该奖励函数的智能体的行为——这里是人类专家驾驶员。

**学徒学习（apprenticeship learning）**研究的是：给定专家行为的观察，学习如何表现良好。我们给算法看专家驾驶的例子，并告诉它“照那样做”。至少有两条路。

第一条在章首简短讨论过：若环境可观测，对观察到的状态–动作对做监督学习，学出策略 `π(s)`。这叫**模仿学习（imitation learning）**。它在机器人学里有过一些成功（p.966），但有脆性问题：对训练集的很小偏离会引出随时间增长的误差，最终失败。而且模仿学习至多复制教师的性能，不会超过教师。人类靠模仿学习时，有时用贬义词 “aping” 来形容；学习者并不理解为什么要执行某个动作。

第二条路是去理解**为什么**：观察专家的动作（以及随之而来的状态），设法弄清专家在最大化什么奖励函数，再导出关于该奖励函数的最优策略。预期这条路能从相对少的专家行为例子里产生稳健策略。强化学习这个领域的前提是：奖励函数是任务最简洁、最稳健、最可迁移的定义，策略和价值函数都更冗长。此外，若学习者对专家可能的次优留出适当余地，它就可能通过优化真实奖励函数的准确近似，做得比专家更好。这叫**逆向强化学习（inverse reinforcement learning，IRL）**：通过观察策略来学习奖励，而不是通过观察奖励来学习策略。

给定专家的动作，怎样找专家的奖励函数？先假定专家行动是理性的。那么我们要找的 `R*` 应当使：专家策略下的期望折扣总奖励，高于（或至少等于）任何其他可能策略。

不幸，满足该约束的奖励函数很多。其中一个是 `R*(s,a,s′) = 0`，因为完全没有奖励时任何策略都是理性的。脚注：按式 (17.9)（p.569），`R′(s,a,s′) = R(s,a,s′)+γΦ(s′)−Φ(s)` 与 `R` 有完全相同的最优策略，因此奖励函数只能恢复到“可以加上任意整形函数 `Φ(s)`”的程度。这不算严重：用 `R′` 的机器人与用“正确” `R` 的机器人行为一样。

这条路的另一个问题是：理性专家的假设不现实。例如，机器人看到 Lee Sedol 对 ALPHAGO 走出一手最终被证明是输棋的棋，就不得不假定 Lee Sedol 在试图输掉。

为避开“`R* = 0` 能解释任何观察行为”，用贝叶斯方式思考（20.1 节）。观察数据 `d`，令 `h_R` 为“`R` 是真实奖励函数”这一假设。按贝叶斯规则：

```
P(h_R | d) = α P(d | h_R) P(h_R)
```

若先验 `P(h_R)` 基于简单性，则 `R = 0` 得分相当好，因为 0 确实简单。但似然 `P(d|h_R)` 对 `R = 0` 是无穷小：它解释不了专家为什么在“若该假设为真则全都最优”的巨大行为空间里，偏偏选了那种行为。相反，若 `R` 有唯一最优策略、或最优策略的等价类相对小，`P(d|h_R)` 会高得多。

为允许专家偶尔犯错，只要让 `P(d|h_R)` 在 `d` 来自对 `R` 而言稍微次优的行为时也非零即可。一个典型假设——必须说，更多是为了数学方便，而不是忠实于真实人类数据——是：真实 Q 函数为 `Q(s,a)` 的智能体，并不按确定性策略 `π(s) = argmax_a Q(s,a)` 选择，而按式 (22.14) 的 softmax 随机策略选择。这有时叫**玻尔兹曼理性（Boltzmann rationality）**：统计力学里，玻尔兹曼分布的状态占据概率对其能级呈指数依赖。

文献里有几十种逆向 RL 算法。最简单的一种叫**特征匹配（feature matching）**。它假定奖励可以写成特征的加权线性组合：

```
R_θ(s, a, s′) = Σ_{i=1}^{n} θᵢ fᵢ(s, a, s′) = θ · f
```

驾驶领域的特征可以包括速度、超过限速的速度、加速度、与最近障碍的接近程度，等等。

由式 (17.2)（p.567），从 `s₀` 执行策略 `π` 的效用是

```
U^π(s) = E[ Σ_{t=0}^{∞} γ^t R(S_t, π(S_t), S_{t+1}) ]
```

期望针对由 `s` 与 `π` 决定的状态序列分布。`R` 是特征值的线性组合，因此

```
U^π(s) = E[ Σ_t γ^t Σ_i θᵢ fᵢ(S_t, π(S_t), S_{t+1}) ]
        = Σ_i θᵢ E[ Σ_t γ^t fᵢ(S_t, π(S_t), S_{t+1}) ]
        = Σ_i θᵢ μᵢ(π)
        = θ · μ(π)
```

**特征期望** `μᵢ(π)` 是执行 `π` 时特征 `fᵢ` 的期望折扣值。例如若 `fᵢ` 是车辆的超速（高出限速的部分），则 `μᵢ(π)` 是整条轨迹上（时间折扣的）平均超速。关键一点：若策略 `π` 产生的特征期望 `μᵢ(π)` 与专家策略 `π_E` 的特征期望相匹配，则按**专家自己的奖励函数**，`π` 与专家策略一样好。

我们量不到专家策略特征期望的精确值，但可以用观察到的轨迹上的平均值来近似。于是需要找到参数 `θᵢ`，使这些参数值所诱导的策略的特征期望，与观察轨迹上的专家策略相匹配。下面的算法能以任意期望的误差界做到这一点：

- 选取初始默认策略 `π⁽⁰⁾`。
- 对 `j = 1, 2, …` 直到收敛：
  - 找参数 `θ⁽ʲ⁾`，使得按期望效用 `θ⁽ʲ⁾ · μ(π)`，专家策略最大限度地优于策略 `π⁽⁰⁾, …, π⁽ʲ⁻¹⁾`。
  - 令 `π⁽ʲ⁾` 为奖励函数 `R⁽ʲ⁾ = θ⁽ʲ⁾ · f` 的最优策略。

算法收敛到一份在价值上接近专家的策略，接近程度按专家自己的奖励函数来衡量。它只需要 `O(n log n)` 次迭代和 `O(n log n)` 次专家演示，`n` 是特征个数。

机器人可以用逆向强化学习、通过理解专家的动作，为自己学到一份好策略。此外，机器人可以学习多智能体领域里其他智能体所用的策略，无论对方是对抗的还是合作的。最后，逆向强化学习可以用于科学探究（完全不考虑智能体设计），以便更好地理解人类和其他动物的行为。

逆向 RL 的一个关键假设是：“专家”对单智能体 MDP 里的某个奖励函数行为最优或近乎最优。学习者隔着单向玻璃看专家、而专家并不知道自己被观察时，这个假设合理。专家知道学习者在场时，就不合理。例如机器人在医学院通过观看人类专家学习做外科医生。逆向 RL 算法会假定人类以平常的最优方式做手术，仿佛机器人不在场。实际不会这样：人类外科医生有动机让机器人（像任何其他医学生一样）学得又快又好，因此会大幅改变自己的行为。她可能边做边解释；可能指出要避免的错误，例如切口太深或缝线太紧；可能描述手术中出问题时的应急计划。这些行为在独自做手术时都说不通，逆向 RL 算法无法解释底层奖励函数。这种情形要理解成二人**辅助博弈**，如 18.2.5 节所述。

## 22.7 强化学习的应用（Applications of Reinforcement Learning）

应用包括博弈——转移模型已知，目标是学习效用函数——以及机器人学——模型一开始未知。

### 22.7.1 博弈中的应用

第 1 章描述了 Arthur Samuel 从 **1952** 年开始的西洋跳棋强化学习。几十年后 Gerry Tesauro 在双陆棋上重新拾起这个挑战。

Tesauro 的第一次尝试（1990）是 **NEUROGAMMON**。做法是模仿学习的一个有趣变体。输入是 Tesauro 与自己下的 **400** 盘棋。它不学习策略，而把每步 `(s, a, s′)` 转成一组训练例子，每个例子把 `s′` 标成比从 s 经不同着法到达的某个其他位置 `s″` 更好。网络有分开的两半，一半给 `s′`、一半给 `s″`，并被约束为通过比较两半的输出来判断哪边更好。这样每一半被迫学习一个评价函数 `Û_θ`。NEUROGAMMON 赢得 **1989** 年计算机奥林匹克——第一个赢得计算机博弈锦标赛的学习程序——但从未超过 Tesauro 自己的中等水平。

下一个系统 **TD-GAMMON**（1992）采用 Sutton 当时刚发表的 TD 学习——本质上回到 Samuel 探索过的路，但对怎样做对有了好得多的技术理解。评价函数 `Û_θ` 由一个全连接神经网络表示，单个隐藏层 **80** 个节点。（它也用了一些从 NEUROGAMMON 借来的人工设计输入特征。）**300,000** 盘训练对局之后，它达到与世界前三名人类棋手相当的水平。前十名棋手 Kit Woolsey 说，它的局面判断远好于他自己。

下一个挑战是从原始感知输入学习——更接近真实世界——而不是从离散棋盘表示学习。从 **2012** 年起，DeepMind 的一个团队开发了**深度 Q 网络（deep Q-network，DQN）**，第一个现代深度 RL 系统。DQN 用深度神经网络表示 Q 函数；除此之外它是一个典型的强化学习系统。DQN 分别在 **49** 种不同的 Atari 电子游戏上训练。它学会开模拟赛车、射击外星飞船、用球拍弹球。每种情况下，智能体从原始图像数据学习 Q 函数，奖励信号是游戏分数。总体而言，系统表现大约在人类专家水平，尽管有几款游戏让它遇到麻烦。特别是 *Montezuma’s Revenge* 困难得多，因为它需要延伸的规划策略，而且奖励太稀疏。后续工作产生了探索行为更广泛的深度 RL 系统，能够攻克 *Montezuma’s Revenge* 和其他困难游戏。

DeepMind 的 **ALPHAGO** 也用深度强化学习，在围棋上击败最好的人类棋手（见第 5 章）。Atari 游戏本质上主要是反应式的，没有前瞻的 Q 函数就够用；围棋需要大量前瞻。因此 ALPHAGO 既学习价值函数，也学习一个 Q 函数，用它预测哪些着法值得探索，从而引导搜索。这个 Q 函数实现为卷积神经网络，单凭它就准确到能在完全不搜索的情况下击败大多数业余人类棋手。

### 22.7.2 机器人控制中的应用

著名的**车杆平衡**问题，也称**倒立摆**，设置见图 22.9(a)。问题是施加力使小车向右或向左移动，把杆保持大致竖直（`θ ≈ 90°`），同时把位置 `x` 保持在轨道范围之内。强化学习与控制论里有几千篇论文讨论这个看起来简单的问题。一个困难是状态变量 `x、θ、ẋ、θ̇` 是连续的。动作则被定义成离散的：向左猛推或向右猛推，即所谓 **bang-bang 控制**。

这个问题上最早的学习工作由 Michie 与 Chambers（1968）完成，用的是真实的车和杆，不是模拟。他们的 **BOXES** 算法在 **30** 次试验后能把杆平衡一个小时以上。算法先把四维状态空间离散成盒子——名字即由此而来。然后跑试验直到杆倒下。负强化与最后那个盒子里的最后一个动作相关联，再沿序列往回传播。按观察到的奖励变化自适应地划分状态空间，或使用连续状态的非线性函数近似器（如神经网络），可以得到更好的泛化和更快的学习。如今，平衡**三级倒立摆**（三根杆首尾相接）是一道常见练习——这一技艺远超大多数人类的能力，但用强化学习做得到。

更令人印象深刻的是把强化学习用于无线电遥控直升机飞行（图 22.9(b)）。这项工作一般在大型 MDP 上做策略搜索（Bagnell 与 Schneider，2001；Ng 等，2003），常常结合模仿学习，以及给定人类专家飞行员观察的逆向 RL（Coates 等，2009）。

图 22.9(b) 是一架自主直升机做非常困难的 “nose-in circle” 机动时、六幅叠在一起的延时图像。直升机由 PEGASUS 策略搜索算法得出的策略控制（Ng 等，2003）。模拟器模型通过观察各种控制操作对真实直升机的效果来建立，然后算法在模拟器模型上跑了一夜。针对不同机动开发了多种控制器。所有情形下，性能都远远超过使用遥控的人类专家飞行员。（图像由 Andrew Ng 提供。）

逆向 RL 也被成功地用来解释人类行为，包括：基于 **100,000** 英里 GPS 数据的出租车司机目的地预测与路线选择（Ziebart 等，2008），以及基于数小时视频观察的、复杂环境中行人的详细身体运动（Kitani 等，2012）。在机器人学方面，一次专家演示就足以让四足机器人 LittleDog 学到一个 **25** 个特征的奖励函数，并灵活穿过先前未见的岩石地形（Kolter 等，2008）。RL 与逆向 RL 在机器人学中的更多用法，见 26.7 与 26.8 节。

## 小结

本章考察的问题是：只给感知和偶尔的奖励，智能体如何在未知环境中变得熟练。强化学习是创造智能系统的一种适用范围很广的范式。

1. 智能体的总体设计决定必须学习什么信息。
   - 基于模型的智能体获得（或被装备）环境的转移模型 `P(s′|s,a)`，并学习效用 `U(s)`。
   - 无模型智能体可以学习动作效用 `Q(s,a)`，或策略 `π(s)`。
2. 效用可以用几种不同做法来学。
   - 直接效用估计把某状态观察到的此后奖励总和，当作学习其效用的直接证据。
   - ADP 从观察中学习模型和奖励函数，再用价值迭代或策略迭代得到效用或最优策略。ADP 最优地利用了环境邻域结构加在状态效用上的局部约束。
   - TD 方法调整效用估计，使之与后继状态的估计更加一致。它们可以看成 ADP 的简单近似，学习时不需要转移模型。用学到的模型生成伪经验，则可以得到更快的学习。
3. 动作效用函数（Q 函数）可以用 ADP 或 TD 来学。用 TD 时，Q-learning 在学习和选动作阶段都不需要模型。这简化了学习问题，但可能限制在复杂环境中学习的能力，因为智能体不能模拟可能行动路线的结果。
4. 学习智能体在学习期间负责选择动作时，必须在这些动作的估计价值与“学到有用新信息的潜力”之间权衡。探索问题的精确解不可行，但一些简单启发式做得还不错。探索中的智能体还必须小心，避免过早死亡。
5. 大状态空间里，强化学习算法必须用 `U(s)` 或 `Q(s,a)` 的近似函数表示，才能在状态之间泛化。用深度神经网络做函数近似器的深度强化学习，在困难问题上取得了相当的成功。
6. 奖励整形和分层强化学习有助于学习复杂行为，尤其当奖励稀疏、又需要很长的动作序列才能获得奖励时。
7. 策略搜索方法直接在策略的表示上操作，试图根据观察到的性能来改进它。随机领域里性能的变异是严重问题；对模拟领域，可以事先把随机性固定下来，从而克服它。
8. 当正确的奖励函数难以指定时，通过观察专家行为的学徒学习可以是有效办法。模仿学习把问题写成从专家的状态–动作对监督学习一份策略。逆向强化学习从专家行为推断奖励信息。

强化学习仍然是机器学习研究最活跃的领域之一。它使我们不必手工构造行为，不必为监督学习标注巨大数据集，也不必手写控制策略。机器人学中的应用有望特别有价值；这些应用需要能处理连续、高维、部分可观测的环境的方法，其中成功的行为可能由数千甚至数百万个原语动作组成。

本章给出了多种做法，因为（至少到目前）没有单一的最佳做法。基于模型与无模型之争，核心是智能体函数的最佳表示方式。这是人工智能基础层面的问题。如第 1 章所说，许多 AI 研究的一个关键历史特征，是它（常常未明说）坚持**基于知识的方法**。这等于假定：表示智能体函数的最佳方式，是对智能体所处环境的某些方面建立一种表示。有人认为，只要数据足够，无模型方法在任何领域都能成功。这在理论上也许为真，但宇宙里的数据当然可能不够使它在实践中为真。（例如，不容易想象无模型方法如何使人能够设计并建造比方说 LIGO 引力波探测器。）我们的直觉是：环境越复杂，基于模型的做法的优势越明显。

**书末历史注（压缩）**

奖励与惩罚塑造行为的想法，可能在至少 **15,000** 年前驯化狗时就起了作用。科学理解的早期基础包括 Ivan Pavlov（1904 年诺贝尔奖）和 Edward Thorndike，尤其是 *Animal Intelligence*（1911）。综述见 Hilgard 与 Bower（1975）。

Alan Turing（1948, 1950）提出用强化学习教计算机，并认为它至多是教学过程的一部分。Arthur Samuel 的跳棋程序（1959, 1967）是任何种类的机器学习的第一次成功使用。Samuel 提出了包括时序差分和函数近似在内的大部分现代想法，并试验过类似今日深度 RL 的多层价值函数表示；最后发现手工特征上的简单线性评价函数最好。这可能是因为所用计算机大约比现代张量处理单元弱 **1000 亿**倍。大约同时，自适应控制里的 Widrow 与 Hoff（1960）在 Hebb（1949）的工作上用 delta 规则训练简单网络。强化学习因此汇合了动物心理学、神经科学、运筹学和最优控制。

强化学习与 MDP 的联系首先由 Werbos（1977）建立。Ian Witten（1977）用控制论语言描述了类似 TD 的过程。AI 中的发展主要源自 1980 年代初马萨诸塞大学的工作（Barto 等，1981）。Rich Sutton（1988）给时序差分方法以数学理解。把 TD 与基于模型的模拟经验生成结合起来，是 Sutton 的 **DYNA** 结构（1990）。Q-learning 出自 Chris Watkins 的博士论文（1989）；SARSA 出现在 Rummery 与 Niranjan（1994）的技术报告里。优先扫描由 Moore 与 Atkeson（1993）、Peng 与 Williams（1993）独立提出。

函数近似可追溯到 Samuel（1959）。用神经网络表示价值函数在 1980 年代很常见，并在 Tesauro 的 TD-Gammon（1992, 1995）中突出。深度网络是当前最流行的函数近似器。深度 RL 综述见 Arulkumaran 等（2017）与 François-Lavet 等（2018）。DQN（Mnih 等，2015）用深度网络学 Q 函数；**ALPHAZERO**（Silver 等，2018）既学习供已知模型使用的价值函数，也学习用于引导搜索的元层决策的 Q 函数。Irpan（2018）警告：实际环境只要与训练环境稍有不同，深度 RL 系统就可以表现很差。

加权线性特征组合与神经网络是函数近似的因子化表示。也可以把强化学习用于结构化表示，叫关系强化学习（Tadepalli 等，2004）。

带函数近似的收敛性分析极为技术性。线性近似器上的 TD 结果被逐步加强（Sutton，1988；Dayan，1992；Tsitsiklis 与 Van Roy，1997）；非线性函数则有若干发散例子。Papavassiliou 与 Russell（1999）描述了一种对任何形式的函数近似器都收敛的强化学习，前提是“把假设拟合到数据”这个问题可解。Liu 等（2018）描述梯度 TD 算法族，并给出收敛性与样本复杂度的大量理论分析。

序贯决策的多种探索方法见 Barto 等（1995）。Kearns 与 Singh（1998）、Brafman 与 Tennenholtz（2000）给出探索未知环境、并以状态数的多项式样本复杂度收敛到近优策略的算法。贝叶斯强化学习（Dearden 等，1998, 1999）从另一个角度处理模型不确定性与探索。

模仿学习的基本想法是对专家动作的训练集做监督学习。这在自适应控制里是旧想法，在 AI 中首先因 Sammut 等（1992）在飞行模拟器上的 “Learning to Fly” 而突出。他们把方法称为**行为克隆（behavioral cloning）**。几年后同一研究组报告，该方法比最初报告的脆弱得多（Camacho 与 Michie，1995）：很小的扰动就会使学到的策略偏离期望轨迹，智能体离训练集越来越远，误差复合。（亦见 p.966 的讨论。）学徒学习的工作旨在让做法更稳健，部分地靠纳入关于期望结果的信息，而不只是专家策略。Ng 等（2003）与 Coates 等（2009）展示了学徒学习如何用于学习驾驶真实直升机（图 22.9(b)，p.817）。

逆向强化学习由 Russell（1998）引入，第一批算法由 Ng 与 Russell（2000）发展。（经济学里一个相似问题以“MDP 的结构估计”为题被研究得久得多，Sargent，1978。）本章给出的算法出自 Abbeel 与 Ng（2004）。Baker 等（2009）把理解另一智能体的动作看成逆向规划。Ho 等（2017）表明，智能体从有教导性的行为中学得比从最优行为中更好。Hadfield-Menell 等（2017a）把 IRL 推广成同时包含观察者与演示者的博弈论表述，表明教学行为与学习行为作为该博弈的解出现。

安全强化学习的综合综述见 García 与 Fernández（2015）。Munos 等（2017）描述安全的离策略（例如 Q-learning）探索算法。Hans 等（2008）把安全探索拆成两部分：定义指出哪些状态要避开的安全函数，以及定义在可能进入不安全状态时把智能体领回安全的备份策略。You 等（2017）展示如何在模拟中训练深度强化学习模型来开车，再用迁移学习在真实世界安全驾驶。Thomas 等（2017）给出一种以高概率保证不比当前策略更差的学习方法。Akametalu 等（2014）描述基于可达性的做法：学习过程在一份控制策略的指导下运行，该策略保证智能体永不到达不安全状态。Saunders 等（2018）表明，系统可以用人类干预阻止自己走出安全区域，并随时间学会需要更少的干预。

策略搜索因 Williams（1992）而突出。他发展了 REINFORCE 算法族，全称是 “REward Increment = Nonnegative Factor × Offset Reinforcement × Characteristic Eligibility”。Marbach 与 Tsitsiklis（1998）、Sutton 等（2000）、Baxter 与 Bartlett（2000）加强并推广了策略搜索的收敛结果。Schulman 等（2015b）描述信任域策略优化，一种理论上有根据、实践中也好用、并衍生出许多变体的策略搜索算法。用相关抽样降低蒙特卡洛比较中的方差，出自 Kahn 与 Marshall（1953）；它也是 Hammersley 与 Handscomb（1964）探索的若干方差缩减方法之一。

早期分层强化学习试图用状态抽象构造层次：把状态分组成抽象状态，再在抽象状态空间里做 RL（Dayan 与 Hinton，1993）。抽象状态的转移模型通常是非马尔可夫的，导致标准 RL 算法发散。本章的时间抽象做法发展于 1990 年代末（Parr 与 Russell，1998；Andre 与 Russell，2002；Sutton 等，2000），并由 Marthi 等（2005）扩展到并发行为。Dietterich（2000）引入由子程序层次诱导的 Q 函数加性分解。时间抽象基于更早的 Forestier 与 Varaiya（1978）的结果：大型 MDP 可以分解成两层系统，监督层在低层控制器之间选择，每个控制器完成时把控制权交还监督者。学习抽象层次本身，至少从 Peter Andreae（1985）起就被研究；机器人运动原语的近作见 Frans 等（2018）。keepaway 游戏由 Stone 等（2005）引入；这里给出的 HRL 解出自 Bai 与 Russell（2017）。

神经科学常常启发强化学习，并确认其价值。单细胞记录研究表明，灵长类脑中的多巴胺系统实现着某种类似价值函数学习的东西（Schultz 等，1997）。Dayan 与 Abbott（2001）描述时序差分学习可能的神经实现；相关工作描述其他神经科学与行为实验（Dayan 与 Niv，2008；Niv，2009；Lee 等，2012）。

开源模拟环境加速了这个领域。阿尔伯塔大学的 Arcade Learning Environment（ALE）（Bellemare 等，2013）为 **55** 款经典 Atari 游戏提供了框架：屏幕像素作为感知，另加一个接到游戏至今分数的硬连线。DeepMind 用 ALE 实现 DQN，并在多种游戏上验证系统的一般性（Mnih 等，2015）。ALE 收录 55 款游戏；22.7 节写的是 DQN 分别在 49 款上训练。两个数字各有出处。

DeepMind 随后开源了若干智能体平台，包括 DeepMind Lab（Beattie 等，2016）、AI Safety Gridworlds（Leike 等，2017）、Unity 游戏平台（Juliani 等，2018）和 DM Control Suite（Tassa 等，2018）。暴雪发布了 StarCraft II Learning Environment（SC2LE），DeepMind 为其加上 Python 机器学习组件 PySC2（Vinyals 等，2017a）。Facebook 的 AI Habitat（Savva 等，2019）为室内机器人任务提供照片级虚拟环境；HORIZON（Gauci 等，2018）使大规模生产系统中的强化学习成为可能。SYNTHIA（Ros 等，2016）是为改进自动驾驶汽车的计算机视觉而设计的模拟环境。OpenAI Gym（Brockman 等，2016）提供若干强化学习环境，并与其他模拟（如 Google Football）兼容。

面向一般科学读者的综述见 Littman（2015）。Sutton 与 Barto（2018）是该领域两位先驱的权威教材，展示强化学习如何把学习、规划与行动织在一起。Kochenderfer（2015）数学稍少，真实世界例子很多。Szepesvári（2010）的短书概述了算法。Bertsekas 与 Tsitsiklis（1996）给动态规划与随机收敛以严格基础。论文经常发表于 *Machine Learning*、*Journal of Machine Learning Research*，以及 ICML 与 NeurIPS 的会议录。
