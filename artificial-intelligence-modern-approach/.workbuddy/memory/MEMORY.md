## 项目约定（硬性）

1. **信 > 达 > 雅**。不得为文句通顺牺牲数值/逻辑精确性。
2. **区分「原著内容」与「作者发挥」**，后者一律加 `【延伸·非原著】`。
3. **术语以 `AIMA-术语对照表.md` 为准**，不得自造译法；新词按 skill §3 四步流程处理并回填术语表。
7. **发现错误必须回填 `log.md`**（一条一坑、必填书页码出处），提炼后再同步进项目配置 §5 与术语表。
   - **三层分离**：通用方法论 → `book-translation` skill；本书专属（页码/专名/陷阱实例/信源）→ `AIMA-翻译项目配置.md`；对照数据（术语/标题）→ `AIMA-术语对照表.md`。新增内容先判断属于哪一层再决定放哪。
4. 章节/小节编号以**官方 TOC**（aima.cs.berkeley.edu/contents.html）为准，不得跳号。
5. 笔记统一四段式：`0. 本章要解决的问题 → 分节 → 小结 → 附：核心术语中英对照 → 延伸阅读`。
6. 数值示例必须带**完整推导**，不得只写结论。

## 已确立的术语红线（踩过的坑）

- 无条件独立（🚫 绝对/绝对值独立）
- 单连接 / 多树 polytree（🚫 单连通）
- 数量陈述 number statement（🚫 编号变量）
- 最可能序列（🚫 最可能解释 MAP，用于 14.2.3）
- 开宇宙 open-universe（🚫 开放世界）
- 核 core（博弈论；🚫 核心）
- 两两独立 ≠ 相互独立
- 4e 章节：Ch5 对抗搜索和博弈 / Ch6 CSP / Ch12 不确定性的量化 / Ch13 概率推理 / Ch26 机器人学
- 4e 第 4 章章名是 **Search in Complex Environments（复杂环境中的搜索）**，3e 的 "Beyond Classical Search" 已废
- 平滑空间 O(t)（非 O(1)）；POMDP = PSPACE-hard（非 PSPACE-完全）
- VPI 性质是**链式分解** `VPI(E₁,E₂)=VPI(E₁)+VPI(E₂|E₁)`，不是"顺序无关"
- Tiger 问题是文献示例，**原书 17.4 算例是 two-state world**

## 技术备忘

- PDF 页码：索引页 → 书页码偏移 **−12**。页码索引见 `AIMA-翻译项目配置.md` §2（Ch1–18 全表，前 6 章为推定值 ±2 页容差）。
- 提取用 `pypdf`（venv `~/.workbuddy/binaries/python/envs/default`），需装 `fonttools`，用 `2>/dev/null` 屏蔽警告。
- 归一化后下标会被拆开（`P1, 3`），查数字需放宽匹配。
- WebFetch 抓 aima.cs.berkeley.edu 返回空，必须 `curl` + 本地正则。
- 微信读书 API（bookId 3300048020）**无正文接口**，只能拿划线原文做译名抽样校验。
