# 第 16 章 做简单决策（Making Simple Decisions）

> 来源：《人工智能：现代方法（第 4 版）》第四部分「不确定知识和不确定推理」
> 作者：Stuart Russell、Peter Norvig ｜ 中文版：人民邮电出版社
> 说明：本文为按原书章节结构整理的**学习笔记**（非逐字原文）。

## 0. 本章要解决的问题

第 12–15 章只解决"**世界是怎样的**"（概率）。本章加入"**我想要什么**"（效用），构成完整的**决策论**：

```
决策论 = 概率论 + 效用论
理性智能体 ⟺ 最大化期望效用（MEU, Maximum Expected Utility）
```

本章处理**一次性（one-shot）决策**：一个决策节点、一个效用节点。

---

## 16.1 在不确定性下结合信念与愿望

### 基本框架

- **结果（outcome）**：动作在不同世界状态下产生的结果
- **效用 U(s)**：对结果的主观价值
- **期望效用**：

```
EU(a | e) = Σ_{s'} P(RESULT(a) = s' | a, e) · U(s')
```

- **理性选择**：`a* = argmax_a EU(a | e)`

### 三种典型情形

| 情形 | 描述 | 输出 |
|---|---|---|
| **完全可观测** | 证据 e 确定当前状态 | 选择最优单一动作 |
| **无观测** | 没有任何信息 | 选择使期望效用最大的动作 |
| **部分可观测** | 需要根据感知结果的不同分支行动 | **条件计划（contingent plan）**："若看到 X 则做 A，否则做 B" |

### 经典例子：赶飞机（airport problem）

- 动作：`Go`（提前出发/正常出发）
- 结果依"是否误机"而定，误机的效用极低
- 若预留时间充足 → 天气信息价值为 0，"出发时间"取决于代价/收益权衡
- 通过**效用表**可列出每种（动作, 状态）组合的效用，再按概率加权

> 关键洞见：**同样的概率，不同的效用函数会导致不同的理性行为**——概率本身不足以决定行动。

## 16.2 效用理论基础

### 偏好与公理

设 `A ≻ B` 表示"严格偏好 A 于 B"，`A ~ B` 表示"无差异"。

**理性偏好应满足的公理**：

| 公理 | 含义 |
|---|---|
| **有序性（orderability）** | 任意两选项可比：`A ≻ B`、`B ≻ A` 或 `A ~ B` 之一 |
| **传递性（transitivity）** | 若 `A ≻ B` 且 `B ≻ C`，则 `A ≻ C` |
| **连续性（continuity）** | 若 `A ≻ B ≻ C`，则存在概率 p 使 `[p, A; 1−p, C] ~ B` |
| **可替代性（substitutability）** | 若 `A ~ B`，则在任何彩票中用 A 替 B 结果不变 |
| **单调性（monotonicity）** | `A ≻ B` 时，`[p, A; 1−p, B]` 随 p 增大而更优 |
| **可分解性（decomposability）** | 复合彩票可化简为简单彩票 |

### 效用原理（Utility Principle）

> **若一个智能体的偏好满足上述公理，则存在实值函数 U 使得该智能体的行为等同于最大化期望效用。**

```
U(A) > U(B) ⟺ A ≻ B
U([p₁,S₁; …; pₙ,Sₙ]) = Σ pᵢ U(Sᵢ)
```

**唯一性**：U 只在**正仿射变换**下唯一：`U'(s) = a·U(s) + b`，其中 `a > 0`。→ 效用是**序数**度量，不是绝对量。

### 为什么不用"最大化目标达成概率"

因为那等价于假设**风险中性**，无法表达风险厌恶/偏好。效用函数正是用来刻画**风险态度**的。

## 16.3 效用函数

### 金钱与效用

当结果是货币金额时，`U(money)` 通常**非线性**：

| 曲线形状 | 名称 | 行为 |
|---|---|---|
| **凹（concave）** | 风险厌恶（risk-averse） | 愿意付保费换取确定性 → **买保险** |
| **凸（convex）** | 风险偏好（risk-seeking） | 愿意为更大的收益承担风险 → **买彩票** |
| **S 形** | 混合 | 小额风险厌恶、大额风险偏好（前景理论） |

**关键概念**：

- **边际效用递减**：金钱越多，额外一元带来的效用越小
- **确定性等值（certainty equivalent）**：与该彩票期望效用相等的确定金额
- **保费**：期望值 − 确定性等值

### 人类偏好并非完全理性

- **阿莱悖论（Allais paradox）**、**埃尔斯伯格悖论（Ellsberg paradox）**：违反期望效用公理
- **前景理论（Prospect Theory，Kahneman & Tversky）**：
  - 人相对于**参照点**评估收益与损失，而非绝对财富
  - **损失厌恶**：同样金额的损失比收益更"重"（约 2 倍）
  - 结论：理论模型的边界；实践中需注意人类决策偏差

### 效用评估方法

- **标准彩票法**：把结果 `S` 与"最好结果 / 最差结果"的彩票比较，调节概率直到无差异，读出 U(S)
- 彩票法给出的是**任意尺度的效用**，可做正仿射变换

## 16.4 多属性效用函数

### 问题

真实结果往往是**多属性**的：如选择机场航班涉及
`价格（Cost）`、`总耗时（TotalTime）`、`舒适度（Comfort）`、`安全性（Safety）`。

### 偏好独立性

| 概念 | 条件 | 结果 |
|---|---|---|
| **偏好独立（preferential independence）** | 任意两个属性之间的偏好不依赖其他属性的取值 | 效用可写成**加法形式** `U(x₁, …, xₙ) = Σ Uᵢ(xᵢ)` |
| **相互偏好独立（mutual preferential independence）** | 所有属性两两偏好独立 | 乘法形式 `U = Π Uᵢ` 或加法形式 |
| **效用独立（utility independence）** | 风险态度不依赖其他属性 | 允许乘法式效用 |

### 实用技巧

- 若其中一个是**金钱**（如价格），常用"金钱-效用曲线"把货币折算成效用，其余属性线性加权
- **无差异曲线（indifference curve）**：效用相同的属性取值组合；多属性权衡的几何表示
- 该方法可叠加到决策网络上（见 16.5）

> 意义：多属性效用把"主观权衡"分解成若干个一维效用函数 + 聚合规则，使复杂偏好可被建模与推理。

## 16.5 决策网络

**决策网络（decision network / 影响图，influence diagram）** = 贝叶斯网络 + 两类新节点：

| 节点类型 | 形状 | 含义 |
|---|---|---|
| 随机变量 | 椭圆 | 与贝叶斯网络相同 |
| **决策节点（decision node）** | 矩形 | 智能体可选择的动作 |
| **效用节点（utility node）** | 菱形 | 该结果的效用（可有多个，按加法组合） |

**结构要求**：决策节点的父节点 = 在决策时已知的信息（no-forgetting 假设：后决策知道先决策的信息）。

**求解方法**：

1. 按拓扑顺序，**从后往前**处理决策节点
2. 对每个决策节点，在其父节点给定取值下，选择使**期望效用最大**的动作
3. 得到一组条件化的最优决策 → **策略提取（policy extraction）**

**例子**：机场决策网络——随机节点（是否误机、天气等）+ 决策节点（出发时间）+ 效用节点。

> 决策网络把"概率推理"与"决策优化"统一在同一张图里，是更复杂决策问题（MDP/POMDP）的静态版本。

## 16.6 信息价值

**问题**：在行动之前花代价去获取信息，值得吗？

**完美信息价值（Value of Perfect Information, VPI）**：

```
VPI_E(e) = ( Σ_e' P(e' | e) · EU(α_{e'} | e, e') )  −  EU(α | e)

其中 α  = 当前证据 e 下的最优动作
     α_{e'} = 获得新证据 e' 后的最优动作
```

**三条重要性质**：

| 性质 | 陈述 | 直觉 |
|---|---|---|
| **非负** | `VPI_E(e) ≥ 0` | 信息不会让你更差（最多忽略它） |
| **非可加（次可加）** | `VPI(E₁, E₂) ≤ VPI(E₁) + VPI(E₂)` | 两条信息有重叠，价值不能直接相加 |
| **顺序无关** | `VPI(E₁, E₂) = VPI(E₂, E₁)` | 最终获得的信息集合相同则价值相同 |

**决策规则**：只有当**信息获取的代价 < VPI** 时才值得去获取。

**例子**：赶飞机场景中，若出发时间已预留很久，则"看天气预报"的信息价值为 0（无论天气如何都走同一时间）——**信息只有在"能改变行动"时才有价值**。

## 16.7 未知偏好

### 问题

效用函数是**主观**的，智能体往往**不知道用户（或自己）的真实偏好**。

**场景**：买车、选航班、网上购物——选项是多属性的，用户的偏好未明说。

### 偏好启发（Preference Elicitation）

- 让用户**比较两个选项**，从答案中逐步排除不可能的效用函数
- 维护"**与已获得答案一致的效用函数集合**"（偏好空间）

### 核心洞见：问什么问题最有效

| 两个选项的关系 | 比较后能排除的偏好空间 |
|---|---|
| **非常相似**（仅一个属性有差异） | **非常多**——直接定了该属性的方向 |
| 差异很大（多属性都不同） | 很少——只能排除一小部分 |

> **结论**：应当优先询问**在少数属性上有差异的相似选项**，这样才能以最少的提问快速收敛到用户的真实偏好。

**实际意义**：

- 推荐系统与对话式助手应设计"**最有区分度的对比问题**"
- 这直接对应现代 LLM 偏好对齐（RLHF）中"成对比较"（pairwise comparison）的设计逻辑

## 小结

1. 决策论 = 概率论 + 效用论；理性 = **最大化期望效用**。
2. 偏好必须满足一组公理（有序性、传递性、连续性、可替代性、单调性、可分解性），才能用实值效用表示。
3. 效用函数刻画**风险态度**：凹=风险厌恶、凸=风险偏好、S 形=前景理论。
4. **多属性效用**用偏好独立性把复杂偏好分解为若干一维效用 + 聚合规则。
5. **决策网络**把随机变量、决策节点、效用节点统一到一张图上，按拓扑顺序反向求解并提取策略。
6. **信息的价值（VPI）**非负、次可加、顺序无关；只有能改变行动的信息才有价值。
7. 偏好未知时需**偏好启发**；对比"相似选项"能以最少的提问最大程度地缩小偏好空间。
