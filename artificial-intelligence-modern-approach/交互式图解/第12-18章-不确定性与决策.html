全联合分布：一张表能回答一切，代价是 2ⁿ 个数

牙科诊断只有三个布尔变量 —— Toothache（牙疼）、Cavity（有洞）、Catch（探针挂住）。 把它们的完全联合分布整张写下来（2³ = 8 行），任何概率问题都能靠求和消元 + 归一化回答。

顺序不能反：要算 P(Cavity | Toothache)，必须先把无关变量 Catch 求和掉，得到 ⟨0.12, 0.08⟩，再归一化 → ⟨0.6, 0.4⟩。 如果先按某一列归一化（比如直接拿 ⟨0.108, 0.012⟩ 归一），你得到的其实是 P(Catch | Cavity ∧ Toothache) —— 一个完全不同的量。
为什么不能一直用下去：n 个布尔变量的完全联合分布有 2ⁿ − 1 个自由参数。 30 个变量就是十亿量级，而且每个数都得有人（或数据）给出来。第 13 章的贝叶斯网络就是来拆这张表的。

贝叶斯法则：0.002% 的先验，怎样被一个症状撬到 0.14%

脑膜炎（meningitis）很罕见，但脖子僵硬（stiff neck）是它的症状。 真正反直觉的是：即便后验概率涨了整整 70 倍，它依然小于 0.2% —— 罕见病的先验太强了。

为什么医生不会一看到脖子僵硬就下诊断： P(m|s) = P(s|m)·P(m) / P(s) 里的分母 P(s) 是所有原因导致的脖子僵硬， 而它绝大多数来自别的原因。忽略分母（"这个症状在脑膜炎里很常见，所以多半是脑膜炎"）就是典型的基础比率谬误。
调一调就知道哪个参数最要命：把 P(s) 从 0.01 调到 0.001（更精确的"脖子僵硬"定义）， 后验立刻翻 10 倍；把似然 P(s|m) 从 0.7 调到 1.0，后验只涨 43%。 改善证据的特异性，通常比提高灵敏度更值钱。

独立性：把指数级压回线性级的唯一杠杆

概率表的膨胀来自变量之间的耦合。一旦某些变量独立，联合分布就能拆成几个小表的乘积 —— 这是第 13 章贝叶斯网络能成立的全部前提。

两两独立 ≠ 相互独立（真算出来的反例）

反例怎么造的：扔两枚公平硬币 A、B，令 C = A ⊕ B（异或）。 于是 A、B、C 三者的任意两个都独立：知道 A 完全不影响你对 B 的判断，也不影响对 C 的判断。 但三个放一起就露馅了 —— P(A,B,C) 在 4 个世界上是 1/4，在另外 4 个世界上是 0， 而相互独立要求它处处等于 1/8。
条件独立才是真正常用的那个：牙疼和探针挂住并不独立（知道有洞，两者就一起涨）， 但它们给定 Cavity 后条件独立。贝叶斯网络要的就是这个：不是"没关系"，而是"给定父节点后没关系"。

精确推断：枚举 vs 变量消元，算的是同一个数

同一个查询 P(B | j, m)，两种算法会得到完全相同的答案 —— 区别只在做了多少次乘法。变量消元把"对每个世界重复算一遍"改成"把中间结果存成因子反复用"。

为什么消元顺序很要命：消元顺序直接决定中间因子有多大 —— 这里先消 A 要 22 次乘法，先消 E 要 18 次，两个顺序算出的答案完全一样，代价却不同。 差别在这个小网络上还看不太出来，但乘法次数是因子大小的指数，大网络上能差几个数量级。 找最优消元顺序本身是 NP-难问题，实践中用最小度 / 最小填充启发式。

三类结构，规则完全不同： 链 A→B→C 与 分叉 A←B→C：中间节点未观测时通路、观测时被堵住； 对撞 A→B←C：正好反过来 —— 未观测时堵住，一旦观测了 B（或 B 的后代）就打通。

平滑与 Viterbi：同一个序列，三种不同的问题

同样的观测，问法不同答案就不同。滤波问"现在怎么样"， 平滑问"当时到底怎么样"（可以用后来的证据），Viterbi问"哪一种状态序列最可能"。 这三个数经常不一样 —— 尤其平滑和滤波。

教材那个数：T = 2、两天都带伞时，P(R₁ | u₁) = 0.818， 但用上第 2 天的证据做平滑后变成 P(R₁ | u₁, u₂) = 0.883 —— 和"第 2 天的滤波值"恰好相同，这不是巧合：在只有两个状态的链里， 平滑第 1 天 = 滤波第 1 天 × 后向消息，而这里的后向消息正好把 0.818 抬到了 0.883。
Viterbi 和"逐点取最大"不是一回事：Viterbi 求的是 整条路径的最大概率（用 max 代替求和，并要回溯），它可能给出一条"某单点概率并不是最大"的路径。 序列概率 P(路径) 与逐点概率 P(Rₜ) 是两个不同的量。

更新一定会让方差变小： σ′² = σ²_z·σ²_pred / (σ²_z + σ²_pred) < σ²_pred —— 看到任何观测都只会让你更确定， 永远不会更不确定。真正让方差变大的只有预测那一步（加上 σ²ₓ）。
方差会收敛到一个稳态值（解析解 (−σ²ₓ + √(σₓ⁴ + 4σ_z²σₓ²)) / 2）： 每步预测加的 σ²ₓ 和每步更新削掉的量刚好抵消。σₓ = σ_z = 1 时稳态是 (√5 − 1)/2 ≈ 0.618。卡尔曼增益也随之收敛 —— 一旦收敛，滤波器就退化成一个固定系数的指数平滑。

概率程序：可能世界不是赋值表，是执行轨迹

写一段带随机选择的程序，每运行一次就产生一个可能世界； 程序的每一步随机选择贡献一个因子，世界概率就是它们的乘积。 observe（条件）把不满足的轨迹概率清零，剩下的重新归一化 —— 这就是贝叶斯法则。

程序里有 N 枚独立硬币，每枚的真实值通过一个有 20% 噪声的读数观测， 而你恰好读到 N 个读数全是 1。这个证据的概率正好是 2⁻ᴺ —— 于是拒绝采样的接受率随 N 指数衰减。下面三个数都是真跑出来的，而且后验有解析解可以对照。

解析解怎么来的（可以自己验）：各枚硬币互相独立，所以只需看一枚。 P(x = 1 | 读数 = 1) = 0.5×0.8 / (0.5×0.8 + 0.5×0.2) = 0.8 —— 与 N 完全无关。于是"证据有多稀有"（2⁻ᴺ）和"后验有多确定"（0.8）是两件独立的事， 而拒绝采样偏偏是被前者卡死的。
三种方法各自的死法： 拒绝采样死于接受率（稀有证据 ⇒ 样本全被扔掉）； 似然加权死于权重方差（绝大多数样本权重极小，等于白抽）； MCMC不死于稀有性，它死在别处 —— 相邻状态高度相关，样本不独立。

Metropolis–Hastings：用一条马尔可夫链代替独立采样

MCMC 从不独立地生成世界，它只是沿着一条链慢慢走：提议一个新世界， 按概率比决定接不接受。走久了，链上出现的频率就收敛到后验。 唯一的旋钮是提议分布有多大胆 —— 太小走不动，太大老被拒。

合作能够维持的条件—
教材那组数：确定要打 100 轮时，逆向归纳给出每轮都背叛， 两人各判 500 年（100 × 5）。这不是"人不理性"，而是 "最后一轮一定背叛"这个结论把整个未来都吃掉了。 把"继续的概率"调高（比如 0.99），终点变得不确定，合作就有了立足之地。
循环赛的冠军是 TIT-FOR-TAT（与冷酷触发并列）：它善良（第一轮合作）、 可报复（你背叛我就背叛一次）、宽容（你回头我就回头）、清晰（对手能看懂）。 冷酷触发在无失误的世界里和它打平，可一旦出现误判（比如手抖、信号出错），冷酷触发会永久互相毁灭， 而 TIT-FOR-TAT 下一轮就能修复 —— 这就是"宽容"的价钱。 纯粹的 ALWAYS-DEFECT 反而垫底区间：它只在"永远合作"身上占到便宜， 遇到会报复的策略就被反制，总分比"永远合作"还低。

拍卖与机制设计：让"说真话"变成最优策略

机制设计是反过来的博弈论：不改参与者，改规则， 让每个自私的人在规则下"说实话"恰好对自己最有利。

二价拍卖为什么能诱导真话：你付的是第二高的出价， 也就是一个与你自己出价无关的数。所以把出价抬高只会让你更容易赢（好事，因为你赢说明 v > 第二价）， 把出价压低只会让你更容易输（坏事）。如实出价因此是占优策略 —— 上表就是扫描所有出价算出来的。
VCG 的精髓是"你给别人造成了多少损失就付多少"： 买家 1 的税 = [没有他时其他人的最优总价值] − [有他时其他人的实际总价值]。 单物品情形退化成二价拍卖（他付第二高价）；多物品时它保证社会最优且说实话是占优， 代价是机制复杂、容易被人合谋攻击。

12全联合分布把整个世界列成 2ⁿ 行，任何查询都靠「求和 + 归一化」完成。表随变量指数爆炸，只适合极小的问题；现实里必须换成贝叶斯网络。
12贝叶斯法则P(Y|X) = α·P(X|Y)·P(Y)，把「因果方向」的知识反过来用于诊断。忘记归一化 α；把 P(症状|病) 直接当成 P(病|症状)（忽略基础概率）。
12独立性与条件独立独立让联合分布从 2ⁿ 个参数降成 n 个边缘分布。两两独立 ≠ 相互独立，XOR 就是现成的反例。
12wumpus 前沿推断枚举所有与观测相容的世界，按各自的先验加权求和。忘记对未观测变量求和；把「没观测到」当成「概率为 0」。
13贝叶斯网络每个节点只存「给定父节点的条件概率」，把 2ⁿ 压成 Σ2^k。图的结构本身就是独立性断言，画错一条边 = 断言一个假的独立。
13枚举 vs 变量消元枚举按变量逐个展开；VE 把重复的子表达式因式分解掉。消元顺序决定计算量：先消掉"度小"的变量能省一半以上的乘法。
13拒绝 / 似然加权 / Gibbs拒绝丢弃不相容样本，似然加权给样本配权重，Gibbs 沿条件分布游走。证据越稀有，拒绝采样越接近永远采不到；似然加权的权重会退化。
13noisy-OR每个父节点独立地「以 qᵢ 触发」，于是 P(¬x|父) = Π(1 − qᵢ)。它假设各机制相互独立；多个弱因叠加会莫名地逼近 1。
13d-分离看图上的链 / 分叉 / 对撞三种模式判断条件独立性。对撞节点（A→C←B）本身阻断，但一旦条件化它或它的后代，反而变相关。
14HMM 滤波递归两步：预测（乘转移矩阵）→ 更新（乘传感器模型）→ 归一化。依赖一阶马尔可夫假设；传感器模型必须显式写进"看错的概率"。
14平滑与 Viterbi平滑问「某时刻是什么状态」（用前后全部证据），Viterbi 问「最可能的整条路径」。逐个时刻取最大的平滑序列根本不是一条合法路径，和 Viterbi 答案是两回事。
14卡尔曼滤波线性高斯下，滤波就是高斯的均值/方差两步更新，增益会收敛到与观测无关的常数。必须线性 + 高斯；重尾噪声 / 离群点会把估计拖飞（此时用粒子滤波）。
14粒子滤波用一堆带权粒子近似任意后验：预测 → 按似然加权 → 重采样。粒子不够会退化（权重全压到一个粒子上）；重采样太频繁会丢多样性。
15概率程序把生成模型写成普通程序，observe 把证据"塞进"执行路径并重新加权。程序里的分支数量直接决定推断难度；证据落在极稀有分支上就采不到。
15稀有证据证据概率随变量数指数变小（2⁻ᴺ），但后验可以是常数（如 0.8）。拿"证据概率"判断采样器好坏会被骗：它趋近 0 不代表后验收敛不了。
15MCMC（Metropolis–Hastings）构造一条平稳分布 = 后验的马尔可夫链，用接受率 α 修正提议分布。必须丢掉 burn-in；样本高度自相关，不能当独立样本直接算方差。
15关系模型与开放宇宙一阶概率模型用少量参数描述无限世界，存在与身份都是随机变量。世界数量组合爆炸（C=B=10 时 ≈10^86.9）；数据关联不确定时似然很难算。
16效用与风险态度效用是序数的：正仿射变换不改变决策；风险态度由效用函数的曲率决定。比的是效用不是金额；阿莱悖论说明人并不总遵守期望效用公理。
16决策网络决策节点 + 机会节点 + 效用节点，MEU = 当前证据下的最大期望效用。求值必须自底向上：先对机会节点取期望，再对决策节点取 max，顺序错了答案就错。
16信息的价值（VPI）VPI = 拿到信息后的 MEU − 现在的 MEU，恒 ≥ 0（信息不会有害）。VPI 依赖当前证据，不是常数；多份信息的价值边际递减。
16顺从人类偏好不确定时，把"去问人类"本身变成一个带代价的动作，再比 MEU。顺从 ≠ 盲从：人类偏好的不一致与被打断的代价都要建模，否则机器会一直问。
16多属性效用互效用独立 → U = Σ kᵢ·uᵢ(xᵢ)；先用支配检查淘汰不用问权重的方案。没有支配关系时，"选哪个"完全由权重决定；属性变成分布时要用随机支配，否则排序取决于风险态度。
17序贯决策（MDP）U(s) = R(s) + γ·maxa Σ P(s′|s,a)·U(s′)；值迭代反复代入，策略迭代先精确评估再改进。γ→1 时值迭代收敛极慢（误差收缩因子就是 γ）；策略评估要解线性方程组（O(n³)），但迭代次数少得多。
17折扣与有效视界γ 折现未来；H = ⌈log(Rmax/(ε(1−γ))) / log(1/γ)⌉ 步之后可以忽略。γ→1 时 H 暴涨（γ=0.99 → 688 步）；平均奖励准则不能简单套用折扣公式。
17POMDP把状态换成信念分布 b，V(b) 分段线性且凸（PWLC），于是值迭代可收敛。信念是连续的；策略树随深度指数爆炸（深度 d 时 2^((2^d−1)) 个叶子）。
17Gittins 指数每个老虎机臂有一个"价签" G，每次拉指数最大者就是折扣收益下的最优。只对折扣 + 各臂独立成立；换成平均奖励、带预算或带约束就不成立了。
17Gittins vs 贪心Gittins 肯付眼前的空档换未来的大收益；贪心只盯即时收益。ε-greedy 的探索是随机的，长期会在已知很差的臂上浪费大量步数。
18囚徒困境占优策略把双方一起推进 (−5,−5)；均衡不等于好结果。"纳什均衡"不是"最优"，它只保证没人想单方面改主意。
18合作博弈（Shapley / 核心）φᵢ = 对所有加入顺序的平均边际贡献；核心 = 没有子联盟想退出的分配。Shapley 值总存在且唯一，核心可以是空的；Shapley 值还可能落在核心之外 —— 公平不等于稳定。席位也不等于权力。
18零和与 minimaxV = max_p min_q；没有鞍点时必须随机化，把对手的期望锁死。零和意味着对手收益 = −你的收益；现实博弈几乎都不是零和。
18重复博弈确定终点 → 逆向归纳 → 每轮背叛；终点不确定且 γ ≥ (T−R)/(T−P) 时合作可维持。"以后还得见面"必须真的不确定，否则最后一轮的逻辑会一路反推到第一轮。
18拍卖与 VCG税 = 你给别人造成的损失；单物品时正好退化成"付第二高价"。VCG 保证社会最优 + 说真话占优，但不保证预算平衡，且怕合谋。
18投票与孔多塞悖论多数决没有传递性；规则一换赢家就换（Arrow 不可能定理）。个体理性不会自动聚合成群体理性；三种合理的规则给出三个不同的赢家。
贯穿全卷的三条线： ① 表示：从 2ⁿ 的全联合表 → 贝叶斯网络 → 时序模型 → 一阶/开放宇宙模型，每一步都在用结构换参数； ② 推断：精确（枚举 / 变量消元 / 卡尔曼）与近似（采样 / 粒子 / MCMC / 概率程序）的分工 —— 稀有证据和开放宇宙是近似的地盘； ③ 决策：从"知道概率后怎么选"（MEU、VPI）到"概率本身也不确定"（POMDP、Gittins），再到"对面还有一个会思考的 agent"（博弈、机制设计、投票）。 数字全部由本页实时算出，没有一个是写死的。
