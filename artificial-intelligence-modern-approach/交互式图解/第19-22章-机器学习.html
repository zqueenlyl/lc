学习 = 用数据换掉「手写规则」

前五卷里，智能体的知识都是我们写进去的。从这一卷开始，知识是从样例里学出来的： 给定数据 D 与假设空间 H，找一个 h 使它在没见过的数据上也对。 全部内容都在回答两个问题：怎么从数据里挑出那个 h，以及凭什么相信它在新数据上也行。

学习的三种反馈，与一个最硬的定理

监督（给标准答案）、无监督（只给数据）、强化（只给奖励）。 三者共用同一件事：从 H 里挑一个 h。挑得多好，PAC 学习理论给了个能算出来的界。

PAC 界最重要的那句话：N ≥ (1/ε)(ln(1/δ) + ln|H|)。 |H| 出现在 ln 里面 —— 假设空间从 10⁶ 涨到 10¹²，样本数只从 ≈152 涨到 ≈290（ε=0.1, δ=0.05）。 「假设空间很大」本身不是灾难，真正的灾难是误差随 1/ε 线性增长：想把误差减半，样本要翻倍。
没有免费午餐：任何学习算法都自带归纳偏置（偏好某些 h）。 离开偏置，对「所有可能的函数」的平均误差对所有算法都一样 —— 所以"更好的算法"永远是"更适合这个世界的偏置"。

信息增益的陷阱：它偏爱取值多的属性。极端情况下给每个样本一个唯一取值（比如邮编）， 每组只剩 1 条、熵全为 0，增益最大 —— 但这样的树什么也没学到，只是在背答案。
Alt、Bar、Type 三个属性的增益都是 0：按"附近有没有别家""有没有吧台""什么菜系"分组后， 每组都是 1:1 或 2:2，和总体的 6:6 一模一样 —— 一点信息都没得到。 Friday / Rain / Reservation 也只有 0.021。 真正有用的是 Patrons（0.541）：店里没人 → 一定不等，坐满了 → 八成不等。 其次是 Est（0.207） 和 Hungry / Price（0.196）。

ID3：一步步把树长出来

ID3 是贪心：每次挑当前信息增益最大的属性分裂，直到这一堆样本全同类。 它一定能拟合训练集，但拟合得太好就过拟合 —— 所以要剪枝。

χ² 剪枝在问什么：这个分裂带来的分布差异，会不会只是随机波动？ 它算 Δ = Σ (观测 − 期望)²/期望，自由度 = 取值数 − 1；若 Δ 小于临界值（df=3 时 5% 对应 7.82）， 就认为"这一刀不显著"，直接做成叶节点而不是继续分裂。
剪枝 ≠ 早停。XOR 那种问题上，单个属性单独看毫无信息，早停会直接放弃； 所以要"先长完再回头剪"，而不是"看不对就停"。

线性回归：闭式解 vs 梯度下降

平方损失是凸的，所以它有唯一最小值 —— 既能一步算出（正规方程），也能一步步滚下去（梯度下降）。 滚下去的好处是：大数据下每一步都很便宜。

闭式解：w₁ = (N·Σxy − Σx·Σy) / (N·Σx² − (Σx)²)， w₀ = (Σy − w₁Σx)/N —— 一步到位，但要算 Σ（大数据下贵）。

感知机 vs 逻辑回归：一条线的两种学法

两者都在找一条线性边界，区别只在"错了怎么改"。 感知机只看错得多离谱（硬阈值），逻辑回归看概率离目标多远（连续输出）。

感知机（硬阈值）：wᵢ ← wᵢ + α(y − h_w(x))·xᵢ， h = 阈值(w·x)。数据线性可分时它一定收敛；不可分时它会一直抖 —— 反复经过误差最小的那组权重，却永远停不下来。
逻辑回归：h = 1/(1+e^{−w·x})，更新 wᵢ ← wᵢ + α(y − h)·h·(1−h)·xᵢ。 多乘的那个 h(1−h) 是 logistic 的导数 —— 已经很确定的样本，梯度几乎为 0，所以它学得更稳。

过拟合：把噪声也背下来了

同一个真函数，用不同复杂度的模型去拟合：太简单欠拟合，太复杂把噪声当规律。 验证集上的误差是一条 U 形曲线，最低点就是你要的复杂度。

为什么一定要有验证集：训练误差随复杂度单调下降，它永远偏爱"最复杂的那个"。 只有没参与训练的数据才能告诉你模型是不是在背答案。测试集更是只能摸一次 —— 拿它调参，它就已经不是测试集了。
正则化是在给"复杂"标价：Cost = EmpLoss + λ·Complexity。 L2 的 Complexity = Σwᵢ²，把权重均匀压小；L1 = Σ|wᵢ|，会把没用的权重压成 0（自动做特征选择）。 把 λ 拉大，看那条抖动的曲线怎么被压平。

贝叶斯糖果袋：五个假设在赛跑

袋子里樱桃糖和柠檬糖的比例未知，只有 5 个候选假设。每打开一颗糖， 就按贝叶斯法则把所有假设的后验重新加权。注意：贝叶斯预测是对所有假设取平均， 而 MAP 预测只信当前最可能的那个 —— 它们的答案常常不一样。

MAP 更冒险，贝叶斯更诚实。看完 3 颗柠檬后， h₅（0% 樱桃）后验最大，于是 MAP 拍胸脯说"下一颗一定是柠檬（1.0）"。 贝叶斯预测却只有 0.8 —— 因为它把 h₄、h₃ 的可能性也算了进去。 用 MAP 近似贝叶斯，会丢掉假设空间里的不确定性。
数据量足够时两者会合流：随着证据增多，后验越来越集中在一个假设上， MAP 与贝叶斯预测趋于一致。这就是"数据最终会压倒先验"。

先验 = 虚拟计数。Beta(a,b) 相当于"在看到真实数据之前， 你已经见过 a 次正面、b 次反面"。Beta(1,1) 是均匀分布（什么都不假设）， 均匀先验下 MAP ≡ MLE。
数据越多，后验越尖。Beta(3,1) → Beta(6,2) → Beta(30,10)： 均值都在 0.75 附近，但标准差一路从 0.19 缩到 0.075 —— 这就是"学"的过程： 不是找到一个点，而是把不确定性挤掉。

不做平滑会怎样：只要某个属性值在某个类别里一次都没出现过， P(xᵢ|C) = 0 → 整个乘积变成 0 → 两边都是 0，分类器直接失灵。 拉普拉斯平滑给每个计数加 1，等于说"没见过 ≠ 不可能"。
它的概率是过度自信的。条件独立假设在现实里几乎从不成立， 把 10 个"半独立"的概率连乘，结果会趋近 0 或 1。所以朴素贝叶斯当分类器很好用， 但当概率估计器要小心。

预测带为什么是喇叭形：预测方差 = σ² + σ_N²·x²。 σ² 是数据本身的噪声（哪儿都有）， σ_N²·x² 是"斜率还不确定"带来的 —— 离原点越远，斜率的一点误差被放得越大。
纯最大似然的结构学习必然选全连接网（多加一条父边，似然只会升不会降）， 所以必须加复杂度惩罚：MDL = −log₂P(d|h) − log₂P(h)。 把 λ 拉到 0，看最复杂的结构是不是立刻"赢"了。

ReLU 为什么赢：它的导数在正半轴恒为 1，梯度可以无损地穿过多层， 而 logistic / tanh 的导数最大只有 0.25 / 1，连乘十几层就趋近 0（梯度消失）。 代价是：负半轴导数恒为 0 —— 一旦某个神经元的所有输入都为负，它就永久死亡，再也不更新。
softmax 的温度：T → 0 时它变成硬取最大（one-hot）， T → ∞ 时变成均匀分布。蒸馏、采样都在调这个旋钮：想要"确定"就降温，想要"多样"就升温。

动量为啥有用：峡谷里梯度在"陡的方向"来回震荡、在"平的方向"走得很慢。 动量把历史梯度累加起来，震荡方向互相抵消，平坦方向不断加速 —— 就像带惯性的球。

为什么要除以 √dₖ：两个 d 维向量点积的量级是 √d， d 一大，点积就很大 → softmax 进入饱和区（梯度近乎 0，学不动）。 除以 √dₖ 把方差拉回 1。把上面的开关切到"不要"，看权重怎么塌成 one-hot。

价值迭代：把 Bellman 方程迭代到不动点

智能体知道转移模型 P(s'|s,a) 和奖励，只是不知道该怎么做 —— 那就反复用 U(s) = R(s) + γ·max_a Σ P(s'|s,a)U(s') 更新，直到收敛。 这就是价值迭代。

为什么迭代一定会收敛：Bellman 更新是一个压缩映射（γ < 1 时）， 每次迭代都把所有 U 值之间的距离压缩 γ 倍 → 几何级数收敛。 γ = 1 时它依然收敛（因为最终会碰到终止状态），只是没有折扣，agent 会为了远期奖励无限拖延。
价值迭代 vs 策略迭代：价值迭代每轮只做一次 Bellman 更新（便宜但轮数多）； 策略迭代每轮要做完整的策略评估（解方程，贵但轮数极少，通常 3–5 轮）。 状态多时两者都做不动 —— 那就要靠后面的近似方法。

被动学习：同一个策略，三种学法

策略固定不变（就用上一面板价值迭代算出来的那个最优策略），只是从"跑出来的轨迹"里估它有多好。 三种方法的区别只在于：用多少信息。 下面是同一个 4×3 网格上真跑出来的轨迹，误差是相对真值 U* 的 RMS，按每个状态被访问的次数加权 —— 从没去过的格子不算，因为三种方法在那儿都只能给出初始值。

三者的信息量排序：ADP 用了学到的完整模型（可以做动态规划）， 所以最好；TD 只用了"下一步的实际后果"（自举），次之； 蒙特卡洛只用了整条轨迹的最终回报（方差最大），最差。
TD 为什么比 MC 好：MC 要等一整条轨迹跑完才更新，而且它把终局的随机性 整条灌回每个状态；TD 每走一步就更新一次，只把一步的随机性引进来 —— 方差小得多。 但 TD 有自举偏差（它相信的是自己当前的估计）。

主动学习：Q-learning 敢走悬崖边，SARSA 不敢

同一个悬崖世界、同一个 ε-greedy 探索，只差一个更新公式： Q-learning 用 max（学"最优策略"，off-policy），SARSA 用实际会执行的下一步（on-policy）。 结果它们的性格完全不同。

为什么 SARSA 更"怂"：它在更新时把ε-greedy 的探索也算进去了 —— "我接下来有 10% 的概率乱走，那走悬崖边就很可能掉下去"。 于是它学会绕开悬崖。它学到的是"带探索的自己"的最优策略，不是"纯策略"的最优策略。

多臂赌博机：探索到底值多少钱

三个摇臂，真实回报率分别是 0.2 / 0.5 / 0.8（伯努利：以该概率给 1，否则给 0）。 你不知道哪个最好，只能一边试一边收钱。差的那部分叫后悔（regret）。 单次实验运气成分太大，所以下面所有数字都是 20 次独立重复实验的平均。

后悔值的下界是 Ω(log N)：你不可能既"一直吃最优臂"又"确定它是最优的" —— 探索本身有代价，而且这个代价不可能被消除，只能被压到对数级。 UCB 和 Thompson 采样都做到了 O(log N)，ε-greedy 做不到（它的 ε 是常数，后悔线性增长）。
乐观初始化为什么有效：把没试过的臂的初始 Q 值设得很高， 智能体就会被"骗"去把它们都试一遍；随着尝试，Q 值下降，它自然收敛到最好的那个。 它不需要 ε，也不需要 UCB 公式 —— 简单得离谱，而且在确定性环境里特别好使。

奖励黑客：你是按你写的奖励优化的，不是按你的本意

设计者想让 agent 到终点，顺手给"捡罐子"加了点奖励。 底下这个 3×3 小世界里，最优策略是真算出来的 —— 调一调奖励，看它什么时候开始摆烂。

捡到罐子的奖励 r0.50 每步代价 c0.00 折扣 γ0.90
奖励黑客的本质：agent 不是"理解你的意图"， 它只是在最大化你写下来的那个数。只要你写的奖励里有可以反复刷的漏洞， 最优策略就一定会去刷 —— 而且刷得越彻底越好。这不是 bug，这就是最优。
三条止血办法：① 给每步负奖励（让"绕圈"有代价，上面的 c 滑块）； ② 把 γ 调小（让远期奖励不值钱）；③ 别把奖励设计成"可以重复领取" —— 罐子捡完就不再刷新，是最简单也最有效的修法。

章主题一句话最容易踩的坑
19三种反馈监督给标准答案，无监督只给数据，强化只给奖励信号。强化的奖励不是标签：它可能延迟、稀疏、还能被刷。
19假设空间 / 归纳偏置选 H 就是选你允许自己学到什么。H 太小 → 欠拟合；太大 → 过拟合，而且 PAC 界会一起爆炸。
19PAC 样本复杂度N ≥ (1/ε)(ln(1/δ) + ln|H|)。它只保证 consistent 假设的误差，且是个上界；ln|H| 让纯记忆表直接爆炸。
19熵与信息增益Gain = B(q) − Σ (pᵢ+nᵢ)/(p+n) · B(qᵢ)。信息增益偏爱取值多的属性（如日期），要 gain ratio 或干脆别用。
19ID3 与剪枝每次挑增益最大的属性分裂，再用 χ² 检验剪掉统计上不显著的枝。不剪枝的树在训练集上能到 100%，在测试集上什么都不是。
19线性回归最小二乘有闭式解；数据大时用梯度下降。α 太大会发散；特征尺度差太远必须标准化，否则下降走 Z 字。
19L1 / L2 正则在损失上加 λ·Σ|w| 或 λ·Σw²，惩罚大权重。L1 会造出稀疏解（部分权重归零）；截距不参与惩罚；λ 太大 → 欠拟合。
19模型选择留出集 / k 折交叉验证 / 留一法。用测试集调超参 = 测试集已经不干净了，它不再是泛化误差的无偏估计。
19感知机 vs 逻辑回归感知机输出硬 0/1，逻辑回归输出概率且可微。数据线性不可分时感知机永远不收敛，会一直抖；逻辑回归给的是概率，可以定阈值。
20贝叶斯推断P(h|d) = α·P(d|h)·P(h)，后验 ∝ 似然 × 先验。先验不是随便编的偏好：数据少时它主导结论，数据多时它被淹没。
20MAP vs 贝叶斯预测MAP 用后验最大的那一个 h；贝叶斯预测对全部 h 做加权平均。MAP 是贝叶斯预测的近似，丢掉了不确定性；小数据下两者结论可以完全不同。
20MLEθ̂ = argmax P(d|θ)，只看数据。抛 3 次全是正面 → MLE 说 P(H)=1。零概率会毁掉后面所有计算。
20共轭（Beta-Bernoulli）Beta(a,b) × 伯努利数据 → 还是 Beta(a+h, b+t)。共轭只是好算，不是"更对"；真实后验常常没有闭式解。
20朴素贝叶斯假设给定类别后各属性条件独立 → P(C|x) ∝ P(C)·Π P(xᵢ|C)。独立性假设几乎从不成立，但分类仍然常常很准；没见过的属性值要平滑。
20拉普拉斯 / 杰弗里斯平滑计数加 1 或加 ½，避免零概率。加多少是先验强度，不是常数魔法；属性多时 +1 会明显改变估计。
20EME 步补齐隐藏变量的期望，M 步用补齐的数据重估参数。只保证似然单调不降，不保证找到全局最优；初值不同 → 不同的局部最优。
20贝叶斯线性回归不估一个 w，而是估 w 的后验分布；预测方差随 x 离数据中心的距离增大。预测带在训练数据之外会张开 —— 这正是它比点估计有用的地方。
20MDL代价 = −log₂P(d|h) + λ·k，拟合好坏 + 描述 h 的比特数。λ 是你自己选的（单位换算系数），不是从数据里学出来的。
21激活函数sigmoid 会饱和、ReLU 稀疏不死、tanh 零中心。sigmoid 饱和区梯度≈0 → 梯度消失；ReLU 有死神经元（输入恒负则永久为 0）。
21softmax 温度pᵢ = exp(zᵢ/T)/Σexp(zⱼ/T)。T→0 变硬 argmax、T→∞ 变均匀分布；默认 T=1 常常过于自信。
21卷积参数共享 + 局部连接：一个 k×k 核只有 k²+1 个参数。同一个核扫全图 → 学会的是平移不变的特征；全连接层做不到、也做不到参数量这么省。
21反向传播就是链式法则，只不过从输出层往回算，中间结果复用。它不是"另一种算法"，就是高效的求导；数值梯度只是用来验算的。
21SGD / 动量 / AdamSGD 直接用梯度；动量累积方向；Adam 再按梯度的二阶矩自适应缩放步长。各向异性的碗里 SGD 会来回震荡；Adam 快但泛化有时略差。
21自注意力Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V。不除 √dₖ 时点积太大 → softmax 饱和 → 梯度消失。代价是 O(n²)。
21RNN vs LSTMRNN 每步乘 w·σ′，连乘导致梯度指数消失；LSTM 的记忆单元走加性通路。LSTM 也不是万能：它仍然顺序计算，长序列上训练慢，这才有了 Transformer。
22MDP 与 Bellman 方程U(s) = R(s) + γ·max_a Σ P(s'|s,a)U(s')。γ 既是"折扣"也是"收敛保证"；γ=1 时压缩映射的证明就不成立了。
22价值迭代 vs 策略迭代价值迭代每轮一次 Bellman 更新（便宜、轮数多）；策略迭代每轮完整评估（贵、轮数少）。两者都要求状态可枚举；状态一多就只能靠近似/采样。
22被动学习三兄弟ADP 学模型再做 DP；TD(0) 自举一步；蒙特卡洛用整条轨迹的回报。TD 有自举偏差但方差小；MC 无偏但方差大；ADP 最省样本但要先学对模型。
22Q-learning vs SARSAQ 用 max（off-policy），SARSA 用实际下一步（on-policy）。Q 学到的是最优策略，却因为贴边探索在线摔得更惨；SARSA 学到的是"带探索的自己"。
22多臂赌博机后悔下界 Ω(log N)；UCB 与 Thompson 采样达到 O(log N)，ε-greedy 只能线性。ε-greedy 的 ε 是常数 → 永远在乱试；UCB 的探索预算会随证据自动收缩。
22奖励黑客agent 最大化的是你写下来的奖励，不是你的本意。不是 bug，是最优解。修法：每步负代价、降低 γ、让奖励不可重复领取。

五个「看起来像、其实不是」

监督 vs 强化监督的标签是"这一步该做什么"，强化的奖励是"结果有多好" —— 后者可能延迟很多步才到，中间每步都没有标准答案。
MAP vs 贝叶斯预测MAP 挑一个 h 就用；贝叶斯预测对所有 h 按后验加权。前者丢掉了"我不确定"，小数据时两者会给出不同的决策。
off-policy vs on-policyQ-learning 更新时用的是"如果我之后都最优"；SARSA 用的是"我接下来真的会做什么（含探索）"。差的就是那个 ε。
偏差 vs 方差TD 自举 → 有偏差、方差小；MC 用真实回报 → 无偏、方差大。样本少的时候方差才是主要矛盾。
过拟合 vs 欠拟合两者都表现为"误差大"，但一个是训练误差已经很低、验证误差高；另一个是训练误差本身就下不来。看两条曲线才分得清。
探索 vs 利用后悔下界说得很清楚：你不可能既一直吃最优臂又确定它是最优的。探索的代价只能压到对数级，不能消除。
四章一条线：第 19 章在挑一个 h（并问"挑得多好"）； 第 20 章不再挑，而是保留整个后验分布；第 21 章把 h 换成一个可微的巨大函数，用梯度去搜； 第 22 章连"标准答案"都没有了，只有一个奖励信号，而且这个信号还可能被你自己写错。
