「智能体」不是一段程序，而是「用感知选动作」这件事本身

后面 22 章讲的都是方法：搜索、逻辑、概率、学习。这一卷先回答更前面的问题： 什么算「智能」？什么叫「做对了」？答案落在一串很具体的定义上 —— 智能体（用感知序列选动作）、性能度量（谁说了算）、 理性（在已有信息下把期望性能做到最大）、任务环境（决定你该用哪种 agent）， 最后才是内部结构：反射 → 有模型 → 有目标 → 有效用 → 会学习。

理性 ≠ 像人：AI 的四种定义，以及本卷为什么选最后一种

教材把 AI 的定义摆成一个 2×2：横轴是像人 / 理性，纵轴是思考 / 行动。 四条路线都合理，但只有理性行动这一条能写成可计算的目标 —— 因为它是唯一一个「做得好不好」能量化的标准。下面这个实验就是把这条标准拿去和「像人」正面比一次。

为什么「像人行动」不够：图灵测试要求模仿人类，但人类在某些任务上系统性地做不好 （赌徒谬误、热手谬误、锚定效应都是被反复验证过的）。如果标准定成「像人」， 这些偏差就会被当成目标写进系统里。而标准定成「理性」， 偏差就只是需要被修正的东西 —— 上面那个差值就是把标准换一下、真金白银的差距。
「理性地思考」为什么也被放下：逻辑只能处理能写出来的知识， 而现实里大量任务是「证据不全、时间有限、还得立刻动」。 理性行动不问「你的推理形式对不对」，只问「你选的动作把期望性能做到最大了吗」—— 这一问，就把概率、效用、学习全都请了进来（也就是后面 12–18 卷的内容）。

智能体 = 感知 + 动作：真空吸尘器世界

教材最小的例子：两个方格 A / B，一只只看得见自己脚下的吸尘器。 它每一步收到一个感知 [位置, 这格脏不脏]，然后选一个动作：左 / 右 / 吸 / 不动。 所谓 agent 函数，就是「感知序列 → 动作」这张表。问题是：这张表有多大？

这张表会炸，但世界不会：4 种感知 → t 步就是 4t 条不同的历史； 可 N 格世界的实际状态只有 N·2ᴺ 种（位置 N × 每格脏/净 2ᴺ）。 两者的差就是「用状态代替历史」的全部价值 —— 一旦你发现当前状态已经包含了做决定所需的全部信息，历史就不用记了。 这正是第 7 章以后所有「状态空间搜索」能成立的前提。
感知 ≠ 状态：这只吸尘器看得见自己脚下，看不见另一格。 所以它的感知（4 种）比状态（8 种）还粗 —— 这正是「部分可观测」。 教材 2.4.2 的基于模型的反射 agent就是为这种情况准备的：自己记住另一格上次是什么样。

「最优」是怎么算出来的：这里的最优不是拍脑袋的规则， 而是把世界当成有限期 MDP，从最后一步往前做值迭代倒推出来的（状态数 N·2ᴺ，最多 80 个）。 所以它是在"只知道当前感知 + 已知变脏率"这个信息条件下的真正上界 —— 不是「它知道未来」（那是下一个面板的全知 agent）。
「最优」优化的是期望，不是这一条世界： 所以偶尔会看到最优 agent 输给运气好的简单反射 —— 那不是它算错了，是这一轮的随机性站到了对手那边。 想看它真正赢，要比很多条世界的平均分（这正是「理性 = 最大化期望」的含义）。
移动代价一开，行为就变了：把代价从 1 拉到 5 再看看 —— 当「跑过去吸」的代价大于「多脏一步」的损失时，理性的选择是原地不动。 agent 没变、环境没变，只改性能度量，最优行为就换了 —— 这提醒我们：性能度量写错，后面所有优化都在高效地做错事。

理性 ≠ 全知：事后看起来蠢的决定，当时可能就是最优的

理性的定义里有一个容易被漏掉的词：期望。 理性不是「每次都选对」，而是「在用得上的信息下把期望性能做到最大」。 下面三个 agent 跑在同一条变脏序列上：全知（看得到未来）、理性（只知道模型和当前感知）、短视（脏了才吸）。

「理性 ≠ 全知」是这一章最容易被学歪的一句： 理性 agent 不知道未来，它只知道分布。所以它会做出一些事后看很蠢的决定 （刚扫完 A 就跑去 B，结果 A 下一秒又脏了）—— 但那一步在当时的期望下是对的。 评价一个 agent 要按决策时的信息打分，不能按结果打分。
全知 − 理性 = 信息的价值：这个差值就是 16 章的 VPI 在这一章的雏形。 它同时也是「预测值多少钱」的定价公式：如果你能提前知道哪里会变脏， 你最多也就多拿这么多分 —— 超过这个价去买预测，就是亏的。

先把任务说清楚：PEAS 与状态空间有多大

设计一个 agent 之前，教材要求先写四件事：Performance（性能度量）、 Environment（环境）、Actuators（执行器）、Sensors（传感器）。 这四行写不出来，后面所有算法都无从谈起。写完再算一件事：这个环境有多少个状态 —— 它决定了能不能「把答案背下来」。

当前 N 的状态数—
与「把每个状态的最优动作背下来」的可行性—
N·2ᴺ 是「组合爆炸」的最小样本：N=2 时只有 8 个状态，你可以把最优动作全部背下来； N=20 时是 2000 万个；N=30 时是 320 亿 —— 而真实任务（出租车、下棋）是连续的，状态根本数不完。 这就是为什么第 3 章开始要找结构（可分解的表示、启发式、近似），而不是穷举。
PEAS 里最容易被写错的是 P：性能度量必须是环境里的客观量，不能是 agent 以为的量。 「让乘客满意」不是度量，「按时到达 + 不违章 + 油耗」才是。 出租车那个经典反例：如果只按「速度快」打分，最优策略会变成疯狂超速 —— 度量写漏一项，agent 就会在漏掉的那项上无限作恶。

任务环境的 7 个维度：它们直接决定该用哪种 agent

教材用 7 个维度给任务环境分类。这不只是贴标签 —— 每一维都在逼 agent 长出一种能力：看不见就得记（内部状态）、有别人就得猜（对手模型）、 不确定就得算期望、会变就得边看边动、不认识就得学。

「最难」的那一组是什么：部分可观测、多 agent、随机、序贯、动态、连续、未知 —— 七个维度全在难的一端。真实的自动驾驶就落在这一格：看不见全部（遮挡）、有别的车（多 agent）、 结果不确定、动作影响未来、环境一直在变、状态连续、而且规则永远学不全。 教材说「大部分真实任务都在最难那一格」，这就是为什么后面 22 章的方法各有各的适用边界。
注意「片段式」这一个反直觉的点：片段式（每局独立，如零件分拣、图像分类） 反而更简单 —— 因为上一个片段的经验不影响下一个，不需要跨片段记状态。 所以「能把任务切成独立片段」是一种设计上的减负：很多工程上做的第一件事，就是把序贯任务切成一个个片段。

为什么简单反射会「卡住」：它只看脚下。两格都干净时，规则「不脏就往右移」 会让它左右横跳——永远等不到下一次脏。这不是运气不好，是结构上不可能： 没有内部状态，它连「我扫过哪里」都表达不出来。
基于目标 vs 基于效用 —— 差在有冲突的时候： 只有一个目标（全部扫干净）时，搜索就够了。可一旦出现权衡（跑过去很贵，而那边脏的概率不高）， 「目标」就说不清了：达到了 / 没达到，哪种更好？这时必须换成效用：把「概率 × 收益 − 代价」算成一个数再比大小。 把移动代价拉大，你就能看到基于效用的 agent 开始「懒得跑」—— 那不是它变笨了，是它算清楚了。

学习型 agent：把「不知道」变成「估计」

前面所有 agent 都预先知道环境怎么变。若变脏率未知，就只有一条路： 先看、再估计、再按估计行动 —— 并在「用当前估计去赚」和「再多看一眼」之间取舍（探索 vs 利用）。 下面的曲线是真跑出来的：估计误差在下降，得分在上升。

探索有两种，别只盯着 ε：这个 agent 即使把 ε 拉到 0 也会去看另一格 —— 因为它用模型算出「那边已经过了一会儿，可能又脏了」。这是模型驱动的探索，比瞎逛聪明得多。 ε 那种随机探索的价值在于兜底：模型没覆盖到的地方，它还能撞见。 代价也很直白 —— 把 ε 拉到 0.4，它 40% 的步数花在跑腿上，分数会明显掉下来：探索是要付钱的。
学习的代价是可以量化的：「全知」那条线是知道真实变脏率时的最优； 学习 agent 与它之间的差，就是「从零开始学」这件事本身的学费。 学费随轮数下降（曲线在收敛），但永远不为零 —— 只要环境还在变，学习就不该停。

1AI 的四种定义像人思考 / 像人行动 / 理性思考 / 理性行动；本卷采用理性行动。把「像人」当标准，会把人类的认知偏差（赌徒谬误等）当成目标写进系统。
2智能体与环境agent = 用感知序列选动作的东西；agent 函数就是「感知序列 → 动作」那张表。感知 ≠ 状态：真空世界只看得见脚下，这是部分可观测，得靠记忆补。
2感知序列会爆炸t 步有 4ᵗ 条历史，但世界只有 N·2ᴺ 个状态 —— 用状态代替历史。以为「记住所有历史」才安全；其实历史里大部分信息对决策无用。
2性能度量度量由设计者定，不由 agent 定；教材真空世界用「每步每干净格 +1」。度量写漏一项（如只奖速度），agent 就会在漏掉的那项上无限作恶。
2理性理性 = 在已有信息下最大化期望性能，不是每次都选对、也不是全知。按结果评价 agent；正确做法是按决策时的信息评价。
2PEAS先写 Performance / Environment / Actuators / Sensors，再谈算法。P 写成主观感受（「让乘客满意」）而不是环境里的客观量。
2任务环境 8 维可观测 / 单多 / 确定 / 片段-序贯 / 静态-动态 / 离散-连续 / 已知-未知，每维逼出一种能力。以为分类只是贴标签；其实它决定了「最简够用的 agent 结构」。
2四种 agent 结构反射 → 有模型 → 有目标 → 有效用 → 会学习，内部表示越丰富，能处理的环境越多。以为「更聪明的结构一定更好」；没有冲突的目标时用搜索就够，不必上效用。
这一卷和后面的关系：第 2 章定下的「理性 = 最大化期望性能」是后面所有章的统一目标： 搜索（找动作序列）、逻辑（表示环境）、概率（处理不确定）、效用（处理冲突目标）、学习（处理未知）， 都是在同一个定义下，针对不同环境维度给出的解法。
