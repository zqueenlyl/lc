## 二、必须修正的错误（P0：会误导读者）

### P0-1｜第 12 章 §12.3 全联合分布推断：中间向量写错

**笔记原文**
```
P(Cavity | Toothache) = α ⟨0.108, 0.012⟩ ≈ ⟨0.6, 0.4⟩
```

**问题**：⟨0.108, 0.012⟩ 归一化后是 ⟨0.9, 0.1⟩，**不是** ⟨0.6, 0.4⟩。0.108 和 0.012 是 `Cavity ∧ Toothache ∧ Catch` / `Cavity ∧ Toothache ∧ ¬Catch`，求 `P(Cavity|Toothache)` 需要先对 Catch **边缘化**。

**应改为**
```
P(Cavity | Toothache) = α ⟨0.108+0.012, 0.016+0.064⟩ = α ⟨0.12, 0.08⟩ = ⟨0.6, 0.4⟩
```

### P0-2｜第 12 章 §12.7 wumpus 世界：整个推导式不成立

**笔记原文**
```
P(P₁,₃) = 0.2    P(P₂,₂) = 0.2    P(P₁,₃ ∨ P₂,₂) = 0.2 → 二者互斥地不确定
∴ P(P₁,₃) = 0.2 / (0.2 + 0.2 − 0.04) ≈ 0.31   （用归一化后）
```

**问题**：
1. 两格独立各 0.2 时，`P(P₁,₃ ∨ P₂,₂) = 1 − 0.8² = 0.36`，不是 0.2；
2. `0.2 / (0.2+0.2−0.04) = 0.2/0.36 ≈ 0.556`，算不出 0.31。**结论数字碰巧对，推导全错**。

**原书正确推导**（fringe = {P₁,₃, P₂,₂} 之外的前沿格，P(坑)=0.2/格）：

```
P(P₁,₃ | known, b) = α′ ⟨P(P₁,₃), P(¬P₁,₃)⟩ · ⟨Σ_fringe P(b|…), Σ_fringe P(b|…)⟩
                   = α′ ⟨0.2, 0.8⟩ ⟨0.36, 0.20⟩
                   = α′ ⟨0.072, 0.160⟩ ≈ ⟨0.31, 0.69⟩
```

**还漏了原书的落点**：同一场景下 `P(P₂,₂ | known, b) ≈ 0.86`，因此**没有一个格子是安全的**（原书图注："no safe actions"）——这才是这一节想说明的"概率推理让智能体做出有信息的冒险决策"。建议补上。

### P0-3｜第 13 章 §13.2.1：关于朴素贝叶斯的论断说反了

**笔记原文**
> `JohnCalls ⊥ MaryCalls | Alarm` ← **这是朴素贝叶斯做不到的**，因为 J 和 M 通过共同父节点 A 相连

**问题**：恰好相反。"给定共同父节点（类/原因）后，各证据变量条件独立"**正是朴素贝叶斯的结构定义**（第 12 章 §12.6：`P(Cause, E₁…Eₙ) = P(Cause)·Π P(Eᵢ|Cause)`）。报警器网络里 A→J、A→M 就是标准朴素贝叶斯骨架。

**建议改为**：这一句应说明"**这正是朴素贝叶斯假设**；网络比朴素贝叶斯强的地方在于它还能表达非朴素的结构（如 Burglary、Earthquake 两个独立原因共同作用于 Alarm）"。

## 四、术语与"信达雅"（P2）

### 生造 / 直译的术语

| 笔记用词 | 建议 | 理由 |
|---|---|---|
| 绝对值独立性 | **无条件独立**（unconditional independence） | "绝对值"是英文 absolute 的直译，中文无此说法 |
| 单连通网络 | **单连接网络 / 多树（polytree）** | "单连通"在中文数学里指 simply connected，是另一个概念 |
| 编号变量（number statement） | **数量陈述** | BLOG 的 number statement 是"声明存在 n 个某类对象"，不是给对象编号 |
| 最可能解释（MAP） | **最可能序列**（原书 §14.2.3 标题即为 "Finding the most likely sequence"） | MAP 一般指最大后验估计，此处特指 Viterbi 解码 |
| 布尔可满足性规划 | 可保留，建议加"（Planning as SAT / SATPLAN）" | 已可接受 |
| 松弛量 | 建议加"（slack / float，也译"浮动时间"）" | 工程管理界更常说"时差/浮动时间" |

### 建议统一的一处义项

第 18 章把 payoff 时而译"收益"、时而译"效用"。建议：**博弈内用"收益（payoff）"，决策论语境用"效用（utility）"**，与原书用词一致。

### 原文与个人发挥未区分（建议加标记）

以下属于**笔记作者的延伸**，并非原书内容，建议统一加 `【延伸·非原著】` 标记，以免读者当成考点：

- 第 16 章 §16.7："这直接对应现代 LLM 偏好对齐（RLHF）中'成对比较'的设计逻辑"
- 第 15 章 §15.4："变分/摊销推断……（现代生成式 AI 的主流）"
- 第 17 章 §17.4："现代 RLHF / 对话策略优化常建模为 POMDP"
- 第 14 章 §14.5："NASA 的 IVHM、远程智能体"（原书历史注记里确有相关背景，但"电池监测 DBN"的具体变量表建议回书核对）
