## 0. 本章要解决的问题

第 12 章的全联合分布规模为 `2ⁿ`，完全不可扩展。本章引入**贝叶斯网络**：用**变量之间的直接因果关系**来紧凑地表示联合分布，并给出精确与近似的推断算法。

## 13.1 不确定域的知识表示

### 贝叶斯网络（Bayesian network / 信念网络 / 因果网络）

**组成**：

1. **有向无环图（DAG）**，每个节点是一个随机变量
2. 每个节点对应一张**条件概率表（CPT）**：`P(Xᵢ | Parents(Xᵢ))`

**拓扑语义**：从 `X` 指向 `Y` 的箭头的含义是"X 对 Y 有**直接影响**"（通常是因果关系）。

### 经典例子：家庭防盗报警器

```
Burglary ──┐
           ├──► Alarm ──┬──► JohnCalls
Earthquake ┘            └──► MaryCalls
```

| 节点 | 含义 |
|---|---|
| Burglary (B) | 入室盗窃 |
| Earthquake (E) | 地震 |
| Alarm (A) | 报警器响 |
| JohnCalls (J) | John 打电话 |
| MaryCalls (M) | Mary 打电话 |

CPT 示例：

```
P(B) = 0.001                       P(E) = 0.002
P(A | B, E):  真真 0.95  真假 0.94  假真 0.29  假假 0.001
P(J | A):     真 0.90    假 0.05
P(M | A):     真 0.70    假 0.01
```

**参数规模**：朴素表需 2⁵ − 1 = 31 个数；贝叶斯网络只需 1 + 1 + 4 + 2 + 2 = 10 个数。

> **建模建议**：按**因果顺序**加节点（原因在前），CPT 会最简洁——因为每个变量只需以其直接父节点为条件。

## 13.2 贝叶斯网络的语义

### 三种等价视角

**(a) 联合分布的分解**

```
P(X₁, …, Xₙ) = Π_{i=1}^{n} P(Xᵢ | Parents(Xᵢ))
```

以报警器为例：

```
P(B, E, A, J, M) = P(B) P(E) P(A | B, E) P(J | A) P(M | A)
```

**这是贝叶斯网络的定义性语义**：它指明了如何构造一个能精确匹配给定网络的联合分布。

**(b) 局部语义**：每个节点以其父节点为条件，编码一族条件分布。

**(c) 条件独立性陈述**：见 13.2.1。

### 如何构造一个贝叶斯网络（13.2 正文的核心）

原书给出的标准构造法：反复执行"**选一个变量 → 从已有变量中挑出能让它条件独立的**最小父节点集 → 画箭头、填 CPT**"。

**节点顺序决定紧致性**：

| 加节点顺序 | 结果 |
|---|---|
| **因果序**（原因在前：B, E → A → J, M） | 每个变量的父节点就是它的直接原因，**CPT 最小**（报警器网 10 个参数） |
| 反因果序（结果在前：J, M → A → B, E） | 常常要连很多边，甚至变成全连接，CPT 指数膨胀 |

> 要点：**网络越稀疏，参数越少、推断越快**，而"因果关系"通常正是最稀疏的那种依赖关系。这是本书反复强调"按因果方向建模"的原因——它不是哲学偏好，是工程结论。

### 13.2.1 贝叶斯网络中的条件独立性关系

> **核心性质**：给定父节点，一个节点**条件独立于它的全部非后代节点**。

形式化：`P(Xᵢ | Parents(Xᵢ), NonDescendants(Xᵢ)) = P(Xᵢ | Parents(Xᵢ))`

报警器中的例子：

- `JohnCalls ⊥ Earthquake | Alarm`（给定是否报警，John 是否打电话与地震无关）
- `JohnCalls ⊥ Burglary | Alarm`
- `JohnCalls ⊥ MaryCalls | Alarm` ← **这正是朴素贝叶斯假设**（第 12 章 §12.6：`P(Cause, E₁…Eₙ) = P(Cause) Π P(Eᵢ | Cause)`）。J 与 M 通过共同父节点 A 相连，但**一旦 A 已知，二者就独立**。

> ⚠️ 别记反：**给定共同原因后各证据独立，恰恰就是朴素贝叶斯的结构定义**。贝叶斯网络比朴素贝叶斯强的地方不在这里，而在它能表达**朴素贝叶斯表达不了的结构**，例如：
> - `Burglary` 与 `Earthquake` 是**两个互相独立的原因**，各自独立地影响 `Alarm`——朴素贝叶斯只允许"一个原因节点"；
> - 更长的因果链 `A → B → C`、以及"对撞"结构带来的**观测后相关性**（见下）。

**"给定 X 独立"的其他判据**：d-分离（d-separation）——若从 X 到 Y 的所有路径都被 Z 阻断，则 `X ⊥ Y | Z`。三类基本结构：

| 结构 | 形式 | 阻断条件 |
|---|---|---|
| 链式 | X → Z → Y | Z 被观测则阻断 |
| 分叉 | X ← Z → Y | Z 被观测则阻断 |
| **对撞（v-structure）** | X → Z ← Y | Z **未被观测**则阻断；Z 或其**后代**被观测则**打开** |

（对撞结构"反直觉"：观测到共同效应反而使两个原因相关。）

### 13.2.2 条件分布的高效表示

当父节点很多时，完整 CPT 仍会爆炸。可用**规范分布（canonical distribution）**替代：

| 表示 | 说明 |
|---|---|
| **确定性节点** | 父节点取值**唯一确定**子节点。逻辑例：`NorthAmerican = Canadian ∨ US ∨ Mexican`；数值例：`BestPrice` 取各经销商价格的最小，`WaterStored` 为入库减出库 |
| **噪声或（noisy-OR）** | `qⱼ` 是**抑制**概率（该原因单独为真时效果仍不出现），不是“导致效果”的概率。`P(xᵢ \| parents) = 1 − Π_{j: Xⱼ=true} qⱼ`。Fever 例：`q_cold=0.6`，`q_flu=0.2`，`q_malaria=0.1`；未列出的原因用**漏节点（leak）**。参数 `O(k)` 而非 `O(2ᵏ)` |
| **噪声最大** | noisy-MAX 等噪声逻辑关系。CPCS 内科网络：448 节点、906 条边，8254 个参数，而不是满 CPT 的 133,931,430 |
| **上下文特定独立性（CSI）** | 某些父节点取值下，子节点不再依赖其余父节点。例：`Accident=false` 时 `Damage` 与 `Ruggedness` 无关。用 **if-then-else** 写条件分布 |

### 13.2.3 连续变量的贝叶斯网络

- **离散化**：把连续变量分成区间（简单，但精度与规模两难）
- **混合网络**可以同时有离散节点与连续节点。书中的水果例子：`Harvest`（连续）、`Subsidy`（离散）→ `Cost`（连续）→ `Buys`（离散）
- **线性高斯**：连续子节点的均值随连续父节点线性变化、方差固定。`Cost` 对 `subsidy` / `¬subsidy` 各有一套 `(a, b, σ²)`
- **条件高斯（CG）**：离散变量作连续变量的**父节点**时，给定离散赋值，连续变量的联合是多元高斯。全连续线性高斯网络的联合本身就是多元高斯，推断最坏 `O(n³)`，与拓扑无关
- **离散子节点可以有连续父节点**。`Buys` 的父节点就是连续的 `Cost`，用软阈值：**probit** `P(buys \| c) = 1 − Φ((c−μ)/σ)`，或 **expit / 逆 logit**。图 13.8 的参数是 `μ=6.0`、`σ=1.0`

### 13.2.4 案例研究：汽车保险

用于说明大规模网络怎么建。申请表上的输入（图 13.9 浅蓝节点）：

| 方面 | 变量 |
|---|---|
| 申请人 | `Age`、`YearsLicensed`、`DrivingRecord`、`GoodStudent`（四分制 GPA 达到 3.0） |
| 车辆 | `MakeModel`、`VehicleYear`、`Airbag`、`SafetyFeatures` |
| 驾驶情形 | 年 `Mileage`、是否 `Garaged` |

关键隐藏变量是下一期会不会 `Theft`、`Accident`，以及 `RiskAversion`（年龄与 `SocioEcon` 影响它）、`DrivingSkill`、`DrivingBehavior`、`CarValue`。赔付分三类：`MedicalCost`、`LiabilityCost`、`PropertyCost`（另有 `OwnCarCost` 等）。

**要点**：`RiskAversion` 是承保方最关心的隐藏变量。`MakeModel` 在真实系统里可有上千个取值，但其值总是被观测到的，所以不会把推断复杂度抬上去。该网的条件分布在原书代码库里；下面每种精确算法都用这张网记时间与空间。枚举做一次典型费用查询大约要 **2.27 亿**次算术运算。

## 13.3 贝叶斯网络中的精确推断

**推断任务**：已知证据 `e`（某些变量取值），求 `P(X | e)`。

### 13.3.1 通过枚举进行推断

直接按联合分布分解展开求和：

```
P(B | j, m) = α P(B) Σ_e P(e) Σ_a P(a | B, e) P(j | a) P(m | a)
```

- 不把求和内移时，最坏是 `O(n 2ⁿ)`；把求和尽量内移后降到 `O(2ⁿ)`。`P(j|a)P(m|a)` 仍会在每个 `E` 上各算一遍
- 用数字：`P(b|j,m) = α × 0.00059224`，`P(¬b|j,m)` 对应 `α × 0.0014919`，归一化得 `⟨0.284, 0.716⟩`
- 共享子表达式（动态规划）→ 变量消元

### 13.3.2 变量消元算法（Variable Elimination）

**核心思想**：按顺序逐个消元（求和）变量，把中间结果存为**因子（factor）**。

两个基本运算：

1. **因子点积**：`f₁ × f₂`，对共同变量取值的乘积
2. **求和消元**：`Σ_z f`，对某变量求和，得到新因子

```
P(B | j, m) = α f₁(B) × Σ_e f₂(E) × Σ_a f₃(A, B, E) × f₄(A) × f₅(A)
```

`f₁=P(B)`，`f₂=P(E)`，`f₃=P(A|B,E)`，`f₄=P(j|A)=⟨0.90, 0.05⟩`，`f₅=P(m|A)=⟨0.70, 0.01⟩`。`f₃` 的首项 `P(a|b,e)=0.95`，末项 `P(¬a|¬b,¬e)=0.999`（即 `P(a|¬b,¬e)=0.001`）。先对 `A` 求和得 `f₆(B,E)`，再对 `E` 求和得 `f₇(B)`，最后算 `α f₁ × f₇`。`f₆`、`f₇` 是中间因子，不是一开始就有的项。

**性能**：

- 消元顺序极其重要；最优顺序的复杂度取决于网络**诱导图的树宽（treewidth）**
- 对**单连接（singly connected，即多树 polytree）**网络，复杂度对网络规模是**线性**的
- 一般网络为 NP-难
- ✅ **原书实测（p.433）**：在 §13.2.4 的汽车保险网络上，按逆拓扑序做变量消元，精确推断比朴素枚举**快约 1000 倍**——这是变量消元在真实规模网络上价值的直接证据

### 13.3.3 精确推断的复杂性

- 一般贝叶斯网络的精确推断是 **#P-难**（#P 是"计数"复杂度类，比 NP 更难）；**其判定形式（如 `P(X = x | e) > q` 是否成立）是 NP-难**
- **单连接（多树 polytree）网络**（任意两节点间只有一条无向路径）→ **线性时间**
- **多连接（multiply connected）**网络可用**聚类（clustering）**转换为单连接结构
- 多连接网络在最坏情况下要做指数级计算（复杂度由诱导图的**树宽**决定）；实践中常可处理
- 若限制网络结构（树、polytree），可保证多项式

### 13.3.4 聚类算法（Clustering / Join tree）

1. **多连接 → 多树**：把节点并成**簇（cluster / meganode）**，使结果成为多树。例：把 `Sprinkler` 与 `Rain` 并成四值簇 `Sprinkler+Rain`
2. 簇之间若共享变量，普通推断处理不了；要用一种**约束传播**：相邻簇对共享变量的后验必须一致
3. 也叫 **联接树（join tree）**。多树上若对每个变量各做一次 `O(n)` 的消元，总时间是 `O(n²)`；聚类把它降到 `O(n)`，一次给出全部非证据节点的后验。树宽带来的指数代价仍在：簇的 CPT 可以指数大

## 13.4 贝叶斯网络中的近似推理

当精确推断不可行时，用**采样（sampling / 蒙特卡罗）**。

### 13.4.1 直接采样方法

| 方法 | 做法 | 特点 |
|---|---|---|
| **先验采样** | 按拓扑顺序对每个变量按其 CPT 采样，生成样本 | 得到的是先验 P(ω)，不能回答证据查询 |
| **拒绝采样（rejection sampling）** | 先验采样后**丢弃**与证据不符的样本，统计剩下的 | 证据概率极低时几乎全被拒绝，效率极差 |
| **似然加权（likelihood weighting）** | 证据变量**固定为观测值**，只对非证据变量采样，并给每个样本乘权 `w = Π P(eᵢ | parents)` | **最实用的重要性采样**之一；证据多时权重方差大、仍需大量样本 |

### 13.4.2 通过马尔可夫链模拟进行推断

- **MCMC**：构造一条平稳分布恰为 `P(X | e)` 的马尔可夫链，长时间跑后统计
- **Gibbs 采样（吉布斯采样）**：每次只改变**一个**非证据变量的值，以其马尔可夫毯（parents + children + children's parents）为条件重新采样
- 属于**吉布斯采样器 / 大都会-黑斯廷斯算法（MH）**家族
- 优点：不需要提议分布的最优设计，广泛适用；缺点：收敛慢、难以判断是否收敛

### 13.4.3 编译近似推断

- 采样时反复在图上查父节点、查 CPT，这些查找对固定网络是多余的。13.4.3 把网络**编译成针对该模型的采样代码**
- 例：为报警器网里的 `Earthquake` 生成 Gibbs 代码，马尔可夫毯每种取值对应一个预先算好的阈值（如 `Alarm=true, Burglary=true` 时 `return [r < 0.0020212]`）
- 相对 `GIBBS-ASK` 通常快 **2–3 个数量级**，普通笔记本上每秒可做数千万步，瓶颈多在随机数
- 带权模型计数（WMC）是 **13.3.3 的精确推断**归约，不是本节的编译采样。【延伸·非原著：算术电路 / 代数决策图出现在章末文献注记，不是 13.4.3 正文】

## 13.5 因果网络

贝叶斯网络常被当作因果网络使用，但**观测与干预是两回事**。

### 13.5.1 表示动作：do 操作（do-calculus）

- **条件化** `P(Cavity | Toothache)`：被动观测到牙痛
- **干预** `P(Cavity | do(Toothache))`：主动"制造"牙痛

**计算规则**：`do(X = x)` 相当于

1. **删除所有指向 X 的箭头**（切断其原有的原因）
2. 把 X 固定为 x
3. 在修改后的网络中做推断

> 例子：`P(Cavity | do(Toothache))` 与 `P(Cavity | Toothache)` 不同——主动引发牙痛不会改变龋齿的原因，但观测到牙痛可能携带其他信息。

### 13.5.2 后门准则（Back-door criterion）

判定一组变量 `Z` 是否**足以**从观测数据估计 `X` 对 `Y` 的因果效应：

1. `Z` 中**不含 X 的后代节点**
2. `Z` **阻断了 X 与 Y 之间所有"后门路径"**（即所有以指向 X 的箭头开始的路径）

满足后，可用**调整公式**：

```
P(Y | do(X)) = Σ_z P(Y | X, z) P(z)
```

**实际意义**：给出了从观测里估计干预效应时**该对哪些变量做调整**的条件。原书强调：这是在说并非只有随机对照试验才能提供因果信息。【延伸·非原著：把它说成 A/B 实验设计的理论基石，正文没有这个表述】

## 小结

1. 贝叶斯网络 = DAG + CPT，用局部条件分布紧凑地编码全联合分布：`P(X₁..Xₙ) = Π P(Xᵢ | Parents(Xᵢ))`。
2. 网络的结构直接编码**条件独立**关系（"给定父节点，独立于非后代"）；d-分离是通用判据。
3. 用规范分布（确定性节点、noisy-OR、CSI 的 if-then-else）可进一步压缩 CPT。
4. 精确推断有**枚举**、**变量消元**、**聚类/联接树**；一般网络 #P-难，单连接（polytree）网络线性。
5. 近似推断有**直接采样**（似然加权）与 **MCMC/Gibbs**，以及**编译**方法。
6. **因果网络**区分观测与干预；`do` 操作 + **后门准则**提供了因果效应的可判定计算规则。
