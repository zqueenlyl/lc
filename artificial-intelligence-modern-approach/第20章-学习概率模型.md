## 0. 本章要解决的问题

第 12 章指出真实环境充满不确定性。智能体可以用概率和决策论处理它，但概率理论本身必须**从经验里学出来**。本章把学习写成一次概率推断（§20.1）：贝叶斯学习能统一处理噪声、过拟合和最优预测；智能体永远不能确定哪一个世界理论才是对的，却仍必须靠某个理论做决策。

§20.2 与 §20.3 讲怎样学习概率模型，主要是贝叶斯网络。材料偏数学，主线可以不陷入每一步推导；读前宜复习第 12、13 章，并看附录 A。

本章的数据是**证据**（域中部分或全部随机变量的实例化）。假设是这个域如何运作的**概率理论**，逻辑理论是其特例。正文主例是糖果袋。

## 20.1 统计学习（Statistical Learning）

惊喜糖果只有两种味道：cherry（好吃）和 lime（难吃）。每颗糖用同样的不透明糖纸包着。糖装在很大的袋子里，外观无法区分，已知有五种：

- h₁：100% cherry
- h₂：75% cherry + 25% lime
- h₃：50% cherry + 50% lime
- h₄：25% cherry + 75% lime
- h₅：100% lime

随机变量 H 表示袋子类型，取值 h₁…h₅，不能直接观测。打开糖得到数据 D₁, D₂, …, D_N，每个 Dᵢ 取值 cherry 或 lime。任务是预测下一颗的味道。场景简单，但智能体确实要推断一个（很简单的）世界理论。

**贝叶斯学习**（Bayesian learning）算出每个假设在数据下的概率，再据此预测。预测用**全部**假设，按概率加权，而不是只用一个「最好」的假设。于是学习还原成概率推断。

记全部数据为 D，观测值为 d。两个关键量是**假设先验** P(hᵢ) 和每个假设下数据的**似然** P(d | hᵢ)。由贝叶斯法则：

```
P(hᵢ | d) = α P(d | hᵢ) P(hᵢ)          (20.1)
```

要预测未知量 X：

```
P(X | d) = Σᵢ P(X | hᵢ) P(hᵢ | d)       (20.2)
```

每个假设都给出 X 上的一个分布。预测是各假设预测的加权平均，权重 P(hᵢ | d) 正比于 hᵢ 的先验以及它对数据的拟合程度。假设是原始数据与预测之间的「中介」。

糖果例子里，暂时采用厂商公布的先验 ⟨0.1, 0.2, 0.4, 0.2, 0.1⟩，对应 h₁…h₅。观测假定为**独立同分布**（i.i.d.，见书 p.665），于是

```
P(d | hᵢ) = Πⱼ P(dⱼ | hᵢ)               (20.3)
```

> 原书脚注：袋子必须非常大，否则 i.i.d. 不成立。更严格（但不那么卫生）的做法是检查后把糖重新包好放回袋中。方向是：袋子不够大 ⇒ 抽样改变剩余比例 ⇒ i.i.d. 失败。

设袋子其实是全 lime 的 h₅，前 10 颗都是 lime。则 P(d | h₃) = 0.5¹⁰，因为 h₃ 袋中一半是 lime。图 20.1(a) 给出连看 10 颗 lime 时五个后验如何变化：

- 起点是先验，h₃ 最初最可能；打开 **1** 颗 lime 后仍是 h₃
- 打开 **2** 颗后，h₄ 最可能
- **3** 颗及更多后，h₅（全 lime）最可能
- 连续 10 颗后，几乎可以确定

图 20.1(b) 是按 (20.2) 预测「下一颗是 lime」的概率，单调升向 1。

贝叶斯预测最终会与真假设一致：只要固定先验没有排除真假设，在一定技术条件下，任何假假设的后验都会趋于 0——无休止地产生「不像该假设」的数据，概率小到可以忽略。这一点与第 19 章 PAC 学习的讨论类似。更重要的是：给定假设先验，贝叶斯预测是最优的，数据集小或大都一样；任何别的预测，期望正确次数都更少。

代价是假设空间通常极大或无限（第 19 章）。(20.2) 的求和（连续情形是积分）有时能做，多数时候只能近似或简化。

**最大后验（MAP）**。科学里很常见的近似是：只用一个后验最大的假设 hᵢ 来预测，即最大化 P(hᵢ | d)。这叫**最大后验**假设（maximum a posteriori，MAP，读作 “em-ay-pee”）。按 h_MAP 做的预测在 P(X | d) ≈ P(X | h_MAP) 的程度上近似贝叶斯。

糖果例子里，连续 3 颗 lime 之后 h_MAP = h₅，于是 MAP 预测第 4 颗是 lime 的概率为 **1.0**；图 20.1(b) 上相应的贝叶斯预测是 **0.8**。MAP 更冒险。数据再多，竞争假设的概率越来越小，两种预测会靠近。

这个例子看不出来的是：找 MAP 通常比完整贝叶斯学习容易，因为它是优化，不是大求和（或积分）。

**先验、奥卡姆剃刀与 MDL**。贝叶斯学习和 MAP 都用到假设先验 P(hᵢ)。第 19 章说过，假设空间表达力太强、太多假设都能拟合数据时会**过拟合**。贝叶斯与 MAP 用先验惩罚复杂度：更复杂的假设先验通常更低，部分原因是它们数量很多；另一方面它们拟合数据的能力更强（极端情形，一张查找表可以精确复现数据）。假设先验体现的就是「复杂度」与「拟合程度」的折中。

逻辑情形最清楚：H 里只有确定性假设（如 h₁：每颗都是 cherry）。此时若 hᵢ 与数据一致则 P(d | hᵢ) = 1，否则为 0。由 (20.1)，h_MAP 就是与数据一致的**最简单逻辑理论**。所以最大后验学习自然体现了**奥卡姆剃刀**（Ockham's razor；原书拼作 Ockham）。

对 (20.1) 取对数可看到同一折中。最大化 P(d | hᵢ) P(hᵢ) 等价于最小化

```
− log₂ P(d | hᵢ) − log₂ P(hᵢ)
```

按 §19.3.3 的编码–概率关系：−log₂ P(hᵢ) 是指定假设 hᵢ 所需的比特数；−log₂ P(d | hᵢ) 是在给定假设后再指定数据所需的额外比特。假设若精确预测数据（h₅ 遇上全 lime），不需要比特，因为 log₂ 1 = 0。因此 MAP 是在选**对数据压缩最多**的假设。**最小描述长度**（minimum description length, MDL）更直接地做这件事：MAP 用更高概率表达简单，MDL 直接数假设与数据的二进制编码长度。

**最大似然**。若假设空间上的先验是均匀的，MAP 退化为最大化 P(d | hᵢ)，这叫**最大似然**假设 h_ML。最大似然学习在统计学里很常见——许多研究者不信任主观的假设先验。没有先验理由偏爱某个假设时（例如各假设一样复杂），它是合理的。

数据量大时，先验不那么重要：数据证据强到足以盖过假设先验。因此大数据下最大似然是贝叶斯和 MAP 的好近似；小数据则有问题，下一节会看到。

## 20.2 完整数据下的学习（Learning with Complete Data）

假定数据由某概率模型生成，要学习该模型，这叫**密度估计**（density estimation）。这个词原本指连续变量的概率密度，现在也用于离散分布。密度估计是一种无监督学习。

本节是最简单的情形：**完整数据**（complete data）——每个数据点都包含待学模型中**每一个**变量的值。重点是**参数学习**：结构固定，求数值参数。例如结构给定的贝叶斯网络，学习其中的条件概率。结构学习和非参数密度估计只作简短处理。

### 20.2.1 离散模型的最大似然参数学习

换一家厂商，cherry 的比例完全未知，可以是 0 到 1 之间的任何数。假设变成连续统。参数 θ 是 cherry 的比例，假设记为 h_θ；lime 的比例是 1 − θ。若先验认为所有比例同等可能，用最大似然是合理的。

贝叶斯网络只需一个随机变量 Flavor（随机取出的一颗糖的味道），取值 cherry 与 lime，P(cherry) = θ（图 20.2(a)）。打开 N 颗，其中 c 颗 cherry，ℓ = N − c 颗 lime。由 (20.3)：

```
P(d | h_θ) = Πⱼ P(dⱼ | h_θ) = θᶜ (1 − θ)ˡ
```

对数单调，最大化似然等价于最大化**对数似然**：

```
L(d | h_θ) = log P(d | h_θ) = Σⱼ log P(dⱼ | h_θ) = c log θ + ℓ log(1 − θ)
```

取对数把乘积变成对数据的求和，通常更好最大化。对 θ 求导并令其为 0：

```
dL / dθ = c/θ − ℓ/(1 − θ) = 0
⇒ θ = c / (c + ℓ) = c / N
```

也就是说，h_ML 断言：袋子里 cherry 的真实比例等于迄今打开的糖里观测到的比例。

这像是花了很多功夫才得到显然的结论。但由此得到一条通用的最大似然参数学习步骤：

1. 把数据似然写成参数的函数。
2. 把对数似然对每个参数的导数写出来。
3. 求使这些导数为 0 的参数值。

最难的通常是第 3 步。本例很平凡；许多情形要迭代算法或其他数值优化（§4.2），并要验证 Hessian 矩阵负定。

本例也暴露最大似然的一个普遍问题：数据集小到某些事件还没出现（例如一颗 cherry 都没有）时，最大似然假设给这些事件概率 **0**。常用的回避办法包括把每个事件的计数从 0 改成从 1 起算。

新厂商用红、绿糖纸给一点提示。Wrapper 按某个未知的条件分布、依味道随机选取。模型是图 20.2(b)，有三个参数 θ、θ₁、θ₂。按贝叶斯网络语义（书 p.415），一颗绿纸 cherry 的概率是

```
P(Flavor = cherry, Wrapper = green | h_{θ,θ₁,θ₂})
  = P(Flavor = cherry | …) P(Wrapper = green | Flavor = cherry, …)
  = θ · (1 − θ₁)
```

这里 θ₁ 是「cherry 配红纸」的概率，所以绿纸是 1 − θ₁。

打开 N 颗：c 颗 cherry、ℓ 颗 lime。计数：cherry 中红纸 r_c、绿纸 g_c；lime 中红纸 r_ℓ、绿纸 g_ℓ。似然为

```
P(d | h_{θ,θ₁,θ₂}) = θᶜ (1−θ)ˡ · θ₁^{r_c} (1−θ₁)^{g_c} · θ₂^{r_ℓ} (1−θ₂)^{g_ℓ}
```

对数似然分成三项，每项只含一个参数：

```
L = [c log θ + ℓ log(1−θ)] + [r_c log θ₁ + g_c log(1−θ₁)] + [r_ℓ log θ₂ + g_ℓ log(1−θ₂)]
```

分别求导置零，得到三个互不牵扯的方程：

```
θ  = c / (c + ℓ)
θ₁ = r_c / (r_c + g_c)
θ₂ = r_ℓ / (r_ℓ + g_ℓ)
```

θ 与前面相同。θ₁ 是观测到的「cherry 中红纸所占比例」，θ₂ 类似。

只要条件概率用表表示，这可以推广到任意贝叶斯网络。要点有二：

- **完整数据**下，贝叶斯网络的最大似然参数学习**分解成每个参数各自的学习问题**。（非表格参数、一个参数影响多个条件概率的情形见习题 20.NORX。）
- 给定父节点取值，一个变量的参数就是该父节点设定下变量取值的**观测频率**。数据集小时同样要避免零。

### 20.2.2 朴素贝叶斯模型

机器学习里最常用的贝叶斯网络大概是第 12 章（书 p.402）的**朴素贝叶斯**模型。「类」变量 C（待预测）是根，「属性」变量 Xᵢ 是叶。它「朴素」，是因为假定**给定类之后，各属性相互条件独立**。预测式写成连乘，这比「只两两独立」更强。图 20.2(b) 就是类为 Flavor、只有一个属性 Wrapper 的朴素贝叶斯模型。

布尔变量时参数为

```
θ = P(C = true)
θᵢ₁ = P(Xᵢ = true | C = true)
θᵢ₂ = P(Xᵢ = true | C = false)
```

最大似然参数的求法与图 20.2(b) 完全一样。训练之后可以给 C 未观测的新例子分类。观测到属性 x₁, …, xₙ 时

```
P(C | x₁, …, xₙ) = α P(C) Πᵢ P(xᵢ | C)
```

确定性预测取最可能的类。图 20.3 是这个方法用在第 19 章餐馆问题上的**学习曲线**，并与决策树比较：学得不错，但不如决策树——真假设是一棵决策树，朴素贝叶斯表示不了它。尽管如此，朴素贝叶斯在很多应用里出奇地好；其提升版本（习题 20.BNBX）是最有效的通用学习算法之一。

它能扩到很大的问题：n 个布尔属性时只有 **2n + 1** 个参数（1 个类先验，每个属性 2 个条件概率），找最大似然朴素贝叶斯假设 h_ML **不需要搜索**。它也能处理噪声或缺失数据，并在合适时给出概率预测。主要缺点是条件独立假设很少真成立；如书 p.403 所说，这会给出过度自信的概率，常常非常接近 0 或 1，属性很多时尤其如此。

### 20.2.3 生成模型与判别模型

用于分类器的模型分两类。

**生成模型**（generative model）为每个类建立概率分布。§12.6.1 的朴素贝叶斯文本分类器对每个文本类别各建一个模型（体育、天气，等等）。每个模型含类别的先验（如 P(Category = weather)）以及条件概率 P(Inputs | Category = weather)。由此可算联合概率 P(Inputs, Category = weather)，也可以**生成**一组能代表该天气类文本的随机词。

**判别模型**（discriminative model）直接学习类之间的决策边界，即学习 P(Category | Inputs)。给定输入它会输出类别，但不能拿来生成代表某类的随机词。逻辑回归、决策树、支持向量机都是判别模型。

判别模型把力气都放在决策边界上，也就是放在真正要做的分类上，所以在训练数据任意多的极限下往往更好。数据有限时，有时生成模型更好。Ng and Jordan (2002) 在 **15** 个（小）数据集上比较生成式朴素贝叶斯与判别式逻辑回归：数据用到最多时，判别模型在 **15 个里的 9 个**上更好；数据很少时，生成模型在 **15 个里的 14 个**上更好。

### 20.2.4 连续模型的最大似然参数学习

连续模型（如书 p.422 的线性–高斯模型）的最大似然原则与离散情形相同。

先学单变量高斯密度的参数。数据按下式生成：

```
P(x) = 1 / (σ √(2π)) · exp( − (x − μ)² / (2σ²) )
```

参数是均值 μ 和标准差 σ。归一化「常数」依赖于 σ，不能丢掉。观测为 x₁, …, x_N，对数似然为

```
L = Σⱼ log( … ) = N (− log √(2π) − log σ) − Σⱼ (xⱼ − μ)² / (2σ²)
```

导数置零得 (20.4)：

```
∂L/∂μ = − (1/σ²) Σⱼ (xⱼ − μ) = 0  ⇒  μ = (Σⱼ xⱼ) / N

∂L/∂σ = − N/σ + (1/σ³) Σⱼ (xⱼ − μ)² = 0
        ⇒  σ = √[ Σⱼ (xⱼ − μ)² / N ]
```

> ⚠️ 待核（照录）：上式 ∂L/∂μ 的负号按 PDF（书 p.729）抄录。由 L 中 −Σ (xⱼ−μ)²/(2σ²) 对 μ 求导，符号应为正的 (1/σ²) Σ (xⱼ−μ)。令导数为 0 时，μ 的解两边一样，仍是样本均值。∂L/∂σ 的符号与直接求导一致。

最大似然均值是样本平均，最大似然标准差是样本方差的平方根。

再看一个连续父节点 X、连续子节点 Y 的线性–高斯模型。Y 是高斯，均值线性依赖于 X，标准差固定（书 p.422）。学习 P(Y | X) 就是最大化条件似然

```
P(y | x) = 1 / (σ √(2π)) · exp( − (y − (θ₁ x + θ₂))² / (2σ²) )     (20.5)
```

参数是 θ₁、θ₂、σ。数据是 (xⱼ, yⱼ) 对。图 20.4(a) 是 y = θ₁ x + θ₂ 加上固定方差的高斯噪声；(b) 是由此生成的 **50** 个点以及最佳拟合直线。θ₁、θ₂ 的最大似然值见习题 20.LINR。这里要看的是：只对定义直线的 θ₁、θ₂ 最大化对数似然，等价于最小化 (20.5) 指数里的分子 (y − (θ₁ x + θ₂))²。这就是 **L2 损失**，即真实值 y 与预测 θ₁ x + θ₂ 的平方误差。

这正是 §19.6 标准线性回归所最小化的量。原因是：若数据由**固定方差的高斯噪声**生成，最小化平方误差和就给出最大似然直线。

### 20.2.5 贝叶斯参数学习

最大似然步骤简单，但小数据有严重缺陷。例如只看到一颗 cherry，最大似然就说袋子是 100% cherry（θ = 1.0）。除非先验认定袋子必须全 cherry 或全 lime，这不是合理结论；更可能是两种味道的混合。贝叶斯参数学习从假设先验出发，随数据到达更新分布。

图 20.2(a) 只有一个参数 θ：随机一颗是 cherry 的概率。贝叶斯观点里，θ 是随机变量 Θ 的未知取值，假设先验就是 P(Θ) 上的先验分布。P(Θ = θ) 是「袋子中 cherry 比例为 θ」的先验概率。

θ 可取 [0, 1] 中任意值，则 P(Θ) 是连续密度（§A.3）。对 θ 一无所知时可用均匀密度 P(θ) = Uniform(θ; 0, 1)。

更灵活的一族是**贝塔分布**。每个贝塔分布由两个**超参数** a、b 定义（超参数之所以叫超参数，是因为它们参数化的是「参数 θ 上的分布」）：

```
Beta(θ; a, b) = α θ^{a−1} (1 − θ)^{b−1}     θ ∈ [0, 1]     (20.6)
```

归一化常数 α 依赖于 a、b，使密度积分为 1。均值是 a / (a + b)。a 越大，越相信 Θ 靠近 1 而不是 0；a + b 越大，分布越尖，对 Θ 的取值越有把握。均匀密度就是 Beta(1, 1)：均值 1/2，形状是平的。图 20.5(a) 画了 (a, b) = (1, 1)、(2, 2)、(5, 5)。

贝塔族还有一个性质：若 Θ 的先验是 Beta(a, b)，观测一个数据点后，Θ 的后验仍是贝塔分布。Beta 对更新封闭。贝塔族是布尔变量分布族的**共轭先验**。看到一颗 cherry：

```
P(θ | D₁ = cherry) = α P(D₁ = cherry | θ) P(θ)
  = α′ θ · Beta(θ; a, b)
  = α′ θ · θ^{a−1} (1−θ)^{b−1}
  = α′ θ^a (1−θ)^{b−1}
  = α′ Beta(θ; a+1, b)
```

看到 cherry 就把 a 加 1；看到 lime 就把 b 加 1。a、b 可以看成**虚拟计数**：先验 Beta(a, b) 的行为，恰好像从均匀先验 Beta(1, 1) 出发、已经看过 a−1 颗真正的 cherry 和 b−1 颗真正的 lime。

固定比例、增大 a 和 b，就能看见参数 Θ 的后验如何随数据变化。设袋子实际是 75% cherry。图 20.5(b) 的序列是 Beta(3, 1)、Beta(6, 2)、Beta(30, 10)，分布收到真值 Θ 附近的窄峰上。大数据时，这种贝叶斯学习收敛到与最大似然相同的答案。

> 原书脚注：其他共轭先验包括离散多值分布参数的狄利克雷族，以及高斯分布参数的 Normal–Wishart 族（Bernardo and Smith, 1994）。

图 20.2(b) 有三个参数：θ、θ₁（cherry 上红纸的概率）、θ₂（lime 上红纸的概率）。贝叶斯假设先验必须覆盖全部三个，即要指定 P(Θ, Θ₁, Θ₂)。通常假设**参数独立**：

```
P(Θ, Θ₁, Θ₂) = P(Θ) P(Θ₁) P(Θ₂)
```

这是三个参数变量的**无条件相互独立**（联合先验写成三项乘积），不是只两两独立。在此假定下，每个参数有自己的贝塔分布，随数据分别更新。

图 20.6 把假设先验和数据放进一个贝叶斯网络，每个参数变量一个节点。Θ、Θ₁、Θ₂ 没有父节点。对第 i 次观测，增加 Wrapperᵢ 与 Flavorᵢ：

```
P(Flavorᵢ = cherry | Θ = θ) = θ
P(Wrapperᵢ = red | Flavorᵢ = cherry, Θ₁ = θ₁) = θ₁
P(Wrapperᵢ = red | Flavorᵢ = lime, Θ₂ = θ₂) = θ₂
```

于是，原来图 20.2(b) 的整个贝叶斯学习过程，变成在图 20.6 这个导出网络上的**推断**问题：数据和参数都是节点。证据节点加完后，查询参数变量 Θ、Θ₁、Θ₂。这种表述下只有**一个**学习算法——贝叶斯网络的推断算法。

这些网络与第 13 章的网络不同：表示训练集的证据变量可能极多，参数变量又多为连续值。除朴素贝叶斯这类极简情形外，精确推断可能做不到。实践中常用 MCMC 等近似推断（§13.4.2）；许多统计软件包为此内置了高效 MCMC。

### 20.2.6 贝叶斯线性回归

§19.6 把线性回归说成最小化平方误差和；§20.2.4 把它重新解释成高斯误差模型下的最大似然。两者都给出**一个**最佳假设：确定斜率、截距，以及任一点上固定的预测误差方差。它们不说明对斜率和截距该有多自信。而且，若要预测的点远离已观测点，仍假设预测误差与「紧挨观测点」时一样大，并不合理：斜率的微小变化会让远处的预测值变化很大，越远不确定程度应该越大。

贝叶斯做法同时处理这两点。与上一节一样，给模型参数（这里是线性系数和噪声方差）放上先验，再算给定数据后的参数后验。多元数据、噪声模型未知时线性代数很多，书中只做简单情形：单变量、直线强制过原点、噪声已知为方差 σ² 的正态分布。于是只有一个参数 θ：

```
P(y | x, θ) = N(y; θx, σ²_y)
            = 1 / (σ √(2π)) · exp( −½ (y − θx)² / σ² )     (20.7)
```

对数似然对 θ 是二次的，θ 的共轭先验也取高斯，后验就仍是高斯。先验均值 θ₀、方差 σ₀²：

```
P(θ) = N(θ; θ₀, σ₀²)
     = 1 / (σ₀ √(2π)) · exp( −½ (θ − θ₀)² / σ₀² )          (20.8)
```

对斜率 θ 可以有所预期，也可以完全无知。后一情形取 θ₀ = 0、σ₀² 很大，即所谓**无信息先验**。每个数据点的 x 还可以有先验 P(x)，但它不依赖于 θ，对分析无关。

用 (20.1)：P(θ | d) ∝ P(d | θ) P(θ)。观测点 d = (x₁, y₁), …, (x_N, y_N)。把各点的 P(xᵢ) 以及 N 个高斯的归一化常数吸进与 θ 无关的常数 α 后，

```
P(d | θ) = α exp( −½ Σᵢ (yᵢ − θ xᵢ)² / σ² )
```

与 (20.8) 的先验合在一起，指数仍是 θ 的二次函数，故后验是高斯。用与 §14.4 类似的代数可得

```
P(θ | d) = α′′′ exp( −½ (θ − θ_N)² / σ_N² )

θ_N  = (σ² θ₀ + σ₀² Σᵢ xᵢ yᵢ) / (σ² + σ₀² Σᵢ xᵢ²)

σ_N² = (σ² σ₀²) / (σ² + σ₀² Σᵢ xᵢ²)
```

数据挤在原点附近一小段 x 轴上时，Σᵢ xᵢ² 小，后验方差 σ_N² 大，大约等于先验方差 σ₀²：数据几乎约束不了直线绕原点的转动。数据沿轴散得很开时，Σᵢ xᵢ² 大，σ_N² 小，大约等于 σ² / (Σᵢ xᵢ²)，斜率被卡得很紧。

在指定点做预测，要按 (20.2) 对 θ 积分。书中先写成

```
P(y | x, d) = ∫ P(y | x, d, θ) P(θ | x, d) dθ
            = ∫ P(y | x, θ) P(θ | d) dθ
            ∝ exp( −½ (y − θ_N x)² / (σ² + σ_N² x²) )
```

预测均值是 θ_N x，即用 θ 的后验均值。预测方差是模型噪声 σ² 加上与 x² 成正比的一项，所以预测的标准差随离开原点的距离渐近线性增长。图 20.7：模型过原点，固定噪声方差 **σ² = 0.2**，预测密度画出 ±1、±2、±3 个标准差的等值线。

- (a) 原点附近 **3** 个点，斜率相当不确定，**σ_N² ≈ 0.3861**。离观测点越远，不确定程度越大。
- (b) 再加 **2** 个更远的点，斜率 θ 被卡得很紧，**σ_N² ≈ 0.0286**。预测密度里剩下的方差几乎全来自固定噪声 σ²。

### 20.2.7 学习贝叶斯网络结构

到此都假定网络结构给定，只学参数。结构表示域中的基本因果知识，专家甚至外行常常容易提供。有时因果模型得不到或有争议——例如有公司长期声称吸烟不导致癌症，也有公司断言 CO₂ 浓度不影响气候——所以要知道结构如何从数据中学习。本节只勾勒主要想法。

最直接的是搜索好模型。可以从没有边的模型开始，给每个节点加父节点，用前面的方法拟合参数并衡量准确度。也可以从结构的一个初始猜测出发，用爬山或模拟退火修改结构，每次改完重新调参。修改包括反转、添加、删除边。过程中不能引入环，因此许多算法假定变量有一个序，节点的父节点只能来自序中更早的节点（与第 13 章的构造过程一样）。要完全一般，还得搜索可能的序。

判断「结构已经够好」有两条路。

第一条：检验结构所蕴含的条件独立断言在数据里是否成立。例如餐馆问题若用朴素贝叶斯，就假定

```
P(Hungry, Bar | WillWait) = P(Hungry | WillWait) P(Bar | WillWait)
```

可以检查数据里相应的条件频率是否满足同一等式。即便结构描述了域的真实因果本性，数据集的统计涨落也使等式不会精确成立，所以要做适当的统计检验，看是否有足够证据表明独立假设被违反。网络有多复杂取决于检验阈值：独立检验越严，加上的边越多，过拟合的危险越大。

更符合本章思路的第二条：评估所提模型在概率意义上对数据解释到什么程度。若只找最大似然假设，会得到**全连接**网络，因为给节点增加父节点不会降低似然（习题 20.MLPA）。必须用某种方式惩罚模型复杂度。MAP（或 MDL）在比较结构之前，从（调完参数后的）似然里减去一项惩罚。贝叶斯方法在结构和参数上放联合先验。结构数通常是变量个数的**超指数**，多到无法求和，实践中多用 MCMC 在结构上采样。

惩罚复杂度（无论 MAP 还是贝叶斯）把「最优结构」和「条件分布用什么表示」连在一起。表格分布下，一个节点的复杂度惩罚随父节点数指数增长；噪声或（noisy-OR）分布下只线性增长。因此用噪声或（或其他参数紧凑的模型）学习，得到的结构往往比用表格分布时有更多父节点。

### 20.2.8 用非参数模型做密度估计

采用 §19.7 的非参数方法，可以不假定结构与参数化形式就学习概率模型。**非参数密度估计**通常在连续域上进行。图 20.8(a) 是两个连续变量上的密度（其实是图 20.12(a) 那个高斯混合的三维图）。(b) 是从该密度抽出的 **128** 个点。问题是：能不能从样本恢复模型？

先看 **k 近邻**。第 19 章的近邻用于分类和回归，这里用于密度估计。要估计查询点 x 处的未知密度，就量 x 邻域里数据点有多密。图 20.8(b) 有两个查询点（小方块），各自画了包住 10 个邻居的最小圆（10-近邻邻域）。中间那个圆大，说明那里密度低；右边那个圆小，说明密度高。图 20.9 是不同 k 的密度估计：k = **3** 太尖，k = **40** 太滑，k = **10** 差不多合适。最好的 k 可用**交叉验证**选择。

也可以像局部加权回归那样用**核函数**。假定每个数据点生成一小团自己的密度，例如各轴标准差都是 w 的球形高斯。查询点 x 处的估计密度是这些数据核的平均：

```
P(x) = (1/N) Σⱼ K(x, xⱼ)

K(x, xⱼ) = 1 / (w² √(2π))^d · exp( − D(x, xⱼ)² / (2 w²) )
```

d 是 x 的维数，D 是欧氏距离。

> ⚠️ 待核（照录）：归一化因子按 PDF（书 p.737）写成 (w² √(2π))^d，上标 2 在 w 上。常见的各向同性高斯密度是 (w √(2π))^d。此处不改原文。

核宽 w 仍要选择。图 20.10 用 w = **0.02**、**0.07**、**0.20**：太小、差不多合适、太大。好的 w 同样用交叉验证选取。

## 20.3 隐变量学习：EM 算法（Learning with Hidden Variables: The EM Algorithm）

上一节是完全可观测的情形。许多真实问题有**隐变量**（hidden variable，有时称 latent variable），数据里观测不到。病历常有症状、医生诊断、治疗以及也许有治疗结果，却很少直接观测到疾病本身。注意：**诊断不是疾病**；诊断是观测症状的因果后果，而症状又由疾病引起。

若疾病观测不到，能否只用观测变量建模型？图 20.11 是一个虚构的小心脏病诊断网。三个可观测诱因，三个可观测症状（症状本身太丧，书中不命名）。每个变量三个取值（例如 none、moderate、severe）。

节点旁的数字是该条件分布的独立参数个数：

| 网络 | 计数 | 合计 |
|---|---|---|
| (a) 含隐变量 HeartDisease | 诱因 Smoking、Diet、Exercise 各 **2**；HeartDisease **54**；三个症状各 **6** | **78** |
| (b) 去掉 HeartDisease | 三个诱因仍各 **2**；三个症状为 **54、162、486** | **708** |

(b) 中症状在其父节点给定后**不再条件独立**。隐变量因此可以大幅减少指定一个贝叶斯网络所需的参数，从而大幅减少学这些参数所需的数据。

隐变量重要，但使学习变难。图 20.11(a) 里，既然每个病例都不知道 HeartDisease 的值，就不显然该如何学习它在父节点下的条件分布；症状的分布也一样。**期望最大化**（expectation–maximization, EM）以很一般的方式解决这个问题。下面三个例子，然后给一般形式。

### 20.3.1 无监督聚类：学习高斯混合

**无监督聚类**是在一组对象里辨认出多个类别，类别标签并不给出。例如记录十万颗恒星的光谱：光谱是否揭示出不同的恒星类型，有几种，特征是什么？「红巨星」「白矮星」这些名字不是恒星自己贴的，天文学家要做无监督聚类才能识别它们。其他例子包括林奈分类里的种、属、目、门，以及日常物体的自然类（第 10 章）。

图 20.12(b) 有 **500** 个数据点，每个点两个连续属性。点可以是恒星，属性可以是两个频率上的光谱强度。

聚类假定数据来自一个**混合分布** P。它有 k 个**分量**，每个分量自己是一个分布。生成一个点：先选分量，再从该分量抽样。C 表示分量，取值 1, …, k：

```
P(x) = Σᵢ₌₁ᵏ P(C = i) P(x | C = i)
```

连续数据的自然选择是多元高斯，得到**高斯混合**。参数是 wᵢ = P(C = i)（分量权重）、μᵢ（均值）、Σᵢ（协方差）。图 20.12(a) 是三个高斯的混合，权重从左到右为 **0.2、0.3、0.5**。它既是 (b) 中数据的来源，也是书 p.736 图 20.8(a) 的模型。

无监督聚类就是从图 20.12(b) 这样的原始数据恢复 (a) 那样的高斯混合。若知道每个点由哪个分量生成，恢复很容易：选出该分量的点，用 (20.4) 的多元版本拟合高斯（书 p.729）。若知道每个分量的参数，至少可以在概率意义上把点分到分量。

困难在于分配和参数都不知道。EM 在这里的基本想法是：假装已知模型参数，推断每个点属于每个分量的概率；然后重新拟合分量，每个分量对**整个**数据集拟合，点的权重是它属于该分量的概率。迭代至收敛。本质上是按当前模型推断隐变量（每个点属于哪个分量）的分布，从而「补全」数据。

混合参数任意初始化，然后反复做下面两步。不要把两步写反。

**E 步（期望步）**：计算 pᵢⱼ = P(C = i | xⱼ)，即数据点 xⱼ 由分量 i 生成的概率。由贝叶斯法则

```
pᵢⱼ = α P(xⱼ | C = i) P(C = i)
```

P(xⱼ | C = i) 是第 i 个高斯在 xⱼ 处的密度，P(C = i) 是第 i 个高斯的权重。定义 nᵢ = Σⱼ pᵢⱼ，即当前分到分量 i 的有效点数。E 步可以看成计算隐**指示变量** Zᵢⱼ 的期望值 pᵢⱼ：若 xⱼ 由第 i 个分量生成则 Zᵢⱼ = 1，否则为 0。

**M 步（最大化步）**：用 E 步的期望，按**下列顺序**计算新的均值、协方差和权重：

```
μᵢ  ← Σⱼ pᵢⱼ xⱼ / nᵢ
Σᵢ  ← Σⱼ pᵢⱼ (xⱼ − μᵢ)(xⱼ − μᵢ)ᵀ / nᵢ
wᵢ  ← nᵢ / N
```

N 是数据点总数。协方差用的是刚刚更新的 μᵢ。M 步寻找的是：在隐指示变量取其期望值的条件下，使数据对数似然最大的新参数。

图注：图 20.12(c) 是用 (b) 的数据由 EM 重建的模型，与生成数据的原始模型几乎无法区分。图 20.13(a) 画的是 EM 进行中、当前模型下数据对数似然 L 随迭代的变化；水平线是真模型的对数似然。

> ⚠️ 待核：正文写 EM 用于 “the data in Figure 20.12(a)”。图注则是 (a) 为三分量混合模型，(b) 为从 (a) 抽出的 500 个点，(c) 为用 (b) 重建的模型。笔记按图注。

有两点要注意。第一，最终学到的模型，其对数似然**略高于**生成数据的原始模型。这并不奇怪：数据是随机生成的，不必精确反映底层模型。第二，EM **每一次迭代都提高**数据的对数似然。这一点一般可证。并且在一定条件（多数情形成立）下，可以证明 EM 到达似然的**局部极大**。（罕见情形下可能到达鞍点，甚至局部极小。）

> ⚠️ 待核（照录两侧，不调和）：正文既说每步都提高对数似然，又说罕见时可能到达局部极小。笔记两句都保留。

从这个意义上 EM 像基于梯度的爬山，但没有「步长」参数。

事情不总像图 20.13(a) 那么顺利。一个高斯分量可能缩到只盖住一个点，方差趋于 0，似然趋于无穷。若不知道混合里有多少分量，就要试不同的 k，这本身是误差来源。两个分量还可能「合并」，均值和方差变得相同并共享数据点。这类退化的局部极大是严重问题，高维尤其如此。办法之一是给模型参数放先验，用 MAP 版的 EM。另一办法是分量变得太小或太靠近另一分量时，用新的随机参数重启它。合理的初始化也有帮助。

### 20.3.2 为隐变量学习贝叶斯网络的参数值

把高斯混合上奏效的想法用到含隐变量的贝叶斯网络。图 20.14(a) 是两袋糖混在一起。糖有三个特征：Flavor、Wrapper，以及中间有没有 Hole。每袋里的分布由一个朴素贝叶斯模型描述：给定袋子，特征独立（联合分布是一元分布的乘积，即给定袋子后相互独立），但每个特征的条件分布依赖于袋子。参数：

- θ：糖来自 Bag 1 的先验概率
- θ_{F1}、θ_{F2}：分别来自 Bag 1、Bag 2 时味道为 cherry 的概率
- θ_{W1}、θ_{W2}：糖纸为红的概率
- θ_{H1}、θ_{H2}：糖有孔的概率

整体是混合模型：两个不同分布的加权和，每个分布又是独立一元分布的乘积。（高斯混合也可以画成贝叶斯网络，见图 20.14(b)。）糖混在一起之后，不再知道每颗来自哪一袋，所以袋子是隐变量。只观察混合后的糖，能否恢复两袋的描述？

下面走一遍 EM 的一轮迭代。先看数据：从真参数已知的模型生成了 **1000** 个样本，真参数是

```
θ = 0.5
θ_{F1} = θ_{W1} = θ_{H1} = 0.8
θ_{F2} = θ_{W2} = θ_{H2} = 0.3          (20.9)
```

两袋等可能。第一袋大多是 cherry、红纸、有孔；第二袋大多是 lime、绿纸、无孔。八种糖的计数：

|  | 红纸、有孔 | 红纸、无孔 | 绿纸、有孔 | 绿纸、无孔 |
|---|---|---|---|---|
| cherry | 273 | 93 | 104 | 90 |
| lime | 79 | 100 | 94 | 167 |

八个数之和为 1000。

为数值简单，任意初始化（实践中更好是随机选取，以免对称性造成局部极大）：

```
θ⁽⁰⁾ = 0.6
θ⁽⁰⁾_{F1} = θ⁽⁰⁾_{W1} = θ⁽⁰⁾_{H1} = 0.6
θ⁽⁰⁾_{F2} = θ⁽⁰⁾_{W2} = θ⁽⁰⁾_{H2} = 0.4     (20.10)
```

先看 θ。若完全可观测，就直接用袋 1、袋 2 的观测计数估计。袋子是隐变量，所以改用**期望**计数。期望计数 N̂(Bag = 1) 是每颗糖来自袋 1 的概率之和：

```
θ⁽¹⁾ = N̂(Bag = 1) / N
     = Σⱼ P(Bag = 1 | flavorⱼ, wrapperⱼ, holesⱼ) / N
```

这些概率可用任何贝叶斯网络推断算法计算。本例是朴素贝叶斯，可以用贝叶斯法则加条件独立手算：

```
θ⁽¹⁾ = (1/N) Σⱼ
  [P(flavorⱼ|Bag=1) P(wrapperⱼ|Bag=1) P(holesⱼ|Bag=1) P(Bag=1)]
  / Σᵢ [P(flavorⱼ|Bag=i) P(wrapperⱼ|Bag=i) P(holesⱼ|Bag=i) P(Bag=i)]
```

对 273 颗「红纸、有孔、cherry」的贡献是

```
(273/1000) · (θ⁽⁰⁾_{F1} θ⁽⁰⁾_{W1} θ⁽⁰⁾_{H1} θ⁽⁰⁾)
           / (θ⁽⁰⁾_{F1} θ⁽⁰⁾_{W1} θ⁽⁰⁾_{H1} θ⁽⁰⁾
              + θ⁽⁰⁾_{F2} θ⁽⁰⁾_{W2} θ⁽⁰⁾_{H2} (1−θ⁽⁰⁾))
≈ 0.22797
```

代入 (20.10)：分子 0.6⁴ = 0.1296，分母 0.1296 + 0.4⁴ = 0.1552，273/1000 × 0.1296/0.1552 ≈ 0.22797。对其余七种继续做，得到 θ⁽¹⁾ = **0.6124**。

其他参数同样。完全可观测时，θ_{F1} 直接由袋 1 中 cherry 与 lime 的观测计数估计。袋 1 中 cherry 的期望计数是

```
Σ_{j : Flavorⱼ = cherry} P(Bag = 1 | Flavorⱼ = cherry, wrapperⱼ, holesⱼ)
```

做完得到全部新参数 (20.11)：

```
θ⁽¹⁾     = 0.6124
θ⁽¹⁾_{F1} = 0.6684    θ⁽¹⁾_{W1} = 0.6483    θ⁽¹⁾_{H1} = 0.6558
θ⁽¹⁾_{F2} = 0.3887    θ⁽¹⁾_{W2} = 0.3817    θ⁽¹⁾_{H2} = 0.3827
```

数据的对数似然从起初约 **−2044** 升到第一轮之后约 **−2021**（图 20.13(b)）。似然本身大约提高 **e²³ ≈ 10¹⁰** 倍。到第 **10** 轮，学到的模型已经比原始模型拟合更好（**L = −1982.214**）。此后进展很慢。EM 常这样；许多实用系统在学习的最后阶段把 EM 与牛顿–拉弗森法等基于梯度的算法（第 4 章）结合起来。

本例的一般教训：含隐变量的贝叶斯网络，参数更新**直接来自对每个例子做推断的结果**；而且每个参数只需要**局部**后验概率。这里「局部」指变量 Xᵢ 的条件概率表可以从只涉及 Xᵢ 及其父节点 Uᵢ 的后验得到。令 θᵢⱼₖ = P(Xᵢ = xᵢⱼ | Uᵢ = uᵢₖ)，更新是归一化的期望计数：

```
θᵢⱼₖ ← N̂(Xᵢ = xᵢⱼ, Uᵢ = uᵢₖ) / N̂(Uᵢ = uᵢₖ)
```

期望计数是对例子求和，每个例子用任意贝叶斯网络推断算法算 P(Xᵢ = xᵢⱼ, Uᵢ = uᵢₖ)。对精确算法（包括变量消元），这些概率是标准推断的副产品，不需要为学习另做计算。学习所需的信息对每个参数都是局部可得的。

退后一步：这个例子是从数据里 7 个（**2³ − 1**）观测计数恢复 7 个参数（θ、θ_{F1}、θ_{W1}、θ_{H1}、θ_{F2}、θ_{W2}、θ_{H2}）。第八个计数由「计数之和为 1000」固定。若每颗糖只有两个属性（比如去掉孔），就会有 5 个参数（θ、θ_{F1}、θ_{W1}、θ_{F2}、θ_{W2}），但只有 3 个（**2² − 1**）观测计数。这时恢复不了混合权重 θ，也恢复不了两袋各自的特征。两个属性的模型**不可辨识**。

贝叶斯网络里的可辨识性很棘手。即便有三个属性和七个计数，也不能唯一恢复模型：把 Bag 对调，存在两个观测上等价的模型。参数怎么初始化，EM 会收敛到「袋 1 大多 cherry、袋 2 大多 lime」，或正好相反。从未被观测的变量，这种不可辨识性无法避免。

### 20.3.3 学习隐马尔可夫模型

EM 的最后一个应用是学习隐马尔可夫模型（HMM）的转移概率。§14.3 说过，HMM 可以表示成只有一个离散状态变量的动态贝叶斯网络（图 20.15，即图 14.16 的重复）。每个数据点是一段有限长的观测序列。任务是从一组观测序列（或仅仅一条长序列）学习转移概率。

贝叶斯网络的学法已经见过，但有一处不同：贝叶斯网络里每个参数是分开的；HMM 里，时刻 t 从状态 i 到状态 j 的转移概率 θᵢⱼₜ = P(X_{t+1} = j | X_t = i) 沿时间重复，即对所有 t 有 θᵢⱼₜ = θᵢⱼ。估计从 i 到 j 的转移概率，就是计算「系统处于 i 时转移到 j」的期望比例：

```
θᵢⱼ ← Σₜ N̂(X_{t+1} = j, X_t = i) / Σₜ N̂(X_t = i)
```

期望计数由 HMM 推断算法计算。图 14.4 的前向–后向算法很容易改成计算所需概率。要点是：这些概率来自**平滑**，不是**滤波**。滤波给出的是给定过去之后当前状态的分布；平滑给出的是给定**全部**证据的分布，包括某次转移发生**之后**的情况。谋杀案的证据通常在犯罪（从状态 i 转移到 j）之后才得到。

### 20.3.4 EM 算法的一般形式

前面每个例子都是：对每个例子计算隐变量的期望，再把期望值当作观测值去重算参数。令 x 为所有例子中的全部观测值，Z 为所有例子的全部隐变量，θ 为概率模型的全部参数。EM 是

```
θ^{(i+1)} = argmax_θ  Σ_z  P(Z = z | x, θ^{(i)}) L(x, Z = z | θ)
```

这就是 EM 的全部。**E 步**是那个求和：在后验 P(Z = z | x, θ^{(i)})——给定数据后隐变量的后验，用的是**当前**参数 θ^{(i)}——之下，对「补全数据」的对数似然取期望。**M 步**是关于参数最大化这个期望对数似然。

- 高斯混合：隐变量是 Zᵢⱼ，样本 j 由分量 i 生成时为 1
- 贝叶斯网络：Zᵢⱼ 是样本 j 中未观测变量 Xᵢ 的取值
- HMM：Zⱼₜ 是样本 j 在时刻 t 的状态

一旦认清一般想法，变体就容易导出。许多情形 E 步（隐变量后验）不可处理，例如大型贝叶斯网络。可以用近似的 E 步，仍然得到有效的学习算法。用 MCMC 之类的采样（§13.4）时，学习过程很直观：MCMC 访问到的每个状态（隐变量与观测变量的一个配置）都**恰好当作一次完整观测**，于是每次 MCMC 转移之后就可以直接更新参数。变分方法、有环信念传播等其他近似推断，对学习很大的网络也有效。

### 20.3.5 含隐变量的贝叶斯网络结构学习

§20.2.7 讨论的是完整数据下的结构学习。未观测变量影响观测数据时，事情更难。最简单的情形：人类专家告诉算法某些隐变量存在，由算法在结构里给它们找位置。例如，告知 HeartDisease（三值变量）应纳入模型，算法尝试学习书 p.738 图 20.11(a) 的结构。与完整数据时一样，外层循环搜索结构，内层循环在给定结构下拟合参数。

若算法没有被告知哪些隐变量存在，有两个选择：要么假装数据其实是完整的——这可能迫使它学出图 20.11(b) 那种参数很多的模型；要么发明新的隐变量来简化模型。后一条可以在结构搜索里增加新的修改动作：除了改边，还可以添加或删除一个隐变量，或改变它的元数（取值个数）。算法不会知道新变量该叫 HeartDisease，也不会给取值起有意义的名字。新发明的隐变量通常会连到已有变量上，人类专家往往可以检查涉及新变量的局部条件分布，从而弄清它的含义。

与完整数据时一样，纯最大似然的结构学习会得到全连接网络（而且没有隐变量），所以需要某种复杂度惩罚。也可以用 MCMC 采样许多可能的网络结构，从而近似贝叶斯学习。例如，分量个数未知的高斯混合，可以对个数采样；高斯个数的近似后验由 MCMC 的采样频率给出。

完整数据时，内层学参数非常快——只是从数据集抽取条件频率。有隐变量时，内层可能要许多轮 EM 或基于梯度的算法，每一轮都要在贝叶斯网络里算后验，而这本身是 NP 难问题。迄今，用这条路学习复杂模型已被证明不实用。

一种可能的改进是**结构 EM**。它与普通（参数）EM 大体相同，只是算法可以同时更新结构和参数。普通 EM 在 E 步用当前参数计算期望计数，再在 M 步用这些计数选择新参数；结构 EM 用**当前结构**计算期望计数，再在 M 步用这些计数评估潜在新结构的似然。（这与外层/内层方法不同：后者对每个潜在结构都重新计算期望计数。）因此结构 EM 可以在一次也不重算期望计数的情况下，对网络做若干次结构改动，并能够学习非平凡的贝叶斯网络结构。它的搜索空间是结构空间，而不是「结构 × 参数」的空间。尽管如此，要说结构学习问题已经解决，还有很多工作要做。

## 小结

统计学习从简单的求平均，一直到构造贝叶斯网络这类复杂模型。应用遍及计算机科学、工程、计算生物学、神经科学、心理学和物理学。本章给出基本想法和数学基础的味道。要点：

1. **贝叶斯学习**把学习表述为概率推断，用观测更新假设上的先验分布。这是实现奥卡姆剃刀的好办法，但复杂假设空间上很快变得不可处理。
2. **最大后验（MAP）**选出给定数据后单个最可能的假设。仍使用假设先验，通常比完整贝叶斯学习更好处理。
3. **最大似然**选出使数据似然最大的假设，等价于均匀先验下的 MAP。线性回归、完全可观测的贝叶斯网络等简单情形，最大似然解有闭式。朴素贝叶斯特别有效，而且扩展性好。
4. 有些变量隐藏时，**期望最大化（EM）**可以找到局部最大似然解。应用包括用高斯混合做无监督聚类、学习贝叶斯网络、学习隐马尔可夫模型。
5. 学习贝叶斯网络的结构是**模型选择**的一个例子。通常是在结构空间里做离散搜索。需要某种方法在模型复杂度与拟合程度之间折中。
6. **非参数模型**用数据点的集合表示分布，参数个数随训练集增长。近邻方法看离查询点最近的例子；核方法对所有例子做距离加权组合。

统计学习仍是非常活跃的研究领域。理论和实践都有巨大进展，以至于只要精确或近似推断可行，几乎任何模型都可以学习。

原书注释里与正文直接相关的历史线索：

- 统计学习在 AI 早期就活跃（Duda and Hart, 1973），后来因主流 AI 转向符号方法而分离。贝叶斯网络在 1980 年代末引入后兴趣回升；大约同时，神经网络学习的统计观点出现。1990 年代末，机器学习、统计学与神经网络在「从数据建立大型概率模型」上汇合。
- 朴素贝叶斯是最老、最简单的贝叶斯网络形式之一，可追溯到 1950 年代（起源见第 12 章）。Domingos and Pazzani (1997) 部分解释了它为何出奇地成功。提升的朴素贝叶斯赢得第一届 KDD Cup（Elkan, 1997）。Heckerman (1998) 是贝叶斯网络学习的优秀导论。用狄利克雷先验做贝叶斯参数学习见 Spiegelhalter et al. (1993)。贝塔分布作为伯努利变量的共轭先验，最早由 Thomas Bayes (1763) 导出，后由 Karl Pearson (1895) 重新引入，长期称为 “Pearson Type I distribution”。贝叶斯线性回归见 Box and Tiao (1973)；Minka (2010) 概括了一般多元情形的推导。
- 带贝叶斯网络的统计学习软件：BUGS（Gilks et al., 1994; Lunn et al., 2000, 2013）、JAGS（Plummer, 2003）、STAN（Carpenter et al., 2017）。
- 最早的结构学习算法用条件独立检验（Pearl, 1988; Pearl and Verma, 1991）。Spirtes et al. (1993) 在 TETRAD 里实现了完整途径。此后的算法改进使一种贝叶斯网络学习方法在 2001 年 KDD Cup 胜出（Cheng et al., 2002）；该任务是有 **139,351** 个特征的生物信息学问题。基于最大化似然的结构学习由 Cooper and Herskovits (1992) 提出，Heckerman et al. (1994) 改进。完整数据情形下较像样的性能见 Moore and Wong (2003)、Teyssier and Koller (2005)。AD-tree 用来缓存所有变量与取值组合的计数（Moore and Lee, 1997）。Friedman and Goldszmidt (1996) 指出局部条件分布的表示会影响学到的结构。
- 含隐变量与缺失数据的一般学习问题：Hartley (1958) 描述了后来称为 EM 的想法并给了若干例子。HMM 学习的 Baum–Welch 算法（Baum and Petrie, 1966）是 EM 的特例。Dempster, Laird, and Rubin (1977) 给出一般形式并分析收敛，是计算机科学和统计学里引用最多的论文之一。（Dempster 本人把 EM 看成模式而非算法，因为用到新的分布族之前往往还要做不少数学工作。）McLachlan and Krishnan (1997) 用一整本书讨论该算法。混合模型（含高斯混合）见 Titterington et al. (1985)。
- AI 内部：AUTOCLASS（Cheeseman et al., 1988; Cheeseman and Stutz, 1996）是第一个成功用 EM 做混合建模的系统，用于从光谱发现新类型恒星（Goebel et al., 1989），以及在 DNA/蛋白质序列库中发现新的蛋白质类和内含子（Hunter and States, 1992）。含隐变量的贝叶斯网络最大似然参数学习：Lauritzen (1995) 与 Russell et al. - 学到的贝叶斯网络结构能否表示真实因果影响：统计学家长期回避这个问题，认为观测数据（相对于实验产生的数据）只能给出相关信息——两个看起来相关的变量，可能是被第三个未知因素影响，而不是彼此直接影响。Pearl (2000) 论证许多情形下因果可以被确定，并发展因果网络形式体系，以表达原因、干预的效果以及普通的条件概率。
- 非参数密度估计也称 Parzen 窗密度估计，最初由 Rosenblatt (1956) 与 Parzen (1962) 研究；导论见 Devroye (1987)。非参数贝叶斯方法源于 Ferguson (1973) 的**狄利克雷过程**（可看成狄利克雷分布上的分布），对分量个数未知的混合特别有用。教程见 Ghahramani (2005)、Jordan (2005)。Rasmussen and Williams (2006) 讲**高斯过程**，用来在连续函数空间上定义先验。

(2001)。NeurIPS（原 NIPS）的论文集 *Advances in Neural Information Processing Systems*，以及 Artificial Intelligence and Statistics 会议，都有许多贝叶斯学习论文。专门的贝叶斯场所包括 Valencia International Meetings on Bayesian Statistics 和期刊 *Bayesian Analysis*。
