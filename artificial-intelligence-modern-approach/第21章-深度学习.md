## 0. 本章要解决的问题

第 19 章的线性回归、逻辑斯谛回归，计算路径很短：每个输入乘一个权重再加进输出，输入之间不交互（图 21.1(a)），只能表示输入空间里的线性函数和线性边界。决策表和决策树可以有很长的计算路径，但只覆盖一小部分可能的输入向量（图 21.1(b)）；若相当比例的输入都要走长路径，树的规模对输入个数是指数的。

深度学习把假设写成**带可调连接强度的复杂代数电路**，并且通常分成很多**层（layer）**，使从输入到输出的路径有很多步，从而让全部输入变量以复杂方式交互（图 21.1(c)）。用梯度下降去学这种多步程序。这些电路常被称为**神经网络（neural network）**，但和真实神经细胞的相似只是表面的；源头是 McCulloch and Pitts (1943) 用计算电路模拟脑内神经元网络。

原书点名的应用：视觉目标识别、机器翻译、语音识别、语音合成、图像合成；强化学习里也占重要地位（第 22 章）。成功原因尚未完全讲清。

## 21.1 简单前馈网络（Simple Feedforward Networks）

**前馈网络（feedforward network）**的连接只有一个方向：带指定输入节点和输出节点的有向无环图。每个节点计算其输入的函数，把结果传给后继。信息从输入流到输出，没有环。

**循环网络（recurrent network）**把中间或最终输出送回自己的输入，网络内部的信号构成有内部状态（记忆）的动力系统。放到 21.6。

布尔电路是前馈网络的一例：输入只取 0 和 1，每个节点实现简单布尔函数，输出也只是 0 或 1。神经网络的输入通常是连续的，节点吃连续输入、产连续输出。节点的一部分输入是网络参数；学习就是调这些参数，使整个网络拟合训练数据。

### 21.1.1 作为复杂函数的网络

网络里的节点叫**单元（unit）**。沿 McCulloch–Pitts 的设计，单元先对前驱输出做加权和，再过一个非线性函数。记 `aⱼ` 为单元 `j` 的输出，`wᵢ,ⱼ` 为从单元 `i` 到单元 `j` 的权重，则

```
aⱼ = gⱼ( Σᵢ wᵢ,ⱼ aᵢ ) ≡ gⱼ(inⱼ)
```

`gⱼ` 是单元 `j` 的非线性**激活函数（activation function）**，`inⱼ` 是加权输入和。

与 19.6.3（书页 679）一样：每个单元还有来自**虚单元 0** 的额外输入，该单元固定为 `+1`，对应权重 `w₀,ⱼ`。这样即使前一层输出全是 0，`inⱼ` 仍可以非零。向量形式：

```
aⱼ = gⱼ(w⊤ x)                                          (21.1)
```

`w` 是进入单元 `j` 的权重向量（含 `w₀,ⱼ`），`x` 是输入向量（含 `+1`）。

激活必须非线性。若不然，单元的任意复合仍是线性函数。足够大的单元网络能表示任意函数。**万能逼近定理（universal approximation theorem）**：只有两层计算单元、第一层非线性、第二层线性的网络，可以把任意连续函数逼近到任意精度。证明思路是：指数大的网络能在输入空间的不同位置放上指数多个不同高度的“凸起”，从而逼近目标函数。换言之，足够大的网络可以实现连续函数的查找表，正如足够大的决策树实现布尔函数的查找表。

常用激活函数（图 21.2）：

- **逻辑斯谛 / sigmoid**：

```
σ(x) = 1 / (1 + e^(−x))
```

也用于逻辑斯谛回归（书页 685）。

- **ReLU**（rectified linear unit，整流线性单元）：

```
ReLU(x) = max(0, x)
```

- **softplus**，ReLU 的平滑版：

```
softplus(x) = log(1 + e^x)
```

softplus 的导数就是 sigmoid。

- **tanh**：

```
tanh(x) = (e^(2x) − 1) / (e^(2x) + 1)
```

值域是 `(−1, +1)`。它是 sigmoid 的缩放平移：`tanh(x) = 2σ(2x) − 1`。

这四个函数都单调不减，导数 `g′` 非负。

多个单元耦合成的网络，是各单元代数式的复合。图 21.3(a) 是两个输入、一个隐藏层两个单元、一个输出单元（虚输入及其权重未画出）。它表示由权重 `w` 参数化的函数 `h_w(x)`，把二维输入映到标量 `ŷ`。把输出展开（单元 5 为输出，单元 3、4 为隐藏单元）：

```
ŷ = g₅(in₅)
  = g₅(w₀,₅ + w₃,₅ a₃ + w₄,₅ a₄)
  = g₅(w₀,₅ + w₃,₅ g₃(in₃) + w₄,₅ g₄(in₄))
  = g₅(w₀,₅ + w₃,₅ g₃(w₀,₃ + w₁,₃ x₁ + w₂,₃ x₂)
             + w₄,₅ g₄(w₀,₄ + w₁,₄ x₁ + w₂,₄ x₂))     (21.2)
```

于是 `ŷ` 写成输入与权重的函数 `h_w(x)`。

图 21.3(a) 是传统画法。更一般的看法是**计算图（computation graph）**或**数据流图（dataflow graph）**：每个节点是一次初等计算。图 21.3(b) 把 (a) 拆开，并区分输入（蓝色）和权重（浅紫色）。每个权重像一个音量旋钮，决定下一节点从该前驱听到多少。调权重，使 `ŷ` 更接近训练数据里的真值 `y`。

整网也可以写成矩阵形式。`W⁽¹⁾` 是第一层权重（`w₁,₃`、`w₁,₄` 等），`W⁽²⁾` 是第二层权重（`w₃,₅` 等），`g⁽¹⁾`、`g⁽²⁾` 是两层的激活函数：

```
h_w(x) = g⁽²⁾( W⁽²⁾ g⁽¹⁾( W⁽¹⁾ x ) )                 (21.3)
```

这仍是一条计算图，只是比图 21.3(b) 简单：权重矩阵依次送进各层。

图 21.3(b) 又小又浅，但做法通用：造计算图，调权重去拟合数据。该图还是**全连接（fully connected）**的：每一层的每个节点都连到下一层的每个节点。这是默认接法；21.3 会说明，连接模式本身也决定学得好不好。

### 21.1.2 梯度与学习

19.6 的监督做法是梯度下降：对权重求损失函数的梯度，沿梯度方向改权重以减小损失。未读 19.6 的话，原书建议先读再继续。同一做法用于计算图。连到**输出层（output layer）**的权重，梯度算法与 19.6 本质相同；连到**隐藏层（hidden layer）**（不直接连输出）的权重只稍复杂一点。

先用平方损失 `L₂`，对图 21.3 的**单个**训练例 `(x, y)` 求梯度。多个例子时，梯度是各例梯度之和。网络给出 `ŷ = h_w(x)`，真值是 `y`：

```
Loss(h_w) = L₂(y, h_w(x)) = ‖y − h_w(x)‖² = (y − ŷ)²
```

工具是第 19 章的链式法则：

```
∂g(f(x)) / ∂x = g′(f(x)) · ∂f(x) / ∂x
```

先看直接连到输出的权重 `w₃,₅`。从 (21.2) 出发：

```
∂Loss/∂w₃,₅
  = ∂(y − ŷ)² / ∂w₃,₅
  = −2(y − ŷ) · ∂ŷ/∂w₃,₅
  = −2(y − ŷ) · g′₅(in₅) · ∂in₅/∂w₃,₅
  = −2(y − ŷ) · g′₅(in₅) · a₃                      (21.4)
```

最后一步成立，是因为 `w₀,₅` 和 `w₄,₅ a₄` 都不依赖 `w₃,₅`，而 `w₃,₅` 的系数 `a₃` 也不依赖 `w₃,₅`。

再看不直接连输出的 `w₁,₃`，链式法则要多用一次。开头几步与上面相同，略去后：

```
∂Loss/∂w₁,₃
  = −2(y − ŷ) g′₅(in₅) · ∂(w₀,₅ + w₃,₅ a₃ + w₄,₅ a₄)/∂w₁,₃
  = −2(y − ŷ) g′₅(in₅) · w₃,₅ · ∂a₃/∂w₁,₃
  = −2(y − ŷ) g′₅(in₅) · w₃,₅ · g′₃(in₃) · ∂in₃/∂w₁,₃
  = −2(y − ŷ) g′₅(in₅) · w₃,₅ · g′₃(in₃) · x₁      (21.5)
```

定义输出单元 5 处的“感知误差”

```
Δ₅ = 2(ŷ − y) g′₅(in₅)
```

注意 `−2(y − ŷ) = 2(ŷ − y)`，所以对 `w₃,₅` 的梯度就是 `Δ₅ a₃`。`g′` 恒非负，因此 `Δ₅ > 0` 意味着 `ŷ` 太大。此时若 `a₃ > 0`，增大 `w₃,₅` 只会更糟；若 `a₃ < 0`，增大 `w₃,₅` 会减小误差。`a₃` 的大小也有关：本例上 `a₃` 很小，说明 `w₃,₅` 对这次误差贡献不大，不必大改。

再定义

```
Δ₃ = Δ₅ · w₃,₅ · g′₃(in₃)
```

则对 `w₁,₃` 的梯度就是 `Δ₃ x₁`。单元 3 输入处的感知误差，等于单元 5 输入处的感知误差乘上从 5 回到 3 的路径信息。这件事是普遍的，所以把输出端的误差往回送的做法叫**反向传播（back-propagation）**。

这些梯度表达式都含局部导数 `g′ⱼ(inⱼ)`。它们非负，但可以非常接近 0（sigmoid、softplus、tanh 的平坦工作区），或恰好为 0（ReLU）。导数很小或为 0 时，改变进入单元 `j` 的权重几乎不影响它的输出。层数很多时，误差信号在回传中被完全熄灭，这就是**梯度消失（vanishing gradient）**。21.3.3 给出一种处理办法。

这个小网络的梯度，是把信息从输出单元往回送算出来的。任意前馈计算图都如此：梯度计算的结构与底层计算图相同，直接来自求导法则。不必为每个新结构重推 (21.4)(21.5)。**自动微分（automatic differentiation）**对任何数值程序系统套用微积分法则。深度学习里的反向传播就是**反向模式（reverse mode）**微分：链式法则“从外向里”用，在输入多、输出少时拿到动态规划式的效率。主要深度学习软件包都提供自动微分，因此可以自由试结构、激活、损失和复合方式。这鼓励了**端到端学习（end-to-end learning）**：机器翻译这类任务可以由若干可训练子系统拼成，整个系统用输入/输出对一起训练。设计者只需对总体结构有个大致想法，不必事先规定每个子系统做什么、也不必给它的输入输出打标签。

自动微分本身在 1960–1970 年代就用于优化大型 Fortran 程序定义的系统参数。

## 21.2 深度学习的计算图（Computation Graphs for Deep Learning）

假设是带可调权重的计算图，对权重求损失梯度来拟合数据。下面按输入层、输出层、隐藏层来拼图。

### 21.2.1 输入编码

输入、输出节点直接连到数据 `x` 和 `y`。因子化数据（每个训练例有 `n` 个输入属性）的编码通常直接：

| 属性 | 编码 |
|---|---|
| 布尔 | `n` 个输入节点。通常假→0、真→1；有时用 −1 和 +1 |
| 数值（整数或实数） | 通常原样使用；可缩放到固定范围；各例数量级差得极大时可映到对数尺度 |
| 图像 | 不能简单当成因子向量，见下 |
| 多于二值的类别 | **独热编码（one-hot encoding）** |

`X×Y` 的 RGB 图像可以看成 `3XY` 个整数值属性（通常取值 `{0, …, 255}`），但这丢掉了两件事：同一像素的 RGB 三元组属于一起，以及像素相邻性真正重要。把相邻像素映到相邻输入节点，若内部层全连接，相邻性的含义就完全消失。实际用于图像的网络，内部做成阵列结构来反映相邻性（21.3）。

类别属性，例如第 19 章餐馆问题的 Type，取值 French、Italian、Thai、burger。有 `d` 个可能值就用 `d` 个输入位：当前值对应位为 1，其余为 0。这优于把取值映成整数。若 Type 用整数，Thai 会是 3、burger 会是 4。网络是连续函数的复合，只好去注意数值上的相邻，而 Thai 与 burger 的数值相邻没有语义。

### 21.2.2 输出层与损失函数

把原始输出编成图上输出节点的 `y`，与输入编码同类。例如预测第 12 章的 Weather，取值 `{sun, rain, cloud, snow}`，就用四位独热。

理想情况下预测 `ŷ` 正好等于 `y`，损失为 0。调权重之前这很少发生。要定义“错的输出”怎么度量。(21.4)(21.5) 用的是平方误差，代数简单，但不是唯一选择。多数深度学习应用把 `ŷ` 解释成概率，用**负对数似然**作损失，与第 20 章的最大似然学习相同。

最大似然找使观测数据概率最大的 `w`。log 单调，所以等价于最大化对数似然，也等价于最小化负对数似然。（书页 725：取对数把概率的乘积变成和，便于求导。）也就是找 `w*`，使 `N` 个例子的负对数概率之和最小：

```
w* = argmin_w  Σ_{j=1}^{N} ( − log P_w(yⱼ | xⱼ) )       (21.6)
```

深度学习文献常说最小化**交叉熵（cross-entropy）**损失。`H(P, Q)` 度量两个分布的不相似。印刷的一般定义是：

```
H(P, Q) = E_{z∼P(z)}[ log Q(z) ] = ∫ P(z) log Q(z) dz   (21.7)
```

> ⚠️ 待核：式 (21.7) 的期望和积分都没有负号。同页脚注却写 `H(P, Q) = H(P) + D_KL(P∥Q)`，并说 `H(P, P)` 等于熵 `H(P)` 而不是 0，因此交叉熵不是通常意义的距离；`D_KL(P∥P) = 0`，故 `P` 固定时，改变 `Q` 去最小化交叉熵也最小化 KL 散度。后面 (21.17) 的推导把熵写成 `H(Q) = −∫ Q log Q`。按脚注和这套熵，交叉熵应是 `−E[log Q]`，最小化才和“让假设贴近真实分布”同向。此处照录印刷式，不改号。

机器学习里通常令 `P` 为训练例上的真实分布 `P*(x, y)`，`Q` 为预测假设 `P_w(y|x)`。书中说调 `w` 去最小化 `H(P*(x, y), P_w(y|x))`，是让假设尽量贴近真实分布。这个方向只在交叉熵带负号时成立；印刷的 (21.7) 没有负号，见上一条待核。我们没有 `P*` 本身，只有来自 `P*` 的样本，所以 (21.6) 对实际数据的求和近似 (21.7) 里的期望。

要把网络输出解释成概率：

- **布尔分类**：一个 sigmoid 输出单元，输出值直接当作属于正类的概率。这正是逻辑斯谛回归的用法（书页 684）。布尔分类常用 sigmoid 输出层。
- **多类分类**：目标识别常要认几千类；预测下一词可能要在几万个词里选。需要输出范畴分布：`d` 个答案就有 `d` 个输出节点，概率和为 1。用 **softmax** 层。输入 `in = ⟨in₁, …, in_d⟩`，第 `k` 个输出为

```
softmax(in)_k = e^(in_k) / Σ_{k′=1}^{d} e^(in_k′)
```

由构造，输出是非负且和为 1 的向量。每个 `in_k` 仍是前一层输出的加权线性组合。指数会放大输入差异。例如 `in = ⟨5, 2, 0, −2⟩` 时，输出为 `⟨0.946, 0.047, 0.006, 0.001⟩`。softmax 光滑可微（习题 21.SOFG），与 max 不同。sigmoid 就是 `d = 2` 的 softmax（习题 21.SMSG）：sigmoid 单元在网中传递二类信息，softmax 单元传递多类信息。

- **回归**（`y` 连续）：常用线性输出层，即 `ŷⱼ = inⱼ`，没有激活 `g`。把它解释成固定方差高斯预测的均值。书页 729：固定方差高斯下最大化似然（即最小化负对数似然）等于最小化平方误差。因此这样解释的线性输出层就是经典线性回归，只是回归的输入特征是前一层的输出，而前一层通常已经对原始输入做了多次非线性变换。

还可以有别的输出层。**混合密度（mixture density）**层用高斯混合表示输出（高斯混合见 20.3.1）：预测每个成分的相对频率、均值和方差。只要损失函数按这些输出正确给出真值 `y` 的概率，训练后的网络就在前几层所定义的特征空间里拟合一个高斯混合。

### 21.2.3 隐藏层

训练时网络看到许多 `x` 和对应的 `y`。处理 `x` 时，产出 `y` 之前有若干中间计算。每一层的值可以看成 `x` 的另一种表示；每一层把前一层的表示变成新表示。这些变换的复合，若顺利，就把输入变成所需输出。一种解释是：从图像到类别“giraffe”这种复杂的端到端变换，被很多层拆成许多相对简单、可以用局部更新学会的变换。

内部表示有时有意义：识别复杂物体的网络，中间层可能检测边、角、椭圆、眼睛、脸，直到猫。也可能对人类不透明，而输出仍然正确。

隐藏层的花样通常少于输出层。多层网络研究的前 25 年（大约 1985–2010）内部节点几乎只用 sigmoid 和 tanh。大约 2010 年起 ReLU 和 softplus 更流行，部分原因是认为它们能避开 21.1.2 的梯度消失。对越来越深的网络做实验后，在权重总数固定时，很多情况下又深又相对窄的网络比又浅又宽的更好。典型例子是书页 769 的图 21.7。

除了宽度和深度，计算图还有许多别的结构。写作时，人们几乎不理解为什么某些结构对某些问题更好。从业者靠经验获得设计直觉，也靠经验在网络不工作时修理它，像厨师对菜谱一样。因此，能快速探索和评估不同结构的工具，对真实问题是必需的。

## 21.3 卷积网络（Convolutional Networks）

图像不能看成像素值的简单向量，首先因为像素相邻性重要。全连接层加图像输入时，像素随机打乱后再训练，结果会一样。设有 `n` 个像素、第一隐藏层有 `n` 个单元，二者全连接就是 `n²` 个权重。原书说，典型的百万像素 RGB 图像对应 **9 万亿**个权重。如此大的参数空间需要相应巨大的训练图像量和计算预算。

因此第一隐藏层的每个隐藏单元只应从图像的一小块局部区域取输入。这同时做两件事：至少在局部尊重相邻性（若后续层也局部，网络就在全局意义上尊重相邻性）；以及减少权重。若每个局部区域有 `l ≪ n` 个像素，权重总数是 `ln ≪ n²`。

> ⚠️ 待核：上文是 `n` 个像素、`n` 个隐藏单元、`n²` 个权重。百万像素的 `n²` 是 `10¹²`。原文接着写百万像素 RGB 为 9 万亿个权重，与把三通道计入后 `(3×10⁶)² = 9×10¹²` 一致。笔记照录 9 万亿，不把 `n` 改写成 `3n`。

还缺一条图像性质：在一小块区域里能检测到的东西（一只眼、一片草叶），出现在另一小块区域时看起来大致相同。图像数据在小到中等尺度上应表现出近似的**空间不变性（spatial invariance）**。我们并不期望照片上半部分看起来像下半部分，所以超过某个尺度后空间不变性不再成立。时间序列（如音频）有类似的**时间不变性**：一个词无论在一天中的何时说出，听起来相同。循环网络（21.6）自动带有时间不变性。

局部空间不变性的做法：把连接一块局部区域与一个隐藏单元的 `l` 个权重，约束成对每个隐藏单元都相同。即对隐藏单元 `i` 和 `j`，`w₁,ᵢ, …, wₗ,ᵢ` 与 `w₁,ⱼ, …, wₗ,ⱼ` 相同。隐藏单元就成了**特征检测器**，同一特征出现在图像何处都能检测。

第一隐藏层通常要检测多种特征，不只一种。每个局部区域可以有 `d` 个隐藏单元、`d` 套不同权重。权重总数是 `dl`：远小于 `n²`，而且与图像尺寸 `n` 无关。注入相邻性和空间不变性这些先验之后，模型参数少得多，学得快得多。

**卷积神经网络（convolutional neural network, CNN）**至少在早层具有空间局部连接，并且每一层里有在单元之间复制的权重模式。在多个局部区域复制的那套权重叫**核（kernel）**；把核作用到图像像素（或后续层里空间排列的单元）上叫**卷积（convolution）**。信号处理里这个运算应叫互相关（cross-correlation），神经网络领域沿用“卷积”这个名字。

核与卷积先在一维讲。输入向量 `x` 长度为 `n`（一维图像的 `n` 个像素），核向量 `k` 长度为 `l`。为简单起见设 `l` 为奇数。想法直接推广到更高维。

卷积写成 `z = x ∗ k`，定义为

```
zᵢ = Σ_{j=1}^{l} kⱼ x_{j + i − (l+1)/2}                 (21.8)
```

对每个输出位置 `i`，核 `k` 与以 `xᵢ` 为中心、宽度为 `l` 的一段 `x` 做点积。

图 21.4：核 `[+1, −1, +1]`，`l = 3`，**步幅（stride）** `s = 2`，用来检测一维图像里较暗的点（二维版本可以检测较暗的线）。输入向量与核的矩阵形式是 (21.9)：

```
[ +1 −1 +1  0  0  0  0 ]   [5]   [5]
[  0  0 +1 −1 +1  0  0 ]   [6]   [9]
[  0  0  0  0 +1 −1 +1 ] × [6] = [4]
                           [2]
                           [5]
                           [6]
                           [5]
```

三行点积：`5 − 6 + 6 = 5`，`6 − 2 + 5 = 9`，`5 − 6 + 5 = 4`。峰值响应对准更暗（强度更低）的输入像素。结果通常再过非线性激活（图中未画）才进下一隐藏层。核中心所在像素相隔 2，所以说步幅 `s = 2`。因为步幅，像素数从 `n` 大约减到 `n/s`。二维时大约减到 `n / (s_x s_y)`。说“大约”，是因为边缘：图 21.4 的卷积停在图像边缘；也可以用额外像素**填充（padding）**（零，或复制最外层像素），使核能正好作用 `⌊n/s⌋` 次。小核通常用 `s = 1`，输出与图像同尺寸（图 21.5）。

卷积可以用嵌套循环实现，也可以写成一次矩阵乘法，与 (21.1) 的权重矩阵同类。权重矩阵里每一行是按步幅平移的核，多数元素是 0，实践中不必显式造出这个矩阵。卷积是线性矩阵运算，所以梯度下降对 CNN 和对普通神经网络一样直接有效。

核有 `d` 个而不只一个。步幅为 1 时输出大 `d` 倍：二维输入阵列变成三维隐藏单元阵列，第三维大小为 `d`。必须这样组织，使同一图像位置上各核的输出仍留在该位置。这额外的“核维”没有相邻性，沿它做卷积没有意义。

CNN 最初受视觉皮层神经科学模型启发。那里神经元的**感受野（receptive field）**是能影响该神经元激活的那部分感觉输入。CNN 第一隐藏层单元的感受野很小，就是核的大小，即 `l` 个像素。更深的层可以大得多。图 21.5 是 `l = 3`、`s = 1`、两端填充、隐藏层与输入同尺寸的前两层；第二隐藏层某单元的感受野含 5 个像素（图中红色）。步幅为 1 时，第 `m` 隐藏层一个节点的感受野大小是 `(l − 1)m + 1`，对 `m` 线性增长。（二维图像里感受野的每一维对 `m` 线性增长，面积则二次增长。）步幅大于 1 时，第 `m` 层的每个像素代表第 `m−1` 层的 `s` 个像素，感受野按 `O(l s^m)` 增长，即随深度指数增长。池化层有同样效果。

### 21.3.1 池化与下采样

**池化（pooling）**层用一个值概括前一层一组相邻单元。它像卷积层一样有核大小 `l` 和步幅 `s`，但运算是固定的，不是学出来的。池化层通常没有激活函数。两种常见形式：

- **平均池化**：计算 `l` 个输入的平均值。等价于用均匀核 `k = [1/l, …, 1/l]` 做卷积。若 `l = s`，效果是把图像分辨率变粗，即按因子 `s` **下采样（downsampling）**。原来占 `10s` 个像素的物体，池化后只占 10 个像素。能在原图里认出 10 像素大小物体的分类器，就能在池化图里认出这个（在原图里大得认不出的）物体。平均池化便于多尺度识别，也减少后续层的权重，从而降低计算、可能加快学习。
- **最大池化**：取 `l` 个输入的最大值。也可以只用来下采样，语义不同。对图 21.4 的隐藏层 `[5, 9, 4]` 做最大池化得到 9，表示输入图像某处有被该核检测到的较暗点。最大池化像一种逻辑析取：特征存在于该单元感受野的某处。

若目标是把图像分入 `c` 个类别之一，最后一层是有 `c` 个输出单元的 softmax。CNN 早层与图像同尺寸，中间必须显著缩小层的大小。步幅大于 1 的卷积层和池化层都缩小层。也可以用单元数少于前一层的全连接层来缩小。CNN 常在最终 softmax 之前放一或两个这样的层。

### 21.3.2 CNN 中的张量运算

(21.1)(21.3) 说明向量和矩阵能使推导简洁。向量、矩阵是**张量（tensor）**的一维、二维特例。深度学习术语里，张量就是任意维的多维数组。严格的数学定义还要求换基下的某些不变性；深度学习里的用法就是多维数组。

对 CNN，张量用来跟踪数据在各层中的“形状”。卷积依赖相邻性：相邻数据元素被假定语义相关，所以算子作用在局部区域上才有意义。有构造张量和施加算子的语言原语时，层本身可以简洁地写成从张量输入到张量输出的映射。

另一理由是计算效率：网络若写成一串张量运算，软件包可以生成针对底层硬件高度优化的编译代码。负载常跑在 GPU（图形处理单元）或 TPU（张量处理单元）上，并行度很高。原书举例：Google 第三代 TPU pod 的吞吐量大约相当于一千万台笔记本电脑。要在大型图像库上训练大型 CNN，必须用上这些能力。因此通常不是一次处理一张图像，而是许多图像并行；这与 21.4 里随机梯度下降对一小批训练例求梯度的方式一致。

例子：在 `256×256` 的 RGB 图像上训练，小批量大小 64。输入是四维张量，大小 `256×256×3×64`。再用 96 个大小为 `5×5×3` 的核，图像的 `x`、`y` 方向步幅都是 2。输出张量大小 `128×128×96×64`。这种张量常叫**特征图（feature map）**：每个核抽出的特征如何分布在整幅图像上。这里有 96 个**通道（channel）**，每个通道携带一种特征的信息。与输入张量不同，这个特征图不再有专门的颜色通道；若学习算法发现颜色对最终预测有用，颜色信息仍可以留在各个特征通道里。

### 21.3.3 残差网络

**残差网络（residual network）**是建造很深网络、同时避开梯度消失的一种流行且成功的做法。

典型深度模型让第 `i` 层学一个全新表示，完全替换第 `i−1` 层的表示。沿 (21.3) 的矩阵–向量记号，`z⁽ⁱ⁾` 是第 `i` 层单元的值：

```
z⁽ⁱ⁾ = f(z⁽ⁱ⁻¹⁾) = g⁽ⁱ⁾( W⁽ⁱ⁾ z⁽ⁱ⁻¹⁾ )
```

每一层都完全替换前一层，于是每一层都必须做点有用的事，至少要保住前一层里与任务相关的信息。若某一层 `W⁽ⁱ⁾ = 0`，整个网络就停止工作。若再令 `W⁽ⁱ⁻¹⁾ = 0`，网络甚至无法学习：第 `i` 层看不到来自第 `i−1` 层的输入变化，第 `i−1` 层也学不到，因为从第 `i` 层回传的梯度恒为 0。这是极端情形，但说明各层必须充当信号通过网络的管道。

残差网络的要点：一层应当扰动前一层的表示，而不是整个替换它。学到的扰动很小时，下一层接近前一层的拷贝。第 `i` 层写成

```
z⁽ⁱ⁾ = g_r⁽ⁱ⁾( z⁽ⁱ⁻¹⁾ + f(z⁽ⁱ⁻¹⁾) )                  (21.10)
```

`g_r` 是残差层的激活函数。`f` 是**残差（residual）**，扰动“把第 `i−1` 层原样传到第 `i` 层”这个默认行为。计算残差的函数通常是一层非线性加一层线性的神经网络：

```
f(z) = V g(W z)
```

`W` 和 `V` 是学到的权重矩阵，并加通常的偏置权重。

残差网络使显著更深的网络能可靠地学习。若把某一层的 `V` 设为 0 来关掉该层，残差 `f` 消失，(21.10) 变成 `z⁽ⁱ⁾ = g_r(z⁽ⁱ⁻¹⁾)`。再设 `g_r` 由 ReLU 组成，且 `z⁽ⁱ⁻¹⁾` 也是对输入做了 ReLU：`z⁽ⁱ⁻¹⁾ = ReLU(in⁽ⁱ⁻¹⁾)`。则

```
z⁽ⁱ⁾ = g_r(z⁽ⁱ⁻¹⁾)
     = ReLU(z⁽ⁱ⁻¹⁾)
     = ReLU(ReLU(in⁽ⁱ⁻¹⁾))
     = ReLU(in⁽ⁱ⁻¹⁾)
     = z⁽ⁱ⁻¹⁾
```

倒数第二步因为 `ReLU(ReLU(x)) = ReLU(x)`。因此在带 ReLU 的残差网里，权重为零的一层只是原样传递输入。网络其余部分就像这层从未存在。传统网络必须学会传播信息，参数选坏时传播会灾难性失败；残差网络默认就传播信息。

残差网络常与卷积层一起用于视觉，但它是通用工具：让深度网络更稳健，也让人更自由地试验复杂、异构的设计。写作时，见到几百层的残差网络并不罕见。这类设计演变很快，原书不再给更多会迅速过时的细节。

## 21.4 学习算法（Learning Algorithms）

训练就是修改参数，使训练集上的损失最小。原则上任何优化算法都可以用。实践中现代神经网络几乎总用**随机梯度下降（stochastic gradient descent, SGD）**的某种变体。

标准梯度下降及其随机版本在 19.6.2。目标是最小化 `L(w)`，`w` 是网络全部参数。每步更新：

```
w ← w − α ∇_w L(w)
```

`α` 是学习率。标准梯度下降的 `L` 相对整个训练集定义。SGD 的 `L` 相对每步随机抽出的、大小为 `m` 的**小批量（minibatch）**定义。

高维连续空间的优化有无数增强（见 4.2）。与训练神经网络特别相关的几点：

- 真实问题里 `w` 的维数和训练集都很大。这强烈支持用相对小的 `m` 做 SGD：随机性帮助算法逃出高维权重空间里的小局部极小（类似模拟退火，书页 114）；小的 `m` 使每步权重更新的计算代价是与训练集大小无关的小常数。
- 小批量里每个训练例对梯度的贡献可以独立计算，所以 `m` 常选成能尽量吃满 GPU 或 TPU 的硬件并行。
- 为改善收敛，学习率通常应随时间下降。合适的日程多半靠试。
- 靠近相对整个训练集的局部或全局极小值时，小批量估计的梯度方差往往很大，方向可能完全错误，难以收敛。办法之一是训练过程中增大 `m`；之二是用**动量（momentum）**：保留过去小批量梯度的滑动平均，以补偿小的 `m`。
- 要抑制上溢、下溢和舍入造成的数值不稳定。softmax、sigmoid、tanh 里的指数，以及很深的网络和循环网络（21.6）里的反复计算，特别容易引出激活和梯度的消失与爆炸。

学习权重的过程通常收益递减。跑到再跑下去已不实际地降低测试误差为止。这通常并不意味着已经到达损失的全局极小甚至局部极小。它意味着：要继续降代价得做多得不实际的极小步，或者再走只会造成**过拟合（overfitting）**，或者梯度估计已不准到无法再前进。

### 21.4.1 在计算图中计算梯度

书页 755 对一个具体小网络推导了损失对权重的梯度，并观察到梯度可以把误差从输出层回传到隐藏层。这对任意前馈计算图都成立。

图 21.6 是计算图里的一般节点。节点 `h` 的入度和出度都是 2，分析不依赖这一点。前向时，`h` 由其输入（来自节点 `f` 和 `g`）计算某个函数，再把值送给节点 `j` 和 `k`。前向从左到右，梯度回传从右到左。

回传沿每条链路送消息。每个节点收集进入的消息，再算出要往回送的新消息。消息都是损失 `L` 的偏导数。例如后向消息 `∂L/∂hⱼ` 是 `L` 关于 `j` 的第一个输入的偏导，该输入就是从 `h` 到 `j` 的前向消息。`h` 通过 `j` 和 `k` 两条路影响 `L`，所以

```
∂L/∂h = ∂L/∂hⱼ + ∂L/∂hₖ                              (21.11)
```

节点 `h` 把来自 `j` 和 `k` 的进入消息相加，就得到 `L` 对 `h` 的导数。再算送出的消息 `∂L/∂f_h` 和 `∂L/∂g_h`：

```
∂L/∂f_h = (∂L/∂h) · (∂h/∂f_h)
∂L/∂g_h = (∂L/∂h) · (∂h/∂g_h)                        (21.12)
```

(21.12) 里的 `∂L/∂h` 已由 (21.11) 得到；`∂h/∂f_h` 和 `∂h/∂g_h` 只是 `h` 对其第一、第二自变量的导数。例如 `h` 是乘法节点，`h(f, g) = f · g`，则 `∂h/∂f_h = g`，`∂h/∂g_h = f`。深度学习软件包通常带一个节点类型库（加法、乘法、sigmoid 等），每种节点知道如何为 (21.12) 计算自己的导数。

回传从输出节点开始。每条初始消息 `∂L/∂ŷⱼ` 直接由 `L` 关于预测 `ŷ` 和训练数据真值 `y` 的表达式算出。每个内部节点按 (21.11) 把进入的后向消息相加，再按 (21.12) 产生送出消息。过程终止于表示权重 `w` 的节点（如图 21.3(b) 里的浅紫色椭圆）。到达该点时，进入 `w` 的消息之和就是 `∂L/∂w`，即更新 `w` 所需的梯度。习题 21.BPRE 要求用这个过程在图 21.3 上重推 (21.4)(21.5)。

**权重共享**（卷积网络 21.3、循环网络 21.6）的处理：每个共享权重是计算图里一个节点、多条出弧。回传时它收到多条梯度消息。由 (21.11)，共享权重的梯度是它在网络中每一处被使用所贡献的梯度之和。

反向传播的计算代价对计算图节点数是线性的，与前向相同。节点类型通常在设计网络时就固定，梯度计算可以事先写成符号形式，并编译成每个节点上很高效的代码。图 21.6 的消息不必是标量，同样可以是向量、矩阵或更高维张量，从而把梯度计算映射到 GPU 或 TPU。

一个缺点：为了在后向计算梯度，必须保存前向中算出的大部分中间值。训练的总内存代价与整个网络的单元数成正比。即便网络本身只由带许多循环的传播代码隐式表示，而不是显式数据结构，这些中间结果也必须显式存下来。

### 21.4.2 批归一化

**批归一化（batch normalization）**重缩放每个小批量里、网络内部层产生的值，从而提高 SGD 的收敛速度。写作时其有效的原因尚未被很好理解；原书收入它，是因为实践中收益显著。在一定程度上，它的效果与残差网络相似。

考虑网络中某处节点 `z`。小批量 `m` 个例子上的值是 `z₁, …, z_m`。批归一化把每个 `zᵢ` 换成

```
ẑᵢ = γ · (zᵢ − μ) / √(ε + σ²) + β
```

`μ` 是 `z` 在该小批量上的均值，`σ` 是 `z₁, …, z_m` 的标准差，`ε` 是防止除零的小常数，`γ` 和 `β` 是学到的参数。

它按 `β` 和 `γ` 所决定的方式，把这些值的均值和方差标准化，使深度网络容易训练得多。没有批归一化时，若一层权重太小，信息会丢失，该层标准差会衰减到接近 0。批归一化阻止这件事。它也降低了“必须小心初始化全部权重、使每层节点处于能让信息传播的工作区”这一需求。

`β` 和 `γ` 可以是节点专属或层专属，通常放进网络参数一起学习。训练之后，它们固定在学到的值上。

## 21.5 泛化（Generalization）

前面讲的是拟合训练集。机器学习的目标是泛化到先前未见的新数据，用测试集上的表现来衡量。本节三条途径：选对网络架构、惩罚大权重、训练时随机扰动通过网络的值。

### 21.5.1 选择网络架构

大量研究用来找泛化好的架构。对图像、语音、文本、视频等每一类数据，性能进展有不少来自探索不同架构，以及改变层数、连接方式和每层节点类型。这些增量式探索很多由研究生完成，因此有人称之为 graduate student descent（GSD）。

有些架构是为特定数据的泛化而显式设计的：卷积网络编码“同一特征提取器在空间网格的所有位置都有用”；循环网络编码“同一更新规则在序列的所有时刻都有用”。这些假设成立的范围内，卷积架构应在图像上泛化好，循环网络应在文本和音频上泛化好。

深度学习里最重要的经验发现之一：权重数目相近的两个网络，更深的那个通常泛化更好。图 21.7 画出测试集误差随层宽（以权重总数衡量，横轴为权重数 `× 10⁷`）的变化，比较三层与十一层卷积网络。数据来自 Google 街景车辆照片门牌转录系统的早期版本（Goodfellow et al., 2014）。对任意固定的参数数目，十一层网络的测试误差都比三层低得多。

深度系统在一部分任务上表现好，不是全部。高维输入（图像、视频、语音信号等）上，它们好于任何其他纯粹的机器学习方法。第 19 章的多数算法要处理高维输入，得先用手工设计的特征把维数降下来。2010 年之前盛行的这种预处理，没有达到深度学习系统的性能。

这些模型抓住了任务的某些重要方面。它们的成功意味着：任务可以用步数相对少的并行程序解决——`10` 到 `10³` 步，而不是比方说 `10⁷` 步。这或许不奇怪：这些任务大脑通常在不到一秒内解决，而一秒只够几十次顺序的神经元发放。检查视觉任务里深度卷积网络学到的内部层表示，会看到处理步骤像是抽取越来越抽象的场景表示：从细小的边、点和角特征，直到整个物体以及多个物体的布置。

另一方面，深度模型是简单电路，缺少一阶逻辑（第 8 章）和上下文无关文法（第 23 章）里那种组合性与量化表达力。

它们在许多情形下泛化良好，也会产生不合直觉的错误。它们倾向于产生不连续的输入–输出映射，输入的小改动可以造成输出的大改动。例如，只改一张狗的图像里的少数像素，就可能让网络把狗分成鸵鸟或校车，而改过的图像看起来仍完全是一只狗。这种改过的图像叫**对抗样本（adversarial example）**。

低维空间里很难找到对抗样本。一百万个像素值的图像则常常是：多数像素把图像放在空间里“狗”区域的内部，但有少数维度上的像素值靠近另一类别的边界。能逆向该网络的对手可以找到把图像推过边界的最小向量差。

对抗样本刚被发现时，引发了两场全球性的忙乱：一场找不容易被攻击的学习算法和架构，一场制造对各种学习系统越来越有效的攻击。迄今攻击方领先。起初人们以为必须能看到已训练网络的内部，才能为该网络专门构造对抗样本；后来发现可以构造稳健的对抗样本，同时骗过架构、超参数和训练集都不同的多个网络。这些发现说明，深度模型识别物体的方式与人类视觉系统相当不同。

### 21.5.2 神经架构搜索

还没有一套清楚的指南，告诉你某个问题该选哪种架构。部署深度学习方案需要经验和判断。

从神经网络研究的早期起，就有人试图把架构选择自动化。这可以看成超参数调节（19.4.4）：超参数决定深度、宽度、连接性及其他属性。要做的选择太多，网格搜索无法在合理时间内覆盖。

因此常用**神经架构搜索（neural architecture search）**去探索可能架构的状态空间。本书前面的许多搜索技术和学习技术都被用过：

- 进化算法流行，因为重组（把两个网络的部分接起来）和变异（加或删一层，或改一个参数值）都说得通。
- 爬山可以用同样的变异操作。
- 有人把它做成强化学习，有人做成贝叶斯优化。
- 也可以把架构可能性当成连续可微空间，用梯度下降找局部最优。

对所有这些搜索，主要困难是估计候选网络的价值。直截的办法是在测试集上训练多个批次，再在验证集上评准确率。大网络可能要许多 GPU 日。

> ⚠️ 待核：原文是 train it on a test set，然后在 validation set 上评。笔记照录“测试集”，不改成训练集。

因此有许多工作试图去掉或至少减少昂贵的训练：在更小的数据集上训练；只训练少量批次并预测再训练会如何变好；用缩小版架构，希望它保住完整版的性质；先训练一个大网络，再搜索其中表现更好的子图——子图共享参数，不必重训，所以搜索可以很快。

另一办法是学习一个启发式评价函数（如同 A\* 搜索）：先选几百个架构，训练并评价，得到（网络, 分数）数据；再学一个从网络特征到预测分数的映射；此后可以生成大量候选并快速估计价值；在网络空间搜完之后，最好的那些再用完整训练程序充分评价。

### 21.5.3 权重衰减

19.4.3 里，**正则化（regularization）**——限制模型复杂度——有助于泛化。深度模型同样如此。在神经网络语境里这通常叫**权重衰减（weight decay）**。

权重衰减就是在训练用的损失函数上加惩罚项

```
λ Σᵢ,ⱼ Wᵢ,ⱼ²
```

`λ` 是控制惩罚强度的超参数，求和通常遍及网络中所有权重。`λ = 0` 等于不用权重衰减；`λ` 更大则鼓励权重变小。常用 `λ` 在 `10⁻⁴` 附近。

选定具体架构是对假设空间的绝对约束：一个函数要么能在该架构里表示，要么不能。权重衰减这类损失惩罚是更软的约束：大权重表示的函数仍在函数族里，但训练集必须提供比选择小权重函数更多的证据，才会选它们。

权重衰减在网络里的效果不好直接解释。sigmoid 网络上的一种假说是：它帮助激活留在 sigmoid 的线性段附近，避开导致梯度消失的平坦区。ReLU 网络上权重衰减似乎仍有益，但 sigmoid 的解释不再适用，因为 ReLU 的输出要么线性、要么为零。再有残差连接时，权重衰减鼓励的是相邻层之间的差小，而不只是权重绝对值小。尽管在许多架构上行为不同，权重衰减仍然广泛有用。

一种解释：它实现了最大后验（MAP）学习（书页 723）。令 `X` 和 `y` 表示整个训练集上的输入和输出，最大后验假设 `h_MAP` 满足

```
h_MAP = argmax_w  P(y | X, W) P(W)
       = argmin_w  [ −log P(y | X, W) − log P(W) ]
```

第一项是通常的交叉熵损失；第二项偏好在先验下更可能的权重。若令

```
log P(W) = −λ Σᵢ,ⱼ Wᵢ,ⱼ²
```

就与正则化损失完全对齐，此时 `P(W)` 是零均值高斯先验。

### 21.5.4 Dropout

另一条降低测试误差的干预——代价是更难拟合训练集——是 **dropout**。训练的每一步，先造一个新版本的网络：随机停用一部分单元，再对这个版本做一步反向传播。这是训练一大群不同网络之集成（见 19.8）的一种粗糙、很便宜的近似。

具体地，设 SGD 的小批量大小为 `m`。对每个小批量，dropout 对网络中每个节点做：以概率 `p` 把该单元输出乘以 `1/p`；否则把输出固定为 0。隐藏层单元常用 `p = 0.5`；输入单元用 `p = 0.8` 最有效。这样得到一个大约只有一半单元的抽薄网络（对应 `p = 0.5`），再对 `m` 个训练例做反向传播。重复直到训练结束。**测试时模型不用 dropout。**

几种看法：

- 训练时引入噪声，迫使模型对噪声稳健。
- 如上，dropout 近似造出一个抽薄网络的大集成。线性模型上可以解析验证；深度模型上实验看来成立。
- 用 dropout 训练的隐藏单元，不但要自己有用，还要能与许多别的、可能出现也可能不出现在完整模型里的隐藏单元集合相容。这类似引导基因演化的选择：每个基因不但要在自己的功能上有效，还要与未来生物体里身份可能很不相同的其他基因配合。
- 用在深层网络的较后层时，dropout 迫使最终决策稳健地注意例子的全部抽象特征，而不是只盯一个、忽略其余。例如动物图像分类器也许只看鼻子就能在训练集上表现很好，但鼻子被挡住或损坏的测试例会失败。有 dropout 时，会有内部“鼻子单元”被置零的训练例，学习过程就去找另外的辨认特征。想靠给输入数据加噪声达到同样稳健会很难：无法预先知道网络会盯着鼻子，也无法自动从每张图里删掉鼻子。

总的来说，dropout 迫使模型为每个输入学到多种稳健解释。模型因此泛化更好，也更难拟合训练集——通常要用更大的模型，并训练更多轮。

## 21.6 循环神经网络（Recurrent Neural Networks）

**循环神经网络（recurrent neural network, RNN）**与前馈网络的区别是计算图允许环。下面考虑的情形里，每个环都有延迟，单元可以把自己在更早一步算出的输出当作输入。（没有延迟的话，有环电路可能进入不一致状态。）这使 RNN 有内部状态，即记忆：较早时刻收到的输入影响它对当前输入的响应。图 21.8(a) 里的 `Δ` 表示延迟。

RNN 也可以做更一般的计算——普通计算机就是带记忆的布尔电路——并用来为含环状连接的真实神经系统建模。这里集中于分析序列数据：假定每个时间步到来一个新的输入向量 `x_t`。

作为序列工具，RNN 可与第 14 章的隐马尔可夫模型、动态贝叶斯网络和卡尔曼滤波器比较。与那些模型一样，RNN 作马尔可夫假设（书页 463）：网络的隐藏状态 `z_t` 足以抓住此前全部输入的信息。再把隐藏状态的更新写成 `z_t = f_w(z_{t−1}, x_t)`。训练之后，这个函数表示一个时间齐次过程（书页 463）——实际上是一句全称断言：`f_w` 所表示的动力学对所有时间步成立。因此 RNN 相对前馈网络增加了表达力，正如卷积网络所做的，也正如动态贝叶斯网相对普通贝叶斯网。若用前馈网络分析序列，输入层大小固定，网络只能看有限长的窗口，从而检测不到长距离依赖。

### 21.6.1 训练基本 RNN

基本模型有输入层 `x`、带循环连接的隐藏层 `z`、输出层 `y`（图 21.8(a)）。假定训练数据在每个时间步都观测到 `x` 和 `y`。按时间步 `t` 索引：

```
z_t = f_w(z_{t−1}, x_t) = g_z(W_{z,z} z_{t−1} + W_{x,z} x_t) ≡ g_z(in_{z,t})
ŷ_t = g_y(W_{z,y} z_t) ≡ g_y(in_{y,t})                    (21.13)
```

`g_z`、`g_y` 分别是隐藏层和输出层的激活。与通常一样，每个单元还有固定为 `+1` 的虚输入及相应偏置权重。

给定输入序列 `x₁, …, x_T` 和观测输出 `y₁, …, y_T`，把模型“展开”`T` 步就得到前馈网络（图 21.8(b)）。权重矩阵 `W_{x,z}`、`W_{z,z}`、`W_{z,y}` 在所有时间步共享。展开后可以用通常方式算梯度来训练；差别只是跨层共享权重使梯度稍复杂。

为使方程简单，下面只对一个输入单元、一个隐藏单元、一个输出单元推导，并把偏置写明：

```
z_t = g_z(w_{z,z} z_{t−1} + w_{x,z} x_t + w_{0,z})
ŷ_t = g_y(w_{z,y} z_t + w_{0,y})
```

与 (21.4)(21.5) 一样用平方误差损失 `L`，这里对时间步求和。输入层、输出层权重 `w_{x,z}` 和 `w_{z,y}` 的推导与 (21.4) 本质相同，原书留作习题。隐藏层权重 `w_{z,z}` 的前几步也遵循 (21.4) 的模式，得到

```
∂L/∂w_{z,z}
  = Σ_{t=1}^{T} −2(y_t − ŷ_t) g′_y(in_{y,t}) w_{z,y} · ∂z_t/∂w_{z,z}   (21.14)
```

隐藏单元 `z_t` 的梯度再由前一时间步递推：

```
∂z_t/∂w_{z,z}
  = g′_z(in_{z,t}) · ( z_{t−1} + w_{z,z} · ∂z_{t−1}/∂w_{z,z} )         (21.15)
```

最后一行用乘积的求导：`∂(uv)/∂x = v ∂u/∂x + u ∂v/∂x`。

(21.15) 有两点。第一，梯度表达式是递归的：时间步 `t` 的贡献用 `t−1` 的贡献来算。计算顺序排对时，总运行时间对网络大小是线性的。这个算法叫**沿时间反向传播（back-propagation through time）**，通常由深度学习软件自动处理。第二，把递归展开后，时刻 `T` 的梯度含与

```
w_{z,z} · Π_{t=1}^{T} g′_z(in_{z,t})
```

成比例的项。对 sigmoid、tanh 和 ReLU，`g′ ≤ 1`，所以若 `w_{z,z} < 1`，这个简单 RNN 一定遭受梯度消失（书页 756）。另一方面，若 `w_{z,z} > 1`，可能遇到**梯度爆炸（exploding gradient）**。一般情形下，这两种结果取决于权重矩阵 `W_{z,z}` 的第一特征值。下一小节的设计用来缓解这个问题。

### 21.6.2 长短期记忆 RNN

若干专门的 RNN 架构旨在让信息跨许多时间步保存下来。最流行的之一是**长短期记忆（long short-term memory, LSTM）**。LSTM 的长期记忆部分叫**记忆细胞（memory cell）**，记为 `c`，本质上是从一个时间步复制到下一个时间步。（对比：基本 RNN 每个时间步都用权重矩阵去乘它的记忆，见 (21.13)。）新信息以相加的更新进入记忆；这样梯度表达式不会随时间做乘法累积。LSTM 还有**门控单元（gating unit）**：用对应信息向量的逐元素乘法来控制信息流。

- **遗忘门 `f`**：决定记忆细胞的每个元素是被记住（复制到下一时间步）还是被忘记（重置为 0）。
- **输入门 `i`**：决定记忆细胞的每个元素是否被当前输入向量的新信息做加法更新。
- **输出门 `o`**：决定记忆细胞的每个元素是否传到短期记忆 `z`。`z` 的角色类似基本 RNN 的隐藏状态。

电路设计里“门”通常指布尔函数；LSTM 的门是软的。例如遗忘门向量的对应元素小但不是零时，记忆细胞向量的元素只是被部分忘记。门控单元的值总在 `[0, 1]`，由 sigmoid 作用在当前输入和前一隐藏状态上得到。更新方程：

```
f_t = σ(W_{x,f} x_t + W_{z,f} z_{t−1})
i_t = σ(W_{x,i} x_t + W_{z,i} z_{t−1})
o_t = σ(W_{x,o} x_t + W_{z,o} z_{t−1})
c_t = c_{t−1} ⊙ f_t + i_t ⊙ tanh(W_{x,c} x_t + W_{z,c} z_{t−1})
z_t = tanh(c_t) ⊙ o_t
```

各权重矩阵 `W` 的下标表示链路的起点和终点。`⊙` 是逐元素乘法。

LSTM 是最早一批实际可用的 RNN。它在语音识别、手写识别等广泛任务上表现优异。自然语言处理中的用法在第 24 章。

## 21.7 无监督学习与迁移学习（Unsupervised Learning and Transfer Learning）

至此的系统基于监督学习：每个训练例都要有目标函数的标签。它们可以达到很高的测试准确率——例如 ImageNet 竞赛的结果——但所需标签常常远多于人类完成同一任务所需。孩子看一张长颈鹿的图就能在各种场景和视角里可靠认出长颈鹿，而不是要看几千张。监督学习的故事里缺了什么；现行的监督深度学习甚至可能使某些任务完全达不到，因为所需标签会超过人类（或宇宙）能提供的量。即便任务可行，给大数据集打标签通常也要稀缺而昂贵的人力。

因此有几类降低对标签依赖的范式受到强烈关注。第 19 章已经见过：**无监督学习**、**迁移学习**、**半监督学习**。

| 范式 | 用什么数据 |
|---|---|
| 无监督 | 只从未标注输入 `x` 学习。`x` 往往比带标签的例子多得多。通常产出**生成模型**，能生成逼真的文本、图像、音频和视频，而不只是预测标签 |
| 迁移 | 需要一些带标签的例子，还能靠研究**其他任务**的带标签例子进一步提高 |
| 半监督 | 需要一些带标签的例子，还能靠研究未标注例子进一步提高 |

本节只讲无监督和迁移的深度学习做法。半监督在深度学习社区也是活跃研究方向，但当时已发展的技术在实践中尚未证明广泛有效，原书不讲。

### 21.7.1 无监督学习

监督算法的目标实质相同：给定输入 `x` 和对应输出 `y = f(x)`，学一个很好地逼近 `f` 的 `h`。无监督算法拿到的是未标注例子 `x`。这里它可能做两件事。一是学新的表示，例如使图像中的物体更容易辨认的新特征。二是学生成模型，典型形式是一个可以抽出新样本的概率分布。（第 20 章学习贝叶斯网的算法属于这一类。）许多算法两者都能做。

设学到联合模型 `P_W(x, z)`，其中 `z` 是一组隐的、未观测的变量，以某种方式表示数据 `x` 的内容。与本章的精神一致，不预先规定 `z` 的含义；模型可以自由学习如何把 `z` 与 `x` 关联。例如在手写数字图像上，模型可能用 `z` 空间的一个方向表示笔划粗细，另一个表示墨水颜色，再一个表示背景颜色。在人脸图像上，可能用一个方向表示性别，另一个表示有没有眼镜（图 21.9）。

学到的 `P_W(x, z)` 同时完成表示学习（从原始 `x` 构造有意义的 `z`）和生成建模：把 `z` 从 `P_W(x, z)` 里积分掉，就得到 `P_W(x)`。

**概率主成分分析（PPCA）**

`P_W(x, z)` 可以取许多形式。最简单的之一是概率主成分分析。在 PPCA 里，`z` 取自零均值的球形高斯，再由 `z` 乘权重矩阵 `W` 并加上球形高斯噪声生成 `x`：

```
P(z) = N(z; 0, I)
P_W(x | z) = N(x; Wz, σ² I)
```

权重 `W`（以及可选的噪声参数 `σ²`）靠最大化数据似然来学习：

```
P_W(x) = ∫ P_W(x, z) dz = N(x; 0, WW⊤ + σ² I)         (21.16)
```

对 `W` 的最大化可以用梯度法，或用高效的迭代 EM（见 20.3）。`W` 学到之后，可以用 (21.16) 直接从 `P_W(x)` 生成新样本。按 (21.16) 概率极低的新观测 `x` 可以标成潜在异常。

PPCA 通常假定 `z` 的维数远小于 `x`，从而用少量特征尽量解释数据。这些特征可以交给标准分类器用：计算 `ẑ`，即 `P_W(z | x)` 的期望。

从概率 PCA 生成数据很直接：先从固定的高斯先验抽 `z`，再从均值为 `Wz` 的高斯抽 `x`。下面许多生成模型像这个过程，只是用深度模型定义的复杂映射，而不是从 `z` 空间到 `x` 空间的线性映射。

标准 PCA 是给原始输入拟合一个多元高斯，再选出该椭球分布最长的轴，即主成分。

**自编码器**

许多无监督深度算法基于**自编码器（autoencoder）**。它有两部分：把 `x` 映到表示 `ẑ` 的**编码器**，把表示 `ẑ` 映回观测数据的**解码器**。一般地编码器是参数化函数 `f`，解码器是参数化函数 `g`。训练使 `x ≈ g(f(x))`，编码大致被解码反过来。`f` 和 `g` 可以是由单个矩阵参数化的简单线性模型，也可以是深度神经网络。

很简单的一种是**线性自编码器**，`f` 和 `g` 都线性，并共享权重矩阵 `W`：

```
ẑ = f(x) = W x
x = g(ẑ) = W⊤ ẑ
```

左边的 `x` 是解码器的输出，训练时再拿它和原来的输入比。

一种训练方式是最小化平方误差 `Σⱼ ‖xⱼ − g(f(xⱼ))‖²`，使 `x ≈ g(f(x))`。想法是训练 `W`，让低维的 `ẑ` 尽量保留重建高维 `x` 所需的信息。线性自编码器与经典主成分分析紧密相关。当 `z` 是 `m` 维时，`W` 应当学成张成数据的 `m` 个主成分——即数据方差最高的 `m` 个正交方向，也就是数据协方差矩阵最大特征值对应的 `m` 个特征向量——与 PCA 相同。

PCA 是对应于简单线性自编码器的简单生成模型。这个对应提示：更复杂的自编码器或许能抓住更复杂的生成模型。**变分自编码器（variational autoencoder, VAE）**是一条路。

变分方法在书页 458 简要介绍过：复杂概率模型里，对大量隐变量求和或积分不可行时，用它近似后验。想法是用一个来自计算上可处理的分布族的**变分后验** `Q(z)` 去近似真后验。例如 `Q` 可以取对角协方差的高斯族。在所选的可处理族里，把 `Q` 优化到尽量接近真后验 `P(z | x)`。

“尽量接近”用书页 758 提到的 KL 散度：

```
D_KL( Q(z) ∥ P(z|x) ) = ∫ Q(z) log( Q(z) / P(z|x) ) dz
```

这是（关于 `Q` 的）`Q` 与 `P` 的对数比的平均。`D_KL(Q(z) ∥ P(z|x)) ≥ 0`，`Q` 与 `P` 重合时取等号。由此定义数据对数似然的**变分下界** `L`（有时叫证据下界，ELBO）：

```
L(x, Q) = log P(x) − D_KL( Q(z) ∥ P(z|x) )             (21.17)
```

KL 非负，所以 `L` 是 `log P` 的下界。变分学习最大化的是 `L` 关于参数 `w`，而不是直接最大化 `log P(x)`，希望找到的 `w*` 也接近最大化 `log P(x)`。

写成这样，`L` 似乎并不比 `log P` 更好最大化。把 (21.17) 改写（`∫ Q = 1`，故 `log P(x) = ∫ Q(z) log P(x) dz`；并且 `P(z, x) = P(x) P(z|x)`）：

```
L = log P(x) − ∫ Q(z) log( Q(z) / P(z|x) ) dz
  = −∫ Q(z) log Q(z) dz + ∫ Q(z) log( P(x) P(z|x) ) dz
  = H(Q) + E_{z∼Q}[ log P(z, x) ]
```

`H(Q)` 是 `Q` 的熵；与这一行对齐时，`H(Q) = −∫ Q log Q`。某些变分族（如高斯）的 `H(Q)` 可以解析求出。期望 `E_{z∼Q} log P(z, x)` 可以用从 `Q` 抽出的 `z` 样本做高效的无偏估计。每个样本上 `P(z, x)` 通常可以高效求值——若 `P` 是贝叶斯网，因为 `z` 和 `x` 构成全部变量，`P(z, x)` 就是各条件概率的乘积。

VAE 把变分学习放进深度学习设定。变分学习对 `P` 和 `Q` 双方的参数最大化 `L`。在 VAE 里，解码器 `g(z)` 被解释为定义 `log P(x | z)`。例如解码器的输出可以定义条件高斯的均值。编码器 `f(x)` 的输出被解释为定义 `Q` 的参数。例如 `Q` 可以是均值为 `f(x)` 的高斯。训练 VAE 就是对编码器 `f` 和解码器 `g` 的参数最大化 `L`；`f` 和 `g` 本身可以是任意复杂的深度网络。

**深度自回归模型**

**自回归模型（autoregressive model, AR）**用数据向量 `x` 的其他元素来预测每个元素 `xᵢ`。这种模型没有隐变量。若 `x` 大小固定，AR 模型可以看成完全可观测、并且可能全连接的贝叶斯网。因此，按 AR 模型算给定数据向量的似然是平凡的；在其余变量都给定时预测单个缺失变量、以及从模型抽取数据向量，同样平凡。

最常见的应用是时间序列：`k` 阶 AR 模型用 `x_{t−k}, …, x_{t−1}` 预测 `x_t`。用第 14 章的术语，AR 模型是没有隐藏状态的马尔可夫模型。用第 23 章的术语，字母或词序列的 `n` 元模型是 `n−1` 阶 AR 模型。

经典 AR 里变量是实值，条件分布 `P(x_t | x_{t−k}, …, x_{t−1})` 是固定方差的线性–高斯模型，均值是 `x_{t−k}, …, x_{t−1}` 的加权线性组合，也就是标准线性回归。最大似然解由 **Yule–Walker 方程**给出，与书页 680 的正规方程紧密相关。

**深度自回归模型**用任意深度网络替换线性–高斯模型，输出层按 `x_t` 是离散还是连续来选。近期应用包括 DeepMind 的 WaveNet 语音生成（van den Oord et al., 2016a）。WaveNet 在原始声学信号上训练，每秒采样 16,000 次，实现一个 4800 阶的非线性 AR 模型，结构是多层卷积。测试中它比此前最先进的语音生成系统真实得多。

**生成对抗网络**

**生成对抗网络（generative adversarial network, GAN）**其实是一对网络，合起来构成生成系统。其中一个是**生成器（generator）**：把 `z` 的值映到 `x`，以产生来自分布 `P_w(x)` 的样本。典型方案是从中等维数的单位高斯抽 `z`，再通过深度网络 `h_w` 得到 `x`。另一个是**判别器（discriminator）**：把输入 `x` 分成真实（来自训练集）或伪造（生成器造的）的分类器。GAN 是一种**隐式模型（implicit model）**：可以生成样本，但样本的概率不容易得到。贝叶斯网则相反，一个样本的概率就是生成路径上各条件概率的乘积。

生成器与 VAE 框架里的解码器紧密相关。隐式建模的难点是设计一个损失函数，使模型能用从分布抽出的样本来训练，而不是去最大化数据集中训练例被赋予的似然。

生成器和判别器同时训练：生成器学习骗过判别器，判别器学习准确分开真与假。二者的竞争可以用博弈论的语言描述（第 18 章）。想法是在博弈的均衡状态，生成器应当完美复现训练分布，使判别器无法好于随机猜测。GAN 在图像生成上特别成功。例如可以造出从未存在过的人的、照片般真实的高分辨率图像（Karras et al., 2017）。

图 21.9（Radford et al., 2015，获准转载）演示生成模型如何用 `z` 空间的不同方向表示人脸的不同方面，并且可以在 `z` 空间做算术。图中图像都由学到的模型生成：从“戴眼镜的男人”的坐标减去“男人”、加上“女人”，得到“戴眼镜的女人”的坐标。

**无监督翻译**

广义的翻译，是把有丰富结构的输入 `x` 变成同样有丰富结构的输出 `y`。这里“丰富结构”指数据是多维的，各维之间有有趣的统计依赖。图像和自然语言句子有丰富结构；单个数（例如类别 ID）没有。把句子从英语译成法语，或把夜景照片变成等效的日间照片，都是翻译任务。

监督翻译收集许多 `(x, y)` 对，训练模型把每个 `x` 映到对应的 `y`。例如机器翻译系统常在职业译者译好的句对上训练。其他翻译可能没有监督数据。例如一张有许多移动的车和行人的夜景照片：要把所有车和行人放回夜间照片里的原位置、再于白天重拍同一张，大概不可行。可以用**无监督翻译**：在许多 `x` 的例子和许多分开的 `y` 的例子上训练，但没有对应的 `(x, y)` 对。这些做法一般基于 GAN。例如可以训练一个 GAN 生成器，在以 `x` 为条件时产生逼真的 `y`，再训练另一个 GAN 生成器做反向映射。GAN 的训练框架使生成器能够生成判别器愿意接受为“给定 `x` 的一个逼真 `y`”的许多可能样本中的任意一个，而不需要监督学习里传统上要的那个特定配对 `y`。图像无监督翻译的更多细节在 25.7.5。

### 21.7.2 迁移学习与多任务学习

**迁移学习（transfer learning）**里，一个学习任务上的经验帮助智能体更好地学另一个任务。已经会打网球的人通常更容易学壁球和短柄墙球；会飞一种商用客机的飞行员很快能飞另一种；学过代数的学生更容易学微积分。

人类迁移学习的机制还不清楚。对神经网络，学习就是调权重，所以最说得通的做法是：把任务 A 学到的权重复制到将为任务 B 训练的网络上，再用任务 B 的数据按通常方式做梯度下降更新。视任务有多相似、任务 A 用了多少数据，任务 B 上用更小的学习率可能是好主意。

这要求人来选择任务：代数训练学到的权重，对打算用来打壁球的网络可能没什么用。复制权重还要求两个任务的输入空间之间有简单的映射，并且网络架构本质上相同。

迁移学习流行的一个原因是有高质量的预训练模型。例如可以下载在 COCO 数据集上训练的 ResNet-50 视觉目标识别模型，省下数周工作，再提供你自己任务的额外图像和物体标签来修改参数。

假设要给独轮车的类型分类。你只有几百张不同独轮车的照片，而 COCO 在自行车、摩托车、滑板每一类里都有 3,000 张以上的图像。在 COCO 上预训练的模型已经有车轮、道路和其他有助于解释独轮车图像的特征经验。

常常要**冻结**预训练模型的前几层——这些层是对新模型仍有用的特征检测器。新数据集只允许修改更高层的参数；那些层识别问题专属的特征并做分类。不过，传感器不同时，即使最低层也可能要重训。

建造自然语言系统的人，现在常从一个预训练模型起步，例如 ROBERTA（见 24.6），它已经“知道”日常语言的大量词汇和句法。下一步以两种方式微调。第一，给它目标领域的专门词汇例子：医学领域会学到 “mycardial infarction”，金融领域会学到 “fiduciary responsibility”。第二，在它要执行的任务上训练。若要做问答，就用问答对训练。

> ⚠️ 待核：书页 781 印刷为 “mycardial infarction”。通行医学拼写是 myocardial infarction。笔记照录原书用词。

一种很重要的迁移发生在仿真与真实世界之间。例如自动驾驶汽车的控制器可以在数十亿英里的仿真驾驶上训练，这在真实世界里做不到。控制器转到真实车辆上之后，会很快适应新环境。

**多任务学习（multitask learning）**是同时在多个目标上训练一个模型的迁移学习。例如，不是先在词性标注上训练自然语言系统、再把学到的权重迁到文档分类，而是用一个系统同时做：词性标注、文档分类、语言检测、词预测、句子难度建模、抄袭检测、句子蕴涵、问答。这是八项。想法是：只解其中任何一项时，模型也许能利用数据的表面特征；要用一个公共表示层同时解全部八项，模型更可能造出反映真实自然语言用法和内容的公共表示。

## 21.8 应用（Applications）

深度学习已被成功用于 AI 中许多重要问题。深入解释见相关章：第 22 章（强化学习中的深度学习）、第 24 章（自然语言处理）、第 25 章尤其 25.4（计算机视觉）、第 26 章（机器人学）。

### 21.8.1 视觉

计算机视觉大概是对深度学习影响最大的应用领域，反之亦然。深度卷积网络从 1990 年代起就用于手写识别等任务；大约 2010 年，神经网络在语音识别上开始超过生成式概率模型。把深度学习推到聚光灯下的，是 AlexNet 在 2012 年 ImageNet 竞赛中的成功。

ImageNet 竞赛是监督学习任务：1,200,000 张图像、1,000 个类别，系统按 **top-5** 分数评价——正确类别出现在前五个预测里的频率。AlexNet 的错误率是 **15.3%**，次好系统的错误率超过 **25%**。AlexNet 有五个卷积层，其间插入最大池化层，后面是三个全连接层。它用 ReLU，并用 GPU 加速训练 **6,000 万**个权重。

2012 年以来，随着网络设计、训练方法和计算资源的改进，top-5 错误率降到 **2% 以下**，低于受过训练的人（大约 **5%**）。CNN 已被用于从自动驾驶到给黄瓜分级的广泛视觉任务。驾驶在 25.7.6 和第 26 章若干节讨论，是要求最高的视觉任务之一：算法不但要检测、定位、跟踪并识别鸽子、纸袋和行人，还要实时、近乎完美地做到。

关于黄瓜：广为流传的“日本瓜农用 TensorFlow 自建分拣机器人”大多是传说。算法是瓜农的儿子开发的，他此前在丰田做软件工程师；准确率大约 **70%**，黄瓜仍须手工分拣（Zeeberg, 2017）。

### 21.8.2 自然语言处理

深度学习也大幅影响了机器翻译、语音识别等自然语言处理应用。优势包括：端到端学习的可能、自动产生词义的内部表示、以及学到的编码器与解码器可以互换。

端到端学习指把整个系统建成单个学到的函数 `f`。例如机器翻译的 `f` 可以拿英语句子 `S_E` 作输入，产生等价的日语句子 `S_J = f(S_E)`。这样的 `f` 可以从人工翻译的句对（甚至文本对，此时对应句子或短语的对齐本身是待解问题的一部分）学到。更经典的流水线可能先分析 `S_E`，再抽取其意义，再把意义用日语重述为 `S_J`，再用日语语言模型对 `S_J` 做后编辑。流水线有两个主要缺点：每一步的错误会累积；以及人必须规定什么是“分析树”、什么是“意义表示”，而这些概念没有容易取得的真实标准，我们的理论几乎肯定不完整。

以目前的理解，经典流水线——至少天真地看，它对应人类译者的工作方式——被深度学习使之成为可能的端到端方法超过。Wu et al. (2016b) 表明，用深度学习做端到端翻译，相对此前基于流水线的系统把翻译错误相对降低了 **60%**。到 2020 年，对有非常大配对数据集的语言对（如法语和英语），机器翻译正接近人类表现；对覆盖地球上大多数人口的其他语言对，系统已经可用。甚至有一些证据表明，在多种语言上训练的网络确实学到了内部意义表示：例如学会葡语到英语、英语到西班牙语之后，可以在训练集里没有任何葡语/西语句对的情况下把葡语直接译成西班牙语。

把深度学习用于语言任务后，一个最重要的发现是：把单个词重表示成高维空间里的向量能带来很大收益，即所谓**词嵌入（word embedding）**（见 24.1）。这些向量通常从在大量文本上训练的网络的第一隐藏层权重中抽出，抓住词被使用的词汇语境统计。意义相近的词用在相似语境里，于是在向量空间里彼此靠近。网络就能在词的类别上有效泛化，而不需要人预先定义那些类别。例如以 “John bought a watermelon and two pounds of …” 开头的句子，很可能接 “apples” 或 “bananas”，而不是 “thorium” 或 “geography”。若 “apples” 和 “bananas” 在内部层有相似表示，这种预测容易得多。

> ⚠️ 待核：书页 783 印刷为 “a great deal deal of mileage”，多了一个 deal。笔记按 “a great deal” 理解，写成“很大收益”。

### 21.8.3 强化学习

强化学习（RL）里，做决策的智能体从一串奖励信号学习，这些信号对其行为质量给出某种指示。目标是优化未来奖励之和。按第 17 章的术语，可以学价值函数、Q 函数、策略，等等。从深度学习看，这些都是可以用计算图表示的函数。例如围棋里的价值函数以棋盘位置为输入，返回该位置对智能体有多有利的估计。RL 的训练方法与监督学习不同，但多层计算图能在很大的输入空间上表示复杂函数，这一点被证明非常有用。由此产生的领域叫**深度强化学习（deep reinforcement learning）**。

1950 年代 Arthur Samuel 在跳棋的强化学习工作里试验过价值函数的多层表示，但实践中线性函数近似器效果最好。（这可能是因为当时的计算机大约比现代张量处理单元弱 **1,000 亿**倍。）深度 RL 的第一次重大成功演示是 DeepMind 的 Atari 智能体 DQN（Mnih et al., 2013）。这个智能体的不同副本被分别训练去玩若干种 Atari 电子游戏，展示了射击外星飞船、用挡板弹球、开模拟赛车等技能。每种情形里，智能体从原始图像数据学一个 Q 函数，奖励信号是游戏分数。后续工作做出的深度 RL 系统，在 57 种 Atari 游戏的大多数上达到超人水平。DeepMind 的 ALPHAGO 也用深度 RL 在围棋上击败了最好的人类棋手（见第 5 章）。

尽管成功令人印象深刻，深度 RL 仍有显著障碍：常常很难得到好的性能；若环境与训练数据哪怕稍有不同，训练好的系统可能行为非常难以预料（Irpan, 2018）。与深度学习的其他应用相比，深度 RL 很少用于商业场合。它仍然是非常活跃的研究领域。

## 小结

原书小结的五条：

1. 神经网络用参数化的线性阈值单元组成的网络表示复杂非线性函数。
2. 反向传播算法在参数空间里做梯度下降，以最小化损失函数。
3. 深度学习在视觉目标识别、语音识别、自然语言处理和复杂环境中的强化学习上表现好。
4. 卷积网络特别适合图像处理以及其他数据具有网格拓扑的任务。
5. 循环网络对包括语言建模和机器翻译在内的序列处理任务有效。

> ⚠️ 待核：小结第 1 条原文是 parameterized linear-threshold units。正文单元用的是连续激活（sigmoid、tanh、ReLU、softplus），ReLU 可以看成线性整流，sigmoid / tanh 不是硬阈值。笔记照录小结原文，不改成“任意非线性单元”。

把各节的要点收在一起：

- **21.1** 前馈网络是有向无环图。单元 `aⱼ = gⱼ(w⊤ x)`（21.1），含固定 `+1` 的虚输入。两层（先非线性、后线性）的万能逼近需要指数大的网络。平方损失下，输出权重梯度是 `Δ₅ a₃`，更早的权重把感知误差沿路径乘回去（21.4）（21.5）。`g′ ≈ 0` 造成梯度消失。反向传播是反向模式自动微分。
- **21.2** 布尔输入通常 0/1；类别用独热，不要用无语义的整数相邻（Thai=3、burger=4）。多类用 softmax；`⟨5, 2, 0, −2⟩ → ⟨0.946, 0.047, 0.006, 0.001⟩`。回归的线性输出加固定方差高斯等于平方误差。负对数似然是 (21.6)。
- **21.3** 全连接百万像素 RGB 被原书写成 9 万亿权重。局部连接加权重复制把参数降到与 `n` 无关的 `dl`。卷积 (21.8)；图 21.4 核 `[+1,−1,+1]`、步幅 2，输出 `5, 9, 4`。步幅 1 时第 `m` 层感受野 `(l−1)m+1`；步幅大于 1 时 `O(l s^m)`。平均池化在 `l = s` 时按下采样因子 `s` 变粗（`10s` 像素变成 10）；最大池化 `[5,9,4]→9`，像逻辑析取。张量例：`256×256×3×64` 经 96 个 `5×5×3`、步幅 2 的核，得到 `128×128×96×64`。残差层是扰动而不是替换；(21.10) 在 `V = 0` 且 ReLU 幂等时，该层等于不存在。
- **21.4** 更新 `w ← w − α ∇_w L(w)`。小批量 SGD、下降的学习率、动量、以及数值上的消失/爆炸。回传 (21.11)(21.12)；共享权重的梯度是各处贡献之和。内存与单元数成正比。批归一化 `ẑᵢ = γ(zᵢ−μ)/√(ε+σ²)+β`。
- **21.5** 固定参数量时十一层的测试误差远低于三层（图 21.7，街景门牌）。成功意味着任务可以用 `10` 到 `10³` 步的并行程序解决。对抗样本可以把狗改成鸵鸟或校车。权重衰减惩罚 `λ Σ Wᵢ,ⱼ²`，`λ` 常在 `10⁻⁴` 附近，对应零均值高斯先验下的 MAP。dropout：以概率 `p` 把输出乘 `1/p`，否则置 0；隐藏层 `p = 0.5`，输入层 `p = 0.8`；测试时关闭。
- **21.6** 展开后权重跨时间共享。(21.15) 使沿时间反向传播对网络大小线性。`g′ ≤ 1` 时，`w_{z,z} < 1` 梯度消失，`w_{z,z} > 1` 梯度爆炸；一般看 `W_{z,z}` 的第一特征值。LSTM 用遗忘门、输入门、输出门（值在 `[0,1]`）以加法更新记忆细胞，避免梯度连乘。
- **21.7** PPCA 的边缘是 `N(x; 0, WW⊤+σ²I)`（21.16）。线性自编码器与 PCA 的主成分对应。ELBO 是 `log P(x)` 减去 `D_KL(Q(z)∥P(z|x))`（21.17）。WaveNet：每秒 16,000 次采样、4800 阶。GAN 在均衡时生成器复现训练分布、判别器不能好于随机猜测。迁移：复制权重，常冻结前几层；COCO 每类 3,000 张以上，独轮车只有几百张。多任务的例子是同时做八项语言任务。
- **21.8** AlexNet：15.3% top-5 错误，次好超过 25%；五个卷积层加最大池化，三个全连接，6,000 万权重。此后 top-5 低于 2%，受训人类大约 5%。端到端翻译相对流水线把错误相对降低 60%（Wu et al., 2016b）。DQN 从原始图像和游戏分数学 Q 函数；后续系统在 57 个 Atari 游戏的大多数上达到超人水平。

- 感知机：Rosenblatt (1957)；1958 年 7 月演示后《纽约时报》的报道把预期说得极高。收敛定理 Rosenblatt (1960)，更早的纯数学工作有 Agmon (1954)、Motzkin and Schoenberg (1954)。多层的早期工作包括 Gamba 感知机和 madaline（Widrow, 1962）。Minsky and Papert (1969) *Perceptrons* 指出单层只能表示线性可分概念，且多层缺少有效学习算法；这些限制当时已知（Hawkins, 1961；Rosenblatt, 1962）。

(2013) 用深度卷积网络赢得 ImageNet（Russakovsky et al., 2015）。ReLU 取代逻辑斯谛 sigmoid（Jarrett et al., 2009；Nair and Hinton, 2010；Glorot et al., 2011），其后是残差网络（He et al., 2016）。小批量 SGD（Bottou and Bousquet, 2008）和批归一化（Ioffe and Szegedy, 2015）是算法侧的关键。关于过参数化网络上 SGD 常达到训练误差为零的全局极小，已有定理，但这些定理假定的层宽远超实践（Allen-Zhu et al., 2018；Du et al., 2018）；这样的网络有足够容量充当训练数据的查找表。

- 沿时间反向传播出现在 Werbos (1974) 的博士论文。Elman (1990) 建在 Jordan (1986) 的架构上。Bengio et al. (1994) 分析循环网的梯度消失。LSTM：Hochreiter (1991)；Hochreiter and Schmidhuber (1997)；Gers et al. (2000)。
- 权重衰减：Hinton (1987)；Krogh and Hertz (1992)。dropout：Srivastava et al. (2014a)。对抗样本：Szegedy et al. (2013)。GAN：Goodfellow et al. (2015a)。VAE：Kingma and Welling (2013)；Rezende et al. (2014)。概率 PCA：Tipping and Bishop (1999)；PCA 本身可追溯到 Pearson (1901)，名称来自 Hotelling (1933)。
- 深度与浅层的表达力：Poole et al. (2017) 表明深网络（浅网络则否）能把复杂函数拆成隐藏单元空间里的平坦流形。Rolnick and Tegmark (2018) 表明，逼近某类 `n` 元多项式所需单元数，浅网络是指数的，深网络只是线性的。
- 架构搜索的文献结果（正文 21.5.2 没有点名这些系统）：White et al. (2019) 的 BANANAS 在只训练 200 个随机架构之后，能把网络准确率预测到 1% 以内。Yu et al. (2019) 表明有些情形下这些算法并不比随机选择架构更有效。综述见 Elsken et al. (2018)。
- 曾经流行、写作时已不积极探索的分支：Hopfield 网络（Hopfield, 1982）节点两两对称连接，可把模式存进联想记忆，用模式的片段检索整个模式；它是确定性的。后来推广为随机的玻尔兹曼机（Hinton and Sejnowski, 1983, 1986），可能是最早的深度生成模型。玻尔兹曼机推断困难，推动了蒙特卡洛和变分技术（见 13.4）。
- 现代教材：Goodfellow et al. (2016)，Charniak (2018)。LeCun、Bengio、Hinton 的 *Nature* 文章（2015）；三人获 2018 年图灵奖。主要会议：NeurIPS、ICML、ICLR。主要期刊：*Machine Learning*、*Journal of Machine Learning Research*、*Neural Computation*。
