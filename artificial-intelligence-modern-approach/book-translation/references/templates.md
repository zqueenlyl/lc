## 3. 自检清单

每节翻译完逐条打勾。

### 信

- [ ] 每个数字、下标、变量名都与原文逐字符比对过
- [ ] 公式推导步骤完整，没有跳步
- [ ] 条件 / 结论方向没写反（T1）
- [ ] 需要消元的变量已全部消元（T2）
- [ ] 二值 / 离散性质没被写成连续量（T3）
- [ ] "未知"没被写成"已知为否"（T4）
- [ ] 没有把文献示例当成原书示例（T6）
- [ ] 复杂度 / 规模断言是逐字抄的（T7）

### 达

- [ ] 朗读一遍，没有翻译腔
- [ ] 被动句 ≤ 20%
- [ ] 单句 ≤ 60 字
- [ ] 枚举 / 性质 / 步骤已列表化

### 术语

- [ ] 全部术语查过术语表，无自造译法
- [ ] 同一英文全篇译法统一
- [ ] 同形异义词已按语境取义
- [ ] 人名、算法名、缩写按 §4 处理

### 结构

- [ ] 小节号与官方目录一致，无跳号
- [ ] 三级标题有编号
- [ ] 作者发挥已加 `【延伸·非原著】`（T8）

### 复核

- [ ] 用原文回查了至少 1 处关键数值
- [ ] 拿不准的地方标注 `⚠️ 待核`，没有硬编
- [ ] 新增术语已回填术语表
- [ ] 新踩的坑已记入项目配置 §5

## 4. 输出模板

```
# 第 N 章 <中文章名>

## 0. 本章要解决的问题        ← 一句话说清动机
## N.1 <小节号> <中文标题>（English）
  ### N.1.1 <三级标题>
## ...
## 小结                        ← 原书 Summary 的要点重述
## 附：核心术语中英对照        ← 表格（| 中文 | English |）
## 延伸阅读                    ← 原书注释 + 交叉章节
```

**写作口径**：

- 用**精炼自然语言重述**，不是逐句翻译。
- 保留原书的教学线索（"注意""直觉上""常见错误"）。
- 数值示例必须带完整推导。
- 章末术语表用 `| 中文 | English |` 两列表。
