# 陷阱类型库：8 类高频错误

> 配套 `SKILL.md` §8。本文只给**类型说明与检测方法**；具体实例写在各书的 `<书名>-翻译项目配置.md` 里。
>
> 分类原则：按**错误的认知成因**分，不按章节分。同一类型会在不同章反复出现。

---

## 总原则

陷阱分三级，处理方式不同：

| 级别 | 含义 | 处理 |
|---|---|---|
| 🔴 | **硬错误**——教会读者一个错的结论 | 必须改，并回查原文确认 |
| 🟡 | **术语/表述错误**——不致命但误导 | 必改，通常查术语表即可 |
| 🟢 | **归属/来源错误**——内容对但出处错 | 标注清楚，或移到「延伸」区 |

**最危险的是 🔴 中的 T1–T4**：它们生成的句子**语法通顺、逻辑自洽**，语感和常识都发现不了，只能靠逐字符回查原文。

---

## T1 方向颠倒 🔴

**表现**：把方向性的关系写反或写偏。

| 子类 | 例子 |
|---|---|
| 条件关系 | 把"给定 X 后独立"写成"因为独立所以能给定 X" |
| 蕴含 / 因果 | 把"X 导致 Y"与"Y 蕴含 X"混用 |
| 双条件 | `A iff B` 写成 `B iff A`（在论证中二者的地位不同） |
| 独立性方向 | `A ⊥ B \| C` 写反为 `A ⊥ C \| B` |

**检测方法**：原文每出现一次方向性关系，就在译文里**单独圈出来**，逐字符比对三个位置——主体、客体、条件。

**为什么危险**：方向写反的句子往往仍然"像一句正确的话"，读者会照单全收。

---

## T2 缺步骤 🔴

**表现**：推导少做一步，导致中间量错误。**结论数字有时碰巧还对**，过程全错。

典型漏步：
- 需要边缘化（对未观测变量求和）却没有求和，直接拿联合分布的一行去归一化。
- 需要归一化常数 `α` 却直接把未归一化的向量当概率。
- 跳过了中间变量代入的那一步。

**检测方法**：
1. 数一遍**查询里未观测的变量有几个**——有几个就要消元几次。
2. 把译文的中间向量自己算一遍，看与原文是否一致；不一致就是漏步。

**记录模板**（写入项目配置）：

```
| 少做一次<步骤名> | <错误写法> | 正确：先<做什么>，得 α<正确向量> |
```

## T3 性质误判 🔴

**表现**：把一个函数/量的**数学性质**改了。

| 子类 | 错误 | 正确 |
|---|---|---|
| 二值 → 连续 | 把只取 `{0,1}` 的相容性指示写成小数概率 | 保留"只取 0 或 1"，小数是**求和之后**的结果 |
| 离散 → 概率 | 把类别标签写成概率 | 明确它是类别还是概率 |
| 精确 → 近似 | 把精确解写成近似 | 标注方法名（精确/近似） |

**检测方法**：看到原文里出现"要么……要么……""只取""当且仅当相容"这类措辞，立刻在译文里确认该性质被保留。

**为何易犯**：写成软概率**读起来更顺**，译者无意识中"润色"掉了硬约束。

---

## T4 类别混淆 🔴

**表现**：把"未知/被消掉/无关"写成"已知为否/已确定/已排除"。

| 子类 | 错误 | 正确 |
|---|---|---|
| 未知 ≠ 已知为否 | "其余部分已知安全" | "其余部分由独立性整体求和消掉，取值不影响结果" |
| 边缘化 ≠ 确定 | "该变量已确定" | "该变量已被求和消元" |
| 无关 ≠ 不存在 | "该因素不存在" | "该因素对本次查询无影响" |

**为什么危险**：这类错误会**丢掉原书真正的技术要点**——"靠某种性质把无关部分整体消掉"往往正是该方法的核心，写成"已知"就把精髓抹掉了。

---

## T5 近似概念混用 🟡

**表现**：两个相似但**不等价**的概念互换。

常见对子（各学科不同，需在术语表登记）：
- 两两独立 vs 相互独立
- 必要条件 vs 充分条件
- 上界 vs 精确界
- 启发式 vs 可采纳启发式

**检测方法**：术语表里为这类对子**单独建一节**，并在备注栏写明"⚠️ X 不蕴含 Y"。翻译时遇到其中一个，强制回头看备注。

---

## T6 版本 / 来源错 🟡

**表现**：

| 子类 | 例子 |
|---|---|
| 版本混 | 拿旧版的结构/示例当新版（章节号、示例都可能变过） |
| 示例归属混 | 把**文献里的经典示例**当成**原书正文的示例** |
| 章节号记忆错 | 凭印象写章节号（新旧版顺序可能不同） |

**检测方法**：
1. 章节号一律查**官方目录**，不凭记忆。
2. 任何"著名的例子"，确认它在原书**正文**出现，还是只在**习题/参考文献**出现；只在前者的才能写"原书示例"。

---

## T7 量化描述错 🟡

**表现**：把复杂度、规模、增长率写错。

| 子类 | 例子 |
|---|---|
| 时间/空间混淆 | "常数空间"实为 `O(t)` |
| 类别混淆 | `-完全` vs `-难`（或反过来） |
| 规模量级 | 差一个数量级、把线性写成常数 |

**检测方法**：原文每出现一次复杂度/规模断言，回查原文**逐字抄**，不改写措辞。

---

## T8 归属错误 🟢

**表现**：

| 子类 | 处理 |
|---|---|
| 作者发挥混入正文 | 加 `【延伸·非原著】` |
| 他书术语当本书术语 | 注明出处 |
| 引用他人成果未标注 | 补出处 |

**原则**：译稿里"原文如此"与"译者补充"必须**视觉上可区分**，否则读者无法判断哪些是要考的内容。

## 记录模板

每踩一个新坑，按下面格式写入 `<书名>-翻译项目配置.md`：

```
| # | 类型 | 错误写法 | 正确写法 | 出处 |
| - | ---- | -------- | -------- | ---- |
| 1 | T1 方向颠倒 | `...` | `...`（原文：<章/页>） | Ch N |
```

**要求**：
- **必须写出"正确写法"**，不能只写"这里错了"。
- 必须标出处（章/页），便于日后回查。
- 同一类型在同一本书里出现多次，合并成一行 + 备注。
