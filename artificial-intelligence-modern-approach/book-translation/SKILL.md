# 书籍翻译方法论（英 → 中）

一套**与具体书目无关**的翻译与精校流程。适用于：教材 / 技术书籍的章节翻译、译稿核查、笔记重写、术语统一。

核心思想是**把"方法"与"数据"分离**：方法是稳定的，每本书的数据（术语、页码、专有名词、踩过的坑）单独建文件。

---

## 0. 三条铁律

1. **术语表优先于个人语感。** 表中已有的译法不得另起炉灶；表内 🚫 标记的译法绝对禁用。
2. **拿不准就查原书，不凭领域常识推断。** 译稿里最危险的错误全部源于"觉得应该是这样"——读起来通顺、逻辑自洽、但与原书相反。
3. **原文没有的内容必须标记。** 任何引申、类比、现代视角一律加 `【延伸·非原著】`，与事实性内容分离。

---

## 1. 总则：信 / 达 / 雅 的裁决顺序

| 层 | 要求 | 违反后果 | 判定方法 |
|---|---|---|---|
| **信**（最高） | 不增不减、不改数值、不颠倒逻辑关系 | 🔴 教错人，必须修 | 逐个数对回原文；核对条件/结论方向 |
| **达** | 中文通顺，无翻译腔 | 🟡 影响理解 | 朗读一遍；被动句占比 ≤ 20% |
| **雅**（最低） | 简洁有力，可读 | 🟢 锦上添花 | 在不损"信""达"的前提下优化 |

**冲突时 信 > 达 > 雅。** 绝不允许为了句子好看牺牲精确性——例如把二值函数改写成小数更好读，但它是错的。

### 1.1 数值与公式

- 原文的**每个数字、下标、变量名**原样搬运，不得"顺手化简"。
- 公式用代码块包裹；变量名与下标保留原文形式，不转写。
- **推导过程必须完整**，不得只写结论——推导步骤本身常是考点。
- 原文若是二值/离散性质（只取 0 或 1、只取互斥类别），译文必须保留该性质，不能写成连续小数。

### 1.2 逻辑关系词

| 英文 | 译法 | 说明 |
|---|---|---|
| given | 给定 | 条件化的"给定" |
| conditional on | 以……为条件 | |
| iff / if and only if | 当且仅当 | 不写"等价于" |
| such that | 使得 | |
| w.r.t. | 关于 | |

⚠️ **方向敏感**：`A iff B` 与 `B iff A` 在论证中的地位不同；条件与结论不可互换。

## 2. 项目初始化：每本书建两份工件

接手一本新书时，**先建这两份文件，再动笔翻译**：

| 工件 | 放什么 | 不放什么 |
|---|---|---|
| **`<书名>-术语对照表.md`** | 术语中英对照、小节标题对照、同形异义分列、禁用译法 | 任何"怎么翻"的方法说明 |
| **`<书名>-翻译项目配置.md`** | 源文件定位与页码索引、参考译本、专有名词清单、本书踩过的陷阱实例、信源清单 | 通用方法论（那在本 skill 里） |

骨架见 `references/templates.md`。

**为什么必须分开**：方法论跨书复用，术语表随书增长。混在一起会导致每换一本书就复制一遍方法，且表更新时容易改坏规则。

---

## 3. 术语判定流程

遇到英文术语，按序决定译法：

```
① 查 术语对照表 ──命中──> 直接用，不得改写
        │未命中
        ▼
② 查中译本（纸书 / 电子书 / 官方目录）──命中──> 用中译本译法
        │未命中
        ▼
③ 查中文学界通行译法 ──有强共识──> 用通行译法
        │无共识
        ▼
④ 自拟译法 → 首现写「中文（English）」，并回填术语表
```

**自拟译法的四条约束**：

1. 优先**直译**而非意译（避免用本领域已有固定含义的词去套）。
2. 不造新词，除非英文确实是本书首创。
3. 一词一译，**全章全篇统一**。
4. 同一英文在不同语境含义不同时，**必须分列**（在术语表「同形异义」节登记，不要合并成一行）。

---

## 4. 专有名词规则

| 类别 | 规则 |
|---|---|
| **人名** | 保留英文；以人名命名的定理/指数/策略，音译 + 保留英文；**不强行音译缩写名** |
| **算法名 / 系统名** | 保留英文原样，不译 |
| **缩写** | 首次出现给全称，之后用缩写；业界通用的缩写可直接使用 |
| **代码标识符** | 完全不译（含文件名、函数名、变量） |
| **书名 / 论文** | 保留原文，用斜体或书名号，不译 |
| **本书自造专名** | 若通行译法别扭或易歧义，可在项目配置里约定"保留原文"并全书统一 |

术语首现格式：`中文（English）`。

---

## 5. 数学符号规则

1. 变量名保留英文，下标用 Unicode 下标。
2. 运算符不译（`argmax`、`Σ`、`∨` 等）。
3. 向量/元组用尖括号，分量顺序对应原文。
4. 关系符号（如独立、蕴含、偏序）**方向不可写反**。
5. 独立成行的公式用代码块；行内公式用反引号。
6. 复杂度记号（大 O）保留原样。

---

## 6. 文体与句法规则

| 规则 | 说明 |
|---|---|
| **被动转主动** | 英文被动句常占 30%+，中文应降至 20% 以下 |
| **长句拆分** | 超过约 60 字的句子拆成 2 句 |
| **删除冗余限定** | "it should be noted that" 之类不译 |
| **保留原书语气** | 原书的"注意""直觉上""常见错误"要保留，是教学线索 |
| **不添加原文没有的内容** | 尤其不添加当代类比 |
| **第一人称** | 原书用 "we" 时译"我们"，保持对话感 |
| **列表化** | 原文的枚举、性质、步骤一律用列表/表格 |
| **段落长度** | 每段 ≤ 5 行，超了就切 |

**中英混排**：英文术语前后加空格；标点用中文全角，代码块内用半角。

---

## 7. 标题与结构规则

```
## <章号> <中文标题>（<English Title>）
### <小节号> <中文标题>
```

- 二级标题：中文 + 括号附英文，便于对照原书。
- 三级标题：只写中文，但**小节号必须与原书一致**。
- **章节号体系以权威目录（出版社官网 / 官方 TOC）为准，不得跳号或自行编号。**
- 标题本身也是术语：先查术语表，未命中再按 §3 自拟。
- 章级（二级）标题争取与中译本核对；小节（三级）若为自拟，需在术语表里标注"未核对"。

## 8. 陷阱类型库

翻译中最容易犯的错误有固定模式，逐条自查。完整类型说明与记录模板见 `references/pitfalls.md`：

| # | 类型 | 一句话 |
|---|---|---|
| T1 | **方向颠倒** | 条件独立 / 蕴含 / 因果 / iff 写反 |
| T2 | **缺步骤** | 少做一次边缘化、求和、归一化，导致中间量错 |
| T3 | **性质误判** | 二值写成连续、离散类别写成概率值 |
| T4 | **类别混淆** | "未知"写成"已知为否"、"被消元"写成"已确定" |
| T5 | **近似概念混用** | 相似但不等价的两个概念互换（如 pairwise vs mutual） |
| T6 | **版本/来源错** | 拿旧版内容当新版、拿文献示例当原书示例 |
| T7 | **量化描述错** | 复杂度类别、空间/时间、上界/精确值张冠李戴 |
| T8 | **归属错误** | 作者发挥混入正文、他人成果未标注 |

⚠️ **T1–T4 是"读起来通顺但教错人"的错误**，只能靠回查原文发现，靠语感发现不了。

---

## 9. 信源优先级

| 级别 | 来源 | 用途 |
|---|---|---|
| **A** | 原书 PDF（带文本层） | 一切数值、公式、示例归属的终裁 |
| **B** | 出版社官方目录 / 官网 | 章节编号体系 |
| **C** | 官方勘误页 | 原书已知错误 |
| **D** | 正式中译本 | **译名权威** |
| **E** | 电子书平台的划线/摘录原文 | 译名抽样校验 |
| **F** | 网络二手资料 | 仅限交叉验证，**不得单独作为依据** |

**能力边界要如实记录**：例如某电子书 API 若只有划线接口、没有正文接口，就只能在项目配置里写明"可校验译名、不可做内容核查"，不能假装它提供了正文级证据。

## 10. 工作流

```
① 建工件       → §2：术语表 + 项目配置
② 定位原文     → 项目配置的页码索引
③ 提取权威目录 → 信源 B，确定小节编号
④ 翻译一节     → §1 总则 + §3 术语 + §4–7 各项规则
⑤ 过自检清单   → references/templates.md「自检清单」
⑥ 回查原文     → 至少核 1 处关键数值（信源 A）
⑦ 回填术语表   → §3 第 ④ 步
⑧ 记录新陷阱   → pitfalls.md 模板，写入项目配置
```

**每章完成后**用 `references/templates.md` 的自检清单逐条打勾，再进入下一章。

## 11. 输出模板

每章笔记的推荐结构（可按书调整，写进项目配置）：

```
# 第 N 章 <中文章名>

## 0. 本章要解决的问题        ← 一句话说清动机
## N.1 <小节号> <中文标题>（English）
  ### N.1.1 <三级标题>
## ...
## 小结                        ← 原书 Summary 的要点重述
## 附：核心术语中英对照        ← 表格
## 延伸阅读                    ← 原书注释 + 交叉章节
```

**写作口径**：

- 用**精炼自然语言重述**，不是逐句翻译。
- 保留原书的教学线索（"注意""直觉上""常见错误"）。
- 数值示例必须带完整推导。
- 章末术语表用 `| 中文 | English |` 两列表。
