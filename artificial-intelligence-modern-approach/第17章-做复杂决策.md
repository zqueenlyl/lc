## 0. 本章要解决的问题

第 16 章是一次性决策。真实问题要求**在时间上做序列决策**：

- 当前动作会影响未来状态与未来收益
- 现在"牺牲"一点，是为了将来获得更多
- 又要在"探索未知"与"利用已知"之间权衡

本章依次引入：**MDP**（完全可观测）→ **老虎机问题**（最简单的序贯决策）→ **POMDP**（部分可观测）。

## 17.1 序贯决策问题

### 马尔可夫决策过程（MDP）

**四要素**：

```
MDP = ⟨S, A, P(s' | s, a), R(s, a, s')⟩
```

| 要素 | 含义 |
|---|---|
| `S` | 状态集合（含初始状态） |
| `A(s)` | 状态 s 可用的动作 |
| `P(s' | s, a)` | **转移模型** |
| `R(s, a, s')` | **奖励**：沿转移 `s --a--> s'` 获得，有界 `±R_max` |

**马尔可夫性质**：`P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`——未来只依赖当前状态与动作。

### 17.1.1 时间上的效用

- 环境可能永不终止 → 需比较**无限序列**。使用**折扣累积奖励（discounted reward）**：

```
U_h([s₀,a₀,s₁,…]) = Σ_{t=0}^{∞} γᵗ R(s_t, a_t, s_{t+1})       0 ≤ γ ≤ 1
```

- `γ` 为**折扣因子**：γ 接近 0 更短视，接近 1 更看重长远；γ = 1 时退化为纯累加
- γ < 1 且奖励有界时，效用 ≤ `R_max / (1−γ)`
- **平稳偏好**：两条历史若以同一次转移开头，则它们的偏好序应与去掉这次转移后的后缀相同。满足该假设的历史效用只有加法折扣这一种形式

### 17.1.2 最优策略与状态的效用

- **策略 π**：`π(s) → a`（确定性）或 `π(a | s)`（随机）
- **策略效用**：`U^π(s) = E[Σ_{t} γᵗ R(s_t) | π, s_0 = s]`
- **最优策略** `π*`：使每个状态的效用最大
- 关键性质：**最优策略的后续部分也是最优的**（最优性原理）

### 17.1.3 奖励尺度

（奖励的正仿射变换 `R' = mR + b`（`m > 0`）不改变最优策略。更强的是**整形定理**：对任意势函数 Φ，`R'(s,a,s') = R(s,a,s') + γΦ(s') − Φ(s)` 也不改变最优策略。若取 Φ = U，则对修改后奖励的贪心策略就是最优策略。）

### 17.1.4 MDP 的表示

（原书讨论如何用**动态决策网络 / 因子化表示**（DBN + 决策/效用节点）紧凑地描述大规模 MDP，避免显式列出 `|S|·|A|·|S|` 的转移表。）

### 有限时域 vs 无限时域

- **有限时域**：折扣可能不需要（因为 t 有限）；效用可能是**非平稳**的（剩余步数不同，最优动作不同）
- **无限时域**：存在**平稳**最优策略；只需比较 γ 是否可近似为 1

## 17.2 MDP 的算法

### 贝尔曼方程（Bellman equation）

最优效用 `U(s)` 满足递归关系：

```
U(s) = max_a Σ_{s'} P(s' | s, a) · [ R(s, a, s') + γ · U(s') ]
```

**直觉**：在最优动作下，下一步转移的期望（即时奖励 + 折扣后的后继效用）。`max` 在求和之外，奖励在期望里面，折扣只乘后继效用。

### 17.2.1 价值迭代（Value Iteration）

- 反复对每个状态应用贝尔曼更新：

```
U_{i+1}(s) ← max_a Σ_{s'} P(s' | s, a) · [ R(s, a, s') + γ · U_i(s') ]
```

- 从任意初值开始（如 `U_0(s) = 0`），迭代至收敛
- 收敛后提取策略（**策略提取**）：

```
π*(s) = argmax_a Σ_{s'} P(s' | s, a) · [ R(s, a, s') + γ · U(s') ]
```

- **时间复杂度**：每次迭代 O(|S|² |A|)；总代价正比于 |S|² |A| 乘以收敛所需迭代次数

**例子（书中）**：4×3 网格。动作朝意图方向成功的概率是 **0.8**，另外 0.2 分到两个垂直方向（各 0.1）；撞墙留在原地。非终止转移奖励 **−0.04**，进入两个终止格的转移奖励 **+1** 与 **−1**。图 17.3 的状态效用用 **γ = 1**。起点 (1,1) 的最优期望总奖励是 **0.7453**。

### 17.2.2 策略迭代（Policy Iteration）

交替两个步骤：

1. **策略评估**：解线性方程组 `U(s) = Σ_{s'} P(s' | s, π(s)) [ R(s, π(s), s') + γ U(s') ]`
2. **策略改进**：`π(s) ← argmax_a Σ_{s'} P(s' | s, a) [ R(s, a, s') + γ U(s') ]`，直到策略不再变化

- 策略数有限，保证收敛；通常**迭代次数远少于价值迭代**，但每次迭代代价更高（O(|S|³) 解方程组）
- 变体：修正策略迭代（先做少量评估步）

### 17.2.3 线性规划方法

把 MDP 写成一族线性约束，用 LP 求解：

```
最小化各 U(s)   s.t.  U(s) ≥ Σ_{s'} P(s' | s, a) [ R(s, a, s') + γ U(s') ]   ∀s, a
```

- 线性规划多项式时间 ⇒ MDP 可在状态数、动作数（及描述模型的比特数）的**多项式时间**内求解；实践中通常不如动态规划快

---

### 17.2.4 MDP 的在线算法

价值迭代 / 策略迭代 / 线性规划都要**遍历整个状态空间**，状态一多就不可行。在线算法只在智能体**实际访问到的状态**上做更新：

| 思路 | 说明 |
|---|---|
| **实时动态规划（RTDP）** | 在真实或模拟轨迹上做异步贝尔曼更新；与第 4 章 LRTA* 同类 |
| **期望最大（expectimax）与 UCT** | 决策节点取 max、机会节点取期望；γ = 0.5、ε = 0.1、R_max = 1 时 ε-视界深度 H = 5，γ = 0.9 时 H = 44。4×3 上 UCT 平均约 160 次模拟才到总奖励 0.4，而最优策略从起点的期望是 0.7453 |
| 与强化学习的关系 | 在线算法只需一个**生成模型 / 真实环境交互**来采样后继，不必显式知道 `P(s'|s,a)`——这正是第 22 章强化学习的起点 |

## 17.3 老虎机问题（Bandit Problems）

> 原书小节：17.3.1 计算 Gittins 指数、17.3.2 伯努利老虎机、17.3.3 近似最优策略、17.3.4 不可索引的变体（选择问题没有指数；臂是完整 MDP 的**老虎机超过程**里，局部最优动作未必全局最优，仅当 γ = 1 时两者一致）。

### 设定

每个臂是一个**马尔可夫奖励过程**（只有一个动作的 MDP）。整体状态是各臂状态的笛卡儿积；一次只能拉一个臂，臂之间独立。

### 探索与利用

| 选择 | 说明 |
|---|---|
| **利用** | 拉当前看起来最好的臂 |
| **探索** | 拉还不确定的臂，换以后的信息 |

- **后悔**：相对“事先知道最优臂”的策略少拿的期望奖励。无折扣时任何算法的后悔都不能比 O(log N) 更慢地增长
- **Gittins 指数**对**任意**这种老虎机都给出最优策略：总是拉指数最高的臂，再更新该臂的指数。不是只对伯努利臂成立

**书中数字（γ = 0.5）**：臂 M 的奖励序列 `0, 2, 0, 7.2, 0, 0, …`，臂 M₁ 恒为 1。单独拉的效用 U(M) = **1.9**，U(M₁) = **2.0**；先拿 M 的前四笔再换到 M₁，效用 **2.025**。M 的 Gittins 指数是各停止时间下“折扣奖励 / 折扣时间”的最大值 **1.0133**。重启 MDP 上价值迭代给出起点价值 2.0266，乘以 (1−γ) 仍得 1.0133。

**伯努利臂**（γ = 0.9，成功/失败计数从 1 起，即 Beta(1,1)）：状态 (3,2) 的指数 **0.7057** 高于 (7,4) 的 **0.6922**，尽管均值估计 0.6 < 0.6364——少试过的臂有探索奖励。

### 近似

- **UCB**：`μ̂ + g(N) / √Nᵢ`，例如 `g(N) = √(2 log(1 + N log² N))`，后悔 O(log N)。UCB 依赖总抽样次数，严格说不是指数
- **Thompson 采样**：按“该臂确实最优”的后验概率抽样，后悔同样 O(log N)

## 17.4 部分可观测 MDP（POMDP）

### 从 MDP 到 POMDP

**问题**：真实智能体**看不到真实状态**，只能得到有噪声的观测。

**POMDP 定义**：MDP + **传感器模型（观测模型）**

```
POMDP = ⟨S, A, P(s' | s, a), R(s), Ω, O(e | s)⟩
```

| 新增要素 | 含义 |
|---|---|
| `Ω` | 观测集合 |
| `O(e | s)` | 传感器模型：状态为 s 时观测到 e 的概率 |

### 17.4.1 POMDP 的形式定义与信念状态

**核心思想**：智能体维护关于真实状态的**概率分布** `b(s) = P(s | 历史)`。

- **信念更新**（贝叶斯滤波）：

```
b'(s') = α · O(e | s') · Σ_s P(s' | s, a) · b(s)
```

- **信念 MDP**：把信念状态当作"状态"，POMDP 就变成一个**连续状态空间**的 MDP
  - 状态空间 = 所有可能的信念分布（单纯形）
  - 动作仍是 A；转移由上述更新决定；奖励 `ρ(b, a) = Σ_s b(s) Σ_{s'} P(s'|s,a) R(s,a,s')`
  - 最优策略 `π*(b)`：**从信念到动作的映射**

### 例子

- **原书本节（§17.4）主体是形式定义**：给出 POMDP 的元组定义、传感器模型与信念状态更新，不展开数值算例。
- ✅ **已据英文原书核对**：原书用来演示 POMDP 值函数的算例是 **两状态世界（two-state world）**，见 §17.5 的 **Figure 17.15**（p.591）：世界只有两个状态 A / B，动作为 **Stay / Go**，横轴是信念状态 `b(B)`（处于状态 B 的概率），纵轴是效用。图中依次给出 1 步、2 步、去优后的 2 步、8 步最优计划的分段线性效用曲线——这是理解"值函数在信念空间上分段线性凸"的标准图，见下节。
- 【对照·非原书示例】POMDP 文献里最著名的教学例是 **Tiger 问题**（Cassandra、Kaelbling、Littman 1994）：老虎在左/右门后，动作 = "开门 / 听声音"，听声有噪声。它出现在原书**习题**中，不在 §17.4/§17.5 正文。其最优策略形态是"**先听几次，积累到足够把握再开门**"——适合建立对 POMDP 的直观理解。

**意义**：POMDP 刻画了"**在不确定中持续行动并学习**"的最一般不完全可观测决策框架。

## 17.5 求解 POMDP 的算法

### 17.5.1 POMDP 的价值迭代

#### 关键性质：分段线性凸（PWLC）

- 有限时域 POMDP 的**值函数**是信念空间上的**分段线性凸函数**：

```
U(b) = max_α Σ_s α(s) b(s)
```

- 每个 `α` 是状态空间上的一个**向量**（称为 α-vector），代表一个条件计划
- 因此可以用**有限个 α 向量**精确表示值函数

✅ **原书算例（Figure 17.15，书 p.591）**：**两状态世界**。Stay 以 0.9 留在原地，Go 以 0.9 换到另一状态；进入 A 的转移奖励 0，进入 B 的奖励 1；γ = 1；传感器以 0.6 报告正确状态。横轴 `b(B)`。一步计划的 α：Stay 在 A/B 上是 0.1 / 0.9，Go 是 0.9 / 0.1；一步最优是 `b(B) > 0.5` 时 Stay，否则 Go。图：(a) 两个 1 步计划；(b) 8 个 2 步计划；(c) 去掉被支配的，剩 4 个；(d) 8 步最优。深度 8 时计划总数是 2^255，去支配后只剩 **144** 个。八步最优策略仍是 `b(B) > 0.5` 则 Stay。

#### 精确算法

正文算法是 **POMDP 价值迭代**：每个深度 d 的计划由一个动作加上“每个观测对应一个深度 d−1 子计划”组成，然后删掉被支配的计划（图 17.16）。深度 d 的计划数是 `|A|^{O(|E|^{d−1})}`。

- **复杂度结论**：一般 POMDP 求最优策略是 **PSPACE-hard**（Papadimitriou & Tsitsiklis, 1987），不要写成“PSPACE-完全”。无限时域折扣 POMDP **不可判定**（Madani、Hanks、Condon, 1999）。

【延伸·非原著】“一次投影 / 增量剪枝”是 POMDP 文献里的算法名，不是本节给出的算法名。

### 17.5.2 POMDP 的在线算法（与近似方法）

正文的在线算法是：在**信念状态**上做 expectimax（机会节点按观测分支，转移概率是式 17.17），深度 d 的代价是 O(|A|^d · |E|^d)。信念太大时用粒子滤波；视界长时接上 UCT。粒子滤波 + UCT 称为 **POMCP**。4×3 POMDP 一例：墙传感器误差 ε = 0.2，先向左走把位置挤到少数几格，再向上、向右到达目标。

文献注里的**点式值迭代**只在有限个信念点上生成 α 向量，而不是整个信念空间。

【延伸·非原著】**QMDP**（假设下一步起完全可观测，因而低估信息价值）和用策略梯度直接拟合“信念→动作”，都不是本节算法。**AMDP** 也不是本书用语。

### 应用

- 机器人（不确定环境下导航、抓取）
- 对话系统（用户意图不可观测）
- 医疗诊断与治疗规划
- 【延伸·非原著】现代 **RLHF / 对话策略优化** 常建模为 POMDP

## 小结

1. **MDP** 用 `⟨S, A, P, R⟩` 刻画完全可观测的序贯决策；效用为**折扣累积奖励**。
2. **贝尔曼方程**是核心；**价值迭代**迭代逼近，**策略迭代**交替评估与改进，两者都能得到最优策略。
3. MDP 可用线性规划在**多项式时间**求解；在线一侧正文给出 expectimax、RTDP 与 UCT。
4. **老虎机**：各臂是独立的马尔可夫奖励过程。Gittins 指数对这种问题都最优（确定性例子的指数是 1.0133）；更现实的臂上指数难算，正文给出 UCB 与 Thompson 采样。
5. **POMDP** 引入观测模型，用**信念状态**把部分可观测问题转化为连续状态 MDP。
6. POMDP 的值函数**分段线性凸**；精确价值迭代生成条件计划再删掉被支配者。有限时域 PSPACE-hard。正文的近似路线是信念空间上的 expectimax 与 **POMCP**；点式值迭代在章末文献注。
