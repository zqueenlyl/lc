## 0. 本章要解决的问题

第 16 章是一次性决策。真实问题要求**在时间上做序列决策**：

- 当前动作会影响未来状态与未来收益
- 现在"牺牲"一点，是为了将来获得更多
- 又要在"探索未知"与"利用已知"之间权衡

本章依次引入：**MDP**（完全可观测）→ **老虎机问题**（最简单的序贯决策）→ **POMDP**（部分可观测）。

## 17.1 序贯决策问题

### 马尔可夫决策过程（MDP）

**四要素**：

```
MDP = ⟨S, A, P(s' | s, a), R(s)⟩
```

| 要素 | 含义 |
|---|---|
| `S` | 状态集合 |
| `A` | 动作集合（可用 `A(s)` 限定每状态可用动作） |
| `P(s' | s, a)` | **转移模型**：在 s 执行 a 后到达 s' 的概率 |
| `R(s)` | **奖励函数**（也常写作 `R(s, a, s')`） |

**马尔可夫性质**：`P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`——未来只依赖当前状态与动作。

### 效用与折扣

- 环境可能永不终止 → 需比较**无限序列**。使用**折扣累积奖励（discounted reward）**：

```
U(s_0, s_1, s_2, …) = Σ_{t=0}^{∞} γᵗ R(s_t)       0 ≤ γ < 1
```

- `γ` 为**折扣因子**：γ 越小越"短视"，γ → 1 越看重长远
- 求和收敛当且仅当 `R` 有界且 γ < 1
- **平稳偏好假设**：同一状态在不同时刻有相同偏好 → 效用可写成上述折扣和形式

### 策略与最优策略

- **策略 π**：`π(s) → a`（确定性）或 `π(a | s)`（随机）
- **策略效用**：`U^π(s) = E[Σ_{t} γᵗ R(s_t) | π, s_0 = s]`
- **最优策略** `π*`：使每个状态的效用最大
- 关键性质：**最优策略的后续部分也是最优的**（最优性原理）

### 有限时域 vs 无限时域

- **有限时域**：折扣可能不需要（因为 t 有限）；效用可能是**非平稳**的（剩余步数不同，最优动作不同）
- **无限时域**：存在**平稳**最优策略；只需比较 γ 是否可近似为 1

## 17.2 MDP 的算法

### 贝尔曼方程（Bellman equation）

最优效用 `U(s)` 满足递归关系：

```
U(s) = R(s) + γ · max_a Σ_{s'} P(s' | s, a) · U(s')
```

**直觉**：当前奖励 + 最优下一步的折扣期望效用。

### 价值迭代（Value Iteration）

- 反复对每个状态应用贝尔曼更新：

```
U_{i+1}(s) ← R(s) + γ · max_a Σ_{s'} P(s' | s, a) · U_i(s')
```

- 从任意初值开始（如 `U_0(s) = 0`），迭代至收敛
- 收敛后提取策略（**策略提取**）：

```
π*(s) = argmax_a Σ_{s'} P(s' | s, a) · U(s')
```

- **时间复杂度**：每次迭代 O(|S|² |A|)；总代价正比于 |S|² |A| 乘以收敛所需迭代次数

**例子（书中）**：随机游走网格 `4×3` 世界——`+1`、`−1` 目标、`0.8` 转向概率、`γ = 1`，展示效用随迭代扩散并收敛。

### 策略迭代（Policy Iteration）

交替两个步骤：

1. **策略评估**：解线性方程组求 `U^{π_i}(s) = R(s) + γ Σ_{s'} P(s' | s, π_i(s)) U^{π_i}(s')`
2. **策略改进**：`π_{i+1}(s) = argmax_a Σ_{s'} P(s' | s, a) U^{π_i}(s')`

- 策略数有限，保证收敛；通常**迭代次数远少于价值迭代**，但每次迭代代价更高（O(|S|³) 解方程组）
- 变体：修正策略迭代（先做少量评估步）

### 线性规划方法

把 MDP 写成一族线性约束，用 LP 求解：

```
最小化 Σ_s U(s)   s.t.  U(s) ≥ R(s) + γ Σ_{s'} P(s' | s, a) U(s')   ∀s, a
```

- 理论上是**多项式时间**算法；实践中通常不如迭代法快
- 价值在于给出 MDP 的**复杂度上界**：P-完全

## 17.3 老虎机问题（Bandit Problems）

### 设定

**最简单的序贯决策问题**：只有一个状态、`k` 个动作（"摇臂"），每个臂的奖励分布**未知**，观察后可再选下一个。

- 也叫 **k 臂老虎机问题（k-armed bandit）**
- 目标：最大化长期奖励

### 探索与利用（Exploration vs. Exploitation）

| 选择 | 说明 |
|---|---|
| **利用（exploitation）** | 选当前估计收益最高的臂，立即获益 |
| **探索（exploration）** | 尝试不确定的臂，为将来积累信息 |

- **后悔（regret）**：相对"一开始就选最优臂"的策略所损失的期望收益——衡量策略优劣的指标
- 二项分布臂的**最优最优解**：**Gittins 指数（Gittins index）**——为每个臂计算一个指数，总选指数最高的臂即可
  - 一般分布的 Gittins 指数计算困难

### 应用

- 临床试验（选疗效最好的疗法）
- 在线广告与推荐系统的 A/B 探索
- 定价与资源分配
- 现代算法：UCB（置信上界）、Thompson 采样

## 17.4 部分可观测 MDP（POMDP）

### 从 MDP 到 POMDP

**问题**：真实智能体**看不到真实状态**，只能得到有噪声的观测。

**POMDP 定义**：MDP + **传感器模型（观测模型）**

```
POMDP = ⟨S, A, P(s' | s, a), R(s), Ω, O(e | s)⟩
```

| 新增要素 | 含义 |
|---|---|
| `Ω` | 观测集合 |
| `O(e | s)` | 传感器模型：状态为 s 时观测到 e 的概率 |

### 信念状态（Belief State）

**核心思想**：智能体维护关于真实状态的**概率分布** `b(s) = P(s | 历史)`。

- **信念更新**（贝叶斯滤波）：

```
b'(s') = α · O(e | s') · Σ_s P(s' | s, a) · b(s)
```

- **信念 MDP**：把信念状态当作"状态"，POMDP 就变成一个**连续状态空间**的 MDP
  - 状态空间 = 所有可能的信念分布（单纯形）
  - 动作仍是 A；转移由上述更新决定；奖励 `ρ(b, a) = Σ_s b(s) R(s, a)`
  - 最优策略 `π*(b)`：**从信念到动作的映射**

### 例子（书中）

- 一个部分可观测环境：状态 = "老虎在左/右门后"，动作 = "开门/听声音"，观测嘈杂
- 最优策略的形式："先前听，若多次听到左边则有信心开左门"——策略在信念空间中分段

**意义**：POMDP 刻画了"**在不确定中持续行动并学习**"的最一般不完全可观测决策框架。

## 17.5 求解 POMDP 的算法

### 关键性质：分段线性凸（PWLC）

- 有限时域 POMDP 的**值函数**是信念空间上的**分段线性凸函数**：

```
U(b) = max_α Σ_s α(s) b(s)
```

- 每个 `α` 是状态空间上的一个**向量**（称为 α-vector），代表一个条件计划
- 因此可以用**有限个 α 向量**精确表示值函数

### 精确算法

| 算法 | 思路 |
|---|---|
| **一次投影（one-pass / exhaustive enumeration）** | 枚举所有动作与观测分支，生成下一代 α 向量 |
| **增量剪枝（incremental pruning）** | 不一次枚举全部组合，而是分步生成并**剪掉**被支配的 α 向量 |
| **值迭代（精确）** | 反复投影 + 剪枝，直到收敛 |

- 复杂度仍是**指数级**，但剪枝大幅提高实际可行性
- 有限时域 POMDP 是 **PSPACE-完全**的

### 近似算法

| 方法 | 说明 |
|---|---|
| **点式值迭代（point-based value iteration）** | 只在**可达的信念点集**上做备份，避免全空间枚举 |
| **QMDP** | 假设下一步之后可完全观测（乐观），一次算完 |
| **AMDP** | 假设当前观测永远最优（悲观） |
| **蒙特卡罗方法（POMCP 等）** | 用粒子滤波 + 蒙特卡罗树搜索在信念空间上在线求解 |
| **策略梯度 / 深度 RL** | 用神经网络直接近似信念到动作的映射 |

### 应用

- 机器人（不确定环境下导航、抓取）
- 对话系统（用户意图不可观测）
- 医疗诊断与治疗规划
- 现代 **RLHF / 对话策略优化** 常建模为 POMDP

## 小结

1. **MDP** 用 `⟨S, A, P, R⟩` 刻画完全可观测的序贯决策；效用为**折扣累积奖励**。
2. **贝尔曼方程**是核心；**价值迭代**迭代逼近，**策略迭代**交替评估与改进，两者都能得到最优策略。
3. MDP 求解**多项式时间**（P-完全）；线性规划给出另一视角。
4. **老虎机问题**是只有一个状态的序贯决策，核心矛盾是**探索与利用**；Gittins 指数给出二项臂的最优解。
5. **POMDP** 引入观测模型，用**信念状态**把部分可观测问题转化为连续状态 MDP。
6. POMDP 的值函数**分段线性凸**，精确求解用 α 向量投影 + 剪枝；实际多用**近似算法**（点式值迭代、QMDP/AMDP、蒙特卡罗）。
