# 第 14 章 时间上的概率推理（Probabilistic Reasoning over Time）

> 来源：《人工智能：现代方法（第 4 版）》第四部分「不确定知识和不确定推理」
> 作者：Stuart Russell、Peter Norvig ｜ 中文版：人民邮电出版社
> 说明：本文为按原书章节结构整理的**学习笔记**（非逐字原文）。

## 0. 本章要解决的问题

第 13 章的贝叶斯网络是**静态**的。真实智能体需要**随时间不断更新信念**：机器人定位、语音识别、经济预测、病人监护……

**时间切片模型（temporal model）**：把世界看作离散时间步上的状态序列，用一族随机变量描述。

---

## 14.1 时间与不确定性

### 14.1.1 状态与观测

| 变量 | 记号 | 含义 |
|---|---|---|
| **状态变量** | `Xₜ` | 时刻 t 世界的真实状态（不可直接观测，也称隐变量） |
| **证据/观测变量** | `Eₜ` | 时刻 t 的传感器读数 |

表示：

- 序列记号：`X_{a:b}` 表示从 a 到 b 的变量序列；`e_{1:t}` 表示从时刻 1 到 t 的全部证据（含 t）
- 例子（雨伞世界）：`Rₜ`（是否下雨，状态）、`Uₜ`（是否带伞，观测）

### 14.1.2 转移模型与传感器模型

**三条基本假设**（使问题可解）：

1. **一阶马尔可夫假设**：`P(Xₜ | X_{0:t−1}) = P(Xₜ | X_{t−1})`
   → 当前状态只依赖上一时刻状态，历史可被"遗忘"
2. **传感器马尔可夫假设**：`P(Eₜ | X_{0:t}, E_{1:t−1}) = P(Eₜ | Xₜ)`
   → 观测只依赖当前状态
3. **平稳过程假设**：转移模型 `P(Xₜ | X_{t−1})` 与传感器模型 `P(Eₜ | Xₜ)` **不随时间改变**

**模型组成**：

| 组成 | 形式 | 说明 |
|---|---|---|
| **先验** | `P(X₀)` | 初始状态分布 |
| **转移模型** | `P(Xₜ | X_{t−1})` | 状态如何演化 |
| **传感器模型** | `P(Eₜ | Xₜ)` | 观测如何由状态产生 |

> **雨伞世界**：转移模型 `P(Rₜ | R_{t−1})`（今天是否下雨受昨天影响），传感器模型 `P(Uₜ | Rₜ)`（下雨时更可能带伞）。

## 14.2 时序模型中的推断

四类基本推断任务：

| 任务 | 查询 | 用途 |
|---|---|---|
| **滤波（filtering）** | `P(Xₜ | e_{1:t})` | 实时跟踪当前状态 |
| **预测（prediction）** | `P(X_{t+k} | e_{1:t})` | 预测未来 |
| **平滑（smoothing）** | `P(X_k | e_{1:t})`，k < t | 事后分析（历史重建） |
| **最可能序列**（原书 §14.2.3 标题：Finding the most likely sequence） | `argmax_{x_{1:t}} P(x_{1:t} | e_{1:t})` | 语音识别、序列解码（Viterbi） |

### 14.2.1 滤波与预测

**递归估计（recursive estimation）**——先预测、后更新：

```
P(Xₜ | e_{1:t}) = α · P(eₜ | Xₜ) · Σ_{x_{t−1}} P(Xₜ | x_{t−1}) · P(x_{t−1} | e_{1:t−1})
                  └── 传感器更新 ──┘  └────────── 转移/预测 ──────────┘
```

即两个步骤循环：

1. **预测（prediction / projection）**：`P(Xₜ | e_{1:t−1}) = Σ_{x_{t−1}} P(Xₜ | x_{t−1}) P(x_{t−1} | e_{1:t−1})`
2. **更新（update）**：`P(Xₜ | e_{1:t}) = α P(eₜ | Xₜ) P(Xₜ | e_{1:t−1})`

优点：只需**常数空间**与**常数时间**（每步），与 t 无关——这是所有在线跟踪算法的基础。

### 14.2.2 平滑

平滑比滤波更精确（用了更多证据），但通常无法在线递推。

**前向-后向算法（forward–backward）**：

```
P(X_k | e_{1:t}) = α · P(X_k | e_{1:k}) · P(e_{k+1:t} | X_k)
                    └── 前向（滤波结果）──┘  └── 后向 ──┘

其中后向递推：P(e_{k+1:t} | X_k) = Σ_{x_{k+1}} P(e_{k+1} | x_{k+1}) P(e_{k+2:t} | x_{k+1}) P(x_{k+1} | X_k)
```

- **时间复杂度 O(t)**（前向 O(t) + 后向 O(t)）
- ⚠️ **空间复杂度也是 O(|f| t)**：必须保存每个时刻的前向消息 `f_{1:k}`（后向递推时要与它们相乘）。练习 14.ISLE 的做法可把空间降到 `O(|f| log t)`，时间大约再乘一个 `log t` 因子。14.3 的固定滞后平滑在某些情形下可以做到常数空间。
- 与滤波的对比：滤波只需 **O(1) 空间**（每步只保留当前信念），平滑做不到
- 应用：语音识别中的声学模型后处理、历史状态重建

### 14.2.3 寻找最可能序列

**Viterbi 算法**：求 `argmax_{x_{1:t}} P(x_{1:t} | e_{1:t})`。递推的消息不是条件概率，而是

```
m_{1:t} = max_{x_{1:t−1}} P(x_{1:t−1}, Xₜ, e_{1:t})
m_{1:t+1} = P(e_{t+1} | X_{t+1}) · max_{xₜ} [ P(X_{t+1} | xₜ) · m_{1:t} ]
```

- 与滤波递推**形式相同**，但把"求和"换成"**取最大**"，并且**没有**归一化常数 `α`。`m` 与"给定证据的最可能路径概率"只差一个常数 `P(e_{1:t})`，`max` 不在乎这个常数，所以 `argmax` 仍是最可能序列
- 需要**回溯（backpointer）**才能恢复完整路径；因此空间是 `O(t)`，不像滤波那样常数空间
- 应用：语音识别等序列解码。平滑给出的是每个时刻的边缘后验，把各时刻的众数拼起来**不一定**是这条整体最优路径

## 14.3 隐马尔可夫模型

**HMM = 时序模型的特例**：状态是**单个离散变量**。

- 转移矩阵：`T_{ij} = P(Xₜ = j | X_{t−1} = i)`，大小 S × S
- 传感器/观测矩阵：`O_{ik} = P(Eₜ = k | Xₜ = i)`

### 14.3.1 简化矩阵算法

把前向递推写成向量-矩阵形式：

```
f_{1:t+1} = α · O_{t+1} · (Tᵀ · f_{1:t})
```

- 规范形式为 `f_{1:t+1} = α · O_{t+1} · Tᵀ · f_{1:t}`
- 每一步代价 **O(S²)**（矩阵-向量乘法）
- 是 HMM 上滤波、平滑、Viterbi 的统一实现基础

### 14.3.2 隐马尔可夫模型示例：定位

经典例子：真空世界迷宫上的 **HMM 定位**（即第 4 章图 4.18 那张迷宫，不是 4×3 网格）。

- 状态：空格子的位置，标成 `{1,…,S}`。这张图 **`S = 42`**，转移矩阵 `42×42 = 1764` 项
- 转移：`Move` 后**等可能**走到任一相邻空格：`T_{ij} = 1/N(i)` 若 `j` 相邻，否则 0。没有"原地不动 / 打滑"这套失败模型
- 先验：`P(X₀=i) = 1/S`
- 观测：东南西北四个障碍位，共 **16** 种四比特读数。每位独立出错，`ε = 0.2`。与真实障碍差 `d` 位时，`P(E=e|X=i) = (1−ε)^{4−d} ε^d`
- 图 14.7：`E₁=1011` 之后、再随机走到邻格并看到 `E₂=1010` 之后的后验。完美传感下可能的那些格子仍然最可能，但每个格子概率都非零

> 这是离散 HMM 上的**精确矩阵滤波**。粒子滤波 / 蒙特卡罗定位在 §14.5.3，不是本例。

## 14.4 卡尔曼滤波器

**定位**：连续状态、**线性高斯**系统下的精确滤波。

### 14.4.1 更新高斯分布

核心事实：若 `X ~ N(μ, Σ)` 且 `Y = A X + w`（`w ~ N(0, Σ_w)`），则 `Y` 仍是高斯 `N(Aμ, A Σ Aᵀ + Σ_w)`；再用线性观测 `e = H X + v` 条件化，结果仍是高斯。**高斯在线性变换与条件化下封闭**——这是卡尔曼滤波能只维护 (μ, Σ) 的根本原因。

### 14.4.2 一维示例

状态只有位置（无速度），观测直接带噪声。此时所有矩阵退化为标量：

```
预测： μ_{t+1} = μ_t ,   σ²_{t+1} = σ²_t + σ²_x
更新： μ' = [σ²_z μ + σ²_{t+1} e] / (σ²_z + σ²_{t+1}) ,   σ'² = σ²_z σ²_{t+1} / (σ²_z + σ²_{t+1})
```

> 直觉：新的均值是"预测值"与"观测值"的**加权平均**，权重由双方方差之比决定；新的方差**必然变小**（信息只会增加）。

**假设**（一般情形）：

- 状态 `X` 是连续向量（如位置、速度）
- 转移与观测都是**线性函数 + 高斯噪声**：

```
X_{t+1} = F Xₜ + w          w ~ N(0, Σ_x)     （F 为转移矩阵）
Eₜ       = H Xₜ + v          v ~ N(0, Σ_z)     （H 为观测矩阵）
```

**结论**：高斯分布在高斯线性变换下封闭 → 信念始终是一个高斯 `N(μₜ, Σₜ)`，只需维护**均值向量 μ** 和**协方差矩阵 Σ**。

### 14.4.3 一般情形

**更新公式（两阶段）**：

1. **预测（时间更新）**

```
μ_{t+1} = F μₜ
Σ_{t+1} = F Σₜ Fᵀ + Σ_x
```

2. **观测更新**

```
μ_{t+1}' = μ_{t+1} + K_{t+1} (e_{t+1} − H μ_{t+1})
Σ_{t+1}' = (I − K_{t+1} H) Σ_{t+1}
```

其中 **卡尔曼增益（Kalman gain）**：

```
K_{t+1} = Σ_{t+1} Hᵀ (H Σ_{t+1} Hᵀ + Σ_z)^{−1}
```

**直觉**：`K` 在"相信预测"和"相信观测"之间做加权——预测不确定度大时更信观测，观测噪声大时更信预测。

### 14.4.4 卡尔曼滤波的适用性

- `Σₜ` 与增益 `Kₜ` 的更新**不依赖观测**，可以离线算好；在线跟踪要做的计算因此不大
- 正文里的典型应用是飞机与导弹的**雷达跟踪**；也提到声呐、视觉跟踪、气泡室粒子径迹、洋流等。Apollo 导航见章末历史注记（Kalman 1960 年访问 NASA Ames 之后）
- **线性高斯是硬约束**。非线性时：
  - **扩展卡尔曼滤波（EKF）**：在当前均值 `xₜ=μₜ` 附近把系统当成局部线性。平滑、性态好的系统可用；详细例子在第 26 章
  - **切换卡尔曼滤波（switching Kalman filter）**：多只滤波器并行（例如直行、急左转、急右转），按谁更贴数据做加权。等价于在图 14.9 上加一个离散"机动"变量。书中的直观例子是飞鸟冲向树干：单个高斯会把均值放在树干上，合理模型应预测它绕开
- 【延伸·非原著：信息滤波、平方根滤波、无迹滤波（UKF / sigma points）、IMM 这些名字，14.4 正文没有】多峰、强非线性的一般情形用 §14.5 的 DBN / 粒子滤波

## 14.5 动态贝叶斯网络

**DBN = 任意结构的时序模型**（多个状态变量，可含离散与连续），是 HMM 与卡尔曼滤波的统一泛化。

### 14.5.1 构造 DBN

- 需要指定：初始分布 `P(X₀)`、**转移模型** `P(X_{t+1} | X_t)`（可含跨片边）、**传感器模型** `P(E_t | X_t)`
- 每个时间步复制一份静态网络结构，加"跨时间"的转移弧
- 与第 13 章的静态贝叶斯网络共享同一套推断工具

### 14.5.2 DBN 中的精确推断

- **展开（unrolling）**整个时间序列，然后跑**变量消元**
- 复杂度随 t 增长，但在给定窗口内可控（也常配合"滑动窗口/老化"近似）

### 14.5.3 DBN 中的近似推断：粒子滤波（particle filtering）

- 用一组**加权样本（粒子）**近似信念分布
- **序贯重要性重采样（SIR）**步骤：采样 → 按观测加权 → 重采样
- 特点：适用于任意非线性/非高斯模型，是机器人 SLAM 与目标跟踪的主流工具

**例子（书中）**：图 14.13(b)（书 p.486）是 **X–Y 平面上电池供电机器人**的 DBN，不是网格加朝向，也没有充电开关或左右轮电机。变量：

| 变量 | 含义 |
|---|---|
| `Xₜ=(Xₜ, Yₜ)` | 平面位置（连续） |
| `Ẋₜ=(Ẋₜ, Ẏₜ)` | 速度。下一步速度依赖当前速度和电量 |
| `Zₜ` | 位置观测（固定相机或机载 GPS） |
| `Batteryₜ` | 电量，为简单取整数 **0–5**；父节点是上一时刻电量与速度 |
| `BMeterₜ` | 电量计，同样取 **0–5** |

电量计若总是准确，CPT 应在对角线上为 1。瞬态故障例：`P(BMeterₜ=0 | Batteryₜ=5)=0.03`。连续 20 次读到 5 之后 `BMeter₂₁=0`，简单高斯误差模型会把电池判空；瞬态故障模型则把这次 0 解释成传感器失灵。

复杂度对比（书中真空机器人，42 个可能脏的位置）：HMM 式转移要 `5×10²⁹` 个概率，DBN 只要几千个。n 个离散变量、每个至多 d 值、父节点数以 k 为界时，HMM 转移矩阵 `O(d^{2n})`，DBN 是 `O(n dᵏ)`。

> 【延伸·非原著：左右轮 `LeftWheel` / `RightWheel`、`Plug/Unplug`、网格朝向，以及 NASA Remote Agent / IVHM，都不在第 14 章正文或本章历史注记里。】

**DBN 的应用场景**：

- 语音识别（HMM/DBN 混合）
- 机器人定位与建图（SLAM）
- 医疗监护与故障诊断
- 经济与金融时间序列

## 小结

1. 时序模型把世界表示为状态序列 `Xₜ` 与观测序列 `Eₜ`，核心是**先验 + 转移模型 + 传感器模型**。
2. 三条核心假设：一阶马尔可夫、传感器马尔可夫、平稳过程——它们使递归推断成为可能。
3. 四类推断：**滤波**（在线）、**预测**（未来）、**平滑**（回顾）、**最可能序列**（Viterbi）。前三类算的是边缘分布，第四类算的是**整体最优路径**，二者答案可以不同。
4. **贝叶斯滤波**由"预测 + 更新"组成，每步常数时间、常数空间（**平滑**是例外：时间 O(t)，空间也 O(t)）。
5. **HMM** 是单离散状态的特例，用矩阵运算实现；**卡尔曼滤波**是线性高斯的精确解，非线性用 EKF 或切换卡尔曼滤波。
6. **DBN** 是通用框架；**粒子滤波**给出非线性、非高斯下的实用近似推断。
