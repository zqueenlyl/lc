# 03. 光圈与景深

> 光圈是摄影里最反直觉的一个旋钮：**数字越小，孔越大**；而且它不只控制亮度——它同时控制"哪里清晰"。
> 想搞懂虚化，必须把**景深**（哪里算清晰）和**焦外弥散**（背景糊成什么样）当成两件事，它们由不同的变量决定。

一句人话：**f 值是比值，虚化看入瞳；同构图下焦距不影响景深。**

---

## 一、f 值到底是什么

```
N = f / D        f = 焦距，D = 光圈有效孔径（入瞳直径）
```

所以 `f/2.8` 的完整读法是"**焦距 ÷ 2.8**"：50mm f/2.8 → 入瞳直径 = 50 / 2.8 ≈ **17.9mm**。

| 写法 | f/1.4 | f/2 | f/2.8 | f/4 | f/5.6 | f/8 |
|---|---|---|---|---|---|---|
| 入瞳直径（50mm 镜头） | 35.7mm | 25mm | 17.9mm | 12.5mm | 8.9mm | 6.25mm |
| 通光面积比 | 1 | 1/2 | 1/4 | 1/8 | 1/16 | 1/32 |

要点：

1. **f 值是"相对孔径的倒数"**。它是比值，所以跨镜头可比——同 f 值、同场景，进光速率相同（这是曝光表能通用的原因）。
2. **相邻档 ×√2**，因为要面积减半：`D ∝ 1/N`，面积 ∝ `D²` ∝ `1/N²`，所以 `N × √2` 才让面积减半。这就是 1、1.4、2、2.8、4、5.6、8… 数列的来源。
3. 光圈值的变化量可以这样心算：**f 值差 √2 倍 = 1 档；差 2 倍 = 2 档**。f/1.4 → f/2.8 是 2 档、4 倍光。

### "大光圈"与"小光圈"的用词混乱

| 说法 | 含义 |
|---|---|
| 大光圈 / 开大 | f/1.4、f/2 → 孔大、光多、景深浅 |
| 小光圈 / 收小 | f/11、f/16 → 孔小、光少、景深深 |

**"大光圈拍浅景深"** 这句话之所以让人晕，是因为"大"和"浅"分属两个系统。记法：**f 值小 = 孔大 = 景深浅**。

### f 值 vs T 值

f 值是**几何**口径，没算镜片透光损失（镀膜、镜片吸收）。电影镜头用 **T 值（Transmission）**标注实测通光量（如 T2.1 对应 f/1.8），因为拍视频换镜头时曝光必须严格一致。拍照用 f 值足够，但**同一 f 值下不同镜头亮度可能差 1/3 档**。

## 二、景深：定义与公式

### 1. 为什么会有"不清晰"的区域

理想成像只对**一个物距**的平面严格清晰。其他距离的点会在像面上摊成一个圆斑，叫**弥散圆（Circle of Confusion, CoC）**。

**只要弥散圆小于某个阈值（容许弥散圆 c），人眼就认为"清晰"**。景深就是"弥散圆还没超过 c 的那些物距范围"。

- 全画幅常用 **c ≈ 0.03mm**（约等于对角线 43.3mm 的 1/1440）
- 更严格的标准（如蔡司）用 **c ≈ 0.025mm**
- **画幅越小，c 也越小**（因为放大率更高）→ 这在等效计算里自动被吸收

### 2. 公式

**超焦距**（对焦到它时，从 H/2 到无穷远都清晰）：

```
H = f² / (N·c) + f
```

**近 / 远界限**：

```
近界限 = H·d / (H + (d − f))
远界限 = H·d / (H − (d − f))
```

**当对焦距离 d 远小于 H 时的简化式**：

```
景深 DOF ≈ 2 · N · c · d² / f²
```

### 3. 从这个式子能读出全部结论

| 变量 | 变化 | 景深 | 直觉解释 |
|---|---|---|---|
| **N**（f 值） | 收小光圈 | **变深** | 孔径小 → 光线夹角小 → 弥散圆长得慢 |
| **d**（对焦距离） | 靠近主体 | **急剧变浅**（∝ d²） | 近摄景深极浅的根源 |
| **f**（焦距） | 变长 | **变浅**（∝ 1/f²） | ⚠️ 但**仅在对焦距离不变时成立**，见下 |
| **c**（画幅） | 大画幅 | **变浅** | c 更大，但放大率更低，净效果是"等效光圈" |

### 4. 最重要的一条澄清：同构图下焦距不影响景深

这是被引用最多的错误结论之一。推导（把 f 记作焦距、N 记作 f 值、k 记作裁切系数）：

```
要"同构图"，变焦后必须改变距离，使放大率不变：
  d ∝ f
代入 DOF ≈ 2Nc d² / f²：
  DOF ≈ 2Nc (k·f)² / f² = 2Nc·k²   ← 与 f 无关
```

结论：

- **决定景深的是"光圈 f 值 + 构图（放大率）"**，不是焦距。
- 用 24mm f/2.8 走近 vs 用 85mm f/2.8 站远、拍出同样构图 → **景深相同**。
- **但背景的空间关系完全不同**（透视、背景占比、虚化形态），这才是长焦人像"更梦幻"的真正原因，见 [04-焦距与透视](./04-焦距与透视.md)。

### 5. 画幅与"等效光圈"

固定"同视角 + 同对焦距离 + 同 f 值"时，画幅越小景深越深。要让不同画幅拍出**等价画面**，两个量都要乘裁切系数：

| 换算 | 公式 | 例子 |
|---|---|---|
| 等效焦距 | `f_eq = f × k` | APS-C 33mm ≈ 全画幅 50mm（k=1.5） |
| 等效光圈（景深 + 总进光量） | `N_eq = N × k` | APS-C f/2.8 ≈ 全画幅 **f/4.2** |

> 这条同时解释了"手机虚化靠算法"：1 英寸底（k≈2.7）的手机主摄 f/1.8，等效光圈只有 **f/4.9** 左右，物理上根本糊不出人像级的背景。所以手机走的是"多次拍摄 + 深度图 + 抠图虚化"的计算摄影路线。

### 6. 前后景深的分布

"景深前 1/3、后 2/3"是流行经验值，**只在特定条件下近似成立**（对焦距离接近超焦距时趋于 1/2 : 1/2；近距拍摄时远界扩张更快）。

实用版：**对焦略靠主体后方一点**，能让"该清晰的部分"更多落在景深内。拍多人合影时，与其对焦最近或最远的人，不如对焦在**中间偏前**的位置并适当收光圈。

## 三、衍射：为什么最小光圈不是最锐

光穿过小孔必然发生衍射，形成一个**艾里斑（Airy disk）**：

```
艾里斑直径 ≈ 2.44 · λ · N        λ ≈ 0.55 μm（可见光中段）
```

| f 值 | 艾里斑直径 |
|---|---|
| f/2.8 | 3.8 μm |
| f/4 | 5.4 μm |
| f/5.6 | 7.5 μm |
| f/8 | 10.7 μm |
| f/11 | 14.7 μm |
| f/16 | 21.5 μm |
| f/22 | 29.5 μm |

判据（经验）：**艾里斑 ≈ 2 倍像素间距时开始可察觉，≈ 3 倍时明显**。

| 机身 | 像素间距 | 衍射开始显现 |
|---|---|---|
| 24MP 全画幅（6000×4000） | 6.0 μm | f/11 左右 |
| 45MP 全画幅 | 4.4 μm | f/8 左右 |
| 61MP 全画幅 | 3.8 μm | f/5.6–f/8 |
| 20MP M4/3 | 3.3 μm | f/5.6 左右 |

**最佳光圈 = 像差与衍射的交点**，全画幅定焦通常落在 **f/5.6–f/8**（最大光圈收 2–3 档）。

重要推论：
- **高像素机身对衍射更敏感**，因为像素小、判据更严——这不是"高像素不好"，而是"高像素把镜头的短板也放大了"。
- 需要大景深（风光）时，方向是**用更广的镜头走近**或**做焦点堆栈（focus stacking）**，而不是一路收到 f/22。

## 四、焦外（Bokeh）：糊成什么样

**景深回答"哪里清晰"，焦外回答"不清晰的地方长什么样"。** 两者由不同变量控制。

### 1. 弥散圆有多大

背景距离 s₂、对焦距离 s₁（均远大于 f）时，背景点的弥散圆直径近似：

```
C ≈ (f² / N) · |s₂ − s₁| / (s₂ · s₁)
```

对**无穷远背景**（s₂ → ∞）取极限：

```
C∞ ≈ (f / N) · (f / s₁) = 入瞳直径 × 放大率
```

**这条式子是虚化问题的终极答案**：同构图（放大率固定）下，背景虚化程度只由**入瞳直径 f/N** 决定。

| 镜头 | 入瞳直径 f/N | 同构图下的背景虚化 |
|---|---|---|
| 35mm f/1.8 | 19.4mm | 弱 |
| 50mm f/1.8 | 27.8mm | 中 |
| 50mm f/1.4 | 35.7mm | 强 |
| 85mm f/1.8 | 47.2mm | 更强 |
| 85mm f/1.4 | 60.7mm | 很强 |
| 135mm f/2 | 67.5mm | 极强 |
| 200mm f/2.8 | 71.4mm | 极强（但需站远，透视压缩） |

这解释了为什么"人像焦段是 85–135"：**不是焦距有魔力，而是这些焦段的入瞳直径/价格/体积比最优**。

### 2. 焦外的"质量"

同样大小的弥散圆，观感可以差很远：

- **光斑形状**：由光圈叶片多边形决定。**偶数叶片 → 星芒/光斑边数 = 叶片数；奇数叶片 → 星芒条数 = 2 × 叶片数**（多边形没有平行对边）。
- **口径蚀（Cat's eye）**：画面边角的光斑被镜筒遮挡，变成猫眼形/半圆 → 边缘焦外更"旋"。
- **洋葱圈**：非球面镜片研磨残留，光斑内部出现同心环。
- **二线性**：焦外高光边缘出现"重影边"，背景看起来乱。
- **焦外过渡**：前景虚化 vs 背景虚化观感差异很大，有些镜头特意优化前焦外（拍人像隔物）。
- **天塞/双高斯/逆望远**等光学结构决定焦外风格，这是"玄学"里少数真实存在的部分。

### 3. 微距的一个坑：有效光圈会变

近摄时像距被拉长，实际通光下降：

```
N_eff = N × (1 + m)        m = 放大倍率
```

**1:1 微距（m = 1）时有效光圈是标称的 2 倍**：镜头设 f/8，实际相当于 **f/16**。
后果：微距自动曝光会"莫名变暗"、闪光需要补光、衍射来得更早、景深薄如纸（所以微距几乎全靠**焦点堆栈**）。

## 五、景深与虚化的实操对照

| 想要 | 怎么调 |
|---|---|
| 背景糊成一片 | 用最大光圈（f 值最小）+ 靠近主体 + 让背景离主体远 + 用长焦压背景 |
| 前后都清晰（风光） | 收到**衍射起点**（24MP 约 f/8–f/11，61MP 约 f/5.6–f/8）+ 超焦距或广角走近 + 必要时焦点堆栈 |
| 主体清晰、背景可辨（环境人像） | f/2.8–f/4，背景保留可识别信息 |
| 星芒 | 小光圈（f/11–f/16）+ 点光源 / 太阳边缘 |
| 光斑圆润（夜景人像） | 最大光圈 + 背景点光源距离远 + 选择焦外好的镜头 |
| 微距全清晰 | 焦点堆栈（5–50 张）+ f/5.6–f/8 + 三脚架 + 滑轨 |

### 超焦距怎么用（风光最快上手）

1. 收到衍射起点（见上表；A7CR 用 f/5.6–f/8，不要习惯性 f/11）
2. 用手机超焦距 App 或机身景深预览算出 H
3. 对焦到 H（或用镜头上的景深标尺）
4. 结果：从 **H/2 到无穷远**都算清晰

## 六、常见坑

1. **"焦距越长景深越浅"当定律用**。只在同距离成立；同构图下焦距不影响景深，改变的是透视与背景占比。
2. **把"景深浅"等同于"背景糊"**。景深管清晰范围，弥散圆大小管糊的程度；两者受不同变量支配（一个看 N 与放大率，一个看入瞳直径与背景距离）。
3. **一路收到 f/22 拍风光**。衍射会让整张发软，正确做法是收到衍射起点（高像素更早）+ 焦点堆栈。
4. **认为 f/1.2 一定比 f/1.4 画质好**。大光圈镜头的最大光圈往往是"可用但不最佳"，最佳通常在 f/2–f/4；买超大口径主要买的是**虚化与暗光余量**。
5. **最大光圈下对焦后重新构图**（先对焦再平移）。大光圈景深极浅，平移会让焦点偏到焦外，导致"眼睛不锐"。应移动对焦点或使用眼控对焦。
6. **用手持 + 1/30s + f/1.4 拍人像**，然后怪镜头不锐。浅景深 + 手抖/被摄者微动 = 大概率全虚，快门至少要跟上。
7. **相信"全部清晰"是镜头素质问题**。多数"边缘发虚"是场曲 + 景深不够，收一档往往就解决。
8. **忽略光圈叶片的实际影响**：你看到的星芒数、光斑形状、二线性，都由它决定；评测里的"焦外风格"不是玄学。

## 七、现场决策套路

```
要糊还是要清？
  糊：看入瞳直径 f/N，靠近主体，背景拉远
  清：f/5.6–f/8，超焦距或焦点堆栈，不要 f/16
同构图换焦段：景深不变，透视会变（去 04）
微距：按 N(1+m) 算有效光圈，衍射来得更早
```

A7CR 风光默认收到衍射起点即可。判断见 [12](./12-自测与过线.md)。

**记忆线索**：同构图下焦距被消掉，虚化只剩入瞳。下一章讲焦距真正控制的东西：取景范围；透视交给距离。
