# 02. 曝光三要素与测光

> 曝光只有一个目标：**让传感器的每个像素收到恰到好处的光子数**。
> 手动档的价值不在"显得专业"，而在于你能明确知道自己在牺牲什么——因为三要素每动一个，都会付出代价。

---

## 一、曝光的物理式

曝光量（每单位面积的进光能量）可以写成：

```
H = E × t
E ∝ L / N²          （L = 场景亮度，N = f 值）
⇒ H ∝ L × t / N²
```

三个可调量：

| 参数 | 物理含义 | 调大它的副作用 |
|---|---|---|
| **光圈 N**（f 值） | 孔径面积，决定进光**速率** | f 值越小光越多，但景深变浅、像差增大 |
| **快门 t** | 曝光**时长** | 时间越长光越多，但运动模糊增加 |
| **ISO** | 信号**增益** | 增益越高画面越亮，但噪声一起被放大 |

**三个副作用互不相同 → 这是摄影唯一真正的"三选二"结构**：你可以同时要浅景深和大亮度，但必须接受更长的曝光时间或更高的噪声。

### 严格说：ISO 不是曝光要素

- 曝光量 H 只由**场景亮度、光圈、快门**决定，ISO 不改变任何进入传感器的光子数。
- ISO 只是"把多少电荷定义成中灰"。所以更准确的模型是：**曝光（H）+ 增益/映射（ISO）→ 亮度**。
- 教学上叫"曝光三角"是为了好记；理解成"曝光两要素 + 一个亮度放大器"才是原理。

## 二、标准档位（各差一档 = 2 倍光量）

| 光圈（f 值） | 1.0 | 1.4 | 2 | 2.8 | 4 | 5.6 | 8 | 11 | 16 | 22 |
|---|---|---|---|---|---|---|---|---|---|---|
| 通光面积比 | 1 | 1/2 | 1/4 | 1/8 | … | | | | | |

每档 ×√2，因为**面积 ∝ 1/N²**（几何解释见 [03-光圈与景深](./03-光圈与景深.md)）。

| 快门（秒） | 1/2000 | 1/1000 | 1/500 | 1/250 | 1/125 | 1/60 | 1/30 | 1/15 | 1/8 | 1/4 | 1/2 | 1 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

| ISO | 100 | 200 | 400 | 800 | 1600 | 3200 | 6400 | 12800 | 25600 |
|---|---|---|---|---|---|---|---|---|---|

相机允许 1/3 档步进（如 f/3.5、1/80、ISO 160），所以会出现不符合表的值，这是正常的。

---

## 三、互易律与"等效曝光"

**互易律（Reciprocity）**：只要 `t / N²` 不变，曝光量就不变。

```
f/2.8, 1/500   ≡   f/4, 1/250   ≡   f/8, 1/60    （进光量相同）
```

但**画面完全不同**：
- 第一组：景深浅、凝固动作
- 第三组：景深深、可能糊

所以"等效曝光"只是给了你**同一张亮度**，创作信息全在组合方式里。数码时代互易律基本成立（长时间曝光靠暗帧扣除噪点处理），胶片时代需要为长曝做互易律补偿。

---

## 四、曝光值 EV：把三者压成一个数

```
EV = log₂(N² / t)      （忽略场景亮度，只描述相机侧的组合）
```

- `f/2.8, 1/500`：log₂(7.84 × 500) = log₂(3920) ≈ **11.9**
- `f/16, 1/125`：log₂(256 × 125) = log₂(32000) ≈ **15**

把"场景有多亮"也算进来，就是 **EV₁₀₀**（ISO 100 下正确的 EV）。常见参考值：

| 场景 | EV₁₀₀ |
|---|---|
| 烛光 / 夜景弱光 | 2–5 |
| 室内灯光 | 5–8 |
| 阴天 | 12 |
| 日出后 / 日落前 | 13–14 |
| **晴天顺光（阳光 16 法则）** | 15 |
| 雪地 / 沙滩正午 | 16–17 |

### 阳光 16 法则（Sunny 16）

晴天户外，`f/16`、快门 ≈ `1/ISO`（ISO 100 → 1/100s）即可得到正确曝光。

> 精度说明：标准表里"晴天"常记 `EV₁₀₀ ≈ 15`，对应 `f/16 + 1/125s`（需要 ISO ≈ 100–125）。与 `1/100s` 相差 1/3 档，属于该法则本身的精度范围——它是**离线估算的锚点**，不是精确公式。

它的价值是**离线估算**：当你没有测光表、或需要判断"自动测光给出的值是不是离谱"时，它是锚点。

## 五、测光：相机怎么猜"该多亮"

### 1. 反射式测光（机身内置）

相机测量**场景反射回来的光**，并假设"这个亮度对应中灰"。这是绝大多数相机用的方式，也是无数曝光错误的来源。

**中灰到底是什么**：业界约定的中灰是**反射率 18% 的灰卡**。

> 反直觉点：18% 是**反射率（线性域）**，不是"屏幕上一半亮"。在 sRGB 编码下，它对应像素值约 **118/255**（因为编码有约 2.2 的 gamma）。这解释了为什么"18% 灰"看起来比想象中暗。

### 2. 测光模式

| 模式 | 行为 | 什么时候用 |
|---|---|---|
| 评价/矩阵测光 | 全画面分区 + 场景识别（人脸、天空权重） | 默认，顺光/光线均匀 |
| 中央重点测光 | 以中央区域为主 | 主体居中、逆光留白 |
| 点测光 | 只测画面中心很小的区域 | 高反差场景，精确控制高光或主体 |

### 3. 测光必然出错的场景

因为相机只会把东西拍成中灰：

| 场景 | 相机会误判 | 应对 |
|---|---|---|
| 雪地、白沙滩 | 拍成灰雪 | **+1 ~ +2 EV** |
| 逆光人像（大面积亮天） | 把人拍成剪影 | **+0.7 ~ +2 EV**，或对人脸点测光 |
| 黑猫、黑西装占主体 | 拍成灰猫、发灰的黑 | **−0.7 ~ −1.5 EV** |
| 舞台聚光灯下的人 | 高光过曝 | 对高光点测 + 负补偿 |
| 渐变天空（日落） | 天空死白或地面死黑 | 用 GND 滤镜或包围曝光 |

**记忆口径**：**"白要加，黑要减"**——相机不认识白色和黑色，它只认识中灰。

### 4. 入射式测光（外置测光表）

直接测**照到主体上的光**，不受主体反射率影响，是棚拍/多人场景最可靠的方式。手机 App 也能做有限的入射测量。

## 六、曝光补偿：只在自动/半自动模式下有意义

- P / A / S（Av / Tv）模式下，相机会替你选一个参数；**曝光补偿就是修正它的判断**。
- 全手动（M）下，曝光补偿通常不改变曝光（可能只影响机内预览或闪光 TTL），因为没有任何参数交给相机。

**最实用的用法**：用 A 档 + 曝光补偿。盯住快门读数是否低于安全快门，超过就换参数或提 ISO。

---

## 七、怎么判断"曝光对了"

| 工具 | 看什么 | 注意 |
|---|---|---|
| **直方图** | 像素按亮度的分布 | 左端贴边 = 阴影死黑（可恢复度低），右端贴边 = 高光溢出（**不可恢复**） |
| **高光警告 / 斑马纹** | 过曝区域闪烁 | 靠这个判断"白纱裙/云是否已经死了" |
| **亮度预览（EVF）** | 所见即所得 | 受屏幕亮度与预览增益影响，不能只信眼睛 |
| **看主体本身** | 人脸亮度是否自然 | 最终交付标准 |

### ETTR（向右曝光）

在保证高光不溢出的前提下**尽量向右曝光**（画面偏亮），后期再压回正常亮度。理由：

- 光子数越多，**信噪比越好**（散粒噪声是 √N，见 07 章）。
- 传感器在**线性域**记录，高光区占用了更多的编码级数，暗部级数稀薄；把信息往右放，等于用"级数多的地方"记录更多细节。

代价与前提：必须用 RAW（JPEG 有硬截断）、必须真正控住高光（用斑马纹/高光警告），且**某些机型的 ISO 增益切换点在低 ISO 段会削掉右端**——所以"向右"要留余量，不是"过曝"。

---

## 八、闪光曝光：完全另一套逻辑

- 闪光灯的曝光由**闪光持续时间**（不是相机快门）决定：1/1000s ~ 1/20000s，所以它能"凝固"高速动作。
- 亮度用 **GN（Guide Number）= 距离 × f 值** 描述：GN 36 的闪光灯，在 3m、ISO 100 下合适光圈为 f/12。
- **快门速度只决定环境光的量**（"环境曝光"），闪光亮度由光圈 + 功率决定。于是产生了两个独立旋钮：
  - 调光圈/闪光功率 → 改变**主体**亮度
  - 调快门 → 改变**背景/环境**亮度（慢同步慢门）
- 这就是"闪光同步速度"存在的原因与高速同步（HSS）的代价，见 [05-快门与动感](./05-快门与动感.md)。

## 九、常见坑

1. **认为 M 档更专业**。判断标准是"你是否清楚在牺牲什么"，不是档位名称。A 档 + 曝光补偿往往更快更稳。
2. **只看屏幕回放定曝光**。屏幕亮度会骗你（尤其户外），看直方图和高光警告。
3. **高光溢出后想救回来**。RAW 通常能多救 0.5–1 档，再多就是纯白一片；阴影则相对宽容得多——所以**宁欠勿过**这条老规矩在多数机型上依然成立（除非掌握 ETTR）。
4. **ISO 越低画质越好，宁可糊也要低 ISO**。错。糊掉的照片没有任何后期价值，噪声高的照片却常常可用。**先保证快门，再考虑 ISO**。
5. **在自动 ISO 下同时设最大光圈与最低快门**，导致三者在暗光下互相扯；设好"最低快门 + 最高 ISO"上下限就能避免。
6. **混用 JPEG 与 RAW 的宽容度预期**。JPEG 是 8bit 且已经过非线性压缩，阴影一拉就出色带与噪点。
7. **忽略快门与闪光同步限制**：用非 HSS 闪光灯时，快门快过同步速度会出现黑边（帘幕遮挡）。

---

## 十、上手顺序（建议）

1. 用 **A 档 + 固定 ISO**，只控制光圈，观察景深变化 → 建立"光圈 = 景深"的直觉。
2. 开 **自动 ISO，设最低快门**（如 1/125），感受快门与 ISO 的自动权衡。
3. 学 **曝光补偿 + 高光警告**，专挑雪景/逆光/黑主体练"白加黑减"。
4. 学 **M 档 + 点测光**，只在需要精确控制的场景用（舞台、棚拍、长曝）。
5. 学 **直方图判读**，目标是"拍的时候就知道后期有没有余量"。
