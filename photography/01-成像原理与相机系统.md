# 01. 成像原理与相机系统

> 相机只做一件事：**把三维场景中每一点发出的光，按方向映射到二维平面的特定位置，并记录该点的强度与颜色**。
> 后面所有参数（光圈、快门、ISO、焦距、白平衡）都是在回答同一句话的两个追问：「收多少光」和「怎么解释这些光」。

一句人话：**ISO 不增加光子；链路里真正的物理量只有进光量和时间。**

---

## 一、光路的六个环节

```
光 → 镜头（折射/汇聚） → 光圈（限光通量） → 快门（限时间）
   → 传感器（光电转换） → 读出放大（ISO 增益） → ADC → ISP/RAW
```

| 环节 | 物理作用 | 它决定 | 对应摄影参数 |
|---|---|---|---|
| **镜头** | 折射，把物方光线按角度映射到像面 | 视角、透视、像差、能收多少光 | 焦距、最大光圈、画质 |
| **光圈** | 改变孔径面积，限制每秒进光量 | 进光速率 + 景深 + 衍射 | f 值 |
| **快门** | 控制传感器曝光时长 | 总曝光量 + 运动模糊 | 快门速度 |
| **传感器** | 光子 → 电子（光电效应） | 色彩还原、噪声下限、动态范围 | 画幅、像素、感光特性 |
| **增益（ISO）** | 放大电信号 | 亮度与噪声的权衡 | ISO |
| **ISP** | 去马赛克、白平衡、锐化、降噪、压缩 | 直出观感 | 照片风格、RAW/JPEG |

**关键认知**：真正的物理量只有两个——**进光量**和**曝光时间**。"亮度"是这两个量加上增益后的解释结果。所以「ISO 是曝光三要素之一」只是教学简化，物理上它不是曝光要素（见 [02-曝光三要素与测光](./02-曝光三要素与测光.md)）。

## 二、镜头：为什么需要它

### 1. 小孔成像已经能"成像"

小孔成像的原理：**每个物点只有一条直线能穿过小孔到达像面**，于是物点和像点一一对应，形成清晰（但极暗）的像。

限制：
- 孔径小 → 进光量按面积衰减，且孔越小衍射越严重（见 [03-光圈与景深](./03-光圈与景深.md)）。
- 结论：**想要清晰又要亮，就必须用透镜代替小孔**。

### 2. 透镜用"折射"换"口径"

透镜让一大片口径的光线都被弯曲汇聚到同一点，于是既亮又清晰。代价是引入**像差**——不同位置/不同波长的光线不走同一条理想路径。

| 像差 | 现象 | 收光圈能否改善 |
|---|---|---|
| 球面像差 | 边缘光线汇聚点偏离，画面发软 | 能，明显 |
| 彗差 | 画面边缘点光源拖成彗星状 | 能 |
| 像散 | 横竖线条焦点不在同一平面 | 能 |
| 场曲 | 像面是曲面，中心清晰边缘虚 | 部分 |
| 畸变 | 直线变弯（桶形/枕形） | **不能**，与光圈无关 |
| 色差（轴向/倍率） | 紫边、绿边 | 部分（收光圈改善轴向色差） |
| 暗角 | 四角变暗 | 收光圈改善，但机身补偿更常用 |

于是出现**最佳光圈**：收一两档压住像差，再收就开始被衍射主导（见 03）。

### 3. 镜头里还有什么

- **对焦组**：移动镜片组改变像距 → 改变清晰平面。
- **光圈叶片**：多边形孔径，叶片数决定焦外光斑形状与星芒条数。
- **镀膜**：抑制鬼影与眩光，现代多层镀膜；抗污涂层。
- **防抖组**：OIS，靠镜片位移补偿手抖（也有机身 IBIS，见 [05-快门与动感](./05-快门与动感.md)）。
- **变焦组**：改变焦距的同时尽量保持像面位置不变（内变焦/外变焦）。

## 三、传感器：光信号如何变成像素

### 1. 单个像素的结构（自上而下）

```
微透镜（聚光，提高填充率，改善边角入射）
  ↓
彩色滤光片（R / G / B 三选一）
  ↓
光电二极管（光子 → 电子，累积电荷）
  ↓
读出电路 / 放大 / ADC
```

### 2. Bayer 阵列：彩色其实是"猜"出来的

绝大多数传感器每个像素只能测**亮度**（全色盲）。彩色靠在像素上盖滤色片，按 2×2 单元排列：

```
R G
G B      → 绿占 50%，红蓝各 25%
```

相机拍摄后必须做**去马赛克（demosaic）**：用邻域像素推测每个位置缺失的另两个通道。由此产生三个必然结论：

1. **实际彩色分辨率低于标称像素数**。要恢复一个真实彩色像素，至少需要 2×2 个采样点。
2. **高频细节会出现摩尔纹与伪色**（细密纹理、格纹织物最容易）。传统解法是加**光学低通滤镜（OLPF）**牺牲一点分辨率换干净；现代高像素机身倾向**取消 OLPF**，把伪色交给算法。
3. **绿通道最干净**（采样密度最高），这也是去马赛克算法里绿通道权重最大、降噪时最不该动绿的原因。

例外：Foveon 传感器三层堆叠、每层吸收不同波长，每个位置都能测三色；代价是工艺与高感表现，始终小众。

### 3. ISO 到底是什么

| 说法 | 是否正确 |
|---|---|
| ISO 提高传感器灵敏度 | ❌ 传感器量子效率是固定的物理属性 |
| ISO 是模拟/数字增益（放大已有信号） | ✅ 主流实现 |
| ISO 提高会"产生"噪声 | ❌ 噪声主要来自光本身，ISO 把噪声一起放大 |

严格讲：ISO 决定"多少电荷算作中灰"，从而影响增益与后续处理。因此**在总进光量不变时，提高 ISO 只会让画面更亮也更糙，不会拿到更多信息**。这就是"高 ISO 噪声其实是暗光噪声"的原因，详见 [07-对焦与画质](./07-对焦与画质.md)。

### 4. 传感器类型

| 类型 | 结构 | 特点 |
|---|---|---|
| 前照式（FSI） | 布线层在感光面之上，挡光 | 老工艺，边角入射效率差 |
| 背照式（BSI） | 硅片翻转，布线层挪到背面 | 开口率更高、暗光与边角更好，现为主流 |
| 堆栈式（Stacked BSI） | BSI 之上再叠一层带 DRAM 的电路 | 读出更快 → 高速连拍/4K120/更强防抖与果冻抑制 |
| 全局快门（Global Shutter） | 全部像素同时曝光 | 无果冻效应，但传统上动态范围与噪声偏弱（新一代正在改善） |

## 四、画幅：唯一决定"总进光量"的尺寸

| 画幅 | 尺寸（mm） | 面积（mm²） | 裁切系数 | 相对全画幅面积 |
|---|---|---|---|---|
| 中画幅（4433） | 44 × 33 | 1452 | 0.79 | 1.68× |
| **全画幅（135）** | 36 × 24 | 864 | 1.00 | 1×（基准） |
| APS-C（尼康/索尼） | 23.5 × 15.6 | 367 | 1.5 | 1/2.25 |
| APS-C（佳能） | 22.3 × 14.9 | 332 | 1.6 | 1/2.56 |
| M4/3 | 17.3 × 13.0 | 225 | 2.0 | 1/3.84 |
| 1 英寸（手机大底） | 13.2 × 8.8 | 116 | 2.7 | 1/7.4 |
| 常见手机主摄 | ≈ 9.8 × 7.3 | 72 | 3.7 | 1/12 |

**画幅只影响三件事**（其他都是营销叙事）：

1. **视角**：同焦距下画幅越小视角越窄 → 需要"等效焦距"换算。
2. **景深与虚化**：同视角同 f 值时大画幅景深更浅（等效光圈 = f 值 × 裁切系数）。
3. **信噪比**：画幅是"收光面积"。同代工艺、同曝光下，进光量之比 = 面积之比，SNR 之比 = √(面积之比)。

> 第 3 条是"底大一级压死人"的全部物理内容：全画幅比 APS-C 多收 2.25 倍光 → SNR 好 1.5 倍 ≈ **0.58 档**；M4/3 相对全画幅差约 **2 档**。这个差距真实存在，但远小于"换个镜头"或"走近两步"带来的差别。

## 五、单反 vs 无反：差异全在"光路"

| 维度 | 单反（DSLR） | 无反（Mirrorless） |
|---|---|---|
| 取景 | 反光板把光送到光学取景器（OVF） | 传感器直出画面到电子取景器（EVF） |
| 对焦 | 独立相位模块（在反光板下方） | 传感器上的相位/反差（片上 PDAF） |
| 跑焦 | 存在：对焦光路 ≠ 成像光路，需 AF 微调 | 基本不存在：同一光路 |
| 法兰距 | 长（佳能 EF 44mm、尼康 F 46.5mm） | 短（索尼 E 18mm、佳能 RF 20mm、尼康 Z 16mm） |
| 卡口内径 | 较窄 | 普遍更宽 → 大光圈边缘光线入射角更友好 |
| 所见即所得 | 曝光/白平衡靠经验 | EVF 实时预览 |
| 体积/散热 | 大、但电池耐用 | 小、视频性能强、高负载易过热 |

**法兰距为什么重要**：短法兰距让"转接老镜头"变得容易（加一个转接环补足距离），也让后组镜片可以更贴近传感器，为超大光圈与高画质广角留出设计空间。这是无反阵营的结构性优势，不是"少了块反光板"这么简单。

## 六、常见误解

| 误解 | 事实 |
|---|---|
| "像素越高噪声越大" | 单像素变小 SNR 下降，但**同尺寸输出**时画质由总进光量决定。高像素缩图后不输低像素，还多了细节（代价是文件、处理、衍射更早显现） |
| "大像素=好高感" | 决定高感的是**总感光面积 + 读出电路噪声**，不是单像素尺寸 |
| "相机分辨率 = 像素数" | 彩色分辨率受 Bayer 采样限制；镜头解析力、衍射、防抖、对焦精度都是瓶颈 |
| "全画幅镜头装 APS-C 上焦距变了" | 焦距没变，**视角**变了；镜头的光学性质一个都没变 |
| "相机越好照片越好" | 光、构图、时机、距离是主要变量；器材主要决定"哪些条件下拍得到" |

## 七、现场决策套路

```
这张要记录什么光？
  → 进光量够吗？（光圈 × 快门，不是 ISO）
  → 颜色谁来解释？（白平衡 / RAW）
  → 画幅和镜头只决定「哪些条件下拍得到」
```

像素、卡口、单反/无反，全部排在这两问之后。过线判断见 [12](./12-自测与过线.md)。

**记忆线索**：光路六环节里，增益只是对已有电荷的解释。下一章把进光量和时间收成可调档位——互易律、测光为什么总把世界拍成灰、直方图怎么读。
