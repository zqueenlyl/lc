# 10. 装备选型与练习清单

> 器材只决定两件事：**在哪些条件下你能拍到**，以及**你愿不愿意把它带出门**。
> 前者是参数问题，后者是习惯问题——而后者对成片率的影响远大于前者。

一句人话：**机身是消耗品，镜头是资产；成片率由愿不愿带出门决定。**

---

## 一、先想清楚"我拍什么"

选器材前先回答三个问题：

1. **主要题材**：人像 / 风光 / 街头 / 运动 / 微距 / 视频 / 家庭记录？
2. **使用场景**：旅行、通勤、室内、棚拍、户外？
3. **限制条件**：重量上限、预算上限、是否需要防水/防尘/静音？

**题材 → 需求映射表**：

| 题材 | 最需要的 | 最不需要的 |
|---|---|---|
| 人像 | 大光圈定焦、眼控对焦、肤色 | 高速连拍、超高像素 |
| 风光 | 广角到中长焦、三脚架、滤镜、高 DR | 超高速对焦 |
| 街头 / 纪实 | 小体积、静音快门、快速开机 | 大三元变焦、超长焦 |
| 运动 / 体育 | 追焦性能、高速连拍、长焦、缓存 | 大光圈定焦（多数时候要的是焦段） |
| 微距 | 1:1 放大率、对焦滑轨、环形/双头闪 | 高速连拍 |
| 视频 | 无裁切 4K/60、Log、散热、稳定、麦克风口 | 超高像素 |
| 家庭 / 记录 | 轻便、可用高感、自动模式可靠 | 大光圈定焦、复杂操控 |

## 二、机身：看什么参数

| 参数 | 为什么重要 | 怎么权衡 |
|---|---|---|
| **画幅** | 决定暗光、景深、等效换算 | 全画幅是通用甜点；APS-C/M4/3 换轻便与长焦优势 |
| **卡口生态** | 决定你未来能买什么镜头 | 比机身参数更重要，选镜头群丰富的（或原厂规划清晰的） |
| **对焦系统** | 决定成片率（尤其人像/运动） | 无反派更好，看是否支持**主体识别/眼控** |
| **防抖** | 决定手持下限 | IBIS 更好（配任意镜头）；CIPA 档数为参考 |
| **连拍 + 缓存** | 决定能否抓住瞬间 | 看"缓存清空前能连拍多少张 RAW"（比峰值 fps 更重要） |
| **取景器** | EVF 所见即所得 vs OVF 无延迟 | 视频/夜景偏 EVF，运动偏 OVF（但新一代 EVF 已很接近） |
| **双卡槽 / 电池** | 可靠性 | 婚礼、商业、活动必备双卡 |
| **视频规格** | 是否有裁切、Log、10bit、散热 | 参数漂亮不代表散热够 |
| **尺寸重量** | 决定带出门频率 | 最被低估的参数 |

**购买原则**：
- **机身是消耗品，镜头是资产**。同一套预算，宁可机身二手、镜头好。
- 隔代升级通常不值得；跨代 + 换画幅/系统才值得。
- 新机发布 3–6 个月后二手价稳定，是性价比窗口。

## 三、镜头：按焦段决策

### 1. 一套"够用"的组合（全画幅等效）

| 方案 | 配置 | 适合 |
|---|---|---|
| 单镜走天下 | 24–105mm f/4 或 24–120mm f/4 | 旅行、日常、最省心 |
| 人像组合 | 35mm f/1.8 + 85mm f/1.8 | 环境人像 + 半身特写 |
| 一变一定 | 24–70mm f/2.8 + 50mm f/1.8 | 通用 + 暗光/虚化 |
| 风光组合 | 16–35mm f/4 + 70–200mm f/4 + 三脚架 | 广角气势 + 长焦压缩 |
| 街头轻装 | 定焦 28mm 或 35mm f/2 | 轻、快、低调 |
| 生态/运动 | 100–400mm 或 150–600mm | 焦段优先，光圈次要 |

### 2. 定焦 vs 变焦（再强调一次重点）

- **定焦买的是**：更大光圈（→ 入瞳直径 → 虚化与暗光）、更小体积、更少妥协、更明确的拍摄视角
- **变焦买的是**：不错过瞬间、少换镜头、旅行省事
- 新手建议：**先一支变焦建立焦段感，再补一支定焦练距离感**

### 3. 二手镜头的检查项

1. **前后组镜片**：划痕、霉斑（蛛网状）、雾化、脱胶
2. **光圈叶片**：油污（收放迟滞）、形状
3. **对焦**：是否拉风箱、有无异响、AF 是否准确
4. **变焦/对焦环**：是否松垮、阻尼是否均匀
5. **防抖**：通电试防抖是否工作（有轻微嗡声正常）
6. **卡口与螺丝**：有无拆修痕迹（螺丝花、胶痕）
7. **转接痕迹**：老镜头改口可能有对焦限位问题

## 四、附件：按性价比排序

| 优先级 | 附件 | 理由 |
|---|---|---|
| ★★★★★ | **备用电池 ×2** | 一块电池毁一次拍摄 |
| ★★★★★ | **高速存储卡** | 连拍/视频会卡在这；速度看写入（UHS-II / V60+） |
| ★★★★★ | **气吹 + 镜头布** | 灰尘是画质杀手，气吹是唯一安全的日常手段 |
| ★★★★☆ | **三脚架** | 长曝、夜景、风光、精确构图的必需品；**稳定性 > 轻**，但**太重就没人带** |
| ★★★★☆ | **ND 滤镜** | 白天长曝的唯一解（见 [05-快门与动感](./05-快门与动感.md)） |
| ★★★☆☆ | **CPL 偏振镜** | 消水面/玻璃反光、加深天空；约损 1.5 档光；对金属反射无效；广角端天空偏振不均 |
| ★★★☆☆ | **GND（渐变减光）** | 平衡天地光比；如今很多场景可用包围曝光 + 后期替代 |
| ★★★☆☆ | **快门线 / 遥控** | 长曝防手抖；也可用延时自拍替代 |
| ★★☆☆☆ | **UV / 保护镜** | 争议大：能防磕碰，但劣质滤镜会降低画质（尤其逆光）；要么买好镜，要么不装 |
| ★★☆☆☆ | **摄影包 / 防潮箱** | 防潮箱（尤其南方）对抑制镜头发霉很关键 |
| ★☆☆☆☆ | **闪光灯** | 人像/活动大幅提升；但要学布光（见 [09-光线与用光](./09-光线与用光.md)） |

**配件铁律**：**任何装在镜头前的玻璃，都必须配得上镜头本身。** 一支 5000 元的镜头配 50 元的 UV 镜，等于把镜头降级。

## 五、预算怎么分

| 场景 | 建议分配 |
|---|---|
| 入门（首次购买） | 机身 40% : 镜头 40% : 附件 20% |
| 进阶 | 机身 20% : 镜头 60% : 附件 20% |
| 稳定期 | 只顾镜头 + 特定附件；机身用坏才换 |

三条经验：
1. **先买最常用的焦段，而不是"全覆盖"的焦段**。买 15 支镜头的人，通常只用 2 支。
2. **重复的焦段是最大的浪费**。买之前核对现有镜头的实际使用频率。
3. **想清楚"这个东西让我多带出门还是少带出门"**。轻便器材的成片率常常更高。

## 六、手机 vs 相机

| 维度 | 手机 | 相机 |
|---|---|---|
| 传感器 | 小（1 英寸已是"大底"） | 大（APS-C 起） |
| 物理虚化 | 等效光圈小，几乎无法物理虚化 | 强 |
| 计算摄影 | **多帧堆栈、夜景、HDR、算法虚化** 极强 | 依赖后期，但信息量更大 |
| 长焦 | 光学长焦少，多数靠裁切/多摄融合 | 真实长焦 |
| 可控性 | 光圈固定、快门/ISO 有限 | 全参数可控 |
| 即时性 | 永远在身上 | 需携带习惯 |
| 弱光 | 靠堆栈胜在"看起来干净"，但细节被算法涂抹 | 细节保真，但需技术 |

**结论**：**手机赢在"在场"，相机赢在"可控"**。
- 日常记录、社交、光线充足 → 手机往往够用且更快
- 需要虚化、暗光、长焦、闪光、精确曝光、大尺寸输出 → 相机不可替代
- 最佳实践：**把相机当"专门出门拍"的工具，把手机当"永远在身的备份"**，不要用"手机也能拍"当不学相机的借口，也不要因为买了相机就不拍随手可得的画面。

**手机拍照的几个实用要点**：用主摄（不是超广或长焦）画质最好；夜景模式要**保持静止**（它靠多帧对齐）；不要用数字变焦的最大倍率；用专业模式锁定曝光与白平衡比自动更稳定。

## 七、后期入门：最小可用流程

```
导入 → 选片 → 基础校正 → 局部调整 → 输出
```

| 步骤 | 做什么 | 关键 |
|---|---|---|
| **导入** | RAW 到目录，按日期命名 | 备份（至少两份，最好异地） |
| **选片** | 只留能用的 | 先删掉模糊/重复/无主体的，效率最高 |
| **白平衡** | 点中性区域或手动设 K | RAW 阶段调整损失最小（见 06 章） |
| **曝光 / 高光阴影** | 先修高光，再提阴影 | 高光不可恢复，优先保护 |
| **对比 / 曲线** | 建立层次 | 尽量用曲线而不是"对比度"滑块（更可控） |
| **局部** | 蒙版：提亮主体、压暗干扰 | 人像通常只需"眼睛/皮肤/背景"三处 |
| **降噪 + 锐化** | 顺序不能反 | 见 [07-对焦与画质](./07-对焦与画质.md) |
| **输出** | 尺寸 + sRGB + 适当锐化 | 网页用 sRGB；打印用 AdobeRGB |

**三条纪律**：
1. **备份先于一切**（存储卡不是存储）。
2. **后期是"还原现场所见"，不是"重画一张"**——尤其纪实类。
3. **同一批照片保持风格一致**（统一白平衡/曲线），组图观感远好于单张精修。

- 每周只发布 3 张 → 强迫选片，进步最快

- 一个月回顾一次自己的照片，找出"重复出现的毛病"

## 九、常见坑

1. **先买齐器材再学摄影**。器材清单可以等你知道自己要拍什么之后再列。
2. **追高参数忽略可用性**。峰值连拍 20fps 但缓存 20 张、体积巨大 → 实际用不上。
3. **买"全覆盖焦段"的低端变焦**（如 18–300mm）。画质与光圈都不理想，还容易让人以为自己什么都能拍。
4. **省钱买劣质滤镜/三脚架**。三脚架不稳导致长曝废片，滤镜劣化导致所有照片变软——这两处省钱最亏。
5. **不备份**。存储卡损坏、误删、格式化，都真实发生过。
6. **只用自动模式却抱怨"拍不出感觉"**。至少学会曝光补偿（这是投入产出比最高的一步）。
7. **把后期当万能**。曝光错 3 档、对焦错了、手抖了，后期救不回来。
8. **一直用同一套参数**。摄影的参数是"对应当下场景的"，没有通用配方（网上"人像参数"只能当起点）。
9. **忘带备用电池/卡**。这是最蠢也最常见的失败原因。

## 十、我的器材卡（Sony A7CR）

> 记录日期：2026-09-18。这套已经超过上文「够用组合」——缺的是用法，不是焦段。脚架和灯已补上，先练长曝与跳闪，别再买镜头。

### 1. 现有清单

| 角色 | 器材 | 覆盖 |
|---|---|---|
| 机身 | Sony A7CR（全画幅 61MP，IBIS，单卡槽） | 高像素 + 小体积；APS-C 裁切约 26MP |
| 超广定焦 | 16mm f/1.8 | 室内、建筑、星空、前景夸张的风光 |
| 日常变焦 | 24–70mm f/2.8 | 出门只带一支就带它 |
| 标准定焦 | 50mm f/1.4 | 人像、夜景、练距离感 |
| 中长变焦 | 70–200mm f/4 | 压缩、半身人像、活动、局部细节 |
| 三脚架 | Ulanzi ZERO Y（碳纤维，碗式云台，Arca） | 长曝、夜景、风光精细构图 |
| 闪光灯 | Sony HVL-F46RMA（GN46，无线电，HSS） | 室内人像/活动补光、跳闪、压环境光 |

焦段 **16–200mm 无断档**。对照第三节：这是「一变一定」+「风光组合」的合并，定焦端比 50/1.8 更强一档，广角端比 16–35/4 暗光强很多。

### 2. 机身使用要点

- **衍射**：61MP 像素间距约 3.8µm，f/5.6–f/8 开始显现（见 [03](./03-光圈与景深.md)）。风光默认收到这里，不要习惯性 f/16；要更大景深，用 16mm 走近或焦点堆栈。
- **裁切**：APS-C 约 26MP，70–200 变成 105–300。打鸟/舞台先用裁切，再决定要不要超长焦。
- **手持**：高像素把镜头短板和手抖一起放大。安全快门仍按 `1/等效焦距` 起步（见 [05](./05-快门与动感.md)）；IBIS 只管手，不管主体动。
- **备份**：单卡槽 + 大文件，存储卡不当仓库。RAW 按日期拷两份。
- **取景器**：EVF 弱于同传感器的 A7R V，50/1.4 全开时以回放确认焦点为准。

### 3. 四支怎么分工（看入瞳，不看焦段名）

`入瞳直径 = f / N`，同构图下背景虚化只由它决定（见 [03](./03-光圈与景深.md)）。

| 镜头 | 入瞳 | 真正买到的能力 |
|---|---|---|
| 16/1.8 | 8.9mm | 超广视角 + 暗光，不是虚化 |
| 24–70/2.8 | 24mm 端 8.6mm；70mm 端 25mm | 不错过瞬间 |
| 50/1.4 | **35.7mm** | 虚化 + 暗光主力 |
| 70–200/4 | 70mm 17.5mm；200mm **50mm** | 站远带来的压缩；200mm 端虚化其实很强 |

对照实验：

- **50/1.4 vs 24–70 的 50mm f/2.8**：同构图虚化差约 2 档（入瞳 35.7 vs 17.9）。50 不是备用焦段，是暗光和焦外工具。
- **70–200/4 @200mm vs 50/1.4**：200/4 入瞳 50mm，背景糊得更大，但必须站远——人脸比例自然是因为距离，不是因为焦距（见 [04](./04-焦距与透视.md)）。
- **16/1.8 拍人**：可以拍环境人像；不要凑近拍半身，鼻子放大是透视。
- 若 70–200 是 G OSS II（0.5× 微距），70–85mm 近摄可练有效光圈 `N(1+m)`，不必单买微距。

### 4. 8 周练习：用哪支

| 周 | 用哪支 | 做法 |
|---|---|---|
| 1 光圈 | **50/1.4** | f/1.4 → f/2 → f/2.8 → f/4 → f/8 各一组 |
| 2 曝光 | **24–70** | 雪/逆光/黑主体，只改补偿，看直方图 |
| 3 快门 | 流水 **16 + ZERO Y**；摇拍 **70–200** | 同一场景五档快门；长曝关 IBIS |
| 4 透视 | **24–70** 完成 24/35/50/85；再加 **16** 与 **135** | 先脚不动（只裁切），再走动（透视变） |
| 5 色彩 | 任意，但固定一支 | 去掉镜头变量 |
| 6 用光 | 人像 **50/1.4 + F46RMA**；风光 **16 + 70–200 + ZERO Y** | 一天七时段 + 8 个光位；室内加一组直射 vs 跳天花板 |
| 7 构图 | 广角前景 **16**；减法/压缩 **70–200** | 每个风景必带前景 |
| 8 组图 | 只带两支：24–70 + 50，或 16 + 70–200 | 从拍摄到后期 10 张 |

### 5. 脚架与闪光（本套怎么用）

#### ZERO Y

旅行碳纤维 5 节扳扣，收纳约 42cm、重约 1.1kg。碗式云台可在约 20° 内调水平，不用反复拧脚。Arca 快装。云台建议工作负重 **3kg**（标称最大 5kg）；本套最重组合 A7CR + 70–200/4 ≈ 1.3kg，余量够，大风里 200mm 端仍要压低重心、尽量**不开中轴**。

| 场景 | 做法 |
|---|---|
| 16mm 长曝 / 星空 | 脚架上 **关 IBIS 与镜头防抖**（见 [05](./05-快门与动感.md)）；快门线或 2s 延时 |
| 70–200 精细构图 | 中轴落下更稳；碗云台先找水平再构图 |
| 低机位前景 | 中轴可拆，最低约 15cm；16mm 贴地找前景 |
| 竖拍 | 云台双开口竖拍；常用再补 L 型快装板 |
| 不要指望它扛的 | 200–600 级长炮、大风超长焦——超建议负重就换更重的架 |

61MP 会把脚架微震一起放大。能不用升起的中轴就不要升。

#### HVL-F46RMA

索尼原厂机顶灯，GN46（ISO 100 / 105mm），TTL / 手动 / 频闪，HSS，无线电可当指挥官或接收器（约 30m）。A7CR 硬边界：

- **闪光同步：全画幅 1/160s，APS-C 裁切 1/200s**
- **电子快门不能闪**，改机械快门或电子前帘
- 快门快于 1/160s 要开 **HSS**，功率会掉一截，别按标称 GN 估曝光（见 [05](./05-快门与动感.md) §4）

| 先练 | 做法 |
|---|---|
| 跳闪（默认） | 灯头打白天花板/墙，不要机顶直射；直射扁平、硬、红眼 |
| 慢速同步 | 室内 1/15–1/30s + 闪光：主体锐、背景有环境光 |
| 后帘同步 | 有拖影时用后帘，拖影落在人后方 |
| 50/1.4 户外大光圈 | 必须 HSS；欠曝就靠近或加反光，而不是盲目加功率 |
| 混合光 | 闪光约 5500K；钨丝室内贴 **CTO** 统一色温（见 [09](./09-光线与用光.md)） |

AA 电池多带一组。第二支灯、灯架、柔光伞等离机系统齐了再用无线电指挥官——现在这一支先把跳闪和快门/光圈分工跑熟。

### 6. 还缺的附件

镜头、脚架、灯都齐了。按第四节性价比，结合 61MP：

1. 备用电池 ×2（NP-FZ100）
2. UHS-II 卡（V60/V90）——连拍会卡在写入
3. 气吹 + 镜头布——换 16 / 50 时灰尘进 6100 万像素
4. ND——白天用 16mm + ZERO Y 拍水/云
5. CPL——24–70 风光好用；**16mm 天空偏振容易不均**，广角端慎用
6. 闪光 AA 备用 + 快门线/遥控（脚架长曝；也可用 2s 延时替代）

滤镜口径先量四支螺纹。常见是 16 / 50 / 70–200 为 67mm、24–70 GM II 为 82mm——优先统一 67mm，24–70 用转接环。

### 7. 明确不买 / 特定题材才买

| 想买的 | 决定 |
|---|---|
| 85/1.4 或 85/1.8 | 先用 70–200 的 85–135 拍三个月，f/4 暗光不够再考虑 |
| 20–70 / 24–105 | 与 24–70 重复 |
| 14mm / 12–24 | 16/1.8 已覆盖超广；星空它比 f/4 变焦更合适 |
| 100–400 / 200–600 | 只有打鸟、远距离体育；先试 APS-C 裁切 |
| 第二支灯 / 灯架 / 柔光伞 | 跳闪用熟、确定要离机布光再买；F46RMA 可当无线电指挥官 |
