# 06. 白平衡与色彩

> 白平衡要解决的问题只有一句话：**"同一件白色物体，在不同的光下拍出来颜色不一样，相机怎么知道应该把它还原成白色？"**
> 它的答案藏在物理里（色温），但它的**用法**却经常被反着理解——先记住这一条：**白平衡数值设得比实际光源低 → 画面偏冷；设得高 → 画面偏暖。**

---

## 一、色温的物理来源

### 1. 黑体辐射

把一块理想黑体加热，它会发光；温度不同，发光的**光谱分布**不同：

- 温度低 → 辐射能量集中在长波长 → 看起来**偏红/橙**
- 温度高 → 峰值移向短波长 → 看起来**偏蓝**

**色温（Color Temperature）** 的定义：某光源的光谱与某个温度的黑体辐射最接近，就用这个温度（单位 K）描述它。严格称**相关色温（CCT）**。

### 2. 最反直觉的一条

| 说法 | 正确理解 |
|---|---|
| "把色温调高，画面变暖" | ❌ 反了 |
| **高色温 = 偏蓝（冷）；低色温 = 偏红（暖）** | ✅ |
| "烛光很暖 → 色温高" | ❌ 烛光约 1800K，是**低**色温 |
| "阴天很冷 → 色温低" | ❌ 阴天约 7000K，是**高**色温 |

口诀：**"色温数值 = 蓝的程度"**。数值越大越蓝。
（"暖/冷"是**观感词**，"K 值"是**物理量**，方向相反——所有混乱都来自这两个词汇体系混用。）

### 3. 常见光源色温

| 光源 | 约略色温 |
|---|---|
| 蜡烛 / 篝火 | 1500–2000 K |
| 日出/日落时的阳光 | 2000–3000 K |
| 家用白炽灯 / 卤素灯 | 2800–3200 K |
| 摄影棚钨丝灯 | 3200 K |
| 暖白 LED | 2700–3000 K |
| **正午日光（CIE D55）** | **5000–5500 K** |
| **电子闪光灯** | **5500–6000 K** |
| **CIE D65（标准日光）** | **6504 K** |
| 阴天 / 阴影处 | 6500–7500 K |
| 蓝天（天光） | 9000–12000 K |
| 雪山阴影 | 10000 K+ |

注意：**日出日落之所以"暖"，不是因为阳光变暖了**——阳光本身没变，是它穿过更厚的大气，短波被散射掉，剩下的长波偏红（Rayleigh 散射）。而**阴影处偏蓝**，是因为那里的光主要是"被天空散射的蓝光"。

## 二、白平衡到底在做什么

### 1. 它是一组通道增益

相机白平衡的本质：**对 R / G / B 通道施加不同的增益，使"应该中性的物体"三通道数值相等**。

```
WB 增益 = (1/R_ref, 1/G_ref, 1/B_ref)     R_ref/G_ref/B_ref = 光源下的白卡读数
```

### 2. 设置值的方向（务必搞清）

当你把相机白平衡设为 **X K**，你是在告诉相机："**现在的光源是 X K 色温的**"。相机会施加"把这个色温变中性"的补偿增益：

| 你设的值 | 相机施加的补偿 | 实际光源色温更高（更蓝）时 | 实际光源色温更低（更红）时 |
|---|---|---|---|
| 3200 K | 加蓝、减红 | **画面更蓝（冷）** | 画面中性 ✅ |
| 5500 K | 少量补偿 | 画面接近中性 | 画面偏红（暖） |
| 8000 K | 加红/橙、减蓝 | 画面明显偏暖 | 画面偏橙红 |

**一句话记法**：**"我在骗相机"**——设得比真实光源低，相机就按"更暖的光源"去补偿，补偿过头 → 画面偏冷。**反向使用就是创意工具**：

- 白天（5500K）把 WB 设到 **3200K** → 直接得到冷蓝色调（适合城市、雪、冷峻人像）
- 黄昏（3000K）把 WB 设到 **8000K** → 得到浓烈的橙金色（强化日落）
- 蓝调时刻设 3500K 左右 → 保留蓝而不至于灰

### 3. Tint 轴（绿—品红）

黑体轨迹是一条曲线，而**荧光灯、LED、绿色环境的光并不落在这条线上**。所以需要第二个轴：

| 环境 | 需要 |
|---|---|
| 荧光灯（老式） | 往品红（Magenta）偏 |
| 树林 / 草地反光 | 往品红偏（绿色溢出） |
| 绿幕棚拍 | 品红补偿 |
| 阴影偏蓝但发绿 | 微调 Tint |

这也是为什么**老式荧光灯是"白平衡灾难"**：它的光谱是若干条尖峰（汞蒸气），不是连续谱，任何增益都无法让所有颜色同时正确 → 只能靠**自定义白平衡 + 后期微调**，或干脆避开它拍摄。

## 三、RAW 与 JPEG 的根本差别

| | RAW | JPEG |
|---|---|---|
| 位深 | 12 / 14 bit | 8 bit |
| 白平衡 | **记录原始三通道数据，WB 只是元数据** | **WB 已经烘焙进像素** |
| 可调幅度 | 几乎无损（±2000K 随意） | 大改会出色偏、色带、噪点 |
| 色彩空间 | 相机原生（未绑定色域） | 已转为 sRGB / AdobeRGB |
| 高光恢复 | 有 0.5–2 档余量 | 基本没有 |

**结论**：想自由玩白平衡与色彩，**拍 RAW**。用 JPEG 时白平衡必须在拍摄阶段定准（或接受有限调整）。

补一句关键原理：**RAW 没有"色彩空间"概念**。色彩空间是"把三通道数值解释成颜色"的映射，只在输出（JPEG/TIFF/显示）时才需要绑定。

## 四、怎么把白平衡设准

| 方法 | 做法 | 适用 |
|---|---|---|
| **自动（AWB）** | 交给相机 | 日常、混合光，但每次结果可能不一致（连拍组图要小心） |
| **预设** | 选日光/阴天/钨丝/荧光 | 光源类型明确时 |
| **K 值手动** | 直接输入色温 | 需要精确复现、多灯混合 |
| **自定义 / 白卡** | 用 18% 灰卡或白卡填满画面，设自定义 WB | **最准**，室内棚拍、商品、翻拍 |
| **机内吸管（后期）** | 点中性区域 | 最难也最方便的后处理方式 |

**实操要点**：
- **白卡 ≠ 灰卡**：白卡反光强，容易高光溢出导致读数不准；**灰卡（18% 或 90%）更稳**。
- **别用"随手一张纸"**：复印纸含荧光增白剂，在紫外/日光下会偏蓝，读数不可靠。
- **RAW 后期校正成本更低**：先拍一张带灰卡的参考帧，后期把整批照片套同一 WB 数值。

### 混合光源的困境

当场景里有两种以上色温（窗外日光 + 室内钨丝灯 + 闪光灯），**白平衡只能救一种**：

| 方案 | 做法 |
|---|---|
| 统一光源 | 关掉一部分灯 / 拉窗帘 / 换成同色温灯泡（最彻底） |
| 用滤镜匹配 | 闪光灯加 CTO（降色温到 3200K）或 CTB（升到日光），让所有光源同温 |
| 分层处理 | 后期对人物与背景分别调 WB（蒙版/局部调整） |
| 接受色彩对撞 | 冷暖对比本身就是风格（蓝窗户 + 暖室内灯），但要让"主要主体的肤色"正确 |

**永远优先保证：人物肤色正确。** 环境可以偏色，脸不能。

## 五、色彩管理与色域

### 1. 常见色彩空间

| 色彩空间 | 原色 | Gamma | 覆盖可见色域（约） | 用途 |
|---|---|---|---|---|
| **sRGB** | Rec.709 | sRGB | ~35% | 网页、社交平台、通用交付 |
| **AdobeRGB (1998)** | 更广（尤其青绿） | 2.2 | ~50% | 印刷、专业修图 |
| **Display P3** | DCI-P3 原色 | sRGB | ~45%（红绿更饱和） | Apple 设备、HDR 生态 |
| **ProPhoto RGB** | 极广 | 1.8 | ~90% | RAW 工作空间、避免剪切 |
| **Rec.2020** | 更广 | 混合 | ~76% | HDR / 4K 广播 |

### 2. 三个必知事实

1. **在 sRGB 屏幕上直接看 AdobeRGB 图片 → 颜色发灰、发闷**（因为数值被按 sRGB 解释，饱和度被"压缩"）。需要用支持宽色域的浏览器/软件（并正确读 ICC profile）。
2. **导出给网页/手机 → 一律 sRGB**。社交平台会自行转换，宽色域图片常被"粗暴压缩"导致偏色。
3. **色域越大 ≠ 颜色越好看**：它只决定"能表示多饱和的颜色"，不决定"还原是否准确"。日常交付 sRGB 完全够用。

### 3. 位深与色带

- 8bit = 每通道 256 级，RGB 组合约 1677 万色（够看，但**大范围渐变容易出色带**）
- 10/12/14bit → 级数多，后期大幅度调整曲线/渐变不易出色带
- **修图流程**：RAW 16bit 处理 → 输出 JPEG 8bit（最后一步才降位深）

## 六、色彩风格是可调的吗

- **相机厂商的色彩科学不同**：同一场景直出 JPEG，各家白平衡策略、肤色曲线、饱和/对比都有差异（所谓"佳能肤色""富士色彩"）。
- **胶片模拟 / 照片风格**：本质是"曲线 + 色相偏移 + 颗粒"的组合（富士有 Profoto/经典负片/ACROS 等）。
- **LUT 与 3D LUT**：视频里常用的查找表，把"某输入色 → 某输出色"映射，用来跨机匹配（Log → Rec.709）。
- 重要认知：**色彩风格是"解释"层面的东西，不是成像层面的**。它不该被用来弥补曝光/白平衡，而是最后一步的风格化。

---

## 七、常见坑

1. **把"色温高"理解成"更暖"**。物理上高色温偏蓝。UI 上的"暖色滑块"与 K 值方向相反才是正常的。
2. **逆着用还不知道**。设 3200K 拍白天得到冷调，不是"白平衡错了"，是你主动设置了错的值——RAW 里可随时改。
3. **混合光源下反复调 WB 追求全对**。物理上不可能，选"最重要的一种"（通常是肤色）。
4. **用白纸代替灰卡**。含荧光增白剂会偏色，务必用专业灰卡。
5. **JPEG 大幅改白平衡**。会出现色偏、色带、噪点，尤其在暗部。
6. **以为 AWB 稳定**。连拍组图里 AWB 可能逐张漂移，需要统一 WB（尤其做延时/拼接）。
7. **把色域问题当"屏幕坏了"**。显示宽色域图片发灰是色彩管理链没走对。
8. **用 LCD 判断颜色**。屏幕亮度/色温/环境光都在骗你，重要交付前校准显示器（或至少用已知参考图对比）。

---

## 八、上手练习

1. **同一场景拍三档 WB**（3200K / 5500K / 8000K），只改白平衡 → 建立"K 值方向"的肌肉记忆。
2. **拍 RAW，后期把同一张改到 2500K 与 10000K**，观察色偏幅度与暗部噪点变化。
3. **找一张灰卡练自定义 WB**，对比 AWB 与自定义 WB 的差异（商品/翻拍最能看出差距）。
4. **混合光源练习**：室内开暖灯、拉一半窗帘（日光进来），尝试"人物正确 + 背景偏蓝"的处理。
5. **刻意风格化**：白天用 3200K 拍城市/雪景，体会"冷调"；黄昏用 8000K 拍海边，体会"金调"。
