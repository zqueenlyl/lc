# 04. 焦距与透视

> 焦距本身只决定**取多大范围**（视角）；观感上那些"广角变形""长焦压缩"的差异，全部来自**拍摄距离**。
> 把这两件事分开，你就不会再被"换个镜头改变透视"这类说法带偏。

一句人话：**焦距只裁切取景框；透视只由你站哪儿决定。**

---

## 一、焦距决定视角

### 1. 视角公式

```
水平视角 θ = 2 · arctan(d / (2f))        d = 传感器宽/高/对角线
```

全画幅（36 × 24mm）常用视角：

| 焦距 | 水平视角 | 对角视角 | 典型用途 |
|---|---|---|---|
| 14mm | 104.3° | 114.2° | 星空、超广风光、室内 |
| 16mm | 96.7° | 107.0° | 建筑、大场景 |
| 24mm | 73.7° | 84.1° | 风光、环境人像、扫街 |
| 28mm | 65.5° | 75.4° | 随身扫街、手机主摄等效 |
| 35mm | 54.4° | 63.4° | 纪实、人文、环境人像 |
| 50mm | 39.6° | 46.8° | 标准、接近人眼观感 |
| 85mm | 23.9° | 28.6° | 半身人像 |
| 135mm | 15.2° | 18.2° | 压缩感人像、特写 |
| 200mm | 10.3° | 12.3° | 运动、远摄 |
| 400mm | 5.2° | 6.2° | 野生动物、体育 |

> **"50mm 接近人眼"是有限成立**：人眼的周边视野远大于 46°，但"注意力中心区"的放大感确实接近 50mm（也有人说 40–45mm，与观看距离/照片尺寸有关）。这不是物理定律，是经验近似。

### 2. ±1 档焦距的观感

焦距翻倍 = 视角减半 ≈ 画面被"剪切"掉一半。
所以 **24 → 48、35 → 70、50 → 100** 是"一次翻倍"，观感差异显著；24 → 28 则只是微调。

## 二、等效焦距：只解决"视角等价"

不同画幅要比较"拍到的范围"，用裁切系数换算：

```
等效焦距 f_eq = f × k
```

| 画幅 | k | 常见"标准镜" | 常见"人像镜" | 常见"广角" |
|---|---|---|---|---|
| 中画幅 4433 | 0.79 | 63mm | 107mm | 30mm |
| 全画幅 | 1.0 | 50mm | 85–135mm | 24–35mm |
| APS-C（佳能 1.6 / 其他 1.5） | 1.5–1.6 | 33mm | 50–85mm | 16–24mm |
| M4/3 | 2.0 | 25mm | 42–67mm | 12–17mm |
| 1 英寸手机 | 2.7 | 18mm | 31–50mm | 9–13mm |

**必须成对理解的一个事实**：等效焦距只等价**视角**。要比较"景深与总进光量"，还得用**等效光圈** `N × k`（见 [03-光圈与景深](./03-光圈与景深.md)）。

> 所以"APS-C 上 35mm f/1.8"≈"全画幅 52mm f/2.8"：视角与景深接近，但全画幅可以收到 f/4 获得更好画质，而 APS-C 已经到底。这才是画幅差距的真实形状。

## 三、透视只由距离决定

### 1. 核心结论

**同一位置、同一构图下，换任何焦距都不会改变物体之间的相对大小关系。** 透视（近大远小、汇聚线、形变感）是**三维场景经中心投影后的几何结果**，由相机位置与物体位置决定。

焦距只是一个"取景框大小"，它决定你在这幅投影里**裁出哪一块**。

### 2. 经典实验

站在同一点，用 24mm 和 200mm 各拍一张：

- 200mm 的画面 ≈ 24mm 画面的中央部分放大 → **两者透视关系完全一致**（没有"压缩"）。
- 只有当你为了"让 200mm 拍全主体"而后退时，透视才变了。

### 3. "长焦压缩/广角拉伸"的真相

| 说法 | 真相 |
|---|---|
| 长焦压缩空间 | 为了同构图必须站远；距离增大 + 视角变窄 → 前后物体相对大小差异变小，看起来"压缩" |
| 广角夸张变形 | 为了拍全必须靠近；距离小 → 近处物体比例暴增、远处急剧缩小 |
| 广角把脸拍变形 | 是**靠得太近**把鼻子放大、耳朵缩小 |
| 广角拍腿长 | 相机位置低 + 靠近脚，是利用"近大远小"，与焦距无关 |

推论（很实用）：**想控制透视，就控制相机与被摄体的距离；想控制取景范围，才动焦距。** 这就是为什么"人像用长焦"是对的——它逼你站远，而站远才是让人脸比例自然的原因。

### 4. 一个例外：画幅裁切

同一位置同焦距，小画幅只是**裁切**中心区域，透视当然一致。所以"APS-C 会用 1.5 倍长焦"这种说法，本质是"裁得更少"。

## 四、焦段与题材

| 焦段（全画幅等效） | 俗称 | 强项 | 弱项 |
|---|---|---|---|
| < 20mm | 超广 | 星空、室内、夸张前景、气势 | 边缘畸变/软化、易塞入杂物、人像变形 |
| 24–35mm | 广角 | 风光、纪实、环境人像、vlog | 需要强前景与层次，否则"平" |
| 40–58mm | 标准 | 最接近人眼观感、进可攻退可守 | 没有明显特色，容易被当"没风格" |
| 70–135mm | 中长焦 | 人像、特写、压缩背景、隔离主体 | 需要空间，室内施展不开 |
| 150–300mm | 长焦 | 运动、舞台、野生动物、细节 | 大而重、安全快门要求高 |
| > 400mm | 超长焦 | 打鸟、远距离运动 | 极贵极重、大气扰动影响画质 |

### 定焦 vs 变焦

| 维度 | 定焦 | 变焦 |
|---|---|---|
| 光圈 | 普遍更大（f/1.2–f/2） | 常 f/2.8–f/6.3，恒定大光圈贵 |
| 画质 | 同价位通常更好（结构更简单） | 现代高端变焦已非常接近 |
| 体积重量 | 轻小 | 大 |
| 拍摄节奏 | 逼迫你"用脚变焦"，训练距离感 | 方便抓拍、减少换镜 |
| 适合 | 人像、暗光、风格化 | 旅行、活动、纪实 |

**"用脚变焦"的隐藏价值**：定焦会强迫你改变**拍摄距离**——而改变距离就是改变透视。这是它比"少几个数字"更本质的训练意义。

## 五、两类"变形"必须分开

| | 透视变形（Perspective） | 镜头畸变（Distortion） |
|---|---|---|
| 本质 | 中心投影的几何必然结果 | 光学设计缺陷 |
| 表现 | 近大远小、向后汇聚 | 桶形/枕形/胡须形弯曲 |
| 由什么决定 | 相机与物体的距离 | 镜片结构 |
| 能否消除 | ❌ 不能，只能改变拍摄位置 | ✅ 机内/后期校正 |
| 例子 | 广角仰拍建筑"倒向中心" | 直线在广角端向外鼓（桶形） |

**推论**：

- "广角矫正畸变后人物还是变形" → 因为那部分是透视，不是畸变。
- **拍建筑保持感**：相机水平、用移轴镜头或用足够广的镜头后期裁切（裁切等效于移轴效果），避免仰拍。

另外还有：

- **暗角（Vignetting）**：几何暗角 + 光学暗角，广角端更明显，机内可校正。
- **场曲（Field Curvature）**：像面是曲面 → 中心清晰时边缘虚，收光圈改善。
- **呼吸效应（Focus Breathing）**：对焦改变视角，视频里很明显（现代镜头开始专门优化）。

## 六、镜头工程上的几个概念

| 概念 | 含义 | 为什么关心 |
|---|---|---|
| **法兰距** | 卡口到传感器的距离 | 决定能否转接（短法兰距可转接长法兰距镜头） |
| **卡口内径** | 卡口开口直径 | 影响超大光圈与广角后组设计余量 |
| **增距镜** | 加在镜头与机身间，×1.4 / ×2 | 焦距变长、光圈变小（×1.4 损失 1 档、×2 损失 2 档） |
| **裁切/数码变焦** | 只取传感器中央，等效于裁剪 | 画质不升反降，只是取景方便 |
| **像圈（Image Circle）** | 镜头能覆盖的成像圆 | 全画幅镜头装在 APS-C 上"浪费像圈"，反之会严重暗角/无法覆盖 |
| **近摄接圈** | 增加像距，提高放大倍率 | 微距低成本方案，代价是无限远无法对焦、损失 1–2 档光 |
| **反接环** | 镜头反装 | 超高放大倍率微距，失去自动对焦/光圈控制 |

## 七、常见坑

1. **"换长焦能压缩背景"**。压缩的前提是站远；同位置换焦距只是裁切。
2. **"广角变形靠后期校正"**。透视部分救不回来，只能重拍或裁切。
3. **忽略"等效光圈"**。以为 APS-C f/1.8 等于全画幅 f/1.8 的虚化与暗光能力（实际差约 1 档）。
4. **人像用 24mm 凑近拍半身**，然后嫌鼻子大。这是透视，不是镜头问题。
5. **拍风景只用广角**。长焦能压缩层叠的山峦、隔离远处细节，是风光"减法"的重要工具。
6. **用最大光圈拍风光**：中心尚可、边缘崩坏。收 2 档。
7. **手持长焦不提升快门**。安全快门 ≈ 1/等效焦距（见 [05-快门与动感](./05-快门与动感.md)），400mm 意味着 1/400s 起步。
8. **买镜头只看焦距不看最大光圈/最近对焦距离/重量**。这三项决定你愿不愿意带它出门。

## 八、现场决策套路

```
1. 先定距离（脸/建筑要什么透视）
2. 再选焦距把主体装进框
3. 最后看入瞳够不够虚化、快门够不够跟上
变形：能后期救的是畸变；救不了的是站位
```

选镜头的决策顺序：

1. **先定画幅**（决定等效焦距与等效光圈换算）。
2. **看你要拍的题材需要视角范围**，而不是"别人说什么焦段好"。
3. **看最大光圈**：f 值 → 入瞳直径 → 决定虚化与暗光能力。
4. **看最近对焦距离与放大率**：能不能拍小物件。
5. **看重量与体积**：会不会留在家里。
6. **最后看画质评测**：现代镜头差距远比第 1–5 项小。

**一条实践口径**：如果只买一支定焦，**35mm 或 50mm**（等效）；如果只买一支变焦，**24–70mm f/2.8 或 24–105mm f/4**（等效）。本套怎么分工见 [10 器材卡](./10-装备选型与练习清单.md#十我的器材卡sony-a7cr)。判断见 [12](./12-自测与过线.md)。

**记忆线索**：想控制脸和楼的形状，先挪脚。下一章时间——快门是唯一直接画时间的旋钮。
