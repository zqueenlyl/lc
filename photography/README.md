# 摄影学习笔记（Photography）

> 摄影的三层问题：**光怎么进入相机**（原理）→ **参数怎么取舍**（控制）→ **画面怎么组织**（表达）。
> 本目录按这三层重组：先建立可推导的物理直觉，再给可执行的参数决策，最后讲构图与用光。

一句人话：**参数决定"拍得到"，光与构图决定"好不好看"；而所有参数都是在同一次曝光里做取舍。**

本目录是**系统笔记**，不是相机说明书，也不依赖任何特定品牌。所有公式与数字都给出「它在实践中意味着什么」，不背参数表。

## 核心公式速查

| 式子 | 含义 | 实践推论 |
|---|---|---|
| `N = f / D` | f 值 = 焦距 / 入瞳直径 | f 值是比值，所以跨镜头可比 |
| `H ∝ 1/N²` | 进光量与 f 值平方成反比 | f 值 ×√2 = 面积减半 = 1 档 |
| `EV = log₂(N²/t)` | 曝光值 | 同 EV 下有无穷多组合，取舍在景深与动感 |
| `DOF ≈ 2Nc·d²/f²` | 景深近似式 | 同构图下（d ∝ f）焦距被消掉 → **焦距不影响景深** |
| `C∞ ≈ (f/N) × m` | 背景弥散圆 | 同构图下虚化只由**入瞳直径**决定 |
| `艾里斑 ≈ 2.44λN` | 衍射极限 | f/16 时已达 21µm，超过多数像素间距 |
| `N_eff = N(1+m)` | 微距有效光圈 | 1:1 时镜头 f/8 实际是 f/16 |
| `SNR ∝ √N` | 散粒噪声 | 光子翻 4 倍才让信噪比翻倍 |
| `I ∝ 1/d²` | 平方反比 | 灯近一档，亮度差 4 倍 |

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| **曝光量** | 单位面积收到的光能；只由场景亮度、光圈、快门决定 |
| **f 值** | 焦距 / 有效孔径；数字越小孔越大、景深越浅 |
| **等效焦距** | `f × 裁切系数`，只等价视角 |
| **等效光圈** | `N × 裁切系数`，等价景深与总进光量（手机虚化靠算法的原因） |
| **容许弥散圆 c** | 判定"还算清晰"的阈值，全画幅常用 0.03mm |
| **超焦距 H** | 对焦到 H 时，H/2 到无穷远都清晰 |
| **入瞳直径** | `f / N`；同构图下决定背景虚化强度 |
| **衍射极限** | 小光圈后整幅变软；高像素机身来得更早 |
| **安全快门** | `1 / 等效焦距` 起步；防抖只管手不动，不管主体动 |
| **闪光同步速度** | 由帘幕走行时间决定（常见 1/200–1/250s） |
| **色温（CCT）** | 黑体辐射温度；**数值越高越偏蓝** |
| **白平衡** | 让中性物体三通道相等的通道增益；设低偏冷、设高偏暖 |
| **动态范围** | 满阱容量 / 读出噪声；阴影好救，高光难救 |
| **ISO 不变性** | 部分机型"提高 ISO"与"后期提亮"结果接近 |
| **视觉重量** | 人脸、亮部、饱和色、大面积、清晰区域先被看到 |

## 常见误解速查（本目录反复纠正的几条）

| 误解 | 正确 |
|---|---|
| ISO 是曝光三要素之一 | ISO 是增益，不改变进光量。真正的曝光要素只有光圈与快门 |
| 焦距越长景深越浅 | 只在同距离成立；**同构图下焦距不影响景深** |
| 长焦能压缩背景 | 是"站远"压缩背景，焦距只裁切取景范围 |
| 广角变形可以后期矫正 | 透视变形不可矫正，只能改拍摄位置 |
| 色温高更暖 | 色温高偏蓝；"暖/冷"与 K 值方向相反 |
| ISO 高所以噪点多 | 噪点来自光少；ISO 只是把噪声一起放大 |
| 小光圈一定更锐 | 超过最佳光圈后被衍射统治；f/22 通常明显变软 |
| 柔光箱 = 软光 | 软硬由光源**表观尺寸**决定；灯拉远就变硬 |
| 防抖能拍清运动物体 | 防抖只补偿相机位移，主体运动照糊不误 |
| 像素高画质差 | 同尺寸输出看总进光量；高像素代价是衍射更早显现 |
