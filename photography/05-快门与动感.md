# 05. 快门与动感

> 快门是唯一一个"直接控制时间"的旋钮，因此它不只是曝光工具，更是**在照片里表达时间的唯一手段**。
> 想凝固就短，想流动就长——但两次都别忘了一件事：**你手也在动**。

一句人话：**快门是照片里时间的形状；防抖只管你的手，不管主体动。**

---

## 一、快门机构：为什么会有"同步速度"和"果冻"

### 1. 焦平面快门（机械，主流）

两片帘幕（前帘、后帘）在传感器前方滑动：

```
前帘放开 → 曝光开始（逐行扫描，不是整幅同时）
后帘跟上 → 曝光结束
快门很快时，两帘之间只有一条窄缝在扫描
```

关键量：**帘幕走完全画幅的时间（走行时间）**，通常 **2.5–4ms**。因此：

```
理论同步速度上限 ≈ 1 / 走行时间      （3ms → 约 1/320s）
厂家标称值 = 理论值再留余量          → 常见 1/200s ~ 1/250s
```

**为什么慢门不慢**（如 1/30s）：快门时间比走行时间长得多，帘缝足以整幅全开，此时闪一下就能覆盖全画面。
**为什么 1/2000s 全黑边**：帘缝只有一小条，闪光只照亮了当时被打开的那一条，其余区域没被照到。

### 2. 电子快门

| 类型 | 原理 | 特点 |
|---|---|---|
| **电子前帘（EFCS）** | 机械前帘换成传感器电子复位，后帘仍是机械 | 减少机震/快门声，同步速度基本不变，少数机型高快门时轻微剪裁 |
| **电子快门（滚动）** | 传感器逐行读出、逐行复位 | 静音无震动，但**读出行时间可能 10–30ms** → 果冻效应 |
| **全局快门** | 所有像素同时曝光同时读出 | 无果冻；传统上动态范围/噪声略弱（新一代大幅改善） |

### 3. 果冻效应（Rolling Shutter）

电子快门逐行读出的时间差导致：**画面内不同行记录的是不同时刻**。

| 现象 | 原因 |
|---|---|
| 快速横摇时电线变弯、建筑"倒向" | 左右不同列有读出时间差 |
| 高速运动物（飞机螺旋桨、高铁）被拉斜 | 上下不同行的时刻不同 |
| 闪光灯拍摄出现部分曝光 | 闪光脉冲早于读出完成 |
| LED 灯出现明暗条带（banding） | 灯的闪烁频率与读出行频拍频 |

修法：改用机械快门 / EFCS；或用足够慢的快门（长于读出时间，让整幅曝光都覆盖闪周期，如 1/50s 或 1/60s）。

## 二、安全快门：手抖的定量边界

### 1. 经典经验式

```
安全快门速度 ≈ 1 / 等效焦距
```

- 50mm（等效）→ 1/50s 起
- 200mm → 1/200s 起
- 400mm → 1/400s 起

这是**下限**，不是目标值。前提：**持握稳定、无防抖、不放大**。以下情况要更保守：

| 因素 | 保守量 |
|---|---|
| 高像素机身 | 每档多 1/3 ~ 1/2 倍（像素放大了抖动） |
| 手不稳/疲劳/冷 | 更慢的档位 |
| 需要 100% 放大看细节 | 快 1–2 档 |
| 使用增距镜 | 按等效焦距算 |

### 2. 防抖（IBIS / OIS）

- **OIS**：镜片位移补偿；**IBIS**：传感器位移补偿（可配任意镜头，含手动老镜）。
- 厂商标称值用 **CIPA 标准**（如"8 档补偿"），含义是"能比安全快门慢 8 档还稳住"。实测通常低于标称，且：
  - **对被摄体运动完全无效**（防抖只管你的手，不管人动）
  - 长曝光时补偿幅度有上限（大位移无法修正）
  - 某些机型 IBIS 在超长焦下效果下降

**最重要的一条**：有防抖 ≠ 可以慢快门拍动态主体。拍孩子、宠物、运动，快门要按**主体速度**定（见下表），防抖救不了。

### 3. 运动模糊的参考快门

| 主体 | 参考快门 |
|---|---|
| 静坐人像 | 1/60 – 1/125 |
| 慢速行人 | 1/125 – 1/250 |
| 正常行走/讲话手势 | 1/250 |
| 跑动的人 / 宠物 | 1/500 – 1/1000 |
| 自行车 / 慢速车 | 1/500 – 1/1000 |
| 汽车 / 摩托 | 1/1000 – 1/2000 |
| 鸟类飞行 | 1/1600 – 1/4000 |
| 赛车 / 螺旋桨 | 1/2000 – 1/8000（或故意用慢门做摇拍） |

> 这些是**起点**，实际取决于主体在画面中的大小（越大越需要快）、运动方向（迎面比横向"慢"）、以及你是否接受轻微动态模糊。

## 三、用快门表达：四种语言

| 意图 | 快门 | 手法 |
|---|---|---|
| **凝固（Freeze）** | 1/1000s 以上 | 抓住决定性瞬间，牺牲光线，常需高 ISO |
| **动态模糊（Motion Blur）** | 1/8 – 1/60s | 主体部分清晰、四肢/水流拉丝 → 有速度感 |
| **摇拍（Panning）** | 1/30 – 1/125s | 相机随主体同速横移 → 主体清晰、背景横向拉丝 |
| **长曝（Long Exposure）** | 1s – 30min | 流水如丝、云层流动、车灯轨迹、星轨、光绘 |

### 长曝的三个前提

1. **三脚架**（或稳固支撑）——长曝时防抖反而要关闭（补偿本身可能引起微小漂移）。
2. **减光镜（ND）**：白天想拍 1s 以上必须减光。

   | 标识 | 减光档 | 透光率 | 用途 |
   |---|---|---|---|
   | ND8 | 3 档 | 1/8 | 瀑布、慢门人像 |
   | ND64 | 6 档 | 1/64 | 白天雾化水面 |
   | ND1000 | 10 档 | 1/1000 | 白天 10–30s 长曝、云层 |
   | ND6400 | 13 档 | 1/6400 | 极端（正午拍空无一人的地标） |

3. **控噪**：超长曝光会累积热噪点。现代机型用**暗帧扣除（Dark Frame Subtraction）**处理，但会让"30s 曝光实际占用 60s"。堆栈多张短曝再平均，也是常用替代（改善 √N，见 [07-对焦与画质](./07-对焦与画质.md)）。

   **星轨不要走单张超长曝**：暗帧会把轨掐成虚线。用间隔短曝、后期变亮叠加，见 [11 星轨](./11-常见场景速查.md#一b星轨)。点状银河则相反——单张要短到星不拉丝。

### 摇拍要点

- 快门选 1/30 – 1/125s（太快背景不拉丝，太慢主体也糊）
- 与主体同速、同向平滑转动，用身体转（不要只动手腕）
- 成功率低（10%–30%），连拍＋大量尝试
- 背景有明显横向纹理（建筑、树、灯）时效果最好

## 四、闪光灯与快门的关系（必懂）

闪光灯曝光的两个独立旋钮：

| 旋钮 | 控制什么 |
|---|---|
| **光圈 / 闪光功率** | **主体**被闪光照亮的亮度 |
| **快门速度** | **环境光**的亮度（背景、氛围） |

于是出现经典手法：

| 手法 | 设置 | 效果 |
|---|---|---|
| 正常闪光 | 快门 = 同步速度（如 1/200s） | 主体亮、背景黑（影棚感） |
| **慢速同步（Slow Sync）** | 用 1/15 – 1/30s | 背景环境光进来，主体闪光凝固 |
| **后帘同步（Rear Curtain）** | 同上 + 后帘触发 | 拖影在主体**后方**（自然），前帘同步拖影在前方（诡异） |
| **高速同步（HSS / FP）** | 快门快于同步速度 | 闪光灯脉冲重复输出，可在强光下用大光圈；代价是**功率骤降**（GN 可能只剩 1/4 或更低） |

**快门与闪光的硬边界**：
- 非 HSS 模式：快门**不能**快于同步速度（否则黑边）。
- 用闪光时快门通常不参与"压暗背景"以外的创作，想靠快门凝固动作意义不大——**凝固由闪光持续时间（1/1000–1/20000s）完成**。

## 五、常见坑

1. **防抖开着拍运动主体**。防抖补偿的是相机位移，主体自己动的模糊一点都减不掉。
2. **长曝不关防抖、不用三脚架**。IBIS/OIS 在长曝下可能引入漂移；手持 1s 以上基本无解。
3. **只看快门不看等效焦距**。M4/3 上 25mm 是"50mm 视角"，安全快门按 1/50s 而不是 1/25s。
4. **以为电子快门 = 绝对静音无副作用**。滚动式电子快门有果冻效应、可能与 LED 灯频闪打架、部分机型不能用闪光。
5. **用 HSS 却按标称 GN 计算曝光**。HSS 下 GN 大幅下降，最容易欠曝。
6. **长曝忘了高光溢出**。车灯轨迹、路灯、月亮极容易烧白，先拍一张看高光警告。
7. **用慢门拍人像却不交代"要静止"**。2 秒的长曝人像，人再稳也会糊。
8. **"快门越快越好"**。快门是创作参数：流水、云、人流、雨丝都需要慢门才好看。
9. **忘了长曝会让噪点/热噪累积**。夏天正午长曝尤其明显，注意机身温度与暗帧。

## 六、现场决策套路

```
主体在动吗？
  动：快门按主体速度，防抖帮不上
  静：安全快门 1/等效焦距，可吃防抖；高像素再快 1/3 档
要时间的形状：凝固 / 拉丝 / 摇拍 / 长曝
  长曝：上架、关防抖、白天加 ND
闪光：快门管环境，光圈/功率管主体；A7CR 同步 1/160s，电子快门不闪
```

上手练习：

1. **同一场景拍五档快门**（1/1000 → 1/30），只改快门，观察"什么时候开始有故事"。
2. **瀑布/水龙头**：1/1000（水花凝固）→ 1/8 → 1s → 4s（如丝如雾）各一张。
3. **摇拍**：站在路边拍来车，从 1/250 逐档降到 1/30，找"背景拉丝但车身清晰"的甜点。
4. **慢速同步闪光**：室内 1/20s + 闪光，看主体锐而背景有环境光的过渡。
5. **手持极限**：用同一焦距从 1/焦距 逐档放慢，找出自己真正的稳定边界（防抖开/关各测一次）。

判断见 [12](./12-自测与过线.md)。

**记忆线索**：防抖救手不救主体；闪光把主体和环境拆成两个旋钮。下一章光的颜色——白平衡经常被反着设。
