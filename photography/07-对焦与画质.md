# 07. 对焦与画质

> 一张照片"不够锐"，可能是对焦、抖动、衍射、噪声、镜头、滤镜、降噪中的任何一环。
> 这一章把"画质"拆成**可归因的几项物理来源**，再讲对焦系统怎么工作——目的是让你遇到问题时能**定位**，而不是盲目换器材。

一句人话：**不锐先归因，别先换镜头；噪点来自光少，不是 ISO 高。**

---

## 一、自动对焦的三种原理

### 1. 反差检测（CDAF）

原理：**对比度最大的位置就是合焦位置**。不断移动对焦组，找对比度的峰值。

| 优点 | 缺点 |
|---|---|
| 精度高、不需要专用像素 | 需要"来回试探"→ 慢 |
| 结构简单、成本低 | 低对比/低光下失效 |
| | 无法判断"离焦方向"→ 拉风箱 |

### 2. 相位检测（PDAF）

原理：把进入镜头的光**分成两束**，比较两束成像的位置差：

- 位置重合 → 合焦
- 分开 → 能**同时算出偏离方向与大小**，一次算到位

| 优点 | 缺点 |
|---|---|
| 快，可预测运动物体 | 需要专用像素（遮挡一半），占面积 |
| 能判断方向 | 低光/低对比下精度下降 |
| 追焦（AF-C）的基础 | 单反时代存在"跑焦"问题 |

### 3. 单反跑焦 vs 无反对焦

| | 单反 | 无反 |
|---|---|---|
| 对焦光路 | 反光板下方独立相位模块 | 传感器本身（片上 PDAF） |
| 与成像光路 | **不同**（经过副反光板、分离镜） | **相同** |
| 问题 | 光路偏差 → 系统跑焦，需要 AF 微调 | 基本不存在 |
| 主体识别 | 无法用像素数据 | 可直接用图像做**人脸/人眼/动物/车辆识别** |

**无反对焦的额外优势**：AF 区域可以覆盖几乎整幅、可以做"眼控对焦"（认出眼睛并直接对眼球）、可以按主体的对焦平面优先。这是"无反 = 单反 + 电子化"之外的**结构性**提升。

### 4. 混合方案

- **片上相位 + 反差**（主流）：相位负责快速接近，反差负责最终确认精度。
- **双像素 CMOS（Canon Dual Pixel）**：每个像素一分为二，全像素都能做相位检测 → 覆盖最广、对比度损失最小。
- **激光 / ToF 辅助**：少数机型用测距传感器辅助低光对焦，多为辅助而非主判据。

## 二、对焦模式与区域

| 模式 | 名称 | 行为 | 适合 |
|---|---|---|---|
| **AF-S / One Shot** | 单次对焦 | 合焦后锁定，快门按下不再调 | 静止主体、先对焦后构图 |
| **AF-C / AI Servo** | 连续对焦 | 持续追焦，预测运动 | 运动、宠物、小孩、追焦连拍 |
| **AF-A / 自动** | 自动切换 | 相机判断静止/运动 | 新手抓拍 |
| **MF** | 手动对焦 | 全手动 | 微距、暗光、前景遮挡、视频 |

**区域模式**（名称各家不同）：

| 区域 | 行为 | 适合 |
|---|---|---|
| 单点 | 只用一个对焦点 | 精确控制焦点位置 |
| 扩展/区域 | 单点 + 相邻点兜底 | 运动主体、难以精确对准 |
| 广域/全屏自动 | 相机自己选主体 | 抓拍、人脸识别 |
| 眼控/主体识别 | 直接锁眼睛 | 人像**必开** |

**人像铁律**：**对焦平面落在眼睛上**（通常是靠近相机的那只眼）。眼睛不锐，照片就废——景深越浅，越要保证这一点。

### 手动对焦的辅助

| 工具 | 原理 |
|---|---|
| 峰值对焦（Peaking） | 高对比边缘描色，告诉你在焦内的区域 |
| 放大对焦 | 局部放大到 5–10 倍，精确定位 |
| 裂像/微棱（老式） | 对焦屏上的光学辅助 |
| 对焦指示箭头 | 机身告诉你"该往哪转" |

**陷阱对焦**：先把焦平面定在预期出现的位置，等主体进入 → 手动按下。拍龙舟、跳台、赛车常用。

## 三、噪声：物理来源与下限

### 1. 四类噪声

| 类型 | 来源 | 特征 |
|---|---|---|
| **散粒噪声（Shot noise）** | 光子到达是**泊松过程**，天然随机 | **信号越弱越明显**，是物理下限，不可消除 |
| **读出噪声（Read noise）** | 读出电路/ADC 的电子噪声 | 与 ISO 增益有关，决定暗部噪声与动态范围 |
| **热噪声 / 暗电流** | 温度导致的漏电 | 长曝、高机身温度时明显 |
| **固定模式噪声（FPN）** | 像素间响应不一致 | 表现为图案状噪点，暗帧可扣 |

### 2. 散粒噪声意味着什么

```
信噪比 SNR ∝ N / √N = √N        N = 收集到的光子数
```

**这是画质物理的根基**：

- **光子越多，相对噪声越小**（但绝对噪声随 √N 增长）。
- 想要 SNR 提升 1 倍，需要 **4 倍**的光子。
- 所以改善高感画质的根本手段是"**收更多光**"：更大画幅、更大光圈、更长曝光、更好的量子效率。

### 3. "高 ISO 噪声"的真相

提高 ISO **不产生**噪声，它只是**放大已有信号和噪声**。所以：

> **你在暗光下看到的噪点，来自"光太少"，不是"ISO 太高"。**
> 如果快门/光圈已经到极限，那把 ISO 提上去（拍亮一点，后期压回）几乎总是比"欠曝后期提亮"更好或至少不差——这就是 **ISO 不变性（ISO Invariance）** 的实用推论。

| 概念 | 含义 |
|---|---|
| **ISO 不变性** | 某些机型在特定 ISO 以上"提亮"与"后期提亮"结果几乎一样 → 可以固定光圈快门、欠曝拍摄，把高光余量留给后期 |
| **双增益 / 双原生 ISO** | 传感器有两条增益电路，通常在某一 ISO（如 400 与 2500）噪声骤降 → 在暗光下**跳过中间挡**直接跳到第二档增益更划算 |

### 4. 堆栈降噪

拍摄 N 张相同画面取平均：

- **随机噪声降低 √N**（4 张 → 噪声减半）
- 固定图案噪声也降低
- 前提：主体静止（或对齐后平均），所以适合风光、建筑、星空、静物
- 变体：**多帧合成夜景**（手机的主力武器）、**星空多帧叠加**

## 四、动态范围与位深

| 概念 | 定义 | 易混淆点 |
|---|---|---|
| **动态范围（DR）** | 满阱容量 / 读出噪声（可记录的最亮 : 最暗） | 标"14 档"多是工程测试值，实际可用低 1–2 档 |
| **位深（Bit depth）** | 每个像素可表示的级数（12bit=4096, 14bit=16384） | **位深 ≠ DR**：位深是编码精度，DR 是传感器能力 |
| **宽容度** | 后期能在多大范围内拉回亮度 | 高光宽容度远小于阴影宽容度（因为满阱有上限，暗部只是噪声大） |

**实用推论**：
- **阴影比高光好救**（暗部"只是脏"，高光是"真的没有"）。
- 需要大光比场景（室内外、日落、舞台）时，**包围曝光 + HDR 合成**比单张硬拉更干净。
- 拍 JPEG 相当于把 DR 压到 ~8–9 档，所以"过曝/欠曝"的容错远小于 RAW。

## 五、"不锐"的归因清单

按"从最常见到最罕见"排查：

| 序 | 原因 | 判据 | 修法 |
|---|---|---|---|
| 1 | **对焦错了** | 画面里某处（背景/前景）是锐的 | 检查对焦点位置、开眼控 |
| 2 | **手抖 / 主体动** | 整体方向性拖影 | 提快门、开防抖、上架 |
| 3 | **景深不足** | 只有一条窄带锐 | 收光圈或重新构图 |
| 4 | **衍射** | 全画面均匀发软，收光圈后变差 | 别超过 f/11（高像素机更早） |
| 5 | **镜头素质 / 大光圈边缘** | 中心锐、边角崩 | 收 2 档、换镜头 |
| 6 | **高 ISO 降噪涂抹** | 细节糊、有蜡感 | 关/降低降噪、拍 RAW |
| 7 | **机身锐化/JPEG 压缩** | 边缘有光晕、块状伪影 | 关锐化、用 RAW |
| 8 | **滤镜劣化** | 只有 UV/廉价滤镜时才软 | 摘掉滤镜对比 |
| 9 | **UV/保护镜 + 逆光** | 鬼影、对比下降 | 换好滤镜或摘掉 |
| 10 | **镜头/传感器脏** | 局部雾状、固定黑点 | 清洁 |
| 11 | **镜头跑焦/机身故障** | 特定距离系统性偏差 | AF 微调、送修 |
| 12 | **大气扰动** | 远景长焦抖动、水波纹样 | 无解，靠近拍 |

## 六、其它影响画质的因素

### 1. 摩尔纹与伪色

Bayer 采样对**高频规则纹理**（细条纹、格纹、屏幕像素）采样不足 → 出现彩色摩尔纹。
应对：换拍摄角度/距离、轻微失焦、后期去摩尔纹（代价是细节）、部分机型有 OLPF 或 Pixel Shift。

### 2. 坏点与热噪点

CMOS 个别像素失效（亮/暗点）→ 通常机内自动映射屏蔽；长曝出现的热点靠暗帧扣除。若新增明显，属于硬件问题。

### 3. 传感器清洁

换镜头时的灰尘落在传感器前方，表现为**小光圈下才清晰可见的黑点**（光圈越大越模糊）。

| 现象 | 判据 |
|---|---|
| 大光圈看不见、f/16 明显 | 传感器灰尘 |
| 任何光圈都固定在镜头上的位置 | 镜头内部灰尘（通常不影响成像） |

清洁方式：气吹（首选）→ 传感器刷 → 湿式清洁棒（谨慎）；**不要用嘴吹、不要用普通布擦**。

### 4. 快门震动与反光板震动

单反反光板抬起的震动会污染低速快门（约 1/8–1/125s 区间最明显）。

- **无反天然有优势**（无镜震）
- 解法：**电子前帘快门**、反光板预升、加配重、上三脚架 + 延迟拍摄

### 5. 像素位移（Pixel Shift）

传感器微动多次拍摄（如 1 像素或半像素位移），合成更高分辨率与更准色彩。

- 收益：真彩分辨率、无去马赛克伪色、动态范围略升
- 代价：必须静止场景 + 三脚架 + 合成处理

## 七、降噪与锐化的正确顺序

```
RAW 解码 → 降噪（先） → 细节/锐化（后） → 输出
```

理由与要点：

| 要点 | 说明 |
|---|---|
| **先降噪再锐化** | 锐化会放大噪点，顺序反了等于"先放大垃圾" |
| **亮度噪声与色度噪声分开处理** | 色度噪声可以粗暴抹（人眼不敏感），亮度噪声要保守（决定细节） |
| **AI 降噪的代价** | 效果强，但会**编造细节**——用于纪实/证据类照片要谨慎告知 |
| **锐化用蒙版限制** | 只锐化边缘/主体，避免把平坦区域（天空、皮肤）锐出噪点 |
| **输出尺寸决定锐化量** | 缩图后需要重新锐化（输出锐化），网上看图锐一点、印刷保守一点 |

## 八、常见坑

1. **把"高 ISO"当噪声原因**。噪声来自光少；ISO 只是放大。**该提就提。**
2. **以为"像素高 = 画质差"**。同尺寸输出看总光量；高像素的代价主要是衍射更早显现与处理负担。
3. **盲目收小光圈换"全清晰"**。超过 f/11 开始被衍射惩罚。
4. **对着高对比边缘对焦**却忘了那是背景 → 主体糊。要么用单点精确指定，要么开主体识别。
5. **人像对焦在鼻尖/下巴**。景深浅时，眼睛失焦 = 照片失败。
6. **用"放大到 400% 看噪点"评判可用性**。按输出尺寸（手机屏、A4 打印）看才是有意义的判据。
7. **降噪拉到最高求"干净"**。会把皮肤变塑料、细节变糊，一般"低档 + 局部"更好。
8. **长曝不关防抖、不做暗帧**。热噪点会显著增加。
9. **长期不清洁传感器**。小光圈风光照片会规律性出现黑点。
10. **忽略"对焦 + 快门 + 景深"三者的耦合**：浅景深人像用 1/30s 手持，就算对焦对了也可能糊。

## 九、现场决策套路

```
不锐：对焦 → 抖动 → 景深 → 衍射 → 镜头 → 降噪涂抹
暗光噪：先收光，再提 ISO；别欠曝硬拉
人像：焦平面在靠近相机的那只眼
后期：先降噪后锐化；按输出尺寸看，不要 400% 判死刑
```

上手练习：

1. **AF 归因实验**：同一场景，故意分别制造"对焦错、手抖、光圈太小"三种缺陷，对比观察。
2. **衍射阶梯**：f/2.8 → f/22 逐档拍同一静物，放大对比中心清晰度，找出你机身的"拐点"。
3. **ISO 不变性测试**：同场景拍"ISO 6400 正确曝光"与"ISO 800 欠曝 3 档后期提亮"，对比噪点。
4. **堆栈降噪**：同一星空/静物拍 1 张 vs 16 张平均，看 √N 的实际效果。
5. **灰尘检测**：f/16 对着白墙/天空拍一张 RAW，拉对比看灰尘位置。

判断见 [12](./12-自测与过线.md)。

**记忆线索**：噪声来自光子不够；不锐有十二条原因。下一章参数对了还不好看——开始管视线顺序。
