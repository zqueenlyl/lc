# 08. 构图

> 构图不是"把东西摆好看"，而是**控制观众的视线顺序**：先看什么、再看什么、最后视线停在哪里。
> 所有"规则"都是这个目标的经验解，不是必须遵守的律条。**判断构图好坏的唯一标准：主体是否被正确、有力量地传达。**

---

## 一、构图要解决的三件事

| 目标 | 具体问题 |
|---|---|
| **突出主体** | 观众第一眼看到的是我希望他看到的东西吗？ |
| **排除干扰** | 边缘有没有抢戏的元素（杂物、亮斑、多余的人）？ |
| **建立关系** | 主体与环境、主体与前景/背景的关系是否清楚？ |

**构图的第一步永远是"这是减法"**：先问"这张照片是关于什么的"，再把与它无关的东西移出取景框。

---

## 二、视觉重量：人眼先看什么

人眼在照片上扫视的顺序，由**对比度、大小、色彩、位置、人脸**共同决定：

| 权重因素 | 效果 |
|---|---|
| **人脸 / 眼睛** | 最高优先级，几乎总被先看到 |
| **高对比 / 亮部** | 亮处先于暗处被注意 |
| **饱和度 / 暖色** | 红橙黄比蓝绿更抢眼 |
| **大尺寸 / 主体占比** | 越大越先看到 |
| **清晰 vs 模糊** | 焦点在的区域被读作"主体" |
| **中心与孤立** | 单独的元素比成群的元素更突出 |
| **指向性** | 人物视线、线条指向、运动方向会引导视线 |

**推论**：如果你的主体不够突出，不要急着加东西——先**减掉**更亮的、更饱和的、更靠边的竞争元素。

---

## 三、经典构图法（以及它们真正解决的问题）

### 1. 三分法（Rule of Thirds）

把画面用两条横线两条竖线分成九宫格，把主体/关键线放在**交点或线上**。

| 解决的问题 | 说明 |
|---|---|
| 避免"主体死居中导致的静态与呆板" | 偏离中心增加了**张力**与**运动感** |
| 给主体留出"可呼吸/可运动"的空间 | 放在 1/3 处，另一边自然留下空间 |
| 让地平线不"劈开"画面 | 地平线压在 1/3 或 2/3 处 |

**什么时候该居中**（三分法不是铁律）：

- 对称构图（建筑、倒影、走廊）
- 正对镜头的肖像（压迫感、正面性）
- 极简/单点主体（中心 + 大量留白）
- 需要"直视"的力量（囚服的直视、安详的注视）

> 中心与三分的选择本质是"**稳定 vs 张力**"的取舍。不知道自己想表达什么时，先按三分；想表达"对峙/凝固/仪式感"时，大胆居中。

### 2. 引导线（Leading Lines）

用画面中的线条（道路、栏杆、河流、光影边界、视线）把观众视线**引向主体**。

- 最强的是**汇聚线**（指向消失点）
- 也可以是**隐性的**（排队的人、一排窗户）
- 反向使用：让线条把视线引出画面 → 传达"离开/远方/无望"

### 3. 框架式构图（Framing）

用前景元素（门洞、树枝、窗户、拱廊）在画面内部形成"画框"，把主体夹在中间。

作用：**强制聚焦 + 增加层次与纵深 + 交代环境**。
注意：框不要比主体更吸引人（尤其是高对比/亮的框）。

### 4. 对角线 / 动态构图

主线沿对角线放置 → 带来动势与不稳定感。适合运动、冲突、速度。

### 5. 重复与打破（Pattern & Break）

规则排列的重复元素很悦目；**打破重复的那一个**会成为视觉焦点。这是"秩序 + 意外"的经典配方。

### 6. 对称与反射

对称带来秩序、仪式、庄严。倒影（水面、玻璃、镜面）是对称的实用来源。
要点：**真正完美的对称往往需要轴线上有一个"不同"的元素**，否则容易呆。

### 7. 负空间（Negative Space）

大片"空"（天空、水面、墙面）包围一个小主体。

- 表达：孤独、安静、渺小、自由
- 前提：主体足够清晰、轮廓可读，否则观众找不到主体

### 8. 层次（Layering）：前景 / 中景 / 背景

在画面里安排三个深度层，是**让二维照片产生纵深**最有效的手段。

| 层 | 作用 |
|---|---|
| 前景 | 提供进入画面的"入口"、制造包围感、增加信息 |
| 中景 | 主体所在 |
| 背景 | 交代环境、提供背景图案或氛围 |

**实操**：到达现场先找"能站进去的前景"（树枝、石块、水面、门框），这是风景摄影进步最快的一步。

## 四、摄影构图特有的四个变量

与绘画不同，摄影是在三维世界里取景，所以还有四个"物理"变量：

### 1. 相机高度 / 机位

| 机位 | 心理效果 |
|---|---|
| 低机位（仰拍） | 主体高大、有压迫感、有英雄感；对小孩/宠物**平视**才亲切 |
| 平视 | 平等、纪实、自然 |
| 高机位（俯拍） | 主体渺小、弱势、展示布局；食物/桌面常用 |

**人像关键**：**拍小孩、宠物必须蹲下来到眼睛高度**。这一个动作的改善大于换镜头。

### 2. 拍摄距离 → 透视

距离决定"近大远小"的比例关系（见 [04-焦距与透视](./04-焦距与透视.md)）：

- 靠近 → 夸张前景、强调纵深
- 退远 → 压缩层次、规整

### 3. 画幅方向与比例

| 比例 | 观感 |
|---|---|
| 3:2 / 4:3 横 | 环境、叙事、风景 |
| 3:2 / 4:3 竖 | 人像、垂直结构、手机原生 |
| 1:1 方 | 稳、安静、社交平台友好、要求构图极简 |
| 16:9 / 21:9 | 电影感、风景、宽银幕叙事 |
| 竖长（9:16） | 手机、楼梯、塔、瀑布 |

**边缘与留白**：不要把主体逼到边缘，也不要在关节处切割（手腕、脚踝、脖子切一半最难看）。

### 4. 光线方向也是构图

光的落点是画面里最亮的区域，人眼先看那里。所以**光与构图是同一件事**：用光选择观众的注意力落点（见 [09-光线与用光](./09-光线与用光.md)）。

## 五、平衡与张力

| 概念 | 说明 |
|---|---|
| **平衡** | 画面各元素视觉重量之和大致均衡（不一定对称） |
| **张力** | 有意让重量不均 → 产生不安、期待、动感 |
| **重量补偿** | 一侧有重物，另一侧用留白/小元素/远处物体补偿 |

判断法：**眯眼看**（虚化细节只看明暗块面）、**镜像翻转看**（打破熟悉感，暴露偏重）、**缩略图看**（缩到指甲盖大小，构图问题会浮出来）。

## 六、人像构图的具体条目

| 项 | 要点 |
|---|---|
| **眼睛位置** | 通常放在上三分线附近；对焦必在眼睛 |
| **视线留白** | 人物看向方向要多留空间（"呼吸空间"）；看向镜头则不必 |
| **切点** | 不要切关节、不要切脖子、不要切头顶（留一点空间） |
| **半身/全身** | 大腿中部、膝盖下方、脚踝上方是可接受的分割点 |
| **背景** | 避免头顶"长树/长电线杆"、避免高对比杂物 |
| **明暗关系** | 主体应比背景亮或更饱和；暗背景亮主体最稳 |
| **比例** | 用长焦站远让脸部比例自然（见 04 章） |
| **引导** | 手、身体方向、道具都可以引导视线到脸 |

## 七、反例清单（看到就改）

1. 地平线**穿过人物头部/脖子**（本该上移或下移）
2. 地平线**轻微倾斜**（无意的歪，不是刻意的荷兰角）
3. 主体背后**高亮/高对比杂物**抢戏
4. 边缘有**半个人、半个垃圾桶、半个车灯**
5. 头顶**过窄**（发际线贴着画幅上沿）或**过宽**（大片空天）
6. 主体**贴在正中心且毫无理由**（缺乏张力的居中）
7. 画面**塞满**却没有明确主体（什么都想拍 = 什么都没拍）
8. 前景**虚得一塌糊涂**还占了 1/3 画面（除非它就是氛围）
9. 同一条线上并列两个同等重量的主体（观众不知道看谁）
10. 视角**没有选择的痕迹**（站着平视随手拍）

## 八、练习方法（比看教程有效）

| 练习 | 目的 |
|---|---|
| **一日一焦段**：今天只用 35mm，明天只用 85mm | 建立距离与视角的肌肉记忆 |
| **同一主体拍 10 种构图**：绕它走一圈、变高度、变远近 | 打破"第一直觉即最终答案" |
| **先定主体再按快门**：按前用一句话说出"这张是关于什么的" | 强制减法 |
| **找一个前景：每次风景照必须含一个前景** | 建立层次习惯 |
| **看大师画册的缩略图**：只看块面黑白灰 | 学构图的结构而非细节 |
| **裁切复盘**：拍完当天，把每张重新裁一次，看"原构图差在哪" | 快速建立眼力 |
| **限制拍摄**：只带一支定焦 + 每天只发 3 张 | 逼出取舍 |

## 九、与"好看"无关的一点提醒

构图是**服务表达**的手段。以下情况应该主动违背所有规则：

- 想表达混乱/压迫 → 就让画面拥挤、倾斜
- 想表达空旷/迷失 → 就让主体极小、偏远
- 想表达疏离 → 就让人物被遮挡、被边缘化

**规则是"为什么有效"的总结，不是"必须这样做"的规定**。理解原理，才有资格违反它。
