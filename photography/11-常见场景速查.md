# 11. 常见场景速查

> 场景不是另一套参数表，而是把 01–09 的旋钮**按现场目标排好优先级**。
> 每个场景只回答四件事：**先保什么、再牺牲什么、本套带哪支、按错会废在哪**。
> 文中数字都是**起点值**，以直方图和回放为准。本套落点见 [10 器材卡](./10-装备选型与练习清单.md#十我的器材卡sony-a7cr)。

## 一、点状星空（银河）

**目标**：星星是点不是线；银河结构可见；地面有可识别的前景。

和 [星轨](#一b星轨) 互斥：这里把地球自转当成误差压掉；星轨则把它写成弧。

### 现场顺序

1. 选暗点（远离城市光污染；新月前后更好）。银河夏季南天、冬季猎户座方向。
2. 16mm 找**前景**（石头、树、帐篷、建筑剪影），否则只有一张星空壁纸。
3. 脚架、关 IBIS / 镜头防抖、2s 延时或快门线。
4. 手动对焦：实时放大打在一颗亮星或远处灯光上，合焦后不要碰对焦环。
5. 先拍天空，地面不够亮就**另拍一张更长曝光**后期叠（不要用一张兼顾）。

### 参数起点（A7CR + 16/1.8）

| 项 | 起点 | 为什么 |
|---|---|---|
| 光圈 | **f/1.8**（可试 f/2 看边缘） | 星空是光子饥渴，优先进光 |
| 快门 | **8–12s** | 61MP 上 500 法则太松（`500/16≈31s` 会拉丝） |
| ISO | 1600–6400 | 先看直方图右一点；噪点后期堆栈比欠曝更干净 |
| 白平衡 | 3400–4000K 或后期再定 | RAW；现场只求能看清 |
| 对焦 | 手动无穷远（用星校准，不是镜头刻度） | AF 在黑夜会猎焦 |

**500 法则 vs NPF**：`t ≈ 500 / f` 是胶片经验。高像素用更严的 NPF 近似 `t ≈ (35N + 30p) / f`（`p` 为像素间距 µm）。A7CR `p≈3.8`、16mm f/1.8 → 大约 **11s**。起点就按 8–12s，放大看亮星有没有拖成短线。

多帧平均降噪：同一构图连拍 8–16 张对齐叠加，噪声按 `√N` 降（见 [07](./07-对焦与画质.md)）。单张 ISO 6400 往往不如 8 张 ISO 3200 干净。这是「对齐后取平均」，和星轨的「变亮叠加」不是同一种堆法。

### 坑

- 开着防抖拍长曝 → 星星微漂。
- 对焦在镜头的「∞」刻度上 → 多数现代镜无穷远过冲。
- 城市里硬拍银河 → 光污染把天背景抬成灰橙；城市更适合改拍 [星轨](#一b星轨) 或建筑剪影。
- 一张里既要地面细节又要银河 → 地面用 30s–2min 另拍，或对前景补很弱的手电光绘。

原理：[05](./05-快门与动感.md) 长曝 · [07](./07-对焦与画质.md) 堆栈 · [08](./08-构图.md) 前景层次

## 一B、星轨

**目标**：让地球自转把星星画成弧。弧要连续、够长，前景仍要能认。

地球约 **15°/小时**。16mm 全画幅视野很宽，**30–45 分钟**才像「有轨」，**1.5–2 小时**才像明信片那种圈。拍 10 分钟往往只是短划。

两种拍法里，数码优先走**短曝连拍再变亮叠加**，不要一张 20 分钟硬扛。

| | 短曝堆轨（推荐） | 单张超长曝 |
|---|---|---|
| 做法 | 间隔拍 N 张，后期 Lighten / StarStaX 叠成轨 | B 门一张 10–30min |
| 优点 | 热噪可控、飞机可剔、失败可丢单张 | 没有帧间隙 |
| 缺点 | 要后期；间隙大会断成虚线 | 热噪、高光易糊、A7CR 超 30s 必须 B 门；暗帧会让实际占用翻倍 |
| 本套 | A7CR 机内间隔拍摄 | 快门线 + B 门；先别作为默认 |

### 现场顺序

1. 构图先定**北极还是别的方向**（见下表），再放前景。脚架中轴落下，挂钩加重，关 IBIS。
2. 对焦与点状星空相同：放大打亮星，合焦后胶带或锁环。全程不要碰架子。
3. **关掉长时间降噪**（暗帧会在每两张之间插入等长黑帧 → 轨变成虚线）。
4. 试拍一张，看天光、前景灯有没有烧白。再开间隔拍摄。
5. 地面另拍一张更长曝光（或弱光绘），后期跟轨合成。不要指望堆轨那几百张里地面也干净。

### 朝向决定轨的形状

北半球：

| 相机朝向 | 画面 |
|---|---|
| **北，北极星在画里** | 同心圆；北极星几乎不动。北极星高度 ≈ 当地纬度（如 30°N 就在距地平约 30°） |
| 北，北极星在画外 | 大弧，仍绕看不见的圆心 |
| 东 / 西 | 斜向弧，有升有降 |
| 南 | 反向大弧，没有圆心 |

16mm 容易把北极星和前景一起装进画。50mm / 70–200 轨更「粗」、扫过的天区更窄，要更长时间才满幅。

### 参数起点（A7CR + 16/1.8 堆轨）

| 项 | 起点 | 为什么 |
|---|---|---|
| 光圈 | **f/2.8–f/4** | f/1.8 天光和彗差都会被叠进轨里；堆的是时间，不靠单张最亮 |
| 快门 | **20–30s** | 单张可以比 NPF 更长——本来就要短线；30s 是机身常规上限 |
| ISO | **400–1600** | 几十张变亮叠加后天空会抬亮；城市光污染收 ISO / 收光圈 |
| 间隔 | **1s 或最短** | 间隙 = 虚线。优先连拍间隔，不要每张回放 |
| 张数 | 先按 **总时长** 算：30s × 120 张 ≈ 1 小时 | 少于 40 张通常看起来像虚线短划 |
| 白平衡 | 固定 K，不要自动 | 否则每张色温跳，叠出来脏 |
| 格式 | 压缩 RAW；或 JPEG 只叠天 + 一张地面 RAW | 61MP × 120 张非常占卡和后期 |

16mm、画面中央附近：30s 单张大约划过十几个像素，所以叠起来能接上。赤纬越近天赤道，同样时间弧越长；北极星附近几乎不动。

城市也能拍星轨（亮星仍在），银河不行。灯把天空抬成橙底时：再收光圈或降 ISO，接受轨少、只要最亮的几颗。

### 后期叠法（和银河降噪不是一回事）

- **银河堆栈**：对齐后**平均**，降噪声、星仍是点。
- **星轨堆栈**：对齐后对亮部取 **Lighten / 最大值**（StarStaX、Sequator 的星轨模式），星的短线接成弧。
- 热像素在 Lighten 下会变成亮点或短刺：叠之前去热点，或拍几张盖上镜头的暗帧减掉。
- 飞机、卫星：单张里是直线划过，可在叠之前删那一张，或后期修。

### 坑

- 开着长时间降噪 → 轨断成虚线。
- 总时长只有 10 分钟 → 看起来像点状星空失败，不像星轨。
- 升中轴、风、有人碰脚架 → 整轨错位，后期难救。
- 用堆银河的「平均」去叠星轨 → 轨被稀释成淡影子。
- 满月、厚云、正对路灯 → 天一片白，轨没了。
- 电池只带一块：间隔一小时在冬天很容易拍到一半关机。USB 供电或备用 NP-FZ100。
- ZERO Y 是旅行架：1–2 小时可以，大风里压低、加重，不要指望它扛旗杆似的中轴。

原理：[05](./05-快门与动感.md) 长曝与暗帧 · [07](./07-对焦与画质.md) 热噪 vs 堆栈 · [08](./08-构图.md) 前景

## 二、城市建筑

**目标**：空间可走、竖线直立、材料质感清楚。好看来自几何，不是滤镜。

### 现场顺序

1. **先把相机端平**（EVF 电子水平仪）。仰拍会让建筑倒向中心——这是透视，后期拉直会裁掉大量画面、边缘拉伸。
2. 拍不全就**退后**或换 16mm，不要站在墙根仰着硬拍立面。
3. 室内大厅：16mm 贴墙边找对称轴；室外立面：24–70 正对；装饰/窗格：70–200 压缩成图案。
4. 光圈 **f/5.6–f/8**（61MP 衍射起点，见 [03](./03-光圈与景深.md)），不要 f/16。
5. 玻璃幕墙用 CPL 消反光；广角天空偏振不均，16mm 慎用 CPL。

### 参数起点

| 项 | 起点 |
|---|---|
| 光圈 | f/5.6–f/8 |
| 快门 | 手持按 `1/等效焦距` 再快 1/3 档（高像素） |
| ISO | 尽量 100–400；室内可升，保快门 |
| 畸变校正 | 开镜头校正；**透视倒向不要靠畸变滑块** |

两种「变形」必须分开（[04](./04-焦距与透视.md)）：桶形/枕形是光学，可校正；汇聚线是站位，只能改机位或拍更广再裁（等效移轴升起）。

### 构图

- 对称：走廊、穹顶、倒影——**该居中**（[08](./08-构图.md)）。
- 引导线：扶手、电梯、地砖指向消失点。
- 重复与打破：一排窗户里一个开着的、一个有人。
- 蓝调时刻内外灯都亮，是建筑「金窗」——见下一节夜景。

### 坑

- 广角贴人脸拍「建筑前人像」→ 鼻子夸张，人退后或换 50 以上。
- 地平线穿过楼体 1/2 且微倾 → 比构图差更先刺眼。
- 电子快门快速横摇 → 楼体会「倒」（果冻，[05](./05-快门与动感.md)），改机械快门。

本套：室内/广场 **16**；街道立面 **24–70**；窗格、塔尖、压缩层叠 **70–200**。脚架给长曝和精确水平。

## 三、人像

**目标**：眼睛最锐、脸部比例自然、光有方向。虚化是副作用，不是目的。

### 先定距离，再选镜头

| 你要的画面 | 站位 | 本套 |
|---|---|---|
| 环境人像（人 + 空间） | 可以靠近 | 24–70；交代空间用 16（半身不要贴脸） |
| 半身 / 肩上 | **退远** | 50/1.4 或 70–200 的 85–135 |
| 头像特写 | 更远 | 135–200；50mm 贴太近会变形 |
| 多人 | 中等距离 + 收光圈 | 24–70 @ f/2.8–f/4，对焦中间偏前的人 |

透视只由距离决定：85–135「脸好看」是因为你站远了。24mm 凑近拍半身，鼻子大是几何，不是镜头差。

### 光圈怎么收

| 情况 | 起点 |
|---|---|
| 单人、背景要糊 | 50/1.4 用 **f/2–f/2.8** 比全开稳（眼睛容错 + 像差） |
| 要光斑、确认合焦 | 可以 f/1.4，回放放大看眼 |
| 两人并排 | f/2.8–f/4 |
| 环境人像要认出地点 | f/2.8–f/5.6 |

同构图下虚化看入瞳：50/1.4（35.7mm）比 24–70 的 50mm f/2.8（17.9mm）大约 2 档；200/4 入瞳 50mm，糊得更大，但必须站远。

### 光线（按常见现场）

| 现场 | 做法 |
|---|---|
| 黄金时刻户外 | 侧逆光轮廓 + 脸向亮处或反光板；测光对人脸 **+0.7~+1.5 EV** |
| 正午 | 树荫、屋檐、建筑阴影；或背对太阳 + 反光/跳闪 |
| 阴天 | 天然大柔光，立体感弱，用环境暗背景把人「抠」出来 |
| 窗光 | 人离窗 0.5–1.5m，侧 45° 最通用；可加白墙作补光 |
| 室内闪光 | F46RMA **跳白天花板**；机械快门；同步 1/160s（全画幅） |
| 户外大光圈补光 | 开 HSS；欠曝就靠近人，不盲加功率 |

布光图案（窗或灯）：环形最通用，伦勃朗有戏剧，蝴蝶偏美妆。先只定主光，再谈补光。

### 对焦与快门

- 眼控开，焦平面在**靠近相机的那只眼**。
- 静坐 1/125s 起；讲话/小孩 1/250s+。防抖不管人晃。
- 电子快门**不能闪**。

### 构图速查

眼睛靠近上三分；视线方向留白；别切关节、别让头上「长」树和灯杆；主体比背景亮或更干净。

### 坑

- f/1.4 + 1/30s 手持 → 眼也对了也会糊。
- 机顶直射 → 扁平、红眼、背后黑影。
- 只顾虚化把耳朵、鼻子、第二只眼甩出景深。
- 16mm 环境人像拍成「广角证件照」（人贴边、头大身小）。

原理：[03](./03-光圈与景深.md) 入瞳 · [04](./04-焦距与透视.md) 距离 · [08](./08-构图.md) §6 · [09](./09-光线与用光.md) · [05](./05-快门与动感.md) 闪光同步

## 四、自然风光

**目标**：有进入画面的路径（前景），天地光比可控，全画面够锐但不过衍射。

### 现场顺序

1. 到达先找**能站进去的前景**（[08](./08-构图.md) 层次），再考虑要不要广角。
2. 广角讲气势与纵深（16mm 走近）；长焦做减法、压缩山峦层叠（70–200）——风景不要只用广角。
3. 光圈 **f/5.6–f/8**。要前后都清：广角走近，或对焦超焦距，或焦点堆栈；**不要 f/16**。
4. 16mm f/8、容许弥散圆 0.03mm 时，超焦距大约 **1.1m** → 对焦 1m 附近，从约 0.5m 到无穷远都可用。这比一路收光圈更锐。
5. 日出日落先保**高光**（天空直方图不贴右），地面暗用包围或后期提。GND 可选，RAW + 包围常够用。

### 参数起点

| 项 | 白天 | 黄金时刻 / 蓝调 |
|---|---|---|
| 光圈 | f/5.6–f/8 | 同左；暗了再开到 f/4 |
| ISO | 100 | 100–400，脚架优先于升 ISO |
| 快门 | 随光 | 脚架；关防抖 |
| 偏振 | 24–70 可用 | 16mm 天空容易一块深一块浅 |

天气：阴天是巨型柔光箱；雨后云缝出光柱；雪地是反光板。正午硬顶光改拍纹理、阴影图形，或等。

### 坑

- 地平线微倾、穿过画面正中还带着人的脖子。
- 大广角没有前景 → 「平」。
- ETTR 把太阳、水面闪位置烧白 → 高光不可恢复。
- 脚架上升中轴吹风 → 61MP 把微震放大。

本套分工：前景夸张、星空、室内峡谷感 → **16**；步道与通用 → **24–70**；山脊压缩、孤立树、月亮 → **70–200**。

原理：[03](./03-光圈与景深.md) 超焦距/衍射 · [04](./04-焦距与透视.md) · [09](./09-光线与用光.md) 时段 · [02](./02-曝光三要素与测光.md) 直方图

## 五、城市夜景与蓝调

**目标**：天空还有层次（不是死黑），灯火是点/线而不是一块白，冷暖可以并存但有主次。

### 蓝调窗口

日落后大约 **20–40 分钟**（纬度季节会变）：天空亮度和城市灯光接近，一张里两者都在。过了这段，天死黑，只剩灯。

| 项 | 起点 |
|---|---|
| 时机 | 蓝调；建筑室内灯已亮 |
| 器材 | 16 或 24–70 + ZERO Y，关防抖 |
| 光圈 | f/5.6–f/8（星芒可收到 f/8；再小衍射） |
| ISO | 100–400 |
| 快门 | 2–15s（车流轨迹）；手持就 1/等效焦距并升 ISO |
| 白平衡 | 4000–5000K 看灯；或保留钨丝暖、天蓝的分离 |

高光：路灯、招牌极易烧。点测最亮灯或看斑马纹，宁可整体偏暗后期提阴影。

人在画面里：要么 1/125s+ 冻住（升 ISO），要么 2s+ 让人走空/拉成残影。不要 1/8s 这种「人半糊」。

### 坑

- 天全黑才出门。
- 电子快门 + LED 广告屏 → 条带，改机械快门或 1/50–1/60s。
- 白平衡强行 5500K → 夜景脏黄；强行 3200K → 天灰。
- 16mm 把最近的路灯放进角里爆成一大块。

原理：[09](./09-光线与用光.md) 蓝调 · [06](./06-白平衡与色彩.md) 混合光 · [05](./05-快门与动感.md)

---

## 六、街头与纪实

**目标**：先拍到，再谈构图。决定性瞬间对焦段和画质的容忍度，高于风光。

### 策略

- 出门只带一支，减少选择：24–70 最稳，或只带 50 练距离。
- 光圈优先、ISO 自动设上限（如 6400）、**最低快门 1/250s**（行人）。
- 对焦区不要缩成一个点：区域/人识别，准备随时切眼控。
- 先靠近再拍，比「长焦偷拍一层层人」更有现场感；但距离仍决定透视。

### 参数起点

| 项 | 白天 | 夜晚街道 |
|---|---|---|
| 光圈 | f/4–f/5.6（景深容错） | 50/1.4 开到 f/1.8–f/2 |
| 快门 | ≥ 1/250s | 能 1/125s 就 1/125s，否则升 ISO |
| 曝光 | 点测人脸或 +补偿 | 对亮招牌容易欠曝人脸，+0.7~+1 |

构图靠减法：边缘半个人、垃圾桶、刺眼灯先裁掉。框架（门洞、车窗）比硬套三分有用。

### 坑

- 大三元一直挂着不拍，等「更好的焦段」。
- 电子快门扫过闪烁的灯箱。
- 晚上用 1/30s 拍走路的人，然后怪对焦。

原理：[05](./05-快门与动感.md) 安全快门 · [08](./08-构图.md) 减法 · [02](./02-曝光三要素与测光.md) 白加黑减

## 七、流水、云层与车轨

**目标**：用快门把时间写成形状——丝、雾、线。

| 对象 | 快门起点 | 备注 |
|---|---|---|
| 溪流纹理还在 | 1/8–1/2s | 太长会成白雾，看你要质感还是雾 |
| 瀑布如丝 | 0.5–2s | 脚架 |
| 海边雾化 | 5–30s | 白天必须 **ND** |
| 云流动 | 15s–2min | 看风速 |
| 车灯轨迹 | 8–20s | 蓝调最干净 |
| 星轨 | **短曝连拍再变亮叠加**，总时长 30min–2h；详见 [一B](#一b星轨) | 与点状银河互斥，不是把银河快门拖长 |

白天长曝：ND8 / ND64 / ND1000 的档位见 [05](./05-快门与动感.md)。没有 ND 就等更暗，不要用 ISO 50 硬扛（高光还是爆）。

流程：构图锁定 → 关防抖 → 盖接目镜/用 EVF 避免漏光（若有）→ 2s 延时 → 查高光警告（水面闪、车灯）。

本套：16mm 最常用；70–200 可拍远处一条瀑或公路。ZERO Y 中轴落下。

### 坑

- 长曝人像没让人静止。
- 中轴升满 + 风。
- 10s 车轨却从红灯停着的车拍起（轨迹变点）。

## 八、室内活动与家庭

**目标**：孩子/客人眼睛锐、肤色可接受、现场气氛还在。不要把客厅拍成廉价影棚。

### 优先顺序

1. 有窗：人靠近窗，50/1.4 或 24–70，ISO 自动，快门 **1/125s+**（小孩 1/250s）。
2. 窗不够：F46RMA **跳白天花板或白墙**，TTL 起步，补偿 −0.3~+0.7 看肤色。
3. 天花板是彩绘/很高/黑色：跳闪失效，灯头 45° 加卡片反光，或离机（下一阶段）。
4. 想保留钨丝氛围：慢速同步 1/15–1/30s + 闪光冻人；闪光贴 CTO 才能和 3200K 灯同色。

A7CR：**机械快门**；全画幅同步 1/160s；电子快门不闪。

| 项 | 窗光 | 跳闪 |
|---|---|---|
| 镜头 | 50/1.4 暗光；24–70 抓瞬间 | 同左 |
| 光圈 | f/1.8–f/2.8 | f/2.8–f/4（容错） |
| 快门 | 保人锐 | ≤ 1/160s；慢同步另论 |
| ISO | 能低则低 | 400–1600，让环境露一点 |

### 坑

- 直射闪光 + 背后墙 → 硬影。
- 混着节能灯、窗外日光、闪光三色，却把 WB 锁死日光。
- 客厅 16mm 贴着小孩拍头像。
- 合影对焦最近的人，后排全虚——收至 f/4，焦放中排。

原理：[09](./09-光线与用光.md) 跳闪/混合光 · [05](./05-快门与动感.md) 慢同步 · [06](./06-白平衡与色彩.md)

## 九、近摄与静物

**目标**：焦点在你指定的毫米上；背景干净；知道近摄会变暗、变浅。

70–200 若带 0.5× 近摄，先用 70–85mm 端练，不必单买微距。有效光圈 `N_eff = N(1+m)`：放大率 0.5 时，镜头 f/4 实际大约 f/6——衍射和曝光都按这个走。

| 项 | 起点 |
|---|---|
| 支撑 | 脚架或靠住；手持快门再快 1 档 |
| 光圈 | f/5.6–f/8（景深太浅就堆栈，不盲收 f/16） |
| 对焦 | 手动 + 放大；对焦环微动，不靠身体前倾 |
| 光 | 窗侧光看材质；或跳闪 + 白卡反光 |

静物构图：减法、一块干净衬底、光的方向即体积。食物/桌面常用略俯，但不要「纪录片航拍」那么顶。

原理：[03](./03-光圈与景深.md) 有效光圈 · [07](./07-对焦与画质.md)

## 十、一张表对照「废片通常废在哪」

| 场景 | 最常见废因 | 当场改一刀 |
|---|---|---|
| 星空（点） | 星星拉丝 / 没合焦 | 快门改 8s；放大对亮星 |
| 星轨 | 总时长太短、暗帧造成虚线 | 先拍满 1 小时；关掉长时间降噪 |
| 建筑 | 竖线倒、地平线斜 | 水平仪；退后或换 16，不要仰 |
| 人像 | 眼不锐、脸变形、直射闪 | 快门加快；退远；跳天花板 |
| 风光 | 平、高光爆、f/16 发灰 | 加前景；保天空；回到 f/8 |
| 夜景 | 错过蓝调、灯烧白 | 日落后立刻到场；看斑马纹 |
| 街头 | 人糊、犹豫 | 最低快门 1/250s；只带一支 |
| 长曝 | 微震、高光溢出 | 中轴落下、关防抖；减曝光 |
| 室内 | 直闪、三色光、小孩糊 | 跳闪；定一种色温；1/250s |
| 近摄 | 焦在前面空气上 | 放大取景；收一档或堆栈 |

参数可以下次再调。**站位、水平、焦点、高光**这四件，当场错了后期救不回来。
