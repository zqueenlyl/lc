# 09. 光线与用光

> 摄影的字面意思就是"用光作画"。器材决定你能不能拍到，**光决定照片好不好看**。
> 用光只有两个基本变量：**光源相对主体的尺寸**（决定软硬）和**光源方向**（决定立体感）。其余全是它们的组合。

一句人话：**软硬看光源表观大小，立体看方向；灯拉远只会变硬。**

---

## 一、硬光与软光：本质是"光源看起来有多大"

### 1. 物理判据

```
阴影边缘的过渡宽度 ≈ 光源的角尺寸（从主体看的张角）
```

- **光源相对主体"小"→ 硬光**：阴影边缘锐利、对比强、质感粗糙、高光尖锐
- **光源相对主体"大"→ 软光**：阴影边缘柔和、过渡平滑、色彩柔美

**关键**：软硬不取决于灯的功率、也不取决于"是不是柔光箱"，而取决于**光源相对于主体的表观大小**。

| 让光变软的方法 | 原因 |
|---|---|
| 加柔光箱 / 反光伞 | 增大发光面 |
| 把灯靠近主体 | 同一面积，距离近则张角大 |
| 用反光板/白墙反射 | 反射面成为新的（大）光源 |
| 等阴天 | 整片天空就是光源，天然巨型柔光箱 |
| 把主体靠近窗口 | 窗口相对主体变大 |

同一个 60×60 柔光箱：离人 0.5m 是很软的光，离人 5m 就是硬光（因为张角变小）。**这是新手最需要纠正的一条。**

### 2. 硬光 / 软光分别什么时候用

| 光质 | 适合 | 不适合 |
|---|---|---|
| 硬光 | 男性肖像、力量感、质感（金属、水面、皱纹）、戏剧性、时尚 | 皮肤瑕疵、婴儿、女性柔美、需要细腻的静物 |
| 软光 | 人像、美妆、静物、食物、婴儿、需要平和氛围 | 需要质感与立体冲击力的场景 |

## 二、光的方向：决定立体感

| 方向 | 效果 | 备注 |
|---|---|---|
| **顺光（正面光）** | 平、无阴影、颜色准、安全 | 最容易也最无聊；适合记录/证件 |
| **前侧光（45°）** | 立体感与细节平衡 | **人像最通用**的光位 |
| **侧光（90°）** | 强调质感与体积，明暗对比强 | 风景拍出纹理（沙丘、山脊） |
| **侧逆光 / 逆光** | 轮廓光、分离主体与背景、通透感 | 需处理测光与眩光 |
| **顶光（正午）** | 眼窝阴影、鼻子下重影、不好看 | 尽量避开或改用反射补光 |
| **底光** | 恐怖、诡异、非自然 | 有意的戏剧效果 |

### 逆光的处理

逆光是最有表现力也最容易失败的光：

| 问题 | 解法 |
|---|---|
| 主体欠曝（测光被天空骗） | **+1 ~ +2 EV**，或对人脸点测光，或补光 |
| 脸部死黑 | 反光板 / 闪光补光 / 后期阴影提亮（RAW） |
| 眩光、对比下降 | 遮光罩、调整角度让光源稍出画、擦净镜片 |
| 想保留轮廓光 + 面部细节 | 补光强度**低于**环境逆光 → 保留轮廓 |

**小技巧**：太阳刚好被主体边缘遮住（或刚出画一点点）时，轮廓光最漂亮、眩光最可控。

## 三、自然光：一天里的光

### 1. 时段速查

| 时段 | 光质 | 色温 | 适合 |
|---|---|---|---|
| 日出前 / 日落后（**蓝调时刻**，约 20–40 分钟） | 软、低照度 | 偏蓝（高 K） | 城市夜景、冷暖对撞、长曝 |
| 日出后 / 日落前 1 小时（**黄金时刻**） | 软、低角度、方向性强 | 2500–3500 K | 人像、风光、逆光轮廓 |
| 上午中段 / 下午中段 | 中等偏硬 | 5000–5500 K | 通用 |
| **正午** | 硬、顶光 | 5500 K | 最难；改拍室内、用遮阳/反光 |
| 阴天 | 极软、无方向 | 6500–7500 K | 人像、静物、色彩（但缺立体感） |
| 雨后 / 雪后 | 大气通透，瞬间光（Sunbreak） | 多变 | 风光大片的常见条件 |

**"坏天气出好照片"的物理原因**：阴天给出巨型柔光箱；暴雨后的云缝会打出局部光柱（god rays）；雪后地面是巨型反光板（**雪地逆光人像的天然补光**）。

### 2. 窗户光是最好用的光源

- 一扇朝北的窗户 = 免费的 2×2m 柔光箱（北半球朝北的窗光稳定、无直射阳光）
- 主体距离窗户 1m 与 3m，效果差异巨大（距离越近越软、衰减越快）
- 用白纱帘可进一步软化；用黑布遮一半可做出"条形光"（Split / Rembrandt 效果）

## 四、人造光入门

### 1. 两类灯

| 类型 | 特点 | 用途 |
|---|---|---|
| **闪光灯（Speedlight / 影棚灯）** | 瞬间高亮（1/1000–1/20000s），能凝固动作 | 人像、活动、压环境光 |
| **常亮灯（LED / 钨丝）** | 所见即所得，不闪，功率相对低 | 视频、静物、新手学习布光 |

**LED 灯的选购关键**：显色指数 **CRI**（≥95 较好）与 **TLCI**（视频用）；很多廉价 LED 在红色与肤色上严重失真，且**调光时会改变色温**。

### 2. 亮度与距离：平方反比定律

```
照度 I ∝ 1 / d²        d = 光源到主体的距离
```

**实际意义**：

| 距离 | 衰减 |
|---|---|
| 1m → 2m | 亮度降到 1/4 |
| 1m → 3m | 亮度降到 1/9 |

两个重要推论：
1. **距离越近，明暗过渡越剧烈**（主体前后 20cm 就有明显亮度差）→ 这就是"近距光源更有戏剧性"的原因。
2. **背景距离必须一起考虑**：主体 2m、背景 4m，则背景比主体暗 2 档（单灯环境下背景自然变暗）。

### 3. 塑光工具

| 工具 | 作用 |
|---|---|
| 柔光箱（方形/八角） | 大面积柔光；八角更接近圆形光斑（眼神光好看） |
| 反光伞（透射/反射） | 便宜的大柔光；反射伞控光差、溢光多 |
| 束光筒 / 蜂巢（Grid） | 限制照射角度，做"窄光束"与光斑 |
| 旗板（Flag） | 遮挡不需要的光，做负补光（加深阴影） |
| 反光板（银/白/金/黑） | 补光；银色强、白色柔、金色改色温、黑色**吸光**（加深阴影） |
| 束光器 / 鼻锥 | 小范围硬光，适合产品/背景光斑 |
| 冷光/Barn door | 限制光斑形状 |

### 4. 混合光源的处理

| 场景 | 方案 |
|---|---|
| 闪光灯（5500K）+ 室内钨丝（3200K） | 闪光贴 **CTO 滤片**降到 3200K，统一色温 |
| 闪光灯 + 日光 | 闪光贴 CTO 或把白平衡设为日光并靠闪光做主光 |
| 只想保留环境色的氛围 | 接受冷暖分离，但**保证肤色正确**（见 [06-白平衡与色彩](./06-白平衡与色彩.md)） |

**原则**：闪光灯加色片的目的是**让闪光与现场光同温**，这样可以用一个白平衡设置同时还原两者。

## 五、人像布光四种基本图案

以"光从哪来 + 鼻影往哪去"命名：

| 图案 | 布光位置 | 特征 | 气质 |
|---|---|---|---|
| **蝴蝶光（Paramount / Butterfly）** | 主体正前方偏上 | 鼻下蝴蝶形阴影、颧骨下方有阴影 | 经典美妆、女性、商业 |
| **伦勃朗光（Rembrandt）** | 45° 侧上方 | 阴影侧脸颊上有**三角形光斑**（鼻影与颧骨影相连） | 古典、有深度、男性/戏剧 |
| **环形光（Loop）** | 前侧方略高 | 鼻影呈小弧形，不与颧骨影相连 | **最通用**、最自然 |
| **侧光/夹光（Split / Edge）** | 正侧方 | 半边脸亮半边脸暗 | 强烈、戏剧、对立 |
| **轮廓光 / 发丝光** | 主体后侧 | 只照亮边缘，把主体"抠"出背景 | 常用作**第二/第三灯** |

**布光顺序**（很实用的工作流）：

1. **先定主光**（Key）——决定立体图案，只开这一盏反复调位置
2. **再加补光**（Fill）——降低阴影对比，通常功率远低于主光
3. **最后加轮廓/背景光**——分离主体与背景，解决"贴在背景上"的问题

**比（Ratio）**：主光:补光 = 4:1 是"有对比但看得清暗部"的常用值；2:1 柔和平；8:1 以上为高对比戏剧。

## 六、常见坑

1. **把灯拉得很远来"柔和"光**。越远越硬。想柔就**靠近 + 加大发光面**。
2. **正午硬光下直拍人像**。找阴影处（树荫、屋檐、建筑背阴面）或让模特背对太阳 + 反光板补光。
3. **逆光不补偿**。测光被天空骗，人脸死黑。记住 +1~2 EV。
4. **只用一个光源却期望背景亮**。单灯一定会让背景按距离衰减，需要额外打背景光或接受暗背景。
5. **LED 不看 CRI**。肤色会发灰发绿，后期很难救。
6. **补光过强盖掉主光**。阴影被填满 → 立体感消失、看起来像证件照。
7. **忽略周边反光**：白墙、白桌、浅色衣服都会变成天然反光板；黑背景/黑衣服会吸光。
8. **不控环境光就上闪光**。房间灯、窗户光都会参与曝光，导致色温与对比失控。
9. **认为"自然光就不用学用光"**。自然光只是"免费但不听话"的灯，你依然要选择时机、方向和遮挡。
10. **闪光灯直射**（机顶直闪）。扁平、硬、红眼、背后重影——要么跳闪（打天花板/墙），要么离机 + 柔光。

## 七、现场决策套路

```
光源看起来有多大？ → 软硬
从哪边来？ → 立体
先定主光，再补光，最后轮廓 / 背景
肤色优先于环境色；灯拉远不会变柔，只会变硬
```

上手练习：

1. **同一主体、同一光源，改变距离**（0.3m / 1m / 3m），观察软硬与衰减。
2. **绕主体走一圈**，每 45° 拍一张，找出你最喜欢的光位。这是最快建立"光感"的练习。
3. **窗口光四态**：脸正对窗 / 侧对窗 / 背对窗（+ 反光板）/ 远离窗，对比差异。
4. **一条黑布 + 一扇窗**：用黑布遮出"条形光"，尝试伦勃朗与侧光。
5. **找光练习（不拍照）**：走在街上，观察光落在哪、影子朝哪、什么时候最通透，判断"现在适合拍什么"。

判断见 [12](./12-自测与过线.md)。

**记忆线索**：软硬是张角，方向是立体。原理到此。下一章用器材和 8 周练习把旋钮变成肌肉记忆。
