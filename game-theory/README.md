# 博弈论学习教程（Game Theory）

> 博弈论研究**多个理性决策者之间相互影响时的策略选择**。核心问题：当我的最优选择取决于你会怎么做，而你的最优选择又取决于我会怎么做时，理性人最终会怎么做？系统会停在哪个结果上？

一句人话：**博弈论不是教你「赢」，而是教你「预测均衡」——在人人都会算的情况下，事情会朝哪里收敛。**

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| **参与者（Player）** | 做决策的人 / 组织 / 程序，≥ 2 个 |
| **策略（Strategy）** | 一套完整的行动规则，而非单个动作 |
| **收益（Payoff）** | 每种结果给参与者带来的效用，是「效用」不是「钱」 |
| **占优策略（Dominant Strategy）** | 不管别人怎么做，它都是最好 |
| **纳什均衡（Nash Equilibrium）** | 给定别人的选择，没人愿意单方面改变 |
| **混合策略（Mixed Strategy）** | 以概率随机化，而不是选定单一动作 |
| **子博弈完美均衡（SPNE）** | 每个子博弈都是纳什均衡，排除了不可信威胁 |
| **不完全信息（Incomplete Information）** | 参与者对别人的类型 / 收益没有完全了解 |
| **机制设计（Mechanism Design）** | 逆向工程：先定目标，再设计规则让自利者「自动」达成目标 |
| **贴现因子（Discount Factor）** | 未来的收益折现到今天值多少，决定长期合作是否划算 |

## 延伸阅读（当入口）

- 入门教材：Dixit & Nalebuff《策略思维》、Osborne《博弈论入门》
- 系统教材：Gibbons《博弈论基础》（经典研究生入门）、Fudenberg & Tirole《博弈论》
- 通俗经典：Schelling《冲突的战略》、Axelrod《合作的进化》
- 算法方向：Nisan 等《算法博弈论》（Algorithmic Game Theory）
