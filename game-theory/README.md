# 博弈论学习教程（Game Theory）

> 博弈论研究**多个理性决策者之间相互影响时的策略选择**。核心问题：当我的最优选择取决于你会怎么做，而你的最优选择又取决于我会怎么做时，理性人最终会怎么做？系统会停在哪个结果上？

一句人话：**博弈论不是教你「赢」，而是教你「预测均衡」——在人人都会算的情况下，事情会朝哪里收敛。**

本目录是系统笔记。六张经典矩阵的数字全书沿用；每章末有求解套路和指向下一章的记忆线索。手算与建模过线见 [10](./10-自测与建模清单.md)。

主线是**非合作、完全信息**，到 07 才揭类型，到 08 才反过来设计规则。合作 / 演化 / 谈判在 09。

## 核心概念速查

| 概念 | 一句话 |
|---|---|
| **参与者 / 策略 / 收益** | 谁、完整行动规则、效用（不是钱） |
| **占优策略** | 不管别人怎么做，它都是最好 |
| **零和 / 常和** | 一方所得 = 另一方所失（常和可平移成零和） |
| **博弈的值** | 两人零和里双方都能保证的收益，唯一 |
| **纳什均衡** | 给定别人的选择，没人愿意单方面改变 |
| **混合策略** | 以概率随机化；零和里是保底，非零和里常是协调失败 |
| **SPNE** | 每个子博弈都是纳什，排除不可信威胁 |
| **贴现因子 δ** | 未来 1 单位今天值多少；决定合作门槛 |
| **BNE** | 不完全信息下按类型给策略，对信念求期望最优 |
| **激励相容 IC** | 说真话是最优；不满足则机制收到谎言 |
| **个体理性 IR** | 参与不低于退出；不满足则没人进来 |
| **Shapley 值** | 按平均边际贡献分配；SHAP 同源 |

## 主线怎么串

```
写出矩阵/树 → 蛋糕固定吗？
  固定：极大极小，有值（03）
  会变：最佳反应交点 = 纳什（04）
有先后：倒推，砍不可信威胁（05）
会再见：δ 够大，合作可被惩罚撑住（06）
看不见类型：对信念求期望（07）
规则可改：让说真话成为占优（08）
```

## 延伸阅读

- 入门：Dixit & Nalebuff《策略思维》、Osborne《博弈论入门》
- 开山：von Neumann & Morgenstern《博弈论与经济行为》
- 系统：Gibbons《博弈论基础》→ Fudenberg & Tirole《博弈论》
- 通俗：Schelling《冲突的战略》、Axelrod《合作的进化》
- 算法：Nisan 等《算法博弈论》
