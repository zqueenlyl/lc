# 09. 应用与延伸：合作博弈、演化、谈判、与 AI

> 前八章是非合作主线：不能签死合同，各人自己选。这一章补四条支线——**联盟怎么分、策略怎么传、谈判谁让利、算法里博弈论干什么**——并收束全书。

---

## 一、合作博弈：有约束力的协议之后

非合作问「个体怎么选」；合作问「能创造多少、怎么分才没人掀桌」。

### 核（Core）

一种分配稳定，当且仅当没有任何子联盟能单干更好。核可能空（怎么分都有人不满），也可能是一整段区间。

### Shapley 值：手套博弈

按「对所有可能联盟的边际贡献的平均」来分。三人：左手套 L1、L2，右手套 R。联盟有价值 1 当且仅当左右手套配成对，否则 0。

六种排队，看谁加入时把 0 变成 1：

| 顺序 | 谁是关键 |
|---|---|
| L1, L2, R | R |
| L1, R, L2 | R |
| L2, L1, R | R |
| L2, R, L1 | R |
| R, L1, L2 | L1 |
| R, L2, L1 | L2 |

R 在 4/6 局是关键 → **2/3**；每个左手套 1/6。稀缺的那只手拿大头——和直觉一致，且由效率、对称、虚设、可加四条公理唯一确定。

机器学习里的 SHAP：把「特征」当成玩家，「预测值」当成联盟价值，算每个特征的平均边际贡献。

## 二、演化博弈：不靠算，靠传

策略是基因或惯例，收益高的在群体里扩张。

**复制者动态**：策略比例的增长率 ∝（该策略收益 − 群体平均）。

**ESS（演化稳定策略）**：群体都用它时，少量突变闯不进来。ESS 一定是纳什，纳什不一定是 ESS。

接 [02](./02-经典博弈.md) / [04](./04-纳什均衡.md) 的鹰鸽：全鸽会被鹰侵入（鹰对鸽拿 2 > 1）；全鹰会被鸽侵入（鸽对鹰拿 0 > −2）。复制者动态停在**各 1/3 出鹰**——正是混合纳什。纯鹰不是 ESS。动物「点到为止」不是道德，是纯鹰不稳定。

## 三、谈判：急的人让利

### Rubinstein 轮流出价

两人分 1 块蛋糕，轮流提案，对方接受或驳回；每拖一期乘 δ。双方贴现同为 δ 时，唯一 SPNE 是**先出价者拿 `1/(1+δ)`**。

- δ → 1（都很有耐心）：接近 50-50。
- δ = 0.9：先出价者约 52.6%。
- 谁更急（δ 更小），谁让利更多。BATNA（谈不成的退路）越好，相当于威胁点越高，分得越多。

### Nash 谈判解

公理化：在合作剩余上最大化 `(u − d)(v − d)`，d 是谈不成时的收益。威胁点、外部选项，再次决定蛋糕怎么切。

| 场景 | 看什么 |
|---|---|
| 薪资 | 谁更急、谁有更好 offer |
| 并购 | 拖延成本、Walk-away 价 |
| 贸易协定 | 关税报复的 δ 和可信度（接 05、06） |

## 四、算法博弈论与 AI

| 方向 | 角色 |
|---|---|
| 多智能体 | 用均衡预测 Agent 互相踩踏后会停在哪 |
| 拍卖 / 机制 | 广告、频谱、gas |
| 匹配市场 | Gale-Shapley 稳定婚配：一侧求婚、另一侧暂持更好的，得到稳定匹配（没有一对宁可互换） |
| 强化学习 | 自博弈（AlphaGo）本质是在近似零和均衡 |
| 可解释性 | SHAP |
| 安全 | 红蓝对抗按零和建模才合适；协作 Agent 不要硬套 |
| 数据定价 | IC / IR 决定人家肯不肯交出真数据 |

对做 Agent 的人：定价、发信号、承诺、让威胁可信，都会变成工程问题。前八章就是这些设计的数学模型。

## 六、怎么继续

1. 先做 [10-自测与建模清单](./10-自测与建模清单.md)，手算比再读一遍有用。
2. 拿一个真实场景写出矩阵，求均衡，再问「改哪条规则能改均衡」。
3. 教材：Gibbons《博弈论基础》→ Fudenberg & Tirole。零和源头：von Neumann & Morgenstern。
4. 算法：Nisan 等《算法博弈论》；多智能体强化学习。

**记忆线索**：非合作主线预测「会停在哪」；合作 / 机制设计问「停在哪更好、规则怎么改」。全书真正能带走的，是遇到场景时把四问写到纸上的那一下。
