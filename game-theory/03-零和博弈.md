# 03. 零和博弈：一方所得即另一方所失

> [02](./02-经典博弈.md) 的猜拳格子两两相加为零——这不是故事属性，是收益结构。博弈论从这种结构诞生。一句话：**蛋糕大小固定，你多一口我就少一口。** 两人有限零和有完整的解：博弈的「值」，以及双方都能保证拿到这个值的策略。

猜拳矩阵全书沿用 02。下面先用一个有鞍点的 2×2 把「值」算清楚，再回到无鞍点的混合。

---

## 一、定义：三种等价说法

对两人博弈，下面三句话是一回事：

| 说法 | 含义 |
|---|---|
| **零和（Zero-sum）** | 每个结果上 `u₁ + u₂ = 0` |
| **常和（Constant-sum）** | 每个结果上 `u₁ + u₂ = c`（平移一下就变成零和） |
| **严格竞争（Strictly competitive）** | 两人对所有结果的偏好完全相反：我更喜欢 A，你就更讨厌 A |

常和与零和**战略等价**：把每人收益同时加减同一个常数，最优策略不变。所以棋类、球赛、扑克筹码，「总量守恒」的都按零和来解。

表示法上，零和矩阵只写行参与者的收益即可——列参与者的收益自动取负。

```
        乙 左     乙 右
甲 上     3        1          ← 只写甲的收益；乙得到 -3 或 -1
甲 下     2       -4
```

---

## 二、和「非零和」差在哪

把 [02-经典博弈](./02-经典博弈.md) 的囚徒困境和石头剪刀布并排放：

```
囚徒困境（非零和）              石头剪刀布（零和）
坦白/坦白 = (-5,-5)            石/剪 = (1,-1)
沉默/沉默 = (-1,-1)            石/石 = (0, 0)

两人可以一起变好，也可以一起变差     一人赢几，另一人就输几
蛋糕大小会变                       蛋糕大小不变
```

**核心洞察：零和不等于「对抗」，非零和也不等于「合作」。** 零和是收益结构的属性——有没有合作空间，是定义决定的，不是态度决定的。囚徒困境里两人也在对抗，但他们可以一起少坐牢；石头剪刀布里哪怕想合作，也没有「双赢格子」可停。

现实里绝大多数场景是**非零和**：价格战两败俱伤、开源协作双赢、气候协议、职场晋升（看起来像零和，但把蛋糕做大往往比抢座位收益更高）。把非零和误当成零和，是策略上最常见的错——你会主动关掉双赢的格子。

---

## 三、纯策略：鞍点 = 博弈的值

行参与者想最大化自己的保底，列参与者想压低这个保底。两边各算一步：

- **极大极小（Maximin）**：每行先取最小值（最坏情况），再在这些最小值里取最大。这是行参与者能**保证**的收益。
- **极小极大（Minimax）**：每列先取最大值（行参与者最能占的便宜），再在这些最大值里取最小。这是列参与者能**压到**的上限。

当两者相等，交点叫**鞍点（Saddle Point）**，这个共同数字就是博弈的**值（Value）**。

上面那个矩阵：

```
        乙 左     乙 右     行最小
甲 上     3        1         1
甲 下     2       -4        -4
列最大    3        1
```

- 甲的 maximin = max(1, -4) = **1**（选「上」）
- 乙的 minimax = min(3, 1) = **1**（选「右」）
- 鞍点在（上, 右），值 = 1

甲选「上」至少拿 1；乙选「右」至多让甲拿 1。双方都锁死在 1 上，谁单方面改都不会更好——这已经是纳什均衡。

没有鞍点时（猜硬币、石头剪刀布），纯策略保证不了值，必须随机化。

---

## 四、von Neumann 定理：混合策略一定有值

> **von Neumann 极小极大定理（1928）**：任何**两人有限零和**博弈，都存在一个值 `v`，以及双方的（可能是混合的）策略，使得：
>
> 行参与者能保证至少 `v`，列参与者能保证至多 `v`。
>
> 即：`max_σ min_τ u(σ,τ) = min_τ max_σ u(σ,τ) = v`

这是博弈论的开山定理，比 Nash（1950）早 22 年。Nash 后来证明：一般有限博弈（含非零和）至少有一个均衡；**两人零和是它的特例，而且更强——均衡不仅存在，值还是唯一的。**

### 点球：一个不对称的混合例子

射门员要进球，守门员要扑出。进球率就是射门员的收益（常和：进球 +1 / 未进 0，只是缩放过）：

```
              守门员 扑左     守门员 扑右
射门员 射左      0.4            0.8
射门员 射右      0.9            0.3
```

没有鞍点：行最小是 0.4 和 0.3，maximin = 0.4；列最大是 0.9 和 0.8，minimax = 0.8。对不上，必须混合。

算法与 [04-纳什均衡](./04-纳什均衡.md) 的「令对手无差异」完全一样：

- 射门员以概率 `p` 射左，令守门员扑左、扑右效果相同：
  `0.4p + 0.9(1-p) = 0.8p + 0.3(1-p)` → **p = 0.6**
- 守门员以概率 `q` 扑左，令射门员射左、射右效果相同：
  `0.4q + 0.8(1-q) = 0.9q + 0.3(1-q)` → **q = 0.5**
- 博弈的值 **v = 0.6**：均衡下进球率是 60%。任一方偏离，都会被对方剥削。

石头剪刀布是对称情形：`v = 0`，各 1/3。猜硬币也是 `v = 0`，各 1/2。

## 五、和纳什均衡的关系：零和里三件事塌成一件

| | 两人零和 | 一般非零和 |
|---|---|---|
| 均衡的收益 | **唯一**（就是值 `v`） | 不同均衡可以有不同收益 |
| 均衡策略是否可互换 | **可互换**：你的最优策略配我的任一最优策略，仍是均衡 | 一般不可互换（性别战里各去各的就崩了） |
| 求解概念 | 极大极小 = 极小极大 = 纳什 | 只有纳什；「保底策略」未必是均衡 |
| 合作空间 | 没有。帕累托改进不存在 | 可能有双赢 / 双输 |

所以在零和里，你不需要猜测对手「善不善良」——假设他全力害你，就是正确的。在非零和里，这个假设是错的：对手害你的同时可能也害他自己，他未必这么做。

> **安全策略（Security Strategy）= 按最坏情况保底。** 零和里它等于纳什；非零和里它往往过于悲观。

## 六、求解套路

```
1. 确认是不是零和 / 常和（所有格子 u₁+u₂ 是否为同一常数）
2. 只保留行参与者的矩阵
3. 先剔除严格劣策略（行里被全面压过的删掉，列同理）
4. 算每行最小、每列最大
   └─ maximin = minimax  → 鞍点，纯策略解，值为 v
   └─ 对不上            → 混合策略：令对手无差异，值为 v
5. 检验：任一方单方面偏离，收益都不会更好
```

两人零和、策略不太多时，手算足够。策略一多（象棋、围棋），值仍然存在，但算不出——这就是为什么要搜索、剪枝、自博弈，而不是改用另一套均衡概念。

---

## 七、什么是零和，什么不是

| 是零和 / 常和 | 不是零和（常被误判） |
|---|---|
| 棋类、电竞对局、球赛胜负 | 价格战、广告军备、内卷加班（双输） |
| 扑克筹码（忽略娱乐价值） | 谈判、并购（存在合作剩余） |
| 点球、猜拳、对称对战游戏 | 开源、标准联盟、平台生态（可双赢） |
| 攻防演练的「攻下 / 守住」 | 职场晋升（把饼做大往往比抢坑值） |
| 对抗训练、红蓝对抗 | 气候、军控（合作能扩大蛋糕） |

**对 AI / 产品的意义**：多智能体里若目标函数真是「我的奖励 = −你的奖励」（自博弈下棋、GAN 的生成器 vs 判别器、红蓝攻防），按零和来建模，安全策略就是对的。若其实是共同把任务做完（协作 Agent、推荐系统 vs 用户长期留存），硬套零和会把能合作的关系做成对抗。

## 八、一张图总结

```
收益结构
  ├─ 零和 / 常和 ──► 蛋糕固定
  │     ├─ 有鞍点     → 纯策略，值 = maximin = minimax
  │     └─ 无鞍点     → 混合策略，von Neumann 保证仍有值
  │           两者都等于纳什均衡，且值唯一、策略可互换
  │
  └─ 非零和 ──► 蛋糕会变（双赢 / 双输都可能）
        必须用纳什；保底策略未必是均衡
        见 [02-经典博弈](./02-经典博弈.md) 的前五个模型
```

**记忆线索**：零和先问「蛋糕固定吗」；固定就按「保底 vs 封顶」对打，对得上是鞍点，对不上就随机到让对手无所谓。下一章会看到，纳什是把这套想法推广到蛋糕会变的世界——存在性还在，唯一性和可互换性就没了。
