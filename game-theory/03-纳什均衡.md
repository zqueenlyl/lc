# 03. 纳什均衡（Nash Equilibrium）

> 博弈论最重要的单一概念。一句话：**给定其他人的选择，没有人愿意单方面改变自己的策略**——这个状态就是纳什均衡。

---

## 一、先学两个更简单的解概念

在找到均衡之前，有两个更直观的「求解」步骤：

### 1. 占优策略（Dominant Strategy）

不管别人怎么选，这个策略都是你的最优选择。

```
          乙 坦白    乙 沉默
甲 坦白   (-5,-5)   (0,-10)
甲 沉默  (-10,0)    (-1,-1)
```

对甲：无论乙坦白还是沉默，坦白都比沉默好（-5 > -10，0 > -1）。「坦白」是甲的占优策略。

**如果双方都有占优策略，直接锁定结果**——这就是囚徒困境。

### 2. 重复剔除严格劣策略（Iterated Elimination of Strictly Dominated Strategies）

有些策略不是「永远最差」，但「不管怎样都劣于另一个策略」，就该被理性人剔除。

```
          乙 左      乙 中      乙 右
甲 上    (1,0)      (1,2)      (0,1)
甲 下    (0,3)      (0,1)      (2,0)
```

对乙来说，「中」严格优于「右」（2>1，1>0），所以乙不会选「右」，删掉右列；再看甲，删掉劣策略……反复剔除直到剩一个策略组合。

**局限**：占优和重复剔除在很多博弈里**找不到唯一答案**（比如性别战、猎鹿博弈），所以才需要纳什均衡这个更一般化的概念。

---

## 二、纳什均衡的定义

**纳什均衡**是一组策略组合，满足：

> 每个参与者在**给定其他人策略不变**的前提下，都没有动机单方面偏离。

形式化：策略组合 `s*` 是纳什均衡，当且仅当对每个参与者 `i`，`s_i*` 是对 `s_{-i}*` 的**最佳反应（Best Response）**。

### 怎么求：画最佳反应

```
          乙 看球    乙 看戏
甲 看球   (3,2)      (0,0)
甲 看戏   (0,0)      (2,3)
```

- 乙看球时，甲的最优是「看球」（3>0）；
- 乙看戏时，甲的最优是「看戏」（2>0）；
- 甲看球时，乙的最优是「看球」（2>0）；
- 甲看戏时，乙的最优是「看戏」（3>0）。

两个格子同时是双方最佳反应：（看球,看球）和（看戏,看戏）。**纳什均衡 = 所有人最佳反应的交点。**

---

## 三、纯策略 vs 混合策略

- **纯策略（Pure Strategy）**：确定地选一个动作。
- **混合策略（Mixed Strategy）**：以概率随机选多个动作。

石头剪刀布**没有纯策略纳什均衡**，因为任何固定手势都会被克制。它的均衡是混合的：双方都以 `(1/3, 1/3, 1/3)` 随机出。

### 混合策略怎么算

让对手「无所谓」——当对手在多个动作间无差异时，他才会随机，而这正是均衡条件。

例：猜硬币博弈（甲选正/反，乙猜正/反，猜中乙赢）。

```
        乙 猜正    乙 猜反
甲 正  (-1,1)     (1,-1)
甲 反  (1,-1)     (-1,1)
```

甲以概率 p 出正，乙以 q 猜正。均衡时双方都让对方「猜哪个都一样」：

- 甲令乙猜正、猜反收益相等 → p = 1/2；
- 乙令甲出正、出反收益相等 → q = 1/2。

**结论：最优是各 1/2 随机化。** 一旦你偏向某一边，对手就能利用这个偏差。

---

## 四、存在性：Nash 定理

> **Nash 定理（1950）**：任何**有限**博弈（参与者有限、策略有限）至少存在一个纳什均衡——**如果允许混合策略**。

这是纳什均衡最重要的理论保证：不一定有纯策略均衡，但混合策略均衡一定存在。John Nash 凭此获 1994 年诺贝尔经济学奖。

---

## 五、纳什均衡的问题

### 1. 多重均衡

性别战、猎鹿博弈都有多个均衡，理论无法告诉你「会落在哪个」。需要额外的聚焦点、历史、习惯来解释，见 [08-应用与延伸](./08-应用与延伸.md)。

### 2. 不一定是「最优」

囚徒困境的均衡是（坦白,坦白），但（沉默,沉默）对双方更好。**均衡 ≠ 最优，均衡只是「没人想改」的稳定点。** 帕累托最优（无法让某人更好而不让另一人更差）是另一把尺子。

### 3. 不排除不可信威胁

纳什均衡没有考虑「如果事情没按计划走会怎样」，因此可能包含「不可信的威胁」。这需要 [04-扩展式博弈与逆向归纳](./04-扩展式博弈与逆向归纳.md) 的「子博弈完美」来修正。

## 六、一张图总结

```
占优策略 ──► 严格占优，一定选它
    │
    ▼
重复剔除劣策略 ──► 逐步删「明显不该选」的
    │
    ▼
纳什均衡 ──► 最佳反应的交点；没人想单方面改
    │
    ├─ 纯策略均衡（确定动作）
    └─ 混合策略均衡（随机化，令对手无差异）
```

求解套路：先找占优 → 再剔除劣策略 → 算最佳反应交点 → 找不到纯策略就解混合策略。
