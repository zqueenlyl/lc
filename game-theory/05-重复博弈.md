# 05. 重复博弈（Repeated Games）

> 单次囚徒困境里，「背叛」是理性的。但**如果同样的博弈要玩很多次**，结果会完全不同——因为今天的背叛，明天会被报复。

---

## 一、为什么「重复」能改变一切

把同一个博弈（叫**阶段博弈 Stage Game**）重复进行，参与者能看到过去的行动历史，策略就能写成「如果对方上次背叛，我这次就……」。

囚徒困境单次均衡是（坦白,坦白）。但重复时，「你这次背叛，我下次就背叛」变成了一种**可执行的惩罚机制**，让「长期合作」成为可能。

**直觉：合作的收益是长期的，背叛的收益是一次性的；当未来足够重要，合作就划算。**

---

## 二、有限重复 vs 无限重复

### 1. 有限重复：逆向归纳的残酷结论

如果博弈**确定**重复 N 次：

- 最后第 N 次：没有「未来」可被惩罚，所以最后一次大家都会背叛（回到单次均衡）。
- 倒数第 N-1 次：既然第 N 次注定背叛，第 N-1 次的合作也不会改变第 N 次的结果 → 第 N-1 次也背叛。
- 一路倒推……**第一次就背叛**。

**结论：有限次重复囚徒困境的 SPNE 是「每次都背叛」。** 这就是「连锁店悖论（Chain-store Paradox）」的逻辑：只要终点确定，合作无法维持。

### 2. 无限重复（或不确定终点）：合作可以维持

如果博弈**无限次**，或**每轮后以一定概率继续**（不知道哪天结束），就没有「最后一步」可以倒推，合作就可能成立。

关键量是**贴现因子 δ（0 < δ < 1）**：未来 1 单位收益在今天值 δ。δ 越接近 1，表示「越看重未来」。

- δ 大（有耐心、关系长久）→ 合作容易维持；
- δ 小（急功近利、随时散伙）→ 合作崩坏。

---

## 三、两种经典策略

### 1. 冷酷触发（Grim Trigger）

「一直合作，直到对方背叛一次，然后**永远背叛**作为惩罚。」

- 惩罚最狠，威慑最强。
- 但一旦有人犯错（哪怕误会），关系不可逆地崩坏，没有回头路。

### 2. 一报还一报（Tit-for-Tat）

「第一轮合作；之后每一轮都复制对方上一轮的动作。」

- 对方合作 → 我合作；对方背叛 → 我背叛；对方重新合作 → 我也合作。
- 特点：**善良（先合作）、报复（被背叛就反击）、宽容（对方悔改就原谅）、简单（可被预测为合作者）**。

Axelrod 的著名计算机锦标赛里，**Tit-for-Tat 在多轮博弈中表现最好**，因为它能在合作环境里合作，在背叛环境里自卫，又不会陷入无尽的互相报复。

---

## 四、民间定理（Folk Theorem）

> 在无限重复博弈中，**只要参与者足够有耐心（δ 足够大），任何「不低于各自最小最大收益」的结果，都能被某个均衡支持**。

通俗讲：**重复博弈里，「合作」「半合作」「轮流占便宜」……几乎什么结果都可能成为均衡**，只要有合适的惩罚策略在后面撑着。

这带来一个麻烦：重复博弈的均衡**太多**，理论本身无法预测唯一结果。真正决定落点的，是聚焦点、惯例、规范——这也是文化和制度起作用的地方。

---

## 五、现实应用

| 场景 | 对应机制 |
|---|---|
| 企业长期竞争，避免价格战 | 触发策略：你敢降价我必跟，长期看大家都吃亏 |
| 国际关系里的「以牙还牙」 | 关税报复、军备对等回应 |
| 熟人社会 vs 一次性交易 | 熟人=重复博弈更守信用；陌生人=单次博弈易坑 |
| 平台与商家的信誉系统 | 用「历史记录 + 惩罚」人为制造「重复博弈」 |
| 品牌与老字号 | 品牌溢价 = 长期合作收益，让商家不敢坑 |

**一句话总结**：想让陌生人变诚实，就把它从「单次博弈」改造成「重复博弈」——增加接触频率、提高未来收益权重、让背叛可被记录和惩罚。
