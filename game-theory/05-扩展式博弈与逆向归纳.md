# 05. 扩展式博弈与逆向归纳（Extensive Form & Backward Induction）

> [04](./04-纳什均衡.md) 留下第三个缺口：纳什不检查「没走到的分支上，那个威胁还敢不敢兑现」。有先有后时，策略是整棵树上的规则，求解从叶子往回推——**逆向归纳**，得到的是**子博弈完美均衡（SPNE）**。

一句人话：**无法兑现的威胁，等于没有威胁。**

---

## 一、策略不再等于动作

静态博弈里策略 ≈ 动作。动态博弈里，策略是「在每个可能到达的节点上选什么」，包括**均衡路径走不到的那些节点**。

### 进入威慑（Entry Deterrence）

市场在位者面对潜在进入者：

```
            进入者
          /        \
      进入          不进入
        |            (0, 2)     # 进入者 0，在位者 2
       在位者
       /     \
   斗争     默许
  (-2,-1)   (1,1)
```

进入者的策略：{进入, 不进入}。
在位者的策略：{若被进入则斗争, 若被进入则默许}——哪怕进入者不进来，这套「若…则…」也要写出来。

---

## 二、逆向归纳

从树的最末端往回推：先问最后行动的人，再把它当作前面的人已经知道的事实。

1. 在位者面对进入：斗争 -1，默许 1 → 选**默许**。
2. 进入者预见到这一点：进入得 1，不进入得 0 → 选**进入**。
3. 结果：（进入, 默许），收益 (1, 1)。

**核心洞察：后动者的最优反应，是前动者做决策时的输入。** 先动优势来自「我知道你回头会怎么选」；若后动能看见并针对性克制，也可能是后动优势（猜拳里后出的人必赢——所以猜拳必须同时出）。

---

## 三、不可信威胁：纳什会放过，SPNE 不会

在位者可以事先喊「你敢进来我就打价格战」。写进策略就是：进入者**不进入**，在位者**若进入则斗争**。

这是纳什：给定「会斗争」，进入者最优是不进入（0 > -2）；给定「不进入」，在位者的承诺走不到，改成默许也不改变他自己的收益，所以「斗争」在纳什意义下也站得住。

但这不是 SPNE。真走进那个节点，斗争得 -1、默许得 1，理性人会默许。**威胁不可信。**

| | 要求 | 排除不可信威胁？ | 本例 |
|---|---|---|---|
| 纳什均衡 | 整局没人想单方面改 | 否 | （不进入, 斗争）也算 |
| **SPNE** | **每个子博弈**都是纳什 | 是 | 只剩（进入, 默许） |

子博弈：从某个节点出发、连同其后所有分支的完整小博弈。信息集不劈开时，每个节点都是一个子博弈的根。SPNE 用逆向归纳求，天然砍掉不可信威胁。

**博弈论金句：无法兑现的威胁等于没有威胁；无法兑现的承诺同样没有约束力。**

---

## 四、让威胁变得可信：改收益，不改口号

要让「我会斗争」可信，必须让真走到那一步时，斗争比默许更划算。常见手段：

- 签对赌 / 授权第三方自动执行（自己没得选）。
- 沉没成本：先把产能砸进去，打价格战的边际成本变低。
- 破釜沉舟：当众自断后路，不斗争的声誉损失大于 -1。

数字上，只要把「斗争」的收益从 -1 改到大于默许的 1，逆向归纳就会翻转，进入者选择不进入。**承诺的本质是限制自己的未来选项，换今天的谈判地位。**

---

## 五、信息集：看不见时，动态退回同时行动

完美信息：轮到你时，之前的动作全看得见（下棋）。
不完美信息：有些动作看不见。把「你分不清的节点」圈进同一个**信息集**。

```
        进入者               进入者
       /      \             /      \
     进        不          进        不
      |                    |
   在位者               ┌─信息集─┐      # 在位者看不见是否进入
   /    \               斗争    默许     # 这种画法才对应「同时行动」
```

信息集里只能选一个动作，不能「在左节点斗争、在右节点默许」。**信息集是连接动态与同时行动的桥梁**——[01](./01-基础概念.md) 那棵「看起来有先后、其实同时」的价格战树，缺的就是它。

---

## 六、承诺与信誉

逆向归纳逼出两件后文会反复用的事：

1. **承诺（Commitment）**：主动烧掉未来的选择，反而能赢。单次进入威慑里，在位者缺的就是这个。
2. **信誉（Reputation）**：单次里斗争不可信；若这是 [06-重复博弈](./06-重复博弈.md) 的一局，今天斗争是给明天看的广告，短期 -1 可能买得起长期的「不敢进」。有限次重复仍会被逆向归纳从最后一期拆掉——除非终点不确定，或对手不知道你的类型（[07](./07-贝叶斯博弈与不完全信息.md)）。

---

## 七、求解套路

```
1. 画树，标谁行动、收益、信息集
2. 写全策略：每个信息集都要指定动作，含均衡走不到的节点
3. 从最末端倒推：最后行动的人选最优
4. 把该选择当已知，往上一层推，直到根 → SPNE
5. 对照普通纳什：有没有「只在嘴上、真到那步不会做」的？划掉
6. 若你想改变均衡，改节点上的收益（承诺 / 合同 / 沉没成本），不要只改台词
```

**记忆线索**：纳什问「给定你这套规则，我还改吗」；SPNE 加问「没走到的那些节点上，你的规则自己还信吗」。下一章把同一棵树重复玩——惩罚变成可执行的，合作才可能从囚徒里长出来。
