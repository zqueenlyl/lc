# 01. 基础概念：博弈的三个要素与分类

> 先建立坐标系：一个博弈由**谁在玩、能怎么玩、结果值多少**三件事定义。几乎所有概念都长在这三个词上。

---

## 一、三个基本要素

| 要素 | 英文 | 含义 | 例子（企业价格战） |
|---|---|---|---|
| **参与者** | Player | 做决策的理性主体，≥ 2 个 | 公司 A、公司 B |
| **策略** | Strategy | 参与者可选的**完整行动规则** | 降价 / 维持原价 |
| **收益** | Payoff | 每种策略组合下，参与者得到的**效用** | 利润 |

三个关键约定：

1. **收益是「效用」不是「钱」**。同样 100 元，对富人和穷人的效用不同。博弈论假设参与者追求效用最大化。
2. **策略是「规则」不是「动作」**。静态博弈里策略 ≈ 动作，但动态博弈里策略要覆盖「每一步该怎么走」，这点到 [04-扩展式博弈](./04-扩展式博弈与逆向归纳.md) 会很重要。
3. **共同知识（Common Knowledge）**：不只是「我知道规则」，而是「我知道你知道规则，你也知道我知道你知道规则……」无限递归。很多结论依赖这个假设。

---

## 二、两种表示法

### 1. 标准式 / 策略式（Normal Form / Strategic Form）

用**矩阵**表示，适合同时行动（静态）的博弈。

```
              公司 B
            降价      维持
公司 A  降价 (3,3)    (8,0)
        维持 (0,8)    (5,5)
```

每个格子里 `(x, y)`：x 是行参与者的收益，y 是列参与者的收益。

### 2. 扩展式（Extensive Form）

用**博弈树**表示，适合有先后顺序的博弈。节点是「轮到谁行动」，树枝是「可选动作」，叶子是收益。

```
        A
      /   \
   降价   维持
    /       \
   B        B
  / \      / \
(3,3)(8,0)(0,8)(5,5)
```

标准式和扩展式可以互相转化，只是「同时 vs 先后」的信息结构不同。

## 三、博弈的分类（四个维度）

| 维度 | 分类 | 含义 |
|---|---|---|
| **合作性** | 合作博弈 / 非合作博弈 | 能否达成有约束力的协议（签合同 = 合作博弈） |
| **收益关系** | 零和 / 非零和 | 一方所得 = 另一方所失（零和）；或可以双赢/双输 |
| **信息** | 完全信息 / 不完全信息 | 是否知道所有人的收益、可选策略 |
| **行动顺序** | 静态 / 动态 | 同时行动（或互不知情）vs 有先后 |

再细分一个容易混的：

| 概念 | 含义 |
|---|---|
| **完美信息（Perfect Information）** | 轮到行动时，之前所有动作都看得到（如下棋） |
| **完全信息（Complete Information）** | 知道所有参与者的收益和策略（但不一定看到过程动作） |

记忆口诀：**「完全」说的是知道规则和收益，「完美」说的是看得见过程。** 完全信息 ≠ 完美信息。

## 四、理性假设

博弈论默认参与者是「理性的」，具体三层：

1. **工具理性**：追求自身效用最大化，不在乎别人。
2. **策略理性**：会预测别人的行动，再据此选自己的最优应对。
3. **知识理性**：知道别人也是理性的，且知道别人知道……（共同知识）。

> 这些是**模型假设**，不是现实描述。真实人类会犯错、会利他、会报复。行为博弈论（Behavioral Game Theory）专门研究这些偏离，见 [08-应用与延伸](./08-应用与延伸.md)。

## 五、怎么用这套坐标

遇到任何博弈场景，先问三句话：

1. **谁是参与者？** 人 / 公司 / 国家 / 程序 / Agent。
2. **他们各自能选什么？** 把动作和「完整策略」分清。
3. **收益是什么？** 别只算钱，算效用；别只看自己，看对手的收益矩阵。
