# 04. 扩展式博弈与逆向归纳（Extensive Form & Backward Induction）

> 静态博弈假设「同时行动」。但现实中很多决策有先后：先出招的人知道后出招的人会怎么反应。这时博弈要用树表示，求解靠**逆向归纳**。

---

## 一、从矩阵到树

静态博弈（上一章）里策略 ≈ 动作。**动态博弈里，「策略」是一套完整规则：在每个可能到达的节点上，我该选什么。** 这个区别很关键。

### 进入威慑（Entry Deterrence）经典例子

市场在位者（垄断企业）面对潜在进入者：

```
            进入者
          /        \
      进入          不进入
        |            (0, 2)     # 进入者 0，在位者 2
       在位者
       /     \
   斗争     默许
  (-2,-1)   (1,1)
```

- 进入者先选「进入 / 不进入」；
- 若进入，在位者选「斗争（打价格战）」或「默许」。

---

## 二、逆向归纳法（Backward Induction）

**从树的最末端往回推**：先想「最后行动的人会怎么选」，再据此倒推前面的人。

1. 在位者面对「进入」：斗争收益 -1，默许收益 1 → 选**默许**。
2. 进入者知道在位者会默许，于是比较：进入得 1，不进入得 0 → 选**进入**。
3. 均衡结果：（进入,默许）。

**核心：后动者的最优反应，是前动者做决策时的输入。**

---

## 三、不可信威胁（Incredible Threat）

在位者嘴上说「你敢进来我就打价格战」。但真进入后，斗争对自己是 -1，默许是 1——**理性人不会真的斗争**。

这个「打价格战」的威胁**不可信**，因为真走到那一步时，执行它不符合自身利益。

**博弈论金句：无法兑现的威胁，等于没有威胁。** 反过来，承诺也一样——无法兑现的承诺没有约束力。

要让威胁可信，得**改变收益结构**：签合同、公开承诺、投入沉没成本、让「不执行」反而更痛。

---

## 四、子博弈完美纳什均衡（SPNE）

普通纳什均衡在动态博弈里会「放过」不可信威胁——它只要求「给定别人策略，没人想改」，但没要求「在没走到的分支上」也理性。

**子博弈完美均衡（Subgame Perfect Nash Equilibrium, SPNE）**：不仅整个博弈是纳什均衡，**每一个子博弈**也都是纳什均衡。

- **子博弈**：从树中某个节点出发，连同其后所有分支构成的完整小博弈。
- SPNE 用**逆向归纳**求得，天然排除了不可信威胁。

对比：

| 概念 | 要求 | 排除不可信威胁？ |
|---|---|---|
| 纳什均衡（NE） | 整个博弈没人想单方面改 | 否 |
| 子博弈完美均衡（SPNE） | 每个子博弈都没人想改 | 是 |

回到进入威慑：SPNE 是（进入,默许），「进入者不进入 + 在位者若被进入则斗争」这组纳什均衡被排除了——因为那个「斗争」威胁不可信。

---

## 五、信息集与不完美信息

完美信息博弈：轮到行动时，你知道之前发生的**一切**（下棋）。

不完美信息博弈：有些动作你看不到。这时把「你无法区分的节点」画进同一个**信息集（Information Set）**。

```
        参与者A
        /    \
      L       R
      |       |
   ┌─信息集─┐   # B 不知道 A 选了 L 还是 R
    B        B
   / \      / \
  (x)(y)  (z)(w)
```

B 看不到 A 的选择，只能在信息集内做决策——这退回到类似「同时行动」的分析。**信息集是连接「动态」和「同时行动」的桥梁。**

---

## 六、承诺与信誉

逆向归纳揭示了两件事对动态博弈至关重要：

1. **承诺（Commitment）**：主动限制自己的未来选项，反而能获得优势。比如「破釜沉舟」——先自断后路，让「我会血战到底」变得可信。
2. **信誉（Reputation）**：单次博弈里「斗争」不可信，但如果这是一场 [05-重复博弈](./05-重复博弈.md) 的一步，为了长期信誉，短期的「斗争」就可能值得，威胁因此变得可信。

---

## 七、求解套路

```
1. 画博弈树，标出信息集（谁在什么时候知道什么）
2. 从最末端叶子开始，问「最后行动的人最优选什么」
3. 把这个选择当成已知，往上一层倒推
4. 一路推到根节点，得到 SPNE
5. 检查：有没有「只在嘴上说、真到那步不会做」的威胁？SPNE 会排除它
```
