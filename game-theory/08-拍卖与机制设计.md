# 08. 拍卖与机制设计（Auctions & Mechanism Design）

> 前七章是正向问题：给定规则，预测均衡。[07](./07-贝叶斯博弈与不完全信息.md) 里高质量会退出，因为规则没给「说真话」付报酬。**机制设计反过来：先定想要的结果，再设计规则，让自私的人自动按你想要的方式行动。**

一句人话：**不要管住人，要让说真话变成最划算的选择。**

---

## 一、正向 vs 逆向

- 正向（博弈论）：规则 → 人怎么做 → 结果是什么？
- 逆向（机制设计）：想要的结果 → 什么规则 → 让人自愿达成？

参与者会策略性隐藏类型。机制必须满足后文的 IC 和 IR，否则规则只是愿望。

---

## 二、四种标准拍卖

一件物品，N 个买家，私人估价 vᵢ（别人不知道）。

| 类型 | 规则 | 均衡出价直觉 |
|---|---|---|
| **英式（升价）** | 公开抬价，最后一人停下 | 出到自己的估价为止 |
| **荷式（降价）** | 从高往下降，第一个喊停 | 与一价密封同构 |
| **一价密封** | 密封出价，最高者付**自己的价** | **低报**（shade） |
| **二价密封（Vickrey）** | 密封出价，最高者付**第二高的价** | **报真实估价是占优策略** |

---

## 三、二价拍卖：为什么诚实是占优

你付的不是自己的出价 b，是别人的最高价 m。估价为 v。

- **m < v**：你应该赢。任何 b > m 都赢，付 m < v。诚实 b = v 能赢。若 b ≤ m，你输掉一笔该赚的交易。
- **m > v**：你应该输。任何 b < m 都输。诚实 b = v 能输。若 b > m，你赢了但付 m > v，亏。
- **m = v**：输赢无差异。

所以 **b = v 从不比别的差**。关键不是「二价比较公平」，是**你的出价只决定赢不赢，不决定付多少**——撒谎改变的是该不该赢的边界，不会让你占便宜。

一价密封没有这层隔离：出价既决定赢，又决定付款，所以均衡是低报。两人估价独立均匀 [0,1] 时，对称均衡是 **b = v/2**。

---

## 四、赢家诅咒

物品对所有人**真值相同**（油田储量、公司并购后的协同），但各人估值有噪声。赢家往往是最乐观的那个人——**「赢」本身是「你高估了」的证据**。

对策：把「我赢了 ⇒ 别人都比我估得低」折进出价，主动再压一档。私有估价拍卖没有这个问题；共同价值拍卖有。装修招标、并购、特许经营权，经常中招。

---

## 五、收益等价

> **Revenue Equivalence**：独立私有估价、风险中性、对称、最低类型期望收益为 0 时，英式 / 荷式 / 一价 / 二价给卖家的**期望收益相同**。

出价路径不同，期望结果一样。现实里一旦风险规避、估价不对称、有合谋或共同价值，等价破裂，选哪种拍卖才有实质差别。

---

## 六、两个硬约束

| 性质 | 含义 | 不满足 |
|---|---|---|
| **激励相容 IC** | 说真话是每个人的最优 | 机制收到的是谎言 |
| **个体理性 IR** | 参与 ≥ 不参与 | 没人进来 |

再加一个目标（效率 / 卖家收益），就是机制设计的基本模具。Myerson-Satterthwaite 还提醒：双边私下估价时，效率、IC、IR、预算平衡不能同时要——有些「好结果」不存在机制能实现。

---

## 七、VCG 与显示原理

**VCG（Vickrey-Clarke-Groves）**：二价拍卖推广到多物品。每个人付的价 = 他加进来之后给别人造成的外部性（没有他时别人的总价值 − 有他时别人的总价值）。

- 真实报价是占优（IC）；
- 分配有效率（给最能用的人）。

短板：卖家收益可能很低甚至为 0，计算和可解释性差。Google 广告实际多用广义二价 GSP——行为类似，但不是 VCG。

**显示原理**：任何机制能实现的结果，都有一个**直接讲真话机制**能实现同样结果。设计时不必遍历「先出价再加塞再抽签」的全部规则，只需在「问类型、保证说真话」的类里找最优。

---

## 八、应用

| 领域 | 机制 |
|---|---|
| 在线广告 | GSP / VCG 定价 |
| 频谱 | 政府把频段卖给运营商 |
| 共享经济 | 动态定价（把 IR 留给司机，把匹配效率留给算法） |
| 平台 | 保证金、评价、补贴——用规则改阶段博弈收益 |
| 区块链 | gas 费拍卖 |
| 数据 / 联邦学习 | 激励真实报质量和贡献 |

## 九、求解套路

```
1. 先问目标：效率（东西给最需要的人）还是卖家收益，还是别的
2. 写出类型空间（估价）和约束：IC、IR
3. 能用二价 / VCG 就先用——占优策略诚实，分析最干净
4. 一价、英式要解 BNE（低报、升到 v 停下）
5. 共同价值？先防赢家诅咒，再谈期望收益
6. 显示原理：找不到好规则时，回到「直接讲真话机制」里搜
```

**记忆线索**：博弈论是「规则已知，求均衡」；机制设计是「均衡目标已知，求规则」。说真话能成为占优，是因为付钱的那一截不由你的嘴决定。下一章离开非合作主线，看联盟怎么分、策略怎么演化、谈判里谁在让利。
