# 07. 贝叶斯博弈与不完全信息（Bayesian Games & Incomplete Information）

> 重复博弈让惩罚可执行，前提是你知道对方在乎什么。[05](./05-扩展式博弈与逆向归纳.md) 的进入威慑里，在位者会不会真打价格战，取决于他的成本。**成本是私有信息时，进入者只能拿信念当输入。**

一句人话：**不知道你的底牌，我就对你的类型下概率，再最大化期望收益。**

---

## 一、不完全信息 ≠ 不完美信息

| 概念 | 问题 | 例子 |
|---|---|---|
| **不完全信息** | 不知道对手的**收益 / 类型** | 不知道成本高低、是不是骗子 |
| **不完美信息** | 不知道对手的**动作过程** | 不知道对方已经下了哪步棋 |

扑克两样都缺：牌是类型（不完全），出没出某张是动作（不完美）。Harsanyi（1967-68）把不完全信息改造成：自然先发类型，大家对分布有共同先验——于是叫**贝叶斯博弈**。

---

## 二、类型、信念、自然

| 概念 | 含义 |
|---|---|
| **类型（Type）** | 私有信息：高/低成本、强硬/软弱、好车/柠檬 |
| **信念（Belief）** | 对别人类型的概率，如「60% 是强硬型」 |
| **自然（Nature）** | 虚构的发牌者，先随机抽类型 |

策略变成映射：**每个自己的类型 → 一个动作**（或混合）。你知道自己的类型，按对别人类型的信念算期望。

---

## 三、贝叶斯纳什均衡：进入威慑加类型

沿用 [05](./05-扩展式博弈与逆向归纳.md) 的树，只让在位者分成两种类型。进入者仍是先行动，不知道类型。

| 在位者类型 | 先验 | 面对进入时的收益 | 理性选择 |
|---|---|---|---|
| **强硬** | p | 斗争 2，默许 1 | 斗争 |
| **软弱** | 1−p | 斗争 −1，默许 1 | 默许 |

进入者：不进入得 0；进入后若碰上强硬得 −2，碰上软弱得 1。

```
EU(进入) = p · (−2) + (1−p) · 1 = 1 − 3p
```

进入当且仅当 `1 − 3p ≥ 0`，即 **p ≤ 1/3**。

- p = 1/2：EU(进入) = −0.5 < 0 → 不进入。强硬类型即使从未行动，单靠信念就吓退了对方。
- p = 1/5：EU(进入) = 0.4 > 0 → 进入；事后强硬斗争、软弱默许。

这就是 **BNE**：给定信念，每个类型（强硬/软弱/进入者）都不想单方面改。p 是共同先验；若进入者能从别的市场看到过往斗争，信念会被更新——那是信号博弈。

---

## 四、信号博弈：行动本身在说话

```
自然抽类型 → 知情者发信号 → 接收者看见信号、更新信念 → 行动
```

信号可信，当且仅当**不同类型发同一个信号的成本不同**，贵的那种模仿不起。

| 均衡 | 含义 |
|---|---|
| **分离（Separating）** | 不同类型发不同信号，接收者看信号就知道类型 |
| **混同（Pooling）** | 不同类型发同一信号，接收者无法区分，只能按先验 |

例子：学历（Spence）——高能力拿学位成本低，低能力模仿太贵，于是学历能分离；若人人都能廉价买证，学历退化成混同，信号失效。大额广告、质保、创始人自投，逻辑相同：烧得起才可信。

## 五、柠檬市场：数字把市场塌掉

二手车。好车卖家底价 8000，买家最多 10000；次品卖家 2000，买家 2500。各一半，买家看不到类型。

1. 买家按平均质量出价：期望价值 (10000+2500)/2 = 6250。
2. 好车卖家 8000 > 6250，退出。
3. 场上只剩次品，买家最多出 2500。次品仍可能成交（2500 > 2000），**好车市场消失**。

**核心洞察：信息不对称会让高质量退出，平均质量下降，出价再降——逆向选择。** 对策是让类型可被分离：质保、品牌、第三方检测，或直接上 [08](./08-拍卖与机制设计.md)，用规则逼人说真话。

## 六、应用

| 场景 | 谁的类型被藏着 | 常见对策 |
|---|---|---|
| 招聘 | 能力 | 作品集、试用、学历（信号） |
| 融资 | 项目质量 | 自投、分期拨款、对赌 |
| 谈判 | 底线 / 耐心 | 让步节奏是信号，也是廉价谈（要防混同） |
| 平台风控 | 商家质量 | 保证金、评分、抽检 |
| 多智能体 | 私有观测 / 奖励 | 通信协议、可验证承诺 |

## 七、求解套路

```
1. 列出类型空间、先验、每个类型的收益
2. 策略 = 类型 → 动作；对别人的类型求期望
3. 每个类型都选最优 → BNE
4. 若知情者先行动：检查分离还是混同；关键是模仿成本
5. 市场类问题：先算「按平均出价」，再看高质量会不会退出
```

```
不完全信息 → 类型 + 信念 → BNE（按类型给策略）
                 │
     ┌───────────┴───────────┐
     ▼                       ▼
信号（用成本差异揭示类型）   机制设计（用规则逼出真实类型，见 08）
```

**记忆线索**：完全信息问「你会怎么做」；不完全信息问「你是哪种人，我会怎么赌」。下一章反过来：先定想要的结果，再设计让自利者「自动」说真话的规则。
