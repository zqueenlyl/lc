# 04. 纳什均衡（Nash Equilibrium）

> 上一章零和里，极大极小、极小极大、纳什三件事塌成一件，还带一个唯一的值。蛋糕会变之后，**只剩「没人想单方面改」还成立**——这个更瘦的概念，就是纳什均衡。

一句人话：**给定别人不动，我也不想动。** 系统停在这里，不是因为它最好，而是因为没有人愿意自己先迈出一步。

---

## 一、为什么不能继续用「保底」

[03-零和博弈](./03-零和博弈.md) 的安全策略是：按最坏情况选，保证一个保底。零和里对手真的在全力害你，这就是对的。

非零和里对手害你往往也害他自己，他未必这么做。鹰鸽博弈：

```
          乙 鹰        乙 鸽
甲 鹰    (-2,-2)      (2,0)
甲 鸽     (0,2)       (1,1)
```

- 甲的安全策略是**鸽**：行最小是 -2 和 0，maximin = 0。
- 如果双方都按安全策略来，（鸽,鸽）= (1,1)。
- 但这**不是纳什**：对方出鸽时，自己改成鹰能拿到 2。

**核心洞察：非零和里「保底」过于悲观，两边一起悲观时，每个人都想偷偷变硬。** 所以求解概念必须换成「互相是最佳反应」，而不是「单独防最坏」。

---

## 二、两个更简单的前置步骤

均衡不好找时，先用这两刀把矩阵砍小。

### 1. 占优策略（Dominant Strategy）

不管别人怎么选，它都是你的最优。

```
          乙 坦白    乙 沉默
甲 坦白   (-5,-5)   (0,-10)
甲 沉默  (-10,0)    (-1,-1)
```

对甲：坦白永远更好（-5 > -10，0 > -1）。双方都有占优策略，直接锁定（坦白,坦白）——这就是囚徒困境。

占优策略均衡一定是纳什；反过来不成立。性别战、猎鹿、鹰鸽都没有占优策略。

### 2. 重复剔除严格劣策略（IESDS）

某个策略在**所有**情况下都差于另一个，理性人不会选它，删掉再继续。

```
          乙 左      乙 中      乙 右
甲 上    (1,0)      (1,2)      (0,1)
甲 下    (0,3)      (0,1)      (2,0)
```

- 乙：中严格优于右（2>1，1>0）→ 删右列。
- 甲：上严格优于下（1>0，1>0）→ 删下行。
- 乙：中优于左（2>0）→ 剩下（上,中）= (1,2)。

只用**严格**劣（处处 ≤ 且至少一处 <）。弱劣策略的剔除可能把某些纳什删掉，所以这刀要保守。

**局限**：性别战、猎鹿删不干净。砍完还剩多个格子时，必须上纳什。

---

## 三、定义：最佳反应的交点

策略组合 `s*` 是纳什均衡，当且仅当对每个参与者 `i`：

> `s_i*` 是对其他人策略 `s_{-i}*` 的**最佳反应（Best Response）**。

没有人能靠自己改策略而变好。注意：是「给定别人不动」，不是「一起改会更好」——所以囚徒可以停在双输。

### 怎么求：逐格标最佳反应

性别战：

```
          乙 看球    乙 看戏
甲 看球   (3,2)      (0,0)
甲 看戏   (0,0)      (2,3)
```

- 乙看球 → 甲最优看球（3>0）；乙看戏 → 甲最优看戏（2>0）。
- 甲看球 → 乙最优看球（2>0）；甲看戏 → 乙最优看戏（3>0）。

两个交点：（看球,看球）、（看戏,看戏）。**纳什 = 所有人最佳反应同时成立的格子。**

回到鹰鸽：交点是（鹰,鸽）和（鸽,鹰）。（鸽,鸽）不是——已见第一节；（鹰,鹰）更不是，双方都想改成鸽。

## 四、六个模型的均衡落在哪

把 [02-经典博弈](./02-经典博弈.md) 用「最佳反应交点」重新看一遍：

| 模型 | 纯策略纳什 | 是不是「最好」 | 备注 |
|---|---|---|---|
| 囚徒困境 | （坦白,坦白）唯一 | 否，双沉默帕累托更优 | 有占优策略 |
| 智猪博弈 | （大猪按, 小猪等） | 对小猪很舒服 | 弱者搭便车 |
| 猎鹿博弈 | （鹿,鹿）、（兔,兔） | （鹿,鹿）更好但不稳 | 风险主导 vs 收益主导 |
| 性别战 | （球,球）、（戏,戏） | 两个都帕累托最优，但偏袒不同人 | 不可互换：各去各的就崩 |
| 鹰鸽博弈 | （鹰,鸽）、（鸽,鹰） | 有人硬有人软 | （鸽,鸽）更好但不是均衡 |
| 石头剪刀布 | 无 | — | 只有混合，见 [03](./03-零和博弈.md) |

零和里这些格子的收益必须相同（值唯一）且策略可互换。非零和里**不同均衡可以有不同赢家**，把你的均衡策略配到我的另一个均衡上，常常不是均衡——性别战就是。

## 五、混合策略：令对手无差异

- **纯策略**：确定地选一个动作。
- **混合策略**：以概率随机选。

零和的算法上一章已经算过（点球、猜硬币、猜拳）：令对手无差异，得到的就是值 `v`。非零和用**同一套方程**，但结果的含义变了。

性别战：甲以 `p` 看球，乙以 `q` 看球。均衡时双方在两个纯策略间无差异：

- 令甲无差异：`3q = 2(1-q)` → **q = 2/5**
- 令乙无差异：`2p = 3(1-p)` → **p = 3/5**

双方期望收益都是 `6/5 = 1.2`，低于两个纯策略均衡（3 或 2，哪怕落到自己比较不喜欢的那个）。他们有 `13/25` 的概率走散（一方看球、一方看戏）。

**核心洞察：非零和的混合均衡经常是「协调失败」的数学描述，不是你能保证的值。** 零和里随机化是为了不被剥削；这里随机化是因为两人都想去自己更喜欢的那个点，又怕对方不去。

鹰鸽的混合：双方各以 1/3 出鹰，期望收益 2/3，低于（鸽,鸽）的 1——但（鸽,鸽）站不住。演化稳定会停在这个混合比例附近，见 [09-应用与延伸](./09-应用与延伸.md)。

## 六、存在性：Nash 定理

> **von Neumann（1928）**：两人有限**零和** → 一定有值，极大极小 = 极小极大。
>
> **Nash 定理（1950）**：任何有限博弈（人数有限、策略有限，**含非零和、含 n 人**）→ 至少有一个纳什均衡（允许混合）。

Nash 是 von Neumann 的真推广：存在性还在，唯一性和可互换性不再保证。有限是关键条件——策略连续时另当别论，但日常矩阵博弈够用。John Nash 凭此获 1994 年诺贝尔经济学奖。

---

## 七、纳什均衡的三个缺口

### 1. 多重均衡：理论不告诉你落在哪

猎鹿、性别战、鹰鸽都有多个。需要聚焦点、习惯、谁先表态、历史。纯数学到这里停了。

### 2. 均衡 ≠ 最优

囚徒的纳什是双输；（沉默,沉默）帕累托更优（没法让一人更好而不让另一人更差），但不是均衡。**稳定和效率是两把尺子。**

### 3. 不排除不可信威胁

纳什只看策略组合本身，不问「如果事情没按计划走，这个威胁还敢兑现吗」。这要 [05-扩展式博弈与逆向归纳](./05-扩展式博弈与逆向归纳.md) 的子博弈完美来修。

## 八、求解套路

```
1. 先看是不是零和 / 常和
   └─ 是 → 走 [03](./03-零和博弈.md)：鞍点或混合，得到唯一的值
   └─ 否 → 继续下面
2. 找占优策略；有则锁定
3. 重复剔除严格劣策略，把矩阵砍小
4. 对剩下的格子标最佳反应，交点 = 纯策略纳什
5. 没有纯策略（或还想找全部均衡）→ 混合：令对手无差异
6. 有多个均衡时，停下来问：聚焦点是什么？谁先动？
```

```
占优策略 ──► 严格占优，一定选它
    │
    ▼
重复剔除劣策略 ──► 逐步删「明显不该选」的
    │
    ▼
纳什均衡 ──► 最佳反应的交点；没人想单方面改
    │
    ├─ 纯策略均衡（确定动作）
    └─ 混合策略均衡（随机化，令对手无差异）
         │
         ├─ 零和：随机化 = 保底，值唯一
         └─ 非零和：随机化常是协调失败，收益可低于纯策略均衡
```

**记忆线索**：零和问「我能保证多少」；纳什问「给定你不动，我还想动吗」。前者是后者在蛋糕固定时的特例。下一章把「同时行动」改成「有先有后」——不动的假设本身会裂开，威胁必须可信才算数。
