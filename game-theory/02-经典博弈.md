# 02. 经典博弈：六个模型，六类困境

> 上一章的四问落到纸上，几乎总会变成下面六张矩阵之一。看懂它们，就是在练「识别困境」，不是背故事。

六个模型的收益数字**全书沿用**。后面算混合策略、贴现门槛、演化稳定，都用这里的矩阵。

---

## 一、囚徒困境（Prisoner's Dilemma）—— 社会困境

两个嫌犯被分开审讯，都面临「坦白 / 沉默」：

```
          乙 坦白    乙 沉默
甲 坦白   (-5,-5)   (0,-10)
甲 沉默  (-10,0)    (-1,-1)
```

- **占优策略是坦白**：不管对方怎么选，坦白都更好（-5 > -10；0 > -1）。
- 结果（坦白,坦白）= (-5,-5)，比都沉默的 (-1,-1) **更差**。
- 这是**非零和**：两人可以一起少坐牢，蛋糕会变。不要和下一章的零和搞混。

**核心洞察：个体理性导致集体非理性。** 每个人都做最优选择，系统停在次优解。

现实映射：军备竞赛、广告军备、价格战、公地悲剧、内卷加班、环保搭便车。

> 走出困境靠**改收益结构**：重复博弈（[06](./06-重复博弈.md)）、第三方惩罚、制度设计（[08](./08-拍卖与机制设计.md)）。规则不改，劝善没用。

---

## 二、智猪博弈（Boxed Pigs）—— 搭便车

猪圈里一大一小两只猪，按按钮出食，按按钮有成本：

```
          小猪 按      小猪 等
大猪 按   (5,1)        (4,4)
大猪 等   (9,-1)       (0,0)
```

小猪的账：大猪若按，等（4）> 按（1）；大猪若等，等（0）> 按（-1）。**等是占优策略。** 大猪预见到这一点，只能自己按：（按,等）= (4,4)。

**核心洞察：强弱不对等时，弱者搭便车、强者多出力是理性结果。** 不是道德问题，是矩阵问题。

现实映射：小公司抄大公司研发、平台上小商家搭大平台便车、开源里少数维护者扛大部分补丁。

---

## 三、猎鹿博弈（Stag Hunt）—— 信任与合作风险

合作能猎鹿（大收益），单干只能抓兔（小但稳）：

```
          乙 猎鹿      乙 抓兔
甲 猎鹿   (4,4)        (0,3)
甲 抓兔   (3,0)        (3,3)
```

两个稳定点：（猎鹿,猎鹿）收益更高，但对方若抓兔自己得 0；（抓兔,抓兔）收益低但安全。关键不是「会不会算」，是**信不信对方也去猎鹿**。

**核心洞察：合作本身可以是均衡，只是不够稳。** 和囚徒不同——囚徒里合作根本不是均衡；这里合作是均衡，怕的是风险。

现实映射：创业合伙、国际减排、开源社区冷启动。

---

## 四、性别战（Battle of the Sexes）—— 协调

两人都想约会，一个想看球、一个想看戏，更怕各去各的：

```
          乙 看球      乙 看戏
甲 看球   (3,2)        (0,0)
甲 看戏   (0,0)        (2,3)
```

两个稳定点：（看球,看球）和（看戏,看戏）。问题不是要不要合作，是**在哪个点对齐**。谁先表态、约定、习惯，会决定落点。需要**聚焦点（Focal Point）**——一个让双方自然选同一个结果的信号。

**核心洞察：这是对齐问题，不是对抗问题。** 把你的均衡策略配到我的另一个均衡上，两人都会走散——这叫策略**不可互换**，[04](./04-纳什均衡.md) 会用来对照零和。

现实映射：左右行车、充电接口标准、交易平台、两队人约地点。

---

## 五、鹰鸽博弈（Chicken / Hawk-Dove）—— 冲突与退让

两车对冲：硬到底可能双输，先软的丢面子。数字取便于后文手算的标准型（把撞车改成 -10 只改混合比例，不改均衡结构）：

```
          乙 鹰        乙 鸽
甲 鹰    (-2,-2)      (2,0)
甲 鸽     (0,2)       (1,1)
```

两个稳定点：（鹰,鸽）和（鸽,鹰）。（鸽,鸽）双方都想偷偷变硬；（鹰,鹰）双方都想改软。最怕的是**双方都硬**。

**核心洞察：实力相当又都想赢时，强硬是威慑，但必须有人（或按概率）退让。** 与猎鹿相反：猎鹿怕的是对方不够合作，鹰鸽怕的是对方不够软。

现实映射：古巴导弹危机、讨价还价最后通牒、竞标加码。

---

## 六、石头剪刀布（Rock-Paper-Scissors）—— 无纯策略稳定点

```
        乙 石   乙 剪   乙 布
甲 石   (0,0)  (1,-1)  (-1,1)
甲 剪  (-1,1)  (0,0)   (1,-1)
甲 布   (1,-1) (-1,1)   (0,0)
```

- 这是**零和**：一方赢几，另一方就输几。解法见 [03-零和博弈](./03-零和博弈.md)。
- 没有任何固定手势是稳定点——出什么都会被克制。
- 唯一稳定点是混合：各 1/3 随机出。

**核心洞察：行为可被预测，就会被针对；随机化是最好的防御。** 混合策略的算法在 [03](./03-零和博弈.md) 和 [04](./04-纳什均衡.md)。

现实映射：扑克诈唬、点球方向、网络攻防的随机化。

## 七、怎么识别：看矩阵，不看故事

| 模型 | 看哪一眼 | 困境 | 稳定点数 | 关键词 |
|---|---|---|---|---|
| 囚徒困境 | 各有占优策略，交点却差于「都合作」 | 个体 vs 集体 | 1（次优） | 占优 |
| 智猪博弈 | 弱者有占优（搭便车），强者只能扛 | 强弱不对等 | 1 | 搭便车 |
| 猎鹿博弈 | 两个对角都稳定，合作那个更好但不稳 | 风险 vs 收益 | 2 | 信任 |
| 性别战 | 两个对角都稳定，各偏袒一方 | 对齐到哪 | 2 | 聚焦点 |
| 鹰鸽博弈 | 两个错角稳定，同侧双输 | 硬碰硬 | 2 | 威慑 |
| 石头剪刀布 | 循环克制，对角是平局 | 被看穿就被针对 | 0 纯策略 | 混合 / 零和 |

快速分流：

```
有没有占优策略？
  ├─ 双方都有，交点不如都合作     → 囚徒
  ├─ 只有弱者有，弱者等           → 智猪
  └─ 没有
        ├─ 对角稳定、合作更好     → 猎鹿
        ├─ 对角稳定、各偏袒一方   → 性别战
        ├─ 错角稳定、同侧双输     → 鹰鸽
        └─ 循环克制、格子相加为 0 → 猜拳（零和）
```

**记忆线索**：从「个体坑了集体」（囚徒），到「弱者搭便车」（智猪），到「敢不敢合作」（猎鹿）、「怎么对齐」（性别战）、「怎么不撞车」（鹰鸽），最后到「怎么不被看穿」（猜拳）——从算收益到藏意图。下一章把第六个模型展开：蛋糕固定时，博弈有一个双方都能保证的**值**。
