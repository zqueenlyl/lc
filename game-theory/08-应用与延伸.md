## 一、合作博弈（Cooperative Game）

非合作博弈研究「个体怎么选」，**合作博弈研究「联盟怎么分」**：一群人合作能创造多少价值，怎么公平地分。

### 1. 核（Core）

一种分配「稳定」当且仅当：没有任何子联盟能脱离出去、靠自己做得更好。若存在这种子联盟，分配就不稳定，会被「掀桌」。

- 核可能为空（怎么分都有人不满），也可能有多个解。

### 2. Shapley 值（Shapley Value）

最经典的「公平分配」方案。思想：**按每个人对每个可能联盟的「边际贡献」的平均值来分**。

Shapley 值公式直觉：

```
ϕᵢ = Σ   [ 加入顺序数 × (有 i 的联盟价值 - 无 i 的联盟价值) ]
     所有联盟

即：把所有人随机排队，i 加入队伍时带来的边际价值，对所有排队方式取平均。
```

四个公理（效率、对称、虚设、可加）唯一确定 Shapley 值。

**现实应用**：合作项目的分成、股东分红、**机器学习里的特征归因（SHAP）**——SHAP 就是 Shapley 值在「解释模型预测」上的应用，算每个特征对预测的「边际贡献」。

## 二、演化博弈（Evolutionary Game Theory）

传统博弈假设「理性计算」。演化博弈假设**「策略是基因/惯例，按收益在群体中传播」**——不靠聪明，靠自然选择。

### 1. 演化稳定策略（ESS）

一个策略是 ESS，当且仅当：若群体都用它，任何少量「突变」进来的新策略都无法侵入（新策略收益更低）。

ESS 是「比纳什均衡更严」的稳定概念——ESS 一定是纳什均衡，但反过来不一定。

### 2. 复制者动态（Replicator Dynamics）

描述各策略在群体中的比例如何随时间变化：

```
策略比例增长率 ∝ (该策略收益 - 群体平均收益)
```

收益高于平均的策略扩张，低于平均的萎缩。

**鹰鸽博弈的演化解释**：全鸽群体会被少数鹰侵入（鹰占便宜）；全鹰群体互相残杀，鸽也能侵入。最终停在**鹰鸽按一定比例共存**的混合均衡。这解释了动物界为什么「打架往往点到为止」——纯鹰策略在演化上不稳定。

**现实应用**：文化习俗、语言演化、市场惯例的形成、网络安全攻防的长期演化。

## 三、谈判理论（Bargaining）

### 1. Rubinstein 讨价还价模型

两人轮流提分配方案，对方要么接受要么还价。每轮拖延都有成本（贴现 δ）。

结论：**先出价者占优，拖延成本低者（更有耐心）占优**。极限下，唯一 SPNE 的分配比例由双方的贴现因子决定——**「急的人让利」**。

### 2. Nash 谈判解（Nash Bargaining Solution）

公理化方法：在「合作总比不合作好」的前提下，找到满足若干公理的唯一分配——**最大化双方从合作中获得的额外收益的乘积**。

### 应用

| 场景 | 谈判要点 |
|---|---|
| 薪资谈判 | 谁更有耐心、谁有更好替代选项（BATNA）谁占优 |
| 并购谈判 | 拖延成本、外部选择决定分蛋糕 |
| 国际贸易 | 关税谈判的讨价还价动态 |

## 四、博弈论与计算机 / AI

博弈论在当代重新走红，很大程度是「算法博弈论（Algorithmic Game Theory）」带动的：

| 方向 | 博弈论的角色 |
|---|---|
| **多智能体系统（Multi-Agent）** | 多个 AI Agent 相互影响时，用均衡预测其行为 |
| **机制设计 / 拍卖** | 广告竞价、频谱、区块链 gas 竞价 |
| **匹配市场** | 稳定婚姻匹配（Gale-Shapley 算法）、学校招生、器官移植匹配 |
| **强化学习 × 博弈** | 多智能体强化学习（MARL）、自博弈（AlphaGo/AlphaStar 自己和自己下） |
| **可解释 AI** | SHAP（Shapley 值）做特征归因 |
| **安全与对抗** | 用博弈建模攻防、红蓝对抗、模型间的策略博弈 |
| **联邦学习 / 数据定价** | 机制设计激励各方贡献真实数据 |

**对 AI Agent 开发者的意义**：当 Agent 进入真实世界与其他 Agent / 人类交互时，「怎么定价、怎么发信号、怎么承诺、怎么让威胁可信」都会变成工程问题——博弈论就是这些设计背后的数学模型。

## 六、怎么继续深入

1. **做题**：把手算纳什均衡、逆向归纳、混合策略练熟，比读十遍概念有用。
2. **建模练习**：拿一个现实场景（定价、招聘、合作、谈判），写出参与者的收益矩阵，求均衡，再问「改变哪条规则能改变均衡」。
3. **教材进阶**：Gibbons《博弈论基础》→ Fudenberg & Tirole《博弈论》。
4. **算法方向**：Nisan 等《算法博弈论》+ 多智能体强化学习资料。
