# 06. 重复博弈（Repeated Games）

> 单次囚徒里，背叛是占优。[05](./05-扩展式博弈与逆向归纳.md) 又说，终点确定时逆向归纳会把合作从最后一期拆到第一期。但**同一局若要反复玩，且不知道何时结束**，今天的背叛明天可以被惩罚——合作可以变成均衡。

一句人话：**把单次博弈改造成重复博弈，等于给「诚实」装上可执行的牙齿。**

阶段博弈（Stage Game）= 每一轮在玩的那局。下面全程沿用 [02](./02-经典博弈.md) 的囚徒矩阵（收益是刑期，越大越好，即越接近 0 越好）：

```
          乙 坦白    乙 沉默
甲 坦白   (-5,-5)   (0,-10)
甲 沉默  (-10,0)    (-1,-1)
```

沉默 = 合作，坦白 = 背叛。

---

## 一、有限重复：连锁店悖论

若确定一共玩 N 次：

- 第 N 次没有未来，惩罚落空 → 双方坦白。
- 第 N-1 次：既然最后一次注定坦白，这期合作也买不来下期合作 → 还是坦白。
- 一路倒推到第 1 次。

**有限次重复囚徒的 SPNE 是「每次都坦白」。** 这就是连锁店悖论（Chain-store Paradox）：只要终点共同知识，威胁从最后一间店开始不可信。想维持合作，必须打破「最后一次」——无限重复，或每轮结束后以概率继续。

---

## 二、贴现因子：未来值多少

**贴现因子 δ ∈ (0,1)**：下期 1 单位收益，今天值 δ。每期以概率 δ 继续、以 1-δ 结束，数学上等价。

- δ 接近 1：有耐心、关系长、下次还要见面。
- δ 接近 0：一次性买卖、随时散伙。

无限重复下，每期固定拿 u 的现值是 `u / (1-δ)`。

---

## 三、冷酷触发：合作的门槛可以算出来

**冷酷触发（Grim Trigger）**：一直沉默；一旦对方坦白，**永远坦白**作为惩罚。

比较「永远合作」和「这期偷叛再被锁死」：

- 永远沉默：每期 -1，现值 `-1 / (1-δ)`
- 这期坦白（对方仍沉默）拿 0，之后每期 -5：`0 + δ · (-5) / (1-δ)`

合作更好，当且仅当：

```
-1 / (1-δ)  ≥  -5δ / (1-δ)
-1          ≥  -5δ
 δ          ≥  1/5
```

**δ ≥ 1/5 时，双方都用冷酷触发是 SPNE。** 耐心越过门槛，合作就能被惩罚撑住。门槛低，是因为这组数字里背叛的一次性好处不够大（从 -1 只偷到 0）；若诱惑更大，门槛会升高。

换成教科书常用正收益 `(合作,合作)=(2,2)，(背叛,合作)=(3,0)，(背叛,背叛)=(1,1)`，同一套算法给出 `δ ≥ 1/2`。结构一样：**(诱惑 − 合作) / (诱惑 − 惩罚)**。

---

## 四、一报还一报

**Tit-for-Tat**：第一期沉默；之后每期复制对方上一期。

四个特征：善良（先合作）、报复（被叛就回击）、宽容（对方回头就原谅）、简单（可被识别为合作者）。

Axelrod 锦标赛里它长期表现突出。后文也指出：有噪声时，「宽恕版」往往更稳，冷酷触发会因一次误会锁死。选择策略时，先问环境里会不会误读动作。

和冷酷比：惩罚更短，威慑稍弱，容错更好。δ 足够大时，TFT 也能撑住合作；计算比冷酷繁一点，直觉相同——**背叛的一次性好处 < 随后被惩罚的现值**。

---

## 五、民间定理：均衡太多了

> **Folk Theorem**：无限重复下，只要 δ 足够大，任何双方收益都不低于各自**最小最大（minmax）**的结果，都能被某个均衡支持。

本例 minmax 是互相坦白的 -5（对方死盯坦白时你最多也是 -5）。所以凡是比 (-5,-5) 更好的——永远合作、轮流占便宜、按比例混合——理论上都能成为均衡。

**核心洞察：重复博弈解决了「合作可不可以」，没有解决「合作会停在哪」。** 真正的落点靠聚焦点、惯例、规范、谁先表态——文化和制度填的就是这个空。

---

## 六、现实里怎么「制造」重复

| 场景 | 机制 |
|---|---|
| 企业避免价格战 | 触发：你敢降我必跟，长期都吃亏 |
| 国际关系 | 关税报复、对等回应 |
| 熟人 vs 陌生人 | 熟人 = 高 δ；陌生人 = 单次 |
| 平台信誉 / 评价 | 用历史记录把单次买卖变成重复博弈 |
| 品牌 / 老字号 | 品牌溢价 = 未来租金，让坑一把变得不划算 |
| Agent 协作 | 会话要有记忆和可验证承诺，否则每轮都是新囚徒 |

**改规则的杠杆**：增加见面次数、提高 δ、让背叛可被观察和记录、让惩罚自动执行。劝双方「目光长远」而不改这些，等于要求他们在 δ 不够时当圣人。

---

## 七、求解套路

```
1. 写出阶段博弈矩阵（本书囚徒：坦白/沉默）
2. 有确定终点？ → 逆向归纳，多半每期都回到单次纳什
3. 无限 / 不确定终点？ → 选惩罚策略（冷酷 / TFT）
4. 算 IC：合作现值 ≥ 偷叛 + 之后被罚的现值 → 得到 δ 门槛
5. 过门槛：该策略组合是 SPNE；没过：合作撑不住
6. 记住民间定理：能撑住的结果很多，落点要另找聚焦点
```

**记忆线索**：有限重复被最后一期毒死；无限重复用 δ 买合作。下一章连「对方是哪种人」都不知道——惩罚和承诺都要先过信念这一关。
