# 13. 三数之和（3Sum）· 中等

给定一个整数数组 `nums`，找出所有和为 0 且不重复的三元组 `[nums[i], nums[j], nums[k]]`（`i != j != k`）。

注意：答案中不可以包含重复的三元组。

## 示例

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

## 考点

- 排序 + 双指针 + 去重，O(n²)。
