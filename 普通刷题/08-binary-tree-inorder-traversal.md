# 08. 二叉树的中序遍历（Binary Tree Inorder Traversal）· 简单

给定二叉树的根节点 `root`，返回其节点值的「中序遍历」结果（左 → 根 → 右）。

## 示例

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

## 考点

- 递归或迭代（栈），O(n)。
