# 01 · 核心概念与快速上手

> 目标：理解 LangGraph 的四个核心抽象 —— **State（状态）、Node（节点）、Edge（边）、编译执行**，能写出第一个线性流程，并搞懂状态如何合并（reducer / `add_messages`）。
>
> 配套 demo：`demos/01_basic_chain.py`

---

## 1. 为什么需要 LangGraph

普通的 `LLMChain` / `RunnableSequence` 只能表达**一条直线**：A → B → C，中途无法「根据结果走不同分支」，更难表达「循环」与「多步 Agent」。

LangGraph 的核心是把应用建模为一张**有状态的有向图**：

- **Node（节点）**：每个节点是一个可执行单元（调 LLM、查库、调工具、写文件……）。
- **Edge（边）**：决定节点之间「怎么走」。
- **State（状态）**：节点之间共享的数据，随执行不断更新。
- **条件边（conditional edge）**：根据 State 动态决定下一步，从而支持分支与循环。

它把「控制流」从「业务逻辑」中解耦出来，是构建 Agent 的事实标准之一。

---

## 2. 最小示例：三步流水线

场景：`检索 → 改写 → 生成` 三步线性流程。

```python
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 1) 定义 State：图里流转的共享数据
class State(TypedDict):
    query: str
    docs: str
    answer: str

# 2) 定义 Node：入参 State，返回「部分更新」
def retrieve(state: State):
    return {"docs": f"[检索结果] 关于 '{state['query']}' 的文档"}

def rewrite(state: State):
    return {"query": state["query"] + "（已改写）"}

def generate(state: State):
    return {"answer": f"根据 {state['docs']} 生成答案"}

# 3) 组装图：加节点 + 连边
g = StateGraph(State)
g.add_node("retrieve", retrieve)
g.add_node("rewrite", rewrite)
g.add_node("generate", generate)

g.add_edge(START, "retrieve")     # 入口
g.add_edge("retrieve", "rewrite")
g.add_edge("rewrite", "generate")
g.add_edge("generate", END)       # 出口

# 4) 编译并执行
app = g.compile()
result = app.invoke({"query": "LangGraph 是什么？"})
print(result)
```

输出 State 的最终值：

```python
{
  "query": "LangGraph 是什么？（已改写）",
  "docs": "[检索结果] 关于 'LangGraph 是什么？' 的文档",
  "answer": "根据 ... 生成答案"
}
```

要点：

- `START` / `END` 是图的两个虚拟端点，从 `langgraph.graph` 导入。
- 节点函数的返回值会被**合并回 State**（只更新你返回的字段，未返回的字段保持不变）。
- 每个节点都能拿到**最新**的 State。

## 3. State 详解：reducer 与 add_messages

### 3.1 默认合并语义：覆盖

默认情况下，节点返回的字段**覆盖**原值。上面的例子就是覆盖语义。

### 3.2 用 reducer 自定义合并方式

当多个节点并发写同一个字段，或需要「累加」时，用 `Annotated` 指定 reducer：

```python
from typing import TypedDict, Annotated
from operator import add

class State(TypedDict):
    total: Annotated[int, add]   # 累加：并发结果会求和
    logs: Annotated[list, add]   # 列表拼接
```

`add` 就是 reducer 函数：`total` 用加法合并，`logs` 用列表拼接合并。你也可以写任意自定义 reducer：

```python
def keep_latest(existing, new):
    return new  # 总是取最新值

class State(TypedDict):
    value: Annotated[str, keep_latest]
```

### 3.3 add_messages：处理对话消息的约定

对话场景里，State 通常用一个 `messages` 列表，且**新消息要追加、不覆盖**。LangGraph 提供了开箱即用的 reducer：

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import HumanMessage, AIMessage

class State(TypedDict):
    messages: Annotated[list, add_messages]

# 节点中追加消息的几种等价写法：
def chat(state):
    return {"messages": [AIMessage(content="你好！")]}
    # 或返回元组： ("ai", "你好！")  / ("user", "hi")
```

`add_messages` 的能力：

- 把新消息**追加**到 `messages` 列表。
- 支持消息**替换/合并**：同一 `id` 的消息会被更新，常用于流式改写 token。
- 自动处理 OpenAI 风格的消息类型（`HumanMessage` / `AIMessage` / `SystemMessage` / `ToolMessage`）。

> 构建对话型 / Agent 型图时，几乎总是用 `messages: Annotated[list, add_messages]`。

## 4. 图的生命周期：compile → invoke / stream

### 4.1 compile 与常用参数

```python
from langgraph.checkpoint.memory import MemorySaver

app = g.compile(
    checkpointer=MemorySaver(),   # 加持久化（详见 03 篇）
    interrupt_before=["approve"], # 执行到某节点前暂停（详见 03 篇）
)
```

不传参数时得到**无状态**图，每次 `invoke` 都从零开始。

### 4.2 invoke：同步执行

```python
result = app.invoke(input, config={"configurable": {"thread_id": "1"}})
```

- `input`：初始 State（只需提供用到的字段）。
- `config`：传递 `thread_id`（记忆隔离）、`recursion_limit`（循环上限）等运行时配置。

### 4.3 stream：流式观察执行过程

```python
for chunk in app.stream(input):
    print(chunk)   # 每个节点执行完后输出一次该节点的更新
```

`stream` 有多种模式（`values` / `updates` / `messages` 等），第 03 篇详解。

### 4.4 常用配置：recursion_limit

循环图默认最多递归 25 步，超出抛错。可调：

```python
app.invoke(input, config={"recursion_limit": 100})
```

## 5. 图结构查询与调试

```python
# 打印图的 ASCII 结构
print(app.get_graph().draw_ascii())

# 打印 Mermaid 图（可贴到 mermaid.live 可视化）
print(app.get_graph().draw_mermaid())
```

这能直观看到节点与边的拓扑，是排查「为什么走错了分支」的第一步。

---

## 6. 小结

| 概念 | 作用 | 关键点 |
|---|---|---|
| State | 共享数据 | `TypedDict` + `Annotated[reducer]` |
| Node | 执行单元 | 入参 State、返回部分更新 |
| Edge | 控制流 | `add_edge` 固定、`add_conditional_edges` 动态 |
| add_messages | 消息合并 reducer | 对话/Agent 标配 |
| compile/invoke | 编译执行 | 可加 checkpointer / interrupt |
