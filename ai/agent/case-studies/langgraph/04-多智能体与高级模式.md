## 1. 子图：把复杂图拆成模块

当一个节点内部逻辑很复杂时，可以把它包成**独立的图**，再作为「子图节点」挂到父图上。子图可复用、可单独测试。

```python
def build_tool_subgraph():
    sg = StateGraph(State)
    sg.add_node("fetch", fetch_node)
    sg.add_node("parse", parse_node)
    sg.add_edge(START, "fetch")
    sg.add_edge("fetch", "parse")
    sg.add_edge("parse", END)
    return sg.compile()

parent = StateGraph(State)
parent.add_node("tool", build_tool_subgraph())   # 子图作为节点
parent.add_node("answer", answer_node)
parent.add_edge(START, "tool")
parent.add_edge("tool", "answer")
parent.add_edge("answer", END)
app = parent.compile()
```

要点：

- 子图的**入口/出口**要和父图约定的 State 字段对齐。
- 子图内部有自己的节点命名空间，与父图互不冲突。

## 2. 并行 fan-out / fan-in：Send API

当需要**同时对多个独立任务并行处理**（例如：同时检索多个数据源、同时评审多篇文档），用 `Send` 动态「扇出」到同一个节点多次，再「扇入」汇总。

```python
from langgraph.types import Send
from langgraph.graph import StateGraph, START, END
from typing import TypedDict, Annotated
from operator import add

class State(TypedDict):
    tasks: list[str]
    results: Annotated[list, add]   # 用 add reducer 汇总并发结果

def fan_out(state) -> list[Send]:
    # 为每个 task 生成一个 Send，指向同一个 worker 节点（局部 state 传 task）
    return [Send("worker", {"task": t}) for t in state["tasks"]]

def worker(state):
    return {"results": [f"处理完成：{state['task']}"]}

g = StateGraph(State)
g.add_node("worker", worker)
g.add_conditional_edges(START, fan_out)   # 入口直接扇出
g.add_edge("worker", END)                  # 每个 worker 结束即到 END，靠 reducer 自动 fan-in
app = g.compile()

result = app.invoke({"tasks": ["a", "b", "c"]})
print(result["results"])  # 三个并行结果已自动汇总
```

要点：

- `fan_out` 挂在 `START` 上，返回 `list[Send]`，LangGraph 会**并行**执行所有 `worker` 分支。
- 每个 `worker` 返回的 `results` 用 `add` reducer **自动汇总**（fan-in），无需单独的聚合节点。
- 所有扇出分支都结束后，图才走到 `END`。

> 完整可运行版本见 `demos/04_parallel_fanout.py`。

## 3. 多智能体：Supervisor 模式

多智能体系统让多个 Agent 各司其职，由一个**监督者（Supervisor）**调度。典型架构：

```
用户 → Supervisor（路由）
         ├─ 研究员 Agent（research）
         ├─ 编码 Agent（coder）
         ├─ 写作 Agent（writer）
         └─ 汇总 / 结束
```

实现方式一：用 LangGraph 手动编排（透明可控，推荐先理解）：

```python
class State(TypedDict):
    messages: Annotated[list, add_messages]
    next: str

def supervisor(state):
    # LLM 决定下一步交给谁
    return {"next": llm_route(state["messages"])}

def research_agent(state):
    result = research_llm.invoke(state["messages"])
    return {"messages": [("ai", f"[研究员] {result}")], "next": "supervisor"}

def coder_agent(state):
    result = coder_llm.invoke(state["messages"])
    return {"messages": [("ai", f"[编码] {result}")], "next": "supervisor"}

def should_continue(state):
    # supervisor 判断可以结束时返回 "finish"
    return "finish" if state["next"] == "finish" else state["next"]

g = StateGraph(State)
g.add_node("supervisor", supervisor)
g.add_node("research", research_agent)
g.add_node("coder", coder_agent)
g.add_edge(START, "supervisor")
g.add_conditional_edges("supervisor", should_continue, {
    "research": "research",
    "coder": "coder",
    "finish": END,
})
g.add_edge("research", "supervisor")   # 完成后回到 supervisor
g.add_edge("coder", "supervisor")
app = g.compile()
```

### 其他多智能体架构

| 架构 | 特点 | 适用 |
|---|---|---|
| **Supervisor** | 中央调度，各 Agent 无直接通信 | 任务清晰、可集中控制 |
| **Swarm / 交接式** | Agent 间直接「交接」控制权 | 顺序依赖的任务 |
| **Network / 网状** | 任意 Agent 可互相通信 | 需要深度协作 |

## 4. 生产级最佳实践

### 4.1 状态设计

- 对话用 `messages: Annotated[list, add_messages]`；累加用 `Annotated[list, add]` 或自定义 reducer。
- State 字段保持**最小必要**，避免把大对象（如整个向量库）塞进 State。
- 用 `TypedDict` 显式声明类型，获得 IDE 补全与类型检查。

### 4.2 错误处理

- 在节点内捕获异常，写入 State（如 `errors` 字段），让图优雅降级而非崩溃。
- 关键节点前用 `interrupt_before` 设卡，便于人工干预。

### 4.3 可观测性

- 打开 LangSmith 追踪：设置 `LANGSMITH_TRACING=true`，自动记录每一步的输入输出。
- 用 `app.get_graph().draw_mermaid()` 可视化图结构。

### 4.4 性能

- 独立任务用 `Send` 并行，避免串行调用 LLM。
- 用流式 `stream(mode="messages")` 降低首字延迟。
- 合理设置 `recursion_limit` 防止循环失控。

### 4.5 版本与依赖

- 锁定 `langgraph`、`langchain-core` 版本，避免 API 变动。
- 生产用 `SqliteSaver` / `PostgresSaver` 持久化，而非内存 `MemorySaver`。

## 5. 小结

| 模式 | 关键 API | 适用 |
|---|---|---|
| 子图 | 把 `compiled graph` 当节点 | 模块化、复用、测试 |
| 并行 | `Send` + `Annotated[list, add]` | 多源检索、批量处理 |
| 多智能体 | Supervisor / Swarm / Network | 复杂任务分工协作 |
| 可观测 | LangSmith + `draw_mermaid` | 调试、追踪 |
