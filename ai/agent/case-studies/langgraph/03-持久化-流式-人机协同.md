> 目标：掌握 Checkpointer（记忆/断点）、Stream（流式输出）、interrupt/Command（人机协同）三大进阶能力。
>
> 配套 demo：`demos/07_human_in_the_loop.py`、`demos/08_checkpointer_memory.py`

## 1. Checkpointer：给图加「记忆」

`compile()` 不传 checkpointer 时，图是**无状态**的：每次 `invoke` 都从零开始，多轮对话会「失忆」。

加了 checkpointer 后，每个节点的执行结果都会**持久化到检查点**，下次调用可续接。

### 1.1 MemorySaver：内存持久化（开发/测试）

```python
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from typing import TypedDict, Annotated

class State(TypedDict):
    messages: Annotated[list, add_messages]

def echo(state):
    return {"messages": [("ai", f"收到：{state['messages'][-1].content}")]}

g = StateGraph(State)
g.add_node("echo", echo)
g.add_edge(START, "echo")
g.add_edge("echo", END)

app = g.compile(checkpointer=MemorySaver())

config = {"configurable": {"thread_id": "user-1"}}
app.invoke({"messages": [("user", "第一句")]}, config)
app.invoke({"messages": [("user", "第二句")]}, config)  # 同一 thread_id，能看到历史
```

### 1.2 thread_id：会话隔离

`thread_id` 是「会话 id」：

- **同一个 thread_id** → 共享记忆，续接对话。
- **不同 thread_id** → 完全隔离，互不干扰。

```python
app.invoke(..., {"configurable": {"thread_id": "alice"}})  # 会话 A
app.invoke(..., {"configurable": {"thread_id": "bob"}})    # 会话 B，互不影响
```

### 1.3 生产级持久化

- **SqliteSaver**：`from langgraph.checkpoint.sqlite import SqliteSaver`（本地文件，适合单机）。
- **PostgresSaver / RedisSaver**：`langgraph-checkpoint-postgres` / `langgraph-checkpoint-redis`（适合服务端多实例）。

```python
from langgraph.checkpoint.sqlite import SqliteSaver
import sqlite3

conn = sqlite3.connect("checkpoints.db", check_same_thread=False)
app = g.compile(checkpointer=SqliteSaver(conn))
```

### 1.4 回溯历史状态

```python
state = app.get_state(config)                 # 当前状态
history = list(app.get_state_history(config))  # 所有历史快照（可回溯/回放）
```

## 2. 流式输出：Stream

### 2.1 stream 的三种模式

```python
# 模式一：values —— 每个节点执行完输出「完整 State」
for s in app.stream(input):
    print(s)

# 模式二：updates —— 每个节点执行完输出「该节点的增量更新」
for chunk in app.stream(input, stream_mode="updates"):
    print(chunk)

# 模式三：messages —— 逐 token 流式输出（对话场景）
for chunk, metadata in app.stream(input, stream_mode="messages"):
    print(chunk.content, end="")
```

### 2.2 逐 token 流式

```python
def chat(state):
    return {"messages": [llm.stream(state["messages"])]}  # 用 .stream 而非 .invoke

for chunk, _ in app.stream(input, stream_mode="messages"):
    if chunk.content:
        print(chunk.content, end="", flush=True)
```

### 2.3 多流混合

```python
for typ, payload in app.stream(input, stream_mode=["updates", "messages"]):
    pass  # typ 标识来源
```

> 流式只是「观察方式」的不同，图的逻辑不变。真正的逐 token 流式需要在节点内用 LLM 的 `.stream()`。

## 3. 人机协同：interrupt / Command

很多场景需要**暂停等人类确认**（审批、人工审核、敏感操作）。LangGraph 用 `interrupt` 实现。

### 3.1 中断并等待人类

```python
from langgraph.types import interrupt

def approve_node(state):
    # 执行到这里会「暂停」，把 prompt 抛给外部，等待 resume
    decision = interrupt({"question": "是否批准该操作？", "data": state.get("payload")})
    return {"approved": decision}
```

- 首次 `invoke` 会在 `interrupt` 处**挂起**，返回一个 `Interrupt` 值。
- 外部拿到问题 → 人类作答 → 用 `Command(resume=...)` 恢复执行。

```python
config = {"configurable": {"thread_id": "1"}}

# 第一次执行：挂起
result = app.invoke({"payload": "..."}, config)
print(result)  # 内含 __interrupt__ 信息

# 人类作答后恢复
from langgraph.types import Command
app.invoke(Command(resume="批准"), config)   # 从 interrupt 处继续，decision == "批准"
```

### 3.2 在特定节点前/后中断

不写 `interrupt()` 也能全局指定「执行到某节点前暂停」：

```python
app = g.compile(
    checkpointer=MemorySaver(),
    interrupt_before=["approve"],    # 进入 approve 节点前暂停
    interrupt_after=["review"],      # 执行完 review 节点后暂停
)
```

配合 `Command(resume=...)` 或 `app.invoke(None, config)` 继续。

### 3.3 动态修改图状态后继续

`Command` 不仅能 resume，还能**在恢复时更新 State**：

```python
app.invoke(
    Command(resume="批准", update={"note": "人工已审核"}),
    config,
)
```

## 4. 完整串联示例

```python
class State(TypedDict):
    messages: Annotated[list, add_messages]
    approved: bool

def draft(state):
    return {"messages": [("ai", "已生成初稿，请审核")]}

def approve(state):
    ok = interrupt({"question": "是否通过初稿？"})
    return {"approved": ok == "yes"}

def publish(state):
    return {"messages": [("ai", "已发布")]}

def route_after_approve(state):
    return "publish" if state["approved"] else END

g = StateGraph(State)
g.add_node("draft", draft)
g.add_node("approve", approve)
g.add_node("publish", publish)
g.add_edge(START, "draft")
g.add_edge("draft", "approve")
g.add_conditional_edges("approve", route_after_approve, {"publish": "publish", END: END})
g.add_edge("publish", END)
app = g.compile(checkpointer=MemorySaver())
```

## 5. 小结

| 能力 | 关键 API | 用途 |
|---|---|---|
| 记忆 | `compile(checkpointer=...)` + `thread_id` | 多轮对话、会话隔离 |
| 断点/回溯 | `get_state` / `get_state_history` | 调试、回放 |
| 流式 | `stream(stream_mode=...)` | 实时反馈、逐 token |
| 人机协同 | `interrupt()` / `Command(resume=)` | 审批、人工审核 |
| 定点暂停 | `interrupt_before/after` | 在关键节点设卡 |
