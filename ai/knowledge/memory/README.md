# Memory · Agent 记忆

> 一句话：**LLM 天生无状态，记忆系统就是「让 Agent 记得住」的那层基础设施**——按时间尺度分工作 / 短期 / 长期三层，决定「写什么、什么时候召回、什么时候忘」。
>
> 全景整理见 [agent-memory.md](./agent-memory.md)；可运行示例见 [09_agent_memory.py](./09_agent_memory.py)。

记忆是 Agent 从「一次性问答」变成「连续协作」的分水岭；它管的是**跨轮次、跨会话的持久化**，与「本轮上下文塞什么」是两件事——后者归 [../context-engineering/](../context-engineering/)。

---

## 一、技术讲解

### 三层记忆（按时间尺度）

| 层 | 存什么 | 生命周期 | 落地载体 |
|---|---|---|---|
| **工作记忆** | 本次任务的中间状态、步骤栈 | 单次任务，易失 | LangGraph `State` |
| **短期记忆** | 本轮会话完整历史（消息、工具调用） | 会话级 | 消息列表 / 滑动窗口 |
| **长期记忆** | 用户画像、稳定事实、沉淀知识 | 跨会话 | 向量库 / DB，**默认不可见，靠检索召回** |

可见性规律：**只有进了上下文窗口的模型才看得见**；长期记忆是「有求才现」，所以关键在**召回准确度**与**固化（consolidation）策略**。

### 四大核心能力

**写入**（提炼什么进长期库、如何防污染）→ **召回**（语义检索 + 过滤 + 排序）→ **遗忘 / 压缩**（TTL、摘要、冲突覆盖）→ **隔离**（按 user / thread / agent 划作用域）。

---

## 二、功能作用

- **连续性**：跨轮次、跨会话不重复问、不丢上下文。
- **个性化**：记住用户偏好、身份、历史决策。
- **稳定性**：重要事实沉淀后可复用，不依赖模型「记性」。
- **成本控制**：不必把全量历史塞进窗口，按需召回。

---

## 三、应用场景

| 场景 | 用到的层 |
|---|---|
| 多轮任务型 Agent（改代码、跑流程） | 工作记忆 + 短期记忆 |
| 个人助手 / 客服（认得人） | 长期记忆（画像） |
| 团队协作 Agent（共享事实） | 长期记忆 + 作用域隔离 |
| 长文档分析、反复追问 | 短期 + 长期（摘要 + 检索） |

---

## 四、经典实现方案（按演进）

| 方案 | 机制 | 代价 |
|---|---|---|
| 全量上下文 | 历史全塞窗口 | 超窗、贵、噪声大 |
| 缓冲记忆 | 保留全部消息 | 同上，仅延迟决策 |
| 摘要记忆 | 定期把历史压成摘要 | 丢细节，摘要本身有损 |
| 向量检索记忆（RAG 式） | 历史 embedding 入库，按需召回 | 召回不准就答偏 |
| 图 / 结构化记忆 | 实体-关系建模 | 构图与维护成本高 |
| **混合记忆（生产推荐）** | 工作状态 + 窗口 + 向量长期库组合 | 实现复杂，要调策略 |

## 六、关键技术细节

- **写入策略**：只从可信轮次提炼、写前过滤（去 PII / 去噪声）、冲突时覆盖或并存。
- **召回策略**：语义检索 + 时间/类型过滤，控制注入条数与顺序。
- **遗忘与压缩**：TTL、摘要、重要性打分淘汰。
- **隔离与作用域**：`user_id` / `thread_id` / `agent_id` 三层键，防串档。

## 八、落地建议

1. **三层别混用**：工作状态进 State、会话历史进窗口、跨会话事实进长期库。
2. **写入要克制**：宁可少写、写准，也别把整段对话灌进长期库。
3. **召回要可解释**：每次召回记录命中原因与分数，否则无法调优（见 [eval](../../reliability/eval/)）。
4. **作用域键从第一天设计**：`user_id` + `thread_id` 隔离，避免上线后串档。
5. **合规前置**：长期记忆常含个人信息，写入/删除要有策略与审计。

## 九、本目录 MVP

[09_agent_memory.py](./09_agent_memory.py) 用 LangGraph 演示三层记忆：工作记忆（`State`）+ 短期记忆（最近 N 条滑动窗口）+ 长期记忆（按 `user_id` 隔离的写入 / 召回 / 覆盖更新，用字符重叠度近似向量检索，无外部 API）。

> 依赖 LangGraph：`pip install langgraph` 后 `python 09_agent_memory.py`。
