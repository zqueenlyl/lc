## 0. 宏观总揽

### 0.1 一句话认知（对照 LLM）

| | Transformer LLM | MiniMax-H3 |
|--|-----------------|------------|
| 机器在干什么 | **接龙**：猜下一个 token id | **运货**：把噪声 latent 沿直线拉回干净音视频 |
| 一次前向的产出 | 词表上的概率分布 | 每个视频/音频 token 上的**速度** \(u_\theta\) |
| 循环 | 拼回一个 token，再前向 | 用 \(u_\theta\) 走一小步 \(t\)，再前向；开源常见约 **50 步**（部署篇有 5-step 预览档） |
| 「懂世界」压在哪 | 权重里的语言统计 | 权重里的「什么画面+声音算合理」+ Qwen3-VL 条件器 |

**H3 = 一台只认 packed 数字的联合去噪机器**：把文/图/视频/音频压成一条带标签的向量序列，喂进 50 层 Omni Transformer，网络吐出「视频该往哪走、音频该往哪走」，按 Rectified Flow 积分到干净 latent，两个 VAE 解码成 768p 画面 + 32 kHz 立体声。

训练做的是**压缩**：真实片子 → 调参，把「世界里的视听规律」压进 33B 权重；推理做的是**解压**：从纯噪声出发，顺着权重一步步走到成片。这和 LLM「语料压缩 / 逐 token 解压」同构，换的是**目标函数**（CE → 速度 MSE）和**时间轴**（自回归 token → 扩散时间 \(t\in[0,1]\)）。

### 0.2 全链路 = 一条主线，两个生命周期

```
多模态输入（文 / 图 / 片 / 声）
         → [环节1] 规格与任务族：你到底在生成什么（FL2VA / Ref2VA）
         → [环节2] Context-IR：把「关系」写成 Base 吃得下的中间表示
         → [环节3] 双 VAE：像素/波形 ↔ latent（真正的 tokenizer）
         → [环节4] Encoder + Patch 投影 + pack：编号世界 → 5376 维序列
         → [环节5] MM-RoPE：给 (t,h,w) 注入时空顺序
         →  ┐
            │  Omni Block × 50（每个 token 都过，模态共享 Attn/FFN）：
         ↓  │  [环节6] AdaLN：按时间步 + 模态标签调制
         ↓  │  [环节7] 共享 Attention + SwiGLU + 残差 RMSNorm
         ↓  └→ 堆叠 = 逐层联合提炼「画面该长什么样、声音该响什么」
         ↓
         ↓ 训练生命周期（一次吃整条 packed 序列）     ↓ 推理生命周期（沿 t 积分，不是自回归）
         ↓                                          ↓
[环节8] 双头 → 视频速度 + 音频速度            [环节8] 同一双头
         ↓                                          ↓
     对真值速度做 MSE                          [环节10] Euler/flow 走一步 t
         ↓                                          ↓
    反向传播更新全部权重                       再前向；积完再 VAE decode
         ↓                                          （没有 LLM 那种 KV 逐 token 增长）
[环节9] VAE → caption → 混合预训练 → 双 checkpoint → CFG 蒸馏
         ↓
[环节11] 服务化：SGLang / vLLM / Modular；产品侧再接 IR + 2K Regen
```

- **训练**：随机抽扩散时间 \(t\)，整条序列一次前向，音画两个 MSE。
- **推理**：从 \(t\approx 1\)（纯噪声）走到 \(t=0\)（干净），每步都要完整跑一遍 50 层——贵在**步数 × 序列长度**，不在「生成第 100 个词」。所以 H3 **没有** LLM 环节 10 里那个「KV Cache 让每步只算增量」的主战场；主战场是 VAE 压缩比、稀疏注意力、AdaLN 卸载、Ulysses 序列并行。

### 0.3 先把「为什么长这样」记住（演进因果链）

| 历史痛点 | 对应解法（H3 里的零件） | 对照 Transformer 环节 |
|---|---|---|
| 像素/波形太长，DiT 吃不起 | 双 VAE：视觉 `f16t4d24` + 再 2×2 patch；音频 32 kHz→40 Hz | 环节 01 Tokenizer |
| 任务墙：T2V / I2V / 参考 / 配音各养专家 | 语言描述关系 + Context-IR；预训练早融合 | 无直接对应（H3 特有） |
| 先出静音再配乐，口型对不齐 | 单流 packed，音画同一去噪环、同一套 Attn | 环节 04 全部可见 |
| 条件（文本、时间步、模态）怎么进 DiT | 模态专用只放输入/输出 + **AdaLN**（约 13B） | 环节 06 的「可自适应」加强版 |
| Attention 没顺序 | 三维 **MM-RoPE** `(t,h,w)` | 环节 03 RoPE |
| 深网不稳 | Pre-RMSNorm + 门控残差 | 环节 06 |
| 只会汇总不会加工 | SwiGLU FFN，无 MoE | 环节 05 |
| 2K 另养超分会丢小字 | 基模 in-context 重生成，再看原上下文 | 环节 11 系统层 |
| CFG 推理要跑两遍 | 蒸馏进权重，每步一次前向 | 环节 10 的「省前向」 |
| Hailuo-02 结构过巧，不利任务泛化 | 丢掉专家骨架，Attn/FFN 通用 | 环节 07 Decoder-only 同思路 |

> Transformer 零件本身（QKV、SwiGLU、RMSNorm、RoPE 公式）不在本系列从头推，需要时回链 foundation 对应环节。本系列只讲 **H3 在那些零件上多做了什么、为什么必须多做**。

## 2. 结构全景图（本系列唯一一张「模型长什么样」）

```
 自由多模态输入
        │
        ▼
 ┌─ 产品前置（常托管）─────────────────────────────┐
 │  [环节2] H3-Context-IR → ~4K 结构化文本          │
 └─────────────────────────────────────────────────┘
        │
        ▼
 ┌─ H3-Base 一次训练/推理前向 ─────────────────────┐
 │  [环节3] VisualVAE / AudioVAE                    │
 │  [环节4] Qwen3-VL 第50层 + patch_proj + pack     │
 │           token_tags ∈ {video, text, audio}      │
 │  [环节5] MM-RoPE (t,h,w)                         │
 │  [环节6–7] Block × 50：AdaLN → Attn → AdaLN → FFN│
 │  [环节8] video_out (→96)  +  audio_out (→32)     │
 └─────────────────────────────────────────────────┘
        │
        ├─ 训练：MSE(u, v_video)+MSE(u, v_audio) → 反传
        └─ 推理：沿 t 积分完 → 两个 decoder → 768p + 立体声
                 │
                 ▼
 ┌─ 产品后置（常托管）─────────────────────────────┐
 │  [环节11] H3-Regenerate-2K：768p + 原上下文 → 2K │
 └─────────────────────────────────────────────────┘
```

开源权重钉死的骨架（记在环节 07，别处不再重复背）：

| 项 | 值 |
|----|----|
| 层数 / hidden / 头 | 50 / 5376 / 56×128 |
| FFN | 14336 SwiGLU |
| 总参 | 33B（AdaLN ≈ 13B，推理可卸） |
| 文本条件 | Qwen3-VL-32B 第 50 层，5120 维 |
| Token Refiner | 文本 2 层，无 AdaLN、无 RoPE |

## 3. 两个生命周期对照（务必先分清）

| | LLM（Transformer 环节 9/10） | H3 |
|--|------------------------------|-----|
| 训练并行单位 | 整句 token，因果 mask | 整条 packed 序列，**双向**（要看未来帧才能去噪） |
| 推理循环 | 每步 +1 token | 每步 \(t\) 减小一档，**序列长度不变** |
| 缓存 | KV Cache | AdaLN 调制按 \(t\) 缓存；VAE latent 常预编码参考 |
| 结束条件 | EOS / max_new_tokens | 调度器步数用尽 |
| 你调的旋钮 | temperature / top-p | 步数、seed、分辨率/时长、IR 是否走官方；**没有 CFG** |
