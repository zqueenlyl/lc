## 1. 干什么

开源：三维 Multimodal RoPE，坐标 `(t, h, w)`。`head_dim=128`，`rope_inv_freq_len=16`。和 Qwen2-VL 的 M-RoPE 同一家族：把头维拆到不同轴上旋转，而不是加一个可学习 `pos_emb[t,h,w]`。

## 2. 最小直觉（先复习旋转）

二维向量转 \(\theta\)：

\[
(x,y)\mapsto (x\cos\theta-y\sin\theta,\; x\sin\theta+y\cos\theta)
\]

RoPE 对 Q/K 做这种转，点积只依赖 **相对角** \(\theta_i-\theta_j\)。MM-RoPE 让一部分维度跟 \(t\) 转、一部分跟 \(h\)、一部分跟 \(w\)。

| 事件 | 哪个轴在转 |
|------|------------|
| 同一物体下一帧 | \(t\) 变，\(h,w\) 不变 |
| 同一帧里右边的 patch | \(w\) 变 |
| 第 3 秒的歌声 vs 第 3 秒画面 | 音频主要走 \(t\)；视频 \(t\) 相同则时间轴对齐 |
| 文本 token | 通常只转序列下标这一维 |

不需要单独的「音画对齐网络」：对齐是位置编码的几何。

## 3. 和绝对时空 embedding 比

| | 可学习 `E[t,h,w]` | MM-RoPE |
|--|-------------------|---------|
| 分辨率外推 | 没见过的格子要外插 | 相对旋转可外推（仍有长度外推问题，同 LLM） |
| 参数 | 随格子数涨 | 几乎不涨 |
| 相对运动 | 要模型自己从绝对坐标减出来 | 点积天然相对 |

视频生成分辨率、时长经常变，相对编码更对口。

## 4. 和 LLM RoPE 的差别

- LLM：一维位置 `0..n-1`，因果注意。
- H3：三维格子；去噪 Attn **双向**，未来帧也要看见（物体从右边走进来，左边的噪声格子需要右边的信息）。
- 文本 Refiner **故意不用 RoPE**（[环节 04](./环节04-Encoder与Packed序列详解.md)）：那 2 层只在文本内部混合。进 packed 主栈之后，文本行才会带上与音画一致的位置方案（实现细节以开源 `text_pos_info` 为准）。

## 5. 工程要点

1. pack 时必须带 `img_pos_info` / `audio_pos_info` / `text_pos_info`。位置错一格，口型会对到错误秒。
2. 稀疏注意力（训练末段有、开源推理暂无）仍要在同一套坐标上定义邻域；块大小 **未披露**。

## 6. 面试追问

- **没有 RoPE 会怎样？** 帧序可互换，运动解体；左右声道时间也对不齐画面。
- **为什么不学 3D 正弦表？** 可以，但 MM-RoPE 直接复用 LLM 设施和相对几何。
