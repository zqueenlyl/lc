误差结构

  • 229 个点把水域判成陆地，仅 43 个点把陆地判成水域 —— 单向偏置明显，模型倾向于回答"陆地"。
  • 预测陆地占比 37.7%，真值 33.1%，系统性高估约 4.6 个百分点。
  • 误差集中在 60°N 以北的北冰洋沿岸（喀拉海、拉普捷夫海、加拿大北极群岛的狭窄水道），以及南极洲边缘的冰架/海域分界。

方法

  1. 按 4° 步长在全球铺网格，得到 4050 个 (lat, lon) 文本坐标。
  2. 询问模型"这个坐标是陆地还是水域"，不给图、不给工具、不给上下文。
  3. 把答案重新铺回网格成像；用 Natural Earth 50m 陆地多边形做点在多边形内判定，得到打分基准。
  4. 同时计算"全猜陆地"退化基线 —— 任何低于 33.1% 的成绩说明模型比瞎猜还差。

结果对应网格点的标签，不是对 4050 次独立提问的统计；独立逐点提问（无跨点上下文）通常会更难。

复现

python run_eval.py --probe mock                      # 全猜陆地基线
python run_eval.py --probe file \
    --path predictions/hy4.intervals.json --name hy4

# 换成真实模型（OpenAI 兼容，任意厂商）
OPENAI_API_KEY=sk-... OPENAI_BASE_URL=https://api.deepseek.com/v1 \
    python run_eval.py --probe openai --model deepseek-chat --batch 40 --workers 8

# Anthropic 官方
ANTHROPIC_API_KEY=sk-ant-... python run_eval.py --probe anthropic \
    --model claude-sonnet-4-5 --batch 40 --workers 8
注意：hy4 这次是「一次性批量回忆」模式——按纬度带回忆陆地经度区间，而非逐点独立提问。 批量模式下模型能看到相邻坐标，空间一致性会被"自我修正"，成绩通常高于真正逐点提问。 要拿到严格可比的数字，请用 --probe openai / --probe anthropic 跑一次真·独立查询。
