# Sandbox · 沙箱隔离执行

> 让 Agent 生成的代码、命令和副作用被关进受控环境里跑：**碰不到宿主文件、上不了网、跑不超资源，越界就被拦。** 一句话：**Harness 给模型方向盘，Sandbox 是笼子 + 安全气囊。**

编码 Agent（Claude Code / Codex / Pi）、代码评测（Judge0 / SWE-bench）、Computer Use、FaaS 多租户，底层都在用某种沙箱。

配套 MVP：[mvp.py](./mvp.py)（虚拟 FS + 命令白名单 + 资源配额 + 审计日志，不碰真实系统）。

---

## 一、技术讲解

Agent 和普通程序最大的区别：**它按自然语言意图产生代码和命令，这些副作用不可信**。模型可能：

- 读走 `~/.ssh`、`.env`、云凭证；
- `rm -rf`、`git push --force`、改系统配置；
- 偷偷联网外传数据。

沙箱解决的是「执行层隔离」：不管模型多不可信，它的动作只能作用在一个受限的盒子里。

隔离的五个维度：

| 维度 | 要挡什么 | 手段举例 |
|---|---|---|
| 文件系统 | 读宿主敏感文件 | overlayfs、只读根、虚拟 FS |
| 网络 | 外传数据 / 打内网 | 断网、域名白名单、代理 |
| 进程 | 提权、逃逸 | seccomp、无特权、PID 命名空间 |
| 凭证 | 偷 key / token | 不注入、临时凭证、短 TTL |
| 资源 | 跑死循环 / 吃内存 | CPU/内存/超时配额 |

**沙箱 ≠ 护栏（Guardrails）**，二者分层：

- [Guardrails](../guardrails/) 是**策略层**：允许做什么、要谁审批、输出对不对。
- Sandbox 是**执行层**：动作真正落在哪个环境、能碰到什么。
- 护栏决定「能不能」，沙箱保证「就算放行也炸不出去」。生产上两者要绑死。

---

## 二、功能作用

- **兜底隔离**：Agent 执行不可信代码时，宿主机和网络不受伤。
- **可复现**：每次从干净快照起跑，避免「我本地能跑」。
- **可审计**：所有命令、读写、网络请求留痕。
- **资源治理**：单任务限 CPU/内存/时间，防拖垮整机。
- **多租户**：一个沙箱一份环境，互不串数据。

---

## 三、沙箱类型怎么选

隔离强度、启动速度、运维成本不可兼得：

| 类型 | 隔离强度 | 启动 | 代表 | 适合 |
|---|---|---|---|---|
| 进程级 | 弱（同内核） | 毫秒 | seccomp、chroot、pledge | 可信代码微隔离 |
| 容器 | 中 | 百毫秒~秒 | Docker、Podman | 编码 Agent 常规选择 |
| 强化容器 | 中高 | 秒 | gVisor、Kata | 多租户 + 需加固 |
| 微虚拟机 | 强（独立内核） | 百毫秒 | Firecracker、Cloud Hypervisor | 云函数 / 评测 |
| WebAssembly | 中 | 毫秒 | Wasmtime、WASI | 插件、浏览器端 |
| 云沙箱 | 强 | 按需 | E2B、Codex 云、Modal | 免自运维 |

记忆口诀：**进程快但弱，容器是默认，微 VM 最稳，Wasm 最轻，云沙箱最省心。**

## 四、应用场景

| 场景 | 沙箱侧重点 |
|---|---|
| 编码 Agent 跑代码/测试 | 文件系统隔离 + 网络白名单 + 超时 |
| 代码评测（Judge0 / SWE-bench） | 微 VM + 快照 + 资源配额 |
| Computer Use 操控 | 浏览器/桌面单独容器，禁钱包/生产后台 |
| FaaS / 多租户函数 | 微 VM 或强化容器，冷启动要快 |
| 插件 / 第三方技能 | WebAssembly 或子进程，最小权限 |

不适合：本机可信的只读分析（不必上沙箱，省成本）；但也别因为「模型说不会乱来」就裸跑。

## 六、落地建议

1. 先定**威胁等级**：只读分析可以轻，跑用户代码必须上隔离。
2. 默认 **网络关闭**，要联网走域名白名单；凭证用短 TTL，不注入长期 key。
3. 资源配额（CPU/内存/超时）是必选项，不是加分项。
4. 留**审计日志**：命令、读写路径、网络出口，出事了能复盘。
5. 从容器起步，多租户或高价值再上微 VM / 云沙箱，别一上来自研。

## 八、本目录 MVP

`mvp.py` 用一个规则沙箱包住虚拟文件系统：只允许 `read` / `write` / `run`，拒绝 `rm` / 网络 / 系统命令，配 CPU 配额与审计日志。一个「Agent」尝试执行正常 + 越界动作，看哪些被拦。展示隔离与审计，不碰真实 OS。
