# 生视频模型演化路线与类型

> **定位**：按**机器怎么出帧**分类型，再按时间看每代在解什么痛点。产品名只当例子。前置：[图像扩散](../generative/diffusion/图像扩散模型详解.md)；关卡地图：[环节00](./环节00-总揽与环节导航.md)；时间维短文：[视频生成详解](./视频生成详解.md)。
> **口径**：年份是公开产品/论文的大致窗口，不是精确首发日。同一产品可以叠多种类型（骨干一套、条件另一套）。

---

## 0. 先钉死两件事

**类型问的是生成核，不是 App 名字。** 一次请求背后通常还有：文本/视觉编码器、VAE、超分、配音、审核。那些是系统层，不要和「这一帧是怎么从噪声或 token 里长出来的」混成一种模型。

**主流生视频已经不是一种 diffusion。** 同属「从噪声走到干净信号」的，至少要拆成：UNet 预测噪声、DiT 预测噪声、DiT 预测速度（flow）。另外还有离散 token 逐段写、GAN 对抗、世界模型动作条件下一帧。H3-Base 落在 **潜空间流匹配 DiT + 音画同环**，不是 DDPM，也不是整条产品只有这一核。

## 1. 六种生成核（按「一次前向在干什么」）

| # | 类型 | 一次前向产出 | 循环 | 时间怎么进模型 | 死在哪 | 代表 |
|---|---|---|---|---|---|---|
| A | **Video GAN** | 真/假判别压力下的帧或 clip | 一次（或少量）前向出片 | 3D conv / 运动码 | 时长短、模式崩、难控文 | MoCoGAN、DVD-GAN、StyleGAN-V |
| B | **图像 UNet 时间膨胀** | 每步去噪整段（或几帧） | 扩散步 | 在 2D 权上插 temporal attn/conv | 长程运动弱、身份漂 | AnimateDiff、SVD、早期 I2V |
| C | **离散 token 写视频** | 下一个（或被掩码的）视觉 token | 自回归或掩码迭代 | 帧/时空 token 当序列 | 误差累积、纹理糊、慢 | VideoGPT、Phenaki、MAGVIT、VideoPoet |
| D | **潜空间 DiT 扩散** | 每个 latent patch 上的噪声（或 \(x_0\)） | 扩散步，序列长度不变 | 3D VAE + 时空 patch + 双向 attn | 步数 × \(n^2\) 贵；音画常分家 | Sora 公开叙述、CogVideoX、Open-Sora 系 |
| E | **潜空间流匹配 DiT** | 每个 latent patch 上的**速度** | 沿 \(t\) 积分，序列长度不变 | 同 D，目标换成 \(v=\varepsilon-x_0\) | 同 D；调度/shift 要分模态 | Wan、Hunyuan 后继、**H3-Base** |
| F | **世界模型 / 动作条件** | 下一状态（像素或 latent） | 逐步 roll-out | 状态 + 动作 | 长时物理穿帮；好看 ≠ 能规划 | Genie、Cosmos、GAIA 类 |

读表口诀：

- A–B 是「先能出能动的短片」。
- C 是「把视频当成一种语言来写」。
- D–E 是 2024 之后的工业主核：压缩进 VAE，整段并行去噪/运货。
- F 是另一条题：不只好看，还要「如果我动一下，世界怎么变」。

**D 和 E 骨干可以长得几乎一样**（VAE + packed patch + AdaLN + Transformer）。换的是训练目标：噪声回归 vs 速度回归。产品文案常统称 diffusion；讲机制时要分开。

## 2. 时间轴（痛点驱动，不是堆型号）

```
2016–2021  A  GAN 短 clip
              痛点：从「会动」做到几秒；控不住语义，更控不住 10 秒叙事

2022–2023  B  把文生图 UNet 在时间维胀开 + 级联超分
           C  视觉 token 当语言模型写
              痛点：图像已经能听 prompt，视频还在闪、漂、只有 2–4 秒

2024       D  3D VAE + 时空 patch + DiT 整段去噪（Sora 把这条线打进主流）
              痛点：像素空间太长；必须压 latent；要一次性看见整段才能不闪

2024–2025  E  同一套 DiT，目标改 flow / rectified flow（跟进文生图 SD3/FLUX）
              痛点：采样更直、步数更好控；开源权重开始能复现「能看的 5–10 秒」

2025–2026  系统层叠在 D/E 上，不是第七种骨干：
              · 音画同环（同一去噪环出声画）     Movie Gen / Veo 3 / H3
              · 任务墙拆掉，语言写关系 + 参考 pack  Hailuo → H3 IR/Ref2VA
              · 2K 不另养纯超分，in-context 重生成  H3 Regen
              · 动作条件 / 可交互世界             F 与 D/E 交叉
```

每一跳都有一条算术或产品原因：

| 从 → 到 | 逼着换类型的原因 |
|---|---|
| GAN → 扩散系 | 要听长文本、要多样本，对抗训练不稳 |
| 时间膨胀 UNet → 3D VAE+DiT | 只插 temporal 层，长程运动和镜头仍漂；序列必须先压短 |
| 像素级联 → 潜空间 | 帧 × 分辨率把注意力打爆 |
| 预测噪声 → 预测速度 | 直线运输更好积、调度更好拧；文生图已经先走了 |
| 先画后配音 → 音画同环 | 口型/节奏对不齐；后配是另一条生成核，对不了同一条 \(t\) |
| 专家任务网 → 语言+pack | T2V/I2V/参考/配音分家，预训练泛化被墙 |
| 另训超分 → in-context 重画 | 小字和品牌传统 SR 只能猜 |

## 3. 系统层（叠在核上，不要当成第七种核）

这些经常被误叫成「另一种视频模型」：

| 层 | 干什么 | 例子 |
|---|---|---|
| 条件编码器 | 文/图理解，不负责出帧 | CLIP、T5、Qwen-VL（H3 Encoder） |
| 任务接口 | 把创意写成模型吃得下的关系 | 专家 ControlNet vs **语言描述关系 / IR** |
| 音频 | 后配 TTS vs **AudioVAE 进同一 packed 序列** | 多数 2024 模型 vs H3 / Veo 3 / Movie Gen |
| 分辨率 | 级联超分 vs 基模重生成 | 传统 SR vs H3 Regenerator |
| 蒸馏 | 少步、去掉 CFG 第二遍前向 | 发布权重「没有 guidance_scale」 |

H3 拆开看：

```
生成核     E  潜空间 flow DiT（双向、速度 MSE、双头音画）
条件       Qwen3-VL 第 50 层 + 语言关系（IR）
压缩       双 VAE（视觉 f16t4d24 + 音频 32kHz→40Hz）
系统       IR（托管）→ Base 768p（开源）→ Regen 2K（托管）
```

所以：**H3 是 flow 系生视频，外加音画同环和任务语言化；不是「整个 App 等于一个 diffusion」。**

## 4. 选型（只问三件事）

1. **出帧核是 D 还是 E，还是 C？** 决定采样旋钮（步数 / shift / 有没有 CFG）、训练目标、能不能套图像 DiT 的蒸馏经验。
2. **音频在不在同一个去噪环？** 不在，口型就是后处理问题；在，序列账和 loss 加权就要按音画两套 \(t\) 算。
3. **任务是专家网还是语言+参考 pack？** 决定你微调打在哪、缺的是权重还是前置 caption/IR。

后端成本不看型号看公式：\(\text{代价} \propto \text{步数} \times n^2\)（全注意力）或 token 步数（自回归）。\(n\) 由时长 × 分辨率 × VAE 压缩比定死——这是 [视频生成详解 §4](./视频生成详解.md) 和 [环节 03](./环节03-双VAE详解.md) 同一笔账。

## 5. 面试可以怎么答（30 秒）

生视频主核从 GAN 短 clip，走到给文生图 UNet 加时间层，再走到 **3D VAE + DiT 整段去噪**；2025 之后开源主核大量改成 **flow matching**。旁支是把视频写成离散 token，以及动作条件下一帧的世界模型。现在产品差距更多在：**压缩比、音画是否同环、条件是专家网还是语言关系、2K 怎么来**，而不是再发明一种全新骨干。
