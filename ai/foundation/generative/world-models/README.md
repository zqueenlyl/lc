# World Models · 世界模型

> 学习一个环境的 **状态如何随动作演化**（下一帧、下一物理状态、下一网页 DOM），用来规划、模拟、生成，而不只是预测下一个文本 token。

代表：游戏 / 机器人里的世界模型、视频生成当可交互模拟（Genie 类）、自动驾驶仿真、部分「空间智能」叙事。仍比 Chat 更前沿、更碎片。

配套 MVP：[mvp.py](./mvp.py)（格子世界 + 学到的转移表做规划）。

---

## 一、技术讲解

LLM 擅长符号与语言。机器人、自动驾驶、游戏 AI 还要回答：

> 如果我现在向右转，3 秒后障碍物在哪？

世界模型 `s' ≈ f(s, a)`：

- **s**：图像、隐向量、物体状态、网页结构；
- **a**：关节扭矩、方向盘、键盘、点击；
- **f**：神经网络、或神经 + 物理引擎混合。

和 [Diffusion](../diffusion/) 生视频的差别：生视频可以只求「好看」；世界模型要求 **动作条件化、时间一致、可用来规划**。和强化学习的关系：真实环境采样贵，先在模型里 roll-out 再实机（Dyna、MuZero 思想的现代表亲）。

2026 年仍未统一成「一个 API」：有的是视频生成器硬充模拟器（物理常穿帮），有的是机器人公司内部仿真，有的是游戏神经引擎。

---

## 二、功能作用

- **规划**：在想象里试多条轨迹，再执行一条。
- **数据倍增**：仿真里练策略，减少实机小时。
- **预测性 UI**：预演「用户点完会怎样」。
- **生成**：可交互世界，而不只是一段固定视频。

---

## 三、应用场景

| 领域 | 状态 | 动作 |
|---|---|---|
| 机器人抓取 | 关节 + 物体位姿 / 像素 | 末端轨迹 |
| 自动驾驶 | BEV / 占用网格 | 转向与加速度 |
| 游戏 NPC | 关卡潜变量 | 按键 |
| 运维演练 | 服务拓扑 | 扩缩容（谨慎：仿真保真） |
| 科研 | 分子 / 气候粗模 | 干预 |

不适合当：企业问答的第一选择（用 RAG / Agent）；高精度安全关键闭环若仿真误差大，必须实机校验。

---

## 四、保真度是核心指标

- 短时预测准 ≠ 长时 roll-out 不崩。
- 视觉像 ≠ 物理对（穿透、能量不守恒）。
- 规划器用错模型会 **自信地撞墙**——要有真实环境的校正环。

## 六、落地建议

1. 先定义 **状态与动作的最小接口**，再选网络。
2. 报告短时误差 **和** 长时散度，不要只秀生成视频。
3. 安全关键域：模型提案 + 规则 / 控制屏障过滤。
4. 和真实日志对齐（离线 RL / 模仿学习），防仿真过拟合。
5. 产品叙事上区分「能玩的生成世界」和「能签责任的控制器」。

## 八、本目录 MVP

`mvp.py` 实现 5×5 格子、墙和目标。先用随机探索估计 P(s'|s,a)，再用该模型 BFS 出一条路径，最后在真实格子上执行，对比「想象」与「实际」。
