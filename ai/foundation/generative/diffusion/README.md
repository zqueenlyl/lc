# Diffusion · 扩散生成

> 从噪声一步步 **去噪** 得到图像 / 视频 / 音频 / 潜空间样本。2024–2026 仍是可控媒体生成的主路径（文生图、视频、设计稿、部分 3D / 分子）。

代表：Stable Diffusion 系、Flux、视频扩散 / DiT、音频扩散；产品侧 Midjourney、可灵、Sora 类（实现细节各异，很多是扩散或流匹配近亲）。

配套 MVP：[mvp.py](./mvp.py)（一维信号上的 DDPM 风格前向加噪 + 学习到的线性去噪器）。

---

## 一、技术讲解

生成式两条大路：自回归（下一个 token）与 **连续/离散扩散**（或 Flow Matching）。

扩散训练：

```
x0（图）→ 按时间步 t 加噪 → xt
模型学：从 xt 预测噪声 ε 或直接预测 x0
```

采样：从纯噪声 xT 出发，反复去噪到 x0。步数从早期 1000 降到蒸馏后的 1–8 步（一致性模型、蒸馏）。

潜空间扩散（LDM）：先 VAE 把图压到 latent，再在小地图上扩散，省算力。条件：文本 embedding、边缘图、姿态、上一帧（ControlNet / 视频）。

和 LLM 的关系：文本编码器（CLIP / T5 / LLM）提供条件；多模态大模型理解图，扩散负责 **高保真像素合成**。二者经常一个产品两套模型。

---

## 二、功能作用

- **高维连续生成**：像素、波形、点云，比纯离散 token 更自然。
- **可控**：文、图、深度、姿态、遮罩局部重绘。
- **多样**：同一提示可采样多张。
- **编辑**：img2img、inpaint、视频延展。

## 三、应用场景

| 场景 | 条件 |
|---|---|
| 设计 / 广告出图 | 文 + 品牌 LoRA / IP-Adapter |
| 产品换背景 | 遮罩 inpaint |
| 短视频 / 分镜 | 文或首帧 |
| 游戏贴图 / 概念图 | 图生图 |
| 语音增强 / 音乐 | 音频扩散 |
| 科研（分子、医疗重建） | 强约束与专家评测 |

版权、肖像、虚假信息是产品必须配套的治理，不是模型附赠。

## 四、和自回归怎么选

| | 扩散 | AR（LLM / 图像 AR） |
|---|---|---|
| 文本逻辑 | 弱，靠编码器 | 强 |
| 像素保真 | 强 | 看 tokenizer |
| 延迟 | 多步迭代，可蒸馏 | 按 token |
| 局部编辑 | 天生友好 | 较差 |

系统里常见：LLM 写分镜 → 扩散出图。

## 六、落地建议

1. 产品先锁 **分辨率、步数、负面提示、安全过滤器**。
2. 要稳用图生图 / ControlNet，少赌纯文生图文字渲染。
3. 风格定制用 LoRA，比继续预训练快。
4. 视频成本按秒计，先短再长，注意时间一致性评测。
5. 记录 prompt + seed + 模型版本，否则无法复现客诉图。

## 八、本目录 MVP

`mvp.py` 在长度 8 的一维「信号」上：前向加噪、用闭式线性去噪器（演示 ε 预测思想）逐步还原，打印几个 t 的 L2 误差。帮助建立「加噪 ↔ 去噪」直觉，不是生产级采样器。
