# Video · 视频生成

> 一句话：**视频生成 ≈ 图像扩散 + 时间维**——把「图 + 时间」打成时空 patch，用 3D VAE 压到潜空间，在 DiT 上做扩散 / 流匹配；难点从「画得好看」变成「**帧间一致 + 运动合理 + 成本低一个量级**」。
>
> 原理详解（视频为什么难 / 时空 patch / DiT 主路线 / 成本账 / 面试题）见 [视频生成详解.md](./视频生成详解.md)。

本目录是生成侧「时间维」专题，前置必读扩散数学底座 [../diffusion/](../diffusion/)；模态全景见 [../00-AIGC总揽与多模态地图.md](../00-AIGC总揽与多模态地图.md)；音频同期声见 [../audio-speech/](../audio-speech/)。

## 一、技术讲解

三条与图像生成的本质差异：

| 差异 | 后果 |
|---|---|
| **时间维要建模** | 帧间必须一致，不能每帧独立生成 |
| **序列长度爆炸** | 视频 token 数 ≈ 帧数 × 单帧 patch 数，注意力成本急剧上升 |
| **数据更贵更少** | 高质量带标注视频远少于图文对 |

主路线：**3D VAE 压缩 → 时空 patch → DiT（Diffusion Transformer）去噪 → 时空解码**。理解视频生成，本质上是在理解「同一条扩散公式换了个更高维的 latent」。

---

## 二、功能作用

- **文生视频**：文字 → 片段，按镜头选模型。
- **图 / 首尾帧生视频**：给定关键帧做插值或延展，可控性更高。
- **视频编辑 / 延展**：局部重绘、时长延长、风格迁移。
- **世界模型雏形**：预测「下一帧」，是具身 / 仿真的技术底（见 [../world-models/](../world-models/)）。

---

## 三、应用场景

| 场景 | 要点 |
|---|---|
| 广告片头 / 动态素材 | 短、可控、风格一致 |
| 短视频 / 分镜预演 | 首帧 + 提示词，快速试错 |
| 电商产品演示 | 多参考图一致性 |
| 影视后期 | 控制与工作流（不只一条生成） |

---

## 四、工程要点（后端直用）

1. **异步 + 队列**：视频是分钟级任务，提交 → 排队 → 轮询 / SSE 进度 → 结果存储，绝不同步阻塞 HTTP。
2. **按帧计成本**：成本 ≈ 帧数 × 单帧图像成本，先短再长。
3. **锁版本 + 灰度**：模型升级必跑回归（时间一致性 / 风格漂移）。
4. **内容审核在服务端**：深度伪造、肖像、版权是硬约束（见 [guardrails](../../../reliability/guardrails/)）。
5. **评测分两层**：单帧质量（图像指标）+ 时序一致性 + 文本对齐 + 主观评分。

## 六、落地建议

1. **按镜头类型选模型**，2026 没有全能冠军，别绑单一供应商。
2. **先图后视频**：出图链路跑顺了，再上时间维，素材可复用。
3. **成本从第一天按帧算**，并配降级链（低质快 / 高质慢）。
4. **合规前置**：训练数据版权、真人肖像、深度伪造，商用前过法务。
