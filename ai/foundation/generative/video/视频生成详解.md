# 视频生成详解（= 图像扩散 + 时间，DiT 主路线）

> **定位**：文生视频（Sora / 可灵 / Veo / Vidu）是图像生成的"加时间维"变体——把每一帧当一张图同时生成，额外要求**帧间连续一致**。先读 [图像扩散模型详解.md](../diffusion/图像扩散模型详解.md)（本篇所有扩散概念直接复用），本篇专注"时间维怎么加"与"成本工程"。

---

## 1. 视频为什么难（相比单帧图像）

| 问题 | 具体表现 |
|---|---|
| 空间质量 | 单帧要清晰（≈ 图像质量） |
| **时间一致性** | 物体不闪变/不突变：帧间身份、纹理、光照连续 |
| 运动自然性 | 符合物理（重力/遮挡/接触）、动作连贯不漂移 |
| 时长与分辨率组合 | 每增加 1 秒 ≈ 多 24~30 帧，数据/算力/显存全线性涨 |

本质：**视频 = 时间轴上的强一致约束**。逐帧独立生成必然闪烁断裂，所以必须让模型"一次看整段"并显式建模时间。

## 2. 关键设计：把时间塞进"patch"

统一视角：视频是 **T×H×W 的 4D 张量**（帧×高×宽×通道）。所有主流路线都在做同一件事——**把 4D 切成 patch，让 patch 带上时间维**：

| 方案 | 做法 | 代表 |
|---|---|---|
| 逐帧生成 + 后处理 | 每帧独立图像模型 + 光流/插值 | 早期，废弃 |
| 图像模型 + **时间层** | 复用在 2D 空间训练好的模型，在帧维插 temporal attention/conv | 老一代（AnimateDiff 思路） |
| **时空 patch（3D patch）** | 立方体切块当 token（如 16×16×几帧），扩散在视频 VAE 潜空间跑 | Sora 系 / 可灵 / Veo |
| 自回归帧预测 | 把视频当"帧 token 序列"逐段预测（世界模型系） | 视频生成另一支 |

**视频 VAE（时空压缩）**：把图像 VAE 扩展成"时间上也有压缩"——空间下采样 ~8×、**时间下采样 4~8×**（几帧合成一个 latent 帧）。作用：① 显存/算力大降；② latent 的"帧"天然包含多帧运动信息，时间建模在低维空间做。

## 3. 主路线：DiT 上做视频扩散

与图像 DiT 完全同构，只是 patch 换成时空 patch、噪声是"整段视频的 latent"：

```
文本/首尾帧/镜头条件 ──► 条件注入（cross-attn / adaLN）
噪声视频 latent ──► DiT（spatial-temporal patch → attention）──逐步去噪──► 视频 VAE Decode ──► 帧序列
```

- 训练策略（对齐现实）：**联合图 + 视频**训练（图像 = 单帧视频，视频学习运动、图像保持质量）；视频数据量稀缺 → 多为"图像数据打底 + 视频数据补运动"
- 时长生成：一次性全 latent 生成 vs 分段续生（clip 追加）；主流做"视频延续"解决超长时长
- 可控：prompt 描述动作/镜头 → 首尾帧控制（可灵）→ 相机运动/轨迹/多视角

**自回归视频系（对照）**：把视频离散成帧/时空 token 逐段预测（如视频 VQGAN token + LLM/扩散混合）。好处是能借用文本自回归设施与"世界模型"式条件推理；坏处是逐帧误差累积 + 生成慢。2026 现实是**扩散视频在画质/一致性领先，自回归系在"条件/交互可控"侧探索**。

## 4. 成本：为什么视频贵一个量级

数量级估算（以 720p、24fps、DiT patch 16 计，纯示意）：

| | 单帧 token 数 | 1 秒 token 数 | 说明 |
|---|---|---|---|
| 文本 | — | ~10³ token/s | 参照系 |
| 视频 | 1280×720/16² ≈ 3.6k /帧 | ×24 帧 ≈ **~8.6×10⁴ token/s** | 快两个数量级 |
| 图像 | 1024²/16² = 4k | — | 一张 4k token |

加上去噪要迭代 N 步 × 这个量级，再叠 VAE 编解码 → **1 秒视频 ≈ 几十倍图像单张成本、几分钟生成时长**是常态。

## 5. 工程要点（后端直用）

1. **必须异步**：分钟级任务 → 任务队列 + SSE 进度（阶段：排队 → 前处理 → 生成 x% → 后处理）；超时/断线重试要有任务态
2. **分级模型 + 配额**：低质快（短/低分辨率）/高质慢（长/高分辨率）路由；按时长/分辨率计费与配额
3. 重复镜头可复用：prompt+seed+长度 hash 缓存；模板库预生成
4. 后处理链：审核（帧采样 + 模型）→ 超分/插帧 → 拼接 → 加水印 → 转码 CDN
5. 一致性坑：CFG 过高会让视频"过拟合 prompt"产生闪烁；长视频要监控"身份漂移/物体变形"
6. 流式播放：边生成边出低清预览（首帧/前几秒），提升体验

## 6. 面试高频追问

1. **视频比图像难在哪（一句话）？** 多一个时间维的强一致性约束——逐帧独立会闪烁，所以要用时空 patch/3D VAE 把时间写进表示。
2. **视频 VAE 为什么要在时间上压缩？** 4D 数据量爆炸；时间压缩让 latent 帧携带多帧运动信息，显存/算力可控。
3. **为什么很多视频模型拿图像模型初始化/联合训练？** 视频数据远少于图像；图像提供空间质量与语义，视频数据只负责"补运动"。
4. **文生视频为什么这么贵？** 每秒 ≈ 30 帧级 token × 去噪步数 × 模型规模，比文本高 1~2 个数量级，且逐任务串行（生成不可增量缓存）。
5. **DiT vs 自回归做视频？** DiT 一次性建模整段时空 latent，画质/一致性领先；自回归可逐段条件可控但误差累积。趋势是混合与"扩散 + 世界模型"。
6. **怎么评估视频生成好坏？** 单帧质量（图像指标）+ 时序一致性（帧间相似/运动忠实）+ 文本对齐 + 主观评分；自动化难，常需人评。
