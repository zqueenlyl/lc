## 0. 一句话定位

**策略梯度 = 让"拿到高分的那些动作"更可能发生。**

```
值方法：  先学会打分  → 再 argmax 导出策略          （打分是主角）
策略方法：直接把策略参数化 π_θ(a|s)，对"期望回报"求梯度 （策略是主角）
```

两种写法的差别不在于"估不估价值"，而在于**最后一步导出的东西**：

| | 值方法 | 策略方法 |
|---|---|---|
| 学什么 | `Q(s,a)` | `π_θ(a\|s)` 的概率参数 |
| 输出 | 确定性（argmax） | **概率分布**（可采样、可探索、可多解） |
| 动作空间大时 | 要比较 10⁵ 个 Q 值 | 一次算 10⁵ 个 logits 的自然延伸 |
| 梯度可导吗 | argmax 不可导 | 概率分布**处处可导** |
| LLM 适用性 | 几乎不适用 | **主线**（全部对齐算法） |

---

## 1. 为什么必须走策略方法（四条硬理由）

1. **需要随机策略本身**：石头剪刀布的最优策略是"1/3 均匀随机"。值方法给的是 argmax（确定性），表达不了"最优解就是随机"。
2. **argmax 不可导**：想端到端优化"最终回报"，中间夹一个 `max` 就没法反向传播。
3. **值误差会被 argmax 放大**：Q 估计的小误差可能让 argmax 选到完全不同的动作（策略对参数敏感但不连续）。
4. **LLM 需要的正是一个"好分布"**：温度、多样性、可探索性、多候选排序，全部要求模型输出概率。**只给你 argmax 的模型在语言任务上没有价值**。

> 记住第 4 条：它解释了为什么 LLM 对齐从 RLHF 到 GRPO 一路都是策略方法，`critic` 只是被顺手借来当一个"基线估计器"。

## 2. 目标函数：期望回报对策略参数求导

把策略参数化（LLM 里就是模型本身），目标是"在策略 π_θ 下的期望回报"：

```
J(θ) = E_{τ ~ π_θ} [ R(τ) ] = Σ_τ P(τ; θ) · R(τ)
```

难点：**期望是对"策略自己产生的分布"求的**——策略一变，数据分布就变（这是 RL 与监督学习最大的数学差别）。所以不能简单地把 R 当常数求导。

---

## 3. 核心推导：似然比技巧（Likelihood Ratio Trick）

**第一步**：把"对概率求导"改写成"对 log 概率求导"（一个恒等式，是全部推导的支点）。

```
∇_θ P(τ;θ) = P(τ;θ) · ∇_θ log P(τ;θ)        # 因为 ∇log f = (∇f)/f
```

**第二步**：代入目标函数，期望的形式立刻出来了。

```
∇_θ J(θ) = Σ_τ ∇_θ P(τ;θ) · R(τ)
         = Σ_τ P(τ;θ) · ∇_θ log P(τ;θ) · R(τ)
         = E_{τ ~ π_θ} [ ∇_θ log P(τ;θ) · R(τ) ]        # ← 用采样就能估！不需要知道所有 τ
```

**第三步（最妙的一步）**：展开 `log P(τ;θ)`，看**哪些项含 θ**。

```
P(τ;θ) = p(s₀) · Π_t π_θ(a_t|s_t) · Π_t p(s_{t+1}|s_t,a_t)
          ↑不含θ     ↑含θ（策略）          ↑不含θ（环境动力学）

∇_θ log P(τ;θ) = Σ_t ∇_θ log π_θ(a_t|s_t)
                 └── 环境项与初始状态项的梯度全为 0，被彻底消掉 ──┘
```

**结论（策略梯度定理）**：

```
∇_θ J(θ) = E_{τ ~ π_θ} [ Σ_t ∇_θ log π_θ(a_t|s_t) · R(τ) ]
```

三点解读，每一点都很重要：

1. **环境模型完全消失**：`p(s'|s,a)` 一项不剩 —— 这就是"无模型 RL"的数学根源。**你不需要知道世界怎么运作，只要知道你选的动作概率是多少、最后拿了多少分**。LLM 场景天然完美契合：不需要"语言环境的转移概率"这种东西。
2. **只对"实际选过的动作"有梯度**：对 softmax 策略，`∇_θ log π_θ(a|s) = onehot(a) − π_θ(·|s)`；没被采样到的动作，其 log 概率根本没进公式。
3. **R(τ) 是权重**：回报高的轨迹，其动作概率被推高；回报低的轨迹，动作概率被压低。**RL 的全部语义就这一句。**

**第四步：因果性（causality）**——第 t 步的动作不该为"它之前"的奖励负责，也不该被"它之后才发生"的延迟掩盖：

```
∇_θ J(θ) = E[ Σ_t ∇_θ log π_θ(a_t|s_t) · G_t ]        # G_t = 从第 t 步起的回报（去掉之前的奖励）
```

这就是 **REINFORCE**（Williams, 1992）。

---

## 4. REINFORCE 的现实问题

```
REINFORCE 更新：  θ ← θ + α · G_t · ∇_θ log π_θ(a_t|s_t)
                    （所有 t 累加）
```

| 问题 | 后果 |
|---|---|
| **方差极大** | 不同任务/不同 prompt 的绝对回报量级天差地别；一条轨迹的随机性全进来 |
| **必须等回合结束** | 没法在线更新；长任务（Agent 几十步）几乎不可用 |
| **信用分配粗糙** | 整段一个 `R`，同一段里所有 token 共享同一个权重——**一步错和九步对拿到的梯度权重一样** |
| **需要大量采样** | 方差 ∝ 奖励尺度的平方，收敛慢得离谱 |

> **LLM 的 RLVR 之所以能 work，正是因为绕开了前两条**：奖励来自验证器（0/1，尺度标准化好了）、而且用 **组内相对优势**（GRPO）把"绝对回报"换成了"相对排名"（→ [环节 07](./环节07-GRPO与RLVR详解.md)）。

---

## 5. 基线：减去一个"平均水位"（方差削减的正统手段）

**做法**：把 `G_t` 换成 `G_t − b(s)`，其中 `b(s)` 不依赖动作：

```
∇_θ J = E[ Σ_t ∇_θ log π_θ(a_t|s_t) · (G_t − b(s_t)) ]
```

**为什么不会引入偏差**（必须会证，面试常问）：

```
E_{a ~ π} [ ∇_θ log π_θ(a|s) · b(s) ]
   = b(s) · Σ_a π_θ(a|s) · ∇_θ log π_θ(a|s)        # 对动作求期望
   = b(s) · Σ_a ∇_θ π_θ(a|s)                        # 用 ∇π = π∇logπ 反代回去
   = b(s) · ∇_θ ( Σ_a π_θ(a|s) )                     # 梯度与求和可交换
   = b(s) · ∇_θ 1 = 0                                # 概率归一化 → 常数 1 → 梯度 0  ∎
```

**结论：任何只依赖状态的函数都可以安全地减掉，期望梯度完全不变，但方差显著下降。**

**语义转变**（这是全专题最重要的一次语义升级）：

```
R（回报）        →  "这条轨迹拿了多少分"          （绝对好坏，噪声大）
A = G − b（优势）→  "比平均水平好多少"            （相对好坏，噪声小）
```

> **优势函数 A（advantage）从此登场**，后面 PPO / GRPO 的目标函数里那个 `A` 就是它。最优基线之一就是 `b(s) = V^π(s)`，此时 `A = Q^π(s,a) − V^π(s)`，正好是 [环节 02](./环节02-值方法与DQN详解.md) 里 Q 与 V 的差。

**实测方差削减（三臂老虎机，均匀初始策略，20 万次采样，§10 复现）**：

| 基线 b | `E[‖g‖²]` | `‖E[g]‖²`（真实信号） | 方差 | 相对方差 |
|---|---|---|---|---|
| **0（无基线）** | 0.3332 | 0.0198 | 0.3134 | 1.00 |
| **0.5（= E[R]，理论最优）** | 0.1667 | 0.0201 | **0.1465** | **0.47** |
| 0.8（偏的基线） | 0.2265 | 0.0199 | 0.2066 | 0.66 |

**读表**：三行的"真实信号" `‖E[g]‖²` 几乎完全相同（≈0.0198）→ **无偏性得到验证**；而方差从 0.3134 降到 0.1465（**降到 47%**）。用偏的基线（0.8）也有效（降到 66%），但不如正确基线好。

> 记忆点：**基线只降方差、不改方向**。这就是 GRPO 敢用一个"组内均值"当基线的理论许可（→ [环节 07](./环节07-GRPO与RLVR详解.md) §2）。

## 6. Actor-Critic：用 critic 网络估基线

上一步的最优基线 `V^π(s)` 是未知的 → **用神经网络学一个出来**。这时框架变成两个角色：

```
Actor  （演员）= π_θ(a|s)     —— 负责"演"，被梯度更新
Critic（评论家）= V_φ(s)      —— 负责"评"，也通过 TD 学习（环节 02 的 TD 误差）
```

**用一步 TD 误差当优势估计**（最常用、最低方差）：

```
A_t ≈ δ_t = r_t + γ·V_φ(s_{t+1}) − V_φ(s_t)
```

**这个式子把三个环节串起来了**（务必体会）：

```
[环节 02] TD 误差 δ = r + γV(s') − V(s)          —— 值方法的产物
      ↓ 当作优势
[环节 03] ∇J = E[ ∇log π · A ]                    —— 策略方法的目标
      ↓ 加"别改太猛"的约束
[环节 04] PPO 的 clip 目标                        —— 让上面的更新稳定可复现
```

**代价与收益**：

| | REINFORCE（用完整回报 G） | Actor-Critic（用 δ） |
|---|---|---|
| 偏差 | 无偏 | **有偏**（δ 里含 critic 的估计误差） |
| 方差 | 很大 | 小（critic 误差不随轨迹长度累积） |
| 能否在线 | 不能（要等回合结束） | **能**（每步拿到 r 就能更新） |
| 多一个网络 | 无 | 多一份 critic（显存 + 训练成本） |

> 权衡的钥匙：**critic 估得越准，偏差越小**；但 critic 也在学，学得不好就"带偏"。这一对矛盾是 RL 工程稳定性的核心，也解释了为什么 **GRPO 干脆不要 critic**（用组内同伴当基线，无偏、零成本）——**代价是必须能采样到一组可比较的回答**（→ [环节 07](./环节07-GRPO与RLVR详解.md)）。

**A2C / A3C**：A2C 是"同步版 Actor-Critic"（一批 worker 采数据 → 一起更新）；A3C 是"异步版"（各 worker 独立更新全局参数）。今天只剩历史意义——现代实现（PPO）都是同步、批量的。

## 7. GAE：把"偏差-方差"做成一个可调旋钮

一步 TD 误差（λ=0）偏差大；完整回报（λ=1）方差大。**GAE（Generalized Advantage Estimation）用指数加权把所有多步估计平均起来**：

```
δ_t = r_t + γ·V(s_{t+1}) − V(s_t)                                   ← 单步 TD 误差

A_t^{GAE(γ,λ)} = δ_t + (γλ)·δ_{t+1} + (γλ)²·δ_{t+2} + …  =  Σ_{l≥0} (γλ)^l · δ_{t+l}
```

**实现上不用求和，用反向递推**（从轨迹末尾往前算，O(T)）：

```
A_t = δ_t + γλ · A_{t+1}         （A_T = 0，从后往前）
```

**两个端点的语义（用这张表记住 GAE）**：

| λ | 优势退化成 | 性质 |
|---|---|---|
| **λ = 0** | `δ_t = r_t + γV(s_{t+1}) − V(s_t)` | 高偏差、低方差、能在线 |
| λ = 0.95（PPO 常用） | 两者的加权折中 | 实践甜点 |
| **λ = 1** | `Σ γ^l r_{t+l} − V(s_t)` | 无偏、高方差（≈ MC 减基线） |

**γ 与 λ 是两个不同的旋钮，别混**（面试高频）：

- **γ**：奖励的时间折扣——"未来多远还算数"（LLM 取 1）；
- **λ**：对 critic 的信任浓度——"多信自举、多信实际回报"（PPO/GRPO 常 0.95）。

> GRPO / DAPO 等"无 critic"方法里 **GAE 直接不用了**：优势改成组内标准化 `A_i = (r_i − mean)/std`。这是"删掉 critic"带来的连锁简化之一。

## 8. 熵正则：防止策略过早变成"一根筋"

策略梯度只会强化"已知好的动作"，会让分布越来越尖（熵越来越小）→ 停止探索 → 卡在平庸解。于是加一项**熵奖励**：

```
H(π_θ(·|s)) = − Σ_a π_θ(a|s) · log π_θ(a|s)          # 熵：分布越均匀越大

总损失 = − L_policy − c₁·L_value − c₂·H(π_θ)         # 熵是要"奖励"的，所以带负号
```

- `c₂` 典型值 `0.01`（PPO）；太小 → 熵坍缩、提前收敛；太大 → 学不动；
- LLM 长思维链训练里熵坍缩是**头号故障**，DAPO 的 **Clip-Higher** 就是治它（→ [环节 07](./环节07-GRPO与RLVR详解.md) §4）。

## 9. 落到 LLM：逐 token 的策略梯度

把上面的符号换成语言模型的符号，就是 LLM 对齐的标准形式（→ 也是 [环节 09 训练管线](../transformer/环节09-训练管线详解.md) §3 的展开）：

```
状态 s_t   = prompt x + 已经生成的 token (y₁…y_{t−1})
动作 a_t   = 下一个 token y_t             （动作空间 = 词表）
策略 π_θ   = 语言模型本身：π_θ(y_t | x, y_{<t})  ← 就是 softmax 出来的那个概率
回报 R(τ)  = 整段回答的一个标量奖励（奖励模型打分 / 验证器结果）

∇_θ J(θ) = E[ Σ_{t=1}^{T} ∇_θ log π_θ(y_t | x, y_{<t}) · A_t ]
```

**四个 LLM 特有的实现要点**：

1. **只有被采样到的 token 有梯度**：`∇_θ log π_θ(y_t|·) = onehot(y_t) − π_θ(·|·)`，词表里其他 token 只是"被压低"的副作用。**所以 RL 的梯度极其稀疏**（每条样本只有 T 个有效项，而 T 相对词表很小）。
2. **A_t 怎么来是各算法的分水岭**：
   - 整段给同一个 `R`（最朴素）→ 信用分配最粗糙；
   - `A_t = R − V(s_t)`（PPO + critic）→ 逐 token 优势；
   - `A_t = (r_i − mean)/std`（GRPO，整段题级）→ 无 critic（→ [环节 07](./环节07-GRPO与RLVR详解.md)）。
3. **序列级 vs token 级损失归一化**：把整段的 token 梯度先求和再平均（序列级）会让**长回答的每条 token 梯度被稀释**；长思维链训练必须按 token 级归一化（DAPO 的 token-level loss，→ [环节 07](./环节07-GRPO与RLVR详解.md) §4）。
4. **重要性比 `ρ_t = π_θ(y_t|·)/π_old(y_t|·)`**：同一批 rollout 要更新多次时，必须按新旧概率比重加权——这个比就是 PPO 的 clip 对象（→ [环节 04](./环节04-信赖域与PPO详解.md)）。

## 10. 数值走查：三臂老虎机上的 REINFORCE（真实输出）

**设定**：3 个臂真实成功率 `p = [0.2, 0.5, 0.8]`；策略用 softmax 参数化 `π = softmax(θ)`；每次采样一个臂、拿 0/1 奖励、更新 `θ += α·A·∇logπ`；`α = 0.1`；3000 回合；5 个随机种子取平均。

**结果（真实运行输出）**：

```
REINFORCE（无基线）        收敛 π = [0.002  0.004  0.994]
REINFORCE + baseline      收敛 π = [0.002  0.005  0.993]
```

**读法**：

- 两条都收敛到"**几乎总是选臂 3**"（其真实成功率 0.8，是三个里的最优）→ **策略梯度真的会找到最优动作**，而且全程不需要知道 `p` 是多少；
- 两者的**收敛点一致** → 印证 §5 的结论：**基线不改变最优解，只改变到达速度与稳定度**；
- 差别体现在训练过程中的梯度噪声（§5 的方差表：0.3134 → 0.1465）。在更难的题上，这个差别就是"能收敛"与"训崩"的差别。

**可运行代码**（纯标准库）：

```python
import math, random
random.seed(7)

P = [0.2, 0.5, 0.8]                 # 三个臂的真实成功率（智能体不知道）
ALPHA, EPISODES = 0.1, 3000

def softmax(th):
    m = max(th); e = [math.exp(t - m) for t in th]
    s = sum(e); return [x / s for x in e]

def run(use_baseline):
    th, b = [0.0, 0.0, 0.0], 0.0
    for _ in range(EPISODES):
        pi = softmax(th)
        r, acc, a = random.random(), 0.0, 0
        for a, p in enumerate(pi):          # 按 π 采样一个臂
            acc += p
            if r <= acc: break
        R = 1.0 if random.random() < P[a] else 0.0
        adv = R - (b if use_baseline else 0.0)      # ← 基线在这里
        g = [(1.0 if i == a else 0.0) - pi[i] for i in range(3)]   # ∇logπ = onehot − π
        for i in range(3):
            th[i] += ALPHA * adv * g[i]             # θ ← θ + α·A·∇logπ
        b += 0.05 * (R - b)                         # 基线用运行均值估计
    return softmax(th)

print("无基线   ", [f"{p:.3f}" for p in run(False)])
print("有基线   ", [f"{p:.3f}" for p in run(True)])
# 都收敛到 ≈ [0.002, 0.005, 0.993]：把选择臂 3 的概率推到 ~1
```

## 11. 坑清单

1. **把 `∇log π` 与 `∇π` 搞混**：只对**被采样到的动作**有直接梯度；其他动作只被间接压低（`−π` 那一项）。这一点决定了 RL 梯度的稀疏性。
2. **忘记"R 是权重、不是目标"**：策略梯度不是"拟合 R"，而是"用 R 当系数放大/缩小动作概率"。所以奖励尺度的平移（加减常数）会改变方差但**不改期望**——这正是基线的合法性来源。
3. **基线写成"依赖动作"的东西**：`b(s,a)` 再减去就会引入偏差。基线必须**不依赖 a**。
4. **γ 与 λ 混为一谈**：γ 管"奖励折扣"，λ 管"多信 critic"。调参时是两件独立的事。
5. **熵正则开太猛/太小**：太小 → 熵坍缩、提前收敛到平庸解；太大 → 策略永远随机、学不动。
6. **在长序列上用序列级损失**：每条 token 的梯度被长度稀释，长思维链训不动（→ DAPO token-level loss）。
7. **以为"无 critic 一定更好"**：GRPO 免 critic 的前提是"能采到一组可比较的回答"；在奖励连续、组内无区分度的任务上，critic 反而更合适。
8. **只看回报曲线不看熵/优势分布**：策略梯度的故障（熵塌缩、优势全 0、KL 爆炸）**在回报曲线上往往是"平的"**，必须同时监控熵、优势标准差、KL（→ [RL选型与工程落地总表.md](./RL选型与工程落地总表.md) §4）。

## 12. 面试高频追问

1. **策略梯度定理怎么推出来的？** → 三步：`∇P = P∇logP`（似然比技巧）把梯度变成期望 → 展开 `log P(τ)` 发现**环境转移项不含 θ、梯度为 0** → 只剩 `Σ_t ∇log π(a_t|s_t)`。推论：**策略梯度天然无模型**，这是它适配 LLM 的根本原因。
2. **为什么可以减一个基线？** → 因为 `E_{a~π}[∇log π(a|s)] = ∇_θ Σ_a π(a|s) = ∇_θ 1 = 0`，任何只依赖状态的项的期望贡献都是 0；因此减掉它**不改变期望梯度**，只降方差。语义上把"绝对回报"变成"优势"。
3. **REINFORCE 与 Actor-Critic 的区别？** → 优势估计用什么：REINFORCE 用完整回报 `G_t`（无偏、高方差、要等回合结束）；AC 用 `r + γV(s') − V(s)` 自举（有偏、低方差、可在线）。
4. **GAE 是什么？λ 的作用？** → 用 `(γλ)^l` 对多步 TD 误差做指数加权：`A_t = Σ(γλ)^l δ_{t+l}`；λ=0 退化为单步 TD 误差，λ=1 退化为 MC 回报减基线。**λ 是"对 critic 的信任浓度"**，与奖励折扣 γ 是两回事。实现用反向递推 `A_t = δ_t + γλA_{t+1}`。
5. **为什么 LLM 的 RL 要逐 token 算优势？** → 因为整段只给一个标量奖励，若所有 token 共享同一个权重，就等于"哪一步的功劳都一样"，信用分配失效、长序列训不动。
6. **熵正则干什么？** → 奖励分布不要过早变尖（保持探索）。长 CoT 训练里的"熵坍缩"是头号故障，DAPO 的 Clip-Higher 就是专门治它。
7. **为什么策略梯度方差这么大？怎么降？** → 一条轨迹的回报噪声 + 动作随机性全进梯度。四个手段：基线/优势、critic 自举（GAE）、组内相对化（GRPO）、奖励标准化与裁剪。
8. **GRPO 为什么可以不要 GAE？** → 它的优势不走"逐 token 自举"路线，而是"同题一组回答的相对排名" `(r_i − mean)/std`——天然完成组内标准化，因此 critic 与 GAE 一并省掉。
