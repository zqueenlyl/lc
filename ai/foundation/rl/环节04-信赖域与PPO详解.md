## 0. 一句话定位

**PPO = 策略梯度 + 一句约束："新旧策略别差太远"。**

```
朴素策略梯度：  θ ← θ + α · A · ∇log π_θ           ← 方向对，但一步迈多大不设限
PPO：          在上面加一个"比率 ρ 只在 [1−ε, 1+ε] 内才被奖励"的机制
```

一句话记住它解决的问题：**策略梯度里最重要也最难调的超参不是学习率，而是"这一步把策略改成什么样"**——因为策略是概率分布，参数空间走一步 ≠ 分布变化一步。

---

## 1. 朴素策略梯度为什么不可靠：三个来源

### 1.1 步长敏感（根本原因）

我们在**参数空间**里走梯度，但真正影响性能的是**策略分布的变化**。两者尺度不同：

```
参数走了一小步  →  分布可能几乎没变（白跑）
参数走了一大步  →  分布可能崩坏（某些动作概率被压到 0 → 再也探索不回来 → 不可逆）
```

而且**坏的方向上走错不可逆**：`π(a|s)` 被压到接近 0 后，策略梯度再也采不到这个动作（截断了它自己的数据来源），等于永久放弃了这条路。

> 这解释了为什么 RL 里的"学习率"不是主要抓手：**需要的是"分布层面的步长控制"**，而这只能靠 KL / ratio 这类度量。

### 1.2 数据只能用一次（on-policy 的代价）

策略梯度是 on-policy 的：**用 π_old 采的数据，只能更新 π_old 附近的策略**。更新一次后数据就"过期"了（`A` 是旧策略下的优势，对新策略不再准确）。

想复用数据 → 必须做 off-policy 修正（乘重要性比）→ 引入方差。**PPO 的全部设计就是在"多用几次数据"与"别引入太多方差"之间取平衡。**

### 1.3 优势估计本身有噪声

`A` 来自 critic 或采样，是估计值。大步长会把估计噪声放大成策略漂移（→ 这就是 [环节 02](./环节02-值方法与DQN详解.md) §6 的"致命三难"在 LLM 对齐里的具体形态）。

---

## 2. 重要性采样：让"旧数据"能服务于"新策略"

**数学基础**（把"对新分布的期望"改写成"对旧分布的期望"）：

```
E_{x ~ p}[ f(x) ] = Σ_x p(x) f(x) = Σ_x q(x) · [ p(x)/q(x) ] · f(x) = E_{x ~ q}[ (p/q) · f(x) ]
```

在 LLM 的 token 上，`p = π_θ`（新策略）、`q = π_old`（采数据时的策略），比率为：

```
ρ_t = π_θ(y_t | x, y_{<t}) / π_old(y_t | x, y_{<t})
```

于是"用旧 rollout 更新新策略"的目标变成（**CPI：保守策略迭代**）：

```
L^{CPI}(θ) = E_t [ ρ_t · Â_t ]            # 一阶近似，ρ 偏离 1 越远越不可信
```

**致命问题：`ρ` 是无界的**。

- `ρ` 很大 → 乘上 `Â` 会产生巨大的正梯度 → 策略被一次推飞；
- **序列级的 `ρ` 是 token 级 `ρ` 的连乘**：`ρ_seq = Π_t ρ_t` → 随长度**指数级**放大或缩小。一个 1000 token 的回答，只要每个 token 的比率是 1.01，序列比率就是 `1.01^1000 ≈ 21000`。

> 这就是"为什么需要 clip"的全部动机：**不是为了让 `ρ` 接近 1 更准确，而是为了不让它把训练炸掉**。

---

## 3. TRPO：用 KL 约束把"信任域"写清楚

**想法**：别在参数空间限步长，直接在**策略分布空间**限步长。

```
max_θ  E_t [ ρ_t · Â_t ]
s.t.   E_t [ KL( π_old(·|s_t) ‖ π_θ(·|s_t) ) ] ≤ δ        ← 信任域（trust region）
```

- `δ` 典型 `0.01`；
- 理论上来自对性能差的单调改进保证（MM 算法）：只要 KL 够小，新策略的真实性能**不低于**替代目标给出的下界；
- 求解要**二阶信息**（Fisher 信息矩阵 / 自然梯度），用共轭梯度 + 线搜索 → **实现复杂、每步开销大、与深度学习框架不合拍**。

> TRPO 的贡献是**把问题说清楚了**：约束该加在"分布"上。PPO 的贡献是**用一个一阶技巧近似它**，于是全世界都能跑起来。

---

## 4. PPO：用 clip 一阶近似信任域

**PPO 的目标函数（记住这一行）**：

```
L^{CLIP}(θ) = E_t [ min( ρ_t · Â_t ,  clip(ρ_t, 1−ε, 1+ε) · Â_t ) ]
```

**为什么要 `min` 两层**：它是**悲观下界**——`L^{CLIP} ≤ L^{CPI}` 恒成立。含义是"**只在最保守的那个估计上做优化**"，于是：

- 如果某次更新看起来特别赚（`ρ` 偏离很远），PPO 假装它只赚 `(1±ε)` 那么多；
- 于是"把策略改远"**不再有任何额外收益**，模型自然地不会去改远。

**`Â>0` 与 `Â<0` 两个分支（面试必答）**：

| 情形 | 想让 `ρ` 往哪走 | clip 拦在哪 | 效果 |
|---|---|---|---|
| **`Â > 0`（好动作）** | 想**变大**（提高其概率） | `ρ > 1+ε` 封顶在 `(1+ε)·Â` | **Gradient = 0**：不再给"多改一点"的激励 |
| **`Â < 0`（坏动作）** | 想**变小**（降低其概率） | `ρ < 1−ε` 封底在 `(1−ε)·Â` | **Gradient = 0**：不再给"猛降一点"的激励 |
| 两分支之外 | — | 不额外惩罚 | 按 `ρ·Â` 正常走 |

> 注意最后一行（很容易误读）：**clip 只"取消激励"，从不"额外惩罚"**。例如 `Â<0` 且 `ρ` 变得很大（坏动作概率反而上升），梯度照常给（继续把它压下去）——PPO 不需要在这里加惩罚，因为 `ρ·Â` 变负已经天然惩罚了。

**三个关键参数**：

| 参数 | 典型值 | 调错的后果 |
|---|---|---|
| `ε`（clip 范围） | **0.1 ~ 0.2** | 太大 → 等价于没约束、策略突变；太小 → 学不动（GRPO 长 CoT 场景常用 0.2） |
| 一批数据更新几轮（`n_epochs`） | **1 ~ 4** | 太大 → `ρ` 漂离 1 很远、clip 大量触发、训练悄悄劣化 |
| `γ` / `λ`（GAE） | `γ=0.99~1.0`、`λ=0.95` | 见 [环节 03](./环节03-策略梯度与Actor-Critic详解.md) §7 |

> **PPO 的能力与代价**：它没有 TRPO 那样的单调改进保证（clip 只是"启发式近似"），但**实现简单、一阶、能吃 mini-batch、能与任何框架配合**。工程上"理论弱一点、能稳定跑起来"赢了——这是深度学习史上反复出现的模式。

## 5. 完整损失：PPO 一共产出三个东西

实现里 PPO 的损失是三段相加（前两段在 LLM 对齐里都保留）：

```
L = E_t [ L^{CLIP}(θ)  −  c₁ · L^{VF}(φ)  +  c₂ · H(π_θ) ]
         ↑ 策略        ↑ critic 回归      ↑ 熵奖励
         (Actor)          (Critic)          (探索)

L^{VF}(φ) = ( V_φ(s_t) − V_t^{target} )²       ← 值函数用平方误差回归
V_t^{target} = Â_t + V_φ(s_t)                   ← 用 GAE 反推"目标价值"
```

**KL 在 PPO-RLHF 里出现三次，位置完全不同（极易混淆，务必分清）**：

| 位置 | 形式 | 作用 |
|---|---|---|
| **① 奖励塑形里** | `r_t = r_θ(y_t) − β·KL(π_θ‖π_ref)` | 拴住**参考模型** π_ref（防语言退化 / 奖励黑客）→ [环节 05](./环节05-偏好对齐与RLHF详解.md) §4 |
| **② clip 里的 `ρ`** | `clip(ρ, 1−ε, 1+ε)` | 限制**新旧策略**之间的变化（信任域，本文主角） |
| **③ KL 早停阈值** | 监控 `KL(π_old‖π_θ)`，超过阈值就提前结束该批数据的更新 | 兜底：一旦跑偏就停止复用这批数据 |

> **① 与 ② 的 `KL` 不是同一个东西**：① 是相对**冻结参考模型**（管"别偏离 SFT太远"），② 是相对**上一版策略**（管"这一步别迈太大"）。混了就会在面试里答错。

## 6. 落到 LLM：token 级 PPO 长什么样

把 PPO 逐 token 展开，就是 RLHF / GRPO 实现里你真正能看到的东西：

```
对一条回答的每个 token t：
  ρ_t    = π_θ(y_t | x, y_{<t}) / π_old(y_t | x, y_{<t})         ← 逐 token 的比率
  Â_t    = GAE(δ_t, γ, λ)，δ_t = r_t + γV_φ(s_{t+1}) − V_φ(s_t)   ← 逐 token 的优势
  L_t    = min( ρ_t·Â_t , clip(ρ_t, 1−ε, 1+ε)·Â_t )

总损失 = − E_t[ L_t ] + c₁·E_t[(V_φ − V^target)²] − c₂·E_t[H_t]
```

**LLM 特色的四个工程点**：

1. **优势白化**：对一批内的 `Â` 做标准化（减均值除标准差）。因为不同 prompt 难度天差地别，不白化则"简单题的梯度"淹没"难题的梯度"。**GRPO 的组内标准化是它的极端形式**（→ [环节 07](./环节07-GRPO与RLVR详解.md)）。
2. **序列级 vs token 级比率**：`ρ` 按 token 算（上表），但**有些实现按整条序列算 `ρ_seq = Π ρ_t`**——后者方差随长度指数爆炸。**GSPO（Qwen 团队）正是把比率从 token 级改成序列级并做长度归一化，换来长序列训练的稳定**（→ [环节 07](./环节07-GRPO与RLVR详解.md) §4）。
3. **奖励只用一次**：整段回答只拿一个标量奖励 `r`，**逐 token 的 `r_t` 通常只在最后一个 token 上非零**（或每步加 KL 惩罚项）。
4. **rollout 与训练分离**：`π_old` 是采样时的权重。**采样阶段是推理负载（KV Cache 大头），训练阶段是训练负载**——显存峰值要同时扛住两套（→ [RL选型与工程落地总表.md](./RL选型与工程落地总表.md) §5）。

## 7. 实现细节与坑清单

| 细节 | 建议 | 为什么 |
|---|---|---|
| `n_epochs`（一批数据更新几轮） | **1~4** | 太多 → `ρ` 远离 1、clip 大量触发、悄悄劣化 |
| advantage 归一化 | 必做（per-batch 白化） | 不同 prompt 难度差异巨大 |
| value loss 的裁剪 | 可选（clip value） | 防 critic 单步跳太远 |
| KL 早停 | 建议开启 | 兜底手段，比调 `ε` 更直接 |
| **监控 `ρ` 的分布** | 看 clip 触发比例 | `clipfrac` 长期 >20% 说明步子太大或 `n_epochs` 太多 |
| 奖励裁剪 / 标准化 | 建议 | 奖励尺度不稳定会污染优势 |
| GAE 的 `γ` | LLM 用 1.0（回答必定终止） | 见 [环节 01](./环节01-RL基础与MDP详解.md) §2 |
| 熵坍缩监控 | 必须看 | 回报曲线平的、熵在掉 → 已经在收敛到平庸解 |

**出场顺序建议**（出问题时按这个顺序查）：

```
① 熵 / 优势标准差 / KL  →  判断"是不是根本没在学"
② clipfrac（ρ 被截断的比例） →  判断"是不是步子太大"
③ 奖励分布与长度分布     →  判断"是不是奖励信号本身有问题"
④ critic 的 value loss   →  判断"优势估计是不是在漂"
```

## 8. 数值走查：clip 到底在哪截断（ε = 0.2，真实计算）

取 `Â = +1`（好动作）与 `Â = −1`（坏动作），扫 `ρ`，计算 `L^CPI = ρÂ` 与 `L^CLIP = min(ρÂ, clip(ρ,0.8,1.2)·Â)`：

**`Â = +1`（想提高该动作概率）**：

| ρ | L^CPI | clip(ρ) | **L^CLIP** | 用哪一支 | dL/dρ |
|---|---|---|---|---|---|
| 0.5 | 0.50 | 0.80 | 0.50 | 未截断 | **1.0** |
| 0.8 | 0.80 | 0.80 | 0.80 | 未截断 | 1.0 |
| 1.0 | 1.00 | 1.00 | 1.00 | 未截断 | 1.0 |
| 1.2 | 1.20 | 1.20 | 1.20 | 未截断 | 1.0 |
| **1.5** | 1.50 | 1.20 | **1.20** | **已截断** | **0.0** |
| **2.0** | 2.00 | 1.20 | **1.20** | **已截断** | **0.0** |

**`Â = −1`（想降低该动作概率）**：

| ρ | L^CPI | clip(ρ) | **L^CLIP** | 用哪一支 | dL/dρ |
|---|---|---|---|---|---|
| **0.5** | −0.50 | 0.80 | **−0.80** | **已截断** | **0.0** |
| **0.7** | −0.70 | 0.80 | **−0.80** | **已截断** | **0.0** |
| 0.8 | −0.80 | 0.80 | −0.80 | 未截断 | −1.0 |
| 1.0 | −1.00 | 1.00 | −1.00 | 未截断 | −1.0 |
| 1.5 | −1.50 | 1.20 | −1.50 | 未截断 | −1.0 |
| 2.0 | −2.00 | 1.20 | −2.00 | 未截断 | −1.0 |

**三处必须看懂的结论**：

1. **上表 `ρ=1.5` 与 `2.0` 一行**：`L^CLIP` 被钉死在 `1.20`、**梯度变成 0** —— "把好动作概率猛推"这件事在目标里**完全失去了收益**。这就是"信任域"以一个减号实现的全部魔法。
2. **下表 `ρ=0.5`/`0.7` 一行**：`L^CLIP` 被钉在 `−0.80`（不是 `−0.50`）——注意它是**更负**的那个，即 `min` 选了封底分支。效果同样是**梯度 0**："猛降坏动作概率"失去额外收益。
3. **下表 `ρ=1.5`/`2.0` 一行没被截断**（梯度仍是 `−1`）—— 因为 `Â<0` 时 `ρ` 变大本身就让目标变负，**天然是惩罚，无需 clip**。很多面试者在这里答错，误以为"PPO 不惩罚坏动作"。

**可运行代码**（纯标准库，输出即上面两张表）：

```python
EPS = 0.2
clip = lambda x, lo, hi: max(lo, min(hi, x))

def L_clip(rho, A):
    unclipped = rho * A
    clipped = clip(rho, 1 - EPS, 1 + EPS) * A
    val = min(unclipped, clipped)
    grad = A if val == unclipped else 0.0      # min 选中哪一支，梯度就是哪一支
    return unclipped, val, grad

for A in (1.0, -1.0):
    print(f"===== Â = {A:+.1f} =====")
    for rho in (0.5, 0.8, 1.0, 1.2, 1.5, 2.0):
        u, v, g = L_clip(rho, A)
        print(f"ρ={rho:.1f}  L^CPI={u:+.2f}  L^CLIP={v:+.2f}  dL/dρ={g:+.1f}"
              f"  {'← 梯度被截断' if g == 0 else ''}")
```

## 9. 面试高频追问

1. **PPO 要解决什么问题？** → 策略梯度的步长问题：参数空间走一步 ≠ 分布变化一步，且压到 0 的动作不可逆。PPO 用 `clip(ρ,1−ε,1+ε)` 把"新旧策略变化"限制在一阶可达的信任域内。
2. **为什么需要重要性采样？`ρ` 是什么？** → on-policy 数据只能用一次，想复用就必须把"对新策略的期望"改写成"对旧策略的期望"，比率 `ρ=π_θ/π_old` 就是修正因子。`ρ` 无界 → 序列级还是连乘 → 必须 clip。
3. **`min(ρÂ, clip(ρ)Â)` 里 min 的作用？** → 构造 **悲观下界**（`L^CLIP ≤ L^CPI`）：只在保守估计上优化，从而"把策略改远"没有任何额外收益。
4. **`Â>0` 与 `Â<0` 时 clip 分别拦哪边？** → `Â>0` 拦上界（`1+ε`，不让好动作概率涨太猛）；`Â<0` 拦下界（`1−ε`，不让坏动作概率降太猛）。**clip 只取消激励，从不额外惩罚**。
5. **PPO 和 TRPO 的关系？** → 同一个约束（KL 信任域）的两种实现：TRPO 用二阶（Fisher + 共轭梯度 + 线搜索），PPO 用一阶 clip 近似。PPO 理论保证更弱但能跑。
6. **PPO 里的 KL 出现在哪几个地方？** → 三处：①奖励塑形里的 `−β·KL(π_θ‖π_ref)`（拴参考模型）；②`clip(ρ)`（拴上一版策略）；③KL 早停阈值。**前两个不是同一个 KL**。
7. **clip 的 `ε` 怎么选？** → 0.1~0.2。太小 → 学不动；太大 → 约等于无约束。配合监控 `clipfrac`：长期 >20% 就该降 `ε` 或 `n_epochs`。
8. **为什么一批数据不能反复更新很多轮？** → 每多一轮，`ρ` 就再偏离 1 一点，clip 大量触发后梯度要么为 0（白跑）要么方向已经失真（悄悄劣化）。所以 `n_epochs` 一般 1~4，并配 KL 早停。
9. **PPO 在 LLM 对齐里为什么被 GRPO 取代？** → PPO 要养 4 个模型（策略/参考/奖励/critic），显存与不稳定都很贵。GRPO 用"同题组内相对优势"顶掉 critic → 省一份完整模型副本，且天然适配可验证的 0/1 奖励（→ [环节 07](./环节07-GRPO与RLVR详解.md)）。
