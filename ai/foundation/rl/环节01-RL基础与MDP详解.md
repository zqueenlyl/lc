## 0. 一句话定位

**强化学习 = 在"没有标准答案、只有一个分数"的世界里，靠试错找到拿分策略。**

三者的差别一句话说清：

| 范式 | 数据 | 反馈 | 目标 |
|---|---|---|---|
| 监督学习 | `(x, y)` 成对 给定 | **告诉你正确答案** | 拟合 `y` |
| 无监督学习 | 只有 `x` | 无 | 找结构 |
| **强化学习** | **自己采样出来的轨迹** | **只告诉你多少分** | **最大化累计分数** |

RL 的两个额外难点（也是它比监督学习难的全部原因）：

1. **反馈是延迟的**：这步走得好不好，可能要 40 步之后才知道（下棋、写完整段代码、跑完一次 Agent）；
2. **数据是自己产生的**：数据分布随策略变化（策略一变，采样到的数据就变了），所以不能像监督学习那样"先攒数据再离线拟合"。

> 这两点对应 RL 的两个核心概念：**信用分配**（延迟奖励怎么归因到每一步）与**分布偏移**（策略/数据互相追赶，训练不稳定）。本专题后面每一篇，本质都在应对这两件事。

## 1. 怎么干：MDP 五元组

把"与环境交互"形式化成**马尔可夫决策过程（Markov Decision Process, MDP）**：

```
MDP = (S, A, P, R, γ)

S  状态集合 state
A  动作集合 action
P  状态转移概率 P(s' | s, a)      # 环境规则
R  奖励函数     R(s, a, s')        # 环境的打分
γ  折扣因子     0 ≤ γ ≤ 1          # 越远的奖励打多少折
```

另外一条隐含假设叫**马尔可夫性**：**"下一步只取决于当前状态和动作，与更早的历史无关"**。写成公式：

```
P(S_{t+1} | S_t, A_t) = P(S_{t+1} | S_0, A_0, …, S_t, A_t)
```

> 这个假设是 RL 能用的原因（状态 = 压缩后的全部历史），也是它最容易翻车的地方。**状态设计不好（把历史信息丢了）→ 学不出来**。LLM 里这个问题被"prompt + 已生成的全部 token"直接解决：**上下文就是状态**，天然满足马尔可夫性。

一次交互产出一条**轨迹（trajectory）**：

```
τ = (s₀, a₀, r₁, s₁, a₁, r₂, s₂, …)
```

**策略（policy）** `π(a | s)` 是我们要学的东西：**在状态 s 下选动作 a 的概率**。

---

## 2. 目标：最大化回报

单步奖励 `r` 只有眼前意义，真正要最大化的是**回报（return）**——折扣后的累计奖励：

```
G_t = r_{t+1} + γ·r_{t+2} + γ²·r_{t+3} + …  =  Σ_{k=0}^{∞} γ^k · r_{t+k+1}
```

γ 的语义（三个等价说法，面试常用）：

| 说法 | 含义 |
|---|---|
| 未来的钱不如现在的钱 | 1 元 100 步后只值 `γ^100` |
| 有效视野 = `1/(1−γ)` | γ=0.99 → 约 100 步；γ=0.9 → 约 10 步 |
| 保证数学性质 | γ<1 时无穷和收敛，Bellman 算子是**压缩映射**（不动点唯一，迭代必定收敛） |

> **γ = 1 的坑**：γ=1 时"无穷和"可能发散、不动点可能不唯一，数学上要求**回合制（episodic）且保证终止**才安全。LLM 对齐全用 **γ=1**——因为回答总有 EOS，"看完整段、不打折"是语义正确的；这属于"终止型 MDP"的合法特例。

## 3. 两个函数：V 与 Q（全场最重要的两个符号）

**值函数 V**：在状态 s、按策略 π 走，预期能拿多少分。

```
V^π(s) = E_π[ G_t | S_t = s ]
```

**动作值函数 Q**：在状态 s、**先强制选动作 a**、之后按 π 走，预期能拿多少分。

```
Q^π(s, a) = E_π[ G_t | S_t = s, A_t = a ]
```

两者关系（一句话：**V 是 Q 按策略加权平均**）：

```
V^π(s) = Σ_a π(a|s) · Q^π(s, a)
```

为什么要两个都要：**V 用来评判"状态好不好"，Q 用来评判"动作好不好"**。想把策略改好，必须知道"换个动作会不会更好"——这只能靠 Q。

---

## 4. Bellman 方程：RL 全部算法的心脏

**核心思想**：把"从 s 走到未来"这件事，**递归地拆成"走一步 + 从新状态继续"**。这就是 Bellman 方程。

**① Bellman 期望方程**（评价一个给定策略 π 有多好）：

```
V^π(s)   = Σ_a π(a|s) Σ_{s',r} P(s',r|s,a) · [ r + γ·V^π(s') ]
Q^π(s,a) = Σ_{s',r} P(s',r|s,a) · [ r + γ·Σ_{a'} π(a'|s')·Q^π(s',a') ]
```

**② Bellman 最优方程**（找最好的策略，把"按 π 平均"换成"取最好"）：

```
V*(s)   = max_a Σ_{s',r} P(s',r|s,a) · [ r + γ·V*(s') ]
Q*(s,a) = Σ_{s',r} P(s',r|s,a) · [ r + γ·max_{a'} Q*(s',a') ]
```

**③ 最优策略是贪心的**（这条极重要）：

```
π*(s) = argmax_a Q*(s, a)
```

> 也就是说：**只要有了 Q\*，策略就不需要"训练"了——每步取 argmax 就行**。这就是"值方法"整条路线的世界观（→ [环节 02](./环节02-值方法与DQN详解.md)）。

**④ 两个方程的关系**：Bellman 最优方程是 Bellman 期望方程在"策略已经最优"时的特例。反过来，**只要 π 不是最优，就能用 Bellman 期望方程算出 V^π，再贪心地改进 π**——这叫**策略改进定理**，是值迭代/策略迭代的理论依据。

**⑤ 唯一性与收敛**：γ<1 时，`(TV)(s) = max_a Σ P·[r + γV(s')]` 是一个 **γ-压缩映射**：

```
‖T V₁ − T V₂‖∞ ≤ γ · ‖V₁ − V₂‖∞
```

压缩映射必有**唯一不动点**，且**反复迭代必收敛**（Banach 不动点定理）。这就是为什么"值迭代"一定能算出 V\*——不是工程技巧，是数学保证。

> 为什么会收敛得这么快：每轮迭代把误差至少乘 γ。所以要跑到误差 ε 以内，迭代次数约 `log(ε)/log(γ)`——**γ 越接近 1，收敛越慢**（视野越长、信息传播越慢）。

## 5. 怎么"解"一个 MDP：四种做法一张表

| 做法 | 依赖 | 迭代什么 | 归属 |
|---|---|---|---|
| **值迭代** | 已知模型 P、R | 反复套 Bellman 最优方程直到 V 不变，最后一次导出 π | 动态规划（DP） |
| **策略迭代** | 已知模型 P、R | 交替：**策略评估**（算 V^π）→ **策略改进**（贪心改 π） | 动态规划（DP） |
| **蒙特卡洛（MC）** | 只采样，不需要模型 | 用**完整轨迹的实际回报**平均来估 V/Q | 无模型 |
| **时序差分（TD）** | 只采样，不需要模型 | 用**下一步的估计**替掉真实回报（自举） | 无模型 |

两条主轴，务必分清：

- **要不要环境模型**：DP 要（知道 `P`、`R`，可以"想"）；MC/TD 不要（只能"试"）。LLM 场景显然**没有环境模型**——采样一次回答的代价就是一次推理。
- **自举（bootstrap）不自举**：MC 等整条轨迹跑完才更新（无偏但方差大）；TD 用 `r + γV(s')` 边走边更新（有偏但方差小）。→ 这个偏差-方差权衡在 [环节 03](./环节03-策略梯度与Actor-Critic详解.md) 的 GAE 里被显式参数化。

> **DP 在 LLM 里没有位置**：`P(s'|s,a)` 意味着"给定 prompt 和已生成内容，预测下一个 token 之后的世界状态分布"——这在语言里根本没有定义（下一个 token 就是你选的动作，不存在"环境随机转移"）。所以 LLM 的 RL **只走采样路线**。这一点是本专题与传统 RL 教材最大的分叉，务必记住。

## 6. 三对必须分清的概念（面试基本都从这里出）

### 6.1 探索 vs 利用（exploration vs exploitation）

- **利用**：用当前认为最好的动作（拿确定的分）；
- **探索**：试从没试过的动作（可能发现更高的分）。

**纯贪心会锁死在次优解**：某动作第一次试就拿了高分，之后永远只选它，再也没机会发现问题。

常用折中：**ε-greedy**（以 ε 概率随机、否则贪心）：

```
π(a|s) = 1 − ε + ε/|A|   ，a = argmax Q(s,·)
       = ε/|A|           ，其余动作
```

其他手段：乐观初始化（先假设没试过的动作很好，逼自己去试）、UCB（按不确定性给探索加成）、熵正则（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md) §6）。

> LLM 对齐全靠**采样温度**做探索（`temperature`/`top-p`），GRPO 还要求"组内 G 条回答要有差异"（→ [环节 07](./环节07-GRPO与RLVR详解.md)）——**温度太低 → 组内全同 → 优势恒为 0 → 白跑**。

### 6.2 on-policy vs off-policy（选型第一分水岭）

| | on-policy（同策略） | off-policy（异策略） |
|---|---|---|
| 定义 | **必须用当前策略产生的数据**来更新当前策略 | 可以用**别的策略**（行为策略）的数据 |
| 代表 | SARSA、REINFORCE、PPO、GRPO | Q-learning、DQN、DPO |
| 优点 | 稳、理论干净 | 样本效率高（可复用旧数据、可离线） |
| 缺点 | 数据用一次就丢，采样贵 | 需要**重要性采样**修正分布差异，方差大、易发散 |

**判据**：如果更新时用的数据不是"当前策略刚采出来的"，就必须乘重要性比 `π_new/π_old` 做修正。重要性采样的方差随轨迹长度**指数级增长**——这是 PPO/GRPO 宁愿"每批数据只更新几次"也要把自己限制成近似 on-policy 的根本原因（→ [环节 04](./环节04-信赖域与PPO详解.md)）。

> 记忆点：**DPO 是 off-policy 的极端形态**——它吃一份固定的偏好对数据集，完全不采样，所以"稳但学不到数据以外的东西"（→ [环节 06](./环节06-DPO家族与离线偏好优化详解.md)）。

### 6.3 预测 vs 控制

- **预测（prediction）**：给定 π，算 V^π / Q^π——"这个策略值多少分"；
- **控制（control）**：找 π\*——"怎么才能拿最多分"。

所有算法的结构都是：**预测 + 改进**。区别只在"用谁做预测、怎么改进"。

## 7. 从 MDP 到 LLM：要素映射

把 LLM 生成塞进 RL 框架，是本专题后面所有内容的地基（→ 也是 [环节 09 训练管线](../transformer/环节09-训练管线详解.md) §3「对齐」的展开）：

| RL 概念 | 符号 | 在 LLM 里是什么 |
|---|---|---|
| 策略 π(a\|s) | π_θ | 当前**待训模型**本身：`π_θ(y\|x)`，给定 prompt 生成回答 |
| 状态 s | — | prompt + **已生成的 token**（状态随生成而变） |
| 动作 a | — | **下一个 token**（动作空间 = 词表，10⁵ 量级） |
| 轨迹 τ | — | 一次完整回答 `y = (y₁…y_T)` |
| 奖励 R | r | **奖励模型打分 / 验证器结果 / 人类偏好**（整段只给一个分数） |
| 价值 V(s) | V_φ | 从当前状态起、后续能拿多少分（**critic** 网络学它） |
| 优势 A(s,a) | A | 这个动作比"平均水平"好多少 → **决定该鼓励还是压制** |
| 折扣 γ | — | **取 1**（不折扣，看整段） |
| 环境模型 P | — | **不存在**（下一个 token 不是环境给的，是自己选的） |
| 回合 | — | 一次生成，直到 EOS 或达到长度上限 |

三个由此产生的**结构性差异**（理解它们，就理解了为什么 LLM 的 RL 长成今天这样）：

1. **信用分配问题被放大**：整段回答只拿一个标量奖励，却要归因到每个 token。
   - PPO：训一个 **critic** 网络逐状态估价值 → `A = R − V(s)`；
   - GRPO：**用同题其他回答的成绩当基线**（组内相对），免掉 critic；
   - PRM（过程奖励）：**直接给每一步打分**，用标注成本换信用分配精度。
2. **状态转移是确定的**：`s' = s + 选中的 token`，没有环境随机性。所以 LLM RL 的随机性**全部来自策略采样**（温度），这使方差分析比传统 RL 简单。
3. **动作空间巨大且连续语义**：10⁵ 选 1，逐 token 采样。所以表格方法（Q-table）彻底无用，只剩"参数化策略 + 梯度"这条路。

## 8. 数值走查：一个 2 状态 MDP 手算到底

用最小例子把"Bellman 期望方程 → 最优方程 → 值迭代 → 不动点"跑通。设定一个**只有两个状态**的 MDP：

```
S = {A, B}，A = {stay, go}，γ = 0.9

规则（确定性）：
  状态 A：动作 stay → 留在 A，奖励 +1
          动作 go   → 转到 B，奖励 +2
  状态 B：动作 stay → 留在 B，奖励 +3
          动作 go   → 回到 A，奖励  0
```

**第一步：手算最优值 V\***。四条 `(s,a) → r + γV*(s')`：

```
Q*(A, stay) = 1 + 0.9·V*(A)
Q*(A, go)   = 2 + 0.9·V*(B)          V*(A) = max( 1 + 0.9V*(A) , 2 + 0.9V*(B) )
Q*(B, stay) = 3 + 0.9·V*(B)
Q*(B, go)   = 0 + 0.9·V*(A)          V*(B) = max( 3 + 0.9V*(B) , 0 + 0.9V*(A) )
```

先猜策略：B 里 stay 最赚（B 会自我复利 `3/(1−0.9) = 30`），A 里跑到 B 最赚。验证：

```
设 V*(B) = 3 + 0.9·V*(B)  →  V*(B) = 30
设 V*(A) = 2 + 0.9·V*(B)  →  V*(A) = 2 + 27 = 29
代入检查 A 的 stay 分支： 1 + 0.9·29 = 27.1 < 29 ✓   （go 确实更优）
代入检查 B 的 go 分支：   0 + 0.9·29 = 26.1 < 30 ✓   （stay 确实更优）
```

所以 `V*(A)=29、V*(B)=30`，**最优策略：A 走 go 去 B，B 一直 stay**。

**第二步：从零开始值迭代，看它真的收敛过去**：

```
V₀ = (0, 0)
V₁(A) = max(1+0.9·0, 2+0.9·0)   = 2          V₁(B) = max(3, 0)   = 3
V₂(A) = max(1+0.9·2, 2+0.9·3)   = 4.7        V₂(B) = max(5.7,1.8) = 5.7
V₃(A) = max(1+4.23, 2+5.13)     = 7.13       V₃(B) = max(8.13, 4.23) = 8.13
…每轮把误差乘 γ=0.9，逐步逼近 (29, 30)
```

**第三步：可运行代码（纯标准库，复现上面的数字）**：

```python
# 可运行：python3 -c "..."；亦可直接跑本目录 mvp.py 看配套演示
GAMMA = 0.9
trans = {("A", "stay"): ("A", 1.0), ("A", "go"): ("B", 2.0),
         ("B", "stay"): ("B", 3.0), ("B", "go"): ("A", 0.0)}

V = {"A": 0.0, "B": 0.0}
for it in range(1, 41):
    new = {}
    for s in V:
        new[s] = max(r + GAMMA * V[s2] for (s2, r) in
                     (trans[(s, a)] for a in ("stay", "go")))
    V = new
    if it <= 3 or it == 40:
        print(f"V_{it:<2} A={V['A']:.4f}  B={V['B']:.4f}")
# 输出：V_1 A=2.0000 B=3.0000 … V_40 A=28.5566 B=29.5566（γ⁴⁰≈0.0148，已逼近不动点 29 / 30）

# 导出最优策略：argmax Q*
policy = {s: max(("stay", "go"),
                 key=lambda a: trans[(s, a)][1] + GAMMA * V[trans[(s, a)][0]])
          for s in V}
print("π* =", policy)          # {'A': 'go', 'B': 'stay'}
```

**读法**：三段代码对应三件事——**Bellman 备份**（一行 max + 加奖励）、**压缩收敛**（迭代 40 次误差乘 0.9⁴⁰≈0.015）、**策略导出**（argmax Q 即可，不用单独"训"策略）。

## 9. 坑清单

1. **状态不满足马尔可夫性**：把关键历史丢了 → 同一状态下"最优动作"不唯一，算法必然学不好。LLM 靠"上下文 = 状态"绕过了这个问题，但 Agent 场景里"该记什么进上下文"依然是真的设计题。
2. **奖励设计错了，一切白搭**：奖励是唯一的"真值来源"。奖励错了，算法越高效跑得越偏（→ 奖励黑客，见 [环节 07](./环节07-GRPO与RLVR详解.md) §5）。
3. **γ 设成 1 却不终止**：无穷和发散。LLM 用 γ=1 是因为**回答必定终止**（EOS / 长度上限）。
4. **把 on-policy 数据当 off-policy 复用**：不乘重要性比直接用 → 更新方向错。反过来，PPO 的 `π_old` 就是用来说明"这批数据是它采的"（→ [环节 04](./环节04-信赖域与PPO详解.md)）。
5. **以为"必须懂 AlphaGo / DQN"才能做 LLM 对齐**：不成立。LLM 对齐全在"无模型 + 参数化策略 + 采样"这条线上，值方法与博弈搜索只提供**思想**（优势、基线、信用分配），不是前置知识。但**面试会问**——这就是本专题保留 [环节 02](./环节02-值方法与DQN详解.md) 的原因。

## 10. 面试高频追问

1. **MDP 的五元组是什么？马尔可夫性在说什么？** → `(S, A, P, R, γ)`；马尔可夫性 = 下一步只依赖当前状态与动作，历史信息已被状态压缩完毕。它的工程含义是：**状态设计得好不好，决定了这个 RL 问题能不能解**。
2. **Bellman 期望方程与最优方程的区别？** → "下一步按策略 π 加权平均" vs "下一步取 max"。前者评价给定策略，后者直接定义最优值；最优方程的解是唯一的 V\*（γ<1 时）。
3. **为什么值迭代一定会收敛？** → γ<1 时 Bellman 最优算子是 γ-压缩映射（`‖TV₁−TV₂‖∞ ≤ γ‖V₁−V₂‖∞`），Banach 不动点定理保证唯一不动点且迭代收敛；每轮误差至少乘 γ。
4. **为什么有了 Q\* 就不需要"训策略"了？** → 最优策略就是 `π*(s)=argmax_a Q*(s,a)`，是 Q\* 的确定性贪心导出物。值方法整条路线（含 DQN）都建立在这条上。
5. **on-policy / off-policy 怎么判？为什么 off-policy 方差大？** → 判据是"更新时用的数据是否来自当前策略"；不是就要乘重要性比 `π_new/π_old` 修正，而这个比的方差**随轨迹长度指数增长**。
6. **为什么 LLM 的 RL 不用 DP、不用值迭代？** → DP 需要环境模型 `P(s'|s,a)`，而语言里"下一个 token"是**智能体自己的动作**、不是环境给的转移；LLM RL 只有采样一条路。
7. **γ 在 LLM 里为什么取 1？为什么传统 RL 常取 0.99？** → LLM 回答必定终止、且"整段质量"是一个整体信号，不该打折；传统 RL 取 <1 是为了数学上的压缩收敛与"偏向近期奖励"。
8. **信用分配（credit assignment）是什么？** → "整段拿了 1 分，到底哪一步的功劳"的问题。它是 RL 与 LLM 对齐最难的一点，也是各算法差异的总根源（critic / 组基线 / 过程奖励三种解法，见 [环节 03](./环节03-策略梯度与Actor-Critic详解.md)、[环节 07](./环节07-GRPO与RLVR详解.md)、[环节 08](./环节08-AgenticRL与信用分配详解.md)）。
9. **ε-greedy 为什么要留 ε？在 LLM 里对应什么？** → 防锁死在次优动作（纯贪心永不探索）。LLM 里对应**采样温度/top-p**：温度太低 → 组内回答全同 → GRPO 优势恒为 0。
