# 环节 02 · 值方法与 DQN（先学会打分，再贪心地动）

> 适合人群：后端/资深读者。**这一环节的主要价值是"语汇与直觉"**——LLM 对齐全线走策略方法，但 `V / Q / 优势 / baseline / critic / 自举 / 重要性采样` 这些词全部来自这里，面试也全在这里出题。

## 0. 一句话定位

**值方法 = 学会"打分"，然后按分数行动。**

```
值方法的世界观：
  1. 先估出 Q*(s, a)      —— "这个状态下做这个动作，长期能拿多少分"
  2. 然后 π*(s) = argmax_a Q*(s,a)   —— 策略是免费的副产品，不用单独训练
```

对应到 [环节 01](./环节01-RL基础与MDP详解.md) 的 Bellman 最优方程：**整条路线都是在用不同方法逼近 `V*` / `Q*`**。

| 算法 | 分数怎么估 | 用谁的数据估计 | 需要环境模型吗 |
|---|---|---|---|
| 值迭代 / 策略迭代 | 反复套 Bellman（精确求和） | 不需要数据，用模型"想" | **需要** |
| 蒙特卡洛（MC） | 完整轨迹的**真实回报**取平均 | 当前策略采出来的完整回合 | 不需要 |
| 时序差分（TD） | `r + γV(s')`（**自举**） | 当前策略的**单步转移** | 不需要 |
| Q-learning | `r + γ·max Q(s',·)` | **任意策略**的转移（off-policy） | 不需要 |
| DQN | 用**神经网络**逼近 Q，套 Q-learning 的目标 | 经验回放池里的历史数据 | 不需要 |

## 1. 绕不开的骨架：广义策略迭代（GPI）

所有值方法都是同一个循环的两个半场：

```
        ┌──────────────────────────────────────┐
        │                                      │
   [评估] 用当前策略 π 算出 V^π / Q^π  ──────▶ [改进] 用估出来的值把 π 变得更好（贪心）
        │                                      │
        └──────────── 重复直到收敛 ◀────────────┘
```

- **策略迭代**：评估做到"完全收敛"再改进（贵，但改进次数少）；
- **值迭代**：评估只做一步就顺便取 max 改进（便宜，迭代次数多）；
- **MC / TD / DQN**：只是把"评估"那一步换成了"用采样数据估"。

> 记住这个骨架，后面看 PPO / GRPO 也有用：**策略方法把这个循环改成了"直接对策略求梯度"**，但"评估得多准"与"改进迈多大步"这两个问题一个字都没变（→ [环节 04](./环节04-信赖域与PPO详解.md) 的 clip 就是在回答"改进迈多大步"）。

## 2. 动态规划（DP）：有模型时最省事

已知 `P(s'|s,a)` 和 `R`，可以直接对 Bellman 方程做迭代（"想"，不用"试"）。

**① 策略评估**：反复把 Bellman 期望方程套在 V 上，直到 V 不再变化。

```
V_{k+1}(s) ← Σ_a π(a|s) · Σ_{s',r} P(s',r|s,a) · [ r + γ·V_k(s') ]
```

**② 策略改进**：用估出的 V 做一步贪心。

```
π'(s) ← argmax_a Σ_{s',r} P(s',r|s,a) · [ r + γ·V^π(s') ]
```

**③ 两种编排**：

| | 策略迭代 | 值迭代 |
|---|---|---|
| 一轮做什么 | 评估**到收敛** → 改进一次 | 评估**一步**（顺便取 max）→ 改进一次 |
| 每轮代价 | 高 | 低 |
| 轮数 | 少（策略很快稳定） | 多 |
| 一句话 | 少跑几轮、每轮跑透 | 多跑几轮、每轮很浅 |

**④ 复杂度**：每轮 `O(|S|²·|A|)`（要对每个状态、每个动作、每个后继状态求和）。**|S| 一大就彻底不可用**——这是"表格方法"的共同天花板，也是后来函数逼近（DQN）出现的原因。

**⑤ 在 LLM 里的地位：零**。因为 `P(s'|s,a)` 在语言里不存在（下一个 token 是智能体自己的动作，不是环境给的转移）。→ **LLM 的 RL 只有"采样"一条路**（→ [环节 01](./环节01-RL基础与MDP详解.md) §5）。

## 3. 蒙特卡洛（MC）：用真实回报平均

不猜模型，直接跑完整回合，用**实际拿到的回报**当 V(s) 的估计。

```
V(s) ← V(s) + α · [ G_t − V(s) ]        # G_t 是从 t 到回合结束的真实折扣回报
```

**first-visit vs every-visit**：同一个状态在一回合里被访问多次时，只统计第一次（first-visit，理论性质更干净）还是每次都算。

| 优点 | 缺点 |
|---|---|
| **无偏**：用的是真实回报，没有任何估计代入 | **方差大**：一条轨迹的随机性全进来 |
| 不需要模型、不受马尔可夫性影响（整段回报自带全部信息） | **必须等回合结束** → 不能用于持续型任务；长任务样本效率极低 |
| 实现最简单（就是平均） | 同一状态可能长期不被访问 → 学不到（见 §8 的真实案例） |

**MC 控制**：`π = ε-greedy(Q)` + **探索起点（exploring starts）**——从随机的 `(s,a)` 开始回合，保证每个状态-动作对都有机会被试到。

## 4. 时序差分（TD）：边跑边学（RL 最核心的一个想法）

MC 要等回合结束；TD 用"**下一步的当前估计**"就地替换真实回报：

```
TD(0)：  V(s) ← V(s) + α · [ r + γ·V(s') − V(s) ]
                              └──────┬───────┘
                                 TD 误差 δ
```

**TD 误差 δ 是 RL 里最重要的一个量**——"这一步比预期好多少"。后面所有内容都是它的变体：

- 取 max 升级成 Q-learning → `δ = r + γ·max Q(s',·) − Q(s,a)`；
- 把 V 换成 critic 网络的估计 → Actor-Critic 的 `A`（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md)）；
- 对多步做加权平均 → **GAE**（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md) §5）。

**自举（bootstrap）**= 用估计去更新估计。它是 TD 全部优点的来源（可在线、样本效率高），也是全部偏差的来源。

**MC vs TD 对照表（重要）**：

| 维度 | 蒙特卡洛 MC | 时序差分 TD(0) |
|---|---|---|
| 更新时机 | 回合结束 | 每一步 |
| 目标 | 真实回报 `G_t` | 估计值 `r + γV(s')` |
| 偏差 | **无偏** | **有偏**（目标里含估计误差） |
| 方差 | 大 | 小 |
| 是否自举 | 否 | 是 |
| 能否用于持续任务 | 不能 | 能 |
| 收敛到 | 最小均方误差解 | **最大似然 MDP 的解** |

> 面试金句：**TD 收敛到"最可能的 MDP"给出的值，MC 收敛到"最小二乘拟合"的值**；两者在有限数据下不相等（经典的 batch TD vs batch MC 对照，Sutton & Barto §6.3）。实践中 TD 几乎总是更快——因为它的方差小得多。

**n-step 与 TD(λ)**：把两端做成一个连续旋钮。

```
1-step（TD）:  r₁ + γV(s₁)
2-step       :  r₁ + γr₂ + γ²V(s₂)
…
∞-step（MC） :  r₁ + γr₂ + γ²r₃ + …（跑到回合结束）

TD(λ)：对所有 n-step 回报按 (1−λ)λ^{n−1} 加权平均  —— λ=0 是 TD(0)，λ=1 是 MC
```

> **这个"偏差-方差旋钮"就是 GAE 的原型**（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md) §5）。PPO 能稳定工作，靠的就是 GAE 在 "TD 的低方差" 与 "MC 的低偏差" 之间取了一个 λ≈0.95 的折中。

## 5. 从预测到控制：SARSA vs Q-learning

要把"打分"变成"行动"，必须解决一个矛盾：**估计要用数据，数据来自策略，而策略又依赖估计**。两种解法：

```
SARSA（on-policy）：Q(s,a) ← Q(s,a) + α·[ r + γ·Q(s', a') − Q(s,a) ]
                                                 └─ 下一步"实际会走"的那个 a'

Q-learning（off-policy）：
                    Q(s,a) ← Q(s,a) + α·[ r + γ·max_{a'} Q(s',a') − Q(s,a) ]
                                                 └─ 下一步"最好"的那个 a'，不管实际走不走
```

差别只有一处，但语义完全不同：

| | SARSA | Q-learning |
|---|---|---|
| 目标里用 | 行为策略**实际选**的 `a'` | **最好**的 `a'`（max） |
| 学的是 | 当前策略（含探索）的价值 | **最优**策略的价值 Q\* |
| 类型 | on-policy | **off-policy** |
| 经典例子 | 悬崖行走（cliff walking）：学会**绕远路**（因为探索会掉下去） | 学会**贴着悬崖走**（因为已假设不再探索） |

> **悬崖行走是理解 on/off-policy 最好的例子**：同一条数据、同一个环境，off-policy 学出的策略"更优但更脆"；on-policy 学出的策略"保守但真的执行时更安全"。**上线后的实际表现 = 学到的策略 + 实际执行的探索噪声**，这一点在 LLM 里同样成立（推理时的采样温度就是你的 ε）。

**两个必知的坑**：

- **最大化偏差（maximization bias）**：`max_a Q(s,a)` 里 Q 本身有噪声 → max 会系统性偏向"被高估的动作"。**解法：Double Q-learning / Double DQN**（用一套网络选动作、另一套网络打分）。
- **行为策略 vs 目标策略**要区分清楚：Q-learning 的行为策略是 ε-greedy（在探索），目标策略是纯贪心（不探索）——**这就是 off-policy 的字面含义**。

## 6. 从表格到函数逼近：DQN

**问题**：状态一大，Q 表格存不下（围棋 10¹⁷⁰ 个状态，图像输入的每个像素组合都是不同状态）。

**解法**：用参数化函数 `Q(s,a; θ)`（DQN 用神经网络）替代表格，损失直接让输出逼近 Q-learning 目标：

```
L(θ) = E_{(s,a,r,s')~D} [ ( y − Q(s,a;θ) )² ]     ,  y = r + γ · max_{a'} Q(s',a'; θ⁻)
                                                     └────────────────┬────────────────┘
                                                     目标网络参数 θ⁻：滞后更新的一份拷贝
```

**半梯度的关键细节（面试爱问）**：`y` 里也含参数（`θ⁻`），但**只对 `Q(s,a;θ)` 求梯度、不回传进 `y`**——所以它是"半梯度"方法，不是真正的梯度下降。这是 DQN 能 work 的工程前提（也意味着没有严格收敛保证）。

**DQN 三件套（缺一个就学不出来）**：

| 技巧 | 解决什么 | 为什么必要 |
|---|---|---|
| **经验回放（experience replay）** | 打破样本时间相关性 | 相邻转移高度相关，直接训会让网络在"最近见过的几帧"上过拟合、忘掉全局 |
| **目标网络（target network，θ⁻）** | 稳定训练目标 | 目标和预测同步移动 = "追自己尾巴"，振荡甚至发散；让目标慢一拍 |
| **奖励裁剪（reward clipping）** | 把奖励压到 `[-1, 1]` | 不同游戏奖励量级差几个数量级，统一尺度才能用同一个 lr |

**致命三难（deadly triad）**——务必记住，它是 RL 不稳定的理论根源：

```
函数逼近（approximation）
  + 自举（bootstrap）
  + off-policy 训练
  ────────────────────
  = 可能发散（无任何收敛保证）
```

去掉任意一项都安全：TD 是自举+函数逼近但 on-policy；Q-learning 是自举+off-policy 但用表格。**三者同时出现才危险**——而 DQN 三者全占，这正是它必须靠工程技巧（回放 + 目标网络）硬压住的原因。

> 这条对 LLM 对齐同样致命：PPO / GRPO 都是"函数逼近 + 自举（GAE）+ 近似 off-policy（一批数据多次更新）"，所以它们的不稳定性不是 bug，是必然，只能靠 clip、KL、早停等工程手段压住（→ [环节 04](./环节04-信赖域与PPO详解.md)、[环节 07](./环节07-GRPO与RLVR详解.md)）。

**DQN 家族的改进（了解即可，用于面试对答）**：

| 改进 | 一句话 |
|---|---|
| **Double DQN** | 用在线网络选动作、目标网络打分 → 治最大化偏差 |
| **Dueling DQN** | 把 Q 拆成 `V(s) + A(s,a)` → 在"动作不重要"的状态上学得更快 |
| **优先经验回放（PER）** | 按 TD 误差大小加权采样 → 多练"还没学会的" |
| **Noisy Nets** | 把 ε-greedy 换成网络内部的参数噪声 → 探索更聪明 |
| **Rainbow** | 以上全叠 + 分布式回报 + n-step，是 DQN 的集大成基线 |

## 7. 为什么 LLM 的 RL 几乎不用值方法

对照一下就会发现，值方法在 LLM 场景几乎每一格都不合适：

| 维度 | 传统 RL（Atari / 控制） | LLM（对齐全线） |
|---|---|---|
| 动作空间 | 几个~几十个（可枚举） | **词表 10⁵**（无法枚举比较） |
| 状态 | 低维、有清晰边界 | 长序列（prompt + 已生成） |
| 转移 | 环境随机转移 | **确定**（下一个 token 就是动作本身） |
| 奖励 | 每步都有（游戏分） | **整段一个标量**（稀疏到极致） |
| 策略 | 常只需确定性 argmax | **必须输出概率分布**（要采样要多样） |
| 需要什么 | 一条最优动作序列 | **一个高质量、多样、可探索的生成分布** |

最后一行是关键：**LLM 要的不是 `argmax`，而是一个好分布**。值方法最终要经由 `π = argmax Q` 导出策略，只给你一个确定性输出，拿不到"温度、多样性、可探索"——这正好是语言模型的核心价值。

**但值函数的思想一个都没丢，全部活在 LLM 对齐里**：

| 环节 02 的概念 | 在 LLM 对齐里的形态 |
|---|---|
| `V(s)` | **critic 网络**（PPO 里唯一"值方法"残留，→ [环节 04](./环节04-信赖域与PPO详解.md)） |
| `Q(s,a)` | 优势 `A(s,a) = Q(s,a) − V(s)` 的分子（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md)） |
| TD 误差 δ | **GAE 的单步单元**（→ [环节 03](./环节03-策略梯度与Actor-Critic详解.md) §5） |
| 自举 | GAE 用 critic 估后续价值 |
| 致命三难 | PPO/GRPO 全部不稳定的理论根源 |
| 探索覆盖 | GRPO 的组内多样性 / 采样温度 |

> **一句话**：LLM 的 RL = **策略方法 + 一个只做"基线"用的 critic**。值方法在这里不再负责"选动作"，只负责"评判平均水位"。

## 8. 数值走查：4×3 网格世界（真实输出）

**设定**（纯标准库，代码见下）：

```
4 宽 × 3 高；起点 (0,0)；目标 (3,2) 转移到 +1；陷阱 (3,1) 转移到 −1
其他转移奖励 0；撞墙则留在原地；γ = 0.9
Q-learning：α = 0.4，ε = 0.1，20000 回合
```

**① 真值（值迭代，有模型）**：

```
      x=0     x=1     x=2     x=3
y=2  0.810   0.900   1.000      G
y=1  0.729   0.810   0.900      P
y=0  0.656   0.729   0.810   0.729
```

**读这张表**（三个反直觉但重要的点）：

1. **紧挨目标的那格是 1.000，不是 0.9** —— 奖励落在第 1 步（`γ⁰`），**只有"未来"才打折**；`γ^k` 里的 k 是"奖励晚到几步"，不是"走了几步"。
2. **起点 (0,0) = 0.656 = 0.9⁴** —— 到目标要 5 个动作，奖励落在第 5 步 → γ⁴。**折扣是"延迟的代价"**。
3. **(3,0) = 0.729 > (2,0) 的邻居预期** —— 因为它必须先往左绕开陷阱，路径更长却比"直接往上掉进陷阱"好得多。

**② Q-learning 学到的（无模型，20000 回合）**：

```
      x=0     x=1     x=2     x=3
y=2  0.810   0.900   1.000      G
y=1  0.729   0.810   0.900      P
y=0  0.656   0.729   0.810   0.000      ← 注意这一格

贪心策略 π(s)=argmax Q：
      →      →      →       G
      ↑      ↑      ↑       P
      ↑      ↑      ↑      ↑          ← (3,0) 的策略是"↑"，即主动往陷阱里走
```

**③ 关键发现：`(3,0)` 访问了 0 次，值完全是 0.000，策略是错的**（最大偏差 0.729）。

统计访问次数（同样 20000 回合）：

```
(0,0) 21628 次（含撞墙原地不动）    (1,0)   609 次    (2,0)  23 次    (3,0)   0 次
```

原因链：从固定起点出发 → 学到的贪心策略在 (2,0) 选择"↑" → **永远不会从 (2,0) 往右走进 (3,0)**；ε=0.1 的随机探索在 (2,0) 只出现 23 次、其中往右约 2.5% → **期望不到 1 次，实测 0 次**。

**④ 只改一件事：把起点改成随机**（其余参数完全不动）：

```
y=2  0.810   0.900   1.000      G
y=1  0.729   0.810   0.900      P
y=0  0.656   0.729   0.810   0.729      ← 与真值逐格一致
最大偏差 0.000
```

> **这就是本环节最值得记住的一课**：**算法再标准，"没访问过的状态"就是学不到的**。RL 的性能天花板往往不在算法，而在**数据覆盖**。这条结论在 LLM 对齐里的对应物是：**GRPO 组内全对/全错 = 这一条 prompt 没提供任何梯度信号**（→ [环节 07](./环节07-GRPO与RLVR详解.md)），以及"训练分布覆盖不到的能力永远学不出来"。

**可运行代码**（纯标准库，输出即上面三张表）：

```python
import random
random.seed(0)

W, H = 4, 3
GOAL, PIT = (3, 2), (3, 1)
TERM = {GOAL, PIT}
GAMMA, ALPHA, EPS, EPISODES = 0.9, 0.4, 0.1, 20000
ACTS = ((0, 1), (0, -1), (-1, 0), (1, 0))
STATES = [(x, y) for x in range(W) for y in range(H)]

def step(s, a):
    ns = (s[0] + a[0], s[1] + a[1])
    if not (0 <= ns[0] < W and 0 <= ns[1] < H):
        ns = s                                  # 撞墙：留在原地
    if ns == GOAL: return ns,  1.0, True         # 转移到目标 → +1
    if ns == PIT:  return ns, -1.0, True         # 转移到陷阱 → −1
    return ns, 0.0, False

# —— 有模型：值迭代（真值） ——
V = {s: 0.0 for s in STATES}
for _ in range(500):
    V = {s: (0.0 if s in TERM else
             max(r + (0.0 if d else GAMMA * V[ns])
                 for (ns, r, d) in (step(s, a) for a in ACTS)))
         for s in STATES}

# —— 无模型：Q-learning ——
Q = {(s, a): 0.0 for s in STATES for a in ACTS}
visit = dict.fromkeys(STATES, 0)
for _ in range(EPISODES):
    s = (0, 0)                                   # 改成 random.choice(...) 即"随机起点"版
    while True:
        visit[s] += 1
        a = random.choice(ACTS) if random.random() < EPS \
            else max(ACTS, key=lambda a: Q[(s, a)])
        ns, r, done = step(s, a)
        Q[(s, a)] += ALPHA * (r + (0.0 if done else GAMMA * max(Q[(ns, a2)] for a2 in ACTS))
                              - Q[(s, a)])
        s = ns
        if done: break

Vq = {s: (0.0 if s in TERM else max(Q[(s, a)] for a in ACTS)) for s in STATES}
for y in range(H - 1, -1, -1):
    print("  ".join("     G" if (x, y) == GOAL else "     P" if (x, y) == PIT
                    else f"{Vq[(x, y)]:6.3f}" for x in range(W)))
print("漏学状态：", [s for s in STATES if s not in TERM and visit[s] == 0])   # [(3, 0)]
```

## 9. 坑清单

1. **以为"值方法 = RL 的全部"**：LLM 对齐全线是策略方法，值函数只剩一个 critic 的位置。别把教材前几章当重点背。
2. **忽视探索覆盖**：§8 的 `(3,0)` 就是活证据——**没访问到 = 没学到**，且它会导致"策略看起来收敛了但其实是错的"。对策：随机起点、ε 衰减、乐观初始化、UCB。
3. **忘了最大化偏差**：`max` 会系统性挑出被高估的动作。修法是 Double Q / Double DQN，不是调 lr。
4. **在 off-policy 里把行为策略与目标策略搞混**：Q-learning 学的是"假设不再探索"的最优策略，实际部署若还在探索，表现会差于 SARSA（悬崖行走）。
5. **以为 DQN 的目标是真梯度**：`y` 含参数但被当作常数 → 半梯度，无严格收敛保证；这是"致命三难"的具体体现。
6. **以为 off-policy 一定更好**：样本效率高，但方差大、可能发散；PPO/GRPO 宁愿"近似 on-policy + 只更新几次"来换稳定（→ [环节 04](./环节04-信赖域与PPO详解.md)）。
7. **γ 与"折扣次数"数错**：`γ^k` 的 k 是**奖励延迟的步数**。这个式子在 [环节 06](./环节06-DPO家族与离线偏好优化详解.md) 推导 DPO 时会再出现一次（`β·log(π/π_ref)` 就是隐式奖励）。

## 10. 面试高频追问

1. **值迭代与策略迭代的区别？** → 前者评估只做一步（顺便取 max），后者评估到收敛再改进；策略迭代轮数少每轮贵，值迭代反之，两者都是 GPI（评估-改进循环）的特例。
2. **MC 与 TD 的核心差别？** → 用什么当"目标"：MC 用真实回报（无偏、方差大、需等回合结束），TD 用 `r+γV(s')` 自举（有偏、方差小、可在线）；有限数据下 TD 收敛到最大似然 MDP 解、MC 收敛到最小 MSE 解。
3. **TD 误差是什么？为什么说它是 RL 的核心？** → `δ = r + γV(s') − V(s)`，"比预期好多少"。取 max 变成 Q-learning，换成 critic 变成 Actor-Critic 的优势，对多步加权变成 GAE——全部算法都是它的一层层包装。
4. **SARSA 与 Q-learning 差在哪？** → 目标里用"实际会走的 `a'`"还是"最好的 `a'`"；前者 on-policy、后者 off-policy。悬崖行走是最经典的行为差异对照。
5. **什么是最大化偏差？怎么解？** → `max` 对 Q 的估计噪声有系统性高估偏置；Double Q / Double DQN 用两套估计分别负责"选"和"评"来消掉。
6. **DQN 为什么要经验回放和单独的目标网络？** → 回放破样本相关性、提高数据复用；目标网络让回归目标不追着自己跑，压住自举带来的振荡。
7. **"致命三难"是什么？** → 函数逼近 + 自举 + off-policy 三者同时出现时可能发散、无收敛保证。DQN 三者全占，所以必须靠工程技巧压住；PPO/GRPO 同理（只是用 clip/KL 代替回放和目标网络）。
8. **为什么 LLM 不用 DQN 这类值方法？** → 动作空间 10⁵ 无法枚举比较、奖励是整段一个标量、LLM 需要的是"好分布"而不是 `argmax`；值方法最终只能导出确定性策略。但 critic 作为 baseline 在 PPO 里活着。
9. **n-step / TD(λ) 的意义？** → 把"低方差高偏差（TD）"与"高方差无偏（MC）"做成一个连续旋钮；**GAE 就是这个旋钮在 LLM 对齐里的形态**（λ≈0.95）。
