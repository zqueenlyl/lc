## 1. 干什么

对一层线性变换，微调时真正在动的不是 W 本身，是 **ΔW**（一步梯度下降后 W′ − W）。全参允许 ΔW 的每个格子独立，mn 个自由度。LoRA 说：底座已经很好，格子之间应有大量依赖，于是规定

```
W′ = W + γ · B A
```

只训练 A、B（以及可选缩放 γ）。前三站的轨道、对角约束、秩 1 外积，至此是同一件事。

---

## 2. 怎么干（4×5 微例）

左 4 个节点、右 5 个节点，全连接 **20 条边**。一步更新得到 20 个增量，排成 4×5 的 ΔW。自由微调 = 在 20 维里找宝藏。

信任「这些增量高度相关」，强制 ΔW 为秩 1：

```
B = [a, b, c, d]ᵀ          # 4×1，本库约定：左乘的那个
A = [p, q, r, s, t]        # 1×5

ΔW = B A =

  a p   a q   a r   a s   a t
  b p   b q   b r   b s   b t
  c p   c q   c r   c s   c t
  d p   d q   d r   d s   d t
```

看起来 20 格，生成它们只用了 **4+5=9** 个数。行与行成比例（都是 `[p,q,r,s,t]` 的倍数），列与列也成比例——环节 03 的「一句信息」。

### 2.1 字母约定（本库 vs 视频）

| 来源 | 写法 | 形状 |
|---|---|---|
| **本库 / LoRA 原文 / HuggingFace PEFT** | `ΔW = B A` | B: d×r，A: r×k |
| Serrano 视频 | `ΔW = A * B` | 字母对调，几何相同 |

本专题一律跟 README 与环节 09：`B` 是「高瘦」、`A` 是「矮胖」。视频口播里的 A/B 不要直接对号入座。

### 2.2 尺度不变：9 个数其实是 8 个真自由度

任取 λ ≠ 0：

```
(λ B) · (A / λ)  =  B A
```

同一张 ΔW。可以把 B 的第一个分量缩放到 1（λ = 1/a，a≈0 时用一个很小的浮点，机器学习里几乎总会碰到），于是自由参数是 8 不是 9。一般地：

| 秩 r | 字面参数 | 可逆混洗造成的冗余 | 真自由度 |
|---|---|---|---|
| 1 | m + n | 1 个尺度 | m + n − 1 |
| r | r(m + n) | r×r 的可逆变换 | r(m + n) − r² |

工程实现**不去掉**这 r² 个冗余（多写几个数比做约束便宜），优化器在等价表示里游荡即可。数参数、报「训了多少」时用字面的 `r(m+n)`，与 [环节09](../transformer/环节09-训练管线详解.md) §4.3.3 的 `2·d·r` 一致。

几何图像：20 维空间里有一块弯曲的 8 维「好轨道」；LoRA 把搜索限制在这块上，希望宝藏就在附近。

### 2.3 一般层

一层 W ∈ R^{m×n}（m 个输出、n 个输入）：

```
全参更新：     mn 个旋钮
LoRA 秩 r：    r(m + n) 个字面旋钮     （真自由度再减 r²）

r ≪ min(m, n) 时，r(m+n) ≪ mn
```

前向不物化 ΔW：先 `A x`（压到 r 维）再 `B (A x)`。反传只产生 ∂L/∂A、∂L/∂B。推理可把 `γ BA` 加回 W，之后与普通层无异——[mvp.py](./mvp.py) 演示同一底座热插拔两份 (A,B)。

## 3. 方法对比（接到工程）

| | 全参 FFT | LoRA | QLoRA |
|---|---|---|---|
| 搜的空间 | mn / 层，叠起来是全部参数 | 每层一块 r(m+n) 的轨道 | 同 LoRA，底座再 4bit |
| 几何假设 | 无（每个格子都能动） | 好的 ΔW 低秩 | 同左 |
| 省什么 | — | 可训练参数的梯度 + 优化器状态 | 再省冻结底座的存储 |
| 不省什么 | — | **激活**照样占 | 同左 |
| 起点 | 必须是好底座才有意义 | **必须是好底座** | 同左 |

QLoRA、注入 q/v 还是 FFN、α/r、B 零初始化，见 [环节09](../transformer/环节09-训练管线详解.md) §4.3–§4.4 与 [README](./README.md)，本站不重复。

## 4. 优缺点（收口）

- **有效**：预训练把模型送到低内在维度的好区域；下游只要低秩扰动。
- **省**：7B、r=16、attention q/k/v/o ≈ 1678 万参数，约全参 0.24%（环节 09 手算）。本 notebook §4 会复用同一公式。
- **不是万能**：轨道以外走不到 → 难任务要加大 r 或加模块；脏数据照样把通用能力带偏；随机初始化上不要指望它。
- **上线两种形态**：合并进 W（零额外延迟）或底座 + 多份小 (A,B) 热插拔（多租户）。

## 5. 数值走查（4×5 → 7B）

```
4×5 全参     20
秩 1 字面     4+5 = 9
秩 1 真 DOF   8
秩 2 字面     2×(4+5) = 18   ← 已经快碰到 20，低秩优势消失

4096×4096 全参     16,777,216
秩 16 字面         16×(4096+4096) = 131,072   ← 每层每个投影
```

r 相对 min(m,n) 必须小，否则「铺的轨」快铺满整个森林，LoRA 退化成贵一点的全参。

## 6. 面试高频追问

1. **LoRA 的公式？** `W′ = W + γ BA`，W 冻结，只训 A、B；B 为 d×r，A 为 r×k，r ≪ min(d,k)。
2. **为什么叫低秩适配？** ΔW 被强制成至多 r 个外积之和，行向量张成的空间最多 r 维。
3. **20 个增量为什么变成 8 个真自由度？** 秩 1 外积 4+5=9 个数，乘/除同一个 λ 矩阵不变，消掉 1 个尺度。
4. **字面参数为啥不减 r²？** 实现省事；报参数量用 `r(m+n)` 即可。
5. **视频里 ΔW=A*B 和论文 BA 矛盾吗？** 字母对调，把「高瘦」叫 B、「矮胖」叫 A 就对齐了。
6. **为什么低秩就够？** 信任底座：好的更新高度相关（环节 01–02）；内在维度论据 + 原文 r=4 追平多数任务（环节 09）。
7. **推理要一直带着 A、B 吗？** 不必。可合并；多租户才热插拔（[mvp.py](./mvp.py)）。
