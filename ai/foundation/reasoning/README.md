# Reasoning · 推理模型与 Test-time Scaling

> 不靠把模型无限做大，而靠 **推理时多想一会儿**（更多 token / 搜索 / 自我验证）换准确率。这是 2024–2026 的「第三条缩放律」。

代表：OpenAI o 系列、DeepSeek-R1（GRPO + 显性 `<think>`）、Claude extended thinking、各家 reasoning 模式。

配套 MVP：[mvp.py](./mvp.py)（思维链 + 自我校验 + 按预算扩展尝试次数）。

---

## 一、技术讲解

训练期缩放（更大模型、更多数据）仍然有效，但边际成本极高。推理模型证明：同一底座上，把测试时算力（test-time compute）花在：

- **更长的思维链**（serial：一步步想）；
- **多样本投票 / 搜索**（parallel：同一题采样多条再选）；
- **过程校验**（算不算得对、约束满不满足）；

就能解更大模型「秒答」解不开的数学、代码、规划题。经验上，准确率对「思考 token」近似对数增长，所以要设预算，不能无限想。

训练侧两代故事：

1. **蒸馏 / SFT 思维轨迹**：用老师模型的长 CoT 教学生。
2. **纯 RL 涌现**（R1-Zero 路线）：不先喂人类思维链，用结果奖励（题对了）+ GRPO 一类算法，模型自己长出反思、换解法、验算。

GRPO（Group Relative Policy Optimization）用同一题的一组采样相对打分，省掉单独 value model，是开源推理训练的常用件。

产品上通常暴露：`reasoning_effort` / `think` 开关、隐藏或可见的思考块、超时与最大思考 token。

## 二、功能作用

- **难题准确率**：竞赛数学、复杂代码、多约束规划。
- **Agent 规划**：先想清再选工具，减少胡乱 `tools/call`。
- **可蒸馏**：大推理模型的轨迹可以压进小模型，便宜复用。
- **可控成本**：简单题走快模型，难题才开 thinking（见 [model-routing](../../reliability/model-routing/)）。

副作用：延迟和单价上升；思考内容可能泄漏内部策略（有的厂商隐藏 CoT）；不一定适合闲聊。

## 三、应用场景

| 适合 | 不适合 |
|---|---|
| 数学 / 逻辑 / 代码修复 | 寒暄、翻译、简单抽取 |
| 多步工具规划、排错 | 强实时语音（见 [voice-realtime](../../runtime/voice-realtime/)） |
| 需要验算的财务 / 合规计算 | 只要流畅文案、不要「想太久」 |
| 作为 Agent 的 planner | 每条消息都开最大 thinking |

---

## 四、三种测试时扩展

| 方式 | 做法 | 成本形态 |
|---|---|---|
| **串行 CoT** | 一条越来越长的思考 | 延迟随长度线性增 |
| **并行采样** | n 条独立思路再投票 / 裁判 | 可横向扩 GPU |
| **带验证的搜索** | 生成 → 检查 → 失败则回溯 | 最稳，实现最重 |

MVP 把三者各做了一点：先想，再验，失败则在预算内换一条思路。

## 五、与相邻技术

| 技术 | 关系 |
|---|---|
| 普通 CoT 提示 | 推理模型把「先想后说」训进权重，不只是提示词 |
| [MoE](../moe/) | 很多推理底座本身是 MoE（如 DeepSeek V3） |
| [SLM](../slm/) | 蒸馏后的小推理模型，适合边侧 / 低成本 |
| [Eval](../../reliability/eval/) | 必须把「思考预算 vs 准确率」画成曲线，而不是只报一个分数 |
| [Guardrails](../../reliability/guardrails/) | 思考块也可能含敏感链，注意日志落盘 |

## 六、落地建议

1. **默认关、按路由开**：分类器或小模型判断「这题要不要想」。
2. 设 `max_think_tokens` 与墙钟超时，防止一条请求占满配额。
3. 对可自动验证的题（单测、数值）上 verifier，比盲目加长 CoT 更值。
4. 用户可见回复与思考分离；思考默认不进客服会话记录。
5. Agent 里「想」和「动」交替：想一小段 → 调工具 → 再想，而不是先空想 2000 token。

## 八、本目录 MVP

`mvp.py` 解「猜数字约束」类谜题：生成候选思路、用可执行校验器判定、失败则在预算内换思路。展示 test-time compute ↔ 成功率，不调用外部模型。
