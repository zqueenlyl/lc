## 0. 宏观总揽

### 0.1 一句话认知

**大语言模型 = 一台"只认数字的接龙机器"**：把一段文字切成数字编号（token id），喂进一个巨型的数字变换网络（Transformer），网络吐出一个"下一个编号的概率分布"，按分布抽一个编号，拼回去，再喂一次……循环到结束。所谓"会写文章、会推理"，全部来自这个单调循环 + 网络参数里压缩的海量语料统计规律。

训练做的是**压缩**：海量语料 → 调参，把"世界里知识"压进网络权重；推理做的是**解压**：顺着权重，一步步猜最合理的下一个 token。

### 0.2 全链路 = 一条主线，两个生命周期

```
文本输入 → [环节1] Tokenizer 切词编号 → [环节2] Embedding 查表成向量
         → [环节3] 位置编码注入顺序 →  ┐
                                        │  Transformer Block × N 层（每个 token 都过）：
         ↓  进入 Block                 │  [环节4] Attention（跨位置交换信息）
         ↓                             │  [环节6] 残差 + 归一化（保深度稳定）
         ↓                             │  [环节5] FFN 逐点变换（参数大头；MoE 在此替换）
         ↓                             └→ [环节7] Block 堆叠 = 逐层"提炼语义"
         ↓
         ↓ 训练生命周期（一次算整条序列）        ↓ 推理生命周期（一次只长 1 个 token）
         ↓                                    ↓
[环节8] LM Head → 全位置 logits       [环节8] LM Head → 末尾 1 行 logits
         ↓                                    ↓
     交叉熵 loss（标签=右移一位的序列）   [环节10] softmax → 采样下一个 token
         ↓                                    ↓
    反向传播更新全部权重 ← 全流程               拼回序列，回环节1的出口循环
         ↓                                    （KV Cache 让每步只算增量，见环节10）
[环节9] 数据工程 + 预训练 + SFT + 对齐
         ↓
   [环节11] 服务化：vLLM/SGLang 等引擎
```

- **训练**：整条序列并行前向（靠因果 Mask 保证"不偷看未来"），一次能学所有位置。
- **推理**：自回归，一次只能多生成 1 个 token（串行、吃带宽），是全行业优化的主战场。

### 0.3 先把"为什么长这样"记住（演进因果链）

| 历史痛点 | 对应解法（Transformer 里的零件） |
|---|---|
| RNN（recurrent neural network，循环神经网络）串行太慢、长距离记不住 | 注意力一次看全部（并行），去掉循环 |
| 注意力并行算完就丢顺序 | 位置编码（RoPE，Rotary Position Embedding，旋转位置编码；等）把"第几个"注入 |
| 只看词义不够，要知道词间关系 | Attention 的 Q/K/V 让词与词按相关度交换信息 |
| 深网络梯度消失/训练不稳 | 残差连接 + LayerNorm/RMSNorm |
| 注意力只会"汇总"，不会"加工" | 每层再跟 FFN（feed-forward network，前馈网络）做逐 token 非线性变换（参数大头） |
| 单一注意力表达能力不足 | Multi-Head：多个子空间并行看 |
| 上下文变长后 KV Cache 太大 | MQA（Multi-Query Attention）→ GQA（Grouped-Query Attention）→ MLA（Multi-head Latent Attention）；滑窗/稀疏注意力 |
| 算力买不起超大稠密模型 | MoE（Mixture of Experts，混合专家）：参数大、每 token 只激活一小部分 |

> 完整演进史（RNN/LSTM 怎么被替代、三种架构如何推下一个 token）见 [环节 07 详解](./环节07-Block堆叠与整体架构详解.md)；训练与推理的机制差见 [环节 09](./环节09-训练管线详解.md) / [环节 10](./环节10-推理解码与KV缓存详解.md)。

## 2. 结构全景图（全局唯一一张"模型长什么样"）

> 另外两张全景图已并入环节详解：**预训练流程图 → [环节 09](./环节09-训练管线详解.md) §0**；**推理流程（Prefill/Decode）图 → [环节 10](./环节10-推理解码与KV缓存详解.md) §0**。

```
输入上下文 Tokens（prompt + 已生成部分）
   │
   ▼
┌───────────────────────────────────────────────┐
│              Input Embedding                  │  token → 向量
├───────────────────────────────────────────────┤
│         + RoPE 位置编码（旋转注入）            │  位置信息
├───────────────────────────────────────────────┤
│          Multi-Head Attention                 │  ★ Q,K,V 投影
│    Q 来自当前位置，K/V 来自全部历史（含 KV Cache）│   → 算注意力权重
│    MHA / GQA / MLA（压缩 KV）                  │  → 加权求和
├───────────────────────────────────────────────┤
│            Add & Norm（残差 + LayerNorm）      │  防梯度消失
├───────────────────────────────────────────────┤
│               Feed-Forward（FFN/SwiGLU）        │  逐位置非线性变换
│     （MoE 模型此处为：Router 激活 Top-K 专家）   │
├───────────────────────────────────────────────┤
│            Add & Norm（残差 + LayerNorm）      │
├───────────────────────────────────────────────┤
│   ┌───────────────────────────────────────┐   │
│   │        ↑ 重复 N 层（如 32/80 层）      │   │
│   └───────────────────────────────────────┘   │
├───────────────────────────────────────────────┤
│               Linear Head（词表映射）          │  向量 → 词表 logits
├───────────────────────────────────────────────┤
│           Softmax → 采样（temperature/top-p）  │   → 下一个 token
└───────────────────────────────────────────────┘
```

看图要点（每行都对应一个环节详解文档）：

- GPT 系是 **Decoder-only（仅解码器）**：没有编码器（encoder）与交叉注意力（cross-attention），自回归生成时每步只看左侧上文（[环节 07](./环节07-Block堆叠与整体架构详解.md)）；
- 两大子模块：**Attention**（跨位置交互，O(n²)，KV Cache 由此而来，[环节 04](./环节04-Attention注意力详解.md)）+ **FFN**（逐位置变换，参数量大头，[环节 05](./环节05-FFN激活与MoE详解.md)）；
- 骨架：N 层堆叠 + 残差连接 + 归一化——这是它能"深"的原因（[环节 06](./环节06-残差连接与归一化详解.md)）；
- 变体映射：MHA → GQA/MLA（省 KV Cache）；FFN → MoE（大参数小激活）；绝对位置 → RoPE/ALiBi。
