# 环节 06 · 残差连接（residual connection）+ 归一化（normalization）（让网络"深得下去"）

> 全链路第六站：不改变模型"能干什么"，却决定"能不能训得动、训得稳"。
> 所属总揽：[环节00-总揽与环节导航.md](./环节00-总揽与环节导航.md) 环节 06。
> 相邻环节：结构上与 Attention/FFN 同处一个 Block（见 [环节 07](./环节07-Block堆叠与整体架构详解.md)），此处单讲这对"脚手架"。
> 适合人群：面试高频冷门——人人都知道有 LayerNorm，能讲清"为什么 Pre-LN + RMSNorm"才是加分项。

---

## 1. 干什么

Transformer 堆几十上百层，必须解决两个老问题：

1. **梯度消失/爆炸（vanishing / exploding gradients）**：层太深，反向传播（backpropagation）梯度在乘积中指数缩水；
2. **分布漂移（distribution shift）**：每层输出数值范围越来越离谱，训练不稳定、收敛（convergence）慢。

解法是一对固定搭档：**残差连接**（给梯度开"高速公路"）+ **归一化**（把每层输入拉回稳定尺度）。

---

## 2. 怎么干：一个 Block 内的标准排布

```
典型 Block 内（Pre-LN 版，现代主流）：
X ← X + Attention(LN(X))      # 先归一化再做注意力，结果加回主干（残差）
X ← X + FFN(LN(X))            # 同样再加工一次
```

对应公式（与 [环节 04](./环节04-Attention注意力详解.md) §2 数值走查 Step 6 衔接）：

```
O     = Attention(X)                              # 注意力输出
X ← X + O                                         # 第一次残差
h     = LayerNorm(X) / RMSNorm(X)                 # 归一化（对每个 token 独立）
h     = FFN(h)                                    # 逐 token 非线性变换（环节05）
X ← X + h                                         # 第二次残差
```

**残差为什么有效**：`X ← X + f(X)` 的形式让反向传播的梯度能沿恒等旁路（identity shortcut）直接回传（∂L/∂X 含一项恒等（identity）梯度），与 LSTM 的"记忆传送带"、ResNet 的恒等映射（identity mapping）是同一个思想——给梯度修高速公路。

---

## 3. 归一化方法对比

| 归一化 | 做法 | 优点 | 缺点 | 代表 |
|---|---|---|---|---|
| **LayerNorm** | 对每个 token 的特征维（feature dimension）做"减均值、除方差，再 ×γ + β"（`(x−μ)/√(σ²+ε)·γ+β`） | 稳定、理论成熟 | 均值部分要统计，算子略重 | BERT、原论文 |
| **RMSNorm** | 只做"除以均方根 ×γ"，**不做减均值** | 更简单更快，实测够稳 | 理论解释略弱 | LLaMA、Qwen、DeepSeek 全系事实标准 |

> 对比理解：LayerNorm 用"均值方差"两统计量把分布拉回标准形；RMSNorm 假设"减均值"并非必要，只除以均方根（root mean square，RMS）即可把尺度稳住——省掉一次统计，算子更轻，实践中足够稳，于是成为现代开源模型默认。

---

## 4. 残差排布对比

| 残差排布 | 顺序 | 特点 |
|---|---|---|
| Post-LN（原版） | 子层输出之后才归一化：`LN(X + Attn(X))` | 深层训练易崩，需要 warmup 等技巧 |
| **Pre-LN（主流）** | 先归一化再进子层，残差留原值：`X + Attn(LN(X))` | 训练极稳、深层友好 → 现代模型默认 |

**一句话记法**：Post-LN 归一化的是"混合后的信号"（梯度要穿过 LN，深层不稳）；Pre-LN 把归一化塞进子层内部、让残差主干保持干净恒等（identity）——梯度更直、更好训。这就是为什么现代模型几乎清一色 Pre-LN。

---

## 5. 组合题的答案：为什么 LLaMA 用 RMSNorm + Pre-LN + SwiGLU

面试常考"LLaMA 的架构选择为什么这么定"，标准答法是对着三个部件的动机逐个说：

| 部件 | 动机 |
|---|---|
| RMSNorm | **便宜**：省掉减均值统计，算子更轻，实测够稳 |
| Pre-LN | **稳**：残差主干干净恒等，深层训练不崩 |
| SwiGLU（[环节 05](./环节05-FFN激活与MoE详解.md)） | **好**：门控非线性表达力更强 |

三者恰好对应"**便宜、稳、效果好**"三个优化维度——这个组合答法既完整又显功力。

## 6. 面试高频追问

1. LayerNorm 与 BatchNorm（batch normalization，批归一化）的区别？→ 前者对每个样本的特征维归一（序列模型标配，batch 无关）；后者按 batch 统计（对变长/小 batch 不稳）。
2. RMSNorm 为什么能去掉减均值（mean centering）？→ 主要矛盾是尺度漂移（scale shift）而非均值漂移；只除 RMS 已能稳定训练，算子更省。
3. Post-LN 为什么难训？→ 归一化在残差汇合点之后，梯度要额外穿过 LN 的统计量依赖；Pre-LN 让残差旁路保持恒等，梯度直达。
4. 残差连接的本质？→ 恒等旁路 + 学习"增量"：`X + f(X)`；与 ResNet、LSTM 记忆传送带同一思想。
5. 归一化在推理时还起作用吗？→ 训练算出的 γ/β 与统计量直接用于推理，结构不变。
